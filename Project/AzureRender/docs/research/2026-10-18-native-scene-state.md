# 原生场景状态与辐照度分支

日期：2026-10-18。
阶段：NR1、NR4。
范围：本机原生索引与静态消费者。

## 索引契约

`NativeIrradianceIndex/2` 描述原生状态分支。
每个分支包含标识、索引数量和场景索引列表。
场景索引引用同一文件的名称数组。
分支标识属于原生数据中的不透明键。

| 分支标识 | 场景名称 | 对应文件 |
| --- | --- | --- |
| `0` | 空激活集合 | `iv_0_0.bytes` |
| `1215527338` | `under_construction` | `iv_1215527338_0.bytes` |

解析结果保留 `scenario_indices` 与名称列表。
`local_state_mask` 按本地名称数组顺序生成。
原生共享名称表可以使用另一组位位置。
工具据此分别记录本地语义与原生掩码。

## 原生消费者证据

来源为本机游戏的 `UnityPlayer.dll`。
文件与索引指纹保存在运行证据中。

| 地址 | 已确认行为 |
| --- | --- |
| `0x1800b6516` 至 `0x1800b65ae` | 读取名称并注册到共享名称表 |
| `0x1800b65f4` 至 `0x1800b664a` | 读取分支及变长场景索引列表 |
| `0x1800b6632` | 按共享名称编号设置状态位 |
| `0x1800b6a30` 至 `0x1800b6a3f` | 将映射表的分支键替换为状态掩码 |

上述加载器检查 `0x03000002` 版本。
本机中庭索引使用该版本。

`SetActiveSceneStateMask` 按名称顺序激活状态。
其入口地址为 `0x180566d60`。
该入口与当前 V3 路径的运行时联系待确认。
