# 原生反射常量的离线数学参考

此能力属于 NR5 原生反射调查。
工具接收运行时探针结构，输出八组四维常量。
场景序列化字段到该结构的映射仍待确证。
原生激活状态、纹理层分配与渐变状态由调用方提供。

## 来源与证据

来源为本机游戏的 `UnityPlayer.dll`。
SHA-256 为 `9aa9397a6c5ee4fa083ea379b81ff14019eeba26a76d15446318d5947fb3d2d0`。
调查使用静态反汇编，游戏文件保持只读。

| 地址 | 已观察行为 |
| --- | --- |
| `0x18021cdb0` | 整理探针并写出常量 |
| `0x180dc5e80` | 探针指针数组排序 |
| `0x180dc70e0` | 比较结构偏移 `+4` 与 `+0x110` |
| `0x180dbe9d0` | 三通道亮度加权 |

证据目录为 `build/runs/20261017-151417-native-render-restoration-e7723b/reflection-native-asm/`。
比较器完整范围为 `0x180dc70e0` 至 `0x180dc70fe`。
常量写入位于 `0x18021d08b` 至 `0x18021d3e5`。
内部调用名称表的注册控制流仍待交叉验证。

## 输入与输出

工具为 [reflection_semantics.py](../../tools/endfield_native/reflection_semantics.py)。
`pack_runtime_probe` 接收长度为 `0x130` 的字节串。
它还要求显式传入纹理数组层与渐变系数。
输入表示运行时结构，调用方负责验证其来源。

第 `i` 个局部探针对应 `CB2[12+8*i]` 起的八行。
矩阵字段按原内存顺序读取。

| 相对行 | 输入与计算 |
| --- | --- |
| 0 | `+0xa4` 的 27 个浮点数，转为亮度并取 `[3,1,2,0]` |
| 1 | `+0x18` 的三个半轴，以及纹理数组层 |
| 2—4 | `+0x64` 矩阵的前三列 |
| 5 | 三轴混合宽度倒数，以及 `+0x14` 的强度 |
| 6 | 标志位 2、标志位 4 的反值、`+4` 整数、渐变系数 |
| 7 | `+0x24` 矩阵的平移，以及半轴向量长度 |

球谐系数按红、绿、蓝各九项连续排列。
亮度权重为 `(0.212672904, 0.715152204, 0.072175004)`。
此写入函数直接打包系数，基函数缩放需追溯上游。
混合宽度倒数为 `1/((1-min(influence,0.99))*extent)`。

排序先按 `+4` 的有符号整数降序。
平局按 `+0x110` 的无符号 64 位键升序。
两个键相同的原生排序顺序尚未定义。
`+4` 的正式字段名仍待序列化桥接证据。

## 验证与边界

在 `tools` 目录运行以下命令：

```powershell
python -m unittest test_endfield_native_reflection_semantics
```

四项测试覆盖颜色排列、矩阵、排序和非法输入。
数学结果使用解码后的单精度常量和双精度运算。
逐指令浮点舍入与现场探针激活属于后续验证。
原生场景验收还需确认字段映射和着色器消费结果。
