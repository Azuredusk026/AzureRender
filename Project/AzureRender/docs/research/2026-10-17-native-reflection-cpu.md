# 原生反射常量的离线数学参考

此能力属于 NR5 原生反射调查。
工具接收运行时探针结构，输出八组四维常量。
静态序列化参数可经转换工具生成常量。
原生激活状态、纹理层分配与渐变状态由调用方提供。

## 来源与证据

来源为本机游戏的 `UnityPlayer.dll`。
SHA-256 为 `9aa9397a6c5ee4fa083ea379b81ff14019eeba26a76d15446318d5947fb3d2d0`。
调查使用静态反汇编，游戏文件保持只读。

| 地址 | 已观察行为 |
| --- | --- |
| `0x18021cdb0` | 整理探针并写出常量 |
| `0x180dc5e80` | 探针指针数组排序 |
| `0x180dc70e0` | 比较结构偏移 `+4` 与 `+0x110` |
| `0x180dbe9d0` | 三通道亮度加权 |
| `0x180148650` | 编码三元组属性标识并查询字段 |
| `0x180e70b70` | 读取反射字段并填充原生对象 |
| `0x180417d30` | 从原生对象生成 ECS 探针结构 |
| `0x180418a00` | 将探针结构复制至组件存储 |

证据目录为 `build/runs/20261017-151417-native-render-restoration-e7723b/reflection-native-asm/`。
比较器完整范围为 `0x180dc70e0` 至 `0x180dc70fe`。
常量写入位于 `0x18021d08b` 至 `0x18021d3e5`。
内部调用名称表的注册控制流仍待交叉验证。

## 输入与输出

工具为 [reflection_semantics.py](../../tools/endfield_native/reflection_semantics.py)。
`pack_runtime_probe` 接收长度为 `0x130` 的字节串。
它还要求显式传入纹理数组层与渐变系数。
输入表示运行时结构，调用方负责验证其来源。

第 `i` 个局部探针对应 `CB2[12+8*i]` 起的八行。
矩阵字段按原内存顺序读取。

| 相对行 | 输入与计算 |
| --- | --- |
| 0 | `+0xa4` 的 27 个浮点数，转为亮度并取 `[3,1,2,0]` |
| 1 | `+0x18` 的三个半轴，以及纹理数组层 |
| 2—4 | `+0x64` 矩阵的前三列 |
| 5 | 三轴混合宽度倒数，以及 `+0x14` 的强度 |
| 6 | 标志位 2、标志位 4 的反值、重要性、渐变系数 |
| 7 | `+0x24` 矩阵的平移，以及半轴向量长度 |

球谐系数按红、绿、蓝各九项连续排列。
亮度权重为 `(0.212672904, 0.715152204, 0.072175004)`。
此写入函数直接打包系数，基函数缩放需追溯上游。
混合宽度倒数为 `1/((1-min(influence,0.99))*extent)`。

排序先按 `+4` 的有符号整数降序。
平局按 `+0x110` 的无符号 64 位键升序。
两个键相同的原生排序顺序尚未定义。
`+4` 为重要性，来源于原生对象的 `+0x58`。

## 序列化参数桥接

入口为 [reflection_bridge.py](../../tools/endfield_native/reflection_bridge.py)。
`decode_serialized_probe` 接收读取器的 `raw_fields`。
`pack_serialized_probe` 另外接收数组层与渐变系数。
它输出与运行时参考工具一致的八行常量。

属性编码为 `((component<<8)|field)<<16|index`。
探针组件的三元组为 `(16,字段序号,0)`。
下表给出静态转换链的字段关系。

| 字段序号 | 原生对象偏移 | ECS 偏移 | 语义 |
| --- | --- | --- | --- |
| 0 | `0x5c` | `0x18` | 尺寸取绝对值后除以二 |
| 3 | `0x8c` | `0x08` | 三轴影响比例 |
| 4 | `0xa4` | `0x24` | 盒到世界矩阵 |
| 5 | `0xe4` | `0x64` | 世界到盒矩阵 |
| 6 | `0x198` | `0x14` | 反射强度 |
| 7 | `0x1e8` | 标志位 2 | 盒投影 |
| 8 | `0x44` | 控制 SH 分支 | 模式 |
| 9 | `0x58` | `0x04` | 重要性 |
| 10 | `0x1ec` | `0xa4` | 模式 0 的烘焙 SH |
| 11 | `0x258` | `0xa4` | 模式 2 的自定义烘焙 SH |
| 13 | `0x74` | 标志位 4 | 等于 1 时使用球形混合 |
| 17 | `0x190` | `0x118` | 纹理路径哈希 |

重要性按有符号 16 位整数读取，并限制到非负值。
矩阵采用静态序列化快照。
运行时变换可能使原生对象重新计算矩阵。
动态变换的等价性需要单独验收。

排序键来自注册事件中的两个 64 位值异或。
该事件与序列化字段的对应关系仍待确证。
工具将注册排序键与激活状态保留为 `null`。
调用方显式提供数组层和渐变系数。

白黄参考候选配置位于同一证据目录的上一级。
文件名为 `white-yellow-reflection-gpu-candidate.json`。
它记录实体 `57463294` 与完整纹理身份。
其验证状态使用数组层 1、渐变系数 1。

配置包含六面八级原生纹理和各文件指纹。
全部 34 个探针均可解析静态参数。
其中模式 0 的探针从字段 10 读取 SH。
候选配置的场景阶段激活关系仍待运行时证据。

## 验证与边界

在 `tools` 目录运行以下命令：

```powershell
python -m unittest test_endfield_native_reflection_semantics
python -m unittest test_endfield_native_reflection_bridge
```

十项测试覆盖字段桥、模式、矩阵、排序和非法输入。
数学结果使用解码后的单精度常量和双精度运算。
逐指令浮点舍入与现场探针激活属于后续验证。
原生场景验收还需确认激活关系和着色器消费结果。
