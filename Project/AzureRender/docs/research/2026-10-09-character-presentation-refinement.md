## 已核实原因

| 问题 | 原因 | 实现 |
| --- | --- | --- |
| 宽半影条纹 | 方格采样在宽核内存在间隙。 | 圆形足迹逐纹素积分。 |
| 局部旋涡波纹 | 稀疏圆盘采样遗漏细小遮挡。 | 所有覆盖纹素参与加权比较。 |
| 半影宽度阶梯 | 遮挡搜索把连续坐标取整。 | 比较后插值遮挡质量与深度矩。 |
| 靴子三角斑块 | 单三角平面外推跨越曲面。 | 按曲率限制接收面深度修正。 |
| 接触阴影运动残差超标 | 分辨率提高与圆盘核改变有效柔化足迹。 | 接触半径按纹素密度与圆盘覆盖校准。 |
| 灰雾感 | 调色把线性黑位抬至 0.03。 | 展示预设保留零黑位。 |
| 材质差异弱 | 粗糙度下限压缩贴图区分。 | 保留表面贴图的有效粗糙度。 |
| 高光缺乏质感 | 简化高光缺少微表面能量归一。 | 衣料与金属采用 GGX 响应。 |
| 介质反射偏弱 | 源参数的反射率换算缩小一半。 | 0.5 对应 4% 的法向反射率。 |
| 主光高光偏弱 | 高光贡献未应用主光颜色和强度。 | 主光与局部光使用各自辐射量。 |
| 皮肤受光区苍白 | 身体与脸部色阶亮部接近中性白。 | 亮部保留暖色，中间调连续过渡。 |
| 肤色色阶贡献弱 | 环境与补光只接收色阶亮度。 | 间接光混合半量归一化色阶色度。 |

## 阴影契约

阴影图集为 4096×4096，分为四个级联。
每个级联拥有 2048×2048 的深度范围。
采样在当前级联内部夹取，深度使用原始纹素。
可见度先比较，再按覆盖权重积分。

圆形核边界使用一纹素的覆盖过渡。
半影宽度仍受配置的最大半径限制。
遮挡深度矩按真实遮挡比例累积。
取样位置变化时，遮挡比例保持连续。

接触半径按级联纹素密度缩放。
1024 纹素级联的圆盘基准半径为 3。
当前 2048 纹素级联的接触半径为 6。
所有半径均受配置的最大值限制。

积分以二乘二纹素块执行。
内部采用四纹素聚集采样，边界逐纹素夹取。
向量权重和接收平面修正保持完整圆盘覆盖。
真实深度纹理验证取样顺序和级联隔离。

接收面修正按平面深度导数计算。
曲率由几何法线和世界位置的导数估计。
过滤足迹的法线变化控制修正权重。
平面保留修正，曲面采用受控接收偏置。

接收偏置包含毫米基准与纹素尺寸项。
角度项使用几何法线和主光方向。
几何法线定义接收面的宏观方向。
近接触与斜面需共同验证。

## 色彩与表面契约

展示预设的曝光为 0，饱和度为 0.98。
对比度为 1，黑位保持零。
晚霞环境贴图、主光方向和相机保持固定。

衣料、金属和普通表面使用 GGX 分布。
可见度采用高度相关的 Smith 项。
菲涅耳项按视线与半角方向计算。
介质反射率按源参数的八百分比尺度换算。

贴图粗糙度保留法线方差过滤。
人物皮肤和头发继续使用自身风格响应。
金属与非金属区域由贴图遮罩区分。

皮肤和脸部色阶存储线性 RGB 系数。
图集以 UNORM 读取，行中心按材质类别定位。
环境和补光混合半量色阶归一化色度。
白色色阶、关闭色阶及其他材质保持中性响应。

受光肩部的隔离色阶样本接近中性白。
样本红蓝差为 0.30/255，高光贡献为零。
该证据将问题定位至漫反射色阶与补光。
肤色校准同时覆盖脸部与身体的三个光照预设。
受光肩部最终色阶红蓝差为 8.1094/255。
该局部检查的最低门槛为 8/255。
官方光照与色彩标定仍属于研究边界。
高光强度与描边仍使用材质参数。
