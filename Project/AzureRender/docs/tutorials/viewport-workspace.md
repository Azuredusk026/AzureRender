# 使用场景视口

本指南适用于编辑器的场景视口。
视口工具栏显示当前投影和变换选项。
渲染图像与输入位置共用工作区计算的图像边界。

## 观察场景

选择对象后，点击“聚焦选择”调整相机。
“透视”或“正交”按钮打开视图选项。
菜单可切换投影、轴向观察和诊断覆盖层。
按钮显示当前相机服务的投影状态。

在图像区域按住右键，可观察和移动相机。
WASD 控制水平运动，E 与 Q 控制高度。
Shift 加速，右键导航期间滚轮调整速度。
Esc 或失去焦点时释放导航捕获。

## 变换与放置

“变换选项”提供世界与局部坐标、活动与包围盒轴心。
吸附和步长继续使用工程编辑设置。
移动、旋转和缩放通过主工具栏选择模式。
手柄拖拽使用既有变换事务与撤销记录。

从资源浏览器拖放兼容资源到图像中，可放置对象。
放置服务依据图像内位置生成射线并校验资源。
窗口和 DPI 改变后，视口保持图像与输入的对应关系。
检查结果见[视口验证](../acceptance/ui7/2026-10-12.md)。
