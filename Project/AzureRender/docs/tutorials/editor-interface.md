# 编辑器界面使用说明

## 开始制作

双击安装目录下的 `bin/AzureRender.exe`。
项目中心提供最近项目、打开项目和新建项目。
最近列表可以按名称或路径搜索。
项目移动后，使用重新定位或刷新检查状态。

移除记录只清理最近列表，项目文件保留。
新建时选择父目录、项目名称和服务提供的模板。
加载期间显示实际任务步骤，失败原因显示在项目中心。
启动日志入口用于查看详细诊断。

## 工作区

顶栏按文件、编辑、窗口、物体和帮助组织操作。
主工具条提供保存、运行、暂停、停止和发布。
窗口较窄时，模拟与单步进入更多菜单。
窗口菜单可以恢复隐藏面板或重置布局。

左侧场景层级管理对象与父子关系。
场景容器行代表场景本身。
把对象拖到场景容器或空白区域可解除父级。
拖到对象行上沿可调整同级顺序。

场景工具提供平移、移动、旋转和缩放。
聚焦选择用于快速找到当前对象。
投影与变换菜单管理观察方式、坐标空间和吸附。
视口快捷键在文本编辑时由输入焦点规则保护。

右侧属性面板显示选中对象及其组件。
搜索框可以筛选组件名称、属性标签与字段名。
字段修改、重置和多选编辑使用统一撤销服务。
资源浏览器提供目录导航、类型筛选、搜索与网格视图。

## 脚本与材质

脚本制作面板可以创建脚本并附加到选中对象。
打开源文件后，在外部编辑器修改内容。
重新加载入口使用既有脚本后端服务。
C# 源文件经托管构建生成可附加资源。

材质资源提供参数编辑、预览与节点图。
节点布局与连接随材质保存。
场景材质槽分配使用场景撤销记录。
材质资源与场景文档的保存范围分别管理。

二维 `.azure2d` 文件可经资源管线导入与校验。
运行时通过现有二维显示服务加载。
当前界面提供资源管理入口。
独立二维可视化画布仍需专门的制作工具阶段。

## 设置、诊断与发布

个人偏好保存在用户配置目录。
项目设置随项目保存。
渲染诊断只作用于当前会话。
设置搜索同时匹配名称与说明。

日志面板显示任务、错误与运行记录。
问题面板可以定位关联对象或资源。
发布面板显示发布工具报告的真实步骤。
完成后可打开输出目录或查看发布日志。

开发用控件目录位于窗口菜单。
它展示共享按钮、状态反馈和品牌绘制。
控件目录默认隐藏，显示状态随工作区保存。

## 模块归属

| 内容 | 所属目录 | 主要依赖 |
| --- | --- | --- |
| 主题、控件、容器、品牌 | `src/ui/` | ImGui |
| 菜单、工具条、状态区 | `src/editor/shell/` | 编辑器服务与公共 UI |
| 层级、属性、资源呈现 | `src/editor/panels/` | 面板上下文与注入能力 |
| 属性字段与编辑事件 | `src/editor/properties/` | 反射与编辑契约 |
| 项目打开与最近历史 | `src/editor/projects/` | 项目服务与用户配置 |
| 系统窗口图标 | `src/platform/` | GLFW 与传入像素 |

面板拥有界面状态，业务服务拥有文档与操作。
宿主装配服务、后端和专用呈现回调。
编辑器依赖公共 UI，公共 UI 仅依赖 ImGui。
