# 编辑器交互教程

> 文档类型：操作教程
> 日期：2026-10-08
> 适用范围：编辑器输入、场景导航与文档保护

## 选择与定位

在大纲单击对象，更新当前选择。
双击对象，按世界边界定位相机。
按 F 定位整个选择集合。
定位保留观察方向，并预留构图边距。

Ctrl 加点击用于累计选择。
无网格节点使用世界位置与默认半径。
导航、选择及工具切换属于编辑会话状态。
场景保存内容保持由制作操作控制。

## 场景导航

按住右键拖动，原地观察周围。
向右拖动时向右看，向上拖动时向上看。
右键配合 WASD 飞行，Q/E 垂直移动。
飞行时按 Shift 临时加速。

Alt 加左键绕导航中心旋转。
中键拖动平移，滚轮调整观察距离。
松开按钮结束捕获，窗口失焦释放导航。
关闭视口后，输入归其他可见面板。

## 编辑工具与设置

场景视口中的 W/E/R 切换移动、旋转和缩放。
Q 选择工具，F 定位选择。
文本框与弹窗优先拥有输入。
右键导航期间，按键用于飞行。

设置面板中的 `editor.camera` 项控制导航参数。
反转设置分别控制水平和垂直方向。
飞行速度、加速倍率与轨道灵敏度均可调整。
`editor.shortcuts` 项使用大写字母重绑场景动作。

## 保存与恢复

Ctrl+S 保存场景，Ctrl+Z/Ctrl+Y 撤销和重做。
回到保存点时，未保存标记清除。
Play/Stop 保留编辑文档并恢复编辑视角。
运行输入需要场景视口焦点。

关闭或重载未保存文档时，选择保存、放弃或取消。
保存失败保留文档、选择和错误详情。
取消返回编辑，放弃按所请求动作继续。
自动工具显式声明关闭策略。

保存前会校验并保留磁盘中的完整文档。
项目备份位于项目根目录的 `.azure/recovery`。
独立场景的备份位于场景目录的同名子目录。
备份按来源身份命名，元数据记录路径和字节数。

恢复时先保留当前文件，再复制备份到来源路径。
重开项目或场景，检查内容及资源引用。
关卡保存使用同目录临时文件与原子替换。
保存失败时清理临时文件，并保留目标内容。

交互启动使用 `--editor-close-policy ask`。
自动任务按目的选择 `save` 或 `discard`。
体验验证分为界面回放、原生事件和实体键鼠。
各类证据按实际执行情况记录。
