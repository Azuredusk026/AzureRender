# 选择对象与编辑属性

本指南适用于已打开工程的编辑器。
层级面板显示场景对象，属性面板显示当前选择。
写入操作使用编辑事务，支持撤销和重做。

## 查找与选择

在层级搜索框输入名称或对象标识。
没有匹配项时，点击“清除搜索”恢复对象列表。
Ctrl 点击切换选择，Shift 点击选择可见范围。
双击对象将场景相机聚焦到该对象。

将对象拖到另一个对象上，可调整父节点。
拖到场景名称或列表空白处，可移到场景顶层。
拖到对象行上沿，可插入该对象之前的同级位置。
服务校验父子关系，非法操作产生诊断。
对象右键菜单提供删除、复制和子树导出。

## 编辑与恢复属性

选择一个对象后，可编辑名称、可见性和组件。
多选时，属性面板显示共享组件及不同值状态。
坐标轴按钮恢复对应属性的声明默认值。
窄属性列按纵向排列坐标轴。

右键属性可恢复整项默认值。
右键组件可删除允许移除的组件。
连续编辑合并为一次撤销记录。
播放与构建期间，文档写入按会话状态保护。

引用属性可搜索兼容对象或资源。
点击“选取”后，从层级、视口或资源面板挑选。
“定位”显示已有引用，“清空”按属性规则执行。
Esc 或“取消选取”结束引用挑选。

搜索框和文字输入框取得焦点时，保护文档快捷键。
保存后重新打开工程，可继续编辑已有属性和引用。
检查结果见[层级与属性验证](../acceptance/ui6/2026-10-12.md)。

## 创建物体与附加脚本

层级的“创建”菜单提供空物体及基础类型。
选中物体时，在该物体下创建子物体。
清空选择后创建场景顶层物体。

属性面板的“附加脚本”提供已有脚本列表。
也可将脚本资源拖到该按钮。
“新建脚本”进入脚本面板，Lua 支持创建并附加。
附加使用一次事务，Ctrl+Z 可撤销。

C# 源文件通过托管构建流程生成 `.azscript` 后附加。
已有脚本在组件引用字段中更换。
