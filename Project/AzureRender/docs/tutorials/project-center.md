# 从项目中心制作并发布游戏

本指南使用完整的 Windows x64 引擎安装目录。
编辑器和游戏运行需要支持 Vulkan 的驱动。
项目与发布目录应使用可写的独立位置。

## 创建 Monica

1. 双击安装目录中的 `bin/AzureRender.exe`。
2. 在项目中心选择“新建项目”。
3. 填写项目名称 `Monica` 和已有的父目录。
4. 选择“可玩游戏”模板，然后点击“创建项目”。

模板完成复制与校验后，程序进入编辑器。
工程文档为 `Monica/project.azureproject`。
资产和脚本位于工程内部，缓存位于 `.azure`。
用户偏好与最近记录保存在用户配置目录。

## 保存与继续制作

在层级面板选择对象，在属性面板编辑名称或属性。
工具栏的 Save 按钮保存当前文档。
关闭时有未保存修改，选择保存、放弃或取消。

再次双击引擎入口，在最近项目中打开 Monica。
也可选择“打开项目”并浏览工程文档。
移动工程后，通过新位置重新打开工程文档。
最近记录依据项目身份更新位置。

失效记录显示原因，并提供重新定位入口。
版本不兼容或打开失败时，项目中心保留错误提示。
启动日志可从项目中心打开。

## 从 GUI 发布

1. 在编辑器工具栏点击 Build。
2. 确认 Release 引擎安装目录。
3. 填写与工程和引擎分离的游戏输出目录。
4. 点击 Build Windows game，等待任务结束。

编辑器保存当前文档，再调用安装树的发布工具。
面板显示验证、复制、包校验和目录提交阶段。
任务结束后，可打开输出目录或构建日志。
构建日志位于工程 `.azure/game-build.log`。

完整游戏目录包含 `Monica.exe` 和包内 Runtime。
资源、配置、依赖和许可随目录分发。
复制整个游戏目录到其他位置，再运行 `Monica.exe`。
启动失败时，查看 `captures/game-startup.log`。

## 安装与目录

| 目录 | 内容与用途 |
| --- | --- |
| 引擎安装目录 | `bin`、Runtime、资源、模板与附带工具 |
| 项目目录 | 工程文档、资产、脚本和项目配置 |
| 项目 `.azure` | 可重建缓存、构建日志和中间结果 |
| 用户配置目录 | 最近项目、偏好、停靠布局和引擎日志 |
| 游戏输出目录 | 项目命名入口、Runtime、资源与配置 |
| 源码与开发构建目录 | 开发者构建引擎所需的输入与产物 |

Windows 用户配置默认位于 `%LOCALAPPDATA%/AzureRender/editor`。
安装版发布工具附带独立 Python 标准库环境。
工程和发布包依据明确根目录解析资源。
命令行发布与包核验见[游戏发布](../runtime/game-publishing.md)。
