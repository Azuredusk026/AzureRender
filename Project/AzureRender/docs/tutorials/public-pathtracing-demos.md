# 打开、编辑与发布公开光追演示

## 从哪里启动

本机安装入口为：

```text
D:/Assigment/2609/FYP/Project/AzureRender/build/ux-2026-10-14/Engine/bin/AzureRender.exe
```

双击入口，在项目中心选择“打开项目”。
按下表选择项目文件。

| 演示 | 项目文件 | 观察重点 |
| --- | --- | --- |
| 金属头盔 | `D:/Project/AzureRenderDemos/DamagedHelmet/project.azureproject` | 面罩反射、金属高光、表面法线细节 |
| 完整棋盘 | `D:/Project/AzureRenderDemos/ABeautifulGame/project.azureproject` | 棋子接触阴影、遮挡、柔和照明 |
| 粗糙玻璃 | `D:/Project/AzureRenderDemos/TransmissionRoughnessTest/project.azureproject` | 背景穿透、折射、粗糙度造成的模糊变化 |

工程的素材和关卡保存在各自 `assets` 目录。
可以移动整个工程目录，再从项目中心打开。

## 怎样观察与修改

1. 在层级选择 `camera`，点击“查看相机视角”。
2. 打开“窗口 → 环境”，确认渲染模式为路径追踪。
3. 保持相机静止，等待采样计数达到 256。
4. 切换“预览降噪”，比较原始采样和滤波画面。
5. 选择 `key` 或 `fill`，移动灯光并观察重新累积。
6. 修改完成后保存，关闭再打开工程。

默认使用 256 采样、10 次散射。
移动相机或修改材质与灯光后，采样会重新开始。
场景观察相机与游戏相机各自保存状态。
点击运行后，画面使用工程中的游戏相机。

头盔适合观察金属和法线细节。
棋盘包含全部棋子，演示副本经过网格简化。
玻璃演示中的对象具有不同粗糙度与折射率。
它们共用引擎的通用材质与灯光服务。

## 怎样发布和运行

1. 点击“发布项目”，选择空的输出目录。
2. 执行发布，等待构建结果显示成功。
3. 将完整输出目录移动到目标位置。
4. 双击目录中以项目名称命名的 EXE。

发布包包含 Player、资源、配置与运行依赖。
发布时保留素材许可与来源记录。
本机交付目录为 `D:/Project/AzureRenderDemos/Published/`。
每个 `中文演示 <模型名>` 目录是一份完整发布包。

## 素材来源与支持范围

三个素材来自 Khronos 的 glTF Sample Assets。
固定来源及校验值见仓库的下载清单：
`assets_public/pathtracing-sources.json`。
每个工程的 `SOURCES.json` 记录素材处理过程。
`assets/licenses` 保存作者信息及 CC BY 4.0 全文。

导入支持金属粗糙度、法线、透射、折射率和体积衰减。
积分器提供点光源、发光面与环境采样。
当前使用计算着色器中的三角形加速结构。
硬件光线查询与高级复用采样属于后续专项。

预览降噪使用法线、深度和局部亮度抑制孤立亮点。
它会平滑部分细节，原始累积数据保持独立。
嵌套介质与专门的焦散采样尚未实现。
高反射和粗糙玻璃场景仍需要较高采样数。
