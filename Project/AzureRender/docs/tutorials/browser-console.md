# 浏览资源与查看日志

本指南适用于已打开工程的 Windows 编辑器。
资源浏览器与日志面板通过工作区标签切换。
普通布局还可使用左侧工具入口。
菜单的面板开关用于恢复已关闭的面板。

## 查找和打开资源

在资源浏览器输入名称或路径，选择需要的类型。
目录树和面包屑限定浏览位置。
后退和前进按钮恢复之前的目录。
没有匹配项时，清除筛选可恢复当前目录内容。

列表显示资产类型、源文件状态和引用数量。
网格模式显示已有缩略图，其他项显示类型提示。
路径和源文件信息可通过鼠标提示查看。
双击资源按注册类型打开相应编辑器或预览。

资源拖拽到场景视口时，使用现有放置服务。
右键菜单提供重命名、移动、复制和删除等操作。
删除和依赖复制经过内容事务确认。
内容撤销与重做位于导入和创建菜单中。

导入任务在后台执行，关闭资源面板后继续运行。
项目、播放和构建状态决定写入操作是否可用。
目录失效时，界面显示原因并恢复全部目录视图。
工程目录和安装资源的边界按项目服务校验。

## 筛选和复制日志

在日志面板输入文字，选择全部、警告或错误级别。
搜索支持逗号分隔条件，以及减号排除项。
警告级别同时显示错误，错误级别只显示错误。
级别由诊断头确定，普通输出采用信息级。

点击“复制可见日志”，复制当前筛选结果。
复制内容保留完整文字和多行消息。
没有匹配项时，界面给出筛选提示。
错误和警告分别采用设计系统的语义颜色。

## 暂停、跟随和处理任务

“暂停日志”固定当前消息快照。
取消暂停后，列表读取最新诊断。
暂停期间，后台任务仍继续运行。

“自动跟随”在列表底部跟随新增消息。
向上滚动查看历史时，当前位置保持稳定。
任务、错误反馈和开发工具由独立区域呈现。
任务取消和错误关闭继续调用编辑服务。
新错误出现时，诊断区域滚动到对应记录。
查看历史诊断时，可在区域内独立滚动。

紧凑布局通过“任务与诊断”按钮打开弹窗。
弹窗提供同样的任务取消、错误关闭和开发工具。
搜索与暂停控件保留在面板工具栏中。

面板布局、DPI 和窗口尺寸按工作区设置恢复。
