# 世界参照、相机与路径追踪

## 打开引擎与演示项目

当前安装入口为：
`build/ux-2026-10-14/Engine/bin/AzureRender.exe`。
双击后在项目中心打开项目文件。

本机演示项目为：
`D:/Project/AzureRenderDemos/PathTracingRoom/project.azureproject`。
工程资产位于项目自己的 `assets` 目录。
项目可移动，资源引用使用项目挂载路径。

需要另建演示时，在源码目录运行：

```powershell
python tools/create_pathtracing_project.py --output D:/Project/MyTracingDemo
```

输出目录必须为空。
素材来源保存在生成项目的 `SOURCES.json`。

## 调整场景与相机

地面网格固定在世界原点，格距为一米。
网格与坐标轴保持固定世界范围。
右键配合移动键操作场景观察相机。
在层级中选择游戏相机，点击“查看相机视角”。
此操作调整观察位置，项目相机保持自身配置。

游戏相机组件的类型为 `azure.camera`。
项目可配置投影、裁剪面、启用状态和优先级。
运行使用启用且优先级最高的游戏相机。
缺少游戏相机时，界面显示默认视角提示。
模拟模式继续使用场景观察相机。
停止运行后恢复编辑状态。

## 选择背景和渲染模式

在“窗口”菜单打开“环境”面板。
天空可选择程序天空、环境贴图或纯色。
天空朝向与亮度属于场景设置，可保存和撤销。
程序天空的地平线与明暗差异固定在世界方向。
相机平移保持背景，旋转改变观察方向。

渲染模式可选择实时渲染或路径追踪。
路径追踪显示实际累积数和目标采样数。
静止时等待噪声收敛，移动或修改场景后重新累积。
目标采样数越高，静止画面通常越稳定。
散射次数控制光线在物体间继续反射的次数。

当前路径追踪使用计算着色器与三角形加速结构。
支持基础色、金属度、粗糙度、透明度和自发光。
点光源与环境光参与照明。
法线贴图、透射和降噪属于后续能力。
高面数和复杂照明场景可能需要较长收敛时间。

## 切换语言与发布

打开“编辑 → 个人偏好”，搜索 `editor.language`。
选择简体中文或 English，偏好自动保存。
重启后的编辑器与项目中心读取该偏好。
项目名称、路径和自定义内容保留原文。
底层技术日志按原始诊断文本显示。

点击“发布项目”，选择输出目录并执行构建。
发布完成后保留完整输出目录。
移动整个目录后，运行其中以项目命名的 EXE。
本机发布验证已覆盖中文和空格路径。

## 代码归属

| 内容 | 负责位置 |
| --- | --- |
| 世界网格和辅助线 | `editor/viewport` |
| 游戏相机选择 | `runtime/camera` |
| 最终相机快照 | `render/RenderCamera.hpp` |
| 程序天空函数 | `shaders/sky.glsl` |
| 空场景背景资源 | `render/sky` |
| 路径追踪几何 | `render/pathtracing` |
| 路径追踪 GPU 资源 | `scenes/pathtracing` |
| 中英词条 | `ui/localization` |
| 场景设置编辑 | `render.settings` 编辑操作 |

宿主负责设备、队列、围栏与场景目标。
渲染模块负责自身缓冲、管线与销毁。
面板通过编辑操作修改项目，服务负责业务校验。
