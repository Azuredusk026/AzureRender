# 同帧照明复用

## 配置与职责

实验选项为 `AZURE_ENABLE_SURFACE_RADIANCE_REUSE`。
默认值为 `OFF`，默认路径执行完整着色。
开启后由设备能力与实际图元选择缓存资格。
画质、设备和整帧预算分别记录验收状态。

`SurfaceRadianceCache` 归属于 RenderCore。
调用方提供 RHI、视图尺寸、帧槽数和字节上限。
资源由视图拥有，帧槽之间具有独立图像。
窗口宿主与独立视图共用材质及生命周期接口。

## 身份与计算

不透明快照保存同帧的普通材质照明结果。
每像素身份包含深度位、实例、三角形和材质。
三角形身份采用原始索引起点及图元编号。
深度保留单精度位模式，非法身份使用保留值。

主颜色阶段按完整四像素组核对身份。
整组命中时读取照明及反射组合所需分量。
身份缺失或条件不符时执行完整着色。
反射置换采用 `azureBeautyReplace` 的精度边界。

材质资格来自具有索引的实际图元。
普通不透明材质采用默认隔离及效果模式。
扩展照明、独立覆盖和多重采样采用完整着色。
显式诊断模式保持所属着色定义。

## 资源与设备

每帧槽包含三个单精度附件及一个整数附件。
每像素占用 64 字节，默认总上限为 512 MiB。
帧槽数量范围为一至八，尺寸与乘法接受上限核验。
超额视图采用完整着色。

设备需支持六个颜色附件及相应图像格式。
描述符资格包含新增的四个采样图像。
片元图元身份需要启用 `geometryShader`。
缓存分配失败时释放部分资源并采用完整着色。

完整四像素组要求四像素组控制与最大重汇合。
实验 SPIR-V 同时要求辅助片元降级能力。
宿主查询、启用并传递完整能力链。
能力缺失的设备执行完整着色。

能力依据见 [Vulkan 着色器环境](https://docs.vulkan.org/spec/latest/chapters/shaders.html)。
辅助片元能力见 [Vulkan 扩展说明](https://docs.vulkan.org/refpages/latest/refpages/source/VK_EXT_shader_demote_to_helper_invocation.html)。

## 检查与观测

CPU 检查覆盖身份、格式、预算及释放。
GPU 夹具覆盖命中、失配、共面顺序及帧槽隔离。
独立视图按字节比较缓存与完整着色输出。
独立视图同时覆盖诊断、材质扩展及尺寸变化。

缺失实验能力的 GPU 夹具返回代码 77。
对应设备的独立视图验证完整着色回退路径。
支持范围按实际执行结果记录。
验证层错误与分配器残留分别核对。

采集元数据包含 `surfaceRadiancePrepared`。
`surfaceRadianceBytes` 表示实际附件占用。
准备状态表示资源资格，实际收益使用成对计时判断。
冻结四帧的既有兼容标准保持 RGB 零差异。

## 消费计数

诊断选项为 `AZURE_ENABLE_SURFACE_RADIANCE_DIAGNOSTICS`。
默认值为 `OFF`，开启时同时启用照明复用选项。
诊断程序单独编译，普通程序保持所属定义。
设备另需启用片元存储原子操作。

每个帧槽拥有二十四字节的映射缓冲。
五项数量覆盖生产、访问、合格访问及两种命中。
两种命中分别为逐片元身份和完整四像素组接受。
第六个字记录有效写入和溢出标志。

计数排除辅助片元，生产数量可能包含覆盖重叠。
这些数量表示实际调用，帧内唯一像素另行统计。
窗口与独立视图按完成栅栏回收帧槽。
主机归零、片元访问及主机读取均声明缓冲依赖。

元数据字段为 `surfaceRadianceStatistics`。
`frames` 只累计已经回收且具有写入的帧槽。
溢出状态在当前资源生命周期中保持有效。
重建资源后的数量从零开始。

原子计数会改变执行成本。
消费比例用于工作量归因，性能收益使用普通程序评估。
独立夹具核对整组命中、混合失配及溢出。
支持设备另行检查同步、输出和释放。

## 帧路径选择

实验选项为 `AZURE_ENABLE_SURFACE_RADIANCE_FRAME_SELECTION`。
默认值为 `OFF`，开启时同时启用照明复用选项。
资格核验、间接命令选择和轻量消费组成同一帧链路。
支持范围及实测收益按所属验收收据记录。

每个帧槽具有四字节的路径标志。
最低位表示完整着色回退，第二位表示 GPU 完成。
新资源及缺少许可的帧使用完整着色初值。
GPU 完成标记在选择阶段后单独写入一次。

完成栅栏后只累计带 GPU 完成标记的帧槽。
取消录制的槽按无完成记录处理。
标志在下一次许可判定后归零或设为完整回退。
资源重建会重置所属统计。

资格绘制读取同帧身份及现有深度。
独立纯深度通道保持颜色附件的原有使用过程。
辅助片元保持排除，真实片元失配写入回退位。
几何与资格范围采用保守条件。

命令选择采用[公共选择器](gpu-predicate-draw-selection.md)。
主颜色保留原有材质及实例的提交顺序。
完整及轻量区域分别使用相应管线。
轻量程序消费已生成的照明及反射分量。

`surfaceRadianceSelection` 记录准备及退役选择。
`frames` 为完成选择并已回收的帧槽数量。
`fastFrames` 和 `fullFrames` 分别记录两个结果。
准备状态、实际选择及整帧净收益分别解释。
