# 并行开发资源调度

各工作树共享主目录的 `tools/shared_resources.py`。
重负载编译、GPU 检查和正式测量共用同一互斥锁。
默认队列为 `D:/Projects/FYP-coordination/resources`。
操作系统在持有进程退出时释放文件锁。
接手前同时核对历史持有者及受管子进程。
存活命令或尚未确认的启动状态继续保持占用。

## 受管命令

下列命令在主引擎目录执行。
其他工作树通过绝对路径调用本入口。
`--build` 指向命令所属工作树的构建根。
`--run` 指向其已经创建的受管任务名称。

```powershell
python tools/shared_resources.py run --build <构建根> --owner <对话标识> --task <用途> --run <任务名称> --timeout 600 --command <程序> <参数>
```

持有者、进程、用途与输出目录写入 `current.json`。
该记录用于诊断，实时互斥由文件锁保证。
资源忙时命令返回退出码二，调用方稍后重试。
正式测量在锁内冻结程序、输入及环境。

命令由受管运行器监测预算和期限。
临时目录和工具缓存进入所属任务。
输出参数由调用方显式指向任务目录。
维护工具依据活动进程延后清理。

## 跨工作树输入

外部消费者在主维护索引中登记活动输入。
`--consumer` 使用真实存在的任务目录绝对路径。
`--input-run` 使用主构建中的任务名称，可重复指定。
输入必须为仍驻留的任务目录。
历史任务通过引用记录获得同等保护。

```powershell
python tools/shared_resources.py inputs --owner <对话标识> --consumer <消费者目录> --input-run <输入任务名称>
python tools/shared_resources.py release-inputs --owner <同一对话标识> --token <返回的令牌>
```

活动引用与清理删除使用同一数据库事务边界。
引用记录包含消费者路径、持有者和创建时间。
消费者封存后显式释放令牌。
失联消费者经核实后由原持有者释放。

## 所有权

性能对话负责主分支和公共接口集成。
画质和论文对话分别持有独立工作树及构建目录。
实际标识与目录登记于外部协调记录。
各自的交付包含提交、命令、结果及剩余限制。
