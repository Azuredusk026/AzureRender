# 来源纹理坐标恢复

离线模块为 `tools/endfield_native/mesh_uv.py`。
工具按明确材质槽恢复主纹理坐标。
目标与参考均采用单个内嵌二进制的 GLB。
资产身份及来源选择由调用方持有。

## 输入条件

材质槽沿用材质交换的稳定标识。
同槽图元的数量、顶点数及索引顺序必须对应。
调用方需先建立源顶点身份关系。
位置和切线方向可具有各自的姿态。

存在切线时，两端的第四分量必须一致。
该分量须为正一或负一。
来源主坐标与目标主坐标均为有限浮点二分量。
读取支持合法步长及访问器偏移。

范围越界、稀疏访问器及归一化整数触发拒绝。
纹理坐标与顶点数量失配同样触发拒绝。
来源选择含糊或图元对应失败时，调用方重新建立来源。

## 输出规则

工具追加参考主坐标及独立访问器。
选定图元的 `TEXCOORD_0` 引用指向该访问器。
原二进制前缀及其他属性保持完整。
未选定图元保留其原始引用。

节点、骨架、动画、材质和纹理保持原文档输入。
切线方向和符号作为已经核验的作者数据保留。
输出与来源分别使用独立文件。
现存输出及报告触发拒绝。

## 命令

工作目录为引擎根目录。
输出目录按[产物规则](artifact-retention.md)生成。

```powershell
python tools/endfield_native/mesh_uv.py `
  --input <动态来源.glb> --reference <冻结参考.glb> `
  --slot name:surface `
  --output <新输出.glb> --report <新报告.json>
```

多次使用 `--slot` 可选择多个明确材质槽。
报告记录来源、程序摘要、顶点及索引规模。
命令完成后重读 GLB 并核对二进制前缀。
真实资产范围见[头发坐标验收](../acceptance/nr/hair-source-uv.md)。

## Python 接口

`restore_primary_uv` 接受两份文档及各自二进制。
最后一个参数为明确的材质槽列表。
返回独立文档、追加后的二进制及来源报告。
非法输入产生 `ValueError`，调用方输入保持完整。

公开检查覆盖共享访问器、骨架文档及无切线几何。
命令行为新建、覆盖保护及失败保留分别验证。
实际图像、动画与资源释放由生产 Player 验收。
