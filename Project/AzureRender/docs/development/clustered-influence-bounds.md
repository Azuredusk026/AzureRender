# 聚簇灯影响盒

## 输入与边界

`RenderLight::clusterBox` 保存 CPU 视空间盒面。
`clusterInfluenceBox` 接收世界盒和仿射视矩阵。
输出坐标的 Z 轴表示正向观察深度。
GPU 灯布局继续采用 144 字节的版本三。

变换求逆采用双精度和条件数检查。
缺失、非有限及病态视变换返回空值。
聚簇分配对空值沿用现有半径覆盖范围。
CPU 盒面随相机或灯数据重新生成。

只有表面接收的局部灯参与盒面裁剪。
方向灯与投影颜色合成覆盖既定范围。
字符接收的分配遵循有序合成契约。
相交、边界不明及数值余量内的聚簇保留引用。

## 分离计算

透视聚簇由屏幕区间和对数深度片构成。
正交聚簇具有固定的屏幕区间。
每个盒面在完整聚簇上的取值区间以双精度计算。
任一盒面证明整体分离时，分配跳过该引用。

屏幕和深度边界向外扩张。
盒面余量覆盖单精度坐标和大数抵消。
保留引用采用原输入顺序，着色器计算保持原顺序。
阴影、反射和角色照明的数据格式按各自契约使用。

## 分配复用

`ClusteredLightGrid` 缓存上次的分配输入。
键包含半径、位置、类型、接收面及盒面。
颜色与强度更新保留相同的空间成员关系。
显式 `configure` 清空成员并使缓存失效。

渲染器只在网格描述变化时调用 `configure`。
位置、盒面或灯顺序变化时重新分配。
公开打包接口继续返回完整的头表与索引。
缓存、临时键及成员表随网格实例释放。
实例由所属渲染线程独占。

## 依据与验证

盒面分离依据凸体的保守可见性判定。
背景见 [NVIDIA 可见性管理](https://developer.nvidia.com/gpugems/gpugems/part-ii-lighting-and-shadows/chapter-15-managing-visibility-pixel-lighting)。
本实现围绕本项目的有限影响盒编写。
实现没有引入第三方代码或额外依赖。

所属夹具覆盖透视、正交、偏移和近面交叉。
异常变换回退及分配键失效均有独立检查。
原始四帧、双设备和场景成本见对应验收记录。
