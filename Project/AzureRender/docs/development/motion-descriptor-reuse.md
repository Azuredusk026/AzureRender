# 运动矢量资源绑定

## 所有权与帧槽

`MotionVectorPass` 持有描述符集、姿态上传缓冲及各槽绑定快照。
`prepare` 在对应帧槽完成在途使用后调用。
每次准备都上传并刷新当前姿态字节。
描述符快照按六份缓冲的句柄、容量及全部图像采样绑定核对。

绑定值一致时，该次准备复用原描述符。
绑定值变化时，完整刷新该槽的全部材质集合。
首次使用、姿态缓冲扩容及新通道实例均执行完整初始化。
更新失败使该槽保持失效状态，下次准备重新初始化。

## 资源替换

输入所有者在销毁并重建借用资源时调用 `invalidateBindings(frame)`。
该操作在对应帧槽下一次准备前完成。
显式失效覆盖本机句柄值被再次分配的情形。
角色渲染器在实例缓冲替换及描边遮罩重建时执行该操作。
纹理内容更新遵循既有资源同步与生命周期规则。

颜色、遮罩及覆盖纹理分别比较图像视图与采样器。
材质数量在通道构造时固定。
记录线程使用准备完成的描述符集合。
通道销毁时，快照随其所属状态释放。

## 观测与使用

时间抗锯齿及屏幕空间反射共享运动生产契约。
捕获清单中的 `motionDescriptorWrites` 表示成功发布的描述符写入数。
`motionDescriptorReuses` 表示省去整份绑定更新的准备次数。
两项均从当前通道实例创建起累计。

每次完整准备写入每材质六份缓冲及三份图像描述符。
复用只消除资源绑定更新，姿态计算与上传持续执行。
驱动调用量与整帧 CPU、GPU 时间分别核定。
生命周期参考 [Vulkan 描述符集规范](https://docs.vulkan.org/spec/latest/chapters/descriptorsets.html)。
