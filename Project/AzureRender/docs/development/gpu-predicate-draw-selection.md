# GPU 绘制路径选择

## 职责与输入

`GpuPredicateDrawSelection` 归属于 RenderCore。
它按 GPU 谓词生成完整和轻量两组间接命令。
照明资格与细节层级可共用此命令选择接口。
谓词的业务定义及产生过程归属于调用方。

输入命令采用 `VkDrawIndexedIndirectCommand`。
原始缓冲提供从起点开始的 `count` 条命令。
谓词缓冲的首个无符号整数提供全局回退。
调用方同时提供显式许可，默认许可为关闭。

许可开启且资格满足时，轻量区域保留原实例数。
其他组合由完整区域保留原实例数。
另一组命令的实例数为零。
原始实例数为零的命令保持空命令语义。

索引数量、索引起点、顶点偏移和实例起点保持原值。
每组的命令次序保持原输入顺序。
命令定义依据 [Vulkan 间接索引命令](https://docs.vulkan.org/refpages/latest/refpages/source/VkDrawIndexedIndirectCommand.html)。
实际绘制按 [Vulkan 间接绘制](https://docs.vulkan.org/refpages/latest/refpages/source/vkCmdDrawIndexedIndirect.html)核对设备能力。

## 谓词范围

`GpuPredicateSpan` 声明起始字、步长及两个掩码。
拒绝掩码作用于全局字和对应局部字。
必需掩码只作用于局部字，各必需位均须存在。
两个掩码保持互斥，拒绝掩码至少包含一位。

默认起始字及步长均为零，采用共享谓词。
默认拒绝掩码包含所有位，必需掩码为零。
逐绘制范围使用正步长及独立的首字偏移。
未满足许可、拒绝或必需位条件时采用完整路径。

最后访问字由起点、步长及数量计算。
声明范围至多为 128 MiB，缓冲须覆盖该范围。
选择器只读谓词，业务标志及其复用由调用方管理。
独立混合命令和场景资格共用此范围接口。

## 范围与所有权

构造接收 RHI、命令容量、帧槽数及 SPIR-V。
容量范围为一至 1048576，帧槽数为一至八。
输出缓冲总量至多为 128 MiB。
其字节数为容量、帧槽数与四十的乘积。

每帧具有独立输出缓冲。
完整区域的字节偏移为零。
轻量区域偏移由 `fastOffset()` 返回。
各区域的有效范围为前 `count` 条命令。

输入数量至多为构造容量。
原始命令的有效字节数至少为 `count × 20`。
非空请求的谓词缓冲覆盖全部声明字范围。
空请求具有可消费的一次性票据。

原始命令与谓词使用不同缓冲句柄。
输入句柄与各帧输出句柄保持独立。
模块拥有输出、描述符和计算管线。
调用方拥有 RHI、输入缓冲及其有效生命周期。

`prepare` 生成带对象、帧槽及代数的票据。
`record` 核对并消费该票据一次。
重新准备会使该帧槽的旧票据失效。
不同对象的票据各自限定于所属对象。

复用、重建和销毁均以所属 GPU 工作完成为条件。
构造失败时释放已经创建的内部资源。
非法范围、容量及句柄别名按异常返回。
输入存储继续由原调用方管理。

## 同步与消费

调用方先发布原始命令及谓词写入。
主机写入对应计算阶段的着色存储读取。
片元或传输产生的谓词使用所属源阶段及访问类型。
选择器的输出完成计算到计算读取的发布。

间接消费者声明计算写入到间接命令读取的依赖。
间接读取阶段为 `VK_PIPELINE_STAGE_DRAW_INDIRECT_BIT`。
访问类型为 `VK_ACCESS_INDIRECT_COMMAND_READ_BIT`。
复制消费者声明计算写入到传输读取的依赖。

实际管线与输入命令的几何和实例约定保持一致。
绘制次数、步长及非零实例起点遵守设备能力。
场景资格核验及画质回退由所属渲染器验证。
机制检查与整帧性能分别记录验收范围。
