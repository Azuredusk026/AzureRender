# 着色热重载编译配置

构建目录的 `shader-reload.json` 描述着色程序事务。
CMake 从实际程序列表生成该文件。
宿主读取描述后持有固定的编译选项。
源文件变化通过内容快照触发候选编译。

## 描述与预算

描述支持版本一和版本二，文件上限为一 MiB。
源快照上限为十六 MiB 及 4096 个文件。
一版描述的程序容量为 512。二版描述通过必填字段 `maximumPrograms` 声明容量，允许一至 1024 的整数。实际程序列表须位于一至所选容量之间。构建描述按完整着色器目录的项数生成容量。
候选编译和取消共用所属任务的六十秒上限。

独立输出最多使用八个并行编译进程。
重复输出及非 ASCII 输出名称采用声明顺序。
全部编译任务结束后，服务才发布或回收候选。
每个进程保持独立句柄、输出管道及任务所有权。

| 字段 | 作用 |
| --- | --- |
| `sourceRoot` | 源文件及包含依赖的快照根目录 |
| `binaryRoot` | 完整活动 SPIR-V 目录 |
| `scratchRoot` | 事务候选及退休目录 |
| `compiler` | 全局编译器路径 |
| `programs` | 源、输出、宏及可选编译参数 |
| `maximumPrograms` | 二版描述的程序容量，范围为一至 1024 |

路径以描述文件的目录为相对解析起点。
程序源和输出使用各自根目录下的相对路径。
路径须保持在相应根目录内。
源快照由事务持有，编译期间保持固定内容。

## 逐程序选项

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `source` | 必填 | 相对源文件路径 |
| `output` | 必填 | 相对 SPIR-V 输出路径 |
| `defines` | 空数组 | 按 `-D` 传给编译器的宏 |
| `compiler` | 空路径 | 空值使用全局编译器 |
| `arguments` | 空数组 | 逐项传递的编译选项 |
| `outputOption` | `-o` | 取 `-o` 或 `-Fo` |

宏和参数数组各最多六十四项。
每项最多 4096 个字符，并须保持有效参数字符串。
全部程序的参数、宏及路径最多一 MiB。
编译器路径、输出选项、宏及参数均进入快照指纹。

编译通过公共进程服务传递参数数组。
命令依次包含自定义参数、宏、包含目录及源路径。
最后使用所属程序的输出选项和候选目标。
编译失败与诊断关联所属事务。

Windows 长输出路径采用完整路径前缀。
GLSL 与 HLSL 共用输出路径转换。
工作目录遵循系统进程创建约束。

## DXC 与投影程序

GLSL 程序使用生成描述中的 glslc。
投影程序通过逐程序字段选择 DXC 和 `-Fo`。
配置包含计算入口、目标环境及描述符绑定移位。
构建命令与热重载描述共用同一份参数列表。

投影程序通过有界 SPIR-V 检查。
编译结果与正式构建的完整字节做独立对照。
程序来源及 GPU 数值门槛见[公共组合](../runtime/projected-screen-reflection.md)。

## 快照诊断

测试构建提供完整源快照的读取与指纹诊断。
命令输出源字节、文件数、内容指纹及实际耗时。
两类读取和指纹循环同时核对完整内容。
该输出用于定位编辑帧成本。

`AzureRender.ShaderCatalogCompilation` 检查完整目录。
测试使用生产编译预算，并逐份对照常规构建。
重复输出顺序及长路径由混合编译夹具验证。

```powershell
.\build\ninja-msvc-debug\AzureShaderCompilerContractTests.exe `
  --snapshot-timing .\build\ninja-msvc-debug\shader-reload.json
```

## 候选生命周期

每个候选包含完整二进制目录及源内容指纹。
全部所选程序成功后才提供可用候选。
管线拥有者退休 GPU 工作后接受或拒绝候选。
编译失败和管线拒绝均保留活动版本。

取消会结束所属编译工作并回收候选。
文件锁导致的退休延迟由服务记录并重试。
重载选项的容量、字段及路径校验发生在编译前。
双配置及混合编译证据见[契约验证](../acceptance/recovery/shader-compiler-contract.md)。
完整目录、长路径及独立宿主恢复见[重载核验](../acceptance/recovery/shader-catalog-reload.md)。
