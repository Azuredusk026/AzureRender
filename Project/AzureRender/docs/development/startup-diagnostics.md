# 启动诊断

编辑器与 Player 通过运行诊断服务记录初始化阶段。
每项开始时输出名称，成功后输出经过毫秒数。
异常通过宿主错误路径报告。
日志用于区分项目校验、资产加载和设备初始化。

## 初始化阶段

记录范围包括逻辑设备、阴影资源及图形管线。
场景渲染器和编辑界面分别记录耗时。
编辑构建另记录开发视图初始化。
耗时覆盖所属初始化调用及其资源准备。

项目打开失败时，诊断包含原始异常文本。
编辑器随后提供项目中心供用户处理项目。
该状态具有独立界面观察，场景验证端点尚未创建。
自动工具应先检查项目打开诊断与当前宿主状态。
