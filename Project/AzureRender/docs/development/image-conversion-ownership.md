# 图像转换所有权

`ImageCodec` 提供借用输入和消费输入两种转换入口。
两者均返回独立持有像素及诊断的 `ImageRgba8`。
像素采用左上角起点的直通透明度 RGBA 顺序。

借用入口接收 `const DecodedImage&`。
调用方继续持有完整原图，八位输出拥有独立副本。
消费入口接收 `DecodedImage&&`。
八位输入通过转移缓冲得到输出。

尺寸、像素预算和存储长度在转移前验证。
验证失败时，输入像素缓冲仍由调用方持有。
十六位及浮点输入按既有公式转换。
量化、颜色空间、裁剪及来源诊断共同保留。

glTF 解码回调将八位像素交给模型图像。
材质因子处理使用模型图像的独立可写结果。
原图可由同一模型的多个材质继续读取。
独立材质图像加载采用相同的消费入口。

已编写的层级数据在所属容器之间转移。
GPU 上传、纹理共享和资源释放采用各自契约。
所属结果见[缓冲验证](../acceptance/nr/owned-image-conversion.md)。
