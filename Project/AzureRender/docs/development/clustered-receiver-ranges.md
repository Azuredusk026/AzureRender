# 聚簇灯接收范围

## 布局与所有权

接收头表采用布局版本二。
每个聚簇连续保存四份 `uvec2` 区间。
每份区间记录有效索引前缀中的偏移和数量。
索引仍指向版本三的 144 字节 GPU 灯数据。

| 组号 | 消费范围 | 筛选规则 |
| --- | --- | --- |
| 0 | 普通表面 | 灯允许表面接收 |
| 1 | 字符材质 | 灯允许字符接收 |
| 2 | 表面发光衰减 | 颜色合成灯按字符接收，其余按表面接收 |
| 3 | 字符颜色合成 | 灯允许字符接收，且具有颜色合成响应 |

普通材质按其实际接收类型选择范围。
表面发光衰减使用组二。
无光照材质的颜色衰减使用组三。
各范围中的灯保持原始相对顺序。

`ClusteredLightGrid::gpuReceiverData` 生成两份打包数组。
网格实例持有缓存，调用方持有输出数组。
灯位置、接收掩码及合成类型参与缓存失效。
显式网格配置使分配与打包缓存一同失效。

## 缓冲访问

渲染器为每聚簇四份头表预留空间。
索引容量按网格数量、最大灯数及四组范围计算。
每帧上传完整头表及有效索引前缀。
着色器通过区间数量界定索引访问。

未被区间引用的缓冲尾部不参与读取。
空范围的数量为零。
缓冲帧槽、同步及释放沿用渲染器所有权。
完整聚簇查询提供组合成员表。

## 使用与验证

普通照明、字符有序合成和无光照表面共同使用该布局。
独立 CPU 夹具遍历全部接收掩码及合成模式。
设备用例检查正向照明、颜色顺序和固定绑定路径。
原生四帧与短时效率按所属验收记录核定。

## 级联归属

显式场景照明下，表面方向灯提供级联可见量。
显式 QA 扫描主灯也可提供该通道。
缺少提供者时，级联消费返回完全可见。
传统展示照明保持其默认主灯提供者。

局部灯保留独立的距离、锥角和影响盒衰减。
NPR 颜色响应消费符合归属规则的场景可见量。
静止局部灯场景的首帧与后续帧采用同一契约。
对象阴影继续通过其显式材质通道采样。
