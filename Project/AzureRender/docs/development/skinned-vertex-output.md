# 蒙皮输出布局

## 数据契约

`GpuSkinnedVertex` 定义计算蒙皮的内部输出。
每个顶点包含十个单精度字，总计四十字节。
位置、法线及切线的字节偏移分别为 0、12 和 24。
切线第四分量逐位保留原始网格的方向符号。

原始网格继续采用 `AssetVertex` 的输入布局。
顶点输入提供纹理坐标、覆盖坐标及其余源属性。
计算输出通过所属帧槽的存储缓冲绑定读取。
实例基址与顶点索引均以顶点数量计量。

计算端、网格、阴影与描边使用相同输出步长。
共享 GLSL 布局位于 `skinned_vertex_layout.glsl`。
位置、法线和切线的形变算术保持所属函数契约。
资产导入、磁盘快照及运动数据采用各自版本布局。

## 分配与生命周期

每个在途帧槽拥有独立输出缓冲。
初始容量与扩容均按四十字节乘以顶点数量计算。
缓冲继续声明存储访问及现有分配用途。
分配失败由视图加载或扩容过程报告。

静态输出有效性由所属帧槽持有。
只有实际录制并成功提交的生产工作能发布有效内容。
分配变化会使所属缓存失效。
取消和代次冲突按现有缓存契约处理。

元数据记录 `computeSkinningVertexWords`。
`computeSkinningOutputBytes` 汇总当前全部帧槽的逻辑容量。
`computeSkinningPreparedVertices` 表示本帧计划生产量。
实际帧收益按原生输出及成本对照分别验收。
