# 编辑对象与功能边界

本页定义本轮编辑器开发使用的数据和模块契约。
状态：ED0 审查完成，后续实现按专项计划推进。

## 对象、组件与预制体

`SceneNode.id` 是对象身份，名称用于展示。
父节点、组件引用和选择状态使用稳定标识。
重命名保持标识及其引用，复制生成独立标识。
创建预设提供默认组合，Prefab 提供可复用层级。

`SceneNode.resourceId` 关联模型资源。
`components` 保存版本化的运行组件。
`prefabSource` 与 `instanceOf` 保存来源关系。
来源关系与普通对象引用分别校验和展示。

对象创建、复制、重命名及删除调用编辑服务。
跨对象操作作为事务进入历史记录。
组件存储标识保持稳定，展示名来自能力元数据。
组件移除同时检查引用、系统注册和资源释放。

## 状态的含义

可见性控制渲染结果，启用状态控制组件行为。
展开和面板显示归属工作区状态。
卸载释放资源，删除修改持久文档。
各组件只显示实际支持的状态操作。

## 功能与文件目录

| 职责 | 目录 | 数据与依赖 |
| --- | --- | --- |
| 平台输入与窗口 | `src/platform` | 原生事件与窗口坐标 |
| 内容生成与导入 | `src/assets` | 文件、资源标识、生成来源 |
| 运行契约与组件 | `src/runtime` | 组件定义、版本及系统更新 |
| 编辑业务服务 | `src/editor/content`、`properties`、`commands` | 文档事务与领域操作 |
| 编辑面板 | `src/editor/panels` | 展示状态并调用服务 |
| 通用 UI | `src/editor/ui` | 设计 token、控件和布局尺度 |
| 渲染能力 | `src/render`、`extensions` | 特性配置及运行资源 |
| 宿主装配 | `src/app` | 生命周期、输入桥接与模块装配 |

面板通过服务处理业务，公共控件消费展示数据。
平台层提供原生事件，编辑器解释目标区域。
运行模块使用数据契约，Player 保持独立装配。
文件按职责收纳，目录调整同步构建源文件清单。

## 已核对的能力

点光源使用 `SceneLight`，相机已有第三人称组件。
物理形状支持盒、球、胶囊和静态网格。
创建菜单按真实支持能力提供灯光与相机选项。
方向光、聚光灯及完整独立相机需另行明确支持。

已有 UI 文档由 `azure.game-ui` 组件消费。
通用创建预设提供该组件的配置入口。
二维文档和材质画布保持各自编辑服务。
本轮复用 ImGui、GLFW 与 Vulkan。
