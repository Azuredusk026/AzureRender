# 编辑对象与功能边界

本页定义本轮编辑器开发使用的数据和模块契约。
状态：ED0 至 ED7 开发交付完成。
集中验收见[本轮收尾记录](../acceptance/p8/2026-10-14.md)。

## 对象、组件与预制体

`SceneNode.id` 是对象身份，名称用于展示。
父节点、组件引用和选择状态使用稳定标识。
重命名保持标识及其引用，复制生成独立标识。
创建预设提供默认组合，Prefab 提供可复用层级。

`SceneNode.resourceId` 关联模型资源。
`components` 保存版本化的运行组件。
`prefabSource` 与 `instanceOf` 保存来源关系。
来源关系与普通对象引用分别校验和展示。

对象创建、复制、重命名及删除调用编辑服务。
跨对象操作作为事务进入历史记录。
组件存储标识保持稳定，展示名来自能力元数据。
组件移除同时检查引用、系统注册和资源释放。

## 状态的含义

可见性控制渲染结果，启用状态控制组件行为。
展开和面板显示归属工作区状态。
卸载释放资源，删除修改持久文档。
各组件只显示实际支持的状态操作。

## 功能与文件目录

| 职责 | 目录 | 数据与依赖 |
| --- | --- | --- |
| 平台输入与窗口 | `src/platform` | 原生事件与窗口坐标 |
| 内容生成与导入 | `src/assets` | 文件、资源标识、生成来源 |
| 运行契约与组件 | `src/runtime` | 组件定义、版本及系统更新 |
| 编辑业务服务 | `src/editor/content`、`properties`、`commands` | 文档事务与领域操作 |
| 编辑面板 | `src/editor/panels` | 展示状态并调用服务 |
| 通用 UI | `src/editor/ui` | 设计 token、控件和布局尺度 |
| 渲染能力 | `src/render`、`extensions` | 特性配置及运行资源 |
| 宿主装配 | `src/app` | 生命周期、输入桥接与模块装配 |

面板通过服务处理业务，公共控件消费展示数据。
平台层提供原生事件，编辑器解释目标区域。
运行模块使用数据契约，Player 保持独立装配。
文件按职责收纳，目录调整同步构建源文件清单。

## 已核对的能力

点光源使用 `SceneLight`，相机已有第三人称组件。
物理形状支持盒、球、胶囊和静态网格。
创建菜单按真实支持能力提供灯光与相机选项。
方向光、聚光灯及完整独立相机需另行明确支持。

已有 UI 文档由 `azure.game-ui` 组件消费。
通用创建预设提供该组件的配置入口。
二维文档和材质画布保持各自编辑服务。
本轮复用 ImGui、GLFW 与 Vulkan。

## 组件描述与引用

组件注册提供展示名、分类和组合约束。
添加和移除通过编辑服务校验组合。
运行加载使用同一组冲突规则。
每个对象的同类组件只有一个实例。

启用和可见字段来自实际反射属性。
组件字段编辑保留现有版本与迁移路径。
网格绑定归属对象资源，点光源归属场景灯光。
刚体和角色控制器使用独立对象。

属性底部的添加入口支持名称和分类搜索。
项目来源按预制体资产及内部对象标识展示。
来源信息只读，预制体操作管理来源关系。
普通组件引用支持选取、清除与定位。

## 文件拖放与视口输入

平台队列保存 UTF-8 路径和窗口坐标。
编辑器按可见区域解释导入或放置目标。
内容区接收导入，层级和视口接收模型放置。
多个文件按队列逐项执行。

导入任务捕获文档版本、位置和父节点标识。
结果发布前检查目标仍然有效。
模型依赖由现有格式管线复制到项目。
取消和过期结果释放未发布的暂存文件。

层级和视口中的 W/E/R 调用同一工具命令。
文本输入、弹窗、导航和运行态按路由规则隔离。
视口右键点击打开菜单，拖动进入相机导航。
主网格、次网格和世界轴使用公共设计颜色。

## 设置保存与工作区

个人相机、快捷键和布局归属用户配置。
相机转向与环绕灵敏度使用度每像素。
项目设置保存于 `config/engine-settings.json`。
项目层接收渲染、运行及游戏输入参数。

项目打开和切换加载其设置层。
发布服务复制项目设置，Player 按项目根加载。
设置控件显示来源、保存目标及启动生效条件。
顶部创建入口与层级、视口使用同一预设服务。

工具栏分组显示文档、变换及运行操作。
工具菜单按面板注册提供功能入口。
公共状态栏显示文档修改状态和真实任务进度。
状态栏的操作提示提供完整导航与快捷键说明。
视口内显示当前导航模式和飞行速度。
二维、材质、动画及发布继续使用所属面板。

## 可选渲染特性

特性注册声明能力及资源依赖。
项目设置使用 `render.features.<标识>` 选择装配。
通用场景默认关闭 Face SDF 和展示平台。
既有角色场景按现有场景类型解析默认能力。

Face SDF 关闭时跳过专用 GPU 纹理上传。
描述符复用基础纹理，着色器跳过 SDF 采样。
头部光照计算按装配状态执行。
展示平台关闭时跳过生成、上传和绘制。

编辑器特性变更触发所属渲染资源重建。
Player 与编辑器使用同一设置和装配描述。
场景格式及资产依赖继续执行完整合法性校验。
已声明但缺失的资产进入真实依赖诊断。

卸载先清空准备任务，再释放描述符和资源。
场景缓存复用校验特性资源状态。
环境面板只展示已启用的专用配置。
未知特性在设置层返回明确错误。

## 层级操作

节点右键菜单提供重命名、聚焦、复制和删除。
创建菜单支持根对象及当前节点的子对象。
保存后的项目可从节点菜单导出子树。
对象写入在层级绘制结束后执行。

创建、复制、移动及历史操作请求展开定位。
祖先展开状态和选择使用稳定标识。
父子循环被拒绝，失败保持文档和历史。

## 制作流程与文件边界

基础创建归属 `editor/content`。
外部事件接入归属 `editor/input`。
材质操作归属 `editor/material`，脚本模板归属 `editor/scripts`。
面板通过生产编辑服务调用这些功能。

项目资产生成由 `runtime/AssetGeneration.cpp` 持有。
原生文件路径保留平台编码，文本接口使用 UTF-8。
元数据路径通过路径对象追加扩展名。
资源加载和生成验证消费同一资产标识。

集成工具为 `tools/test_editor_general_workflow.py`。
它创建场景项目，并通过生产服务完成制作与重开。
人工素材由 `tools/prepare_editor_review_assets.py` 准备。
来源、许可和内容指纹随素材清单保存。
