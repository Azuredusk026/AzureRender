# 图像与静态网格扩展

资源导入通过公共格式注册和传输事务执行。
转换结果记录来源指纹、参数和转换损失。
当前注册输入格式为 29 种，写出格式为 20 种。

| 格式 | 输入范围 | 转换结果与边界 |
| --- | --- | --- |
| GIF | 首个合成帧 | 输出静态图像，记录动画时序损失 |
| PSD | 合成图 | 输出静态图像，记录图层与编辑元数据损失 |
| SVG | 路径、图元、分组及渐变 | 按固有尺寸、96 DPI 栅格化 |
| USDA、ASCII USD | 根级静态多边形网格 | 输出 GLB，应用单位与 Y/Z 上轴 |

SVG 使用固定版本 NanoSVG 和 XML 结构校验。
输入预算为 8 MiB，节点预算为一万个。
栅格尺寸上限为 8192，坐标必须有限。
外部引用、脚本、文本和嵌入图像会明确拒绝。

USD 输入标记为 `#usda 1.0`。
支持顶点、面索引、顶点法线和网格方向。
细分方式要求 `none`，顶点预算为一百万。
组合、变换层级、UV、材质及动画会明确拒绝。

二进制 USDC 需要另行实现对应适配器。
多个带法线网格需要专用交换配置。
网格名称转换为稳定索引名称并记录损失。
交换参数可显式覆盖来源单位和上轴。

新增格式当前提供导入能力。
导出继续使用支持写出的目标格式。
PBR 与风格化材质均可消费转换后的纹理。
GLB 继续由公共模型加载器消费。

NanoSVG 的来源提交与许可随安装包分发。
中文字体许可随游戏发布包分发。
验证记录见[G24 实施记录](../acceptance/g24/2026-10-12.md)。
