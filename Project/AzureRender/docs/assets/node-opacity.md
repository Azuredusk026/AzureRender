# 节点透明度

`AZURE_node_opacity` 为节点提供局部透明度。
物流实例、门牌和提示组可组合使用此能力。
加载器、姿态系统与渲染器共用有效透明度。
实例发射、循环和年龄归属应用内容。

## 资产格式

扩展名必须进入 glTF 的 `extensionsUsed`。
节点扩展包含 `schemaVersion` 和 `opacity`。
当前版本为 1，透明度范围为 `[0,1]`。
未声明节点扩展时，局部透明度默认为 1。

```json
{
  "extensionsUsed": ["AZURE_node_opacity"],
  "nodes": [{
    "extensions": {
      "AZURE_node_opacity": {
        "schemaVersion": 1,
        "opacity": 0.8
      }
    }
  }]
}
```

动画扩展包含 `schemaVersion` 和 `channels`。
每条通道通过 `node` 选择节点。
`sampler` 复用所在动画的采样器索引。
同一动画的透明度通道各自拥有唯一目标节点。

```json
{
  "samplers": [{
    "input": 1,
    "output": 2,
    "interpolation": "LINEAR"
  }],
  "channels": [],
  "extensions": {
    "AZURE_node_opacity": {
      "schemaVersion": 1,
      "channels": [{"sampler": 0, "node": 1}]
    }
  }
}
```

输入与输出访问器均为浮点 `SCALAR`。
时间必须有限、非负且严格递增。
支持 `STEP`、`LINEAR` 和 `CUBICSPLINE`。
关键值必须有限并处于 `[0,1]`。

三次插值按 glTF 的输入切线、值、输出切线排列。
切线允许有限的有符号值。
采样结果夹紧至 `[0,1]`。
矩阵节点也可接受透明度动画。

## 姿态与渲染

`AssetNode::opacity` 保存静态局部值。
`AssetNodePose::opacity` 保存采样局部值。
动画混合先处理局部值，再计算祖先乘积。
`AssetPose::nodeWorldOpacities` 保存最终有效值。

`AssetPrimitive::nodeIndex` 记录来源节点。
渲染器据此读取实例姿态的有效透明度。
未绑定节点的手工构造图元使用透明度 1。

透明度独立于骨骼矩阵与几何缩放。
表情叠加保留基础姿态的局部透明度。
双通道形变从实例数据读取权重。
主表面、阴影和轮廓共享对应实例姿态。

选中图元的变换由同一个矩阵生成函数处理。
颜色、深度、阴影、遮罩与描边共用该矩阵。
其他图元使用单位操作矩阵。
平移、旋转与缩放均保留到各消费通道。

当前光栅渲染入口为 `CharacterSceneRenderer`。
支持主颜色、角色深度、阴影与轮廓通道。
不透明材质按物体空间稳定抖动控制覆盖率。
`Blend` 材质将有效透明度乘入最终 `alpha`。

淡出描边使用每实例独立的完整几何遮罩。
遮罩保留材质裁切，避免外壳填入覆盖孔洞。
不透明表面先写深度，轮廓随后绘制。
前景轮廓据此保留与后景表面的遮挡关系。

每个淡出实例占用一块全视口 `R8` 区域。
每帧遮罩预算为 128 MiB。
图集尺寸同时遵守设备的二维图像上限。
超限时返回明确错误。

帧槽围栏退休后才更新、分配或释放遮罩。
全部实例均为透明度 1 时，遮罩图像按需释放。
无淡出描边时，绘制保持已有实例批次。
路径追踪的透明度接入状态为待实施。

父节点可统一控制整组门牌的显隐。
子节点保留自身曲线与局部透明度。
独立实例分别采样各自时间。
共享资产在采样期间保持只读。

## 校验与验证

加载器校验版本、字段、数值、索引和曲线。
未知字段、重复目标及非法输入均拒绝。
外部姿态的局部值遵守相同数值范围。

CPU 契约测试为 `AzureRender.NodeOpacity`。
夹具覆盖物流曲线与父子门牌两种用法。
验证包含插值、层级、混合、表情和非法输入。
GPU 用例为 `AzureEngine.NodeOpacityGpu`。
覆盖颜色、混合、深度、阴影和重叠描边。
固定纹理表与串行路径同时参与对照。
结果见[节点透明度验收](../acceptance/nr/node-opacity.md)。
