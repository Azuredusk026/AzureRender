# 原生路径资产转换

转换入口为 `tools/blender/build_native_spline_clips.py`。
该工具消费[路径运动编译器](native-spline-compiler.md)的输出。
每个发射器生成一个具有独立周期的 GLB。
骨架角色动画与这些刚体节点动画可共同运行。

## 输入与依赖

命令运行于 Blender 的后台模式。
参数提供探针、发射器、世界矩阵和绘制依赖清单。
`--extractor-src` 指定外部读取器的源码目录。
`--source` 指定完整容器身份，`--seed` 指定随机种子。

世界矩阵须为有限的刚性仿射变换。
旋转基必须正交且保持右手定向。
缩放、剪切及反射输入返回明确错误。
槽位尺寸由原生运动描述独立控制。

外部读取器为 [Endfield-map-extractor](https://github.com/An1X3R/Endfield-map-extractor)。
验证提交为 `6226108267942ec940cc65b6850ea8c49198c20f`。
许可为 MIT，来源与文件摘要进入转换收据。
外部源码由调用者提供，工具在独立命名空间中适配。

读取器提供 OBJ、材质目录和源坐标转换。
资产保留源 LOD0 的全部网格及材质槽。
VFX 的 UV0 烘焙域为单位方形。
域外 LitEffect 需验证重复寻址及整数纹理缩放。
源 COLOR 与 UV1 数据需要对应的独立适配。

## 材质转换

`native_spline_materials.py` 按着色器族选择适配器。
普通表面复用已有的源材质处理。
LitEffect 按源选择器组合发光图的 R 或 RGBA。
RGBA 分别乘四组源颜色后求和。

VFXBaseV2 消费源颜色、透明度、纹理角色及寻址。
透明混合使用源覆盖率与未预乘的颜色。
逐轴钳制与重复采用独立坐标处理。
重复轴保持过滤接缝，钳制轴固定至边缘纹素中心。

烘焙输出基础色、透明度、法线及金属粗糙度。
HDR 发光通过独立倍率保留能量范围。
颜色图采用 sRGB，透明度及数据图使用线性数值。
材质与纹理来源、文件摘要和限制均进入收据。

源屏幕深度软交界、实时曝光与滚动纹理继续核验。
烘焙结果表达明确的静态材质快照。
VFX 的完整无光照消费与原生混合具有独立验收范围。
未覆盖的混合及深度状态返回明确错误。

## 动画与输出

每个槽位拥有独立动画根节点。
位置使用线性关键帧，尺寸在存活边界使用阶梯关键帧。
透明度通过版本化节点扩展表达。
初始透明度与动画通道分别保存。

收据包含输入、转换器、外部适配及输出摘要。
同时记录 Blender 版本、种子、采样率及每份周期。
场景激活、原生随机状态及全局相位继续实景核验。
实际结果见[物流联合验收](../acceptance/nr/logistics-multiclip.md)。
