# 原生路径运动编译

离线编译器位于 `tools/endfield_native/spline_bake.py`。
输入为已有读取器输出的发射器描述。
每份描述通过容器与对象编号组成身份。
输出保存独立周期、稳定槽位及局部运动曲线。

## 编译接口

`compile_emitter` 编译单个发射器。
`compile_emitters` 编译身份互异的描述集合。
采样率默认为每秒 30 次，最大为 1000 次。
默认预算为每个发射器一百万个关键帧。

每个槽位保存时间、位置、尺寸、源欧拉角及透明度。
时间写成单精度浮点数，并合并量化后的重复值。
事件时间优先于普通采样，保留死亡和重生间隔。
位置与透明度采用线性插值。
尺寸在存活边界使用阶梯插值。

预热槽位由寿命、发射率和模拟倍率共同计算。
各发射器保持独立时钟及周期。
源路径评价复用 `spline_motion.py` 的距离契约。
路径端点及终端缓存分别验证。

## 支持范围

速度与寿命使用常量分支。
初始尺寸与旋转支持常量及双常量范围。
范围采样需要显式整数种子。
采样身份包含发射器、槽位、种子和字段名称。

透明度支持常量及无权重 Hermite 曲线。
曲线消费源时间、数值、入切线与出切线。
数值约束到零至一，事件采样包含源透明度关键帧。
存活范围以外的槽位具有零尺寸及零透明度。

源噪声、连续旋转及未覆盖曲线返回明确错误。
预热、发射类型及三维初始旋转必须满足支持条件。
源随机发生器与每次出生重采样具有独立验证范围。
场景激活集合、全局相位和旋转单位继续实景核验。

## 验证

运行 `python -m unittest discover -s tools -p 'test_endfield_native*.py'`。
专项用例覆盖多发射器身份、独立周期和重复身份拒绝。
死亡、重生、单精度边界及透明度切线均有数值检查。
未实现模式及关键帧预算通过失败输入检查。

2026-10-22 批次包含 154 项工具测试。
结果为全部通过，失败数为零。
证据位于本轮运行目录的 `spline-full-regression.log`。
