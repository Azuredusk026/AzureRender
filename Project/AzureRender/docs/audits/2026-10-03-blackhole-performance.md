# 黑洞实时性能评估

> 文档类型：技术评估
> 状态：生效
> 更新日期：2026-10-03
> 依据：R4 验收、当前着色器、隔离诊断实验和公开参考实现

## 结论

当前性能档和平衡档已具备实时 GPU 预算。电影档的瓶颈是全分辨率逐像素四次追踪，以及体积盘采样的重复程序化计算。视觉取舍与实现效率均影响成本。

诊断发现保守高度判断可避免约一半 GPU 时间，测试画面保持逐帧字节一致。高开销不能直接作为高画质或高物理精度的证明。

成熟实时黑洞实现采用预计算测地线、球对称降维和纹理查表。部分演示采用较简单的盘模型，另一些通过算法设计同时实现高质量与较低运行成本。

## 基线与测量边界

本机为 RTX 4060 Laptop GPU，驱动 32.0.15.9579。R4 Release 在 1280×720 下记录性能档 9.53 ms、平衡档 9.87 ms、电影档 40.48 ms。

电影档 CPU 录制约 0.24 ms，主场景 GPU 约 40.42 ms。主场景计时包含追踪、Bloom、时间累积和合成。现有粗粒度查询不能单独归因到某个内部 Pass。

诊断使用隔离安装树替换着色器，项目源码和发布安装树保持原版本。每例运行 150 帧，固定模拟步长与正面相机。开头和结尾基线分别为 38.04 ms 和 42.57 ms。

基线漂移约 12%，影响细小差异的解释。两倍与四倍级变化仍有明确方向，数字用于定位成本。

## 控制变量实验

| 诊断条件 | 整帧 GPU 平均值 | 解释 |
| --- | ---: | --- |
| 原电影档，首轮 | 38.04 ms | 四条射线，原体积盘着色 |
| 保持电影档步进，单条射线 | 9.83 ms | 四次完整追踪是主要倍增成本 |
| 四条射线，增加盘外高度判断 | 19.02 ms | 在昂贵噪声计算前排除必定无密度的位置 |
| 四条射线，噪声函数返回常量 | 17.33 ms | 程序化盘着色成本显著，画面和密度会改变 |
| 四条射线，关闭盘采样 | 9.87 ms | 曲线积分本身仍有成本，透明度终止路径会改变 |
| 替换追踪为常量颜色 | 0.17 ms | 当前场景的后处理与基础流程不是主要瓶颈 |
| 原电影档，904×508 | 20.16 ms | 像素数约减半，成本近似随像素数变化 |
| 原电影档，末轮 | 42.57 ms | 用于界定设备与热状态漂移 |

这些实验不能相加得到各部分独立占比。关闭噪声或盘采样会改变密度、终止位置与后处理输入。

高度判断例保留四条射线、步进参数、噪声、颜色和后处理。四帧 1280×720 截图的 PNG 哈希均一致，最大通道差为零。其 GPU 时间约降低 50%–55%。

## 成本原因

### 盘外采样执行昂贵噪声

`sampleDisk` 先检查柱半径，再计算径向形状、螺旋角和两层厚度噪声。随后才判断采样点是否位于盘的实际厚度内。

盘厚度为 `thin * radialShape * mix(0.38, 1.0, thicknessNoise)`。当前归一化形状与噪声因子均至多为一，因此 `thin` 构成几何厚度上界。

在半径检查后增加 `abs(rayPosition.y) >= thin` 的判断，可直接排除大量盘外位置。诊断中的四帧一致支持该优化；正式合入仍需覆盖多相机与动画回归。

### 噪声使用大量特殊函数

每个完整盘采样点调用约 12 次 `PerlinNoise`。每次噪声使用八个 `sin` 哈希，共约 96 次正弦计算。还包含幂、对数、指数、反三角函数和温度计算。

这些运算位于射线积分循环中。整数哈希、预生成噪声纹理和温度查表是合理候选，收益与画面误差需要分别测量。

### 四次追踪与采样覆盖

电影档为每像素四条射线，最大步数 1800；平衡档为一条射线，最大步数 1100。最大步数只是上限，不能直接当作实际迭代数。

1280×720 的电影档每帧发射约 369 万条射线。近场步长与终止条件会影响每条射线的实际成本。

四样本偏移使用 `levels=4` 作分母，采样覆盖较小且有正向偏移。横纵方向又共同除以图像宽度。该分布需要核验空间抗锯齿收益，四倍计算量未必对应四倍有效覆盖。

### 时间累积的利用有限

时间着色器读取同一 UV 的历史值，采用邻域截断，没有运动重投影。相机移动时，历史采样位置与当前射线并不严格对应。

默认旋转速度为 0.65 rad/s，历史混合受 `abs(rotationDelta) * 45` 约束。固定 60 Hz 步长下当前帧权重至少约 49%。

实际帧间隔达到约 34.2 ms 时，该运动项可使当前帧权重达到一。这限制电影档慢速交互时的时间抗锯齿收益，无法充分替代空间四次追踪。

## 公开实现对照

| 实现 | 实时策略 | 质量与适用边界 |
| --- | --- | --- |
| 本项目 | 三维逐步弯曲追踪、厚体积盘、程序化噪声、电影档四次追踪 | 美术参数丰富；物理模型采用实时近似 |
| Eric Bruneton | 预计算测地线表、每像素常数时间求交、光束与星光过滤、光谱查表 | 面向非旋转黑洞；盘模型与本项目厚体积云盘不同 |
| Oseiskar | 球对称轨道降维、40/100/200 步质量档、盘交点纹理与光谱纹理 | 作者列出低步数及纹理采样伪影；运行性能依赖设备与分辨率 |

Bruneton 的查表方法保留引力透镜、相对论多普勒和辐射束射等效果。其论文目标是高质量实时非旋转黑洞，不能归类为仅靠较差视觉效果获取速度。

Oseiskar 的源码在穿越盘面时采样纹理，避免每个积分点重复计算厚体积云噪声。这同时包含场景模型简化和更紧凑的求解工作量。

Oseiskar README 报告过 GTX 750 Ti、1080p、高档 30+ 帧的结果。该数字来自作者的历史环境，本次未在同机复现，不能作为公平速度排名。

## 优化顺序

1. 加入保守盘体边界，单独验证多相机、动画与逐帧图像误差。这是当前证据最强、视觉风险最低的候选。
2. 核验四样本分布，区分交互与静态输出采样。交互路径评估单射线与有效重投影，静态输出保留累积质量。
3. 在边界优化后拆分追踪、Bloom、时间累积和合成计时。测量实际积分步数、盘采样数与终止原因。
4. 用查表或纹理降低重复噪声、温度和红移计算，建立质量误差与运动稳定性检查。
5. 评估预计算测地线与局部体积盘采样的混合方案。先确认 Schwarzschild、盘厚度及相机变化的适用范围。

当前数据支持电影档存在明显优化空间，但不能承诺完整画质下达到 60 Hz。保守边界候选约为 19 ms，仍需进一步降低成本。

评估依据版本为 `7c5a7a0`。优化候选进入实现阶段后执行独立回归。原始实验与判定见 `evidence/blackhole-performance-2026-10-03/`。
