## R3 基础进展

FrameTaskScheduler 新增并行执行入口。测试先确认缺少接口会编译失败，再验证 64 个任务恰好执行一次。重复运行不重放，任务异常在全部任务结束后传播。该入口尚未接入 Vulkan 录制；不能据此认定 R3 并行录制已完成。

工作任务现接收独占的线程编号，用于选择线程命令池。128 项任务测试检查相同编号不存在并发重入。RHI 新增 indexed indirect draw 接口，Vulkan 与 NullRHI 均实现零数量跳过及参数校验。Compute 参数生成、真实 GPU 间接提交和能力降级尚未接入。

WorkerCommandPools 按帧槽和四个工作线程分别持有 Vulkan 命令池。宿主在帧 fence 完成后重置对应池，退出时等待 GPU 再销毁。未完成 fence 拒绝重置，非法设备参数拒绝构造。Sample 的 30 帧 Debug Validation 运行通过；并行录制回调尚未接入这些池。

RenderGraph 新增接收 recorder 的命令回调。Character 阴影、主场景和蒙皮 Pass 按值捕获上下文，使用执行时提供的 recorder。现行执行仍为串行。共享计数与 renderer 可变录制状态仍需移出，之后才能安全分派工作线程。

Character 已移除共享提交计数指针，绘制函数显式接收 Pass 计数。Character 与 Blackhole 更新阶段复制本帧设置，录制阶段读取 renderer 持有的副本。实际并行路径仍需独立 Pass 计数和不可变实例数据，不能仅凭这些修改宣称并行录制完成。

Character Compute 蒙皮现由工作线程录制 secondary command buffer。全部任务结束后，主线程按图顺序放置屏障并执行 secondary。Debug GPU 蒙皮、Morph 一致性和 RenderGraph 替换回调测试通过。图形 Pass 并行、单线程切换、GPU 剔除及间接提交仍待完成。

`--disable-parallel-recording` 已接入主线程录制切换。Debug 单线程七视图严格回归全部零像素差异，结果见 `build/msvc-debug/visual-single-thread.json`。CLI 测试覆盖默认启用和显式关闭行为。

帧图新增 IndirectBuffer 使用状态，测试确认 Compute 写入到 DRAW_INDIRECT 的屏障。Character 阴影绘制内容已从 render pass 边界拆开，为继承 render pass 的 secondary 录制提供入口。此拆分仍使用原串行执行路径。

Character 阴影现接入图形 secondary 录制，主缓冲负责 render pass 边界和时间戳。Debug 七视图与 GPU 蒙皮测试通过。NullRHI 使用空模拟句柄，因此图形 Pass 改用显式标记，避免模拟执行跳过边界。主场景图形并行及 GPU 间接提交尚未完成。

Character 主场景已拆分边界并接入 secondary 录制。主场景计数由独立存储持有，任务完成后在主线程合并。阴影、主场景与蒙皮可分派到不同工作线程。透明索引上传仍在主场景任务内执行，完整快照和 GPU 剔除仍待收口。

计时 JSON 新增 CPU recordingMilliseconds 和 workerRecordedPasses。RTX 2060 Debug 30 帧采样显示并行路径 90 个工作 Pass，单线程为零。CPU 录制平均分别为 0.883 ms 和 0.846 ms；小场景未体现收益。这是诊断样本，正式预算仍需 Release 压力场景与重复采样验证。

WorkerCommandPools 重置后复用已分配的 secondary 缓冲，仅在每线程任务峰值增长时扩容。此前每帧继续分配会积累命令缓冲，现按帧槽与线程游标复用。每个游标仅由独占工作线程访问。

新增 cull_indirect.comp，使用六平面 AABB 测试，将不可见实例对应命令的 instanceCount 置零。稳定槽保持 firstIndex 和 firstInstance，单槽只表示一个实例。CPU 参考契约与 GLSL 布局断言通过，着色器编译通过。实际 GPU 缓冲、调度与绘制消费尚未接入，不能据此确认 GPU 驱动提交完成。
