## 目标与依据

目标是让干净项目具备完整的基础三维制作流程。
层级、属性、视口与设置使用一致的交互规则。
对象、组件、资源和可选渲染能力具有清楚边界。

需求来源为用户提供的编辑器优化提示词。
原文件为 `D:/Assigment/temp/temp.txt`。
本页保存本轮采用的范围与执行规则。
本轮范围为实施开发计划及集中验收。

采用 Dear ImGui、GLFW、Vulkan 和现有 C++ 服务。
编辑入口调用 `EditService`，运行能力归属运行模块。
DeepWiki 用于辅助定位，源码用于确认实现事实。
本轮静态核对未读取 DeepWiki，其内容未作为证据。

每阶段同步架构、操作说明和变更记录。
提交前核对差异、暂存范围和短测试结果。
提交标题使用 `feat(edN): <中文摘要>`。

### 新增工作流的通过条件

- 干净项目使用基础几何、光照、相机和现有 UI 能力。
- 创建名称可预测，重命名和层级操作保持对象身份。
- 组件依赖、状态、引用及释放与持久化契约一致。
- 文件管理器拖入模型后可见、可选、可定位。
- W/E/R、操作轴、工具栏和焦点使用同一状态。
- 碰撞形状、中心及尺寸与创建规则一致。
- 个人偏好、项目设置和场景数据按各自来源保存。
- 可选特性关闭或缺少依赖时，基础编辑与运行可用。
- 完成 Monica 创建、重开、保存、GUI 发布与移动运行。
- 既有探索、检视、二维、材质及格式交换通过相关回归。

### 优先复核的边界条件

1. 中文和空格路径：外部依赖随导入和移动保留。
2. 异步导入时切换项目：结果绑定原文档或安全取消。
3. 删除对象或移除组件：引用、系统和资源同步更新。
4. 文本输入和失焦：场景快捷键与持续按键正确隔离。
5. 模块缺失和旧数据：明确诊断，基础功能保持可用。

各边界短测试归属 ED1、ED3、ED4 和 ED6。
实体评价及完整端到端结果归属 P8.5。
全部必需条件通过后，P8 才可标记完成。
