# 引用下拉框搜索验收

属性面板的引用下拉框打开时聚焦搜索框。
每次打开从空搜索开始。
无匹配时显示提示，清除后可直接继续输入。
按 Esc 关闭下拉框，保留当前引用。

## 生产界面回放

生产基线为 `4e07fef`，配置为 Release。
批次 `2256` 在两项目录制输入与截图。
直接输入无效，手动聚焦后可输入搜索词。
筛空时无反馈，切换到音频字段仍显示原词。

候选批次为 `2257`。
探索项目与资产检视项目均通过下列检查。

| 操作 | 通过条件 |
| --- | --- |
| 打开节点下拉框，直接输入不存在的词 | 列表即时筛空，显示无匹配提示及清除按钮 |
| 清除并直接输入节点名称 | 兼容节点恢复，随后显示匹配节点 |
| 关闭节点下拉框并打开音频字段 | 搜索为空，可见音频资源且类型匹配 |
| 输入后按 Esc，再打开节点下拉框 | 一次按键关闭，原选择、文档摘要和撤销计数保持 |
| 按节点标识与音频路径搜索并选择 | 每次写入生成一条撤销记录 |
| 分别撤销重做，保存并重开 | 引用恢复到对应状态，重开后的摘要一致 |

Release 构建和 4 项受影响的 CPU 检查通过。
截图用于核对焦点、空结果和切换后的候选。
回放还核对保存文件中的节点和音频资源标识。
实体键鼠、输入法和多屏归属现场复核。 [运行回执](results.json) · [日志与截图](verification.zip)

## 实现与接入

搜索是下拉框的临时状态。
候选复用场景节点、资产目录及注册类型。
选择通过 `component.batch-field` 提交编辑事务。
属性面板的拾取、定位与拖放保留各自入口。

本单元改动属性面板、面板状态与本地化词条。
组合生产补丁可应用于主线 `63523ad` 的隔离索引。
主线合入由集成线安排。
