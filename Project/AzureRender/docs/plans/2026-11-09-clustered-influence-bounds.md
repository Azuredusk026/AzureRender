# 聚簇灯影响盒裁剪

状态：实现及所属验证通过，正式验收继续推进。

## 范围与契约

机制归属于渲染核心的聚簇分配。
有限影响盒与聚簇视锥做保守分离检查。
只有表面接收的局部灯采用此裁剪。
有序角色合成及全局灯保持既有分配。

CPU 灯数据保存正向视空间的盒变换。
变换缺失、病态或投影异常时沿用半径范围。
相交或接近数值边界的聚簇保留灯引用。
现存灯引用保持相同相对顺序。

透视与正交相机共同消费此机制。
独立夹具覆盖相机偏移、符号和近面交叉。
GPU 灯布局与着色程序维持现有契约。
正式画质与帧预算继续按原标准验收。
