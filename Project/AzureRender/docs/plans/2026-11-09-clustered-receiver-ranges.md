# 聚簇灯接收范围

状态：实现及所属验证通过，正式预算继续验收。

## 范围与契约

本单元属于渲染核心的灯引用打包。
每个聚簇保存四份保序范围。
范围分别服务表面、字符、表面发光衰减及字符颜色合成。
原有完整聚簇查询继续提供组合成员表。

表面发光衰减对颜色合成灯采用字符接收规则。
其他灯遵循普通表面接收规则。
无光照材质只消费字符颜色合成范围。
接收策略保持原有材质和灯计算语义。

头表采用每聚簇连续四份区间的布局。
引用指向同一份 GPU 灯表，保留既有相对顺序。
网格缓存维护分配与接收策略的失效条件。
运行时只上传有效索引，头表声明可访问前缀。

## 级联归属

显式场景照明的级联可见量由表面方向灯提供。
缺少该方向灯时，级联消费返回完全可见。
传统展示照明及显式 QA 主灯保持各自提供者。
只有局部灯的 NPR 场景按同一契约处理首帧及绑定模式。

Intel 原控制存在九个绑定差异像素。
禁用备用级联的控制使绑定及首帧差异均归零。
修复后执行所属场景回归，原严格标准保持有效。

既有短测记录对应级联归属修复前的冻结程序。
正式预算继续按最终交付候选独立验收。
