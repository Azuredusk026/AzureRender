# 当前 CPU 子阶段定位

## 问题与来源

当前生产运行实现以 `cb82fcf` 为来源。
原生短检的 CPU 均值仍约十五毫秒。
场景变换及透明缓存的整帧收益未成立。
本单元定位当前耗时占比，作为下一批优化依据。

## 采集边界

私有副本包含宿主帧实现及角色场景实现。
副本保持生产类布局及原计算顺序。
计时记录写入独立目录，生产程序保持原摘要。
现有资产及着色程序通过路径引用。

单次采集使用原生 1080p 联合场景。
预热三百帧，分析其中二十个稳定身份帧。
宿主、渲染器和实例准备按包含关系解释。
计时与日志开销单独说明，结果用于成本归因。

实例准备细分为边界、世界矩阵、姿态及上传。
姿态循环分别记录采样、权重、边界和派发准备。
原 CPU、GPU、环境及画质门禁保持有效。

## 执行与后续

实现、私有构建及一次采集合计预算二十分钟。
运行前后校验源码、正式产品及挂载项目摘要。
采集后按热点耗时估算下一批可消除工作。
预期热点成本减少至少百分之二十时集中评估。
