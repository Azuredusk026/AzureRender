# 原创反射生产接入计划

目标为解决原创场景的动态反射缺失及默认法线偏角。
执行采用测试先行，每阶段验证后独立提交。
依据为原创检修站法线、历史及边缘拒绝证据。
实现归属 RenderCore 和材质资产契约。

## 验收范围

匹配参考输入及 592.82 四帧列为延期专项。
当前开发使用 595.79，明确记录产物身份。
静止兼容、错误历史拒绝及既有预算继续有效。
正式房间交付与 Steam 实机沿用暂停状态。

## 执行阶段

- [x] P0：接入运动深度核验。
  修改 `shaders/projected_reflection_trace.hlsl`。
  在 `tests/ProjectedReflectionCameraGpuTests.cpp` 增加移动用例。
  先验证基线失败，再检查运动恢复及错误深度拒绝。
- [ ] P1：验证平移、旋转、遮挡和相机切换。
  使用公共 GPU 夹具及原创 Player 项目。
  核对正常历史接收、背景拒绝和重置。
- [ ] P2：修正无贴图材质的中性法线契约。
  先核对资产元数据及着色器公共表示。
  保持有贴图材质的方向及既有兼容承诺。
- [ ] P3：执行实际 Player 交互、重开和历史重置。
  用冻结输入、机位和固定时间步复算画面。
- [ ] P4：执行双配置及受影响设备回归。
  检查同步、资源释放和 CPU、GPU 帧耗时。
- [ ] P5：同步证据、总计划及工作线检查点。

## 预算与提交

单个定位十分钟，候选及短检二十分钟。
构建和采集沿用共享队列及受管任务目录。
每阶段检查差异、暂存范围及验证结果。
阶段失败按根因修复和复测，保持原验收门槛。
