# 相机与呈现的物化输入共享

## 状态与交付物

状态：实现及定向兼容检查通过，短时 CPU 收益成立。
源码基线为 `f05f22e`。
实际调用栈包含相机入口中的渲染描述转换。
来源见[当前 CPU 观察](../acceptance/nr/current-cpu-hotspots.md)。

既有场景文档入口保留独立取样方式。

应用的资源路径转换仍由宿主资源服务持有。

测试覆盖两种输入的等价性和调用方快照隔离。
父子变换、优先级及跟随回退共同回归。
