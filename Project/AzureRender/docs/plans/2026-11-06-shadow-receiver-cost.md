# 软阴影接收成本

## 状态与依据

状态：诊断完成，两次基线热状态未满足比较条件。
源码基线为 `9f04eb8`。
完整场景 GPU 帧 P95 为 39.81 毫秒。
场景分项为 33.92 毫秒，阴影分项为 5.65 毫秒。
完整时间和热状态门槛保持未通过。

## 单一变量

私有资源目录复制当前五百三十五份着色程序。
基线目录的所有程序按字节保持一致。
控制目录只替换四份已确认使用的通用片元程序。
`sampleCascadeShadow` 在控制中返回完全可见。
级联深度生成、其他着色及项目输入保持原路径。

该控制测量阴影接收路径及其依赖计算的成本。
它会改变画面，只用于诊断。
生产着色程序与完整画质门槛保持有效。
原始 GLSL 通过同配置编译先核对生产字节。
控制程序通过 SPIR-V 校验后进入私有目录。

## 实际负载与记录

原生项目、1080p、机位及灯组使用既有性能输入。
按基线、控制、基线的顺序运行。
每次预热三百帧，统计一百二十帧。
短时分项用于归因，正式验收继续统计一千八百帧。

每次记录供电、功耗、运行温度与热降频。
源码、生产程序、私有程序及项目输入分别核验。
基线 GPU 均值漂移至多百分之五，且运行环境检查通过，
才将比较用于幅度估计。
控制收益只用于选择后续保留画质的实现。

## 预算与来源

编译每份程序持有一百二十秒期限。
每次原生分项持有三百秒期限。
控制图像验证持有九百秒期限。
定位十分钟，候选与短检二十分钟。
同一问题探索总预算三十分钟。
