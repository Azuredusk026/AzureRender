# 角色展示画面优化计划

> 类型：实施计划
> 状态：2026-10-10 完成
> 执行方式：本会话连续实施和验收

**目标：** 修复软阴影条纹，恢复黑位、肤色和材质层次。

**架构：** 渲染模块提供共享采样和表面响应。
展示资产提供调色参数，应用负责捕获。
公共夹具与角色转台共同验证输出。

**技术栈：** Vulkan、GLSL、C++、Python。

**依据：** 用户提供的脚部阴影截图和现有转台视频。
开发约束见仓库根目录的 `AGENT.md`。

## 输入与约束

角色资产为 `laevat_repaired_v2.glb`。
环境为 `EveningSkyHDRI007B_2K_TONEMAPPED.jpg`。
镜头、环境、转速和曝光在实验期间保持固定。
既有用户改动保留，提交只包含本任务增量。

## 重点验证

| 输入 | 验证要求 |
| --- | --- |
| 宽半影与斜向边缘 | 可见度连续，采样不形成周期条纹。 |
| 接收斜面与级联边界 | 无自遮挡误判，采样保持图集隔离。 |
| 黑色色块 | 输出保留黑位，灰卡亮度合理。 |
| 光滑扣件与粗糙衣料 | 高光宽度与强度区分明显。 |
| 角色旋转与头部近景 | 无额发白块，细节和时间稳定性达标。 |
