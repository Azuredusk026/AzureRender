# 材质视图组合候选

## 目标与资格

验证已通过局部及原生净收益的深度可见性组合。
资格来源为 `d41f927` 与 `e329f55`。
严格原始四帧、设备支持及正式性能保持现有标准。
完整画质与固定功率分别按所属验收执行。

## 模块与契约

设备宿主按物理能力启用四像素组及最大重收敛。
材质渲染器拥有参考管线及优化管线的生命周期。
选择策略消费实际上传的相机值和资源可用状态。
普通项目、诊断视图及参考 UV 场景共同验证边界。

`ComputedMaterialView.hpp` 提供纯值资格及程序映射。
`CharacterMaterialUv.inc` 复用程序来源及管线创建入口。
`CharacterMaterialSampling.inc` 在完成材质策略后选择管线。
渲染器在实际相机上传时更新当帧选择状态。

`mesh.frag` 使用条件编译保留参考族。
优化族保留幸存四像素组的全部四份导数。
`CMakeLists.txt` 生成有界绑定数组族并声明宿主能力开关。
现有 860 份程序保持摘要，新增族至多 128 份。

## 验证顺序

先验证资格、程序名称及非法输入的失败用例。
实现纯值策略后复验不同设备、相机及资源条件。
实际编译两配置，并核对十份测量程序的中间码身份。
缺失可选程序、卸载清理及参考 UV 组合分别核对。

NVIDIA 执行生产选择与严格原始四帧验证。
Intel 执行能力回退与受影响材质回归。
短时参考、候选及参考测量按相同宿主成对执行。
通过所属检查后同步结果、清单及中文阶段提交。
