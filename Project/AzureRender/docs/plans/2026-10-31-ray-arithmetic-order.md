# 射线算术顺序实施计划

日期：2026-10-31。归属为 NR5-R8-R2 的数值参考。
执行方式为当前会话自主实施。
目标是建立可复现、可拒绝错误输入的顺序规范化工具。

生产渲染内核的接入继续按专项计划验收。

## 已验证依据

默认重建的三份输出分别有一、九千三百一十二及零字节差异。
常规优化等级产生相同的计算程序。
全局及局部精确计算声明均未通过完整输出检查。
关闭优化的对照仍有十、二百一十及零字节差异。

十组矩阵乘加和三处点积的计算顺序已有独立 GPU 对照。
同时恢复这些顺序后，三份完整输出均逐字节一致。
原始程序替换及恢复对照均通过。
该结果属于冻结输入的字节码验证。

## 模块与数据

Python 工具位于 `tools/native_render/shader_arithmetic_order.py`。
模块负责 DXBC 容器校验和有限的算术顺序变换。
它使用标准库，并按策略数据选择操作。
捕获事件、资源身份和编译器版本归属于外部来源清单。

公共函数为 `normalize_shader(data, policy)`。
输入为字节串及策略对象，成功时返回新字节串。
容器内容、校验值、程序指纹及策略均须有效。
错误输入产生 `ValueError`，输入内容保持有效。

策略版本为一，以计算程序 SHA-256 锁定来源。
矩阵项声明乘法及后续乘加的字偏移。
点积项声明指令偏移及分量排列。
重复目标、越界、错误操作码及不支持的操作数均拒绝。

矩阵变换从重建程序本身提取两个乘积。
临时量掩码和累加器排列决定分量对应关系。
输出保留独立乘积与后续乘加的规定顺序。
规范化过程只依赖重建程序及外部策略。

点积变换保留寄存器及负号修饰。
指定分量顺序决定乘积的累计次序。
其他指令、反射资料及容器数据保持原始字节。
输出校验值按官方容器规则重新生成。

## 来源与许可

令牌格式依据 Microsoft DirectX-Headers。
固定提交为 `c526f205c5f96cd2884bf0834c14c7e61bb726c8`。
容器校验规则依据 DirectXShaderCompiler 的 `DxilHash.cpp`。
固定提交为 `84f68ed1a40db3f3444a306162cab6ac0adfe842`。

Python 实现记录格式和校验规则的适配范围。
对应许可及来源进入第三方清单。
工具测试覆盖冻结程序及独立的舍入场景。
GPU 结果、编译输入与原始失败分别保留。
