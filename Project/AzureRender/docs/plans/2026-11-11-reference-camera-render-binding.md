# 参考相机生产接入实施计划

## 目标与归属

RenderCore 的共享相机描述持有参考标定及锚点。
Runtime 的场景选择将标定传入该描述。
角色渲染器消费统一的参考投影上传参数。
编辑器拾取和辅助线消费同一描述。

项目参考视图集合在加载阶段声明程序能力。
顶点程序按显式宏生成独立变体。
相机缓冲尾部追加 112 字节，既有偏移保持稳定。
普通项目使用其现行程序选择及数值路径。

## 验收与预算

原四帧摘要及全部现行画质门槛保持有效。
新增顶点程序须保持程序集上限 1024。
原有程序与参考程序分别登记摘要。
参考开启和关闭均核对验证层与资源释放。
实际光栅的几何掩码在各端点须逐像素一致。
端点间颜色误差至多为一个字节。
关闭参考与普通程序的图像摘要须精确一致。

定位预算十分钟，候选预算二十分钟。
问题探索预算三十分钟，正式构建预算三十分钟。
正式 GPU 验证预算二十分钟。
任务产物预算 256 MiB，归档至多 8 MiB。
