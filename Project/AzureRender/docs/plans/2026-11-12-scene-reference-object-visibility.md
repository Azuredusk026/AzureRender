# 场景参考对象可见量

参考场景提供同一帧槽的深度、法线和对象身份。
本单元接入实际对象深度图集及对象记录。
公共可见量通道输出 `R8G8_UNORM`。
默认场景继续使用现有相机及材质通道。

## 配置

具名参考视图通过 `objectVisibility` 选择输出。
配置要求反向参考深度与可见量输入。
像素偏移使用当前参考附件坐标。
参考坐标帧统一位置重建、法线、灯向及对象投影。
