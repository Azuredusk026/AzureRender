# 图形管线复用

## 目标

状态：候选隔离，归属编辑预览性能任务。
私有闲置复用契约已经完成失败控制及通过检查。
生产入口使用受检基线。候选保存在本机任务目录。
资产网格及刷新保持十秒等待预算。
管线复用消费相同的着色字节及完整创建条件。
实际创建接受现行 Vulkan 验证。

## 来源

Debug 综合操作在资产网格及刷新处超时。
原生采样定位到管线创建中的验证层调用。
本机 SDK 的调试符号包含常量折叠调用。
[对应版本源码](https://github.com/KhronosGroup/Vulkan-ValidationLayers/blob/vulkan-sdk-1.4.350.0/layers/core_checks/cc_spirv.cpp)提供验证路径依据。

## 所有权

设备宿主持有有界的图形管线复用池。
Vulkan 后端借用该池，并维护创建元数据。
每次创建持有独立的活动句柄。
池仅复用已释放且创建条件相同的闲置管线。
宿主退役全部渲染资源后清空复用池，再销毁设备。

池保留至多 128 份闲置管线。
闲置键数据预算为 64 MiB，按完整字节保守计数。
活动句柄独立计数，闲置项按最近使用顺序回收。
请求、命中、释放、回收及创建数量均可观察。

## 复用条件

键包含顶点及片元程序的完整字节。
特化值、顶点输入及全部栅格状态参与比较。
附件定义、集合布局和推送范围按完整描述比较。
未知创建元数据沿用直接创建与释放路径。

结构相同的渲染过程及布局用于独立预览视图。
兼容条件见[渲染过程](https://docs.vulkan.org/spec/latest/chapters/renderpass.html#renderpass-compatibility)及[管线布局](https://docs.vulkan.org/spec/latest/chapters/descriptorsets.html#descriptorsets-compatibility)。
此机制服务于资产缩略图及独立相机预览。
渲染图像、帧缓冲、材质和描述符保持各自所有权。

## 验证

1. 保留综合操作失败及原生线程采样。
2. 添加完整键、引用计数及容量回收检查。
3. 核对全部创建字段、字节变化和未知元数据。
4. 接入设备宿主，并验证关闭时的所有权。
5. 复测两个工程的综合操作及重载恢复。
6. 核对两种构建的图像、验证日志和资源卸载。

## 隔离候选

设备宿主持有复用池，后端维护已知创建元数据。
活动句柄独立，闲置对象按完整条件参与复用。
未知创建条件使用原有直接创建及释放路径。

主渲染过程通过原生后端入口创建及销毁。
原生创建描述和依赖定义由调用方完整提供。
该路径使用独立的生命周期身份参与复用。
渲染过程销毁后，其身份从创建元数据中退役。

资产刷新先退役所属渲染器，再创建受检替代资源。
资产缩略图和独立相机视图使用结构相容的创建条件。
完整编辑回归继续按原十秒预算验证。
关闭时核对活动与闲置数量，并记录命中及创建计数。
