# 浮点历史身份编码

目标为核对可混合的逐像素身份表示。
受检接口为生产 RHI 的多颜色附件管线。
来源为 `25f8f7c` 及已有混合验证信息。
本单元使用局部 GPU 夹具，保持生产渲染入口。

## 编码与边界

身份采用 `R32_SFLOAT`，输出 Alpha 固定为一。
合法键为零至 `16777215` 的整数。
越界输入输出负一，消费方按无效身份处理。
键计算须在加法前核对范围并保留回退路径。

身份为第三颜色附件，随深度竞争共同写入。
夹具使用普通 Alpha、预乘 Alpha 及主颜色加法。
每种方式覆盖完整合法键域及越界值。
遮挡绘制与无效身份覆盖分别核对。

[局部契约](../acceptance/nr/float-history-identity.md)在两设备通过。
每台设备完成 57 个场景及 119537664 个像素结果核对。
后续场景验证独立核对容量、采样与净收益。

临时入口只借用既有测试目标的编译配置。
私有程序使用独立名称，运行前恢复原测试源码。
生产渲染代码、着色程序及用户保护文件保持原字节。
本单元不采集场景四帧或整帧计时。

定位预算十分钟，夹具与短检预算二十分钟。
各次构建及单设备运行预算分别为一百八十秒。
任务预留六十四 MiB，精简证据至多八 MiB。
