# 任务空间监控开销

本单元入口为 `794aad1`。
日常清理及前台空间监控沿用现行配额。
单元先核实任务遍历和路径核验的 CPU 成本。
主要开发与性能采样应保持必要的处理器余量。

## 分析与范围

只读基准采用已完成任务的真实目录。
分别记录墙钟、进程 CPU、文件数和热点调用。
候选集中处理重复遍历及重复祖先核验。
每日保留、字节、文件数及卷余量门槛保持有效。

根目录身份、链接及嵌套 Git 保护继续有效。
权限错误与根目录消失仍进入失败路径。
构建临时文件自然消失按既有规则处理。
前台监控保留每秒的预算和期限检查。

## 预算与检查

定位预算为十分钟，实现及所属检查为二十分钟。
本次预留一 MiB，普通产物保留一天。
输入沿用已完成任务，输出均在项目目录。
本单元只运行维护工具检查和局部 CPU 对照。

通过条件为减少实际监控成本并保留保护行为。
受影响源码、主产物及用户差异分别核对。
GPU 图像、整帧计时与长跑按渲染任务门槛执行。

## 阶段结果

真实任务的扫描墙钟中位值减少约 84.95%。
受管夹具的监控父进程 CPU 耗时减少约 81.82%。
目录及配额保护检查通过，运行目标字节保持相同。
结果与边界见[监控开销验收](../acceptance/recovery/storage-monitor-cost.md)。
