# 材质缓存写入生命周期

目标为在加载结束后释放材质身份像素。
驻留核对来源为 `33900fd`。
冻结原生项目保留约 1.66 GB 身份字节。
完整像素比较服务于加载期的精确共享。

## 公共契约

所属模块为 RenderCore 的采样纹理缓存。
缓存提供明确的结束写入操作。
该操作释放 CPU 身份存储，保持 GPU 绑定及所有权。
结束写入后的申请在修改状态前报告错误。

结束写入具有幂等性，支持空缓存。
清空销毁 GPU 资源，并恢复可写状态。
输入所有权、累计统计及失败状态均保持明确。
并发规则沿用加载宿主的串行调用契约。

场景适配在全部加载任务完成后结束写入。
该位置覆盖材质与描边资源的共享申请。
交换链重建及场景资源复用保持既有绑定。
项目重载建立新的缓存生命周期。
