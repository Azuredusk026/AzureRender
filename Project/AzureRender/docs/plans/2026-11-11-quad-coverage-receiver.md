# 四像素组覆盖接收核验

## 目标与依据

核对透明裁剪四像素组的接收计算需求。
来源基点为 `f3071a4`，候选保存在任务目录。
实际固定类别分组约占全事件成本四分之一。
片元调用差额按[工作量范围](../acceptance/nr/material-fragment-work-scope.md)解释。

## 候选规则

延迟资格要求透明裁剪及节点透明度恰为一。
普通快速材质保持其原始接收入口。
完整四像素组没有有效非辅助覆盖时结束着色。
其余组执行原始四份接收导数及各自的裁剪结果。

候选要求实际启用四像素组及最大重汇合特性。
使用受检私有设备的完整冻结捕获。
编译十份实际程序，并按 Vulkan 1.1 验证。
六份附件、完整事件和固定类别成本分别核对。

## 门禁与预算

参考与候选均使用替换管线，并预热十六次。
顺序为参考、候选、候选、参考。
全部六份附件逐字节一致。
热点至少占四分之一帧成本，并减少至少 20%。

整帧节省 GPU 三毫秒也可进入原生核验。
定位预算十分钟，实现与短检预算二十分钟。
候选未准入时保留证据并继续独立单元。
正式性能及整体画质保持既有标准。
