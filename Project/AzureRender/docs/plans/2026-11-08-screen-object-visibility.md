# 屏幕对象可见量实施计划

## 目标与边界

RenderCore 提供由深度、法线和对象身份生产八位可见量的公共通道。
依据为[对象接收输入核验](../acceptance/nr/object-receiver-input-model.md)。
图形通道完成深度重建、偏置、十六次四点采样和真实附件转换。
输出为 `R8G8_UNORM`，红通道为一，绿通道为对象可见量。
公共数据包含矩阵、明确的光方向、偏置、图集范围及采样半径。
原生常量位置、角色名称和资源标识属于校准夹具。

模块借用输入视图，拥有输出、逐帧参数及图形管线。
调用方发布采样依赖，等待各槽位的消费者完成后重用或销毁。
合法输入必须匹配声明的格式、范围和只读布局。
非法参数在上传和录制前拒绝；像素中的零身份及越界身份返回全可见。
对象身份采用一至八的整数，零表示背景。
法线采用以 Y 轴为极点的八面体编码，位于红绿通道。
设备深度和对象深度的正向、反向约定具有独立定义。

第二种使用方式为独立工具生成的平面深度、法线和对象身份。
该用例覆盖全遮挡、全可见、背景、越界身份及槽位重用。
原生校准用例覆盖完整 17017 像素遮罩。
场景集成与完整头发颜色为后续独立单元。
整体画质维持 `failed-user-review`，CPU 八毫秒及 GPU 16.6 毫秒预算持续有效。

## 文件与接口

| 文件 | 职责 |
| --- | --- |
| `src/render/ScreenObjectVisibility.hpp` | 类型、借用规则、输出和所有权接口 |
| `src/render/ScreenObjectVisibility.cpp` | 校验、参数上传、管线及槽位生命周期 |
| `shaders/screen_object_visibility.vert` | 全屏三角形 |
| `shaders/screen_object_visibility.frag` | 完整精度接收与八位附件生产 |
| `tests/ScreenObjectVisibilityTests.cpp` | 公共参数、容量、别名与生命周期契约 |
| `tests/ScreenObjectVisibilityGpuTests.cpp` | 合成输入、实际输出及同步核验 |
| `CMakeLists.txt` | RenderCore、着色程序及受影响检查入口 |

入口为 `ScreenObjectVisibilityGpu::record`。
输出只读布局为 `SHADER_READ_ONLY_OPTIMAL`。
每槽位仅拥有两字节每像素的图像及固定大小参数。
累计资源预算为 256 MiB，槽位范围为一至八。
输入深度的投影逆矩阵包含设备深度约定。
对象记录按正向或反向约定解释投影和图集深度。
