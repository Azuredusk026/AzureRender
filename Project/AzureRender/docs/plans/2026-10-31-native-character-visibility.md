# 原生角色主光可见量配置计划

执行方式：当前会话自主实施，基线为 `ad5f2b3`。
目标为核对角色参考帧的场景主光可见量。
来源与现象见[画质诊断](../acceptance/nr/scene-material-quality-diagnosis.md)。

## 所属模块与契约

候选使用现有场景照明字段 `nprLighting.shadowOverride`。
该字段属于场景数据，范围为零至一。
其消费及来源转换见[照明说明](../runtime/npr-illumination.md)。
角色对象阴影、纹理及几何继续使用原输入。

原生角色参考为 10401 帧的头发事件 950。
冻结常量 CB1 的第 111 行 Z 值为一。
来源转换器将该分量映射至现有可见量字段。
此来源用于独立角色照明候选，完整外观继续验收。

## 预期与失败证据

首先核对常量长度、来源摘要及明确的字段映射。
当前联合关卡的有效值为默认零。
候选应满足冻结角色参考的可见量输入。
失败报告保留当前配置与来源值的实际差异。

完整场景的主光阴影开关提供独立颜色正控制。
角色近景与该控制按同一头发区域核对。
隐藏角色的候选与相同内容基准逐像素检查。
原生完整区域及既有严格兼容预算保持原状态。
