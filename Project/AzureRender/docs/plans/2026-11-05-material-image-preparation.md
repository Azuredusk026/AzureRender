# 材质图像准备

## 目标

状态：实现及两种构建的回归通过。
归属于 Q1 的完整回归。
联合采集保持九百秒期限。
材质图像及所有来源层级保持逐字节一致。
精度转换、纹理预算和法线重建保持现行规则。

## 定位

失败进程的场景 CPU 准备耗时约 735 秒。
材质纹理层级生成约 46 秒，另有独立计时。
阶段采样覆盖完整材质解析及逐像素复制。
其中单位因子的复制经过通用乘法循环。

## 实施

1. 保存超时、阶段计时及原生线程采样。
2. 添加覆盖全部八位数值的材质图像检查。
3. 直接接收受检精度转换的像素所有权。
4. 单位因子使用图像及来源层级的连续复制。
5. 非单位因子按所属通道规则计算。
6. 重跑两种构建及完整联合采集。

实现归属于 `GltfLoader.cpp` 的图像解码适配。
各次调用独立拥有像素。
调用方接收精度转换结果的所有权。
用途包括模型导入及完整材质文档解释。
配置、资产格式及模块边界保持现行版本。
