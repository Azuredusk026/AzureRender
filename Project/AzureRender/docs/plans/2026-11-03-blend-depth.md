# 透明材质深度计划

## 目标与依据

状态：执行中，归属于 Q1。
公共配置通过[专项验收](../acceptance/nr/blend-depth.md)。
固定姿态角色的完整区域仍有失败项。
来源透明衣料的实际绘制开启深度写入。
来源比较方式按原生枚举名称核对。
联合画质与严格重开的失败状态保持有效。

## 配置与边界

版本二画像可声明 `blendDepth`。
该对象使用版本一，包含 `write` 与 `compare`。
写入为布尔值，比较为 `less` 或 `less-or-equal`。
缺省透明材质继续采用严格比较及关闭写入。

该对象属于受光透明材质的光栅配置。
分层无光照表面采用自身的深度契约。
资产加载与运行时打包共享合法性检查。
配置随完整材质文档保存并参与替换校验。

渲染器按实际材料需求创建深度管线变体。
照明及裁剪变体先选定，随后应用深度配置。
变体由渲染器持有，随交换链重建及卸载释放。
GPU 材质布局和片元程序保持现行契约。

## 实施与验收

1. 添加加载、非法输入及保存重开的失败用例。
2. 添加生产录制路径的管线及生命周期检查。
3. 实现显式深度配置及运行时合法性检查。
4. 验证双层透明模型的遮挡及同平面比较。
5. 验证两条描述符路径及缺省像素兼容。
6. 在固定姿态中核验来源衣料的完整区域。
7. 同步运行契约、验收报告及来源清单。

透明标牌和叠层薄片共同验证公共配置。
完整角色继续使用冻结区域、相机及既定门槛。
覆盖层的快照参与和严格重开分别持有后续检查。
