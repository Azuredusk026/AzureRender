## 执行顺序

1. 复用现有阶段、事件及硬件计数证据。
2. 按主导成本选择具备显著收益潜力的优化批次。
3. 完成关联实现，保留各机制的独立归因边界。
4. 核对工作量、收益预期及实现成本。
5. 达到集中验证门槛后统一评估兼容及短时收益。
6. 收益成立后冻结候选，执行正式性能及交付检查。

原生帧时间独立统计，保持原采样要求。

## 归因规则

| 对象 | 所需证据 | 结论范围 |
| --- | --- | --- |
| CPU | 工作及等待分布、当前阶段采样 | 主线程工作或同步成本 |
| GPU | 通道耗时、片元及计算调用 | 优先优化的工作通道 |
| 着色单元 | SM 吞吐、占用及停顿 | 算术吞吐或延迟限制 |
| 缓存与纹理 | L1、L2、纹理吞吐及命中 | 访问局部性或纹理延迟 |
| 显存 | VRAM 吞吐及读写计数 | 设备显存带宽限制 |
| 主机传输 | PCIe 传输及上传阶段 | CPU 与 GPU 之间的传输限制 |

显存容量和带宽分别判断。
NVML 的内存忙碌比例仅作设备状态记录。
指标缺失时登记限制及替代实验的适用范围。
成对测量核对热状态、频率、供电和输入。
