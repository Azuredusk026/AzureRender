# 照明复用消费计数

本单元入口为 `157c757`。
照明缓存候选的短时 GPU 均值增加约 0.72 毫秒。
本单元核定实际消费规模及整组回退范围。
计数来源与完整帧性能分别解释。

## 数据与所有权

诊断记录生产写入、消费访问、合格访问及两种命中。
两种命中分别为逐像素匹配和完整四像素组接受。
辅助片元保持排除，计数溢出具有明确标志。
回收完成的帧槽按现有帧栅栏生命周期读取。

每个帧槽拥有六个无符号计数字。
窗口与独立视图共用缓存资源的计数接口。
重建与卸载按缓存资源生命周期释放计数缓冲。
完整着色及默认关闭路径保持所属行为。

## 配置与验证

诊断使用显式构建选项，默认值为关闭。
设备按诊断要求查询并启用片元存储原子操作。
主机构建沿用 D 卷的两个构建目录。
原 673 个着色程序与普通缓存程序保持字节一致。

先检查帧槽归零、结果读取、溢出及释放。
实际 GPU 夹具核对已知图案的访问与命中数量。
缓冲依赖覆盖主机、快照与主颜色阶段。
所属设备检查完成后执行一次三十二帧计数诊断。

诊断只输出计数及来源，不作为帧率收益证据。
新的性能批次以实际工作量及成本门槛组织。
画质、严格兼容及正式帧预算保持有效。
本单元预留 32 MiB，定位与接口预算三十分钟。
