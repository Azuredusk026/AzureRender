## 契约与所有权

图形管线允许空片元模块，提交阶段只包含顶点程序。
调用方选择与深度附件兼容的渲染通道。
材质完整不透明且节点透明度恰为一时可使用纯深度管线。
几何阴影覆盖标志按当前片元程序的优先级判定。

透明裁切、平方根覆盖及节点淡出使用对应片元程序。
所有描画保持原有次序、常量与顶点输入。
渲染器拥有级联和对象图集两份纯深度管线。
销毁及重建沿用既有在途工作与资源生命周期。

依据为 [Vulkan 官方图形管线教程](https://docs.vulkan.org/tutorial/latest/03_Drawing_a_triangle/02_Graphics_pipeline_basics/00_Introduction.html)。
本单元采用 API 机制，不复制第三方代码。
