# 动画局部姿态初始化

## 当前状态

实现通过两配置各三十六项 CPU 检查。
双设备的十二项姿态及运动 GPU 检查通过。
原生四帧逐像素一致，二百二十次同输入姿态原字一致。
分配、局部计时及整帧限制见[验证记录](../acceptance/nr/animation-local-pose.md)。

## 来源与目标

运行源码基线为 `108bb7c`。
动态采样初始化局部输入，并求解完整动画结果。
动画通道消费局部变换及形变权重。
本单元验证局部输入初始化及一次最终层级求解。

所属模块为 Assets 的 glTF 姿态采样。
局部初始化为私有函数，公共姿态接口保持完整结果。
绑定姿态、动画、混合、表情及运动继续消费既有类型。
基础透明度的合法性在动画覆盖之前验证。

## 通过条件

实际渲染器的大骨架动画夹具先执行分配基线。
逐帧动画分配预算为每节点四百四十八字节及固定余量。
两种描述符路径保持原录制输入及排序。
非法基础透明度的覆盖采样继续拒绝。

两配置执行受影响 CPU 检查及来源核验。
原生四帧和五百三十五份生产程序保持冻结字节。
原有设备失败及完整帧预算保持有效。
局部成本与整帧收益分别验证。

定位十分钟，候选与短检二十分钟。
每配置构建九百秒，原生四帧九百秒。
局部成本采集三百秒，探索总预算三十分钟。
