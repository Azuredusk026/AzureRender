# 不透明快照颜色历史核对

目标为核对静态快照着色的跨帧复用成本。
候选归属于 RenderCore 的快照资源及录制流程。
原有颜色和法线图像提供上一帧载荷。
新增逐像素身份图像随颜色附件共同写入。

## 范围与假设

既有快照成本约占原生 GPU 帧时间的三成。
普通表面的历史资格以既有静态命中作为线索。
预期减少该区间至少两成的实际着色工作。
此推断须由候选的实际命中及成本核对。

私有候选限定冻结相机、输入和普通不透明表面。
光照、静态变换和视图身份共同参与失效。
动态投影区域及不同三角形均执行当前着色。
四个片元共同命中时，才能提前返回。

全部快照颜色写入者同时维护身份附件。
非复用表面写入无效标识。
深度预填保持颜色和身份写入关闭。
提交、取消及图像重建分别核对历史生命周期。
