# 专用常量像素精度

## 已核对范围

原生候选关闭专用管线选择后，四帧恢复一致。
十个受检动态程序与原生候选的相应程序逐字节一致。
其中九个局部专用程序仅改变一个布尔常量指令。
另一程序同时具有明确记录的提前深度执行模式差异。

这些程序各有十项横向和十项纵向默认导数指令。
隐式细节层级采样指令为二十九至四十一项。
默认导数可由实现选择细或粗粒度计算。
语义依据为 [Vulkan 着色器规范](https://docs.vulkan.org/spec/latest/chapters/shaders.html)。

## 诊断边界

编译后的导数选择与浮点融合均为待验证假设。
前端差异不能证明驱动选择了哪种机器指令。
静态分析记录程序字节、指令和现有精度约束。
功能控制保留实际数学运算，仅限定导数指令的粒度。

供电条件影响性能计时，像素比较分别记录环境与范围。
本单元的像素控制具有诊断用途，生产保持受检基线。
性能复测仍等待交流供电及既有收益资格。
本单元静态分析和像素诊断预算为十五分钟。
