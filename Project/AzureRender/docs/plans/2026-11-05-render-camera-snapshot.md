# 相机与场景快照

## 目标与契约

状态：两配置 CPU 定向验证通过，GPU 检查按用户安排延期。
运行时相机消费调用方持有的插值场景文档。
宿主为同一帧生成一次游戏场景，供相机和渲染共同使用。
无参数的相机入口负责获取所需场景文档。

快照由当前帧持有，相机选择借用至调用结束。
节点位置与父级变换取自输入快照。
相机组件和跟随策略遵守当前运行时的选择规则。
独立 Player 与编辑播放共用该入口。

## 执行与验证

1. 补充父级插值、输入快照隔离及相机选择契约。
2. 在新增入口存在前保存编译失败记录。
3. 实现借用快照的相机重载，保留既有入口。
4. 宿主共享本帧游戏场景，并完成双配置 CPU 回归。
5. 空闲设备恢复后执行原生图像及完整性能检查。

定位十分钟，候选与短检二十分钟。
探索总预算三十分钟，构建及采集各九百秒。
GPU 条件满足前，画质与性能结果保持待执行。
