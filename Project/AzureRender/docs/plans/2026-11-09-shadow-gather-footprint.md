# 对象阴影采样足迹

日期：2026-11-09。
状态：实现及受影响验证通过，正式帧预算待验。

## 契约与归属

对象阴影过滤使用八位子纹素采样网格。
着色器显式确定四点足迹的左下纹素。
页内硬件采样定位在该四点组的中心。
跨页路径逐纹素读取，页外值保持完全可见。

该规则属于公共对象阴影过滤器。
单页对象与多页图集共用相同算法。
当前图集及记录布局保持现有所有权。
采样器、附件及销毁顺序沿现有资源契约执行。
