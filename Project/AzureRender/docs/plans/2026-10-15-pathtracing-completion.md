# 路径追踪补齐与公开素材演示计划

日期：2026-10-15。状态：PT0 为 Ready，其余阶段待完成。
执行方式：按 PT0 至 PT7 连续推进，每阶段独立提交。
本页规定下一轮实施范围，当前处于计划阶段。

## 目标与交付

补齐金属、法线、透射和灯光采样的关键能力。
交付三个可打开、编辑和发布的公开素材演示。
最终向用户展示 AzureRender 内实际渲染的画面。
渲染机制进入通用模块，演示内容保存在独立项目。

开发期间执行受影响构建、短测试和必要图像检查。
完整回归、双设备检查与画面验收集中在 PT7。
环境待项按既有 P8 规则记录，独立开发继续推进。

## 当前缺项与归属

| 项目 | 当前依据 | 本轮归属 |
| --- | --- | --- |
| 点光源镜面直接光 | 着色器直接光仅计算漫反射 | PT1，必须补齐 |
| 反射能量与采样一致性 | 现有 GGX 混合采样需要数值核对 | PT1，检查并修复偏差 |
| 顶点法线与法线贴图 | 三角形只保留位置和纹理坐标 | PT2，必须补齐 |
| 材质纹理契约 | 当前只有基础色、表面与自发光图集 | PT2，核对通道、色域和纹理坐标 |
| 面光源与自发光采样 | 自发光依靠随机路径命中 | PT3，必须补齐 |
| 环境重要性采样 | 当前环境照明依靠散射方向采样 | PT3，必须补齐 |
| 多重重要性采样 | 灯光与材质采样尚未统一 | PT3，必须补齐 |
| 玻璃透射 | 材质与积分器尚未支持 | PT4，必须补齐 |
| 降噪与低采样预览 | 当前直接显示累积结果 | PT5，提供可关闭的基础降噪 |
| 公开复杂资产与预算 | 现有演示主要使用简单几何 | PT0、PT6，验证导入和资源预算 |
| 模式切换与重置 | 已有机制需覆盖新增状态 | 各开发阶段检查，PT7 集中回归 |
| 硬件光线查询、SHARC、ReSTIR | 属于加速或高级采样方案 | 登记后续候选，另行立项 |

“上黑下黄”可能来自正常的环境反射分布。
修复判断依据灯光公式与对照画面，保留正确反射。
当前 WC 阶段记录代表其已交付范围。
本轮通过 PT 阶段记录新增能力及验证结果。

## 模块与文件边界

| 位置 | 职责与本轮影响 |
| --- | --- |
| `shaders/pathtracing.comp` | 求交、路径积分与采样入口 |
| `shaders/pathtracing/bsdf.glsl` | 拟新增，共用材质求值与采样 |
| `shaders/pathtracing/lighting.glsl` | 拟新增，灯光采样、概率密度与权重 |
| `src/render/pathtracing/TraceScene.*` | 世界几何、法线、材质与发光三角形描述 |
| `src/scenes/pathtracing/PathTracingSceneRenderer.*` | GPU 缓冲、帧资源和累积生命周期 |
| `src/assets/GltfLoader.*` | 标准材质扩展与纹理导入 |
| `src/assets/MaterialData.*` | 材质参数保存、校验与编辑契约 |
| `src/render/RenderSettings.*` | 采样、降噪与预算设置 |
| `src/editor/panels/` | 通过现有服务编辑参数和显示诊断 |
| `src/ui/localization/Catalog.inc` | 新增界面的中英词条 |
| `tests/PathTracingTests.cpp` | 几何、材质与资源契约测试 |
| `tools/test_pathtracing_gpu.py` | 扩展生产渲染检查 |
| `tools/fetch_pathtracing_demos.py` | 拟新增，固定来源、下载和校验素材 |
| `tools/create_pathtracing_project.py` | 复用项目生成能力，按清单装配演示 |

CPU 数据和 GPU 描述的字段、对齐与版本保持一致。
渲染模块持有缓冲与历史图像，宿主管理提交和围栏。
在途帧分别持有上传资源，关闭时等待相关工作结束。
面板调用既有设置和编辑操作，项目内容使用资源挂载。

### 用户必须能看到的结果

交付三个独立工程，并在汇报中直接展示实际渲染截图。
每个演示至少提供一张主画面与一组关键效果对照。
截图来自本引擎运行结果，记录源码和产物指纹。
用户可通过 GUI 重开对应工程并调整相机与光照。

每张主画面记录分辨率、设备、采样数和散射次数。
同时记录渲染耗时、曝光、环境、降噪状态与素材版本。
固定机位下保存 64 和 256 采样原始画面。
以 1024 采样作为本轮图像参考，记录像素误差。
噪声检查使用固定区域和三组随机种子。
256 采样的平均误差应低于 64 采样。

金属演示必须显示随光照移动的镜面高光。
棋盘演示必须显示接触阴影、软阴影和间接照明。
玻璃演示必须显示背景穿透及粗糙度变化。
对未支持的材质扩展和渲染效果明确标注。
必要效果缺失时记录为未通过，并修复所属模块。

### 复核重点

重点覆盖纯金属、背面法线、非均匀缩放和透明叠层。
检查小型发光体、环境高亮点及粗糙玻璃的数值稳定性。
检查中文路径、移动工程、缺失纹理和预算超限。
每个失败保留定位证据，修复后补测受影响范围。
