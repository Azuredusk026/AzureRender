# 所选接收状态与默认视图组合

目标为组合已取得局部依据的两类工作减少机制。
所选接收状态单项减少约 15.25% 的受检事件时间。
默认视图控制曾通过原始四帧，具有独立计时记录。
本项使用同一实际程序重新核定组合结果。

## 机制与资格

四级导数及所选投影、梯度保留契约沿用所属控制。
视图常量只作用于主颜色的普通不透明管线。
其他材质与快照继续读取原始视图输入。
对应管线通过原专用常量确认普通表面资格。

常量输入须与实际上传缓冲逐项一致。
场景照明为一，默认显示及效果模式为零。
效果启用值为一，反射模式使用计算反射。
外部输入的生产选择与回退须另行明确实现。

正式 CPU、GPU 及完整画质门槛保持原值。

## 预算

定位十分钟，实现及短检二十分钟。
单次重放预算五分钟，任务预留 192 MiB。
全部重编译及 GPU 工作使用共享锁。
历史计时用于选择方向，组合资格使用本次实际数据。

## 结果与接续

六处有序颜色累加边界使六附件逐字节一致。
局部减少约 21.28%，参考漂移约为 1.04%。
组合达到原生验证准入条件。
后续单元核对原始四帧及短时整帧成本。
