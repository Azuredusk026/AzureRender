# 材质图像驻留范围

目标为核对当前原生负载的材质图像占用。
来源为 `4051fea` 的短测及主线 `3494eb6`。
当前记录有 385 份唯一材质纹理。
其驻留量约为 2.16 GB，CPU 像素约为 1.66 GB。

## 范围与判据

诊断归属于 RenderCore 的采样纹理缓存。
同一图像的像素、格式及 MIP 生成规则分别核对。
采样器状态独立记录，当前生产绑定规则保持原样。
原生运行只读取缓存归属，执行两帧后退出。

临时诊断仅在明确的进程环境开关下输出。
诊断源码保存于受管任务，取证后恢复原字节。
着色程序、纹理内容及采样设置保持原摘要。
GPU 容量与正式预算的适用范围独立核对。

## 执行步骤

- [x] 保存受检源码、宿主及程序摘要。
- [x] 按完整像素和图像生成规则核对潜在重复项。
- [x] 记录各图像的尺寸、格式、层数及驻留量。
- [x] 恢复源码及 Release 构建，复核两配置来源。
- [x] 封存证据，按实际规模选择后续修复。

[驻留核对](../acceptance/nr/material-storage-scope.md)记录实际结果。
采样器引起的图像重复仅为 3136 字节。
该范围没有形成新增缓存机制的准入依据。
诊断源码和宿主均已恢复并完成核验。

定位预算十分钟，临时实现及短检二十分钟。
各次构建预算三百秒，原生诊断预算四百八十秒。
任务预留 128 MiB，资产沿用原受管路径。
整体画质及原 CPU、GPU 验收标准保持有效。
