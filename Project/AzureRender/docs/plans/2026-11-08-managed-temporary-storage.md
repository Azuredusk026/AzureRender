# 任务临时目录

本单元入口为 `74b4dfc`。
范围为受管前台程序的临时文件位置。
项目产物、缓存及必要恢复包均使用项目所在卷。

运行器为每个任务准备独立临时目录。
子进程的 `TEMP`、`TMP`、`TMPDIR` 指向该目录。
SQLite 临时目录采用相同位置。
临时文件计入既有任务规模及保留期。

公共入口为 `artifact_maintenance.py run`。
适用场景为编译、测试、截图及离线工具。
父进程环境保持原有值。
目录校验沿用现有链接及路径规则。

验证先复现继承系统目录的行为。
集中检查实际临时文件位置、占用和失败恢复。
维护工具回归在项目任务目录中执行。
本单元预算为三十分钟及 4 MiB 新产物。

工具检查覆盖实际子进程的临时文件及超限诊断。
无效临时目录在启动前报错，并释放进程占用登记。
父进程环境保持原值。
部署范围见[临时目录验收](../acceptance/recovery/managed-temporary-storage.md)。
