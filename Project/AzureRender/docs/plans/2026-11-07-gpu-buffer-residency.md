# GPU 缓冲驻留优化

## 依据与目标

当前捕获包含 795 个缓冲绑定和二十五处分配。
其中三十七个缓冲绑定于非设备本地主机内存。
主颜色片元实际绑定的七个存储缓冲均属于该类型。
阴影范围约二 MiB，包含计算写入及高频片元读取。

当前十一项材质热点约占重放成本的七成。
迁移相关缓冲可消除这些缓冲的主机远程访问。
实际时长受缓存、上传及设备条件共同影响。
本批通过图像和成对短检评估实际收益。

## 模块与契约

分配策略归属 `src/rhi/GpuAllocator.cpp`。
着色、顶点、索引和间接读取优先设备本地内存。
主机可见请求继续要求可见、连贯及持久映射。
纯传输缓冲继续采用主机优先策略。
能力受限时由 VMA 按已有必需属性选择合法内存。

`GpuAllocator::memoryProperties` 查询活动缓冲属性。
空分配和关闭的所有者产生明确错误。
调用方保持所属分配器及活动分配的生命周期。
上传数据与 GPU 生成的范围共同验证公共分配机制。
