# 原生 CPU 阶段成本观察

## 来源与交付物

源码基线为 `724a202`。
当前短时 CPU 工作 P95 为 21.79 毫秒。
相机输入复用的来源见[成对控制](../acceptance/nr/materialized-camera-input.md)。

私有诊断程序记录稳态二十帧的阶段时长。
阶段包含模拟、场景快照、物化、相机、渲染更新和命令录制。
正式程序、源码及生产着色字节保持受检来源。

## 观察范围

诊断副本只在任务目录插入局部计时与输出。
沿用正式 Player 的编译参数与当前链接依赖。
程序布局保持现行 ABI，计时状态归属本次调用。
诊断输出用于选择后续单一候选。

阶段计时可包含调用与局部日志成本。
相机子阶段属于帧准备总时长，统计时保留包含关系。
本轮结果与正式性能、画质及长跑验收分别记录。

定位十分钟，私有编译三百秒，原生命令三百秒。
加载与设备预检按原有期限处理。
生产源及运行产物在诊断前后核验摘要。

实际结果、一次内部细分及热状态范围见[观察记录](../acceptance/nr/cpu-stage-cost.md)。
