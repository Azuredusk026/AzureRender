# 运动矢量资源绑定复用

状态：实现及所属验证通过，整帧预算继续验收。

## 范围与契约

运动矢量通道持有描述符集及各帧槽的绑定快照。
输入缓冲内容继续逐帧上传，绑定按资源句柄、范围和采样器核对。
帧槽已完成在途使用后，准备阶段处理资源替换。
输入所有者在销毁并重建资源时显式使对应槽快照失效。

该机制供时间抗锯齿及屏幕空间反射的运动生产共同使用。
几何、着色器、绘制顺序及运动历史的提交规则保持有效。
新增状态随通道实例释放，受检主资产持续引用 D 盘路径。
任务预算为 128 MiB，保留一天。
