# 照明复用深度重放

状态：机制检查通过，原生激活待验收。
生产默认关闭照明复用。

## 目标与依据

验证通道重放独立深度，保持严格 LESS 顺序。
原生主深度保持所属通道的写入契约。
同深度三角形用例验证可见面选择。
独立网格与原生项目共同覆盖机制。

缓存读取指令量已达到调度门槛。
原生四帧仍须逐像素一致。
快路径实际启用后，才执行一次短时成对计时。
正式预算保持 CPU 8 毫秒及 GPU 16.6 毫秒。

## 实现范围

- 渲染器持有每在途帧的 D32 深度副本。
- 深度采样复制后，验证绘制按原顺序写入副本。
- 副本总预算为 64 MiB，其他格式走完整着色。
- 命令行提供显式复用关闭选项，用于同程序比较。
- 所有临时产物写入本任务的 D 盘目录。

## 检查顺序

1. 记录同深度胜出面与命令行解析的失败用例。
2. 实现资源所有权、布局同步和关闭路径。
3. 集中执行相关 GPU、同步及命令行检查。
4. 通过后采集一次原生四帧并检查实际选择。
5. 实际启用后，按 1080p 条件评估局部收益。

## 当前边界

整体画质、正式帧预算与人工验收均待通过。
本单元保持既有验收标准。

严格四帧及同步、释放检查通过。
原生退役槽仍为零轻量帧、两个完整帧。
帧收益计时未启动，后续处理资格影响范围。
