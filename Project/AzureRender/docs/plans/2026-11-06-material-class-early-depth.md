# 场景着色与透明准备优化计划

## 任务与假设

所属模块为渲染核心及角色场景渲染器。
当前 GPU 场景均值为 26.10 毫秒。
本轮完整采样的 GPU P95 为 31.46 毫秒。
该批热状态及八十瓦稳定条件未通过。
硬件事件证据继续支持减少被遮挡的片元着色。

`mesh.frag` 在不透明且节点完全可见时保持完整覆盖。
屏幕照明法线的快照分支含丢弃行为，需使用对应路径。
候选为合法完整覆盖材质类别选择提前深度程序。
普通材质、淡出及多重采样沿用现有路径规则。

## 契约与所有权

资格由材质、节点透明度及采样方式共同决定。
类别与特性专用常量保持实际值。
屏幕照明法线、混合、遮罩及积分路径保持原选择。
管线由所属渲染器持有，并参与重建和卸载。
主颜色与反射快照共用资格规则。
独立立方体夹具和完整联合场景验证两种用途。

## 透明准备

CPU 排序的密集输入每元素计算一次浮点键。
四份直方图使用一次输入扫描。
恒定字节直接保留稳定次序。
任意索引输入保留完整合法性及兼容规则。
顶点坐标、准备标记、深度和排序空间按渲染器复用。
这些工作空间在卸载时释放。

密集路径的键计算量由每元素八次降至一次。
恒定字节还可减少完整数组的分发遍历。
该操作量满足主热点预期下降 20% 的集中评估门槛。
实际耗时与整帧收益分别测量。
