# 磁盘预算实施计划

## 目标与边界

任务产物使用显式配额及卷空间门禁。
实现属于开发工具，供采集及安装验证共用。
运行时与资源加载契约保持既有定义。
基线为 `23015e7`，用户修改按接手清单保护。

## 规则与验收

单任务默认配额为 2 GiB。
正常任务预留后须剩余 50 GiB 及卷容量的 10%。
低空间诊断的计划输出至多为 64 MiB。
此类诊断预留后须剩余 5 GiB。
配额按文件逻辑大小计算，卷余量按系统查询。
外部程序持续写入需在采集边界再次检查。

清理按当前会话授权分批执行，每批至多十个目录。
归档校验、用途核对及用户改动保护属于删除前置条件。
定时任务执行只读审计，保存候选及错误记录。
大型采集在空间门禁通过后启动。

## 风险输入

链接及联接按既有拒绝规则处理。
负数预留与超额预留在写入前报错。
保留标记保护清理资格，配额仍接受审计。
现存超额目录保持原文件并报告阻断原因。
工具只检查显式任务目录，完整盘点独立执行。

## 性能接续

先读取供电、功率及处理器当前状态。
小型诊断复用现有资产与受检程序。
正式性能仍预热三百帧并采样一千八百帧。
CPU 八毫秒及 GPU 16.6 毫秒预算保持有效。
整体画质维持 `failed-user-review`。
