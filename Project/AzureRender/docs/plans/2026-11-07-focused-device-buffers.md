# 按用途选择可映射设备内存

## 目标与归属

分配策略归属现有 `GpuAllocator::createBuffer`。
主机可见的 GPU 读取缓冲优先设备本地内存。
纯传输缓冲继续优先主机内存。
连贯、可见及持久映射的必需属性保持有效。
公共分配接口及运行时数据布局保持当前定义。

同程序设备内存控制已通过原生四帧。
无上传读取及无显式发布的控制也通过四帧。
原驻留候选的差异尚未解释，并保持隔离。
本批将生产修改限定于分配器内部策略。

## 检查设计

真实设备检查位于 `tests/GpuBufferPolicyGpuTests.cpp`。
每种用途使用全新分配器及独立设备夹具。
存在兼容的设备本地映射类型时检查设备堆分配。
纯回读、CPU 写入、GPU 复制及回读字节共同核对。
两种使用场景为着色与几何上传和纯传输回读。

现有统计按设备堆的块占用记录峰值。
独立夹具隔离历史峰值，避免用途间相互覆盖。
缺少本地映射能力时验证合法回退及完整复制。
全部夹具检查验证层及资源释放。
