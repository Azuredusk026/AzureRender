# 持续负载与帧调度对照计划

> 状态：非桌面输入回归通过，正式性能环境门禁失败。
> 所属阶段：P5-B、P5-C。
> 依据：[自动执行计划](2026-10-11-automatic-through-p8.md)。

## 观察与假设

运行期间的观察发现满载与软件热降频。
当前主循环持续提交帧，优先选择 MAILBOX。
帧率限制需要通过公共设置提供给两个宿主。
假设是按显示目标调度可降低持续负载。

帧调度与工作集归因分别验证。
工作集变化按原公式计量。
驱动分配归属和异步工作触发保持独立结论。
对照结果决定该机制是否适合作为生产设置。

## 文件与接口

| 文件 | 职责 |
| --- | --- |
| `src/foundation/FramePacing.hpp` | 计算一帧剩余等待时间 |
| `src/rhi/PresentationPolicy.hpp` | 按声明策略选择设备呈现模式 |
| `src/runtime/EngineSettings.cpp` | 登记类型、范围和设置来源 |
| `src/app/AzureRenderApp.cpp` | 两宿主在主循环执行帧调度 |
| `src/app/AzureRenderCapture.cpp` | 输出实际调度设置与等待量 |
| `tests/EngineSettingsTests.cpp` | 设置校验、帧时间边界与重置 |

`framePacingWaitSeconds(elapsed, targetRate)` 返回等待秒数。
函数接受有限非负帧耗时与目标帧率。
目标为零时返回零，表示无限制。
帧已经超过目标时返回零，随后正常调度。

设置标识为 `runtime.maxFrameRate`。
支持零至一千，零表示无限制。
支持项目、用户和命令行的设置来源。
候选默认值为每秒六十帧，需实跑验证。

`runtime.vsync` 定义同步呈现策略。
它是启动专用布尔设置，候选默认值为真。
同步呈现选择 FIFO，异步模式优先选择 MAILBOX。
实际模式与设置来源进入运行诊断。

## 当前结果

FIFO 对持续功耗的独立改善尚无稳定证据。

所有对照保留原始失败及冻结来源校验。
