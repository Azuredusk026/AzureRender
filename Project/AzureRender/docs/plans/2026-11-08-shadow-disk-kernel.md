# 阴影圆盘权重成本评估

## 范围与门槛

生产入口为 `b1451cf`。
候选对保守外界以外的四点直接输出零权重，其余输入采用现行表达式。
原捕获中有 11917189 次调用，4232176 次可省略平方根。
工作量依据见[圆盘空覆盖](../acceptance/nr/shadow-disk-work.md)。

本单元先限定局部运算的绝对成本。
调用次数和空覆盖次数与原捕获逐像素匹配。
半径与小数坐标采用具有同等工作形状的有限代表输入。
这些输入用于局部成本对照，原场景的准确采样坐标另有归属。
计算夹具覆盖相同分布及像素顺序，使用连续预热和交替阶段。
基线、候选输出须逐位一致，诊断分支核对全部调用次数。

只有局部收益形成足够的原生收益依据，才进行原四帧及成对评估。
源码指令数量、平方根省略比例与整帧收益分别记录。
正式供电、CPU 八毫秒、GPU 16.6 毫秒及画质标准持续有效。

## 执行

- [x] 建立捕获调用形状与代表输入的逐像素对应。
- [x] 编译基线、候选及独立计数程序，完成合法性检查。
- [x] 核对输出、分支计数及连续阶段成本。
- [x] 根据绝对成本决定原生批次的准入。
- [x] 保存精简证据、来源及剩余限制。

## 预算

所有产物位于 D 卷，任务完成后保留一天。
初始预留 320 MiB，局部夹具优先保存形状索引及小型参数表。
原生阶段的独立程序目录在准入后创建。
GPU 夹具时限为一百二十秒，编译时限为一百八十秒。
正式长期证据至多 8 MiB。

## 结果

输出及全部逐像素调用、空覆盖计数相符。
基线与候选均值分别为 0.090575 及 0.100787 毫秒。
候选在该独立夹具中约慢 11.27%，前后基线漂移约为 0.20%。
原生四帧及性能配对均未启动，生产保持受检实现。
具体范围见[圆盘成本结果](../acceptance/nr/shadow-disk-kernel.md)。
