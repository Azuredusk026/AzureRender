# 公共时序重建接入计划

状态：自主实施中。
本计划实施 NR7-AA1 至 AA5 的公共机制。
来源见[原生时序输入](../acceptance/nr/native-temporal-inputs.md)。
提交基础见[提交验证](../acceptance/nr/temporal-motion-contract.md)。

## 输出与所有权

公共设置保留模式零、一、二的现行语义。
模式三声明原生分辨率时序重建。
主宿主与辅助视图装配相同资源对象。
历史按视图的实际提交推进。

时序对象拥有运动附件及双份 HDR、深度历史。
运动附件为 RGBA32F，记录位移、前帧深度与有效性。
独立 R32F 附件记录颜色描边的表面深度。
运动绘制只读当前硬件深度，保持场景颜色。
渲染图声明只读深度附件及历史读写依赖。

只读子通道通过加载与存储保持深度值。
附件存储按深度写访问同步。
图中的数值读取语义与底层存储访问分别声明。
GPU 检查逐像素核对深度及遮挡覆盖。

历史跨交换链图像连续使用。
描述符按源图像、历史索引和帧槽冻结。
重建与销毁遵守现有围栏退役机制。
尺寸、格式、字节数和回退原因进入采集清单。

## 前帧对象数据

角色渲染器按稳定节点、资源和实例身份匹配前帧。
可见性过滤及当前缓冲行号独立于对象身份。
前帧仅保存模型、关节、形变权重和必要几何参数。
蒙皮顶点、材质纹理和完整资产保持既有所有权。

前帧数据使用独立缓冲，按帧围栏更新。
对象记录、关节及权重使用版本化紧凑布局。
上传前检查偏移、数量、有限值和设备范围。
缺失、替换及新出现对象标记为历史无效。

运动通道使用专用精简描述符布局。
当前姿态复用现有实例、蒙皮与形变资源。
前帧位置在 GPU 按前帧关节和权重重建。
基础顶点、材质与实例表继续使用现行布局。

颜色与运动消费同一冻结实例和覆盖规则。
检查 Alpha、节点透明度、镜像、Gizmo 及视向位移。
透明交叠显式降低历史可信度。
顶点与计算蒙皮均需通过独立图像对照。

## 抖动与重建

每视图使用独立的八相位采样序号。
采样抖动仅进入实际栅格投影。
裁剪、阴影及运动的相机计算使用未抖动投影。
场景投影偏移与采样抖动分别记录。

时序合成位于曝光和调色前。
输入包含 HDR、深度、运动、有效性及透明响应。
重投影后检查屏幕边界、遮挡显露与邻域统计。
历史状态 Alpha 与 RGB 合成权重分别定义。

首帧和历史失效使用当前颜色初始化。
同源相机切换采用显式切镜代次。
能力或预算不足时使用可观察的空间过滤回退。
模式三的晋升依赖公共及正式场景的联合质量门禁。

## 实施顺序

- [ ] 冻结刚体、相机、蒙皮及形变的运动失败用例。
- [x] 接入稳定身份、前帧数据和范围检查。
- [x] 接入只读深度附件及独立运动绘制。
- [x] 核对双描述符、双蒙皮、覆盖和主辅视图。
- [x] 接入视图历史、实际抖动和 HDR 时序合成。
- [x] 接入配置版本、诊断、回退和资源预算。
- [ ] 验证连续运动、首帧、切镜、取消及重建。
- [ ] 完成 KK、细发丝和服饰的时序区域对照。
- [ ] 按 NR8-V2、NR12 完成正式入口晋升。

每项均先保存失败证据，再实施和复测。
公共输入覆盖两个资产、两个视图及两种宿主。
验证同时记录程序指纹、实际设置和卸载归零。
源身份与事件号保留在离线工具和项目数据中。

## 质量门禁

独立参考采用横纵各四倍尺寸的线性下采样。
静态及八相位边缘误差比上限为 `0.8`。
细线积分亮度误差上限为 `2%`。
平坦区域保持一个输出字节以内。

连续序列固定曝光，分别驱动相机与角色。
主带、次带、发丝和服饰区域独立统计。
运动差分、拖影、收敛及峰值保持使用冻结红测。
GPU 耗时、历史附件字节和带宽按 AA5 单独计量。
