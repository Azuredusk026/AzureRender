# 性能采样供电预检

## 目标与归属

共享设备观察器持有供电记录及资格判断。
接口位于 `tools/gpu_environment.py`。
可玩性能与持续运行使用同一观察契约。
功能图像比较继续使用各自的验证入口。

## 契约

Windows 通过系统电源状态查询交流电源。
观察保存来源、交流状态、电池标记及电量。
查询失败及未知状态产生明确诊断。
当前实时采样要求明确的交流供电状态。
历史证据按原有字段表达其已观察范围。

开始等待温度窗口前检查供电。
电池或未知状态立即保存观察并终止采样准备。
运行中供电变化由周期观察进入失败原因。
原温度、负载及正式性能门槛保持有效。
