# 长跑工具有界清理计划

目标是让失败的验收工具按期限退出并保存观察。
所属层为 Python 验收工具，宿主运行契约保持有效。
标准与平台长跑共用同一清理入口。
规格依据为 [P8 关闭诊断](../acceptance/p8/2026-10-12.md)。

## 实施范围

`tools/long_run_cleanup.py` 拥有失败清理与结果记录。
`tools/run_playable_long_run.py` 调用该公共入口。
`tools/test_long_run_cleanup.py` 使用独立窗口进程。
原生窗口关闭通过异步消息请求。

清理先保存观察，再请求关闭并限时等待。
关闭超时后仅终止工具创建的子进程。
强制终止和清理错误写入独立结果。
正常关闭与资源释放仍按原门禁判断。

## 执行步骤

- [x] 使用无消息泵的窗口复现清理期限问题。
- [x] 覆盖正常关闭、已退出与无窗口子进程。
- [x] 覆盖关闭请求失败及场景清理错误。
- [x] 实现公共清理，接入标准与平台入口。
- [x] 执行受影响工具检查并同步阶段记录。

## 验证预算

故障夹具使用短时独立进程，外层等待有期限。
此阶段只执行清理、遥测和交付规则检查。
宿主音频关闭根因保持独立待项。
正式性能与长跑按总计划的触发条件执行。
