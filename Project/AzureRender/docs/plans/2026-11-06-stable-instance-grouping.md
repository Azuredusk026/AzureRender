# 场景实例稳定分组

## 交付与契约

源码基线为 `389ab83`。
实例准备的[阶段观察](../acceptance/nr/instance-preparation-cost.md)记录分组范围约 2.20 毫秒。
本单元交付按网格键稳定排列的源节点索引。
网格顺序与组内源节点顺序共同决定输出。

所属层为场景输入及 RenderCore。
输入为当前帧的网格键及有效网格数。
范围外网格键对应未参与绘制的节点。
空输入与零网格产生空结果。

分组使用计数、前缀和及稳定散布。
结果按值拥有索引，准备过程局部持有临时空间。
配置、角色、关卡及 GPU 生命周期保持所属模块契约。
同机制验证多资源场景与独立合成规模夹具。

## 验证与预算

先记录缺少接口时的编译失败。
正确性以逐资源扫描的独立判定结果核对。
覆盖交错资源、缺失资源、不可见节点及动态重排。
规模夹具记录两算法成本，整帧收益由原生结果判断。

短检覆盖受影响实例、阴影、透明、运动及静态变形。
原生四帧继续按冻结参考逐字节核对。
场景与资源输入保持原字节，五百三十五份程序保持一致。
CPU 八毫秒、GPU 十六点六毫秒及环境条件保持原门槛。

修改与短检预算二十分钟，探索预算三十分钟。
两配置构建分别九百秒，原生四帧九百秒。
短时计时单命令三百秒，设备预检按既有预算执行。
失败按实际范围归档，下一候选需独立假设。
