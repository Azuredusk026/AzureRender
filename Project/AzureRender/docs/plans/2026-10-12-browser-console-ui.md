# 资源浏览器与日志面板迁移计划

本阶段统一资源浏览器与日志面板的常用交互。
实施复用 ImGui、当前面板注册与编辑服务。
用户已授权按自主模式连续执行本阶段。
阶段标识为 UI5，任务由当前会话顺序实施。

设计依据为[UI 架构](../architecture-ui-productization.md)。
业务调用继续经过 `EditorSession` 和内容操作服务。
文件事务、文档保护、资源预览与撤销使用现有契约。
公共控件采用即时绘制，展示状态由面板拥有。

## 文件与职责

| 文件 | 职责 |
| --- | --- |
| `src/editor/ui/Widgets.hpp`、`AppChrome.cpp` | 搜索框、语义状态、空状态与自适应工具栏 |
| `src/editor/panels/AssetBrowserPanel.cpp` | 搜索、类型、导航、列表与资源状态呈现 |
| `src/editor/console/ConsoleLogModel.*` | 日志级别、暂停读取与可见日志复制 |
| `src/editor/panels/ConsolePanel.cpp` | 任务、错误、日志列表和滚动反馈 |
| `src/editor/ImGuiEditorLayer.hpp` | 面板展示状态与日志模型所有权 |
| `src/editor/EditorWorkspaceUI.cpp` | 只读面板状态与控件观察 |
| `tests/ConsoleLogModelTests.cpp` | 级别、暂停、筛选与复制的真实行为 |
| `tools/test_editor_panel_design.py` | 两类项目的生产控件输入与捕获 |

日志模型只读取诊断服务提供的消息快照。
诊断级别依据消息头解析，普通输出作为信息级。
复制内容使用与列表相同的筛选条件。
该模型也可读取离线诊断文件中的格式化行。

## 风险与检查

窄面板的控件按可用宽度换行，资源区域独立滚动。
长路径通过提示查看，列表保留稳定资产身份。
资源无匹配时提供筛选清理入口。
只读、播放与构建状态继续保护内容写入。

日志暂停固定当前快照，恢复后读取最新消息。
级别筛选依据诊断头，正文中的 error 保持原级别。
空日志、长行与错误提示使用公共控件呈现。
任务反馈和开发工具继续在日志面板中可用。

检查覆盖探索工程与场景检查工程。
输入回放验证实际控件、服务结果与保存状态。
视觉证据来自引擎自身捕获，实体操作单独记录。
现有大目录、性能和人工待项沿用交付页的状态。
