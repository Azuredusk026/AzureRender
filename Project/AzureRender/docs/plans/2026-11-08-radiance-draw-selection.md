# 照明资格的绘制范围

状态：机制检查通过，原生精度待验收。
实验入口默认关闭。

## 问题与目标

独立深度重放的原生退役槽仍为完整路径。
当前任一失配会使全部普通绘制使用完整着色。
本单元将片元资格记录到对应间接命令。
全局深度异常继续要求全部完整着色。

## 数据与所有权

公共选择器支持有界步长的谓词范围。
缓冲首字为全局回退，逐绘制字记录局部结果。
许可与拒绝掩码均显式传入，默认完整回退。
所有输入按现有栅栏及帧槽约束回收。

照明缓存为每槽分配至多 65536 项绘制标志。
六字头部保存全局状态、数量及两类统计。
正常见证点间隔为三十二像素，失配逐片元检查。
顶点阶段传递命令编号，验证阶段写入局部结果。
完成阶段归并统计，再由主机回收。

## 实现与检查

1. 为范围越界、缺失许可及混合命令补充用例。
2. 实现选择器范围与缓存标志的预算契约。
3. 接入实际绘制编号及对应命令选择。
4. 集中检查两设备的混合图案、同步和释放。
5. 机制通过后安排一次原生四帧及激活核对。
6. 显著收益候选才进入一次短时成对计时。

独立绘制序列与原生项目共同覆盖机制。
正常临时产物写入 D 盘任务目录，保留一天。
单任务预算为 2 GiB，精简证据至多 8 MiB。

## 验收边界

原生严格四帧须保持 RGB 零差异。
CPU 八毫秒及 GPU 16.6 毫秒标准有效。
整体画质、正式采样及人工验收继续待通过。

## 结果与接续

原生退役槽已经实际启用轻量绘制。
一次采集的第四帧记录十四个单色阶差异。
布局与阶段掩码修正分别通过所属检查。
严格四帧继续待验收，帧收益计时未启动。

后续候选先处理消费端精度与四像素组边界。
实现及相关检查完成后，再组织一次兼容评估。
