# 同帧表面照明复用

## 成本与范围

生产来源为 `521e002`。
当前 GPU 短时均值约为 21.82 毫秒，P95 约为 22.30 毫秒。
完整联合场景的当前程序记录用于定位。
720p 中受检普通材质绘制的完整计算约为 2.469 毫秒。
成本剥离控制约为 0.343 毫秒，属于输出不同的收益上限实验。
该控制按实际管线专用常量识别普通材质。

候选保留反射重组所需的完整单精度照明结果。
三个浮点附件与一个整数身份附件合计每像素 64 字节。
身份包括原始深度位、实例、索引三角形及材质。
同帧同视图的生产者与消费者使用相同身份契约。
完整反射重组、辐射缩放、选中状态及显示遮罩继续生效。
缺少能力、身份不匹配及不适用材质按完整路径计算。

按相同视野的片元规模推算，1080p 可消除的普通材质成本上限约为 4.78 毫秒。
缓存读写与额外附件按约 1.5 毫秒估计，预期净收益约为 3.28 毫秒。
以上为进入候选开发的推断，实际带宽、覆盖及整帧结果单独验证。
原图像及正式性能门槛保持有效。
