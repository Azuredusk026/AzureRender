# 参考深度生产

状态：公共不透明生产通过，原生覆盖及壳层待验。
依据为[原生画质计划](2026-11-09-native-quality.md)。
本单元属于 RenderCore 的几何深度生产机制。

## 输入与所有权

调用方提供相机相对位置及三角形索引缓冲。
位置采用连续四维浮点布局，索引采用三十二位整数。
投影使用已验证的 `ReferenceClipProjectionProfile`。
输入缓冲与对应命令的生命周期由调用方持有。

`ReferenceDepthGpu` 持有各帧槽的输出和管线。
输出包含可采样的 R32 浮点颜色及 D32 深度。
调用方等待槽消费者结束后复用该槽。
销毁前等待已提交的 GPU 工作完成。

## 范围与预算

每种深度约定有明确的比较操作和清除值。
纵轴映射作为投影记录的独立配置。
资源预算上限为二百五十六 MiB。
原生输入与独立正交重叠三角形验证两种用途。

定位预算为十分钟，候选检查为二十分钟。
单个问题探索预算为三十分钟。
双配置构建各预留九百秒，设备检查预留四分钟。
原生来源采集预留四分钟，任务产物预留一百二十八 MiB。
默认四帧的实际宿主回归预留六百秒。
