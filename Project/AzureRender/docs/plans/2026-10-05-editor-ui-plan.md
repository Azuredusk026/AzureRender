## 界面目标与参考

工作区以场景制作、运行调试和构建游戏为主要任务。UE 的菜单、工具栏、视口、Outliner、Details 与内容浏览器作为组织参考。项目使用 Dear ImGui 实现自己的布局与视觉资源。

参考来源为 [UE 5.8 编辑器界面](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-editor-interface)。调研日期为 2026-10-05。参考范围为界面信息架构与交互层级。项目图标使用自制矢量资源，字体许可随安装清单登记。

## 工作区布局

| 区域 | 主要内容 | 布局规则 |
| --- | --- | --- |
| 顶部菜单 | 文件、编辑、视图、工具、帮助 | 24 逻辑像素高度，快捷键与启用状态一致 |
| 主工具栏 | 保存、导入、变换模式、Play、Pause、Step、Stop、构建 | 40 逻辑像素高度，运行控件独立分组 |
| 中央视口 | 场景、视图模式、变换坐标系、碰撞调试 | 占用主要空间，输入仅在有效图像区域捕获 |
| 左侧面板 | 创建对象、项目与资源目录 | 默认宽 220，可收起并由菜单恢复 |
| 右侧上部 | 场景 Outliner、搜索、选择与定位 | 默认宽 320，与 Details 垂直分区 |
| 右侧下部 | Details、组件、渲染与运行状态 | 按组件折叠，字段对齐并显示单位 |
| 底部内容区 | Content Browser、Console | 默认高 220，以标签页切换 |
| 工具标签 | Animation Preview、Gameplay Debug、Build Game、Capture | 明确登记停靠目标，按需显示 |
| 状态栏 | 项目、关卡、未保存状态、导入或构建进度 | 24 逻辑像素高度，错误有定位入口 |

默认工作区面向 1920×1080，所有尺寸按 DPI 缩放。1280×720 下允许收起左侧和底部。中间视口至少保留 480×270。更小窗口进入紧凑布局，工具栏允许分组菜单。

窗口菜单提供显示面板和恢复默认布局。关闭、拖动与重开保留面板状态。布局文件置于用户配置目录，记录布局版本。损坏文件使用默认布局并记录诊断。

## 样式与可读性

| 样式项 | 计划值 |
| --- | --- |
| 工作区背景 | `#15171B` |
| 面板背景与输入背景 | `#202329`、`#14161A` |
| 边框与强调色 | `#343941`、`#4DA3FF` |
| 正文与辅助文字 | `#E6E9EF`、`#A8B0BC` |
| 字体 | 正文 14、标题 16 逻辑像素，使用可分发字体 |
| 间距 | 4 像素基础网格，控件间距 8，面板内边距 8 |
| 圆角 | 面板 3、控件 3 逻辑像素 |
| 状态反馈 | 文字、图标与颜色共同表达错误、警告和禁用 |

普通文字对比度至少为 4.5:1。快捷键、单位、错误与禁用原因使用明确文字。界面按钮保留现有英文操作术语，教程使用对应中文解释。项目名与资源名支持中文 UTF-8 显示和输入。

## 文件与拟定接口

| 操作 | 路径 | 职责 |
| --- | --- | --- |
| 新增 | `src/editor/EditorTheme.*` | 颜色、字体、间距与 DPI 缩放 |
| 新增 | `src/editor/EditorWorkspace.*` | 默认停靠、持久化、面板状态与布局恢复 |
| 新增 | `src/editor/EditorToolbar.*` | 菜单、工具栏、状态栏与命令状态 |
| 修改 | `src/editor/ImGuiEditorLayer.*` | 面板绘制、工作区集成与视口输入 |
| 修改 | `src/editor/EditorContext.*`、`src/editor/EditorSession.*` | 查询、过滤、生产命令与事务 |
| 修改 | `src/editor/EditorAutomation.*` | 工作区自动化与结果观测 |
| 修改 | `src/app/AzureRenderFrame.cpp`、`src/app/AzureRenderApp.cpp` | DPI、图像尺寸、鼠标坐标与布局生命周期 |
| 新增 | `tests/EditorWorkspaceTests.cpp`、`tools/test_editor_workspace.py` | 布局规则、真实点击与 UI 捕获 |
| 新增 | `docs/tutorials/editor-first-game.md` | 从空项目到独立游戏的教程 |
| 修改 | `docs/runtime/editor-game-ui.md`、`docs/assets-and-editor.md` | 界面行为与使用入口 |
| 修改 | `CMakeLists.txt`、`mkdocs.yml`、`THIRD_PARTY_NOTICES.md` | 编译、安装、导航与资源许可 |

拟定主题入口为 `EditorTheme::apply(float dpiScale) -> void`。工作区提供 `reset() -> void` 与 `snapshot() const -> EditorWorkspaceSnapshot`。快照记录稳定面板标识、矩形、显示状态与布局版本。单次 DPI 更新从基础样式计算，避免累计缩放。

字体图集变化后重建纹理，在 GPU 完成后释放旧资源。中文字体的来源、覆盖范围和许可证随包登记。停靠和字体更新均进入窗口恢复回归。

工具栏调用 `EditorSession::execute(EditorCommand)`。操作启用条件与快捷键共用命令状态。UI 元素使用稳定标识，显示名称与停靠配置独立。已有扩展面板通过注册表加入工作区。

- [ ] 实现主题、工作区和工具栏，默认布局包含九个现有面板。
- [ ] 校验视口图像区域、拾取、Gizmo、相机和运行输入的坐标。
- [ ] 在 100%、150%、200% DPI 与两种分辨率捕获并人工核验。

鼠标命中与图像位置的偏差至多为两个物理像素。停靠缩放后截图与输入使用同一矩形。文本框内的 WASD、Delete、Ctrl+D 和 Shift 属于文本操作。视口失焦与 Esc 释放运行输入。

## 任务二：核心面板交互

- [ ] 为 Outliner 实现搜索、类型标识、选中定位和明确的空状态。
- [ ] 为 Details 实现组件分组、字段单位、重置与无效输入反馈。
- [ ] 为 Content Browser 实现目录、搜索、类型筛选、列表或网格和导入进度。
- [ ] 为 Console 实现等级筛选、搜索、复制与节点定位。
- [ ] 整理动画、调试、构建与捕获面板，保持生产命令和撤销链路。

搜索命中后仍按稳定对象身份执行操作。运行或构建期间，编辑操作按已有事务规则禁用。禁用控件显示原因。生成错误保留当前场景与操作历史。

## 任务三：教程与端到端验收

- [ ] 编写环境、界面地图、项目创建与公开资产导入教程。
- [ ] 按教程完成放置、属性、动画、角色、相机、碰撞和交互配置。
- [ ] 验证撤销、保存重开、Play/Stop、脚本错误恢复与构建游戏。
- [ ] 自动化真实鼠标和键盘操作，记录关键 UI 行为与截图。
- [ ] 完成两配置回归、UI 性能、文档、安装与 U2 阶段提交。

教程每步包含入口、动作、截图和可观察结果。中文对象名进入保存重开验收。另覆盖空场景、长路径、选中对象删除与无效资源。实际完成时间、误操作恢复和阻断问题进入报告。

现有 EditorAutomation 用于验证生产命令。新增 UI 验收通过界面实际点击，检查焦点和面板可达性。报告分别记录命令结果与 UI 交互结果。两个入口共同构成验收证据。

UI 回放注入鼠标位置与按键事件，由 Dear ImGui 处理命中。控件结果与工作区快照进入报告。人工键鼠操作按教程复核，并保存公开界面截图。

## 验收与证据

新增测试拟注册为 `AzureEditor.Workspace` 与 `AzureEditor.WorkspaceGpu`。后者串行捕获 GPU 界面。证据位于 `docs/acceptance/u2/<date>.md`。精选公开截图由 P2 纳入展示清单。

专项工具为待实施入口：

```powershell
python tools/test_editor_workspace.py --executable build/ninja-msvc-release/AzureRender.exe --output build/u2/workspace
```

布局快照确认关键区域可见、无阻断重叠。默认、恢复布局与重开均满足操作链路。截图人工检查文字裁切、控件密度和任务层级。UI 性能沿用总计划的编辑器负载与 10 ms 门禁。
