# 照明缓存精度接入

本单元入口为 `9a11cf5`。
范围为同帧照明缓存与当前运行时的接入。
消费者采用已验证的共享组合精度边界。
原零像素、设备及完整帧预算保持有效。

## 机制与范围

机制归属于 RenderCore 的有界图像资源。
窗口与独立视图共用材质选择及资源生命周期。
输入身份包含深度位、实例、原始索引三角形及材质。
消费者按四像素组选择复用或完整着色。

缓存采用三个单精度附件及一个整数身份附件。
资源总上限为 512 MiB，帧槽独立拥有资源。
设备、格式、描述符、模式及规模共同决定资格。
失败或缺失能力时采用完整着色。

片元原始图元身份及完整四像素组能力显式查询。
四像素组控制与最大重汇合共同启用。
默认构建关闭照明缓存实验选项。
原渲染程序须保持全部字节一致。

## 开发与验收

先核对现行实现与旧候选的所有差异。
资源、身份、非法输入及释放检查先于主机接入。
现有 GPU 透明索引与主深度复用保持现行行为。
共享组合函数用于反射置换，原输入计算保持定义。

旧普通材质颜色范围约占历史事件耗时的 42%。
实际缓存命中、附件成本及现行剔除收益分别核定。
缓存准备状态与实际消费资格共同记录。
具体工作量与收益门槛成立后安排整场景评估。

源码与接口接入预算为四十五分钟。
所属检查集中执行，画面核对使用一组冻结四帧。
画面未过时定位后只复测受影响控制。
性能评估以实际空闲及画面资格为前提。

任务预留 128 MiB，原始资产沿用已有位置。
临时内容位于 D 卷，保留一天。
精简证据引用已保存的相同图像及源捕获。
候选通过前保持显式实验状态。

## 结果

严格四帧、设备回退及资源释放检查通过。
短时 GPU 均值增加约 0.72 毫秒，实验选项默认关闭。
最终主构建保持原 673 个程序的字节。
