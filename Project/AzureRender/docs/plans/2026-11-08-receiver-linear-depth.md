# 线性接收深度核对

本单元入口为 `4d84626`。
范围为既有捕获中的线性深度附件。
所属模块为屏幕对象可见量的输入契约。
相机、坐标基和像素相位沿用已核定来源。

读取十月二十七日捕获的实际绑定 18。
仅保存原遮罩内的 17017 个深度值。
捕获及工程数据采用共享路径引用。
新增产物预算为 4 MiB，普通保留期为一天。

双精度换算用于核对深度编码的信息量。
GPU 模型继续使用原生法线及对象图集。
一次区域评估记录逐字节结果和最大误差。
该结果用于判断线性输入能否进入公共接口实施。

区域判据沿用一字节误差门槛。
实际接口实现还须验证 GPU 计算及附件转换。
当前源码、主程序和用户改动保持原有字节。
完整外观和帧预算持续使用既有验收标准。
