# 数值拖动取消验收

生产基线为 `5fccef9`，多选夹具为 `32e56f9`。
本单元使用 Release 配置和生产界面输入回放。
目标是在鼠标持续按下时用 Esc 取消数值拖动。
探索项目与资产检视项目分别验证相同契约。

## 操作与结果

夹具选择 `multi-a` 和 `multi-b`。
两对象位置为 `[1,2,3]` 和 `[4,5,6]`。
`multi-c` 与原项目节点用于检查编辑范围。

| 用户任务 | 具体操作 | 验收结果 |
| --- | --- | --- |
| 取消数值拖动 | 按住位置 X 数值框，移动两次，按 Esc，再释放鼠标 | 原始混合值、选择、场景摘要、撤销计数和保存状态恢复 |
| 提交数值拖动 | 按住同一数值框，移动两次并释放 | 数据发生变化，形成一项可撤销操作 |
| 保留已有重做 | 撤销正常拖动，再拖动并取消，执行重做 | 重做恢复正常提交时的场景摘要 |
| 检查保存数据 | 取消后保存，读取两对象位置 | 两组原始位置分别保持，各轴混合关系保留 |
| 检查既有流程 | 单轴重置、引用拾取取消、修改引用、撤销重做、保存重开 | 两项目通过，非选中节点保存数据保持一致 |
| 保护其他编辑 | 数值修改后切换选择，再请求取消 | 事务检查拒绝过期恢复，保留当前文档和选择 |

基线批次 `2236` 在探索项目复现取消失败。
按 Esc 并释放鼠标后，X 值为 `1.500`。
场景摘要不同于拖动前，撤销计数增加一项。
失败依据保存在输入记录与截图中。

候选批次 `2237` 完成构建、CPU 检查和两项目回放。
受影响的 5 项 CPU 检查全部通过。
两项目取消后的截图均显示三轴混合值。
回放覆盖数据与历史，截图核对可见状态。

## 实现契约

属性控件逐项检测取消并释放活动控件。
属性面板通过 `history.cancel-edit` 请求恢复。
正常释放通过 `history.end-edit` 结束编辑。

`EditService` 保存首次数值变化前的检查点。
检查点包含文档、选择及两侧历史栈。
连续更新仍经 `EditTransaction` 提交并合并历史。
取消校验文档版本，恢复检查点并使临时提案过期。
该机制适用于变换轴和其他带合并标识的编辑操作。

`EditorContext` 和 `EditTransaction` 保持现有接口。
新增取消操作要求空闲编辑会话。
已结束的编辑收到取消请求时保持提交内容。
过期检查点拒绝恢复，避免覆盖其他编辑。
