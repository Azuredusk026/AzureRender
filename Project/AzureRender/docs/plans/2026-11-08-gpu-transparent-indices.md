# GPU 透明索引准备

本单元入口为 `3b4fa9d`。
范围为透明顶点变形、深度键和索引写入。
已有透明准备约占渲染器更新的 28%。
本批目标为省去对应的逐帧 CPU 顶点及排序工作。

## 公共机制

`GpuTransparentIndexSort` 属于 RenderCore。
构造时消费不可变资产及已校验透明拓扑。
位置、骨骼权重、形态差量及三角形按紧凑布局保存。
资产及拓扑变化按加载生命周期重建。

调用方逐帧提供相机、模型矩阵、姿态及骨骼缓冲。
准备阶段只更新实例参数及有限的形态权重。
GPU 依次生成世界位置、深度键、稳定顺序及索引。
变形和深度计算保持现行 CPU 的单精度次序。

相同深度保持输入三角形的顺序。
不同图元分别排序，原始顶点索引保持原值。
内部采用有界缓冲和已交付的稳定键排序器。
普通场景与独立变形排序工具共用该机制。

## 所有权与回退

所有内部资源由机制持有，并按帧槽独立准备。
调用方退役帧槽后，才能更新或释放相应内容。
录制凭据关联槽号及准备代次。
输入骨骼的发布依赖由调用方提供。

机制发布内部计算依赖。
调用方发布最终索引或其他外部读取依赖。
场景适配同时声明渲染图的骨骼读取和索引写入。
尺寸、拓扑及容量资格不足时使用既有 CPU 路径。
小任务沿用 CPU 准备，容量由构造参数明确声明。
