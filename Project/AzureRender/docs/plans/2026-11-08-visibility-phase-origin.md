# 屏幕可见量相位原点

## 目标与边界

公共 `ScreenObjectVisibilityView` 显式配置过滤相位的垂直原点。
输入纹理地址、深度重建和过滤相位分别保持各自的定义。
默认相位沿图像行号，底部原点采用 `height-1-y`。
相位配置由调用方按资源来源选择。
依据见[设备深度输入核验](../acceptance/nr/receiver-device-depth.md)。

RenderCore 持有相位枚举及 GPU 参数打包。
片段程序根据配置选择相位行号，现有资源、输出和所有权保持原契约。
非法枚举在上传及录制前拒绝。
第二种用法由非均匀图集及相反行号原点的工具夹具验证。
默认原生输入的 17017 像素结果继续按原门槛核对。
