## 目标与架构

目标是让常用制作操作符合直觉并可恢复。
覆盖导航、选中、变换、内容制作和运行调试。
技术基础为 C++、GLFW、Dear ImGui 和现有编辑服务。
全部新增能力遵守仓库的引擎级实现约束。

输入路由拥有快捷键上下文和鼠标捕获。
相机服务拥有导航与世界包围盒构图。
选择、变换和内容写入使用公共编辑操作。
文档服务拥有保存点、确认流程和任务生命周期。

计划中的接口属于实施目标。
现行能力以审查和源码为准。
本轮列出三十三项问题与检查项。
待实测项依据证据决定具体修复范围。

## 全局约束

- 具体项目、角色和关卡通过配置消费公共机制。
- 菜单、工具栏、快捷键和自动工具使用同一操作。
- 相机、选择与工具状态归编辑会话。
- 文档写入遵守版本、事务及撤销规则。
- 导航和工具切换保持场景字节与未保存状态。
- 现有视觉、设备、性能和发布预算持续有效。
- 验收覆盖探索项目和场景检视项目。
- 阶段完成后同步文档并单独提交。

## 交互约定

| 操作 | 默认行为 |
| --- | --- |
| 右键拖动 | 原地观察，右移向右看，上移向上看 |
| 右键加 WASD | 沿相机方向飞行，Q/E 垂直移动 |
| 飞行时 Shift | 临时加速，释放后恢复基准速度 |
| Alt 加左键 | 围绕当前导航中心旋转 |
| 中键拖动、滚轮 | 平移、缩放，按场景尺度适配 |
| W/E/R | 非导航状态下切换移动、旋转、缩放 |
| Q | 非导航状态下使用选择工具 |
| F | 按全部选中对象的世界边界定位 |
| 大纲单击 | 只更新选择，相机保持当前视角 |
| 大纲双击 | 显式定位，并保留大纲键盘操作能力 |
| Ctrl 加点击 | 增减选中，视口和大纲语义一致 |
| Shift 加大纲点击 | 按当前可见排序选择连续范围 |
| 视口空白点击 | 清空选择，Ctrl 状态保持既有选择 |
| Esc | 取消拖拽或释放运行输入，弹窗优先消费 |
| Ctrl+D、Delete | 场景上下文中的复制与删除 |
| Ctrl+Z、Ctrl+Y | 编辑历史，文本控件优先处理文本历史 |

大纲单击只选择，双击执行定位。
Ctrl 多选期间累计选择，F 定位整个集合。
W/E/R 与飞行按键由导航状态消除冲突。
具体快捷键可以在设置中查询与重绑。

### 保存安全与运行恢复

新增 `src/editor/documents/DocumentActionGuard.*`。
修改 `EditorContext.*`、`EditorSession.*` 和 `src/main.cpp`。
退出请求在窗口销毁前进入确认状态。
自动测试显式声明保存或放弃策略。

命令行登记 `--editor-close-policy ask|save|discard`。
交互启动默认使用 ask。
既有自动化工具按任务目的显式选择策略。
参数、安装帮助和测试入口同步维护。

`DocumentActionGuard::request(DocumentAction) -> DocumentActionState` 返回请求状态。
动作包含关闭和重新加载。
`resolve(DocumentDecision) -> DocumentActionState` 消费保存、放弃或取消。
保存失败保留文档、选择、窗口和错误详情。

状态分为 Idle、AwaitingDecision、Ready 与 Failed。
取消返回 Idle，成功保存或放弃进入 Ready。
失败保留诊断，允许重试保存或取消。

保存检查点记录规范化文档内容指纹。
Undo/Redo 返回保存点时清除未保存标记。
磁盘重载与退出均遵守同一保护服务。
可恢复备份单独命名，并校验完整内容。

Play 启动前保存编辑相机和输入状态。
Stop 恢复相机、选择与光标状态。
运行滚轮仅在获得视口输入所有权时消费。
关闭视口和失焦释放按键与鼠标捕获。
