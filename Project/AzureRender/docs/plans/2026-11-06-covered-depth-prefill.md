# 完整覆盖深度预填充

## 来源与目标

源码基线为 `e8f95f3`。
场景渲染器的快照及主通道具有既有深度预填充。
预填充关闭颜色写入，并使用原顶点路径及深度偏置。
本单元为完整覆盖的单样本实例选择纯深度管线。

所属模块为 RenderCore 的材质策略及场景录制。
资格要求不透明材质及透明度恰为一。
其他透明度保持原覆盖测试，遮罩及混合材质保持原提交规则。
四样本路径使用既有预填充规则。

主通道及快照通道分别持有三个面向变体。
纯深度变体保留顶点程序、偏置、剔除及所有颜色写掩码。
严格的 `LESS` 颜色比较继续保持共面绘制顺序。
重建及卸载按既有管线生命周期释放全部变体。

## 规范与验证

[Vulkan 管线规范](https://docs.vulkan.org/spec/latest/chapters/pipelines.html)允许省略片元阶段。
该情况下颜色输出未定义，候选的所有颜色写掩码均为零。
实际 GPU 读回同时验证深度字节及颜色附件保持。
双设备范围包括 D16、D32 及两种有色附件数量。

策略检查覆盖遮罩、混合、淡出及阴影专用标志。
实际渲染器覆盖两通道、两种描述符、重建及四样本回退。
既有阴影检查继续限定其自身管线及原断言。
原生四帧保持冻结参考的零像素差条件。

五百三十五份生产程序保持原字节。
CPU、GPU、热状态及整体用户画质保持原验收门槛。
同一候选使用一次短时成本采集，成对收益资格单独判断。
单一原因验证后接续独立任务。

定位十分钟，候选与短检二十分钟，探索三十分钟。
两配置构建分别九百秒，原生四帧九百秒。
单次原生命令三百秒，设备预检按既有预算执行。
