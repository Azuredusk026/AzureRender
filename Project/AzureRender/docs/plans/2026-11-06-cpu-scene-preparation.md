# CPU 场景准备优化

## 范围与依据

当前独立阶段剖析包含二十个稳定帧。
场景准备均值为 6.46 毫秒。
渲染器更新为 6.69 毫秒，录制为 4.21 毫秒。
该程序包含阶段计时，仅用于选择优化方向。

本批集中减少场景快照分配和摄像机无关运算。
目标为场景准备工作量至少减少 20%。
实际整帧收益单独记录，CPU P95 门槛仍为八毫秒。

## 实现契约

快照支持调用者持有的文档存储。
逐帧复用容量，完整刷新源文档和组件状态。
组件存储每次快照解析一次，并保持只读访问。
实体身份、父节点失效和灯光过滤保持有效。
返回值接口继续提供独立的完整文档。

游戏运行时在复用文档上执行相同插值运算。
Player 保留当前帧文档，供摄像机及渲染器共用。
编辑器继续持有所属视图的独立文档。

摄像机按场景次序检查实际摄像机组件。
世界矩阵只解析候选摄像机及其祖先。
可达循环采用完整解析，保持既有退化语义。
优先级、同级身份次序及错误诊断保持一致。
