## 验收与预算

R3 目标验收环境为 RTX 2060，分辨率为 1280×720。多资源场景使用 32 个独立公共网格资源，每路径采样 300 帧。固定模拟输入，四组合顺序运行，结果取三轮中位数。

GPU 可见性路径下，并行 CPU 录制较串行至少改善 5%。GPU 平均时间增长不超过 5%。同网格 256 实例的 CPU 录制平均须低于 0.5 ms，GPU 平均须低于 3 ms。

图像对照要求逐帧一致，降级路径必须实际执行。验收证据应对应当前源码版本。

本机设备为 RTX 4060 Laptop GPU，当前结果单独记录。R1 与 R2 基础采样采用 1280×720、150 帧。结构验收覆盖七视图与黑洞冻结输出。性能记录区分 CPU 提交、GPU Pass、整帧与可见比例。

新增接口先编写会失败的行为测试，再实现与验证。Debug/Release 都执行完整 CTest。发布执行 `tools/run_release_gate.cmake`。每次提交检查差异、暂存范围、文档与测试结果。
