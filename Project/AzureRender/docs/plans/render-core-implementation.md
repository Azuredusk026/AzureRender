> 更新日期：2026-09-26

## 目标与执行依据

产品范围与阶段状态见 [开发总计划](azure-engine-plan.md)。执行采用自主实施模式。各阶段依次完成测试、代码、文档与提交。

涉及 `RenderGraph.*`、`TransientResourcePool.*`、`ISceneRenderer.hpp`、三个场景与 `AzureRenderFrame.cpp`。

- [x] 验证读写依赖、重复声明、显式依赖环与确定性顺序。测试使用显式失败退出码。
- [x] 实现编译期资源状态与屏障，图像与缓冲区分别建模。
- [x] 图负责调用 Pass 录制回调。编译成功后才允许录制和提交。
- [x] 三个场景贡献 Pass。宿主登记合成、HUD、编辑器、捕获与呈现。
- [x] 导入资源保留起止状态。瞬态资源按完成帧复用，覆盖窗口尺寸变化。
- [x] 运行三场景、七视图、固定描述符、窗口恢复、性能与发布门禁。

- [x] Compute 管线、描述符与调度接口具备 NullRHI 契约测试和 Vulkan 实现。
- [ ] 实现多级 Bloom 与运行期 GPU IBL，记录有意视觉变化。
- [ ] 实现 Compute 蒙皮与 Morph，验证动画与降级路径。
- [ ] 加入 OpenEXR 解码，覆盖损坏文件与发布依赖。
- [x] 光源缓冲完成稳定排序和 GPU 打包，级联分割数学具备确定性测试。
- [ ] 保留 PCSS 半影。以可公开多光源资产验证阴影与规模性能。
- [ ] 完成 Debug/Release、两种描述符路径、视觉与发布验收。

## R3：并行录制与 GPU 提交

涉及帧快照、任务调度、命令池、间接绘制缓冲与性能诊断。

- [ ] 冻结帧快照，建立每工作线程独立命令池。

- [ ] 更新总计划、运行时说明、验收记录与 manifest，提交阶段结果。

## 验收与预算

设备使用本机 RTX 4060 Laptop GPU。基础采样为 1280×720、150 帧。结构阶段保持七视图基线与黑洞冻结输出。性能记录分别报告 CPU 提交、GPU 各 Pass、整帧、显存和可见比例。

新增接口先编写会失败的行为测试，再实现与验证。Debug/Release 都执行完整 CTest。发布执行 `tools/run_release_gate.cmake`。每次提交检查差异、暂存范围、文档与测试结果。

## 参考来源

实现以项目 RHI、GLSL、公共资产与测试为依据。Vulkan 接口遵循 Vulkan 1.3 规范。第三方算法或解码依赖接入时记录版本、许可证与适配文件。
