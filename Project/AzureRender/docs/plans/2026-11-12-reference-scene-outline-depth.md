# 参考场景外扩深度

参考场景按材质的 `outlineSurface.depthPrepass` 记录外扩几何。
描边投影使用当前视图、姿态、形变及片元覆盖。
外扩绘制写入反向 R32 和 D32，并保留法线及对象身份。

## 来源与范围

基线提交为 `b21e221`。
帧 10401 的事件 440 提供外扩深度证据。
冻结接收区域采用 49,384 个位置及一字节容差。
原生对照见[接收输入来源](../acceptance/nr/native-receiver-producer-replay.md)。
