# 有界计算归约

状态：效率门槛未通过，候选保持隔离。

## 候选范围与契约

阴影分块和反射计算分别约为 0.48 与 1.66 毫秒。
本单元集中处理其中可证明等价的重复工作。
渲染图、着色模型及采样参数保持现有契约。
GPU 帧预算与严格四帧标准持续有效。

设备抽象查询计算阶段的子组算术能力。
阴影程序仅在单子组工作组中使用子组最值归约。
多子组或显式关闭时采用共享内存归约。
能力缺失的设备加载普通程序。

反射滤波在上下层级相同时共享一次层级求值。
最终插值表达式、置信度及编码操作保持原顺序。
读入图像在所属计算通道中保持只读。
资源所有权和帧槽回收沿用现有机制。

## 执行与门槛

1. 复现设备能力查询缺失。
2. 集中实现能力选择、单子组归约及层级复用。
3. 双设备核对阴影最值、回退及反射精确输出。
4. 达到工作量门槛后执行严格原生四帧。
5. 图像通过后执行一次前后参考成本比较。

单子组归约应跳过共享内存屏障。
最高层级滤波只求值一组十六点核。
精简证据、临时对照程序及输入均位于 D 盘项目。
单任务预算 2 GiB，普通产物按天回收。

二十四项检查及四次逐位参考比较通过。
局部差值约为 0.96%，小于约 1.94% 的参考漂移。
生产源码及两种配置的普通程序摘要保持一致。
