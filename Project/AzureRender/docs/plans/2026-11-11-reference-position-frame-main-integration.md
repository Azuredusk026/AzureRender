# 参考位置帧主线集成

## 目标与范围

主线接入公开位置帧和版本二世界坐标深度。
坐标流、程序配对、资源生命周期及拒绝条件保持所属契约。
实际索引来源的诊断证据随同接入。
整体画质和正式帧预算分别验收。

## 核验步骤

1. 核对来源提交、归档、受检代码和发布注释边界。
2. 构建两配置的实际宿主及所属测试。
3. 核对主线既有 856 份程序和来源 858 份程序。
4. 每配置执行九项所属检查。
5. 两设备、两配置执行位置帧、深度及覆盖检查。
6. 位置帧检查包含 11564 个实际世界坐标来源。
7. 核对宿主全部程序节及运行依赖身份。
8. 宿主有效内容变化时重新采集严格四帧。

## 验收条件

所属检查通过，跳过项为零。
全部既有程序及来源新增程序分别保持受检摘要。
3330800 个坐标分量和 675328 个附件值逐位一致。
设备程序的拒绝、同步和资源清理检查通过。

原四帧按实际产品身份复用或重新采集。
1729 项挂载输入和十三份保护文件保持摘要。
Intel 原生深度差异保持独立记录。
