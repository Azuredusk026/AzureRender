# 材质照明接收

状态：公共机制验证完成，归属为 Q1 服饰照明。
差异依据见[全身动态对照](../acceptance/nr/full-body-native-comparison.md)。

## 目标与契约

材质通过显式策略选择环境照明来源。
场景来源消费辐照场、局部探针及屏幕空间反射。
全局环境来源消费公共环境图及明确的强度和响应。
默认策略保持场景的现行照明契约。

`mainLightShadow` 声明场景或角色对象阴影来源。
对象来源消费角色接收组主光及已有对象图集。
普通照明材质通过该声明进入对应主光接收组。
已有 NPR 材质沿用自身的可见量契约。

该能力归属为资产画像及公共渲染消费。
角色名称、材质槽及参考参数由项目数据声明。
普通表面、织物和独立资产检视共同验证复用。
场景环境资源及其照明效果保持独立所有权。

## 输入假设

完整世界与独立角色的全局环境图具有相同来源。
独立入口使用强度 0.5 及原有环境镜面响应。
完整入口使用强度 0.25、场景辐照及局部探针。
先通过数据控制核对这些差异的合成结果。

独立入口的级联阴影由角色主光持有。
完整世界的级联阴影由场景表面主光持有。
服饰二、五的剩余差异通过关闭独立级联阴影定位。
完整角色继续使用真实阴影，关闭控制仅用于诊断。

## 文件与配置

`AssetMaterial` 持有有类型的环境选择及主光阴影来源。
`GltfLoader.cpp` 校验版本、字段及响应组合。
完整材质文档及图保存相同的表面语义。
对应 JSON Schema 与加载契约同步。

`PackedMaterialSurfaceProfile` 复用第二十一行的预留分量。
画像布局递增为二十，大小保持 352 字节。
第二十一行依次保存显示、环境位、强度及阴影来源。
缺省输入保持现有零标志及场景接收行为。

`environmentLighting` 子对象版本为一。
`diffuse` 与 `reflection` 选择 `scene` 或 `global-environment`。
可选的 `globalIntensity` 为零至十六的有限值。
省略强度时继承视图的全局环境强度。

`mainLightShadow` 默认值为 `scene`。
`object-shadow` 适用于普通照明的通用、织物及金属。
它与无光照、覆盖及专用 NPR 可见量互斥。
缺失或关闭对象图集时，可见量按既有契约返回一。

主片元在环境合成及主光采样处消费显式来源。
主辅视图沿用相同画像、光源及对象图集契约。
场景资源、其他材质及阴影生命周期保持所属所有权。

本项候选须保持独立角色的既有有效区域外观。
完整世界的环境表面继续通过严格兼容检查。
透明背景混合与不透明材质内部具有分别声明的范围。
正式原生参考、运动稳定性及整体验收保持原状态。
