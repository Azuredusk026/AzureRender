# 反射探针空间候选

## 目标与架构

状态：候选兼容通过，整体收益未成立。
候选源码及程序隔离保留，生产使用受检完整遍历。

本批减少探针体积的逐片元遍历。
所属模块为 RenderCore、场景渲染器及着色程序。
基线为 `725dfdd`，现有图像和性能门槛保持有效。
执行采用当前会话的自主实施授权。

场景加载时构造场坐标内的保守网格。
单元以三十二位掩码记录候选探针。
片元按原探针次序处理候选，保持原混合算术。
网格参数附加于所属探针存储缓冲，随原资源退役。

## 依据与预期

现有探针及辐照事件属于主要 GPU 成本。
当前联合场包含十二个局部反射探针。
主颜色与快照均重复执行相同的体积检查。
既有最终颜色复用原型的收益未成立。

使用三十二乘十六乘三十二个单元进行预估。
单元外扩一格后，平均候选为 1.93 个。
体积检查的预期减少量约为 84%。
该预估按均匀场单元统计，整帧收益仍需测量。

方法参考 [NVIDIA 着色建议](https://developer.nvidia.com/blog/advanced-api-performance-shaders/)。
采用保守候选与紧凑数据组织，具体实现由本项目持有。
本批保持材质、反射采样、照明及浮点精度。
最终标准仍为 CPU P95 八毫秒及 GPU 16.6 毫秒。

## 接口与边界

新增 `ReflectionProbeSpatialGrid.hpp`。
网格从有效的 `ReflectionProbeField` 创建独立快照。
默认尺寸为 `{32,16,32}`，每维至多六十四。
单个网格至多包含六万五千五百三十六个单元。

网格原点和步长采用可表示的浮点参数。
体积范围通过实际逆矩阵及保守误差界构造。
单元外扩一格，覆盖索引边界的舍入误差。
数值无法建立安全网格时使用完整探针集合。

GPU 行保留原参数前缀及序列。
头部通过版本与偏移标记索引来源。
掩码以两个精确的十六位数值存储。
存储预算不足、网格外或非有限查询采用完整集合。
