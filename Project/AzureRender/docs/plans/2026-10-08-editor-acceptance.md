## 执行顺序

U7 的独立提交作为验收基础。
Debug 与 Release 分别完成全套 CPU 和 GPU 回归。
GPU 检查串行执行，并保存实际构建来源。
发现失败时保留证据，修复后复测相关门禁。

1. 汇集两个项目的十二项使用任务。
2. 运行原生 Windows 消息至 GLFW 的输入验证。
3. 验证系统路径选择器的选择与取消。
4. 核对尺寸、DPI、视觉及像素命中矩阵。
5. 执行 Intel 支持设备的完整任务与释放。
6. 冻结源码，完成三种负载各三轮性能采样。
7. 安装并移动引擎及双项目发布包。
8. 核对教程、来源、许可和清单。
9. 记录实体键鼠复核及未覆盖范围。
10. 同步三十三项问题与阶段状态。

## 编辑服务性能复核

公共编辑服务负责本轮 CPU 性能修复。
操作前快照用于基础版本和差异基线。
操作后快照用于只读检查、结果版本和差异。
快照复用限于单次操作的同步调用范围。

外部请求仍校验文档身份、修订和内容指纹。
前端当前操作在分派时捕获基础版本。
只读处理器异常写入触发拒绝和恢复。
批量操作、撤销和连续编辑保持事务契约。
