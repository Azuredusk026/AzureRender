# 参考相机渲染主线接入

## 接入范围

来源包括剔除余量传递、混合视锥和参考相机实际消费。
依赖顺序为 `e931a86`、`80199cf` 及 `1a7da41`。
主线保留默认材质构建、程序身份及用户工作文件。
参考相机程序装配采用参考材质族。

## 验证范围

两配置构建独立 Player、Editor 及受影响目标。
核对目录身份、组件选择、拾取和模块依赖。
两设备检查现行及旧版间接剔除模块的兼容性。
混合视锥使用实际原生世界顶点复验。

独立项目采集普通、参考透视和参考正交视图。
几何掩码按公开项目及独立边界逐像素核对。
同设备不同配置核对 PNG 摘要。
冻结原始项目重新采集四帧，核对摘要和 RGB。

## 证据与预算

正式来源归档验证摘要后提取指定夹具。
编译与设备采集使用共享队列。
完整程序目录验证按实际二进制用量预约。
成功报告包含逐份摘要及作用域。
