# 动画曲线校验与运行时采样

## 依据与目标

运行源码基线为 `0f62cb3`。
同输入控制记录每帧十一次实际动画采样。
局部初始化配置的采样合计均值为 2.55 毫秒。
当前曲线入口每次采样都遍历全部时间及输出值。

本单元先在冻结场景中测量一次校验及只读采样。
私有控制使用相同曲线、片段、时间及循环参数。
构建前校验的资源数据由控制器持有独立只读副本。
两个算法交替运行，完整姿态原字必须一致。

## 实施边界

生产方案由实验结果决定。
可变曲线的公共入口继续完整校验输入。
预备曲线在构建时校验，并持有不可变输入。
运行时检查本次采样时间和所属绑定。

曲线数据及绑定归属于加载资源。
实例的采样时间、循环及混合参数分别持有。
加载、重载与卸载按所属资源周期更新预备数据。
图形缓冲及着色程序采用现行布局。

## 参考与验证

借鉴 [ozz-animation 构建过程](https://github.com/guillaumeblanc/ozz-animation/blob/744eb9d99f606eda849acb0b1204f7a3dc20bca1/src/animation/offline/animation_builder.cc)的输入校验分层。
运行时边界参考[采样作业](https://github.com/guillaumeblanc/ozz-animation/blob/744eb9d99f606eda849acb0b1204f7a3dc20bca1/src/animation/runtime/sampling_job.cc)。
来源提交为 `744eb9d99f606eda849acb0b1204f7a3dc20bca1`，许可为 MIT。
运行时插值计算沿用本项目的曲线实现。

私有实验使用单个冻结场景及已加载曲线。
正式实现验证可变输入、非法数据及资源重载。
两种描述符路径、角色、物流及工具夹具共同核验。
原生图像、帧预算和现有设备失败保持原标准。

定位十分钟，候选及短检二十分钟。
私有构建每次三百秒，原生控制三百秒。
正式构建每配置九百秒，原生四帧九百秒。
探索预算三十分钟，达到预算时登记结论及接续任务。

## 实施结果

预备曲线和资源片段快照进入生产接口。
两配置各三十六项 CPU 及十二项 GPU 检查通过。
原生四帧与冻结参考 RGB 逐像素一致。
同输入采样局部均值为 2.685 与 0.431 毫秒。

完整帧收益、热状态及用户画质继续单独验收。
来源与范围见[验证记录](../acceptance/nr/animation-curve-validation.md)。
