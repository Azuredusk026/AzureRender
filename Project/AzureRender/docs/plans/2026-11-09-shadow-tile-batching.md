# 阴影分块批处理

状态：批处理已接入默认配置，正式帧预算待通过。

## 依据与范围

实际阴影分块通道约为 0.48 毫秒。
单子组归约的独立差值小于参考漂移。
本轮按工作组规模和实际线程利用率优化调度。
计算输入、缓冲布局及每个分块的归约顺序保持一致。

一个候选工作组使用 128 个线程处理八个分块。
每个分块仍由十六个线程完成原有归约树。
尾部分块按图像范围判断，所有线程共同经过屏障。
共享内存按分块划分，输出各自写入所属索引。

资源由原 `ShadowTileBounds` 帧槽持有。
调用方声明与着色程序匹配的分块批量。
对象记录的后缀、偏移及生命周期保持原契约。
默认入口使用八分块，显式关闭时使用单分块。

## 执行门槛

1. 复现批量声明、尾部调度及非法输入接口缺失。
2. 集中实现工作组映射、宿主调度及元数据。
3. 双设备核对精确最值、尾部范围和对象记录。
4. 独立 GPU 归约减少至少 20% 后进入原生四帧。
5. 严格四帧通过后执行一次前后参考成本比较。

局部参考漂移界限为 5%。
CPU 八毫秒、GPU 16.6 毫秒及 RGB 零差异标准有效。
原生长采样及整体画质按原验收条件通过。
全部临时产物、输入及证据位于 D 盘项目。

## 执行结果

二十八项检查及原生严格四帧通过。
独立内核均值减少约 43.24%，整帧均值减少约 0.53%。
首轮预热校准与有效比较分别登记。
