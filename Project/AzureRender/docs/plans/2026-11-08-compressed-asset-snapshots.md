# 资产快照压缩

本单元入口为 `ae7bc80`。
范围为运行时资产数据库的源文件快照。
资产刷新及旧快照读取保持现有语义。
源资产、项目挂载及正式证据继续由各自所有者维护。

压缩编解码属于运行时独立机制。
输入为源字节及资产指纹，输出为版本化缓存。
读取时核对指纹、长度及源内容摘要。
坏缓存按现行原子发布流程从匹配源资产重建。

小于 64 KiB 的输入使用编码 1。
64 KiB 至 256 MiB 使用编码 2。
编码 2 记录原始长度、载荷长度和存储方法。
无损压缩节省至少八分之一时保存压缩载荷。

压缩使用本机既有的 Zstandard 1.5.7。
压缩级别为一，压缩帧携带校验和。
解码输出及窗口的上限均为 256 MiB。
大于该范围的输入继续使用编码 1。

编码 2 的原始载荷记录本次压缩决策。
合法暖缓存经过内容核对后直接复用。
范围内的编码 1 大快照在资产刷新时进入编码 2。
具有多个硬链接名称的旧快照保持共享存储。
每次发布核对源内容，已有有效快照语义保持一致。

验证覆盖小文件、可压缩和不可压缩输入。
还覆盖坏长度、截断、错误指纹、旧快照及并发发布。
真实模型语料按共享路径读取，记录压缩比例和局部成本。
素材检视及资产打包共同验证该公共机制。

新增产物预算为 128 MiB，普通保留期为一天。
临时数据、编译缓存和证据均存放在 D 盘。
本单元只运行资产和运行时的受影响检查。
整体外观、CPU 八毫秒及 GPU 16.6 毫秒标准持续有效。
