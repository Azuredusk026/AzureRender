# 投影反射公共组合实施计划

执行方式：当前会话自主实施。
目标：组合公共表面准备、投影射线和足迹过滤。
前置提交为 `1addfb3`，归属 NR5-R8-R6。
依据见[反射接入计划](2026-10-28-reflection-filter-integration.md)。

## 模块与接口

`ProjectedScreenReflectionGpu` 归属 RenderCore。
对象拥有准备、射线、深度、信号金字塔及过滤资源。
输入借用全尺寸表面、HDR 颜色及可选线性 UV 运动。
输出为可供片元存储读取的 RGBA32F 图像。

`ProjectedScreenReflectionParameters` 提供具名设置。
步数范围为一至 4096，默认 96。
边缘宽度范围为 `(0,1]`，默认 0.08。
粗糙度和强度沿用表面准备的范围及默认值。

种子范围为零至 16777215，默认零。
足迹归一化层级由实际信号金字塔层数确定。
组合内部使用 Vulkan 上方像素原点及线性 UV 运动。
参数在任何描述符和命令变化前校验。

`ProjectedScreenReflectionInputs` 提供表面、颜色和运动。
源尺寸在构造及记录时核对。
运动为空时使用对象持有的一像素零位移纹理。
公共射线允许归一化 UV 采样的恒定运动场。

`ProjectedScreenReflectionHistory` 提供前帧槽位、颜色及视图。
前帧槽位须与当前槽位不同，且已有成功提交。
历史模式要求调用者提供当前减前帧的运动。
成功提交、切镜及取消后的历史身份由调用者维护。

当前帧模式使用当前颜色及深度。
历史模式使用借用的前帧颜色和所属槽位的深度。
相机适配分别使用当前和前帧的实际采样投影。
两种模式均生成压缩信号，再通过足迹选择过滤层级。

深度金字塔消费准备后的反向深度，并按最大值规约。
过滤按相机倒数系数恢复正向深度。
相机使用有限远平面，背景深度通过准备步骤归零。

## 资源与生命周期

图像总预算上限为 512 MiB。
表面准备同时遵守其 256 MiB 及瓦片数量上限。
预算包括深度、信号、准备、过滤和恒定运动图像。
瓦片及参数缓冲分别记录实际大小。

调用者发布借用输入的采样可见性。
组合负责中间图像的写入、采样及输出屏障。
调用者退休包括历史在内的全部槽位消费者。
取消录制后可直接重录，同提交内允许独立槽位。

公开 `output`、`prepared` 和 `signal` 供消费与观察。
独立镜面及主场景装配分别使用公共组合。
所需格式在资源分配前查询。
程序缺失、设备不支持及预算越界都有明确诊断。
