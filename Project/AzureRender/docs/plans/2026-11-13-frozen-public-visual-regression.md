# 公开角色冻结画面复验

公开角色的七张冻结图像来自 `eb916a6`。严格验收要求每张图像的 RGB 差异像素为零。验证覆盖默认索引描述符、固定描述符及顶点着色器蒙皮三条路径。Debug 与 Release 各有三个注册用例。

## 历史来源核验

- [x] 复核七张参考图与 `eb916a6` 的文件摘要。
- [x] 保存主线三条 Release 路径的图像摘要、差异区域及原注册结果。
- [x] 使用独立目录编译 `eb916a6` 的公开角色宿主，保存源码、资产、运行时及着色程序的摘要。
- [x] 在当前显卡上执行同一相机、光照、分辨率和七项隔离模式，逐像素核对冻结图像。

历史 Release 重放三条路径的差异统计一致。成片有 3 个像素、直射漫反射有 6 个像素各相差一个色阶，其余五张达到零差异。归档中的 41 份着色程序摘要全部吻合，宿主程序摘要和 43 份源码摘要有差异。原始七张捕获与冻结文件逐字节一致。原始捕获使用 NVIDIA 595.79，重放使用 592.82。

## 画面机制核验

- [x] 核对背景采样、显示变换、镜头和级联阴影，保存各项对照的像素统计。
- [x] 在独立主线候选中核对默认捕获和展台捕获。
- [x] 实现展台捕获，并核对七张图像和三条运行路径。

独立替换屏幕空间背景后，主线成片的差异从 495756 像素降至 25239 像素。分量与法线控制图的像素统计保持一致。

在 595.79 下，历史宿主和展台捕获的全部 42 张图像达到零差异。
