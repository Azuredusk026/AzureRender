# 实例准备阶段观察

## 来源与交付物

源码基线为 `a269247`。
当前完整 CPU 帧预算保持未通过。
先前[阶段观察](../acceptance/nr/cpu-stage-cost.md)记录实例准备约 4.87 毫秒。
本单元在当前实际来源中进一步定位该范围。

私有程序记录二十个稳态帧的嵌套阶段。
范围包括分组、姿态、包围盒、可见性和上传。
每个阶段的时间包含对应局部计时开销。
结果用于选择一次有依据的候选。

## 采集与边界

私有实现副本使用当前头文件、编译参数及链接依赖。
正式类布局、源码及运行产品保持现行字节。
调用栈范围通过线程局部的作用域标记传播。
标记在作用域退出时恢复，采样帧身份单独核对。

每种阶段应覆盖第三百一十至三百二十九帧。
非负有限值、记录数量及来源摘要共同检查。
私有日志与每实例计时开销使结果属于诊断范围。
正式画质、CPU、GPU 及热状态保持所属验收规则。

定位预算十分钟，私有编译三百秒。
原生命令三百秒，设备预检按既有期限执行。
同一来源执行一次本单元的阶段采集。

## 执行结果

五类阶段各二十条记录核对通过。
节点分组均值为 2.20 毫秒，姿态采样为 2.42 毫秒。
关节及权重上传为 0.024 毫秒。
完整数值与失败边界见[阶段观察](../acceptance/nr/instance-preparation-cost.md)。

正式源码、产品及项目文件保持原字节。
资源释放及验证日志检查通过。
软件热降频导致环境未通过，完整计时预算保持失败。
接续稳定资源分组的独立候选。
