# 运动向量命令绑定

## 目标与边界

状态：功能与调用数量验证完成，完整帧预算未通过。
实现归属 `MotionVectorPass` 的单次记录调用。
实际主命令缓冲包含 595 次相同管线的重复绑定。
该过程拥有本次绘制的管线、描述符和命令顺序。

本次调用内连续相同的管线与描述符只绑定一次。
每次调用均从未知绑定状态开始。
绘制顺序、几何、推送常量及输出附件保持原契约。
该能力同时服务反射重投影和时间重建的运动向量。

图执行、外部 Vulkan 互操作与次级命令保持所属边界。
通用记录器的独占状态规则继续适用。
依据为 [NVIDIA 管线建议](https://developer.nvidia.com/blog/vulkan-dos-donts/)和 [Vulkan 命令状态](https://docs.vulkan.org/spec/latest/chapters/cmdbuffers.html)。

## 执行与验证

1. 补充连续复用、变体切换及回切的有效绘制状态检查。
2. 在原实现上确认重复绑定检查失败。
3. 使用调用内状态记录，完成相关 CPU 回归。
4. 完成双配置构建及受影响运动向量 GPU 检查。
5. 对照四帧联合输出与 535 份着色程序字节。
6. 保存实际绑定数量，独立记录完整场景性能。

定位十分钟，候选修改与短检二十分钟。
单问题探索三十分钟，构建和采集各九百秒。
完整画质、实时预算及热状态遵守既有门禁。

实际数量及性能范围见[绑定验证](../acceptance/nr/motion-bindings.md)。
