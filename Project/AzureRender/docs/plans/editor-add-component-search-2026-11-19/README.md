# 添加组件搜索验收

单选对象后，从属性面板打开「添加组件」。
搜索框获得键盘焦点，可以直接输入。
名称、类型标识和分类参与匹配。
无匹配时显示提示，清除后可直接输入新词。

按 Esc 关闭弹窗，重新打开时呈现完整候选列表。
候选范围遵守组件注册、单选及冲突规则。
添加操作通过 `component.add` 提交编辑事务。

## 回放与结果

生产基线为 `c547e76`，配置为 Release。
批次 `2253` 复现打开后直接输入无效。
输入后仍显示未筛选的组件，搜索提示被截断。
批次 `2254` 使用同一操作路径复测。

| 操作 | 通过条件 |
| --- | --- |
| 打开弹窗并直接输入不存在的词 | 搜索生效，显示空结果提示和清除入口 |
| 清除后输入「音频源」 | 可直接重新输入，候选只显示音频源 |
| 按 Esc 后重新打开 | 一次按键关闭，选择、场景摘要和撤销计数保持，重新打开显示完整候选 |
| 输入 `azure.audio-source` 并点击匹配项 | 添加至当前选中对象，产生一项撤销记录 |
| 撤销、重做、保存和重新打开 | 撤销恢复原摘要，重做及重开恢复组件 |

探索项目与资产检视项目均执行同一组操作。
两项目的回放全部通过。
属性搜索、多选编辑、引用拾取也随回放验证。
Release 构建与 4 项受影响的 CPU 检查通过。
