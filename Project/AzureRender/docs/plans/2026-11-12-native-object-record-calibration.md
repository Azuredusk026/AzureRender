# 原生对象记录标定

对象记录标定按图集页绑定到具名参考视图。
锚点保存实际场景生成的世界投影。
源记录保存原生参考坐标中的反向投影及光方向。
当前对象和灯光通过场景生成投影进入同一变换。

## 核对项目

- [x] 保存宿主缺少记录配置的失败结果。
- [x] 验证矩阵、光方向及图集页配置。
- [x] 核对锚点的原生记录位值。
- [x] 核对相机、对象与光方向变化。
- [x] 核对双设备、两配置及原始四帧。
- [x] 记录冻结区域的实际可见量结果。

未指定标定的图集页沿用当前场景记录。
实际深度、法线、对象身份和图集继续提供同帧输入。
冻结区域沿用每通道一字节门槛。

分项结果见[专项验收](../acceptance/nr/native-object-record-calibration.md)。
