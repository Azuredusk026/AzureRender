# 材质纹理梯度主线接入

状态：主线接入及所属验收通过。
结果见[主线验收](../acceptance/nr/material-uv-main-integration.md)。

## 目标与范围

主线接入显式主纹理坐标梯度策略。
材质版本、特性位、设备能力及管线族共同决定资格。
合法请求进入对应颜色、覆盖、阴影及轮廓路径。
缺失程序、非法组合和卸载保持明确失败语义。

## 接入步骤

1. 核对画质分支的最终提交和完整验证归档。
2. 按所属文件接入提交，保留用户保护文件。
3. 构建 Debug、Release 的实际三个宿主及所属测试。
4. 核对既有 688 份程序及 168 份新增程序。
5. 每配置执行九项所属检查及两设备公共梯度检查。
6. 核对设备矩阵的源码、实际程序和适用范围。
7. 重新采集主线严格四帧并核对卸载与验证日志。
8. 同批记录工作集和分配器高水位的实际数值。

## 验收条件

全部适用检查通过，跳过项为零。
既有程序摘要及新增程序的受检摘要保持一致。
冻结四帧的 RGB 差异为零，PNG 摘要分别相同。
项目挂载输入和十三份用户保护文件保持摘要。

设备矩阵按源码、产品及场景范围复用。
复用记录须明确实际产品身份和适用限制。
内存观察使用实际分配结果和进程计数。
正式性能、标准工作负载及整体画质分别验收。
