# 参考透明层级实施计划

目标是提供可选择的椭圆主轴透明采样。
实现归属 RenderCore 的参考深度生产器。
依据见[纹理尺度来源](../acceptance/nr/texture-scale-profile.md)。
独立工具与场景深度生产共用该公共契约。

## 公共契约

`ReferenceDepthAlphaLodPolicy` 声明设备及椭圆模式。
设备模式为默认值，适用于版本一和版本二表面。
椭圆模式要求版本二及片元四像素组能力。
`loadEllipseMasked` 校验能力后加载对应程序。

椭圆模式使用镜像粗粒度导数与显式层级。
采样器采用各向同性过滤，偏移由表面字段提供。
UV、纹理和采样器由调用方持有至 GPU 完成。
现有槽位、同步、覆盖阈值与释放规则保持有效。

## 验收边界

独立用例覆盖平行、正交、反向及零导数。
检查版本、未知策略、缺失能力及缺失程序。
全部输入校验须先于资源分配或绘制操作。
设备模式的既有深度与覆盖用例保持通过。

NVIDIA 原生完整区域须保持零超差。
Intel 的透明判定差须关闭，完整区域不得新增失败。
剩余九十六处深度超差继续独立验收。
原有画质阈值及整体失败状态保持有效。

候选短检预算二十分钟，探索预算三十分钟。
正式双配置构建预算十二分钟。
GPU 检查预算四分钟，原四帧采集预算三分钟。
