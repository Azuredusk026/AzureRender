# 透明准备同输入成本控制

## 来源与目标

源码基线为 `51ed5cd`。
当前透明准备会重复变换同一实例的共享顶点。
本单元按冻结场景记录实际三角形及顶点引用规模。
独立计时比较局部位置缓存与世界位置缓存。

候选按实例和当前调用保存世界坐标。
三角形质心、深度、排序及写入规则保持现行算法。
私有控制交替交换顺序，并比较全部索引及绘制元数据。
生产采用由局部成本及严格兼容结果决定。

## 验证与预算

静态共享姿态的三角形数量单独记录。
姿态、模型、形变及相机输入消费同一实际帧。
私有控制记录二十帧，原生总时间作为诊断解释。
源码、运行产物、程序及项目文件保持冻结字节。

定位十分钟，私有构建三百秒，原生诊断三百秒。
候选及短检二十分钟，探索总预算三十分钟。
生产采用需执行受影响构建、图像及机制检查。
完整帧收益继续采用原有热状态及采样条件。

## 控制结果

二十帧的全部索引及绘制元数据一致。
局部均值为 3.937 与 3.663 毫秒。
约百分之八十二的三角形使用动态姿态。
后续验证稳定深度排序，生产仍保持受检字节。
