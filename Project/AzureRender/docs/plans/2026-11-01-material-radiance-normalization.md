# 材质辐亮度归一实施计划

执行方式：当前会话自主实施，按任务逐项验证。
目标为按明确源曝光换算材质的完整线性输出。
架构归属为既有资产材质与 RenderCore 渲染模块。
实现沿用 C++、GLSL、Vulkan 及 Python 工具。
依据见[输入核验](../acceptance/nr/native-material-input-audit.md)及[开发总计划](azure-engine-plan.md)。

## 输入与契约

角色参考采用负二档曝光，完整场景采用零档曝光。
源曝光换算对应四分之一的线性输出倍率。
灯强度、环境响应、自发光与专用高光具有独立消费者。
完整材质输出通过统一的线性倍率保持能量换算关系。

`azureRenderMaterial` 版本二提供可选 `radianceScale`。
字段为零至十六的有限数值，缺省为一。
倍率作用于材质的出射辐亮度及所属诊断分项。
颜色、法线、粗糙度、可见量及透明覆盖保留各自单位。

乘法合成材质输出无量纲颜色系数。
该合成类型要求 `radianceScale` 为一。
材质声明的轮廓颜色采用同一辐亮度倍率。
视图曝光、调色及雾保持所属消费顺序。

普通表面、专用眼睛和风格化材质共用此契约。
具体角色的源曝光和画像参数由项目数据持有。
核心材质与渲染逻辑通过通用字段消费倍率。
联合外观和显示变换继续按原门禁验收。

## 复核重点

眼睛的专用自发光须与漫反射使用相同的换算倍率。
乘法系数、透明覆盖及可见量须保持所属单位。
无照明表面与具名轮廓须覆盖输出颜色路径。
公共画像尾行须同时兼容无照明纹理层及 UV 扰动。
最终调色差异须按完整画质门禁保留真实状态。
