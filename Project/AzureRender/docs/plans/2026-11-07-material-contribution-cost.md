# 材质着色成本分项

## 目的

当前材质着色约占单帧事件成本的七成。
纹理索引及灯光采样分支控制均未取得足够收益。
本单元分别测量阴影、辐照、反射和直接灯的成本上界。
归因输入复用合法设备捕获及完整程序映射。

各分项通过私有着色程序暂时返回常量。
这类控制会改变颜色，仅用于筛选实现方向。
测量同时可能包含编译器消除相关后续运算的影响。
结果作为成本上界，兼容性与优化收益继续独立验证。

## 执行

每项控制分别预热，并在两端读取基线。
各控制复用同一帧、设备和原始材质输入。
生产源码、程序及挂载资产保持冻结。
本单元预算为十分钟，执行一次集中成本诊断。

成本上界支持具体机制后，才制定兼容的实现候选。
原生检查仍需具备原有收益资格。
CPU、GPU 帧预算及整体画质条件保持有效。
