# 阴影圆盘权重分类

状态：局部效率门槛未通过，候选保存于精简证据。

## 范围与依据

阴影圆盘按四纹素组计算权重。
完全覆盖及完全排除的区域分别具有恒定权重。
本单元使用保守几何界判断这两类区域。
边界及范围外半径使用既有权重公式。

有效分类半径为一至十六个纹素。
平方距离比较保留 0.004 的安全间隔。
该间隔用于覆盖单精度运算与开方误差。
滤波半径、采样位置、累计顺序及覆盖规则保持现有契约。

函数归属于共享阴影采样机制。
实际网格片元与阴影过滤夹具共用同一实现。
几何分类只替代已确定为零或一的四维权重。
数值、内核效率与整帧收益分别验收。

## 执行与门槛

1. 复现保守权重分类接口缺失。
2. 使用独立 GPU 夹具检查边界及逐位数值。
3. 独立核函数减少至少 20%，参考漂移至多 5%。
4. 达到门槛后集中检查相关材质、阴影及视图兼容。
5. 严格四帧通过后执行一次整帧前后参考比较。

GPU 16.6 毫秒、CPU 八毫秒及 RGB 零差异标准有效。
输入及精简证据均保存于 D 盘项目。
资产继续通过既有路径引用，任务按天回收。

精度依据见 [Vulkan 浮点环境](https://docs.vulkan.org/spec/latest/appendices/spirvenv.html)。

## 结果与接续

一百万组输入及累计权重均保持逐位一致。
局部候选均值约为参考的 1.91 倍。
参考漂移约为 10.86%，效率门槛未通过。
原生截图与整帧计时的进程数均为零。

生产源码及两种配置的 675 份程序保持受检摘要。
既有双设备检查按相同源码及产物引用。
后续优先核对主通道遮挡与实际材质工作量。
权重分类的重试须具备新的实际程序成本依据。

结果见[分类验收](../acceptance/nr/shadow-disk-classification.md)。
