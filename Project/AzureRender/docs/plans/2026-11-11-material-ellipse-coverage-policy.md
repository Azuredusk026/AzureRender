# 独立覆盖椭圆层级实施计划

## 目标与契约

覆盖图对象版本二声明 `ellipse-major` 层级策略。
纹理图源、通道及阈值沿用现有独立覆盖接口。
版本一采用设备层级选择。
参考模式使用纹理自身尺寸及镜像四像素组梯度。

该模式要求独立遮罩、线性过滤及最近层级。
各向异性设为一，层级偏移由原采样器持有。
主颜色、深度、轮廓及阴影共享覆盖策略。
公开支持范围由实际采样配置核对。

## 实施步骤

- [x] 为覆盖对象版本、合法策略及拒绝条件建立失败检查。
- [x] 在 `MaterialCoverage.hpp` 声明类型化选级策略。
- [x] 在 `GltfLoader` 与模式文件同步输入解释。
- [x] 核对纹理采样器及四像素组要求。
- [x] 在相关着色器中接入共享覆盖取样。
- [x] 在角色渲染器声明实际配置和不兼容组合诊断。
- [x] 核对普通覆盖、显式层级及实际原生画面。
- [x] 完成两配置、两设备及默认四帧回归。
- [x] 同步文档、清单与证据，审查后独立提交。

## 验收与预算

实际覆盖须复现[局部诊断](../acceptance/nr/native-hair-coverage-lod.md)。
NVIDIA 遮罩保持原输出，Intel 边界按实测值核对。
完整颜色仍采用原 17017 像素及一字节门槛。
原四帧继续要求精确摘要，程序集上限为 1024。

定位预算十分钟，候选预算二十分钟。
问题探索预算三十分钟，正式构建预算三十分钟。
正式 GPU 验证预算二十分钟。
任务产物预算 512 MiB，精简证据至多 8 MiB。
