# 阴影状态录制计划

## 目标与证据

本单元归属于 RenderCore 的命令准备与录制。
原场景捕获中有 864 次纯深度阴影绘制及 255 次带片元阴影绘制。
纯深度顶点程序读取变形、变换和级联状态。
材质常量的有效读取范围按所选管线分别核对。

生产基线为 `845c22f`，运行时沿用 `c3def68` 的受检输入。
候选接入前先定位实际准备与录制成本。
私有诊断在当前代码上附加分段计时，运行资产及着色器按既有路径引用。
记录均属于归因，正式性能资格采用原功率与样本条件。

## 执行

- [x] 编译私有渲染器计时对象及诊断 Player。
- [x] 以原联合场景执行一次有界采样，划分更新及录制成本。
- [x] 按实际主导成本决定状态写入候选的适用范围。
- [x] 记录热点门槛判断及候选调度结果。
- [x] 同步来源、成本、调度决定及剩余验收条件。

阴影录制约为 0.34 毫秒，候选未进入实施。
帧内优化优先处理更新阶段，其占本轮 CPU 工作约 56.5%。
启动管线任务约为一百一十七秒，持久缓存作为独立候选评估。

诊断涵盖场景字段复制、Uniform 准备、实例准备、透明索引、拾取状态、
录制快照、运动数据、图构建及阴影、主颜色、覆盖录制。
嵌套阶段的耗时分别记录，整体成本按非重叠范围解释。

## 预算与验收

定位预算十分钟，候选和短检预算二十分钟。
私有编译、链接及单次原生命令各自至多六百秒。
任务采用 2 GiB 上限及三天保留期，项目数据保持在 D 卷。
当前源文件、运行产物及挂载资产的摘要在诊断前后核对。
正式 CPU 八毫秒、GPU 16.6 毫秒、四帧兼容及整体画质门槛持续有效。
