# 场景参考相机选择实施计划

场景相机通过独立组件选择项目中的具名参考视图。
持久锚点定义参考视图对应的相机姿态。
当前实体姿态驱动同一视图的刚性移动。
本单元交付类型注册、配置装配及选择结果。

## 契约与边界

参考相机组件使用版本一，并依赖游戏相机组件。
组件保存启用状态、视图名称及正交右手锚点。
渲染数学模块拥有锚点到当前姿态的参考投影转换。
运行相机服务拥有具名查找、优先级及诊断。

相机处于锚点时保留原参考参数位值。
移动视图采用相机相对坐标，抖动及深度约定保持原值。
准备结果继续遵守矩阵条件及有限数值门槛。
缺失引用及非法姿态提供可观察诊断。

项目宿主和编辑器运行预览加载同一项目视图集合。
集合及选择结果持有数值副本。
普通相机沿用既有优先级及稳定名称规则。
光栅及拾取消费在后续单元接入。
