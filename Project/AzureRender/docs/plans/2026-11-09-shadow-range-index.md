# 阴影范围索引

状态：局部效率门槛通过，候选隔离保存。

## 机制与范围

归属为共享阴影范围查询。
原有八乘八纹素深度界限作为基础表。
两个重叠范围表分别覆盖二乘二及四乘四基础块。
四角查询的并集与原矩形完全一致。

查询选择矩形短边对应的二次幂。
长边在两倍跨度以内时使用四角查询。
细长矩形继续逐项读取基础表。
有限深度的最小值及最大值保持精确。

普通级联接收与独立矩形夹具共同验证机制。
夹具在查询前构建两张附加表，并记录存储屏障。
生产分块布局及对象记录保持受检契约。
场景集成须由现有资源所有者持有帧内范围表。

## 成本依据与执行

最终绘制与快照共占既有通道计时约 14.61 毫秒。
每次级联采样先查询整个阴影滤波范围。
常见三至四块矩形需要九至十六次基础读取。
索引查询需要四次读取及两张附加表。

先检查全部矩形形状、边界及有限深度。
局部计时同时包含每帧附加表构建。
净成本减少至少 20%，参考漂移至多 5%。
实际热点覆盖及整帧收益资格另行核定。

达到局部及场景工作量门槛后集中进行受影响检查。
随后执行一次严格四帧与一次短时前后参考比较。
GPU 16.6 毫秒、CPU 八毫秒及原画质标准有效。
所有临时输入与结果位于 D 盘受管目录。

整数位查询依据见 [GLSL 内建函数](https://docs.vulkan.org/glsl/latest/chapters/builtinfunctions.html)。

## 结果与接续

两设备分别通过 10404 个矩形的逐位核对。
局部计时包含每次构建，净成本降低约 42.64%。
参考漂移约为 0.12%，净差约为 0.044 毫秒。
该结果尚未建立主通道减少 20% 的依据。

原生采集与整帧计时进程数均为零。
生产源码与两配置 675 份程序分别保持受检摘要。
后续先核对同帧重复阴影计算的复用规模。
结果见[范围索引验收](../acceptance/nr/shadow-range-index.md)。
