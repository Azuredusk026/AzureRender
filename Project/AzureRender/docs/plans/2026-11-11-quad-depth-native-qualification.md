# 深度可见性组合原生核验

## 来源与范围

候选来自[局部组合准入](../acceptance/nr/quad-depth-visibility.md)。
完整材质的六附件精确一致，局部降幅约为 21.21%。
本项在当前主线建立隔离宿主及独立程序目录。
生产源码与产品保持受检摘要。

## 宿主与程序

私有宿主仅启用现行可选四像素组设备特性链。
源文件差异及运行时启用日志分别保存。
宿主使用当前实际库重新编译及链接。
参考和候选使用同一份宿主字节。

两个资源目录分别保存 859 份程序的独立副本。
候选编译 256 个所属材质变体并逐项验证中间码。
其中十份程序须与局部实测程序逐字节一致。
资源路径探针确认各端选择的实际程序目录。

## 原始四帧

先在候选资源目录执行冻结场景的原始四帧。
PNG 摘要及 RGB 内容分别保持零差。
验证检查、实际设备特性及卸载计数共同核对。
1729 项挂载输入和十三份用户保护文件保持摘要。

## 成对短时成本

四帧通过后执行参考、候选、参考三进程。
分辨率为 1920×1080，采用每秒二十四次固定更新。
各端预热六十帧，并统计其后六十帧。
CPU 工作、GPU 整帧及场景阶段分别计量。

短时收益沿用既有四项条件。
整帧均值至少降低 2%，且至少为参考漂移的两倍。
参考漂移至多为 3%，受影响场景成本至少降低 5%。
交流供电及热状态按实际监控结果记录。

正式八毫秒 CPU、16.6 毫秒 GPU 及完整采样继续有效。
固定功率、一千八百帧、十五轮及长跑分别验收。
设备功率入口的限制保持现有记录。
