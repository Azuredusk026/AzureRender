# 帝江号材质、光照与展示视频

目标是在 AzurePlayer 中录制原生资产展示。
角色使用莱万汀编队待机 01，表情保持中性。
角色站位由中庭可行走面的几何检测确定。

## 实施契约

材质转换归属离线内容工具。
复杂节点烘焙为标准表面通道，记录采样范围。
工具同时验证合成材质与真实场景。
游戏源文件保持只读，生成资产存于运行目录。

灯光数据保留源身份、参数和文件校验信息。
运行时支持范围与近似转换分别记录。
镜头、站位和展示设置归属于项目数据。
视频必须来自实际 Player 渲染帧。

## 执行与验收

- [x] 验证材质节点求值、透明度和纹理坐标。
- [x] 读取原生灯光，核对当前版本字段。
- [x] 应用材质和灯光，验证可站立位置。
- [x] 录制展示视频，检查首、中、尾画面。
- [x] 执行相关回归并记录视频编码与来源。

材质验收包含颜色、自发光、法线和粗糙度。
灯光验收包含原生参数映射及实际受光画面。
角色须保持原生动画和中性表情。
视频验收包含帧数、时长、完整解码和运行日志。

## 交付范围

1080p、24 帧、16 秒的录像已通过验证。
材质通道烘焙、灯光读取和可编辑工程已交付。
展示采用源灯光参数的点光近似。
完整原生照明、反射与衣摆物理属于后续范围。
