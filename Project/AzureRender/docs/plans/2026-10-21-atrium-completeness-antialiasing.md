# 中庭完整性与抗锯齿修复计划

日期：2026-10-21。
状态：自主实施中。
所属主线：[NR0 至 NR12 还原计划](2026-10-17-native-playable-restoration.md)。

## 目标与范围

中庭后方的可见室内区域由原生资源闭合。
后门、侧廊、墙体及其遮挡纳入资源调查。
模型保留源身份、变换、材质与依赖收据。
固定视图核验室内缺口及背景透出区域。

抗锯齿覆盖主视口、辅助视口和独立 Player。
默认质量在原生输出分辨率实际生效。
公开夹具采用高采样图像作为边缘参考。
角色与场景的运动画面另行检查细线稳定性。

用户已授权持续获取本机原生资源及自动验证。
本轮目标已登记于会话 goal。
NR0 至 NR12 的正式门禁及状态保持有效。
下列任务作为所属阶段的优先子任务执行。

## 当前证据

最高细节候选包含中央区 86 个源实例。
上层区包含 53 个源实例。
生产导入保存 418 个节点和 110 份资源。
后方区域的资源覆盖和运行时可见性需补齐。

主视口的分数位置采样使用最近邻屏幕采样器。
当前边缘算法固定混入一半原始像素。
辅助视口的输出路径尚未消费抗锯齿设置。
这些问题分别进入采样及共享输出回归。

## 任务与归属

| 任务 | 文件或输入 | 实施与验收 |
| --- | --- | --- |
| NR1-C1 后方来源 | 原生场景目录、分层索引及动态放置 | 定位缺失区域、激活关系及精确对象身份 |
| NR1-C2 资源转换 | `tools/endfield_native/` 及场景交换文件 | 补全依赖，导出源几何、材质及变换 |
| NR1-C3 联合接入 | 项目资源与生产 `scene.import-start` | 保存重开，核验后门和侧廊遮挡闭合 |
| NR7-A1 采样复现 | `inner_outline.frag`、`view_resolve.frag` | 用高对比边缘复现主辅输出缺陷 |
| NR7-A2 共享输出 | RenderCore 视图输出及宿主装配 | 在线性显示颜色上统一抗锯齿与编码 |
| NR7-A3 资源回归 | 主视口、辅助视口及 Player 夹具 | 检查关闭、默认和超采样配置及重建释放 |
| NR8-V1 联合图像 | 固定镜头、角色近景及运动序列 | 核验室内覆盖、边缘误差和可见细节 |

游戏专用身份及区域选择属于导入数据。
采样、输出、资源同步和设备能力属于引擎。
新增公共能力同时验证合成场景和原生场景。
GPU 运行与共享构建分别采用串行所有权。

## 执行与门禁

先保存缺失区域和走样的复现图像。
原生资源调查同时核验裁剪、变换及透明分支。
每份新增模型记录源身份及几何摘要。
场景关闭和重开必须保持资源定位。

抗锯齿用失败用例驱动实际采样修复。
关闭路径提供逐像素基线。
默认路径须降低相对高采样参考的边缘误差。
平坦颜色、调色和诊断输出保持规定契约。

联合验收检查固定前视、后门、左右侧廊和转身视图。
可见室内边界应具有原生几何遮挡。
背景像素统计关联具体视图与区域遮罩。
实际开放区域按原游戏可见状态判断。

两种宿主完成受影响构建与生产短测。
Debug 检查 Vulkan 校验和资源释放。
目录移动、保存重开及辅助视图重建纳入回归。
每项独立交付使用所属 NR 阶段提交。

完整近乎原生验收继续覆盖材质、GI、反射及物流。
原生来源、画面相似度和性能分别保留证据。
本轮两项修复通过后，继续原定还原任务。
