# 场景参考法线与对象身份

参考深度通道提供实际场景的反向深度。
本单元准备同一图元的压缩法线及对象身份。
三种输入按相同尺寸、行原点及提交序号核对。
输出供公共屏幕对象可见量通道消费。

## 原生输入

帧 10401 的事件 699 消费压缩法线资源 141952。
资源为 2560×1440 的十位归一化附件。
事件 422 的头发顶点包含纹理坐标、法线及切线。
原生纹理、采样器和写入事件通过重放确认。

项目材质持有可追溯的头发法线纹理。
纹理尺寸为 2048×2048，含十二个级别。
场景图元保持对应的顶点及索引来源。
法线基向量按有符号轴映射核对。
