# 快照深度壳顺序

## 目标

状态：实现及对应回归通过，归属于 Q1。
完整联合画质按总计划继续验收。
每个可见跨度的快照包含材质颜色及深度壳。
后续跨度接受已经完成的深度覆盖。
颜色及法线附件遵循所属管线的写掩码。

## 来源

原生绘制顺序为角色法线、深度壳及背景。
深度壳片元只声明颜色附件零。
法线位于其他附件，保留所属像素。
后方背景按深度测试决定是否写入法线。

## 实施

1. 在双资产记录夹具中验证实际命令顺序。
2. 为私有描边记录入口增加跨度筛选。
3. 完整颜色快照按跨度完成深度壳。
4. 深度快照及主颜色描边保持各自调用。
5. 核对来源角色、公共几何及缺省图像。

配置与缓冲布局沿用现行版本。
该机制服务于描边模型及独立遮挡代理。
两种构建核对固定、索引及多重采样路径。
完整角色的字节门槛保持现行定义。
