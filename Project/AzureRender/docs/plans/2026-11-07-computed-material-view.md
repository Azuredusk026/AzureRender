结构化 API 绑定可关联全部 3394 个叶绘制，已知着色器身份核对一致。
720p 普通提前深度主颜色组约为 5.345 毫秒，快照组约为 2.045 毫秒。
深度专用绘制约为 1.588 毫秒。
相关时间来自已有捕获，原生帧预算各自验收。

固定步长的联合场景使用场景照明、默认效果及计算反射。
私有专用常量控制保留动态回退，并配合严格限定的主颜色提前深度。

等视野像素规模推算的 1080p 预期节省约为 3.756 毫秒。
该推断用于集中评估资格，原生调度及完整帧收益继续待验证。

动态回退的九项附件比较均逐字节一致。

## 实施契约

专用常量编号四表达完整的计算反射视图。
默认值保留逐帧动态参数。
优化资格逐项匹配实际上传的照明、隔离、效果及反射模式。
原管线与专用管线分别持有，设置变化选择完整回退。
管线映射采用有界资源集合及直接查询，资源释放涵盖全部变体。

主颜色的完全覆盖资格按实际片元丢弃条件确定。
不透明材质要求节点透明度为一，并保留积分及特殊合成的独立路径。
屏幕法线在快照和主颜色中分别判断覆盖资格。
混合材质在单样本主颜色路径使用提前测试。
遮罩、节点淡出及多样本路径保留各自覆盖约束。
颜色、深度写入策略、反射和时间采样保持原定义。
