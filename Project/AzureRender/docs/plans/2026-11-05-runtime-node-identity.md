# 运行时实体身份

## 目标与来源

状态：功能验证完成，完整帧预算未通过。
完整联合场景的 CPU 工作 P95 仍为 46.35 毫秒。
原八毫秒门槛保持失败。
原生采样包含玩法更新中的实体身份反向查询。

现有实体已经持有 `NodeIdentity` 组件。
节点索引持有文档身份与实体的对应关系。
查询使用组件直接访问，并核对所属文档的映射。
该做法参考[实体存储调研](../research/2026-11-05-render-performance-architecture.md)。

## 模块与契约

实现归属 `RuntimeLifecycle::nodeId`。
实体组件由 `ecs::World` 持有，文档索引由运行时持有。
查询返回所属节点的字符串副本。
未知、销毁及缺少身份的实体返回空字符串。

交换世界后，身份组件须符合当前运行时的文档索引。
场景替换及失败恢复使用既有的候选提交边界。
延迟生成在帧边界获得身份，停止时释放全部身份。
接口供玩法插值、动画及编辑操作共同使用。

## 执行与检查

1. 保存四十六毫秒的完整场景失败控制及原生栈。
2. 补充世界交换、回收、替换失败及延迟生成检查。
3. 先运行原实现的功能边界，再实现直接查询。
4. 完成两配置的运行时、玩法及场景检查。
5. 按原帧数复测联合性能，并完成图像与程序字节核验。
6. 保存全部原始结果，继续 GPU 阶段的独立任务。

定位十分钟，候选与短检二十分钟。
构建及完整采集的命令预算各为九百秒。
原实时、完整画质及热状态门禁保持所属范围。
GPU 诊断采用独立捕获及生产程序字节。

本机任务卡位于当前自动验收目录的：
`runtime-node-identity-task.json`。

结果与供电范围见[身份验证](../acceptance/nr/runtime-node-identity.md)。
