# P0 Windows 游戏发布实施计划

> 文档类型：实施计划
> 状态：Complete
> 更新日期：2026-10-04
> 适用范围：Windows x64 游戏模板与发布包

## 目标与依赖

依赖 U0，完成可创建、编辑、构建和分发的游戏项目。发布包包含独立 Player、项目资源、运行库、着色器、字体和许可证。

## 接口与文件

Project 提供公开游戏模板创建入口。`tools/build_game.py` 接收项目路径、Release 安装树和输出目录，生成可移动游戏目录、启动入口与带哈希的资源清单。

构建先验证项目与资产依赖，在临时目录完成候选包，成功后提交到目标目录。资源引用通过挂载目录和 UUID 保持稳定。目标目录冲突与失败构建保留有效发布结果。

## 文件级任务与验证

- [x] 模板包含角色、两个关卡、Lua、RmlUi 界面、动画和公开音效。
- [x] `tools/test_game_package.py` 验证创建、打包、移动、启动、游玩、切关、退出与清单校验。
- [x] 接入发布工具与编辑器构建入口，提供用户可执行的启动命令。
- [x] 验证编辑器代码与私有资产的发布边界、DLL、字体及第三方许可。
- [x] 完整 Debug/Release 回归和最终发布门禁通过。
- [x] 更新总计划、README、主题说明、变更记录、阶段证据与 manifest，提交 P0。

阶段结果见 [P0 验收](../acceptance/p0/2026-10-04.md)。Debug 57 项与 Release 58 项完整回归通过。最终包验证覆盖 MSVC 运行库、目录移动与依赖失败回退，提交标题为 `feat(p0): 完成游戏模板与Windows独立发布闭环`。

## 验收与边界

游戏包在项目目录与引擎安装目录之外运行，并在目录移动后保持可用。真实 Player 完成角色运动、切关和正常退出，Validation 与资源卸载检查通过。

Windows 使用本机环境记录工具链、驱动和性能。Android 保持 Deferred。首次包构建与后续包替换均采用可回退的目录事务。

## 来源

模板资产由项目公开资源组成，字体和依赖许可随包交付。构建工具基于项目现有 AssetDatabase、安装清单和独立 Player，行为由实际包测试验证。
