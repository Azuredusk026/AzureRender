# 场景参考深度实施计划

参考视图通过 `produceSceneDepth` 声明场景深度输出。
视图配置保留原有相机标定和选取规则。
角色渲染器复用当前帧的网格、姿态和覆盖输入。
输出包含 R32 取样附件和 D32 深度附件。

## 输出契约

场景深度使用参考裁剪坐标的深度分量。
绘制沿用当前帧的空间采样和材质覆盖。
本阶段验收范围为反向深度及单样本空间视图。
参考附件按所属帧槽退役和重用。

未声明输出的参考视图采用现有配置。
生成范围和方向通过采集清单记录。
实际颜色通道继续消费其现行深度。
参考可见量可在所属通道使用该附件。

## 验收

实际输入须包含当前场景的网格和覆盖采样器。
17,017 个头发遮罩点按冻结坐标逐位核对。
NVIDIA 使用原生深度，Intel 同时核对同设备读回。
可见量及颜色仍使用原冻结来源和一字节门槛。

定位预算十分钟，候选预算二十分钟。
正式构建预算三十分钟，GPU 验证预算二十分钟。
任务产物预算 512 MiB，证据预算 8 MiB。
