## 结构与维护边界

生产代码沿用现有目录与 CMake 目标。
导航集中描述职责、入口与测试位置。
任务说明引用正式证据，证据记录对应源码与环境。
本机生成内容继续按 `build/runs/` 保留规则维护。

报告、运行收据、原始捕获和源码快照各有用途。
归档清单记录路径、字节数、哈希与来源提交。
历史候选含工作树修改时，归档同时保存补丁与输入。
恢复验证覆盖报告引用和实际使用入口。

清理只消费逐项审核的清单。
主构建、当前交付和保留任务遵守现有保护规则。
目录联接、硬链接和活动写入需要独立核对。
Git 历史改写需专项授权与迁移安排。

## S1 有界检索

新增 `tools/code_query.py`、`tools/code_query_scopes.json`。
测试入口为 `tools/test_code_query.py`。
同步本页与[源码导航](../development/source-navigation.md)。

范围配置使用版本化 JSON。
预设范围包括生产代码、测试、工具、说明和证据。
默认范围覆盖 `src`、`shaders` 与 `managed`。
模块参数进一步限制到已声明的子目录。

查询接口采用以下候选形式：

```text
python tools/code_query.py search RenderGraph --scope source --json
python tools/code_query.py read src/render/RenderGraph.hpp --start 1 --lines 80 --json
```

每次查询返回来源路径、行号、范围和耗时。
结果限制为 20 项及 12,000 个 Unicode 字符。
输出预算包含序列化后的完整 JSON。
截断时返回 `truncated` 和缩小范围的提示。

读取结果包含当前文件 SHA-256。
索引查询也提供结果新鲜度与来源指纹。
查询成功返回零，空结果返回一，参数或执行错误返回二。
短读与结束行超出文件长度按实际内容返回。
