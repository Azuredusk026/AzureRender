# 灯光采样分支成本

## 范围

当前联合场景包含两盏方向光、七盏点光和七盏聚光。
部分局部光使用空间影响盒及距离幂衰减。
普通表面在最终入射权重为零时跳过 BRDF。
方向光的衰减定义独立于距离平方根和局部衰减。

私有控制按灯型限定距离计算的执行范围。
普通表面先核对影响盒为零的条件。
角色组合保留各自的灯光状态及完整计算路径。
有效贡献的运算表达式和累加顺序保持一致。

## 判定与预算

成本控制复用合法设备捕获及完整程序映射。
相关材质范围约占 GPU 事件成本的 71.64%。
预期依据为可避免的平方根、距离衰减及无效灯计算。
实际资格由一次配对局部控制判定。

本单元的诊断和局部候选预算为十五分钟。
先检查精确附件，再评估成本减少比例。
达到现有收益门槛后，才安排生产接入及原生检查。
CPU 八毫秒、GPU 16.6 毫秒及画质条件保持有效。
