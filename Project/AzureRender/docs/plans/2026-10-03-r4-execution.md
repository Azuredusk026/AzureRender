## 文件与职责

- `assets_public/scenes/r4_stress.azscene`：32 个独立网格资源、32 个可见对象和 16 个点光源。
- `tools/run_r4_acceptance.py`：顺序运行性能矩阵、截图与窗口长跑，保存原始报告和汇总。
- `tools/test_r4_acceptance.py`：验证报告完整性、真实路径计数和生命周期判定。
- `src/app/AzureRenderSupport.cpp`：记录成功交换链重建。
- `src/app/AzureRenderApp.cpp`：记录卸载后的分配器存活资源数。
- `src/scenes/BlackholeSceneRenderer.cpp`：记录重建后的历史帧重置。
- `docs/acceptance/r4/2026-10-03.md`：保存版本、设备、结果和性能适用边界。

## 验收条件

复杂场景四组合各采样 300 帧，黑洞三个质量档位各采样 150 帧。分辨率为 1280×720，保存逐帧 GPU 曲线、整帧与录制耗时。性能作为本机测量结果报告。

角色复杂场景和黑洞平衡档各持续运行至少 120 秒。每场景执行六次尺寸变化与最小化恢复，验证重建完成、截图有效、正常退出及资源卸载。黑洞重建必须触发历史帧重置。

GPU 报告必须完整且耗时有限。串行工作线程计数为零，并行角色路径有实际工作线程任务。CPU 路径间接调用为零，GPU 角色路径有间接调用。

Debug 启用 Validation，日志须无验证错误。Debug 与 Release 完整回归通过，Release 安装、隔离运行、打包与许可证清单通过。预算与环境规则沿用现行实施计划。
