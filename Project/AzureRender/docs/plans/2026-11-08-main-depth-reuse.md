# 主通道深度预填复用

本单元入口为 `707a593`。
保守剔除的场景候选有重复深度遍历成本。
本批直接复用主通道已有的深度预填。
图元预填次数与现行生产路径相同。

## 公共机制

`DepthPrepassSplit` 属于 RenderCore。
输入为已有单子通道的附件及依赖描述。
机制创建兼容的深度准备和颜色加载通道。
帧缓冲、图像及绘制管线由调用方持有。

深度准备只保留深度内容，颜色附件采用忽略操作。
颜色通道按原规则清除颜色，并加载已准备的深度。
两通道保持附件格式、顺序、采样数及依赖定义。
兼容规则依据 [Vulkan 渲染通道规范](https://docs.vulkan.org/spec/latest/chapters/renderpass.html#renderpass-compatibility)。

RHI 描述保留显式的子通道依赖。
原生描述通过受限转换记录真实创建信息。
来源不符合单子通道契约时，调用方保留原路径。
加载规则依据 [附件加载操作](https://docs.vulkan.org/refpages/latest/refpages/source/VkAttachmentLoadOp.html)。

深度准备结束后生成最大值层级及剔除命令。
颜色开始前发布采样到深度加载的依赖。
颜色写入和深度加载按实际图像建立同步。
阴影、快照及后处理保留各自的资源集合。

## 场景与所有权

宿主提供当前帧缓冲的真实描述及借用图像。
运行窗口和独立渲染视图共同提供该契约。
交换链图像索引与在途帧槽分别定位相应资源。
主深度图像与颜色帧缓冲保持相同来源。

普通场景适配复用已有完整覆盖及渐隐预填。
预填之后加载同一份深度，颜色阶段执行既有绘制。
保守剔除只影响合格的普通颜色命令。
资源资格不足时使用既有完整录制路径。

通道对象在全部消费退役后释放。
借用图像和帧缓冲的销毁由宿主负责。
视口变化及目标变化触发明确的重建。
多样点通道保持独立的资格规则。
