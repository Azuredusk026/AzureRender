# 加载资源绑定姿态复用

## 目标与归属

源码基线为 `121011c`。
实例准备的[阶段观察](../acceptance/nr/instance-preparation-cost.md)记录姿态采样约 2.42 毫秒。
本单元复用加载后资源的绑定姿态求解结果。
每帧实例按值复制，并独立持有可变姿态。

所属模块为场景渲染器及已加载资源生命周期。
资源节点、绑定矩阵及默认形变在该生命周期内保持只读。
绑定姿态由现有求解入口计算，浮点运算保持原规则。
动画、混合、表情和实例形变继续按当前帧输入求解。

主资源与附加资源均按相同规则建立绑定姿态。
重新加载建立新内容，卸载释放绑定姿态。
帧内复制使实例形变及表情具有独立所有权。
模型世界变换与静态 GPU 输出缓存分别遵守所属契约。

## 验证与预算

实际渲染器先记录缺少复用行为时的失败。
检查静态复制、动态输入绕过、恢复静态及重新加载。
混合透明、节点淡出、蒙皮、运动、阴影及表情共同回归。
四帧原生图像保持冻结参考的严格字节门槛。

采集清单记录绑定姿态条目及本帧静态复制数。
计数描述求解选择，实际收益由独立计时判断。
完整 CPU、GPU、热状态及用户画质保持原验收条件。
受影响的 GPU 机制按原同步及资源断言核对。

候选修改与短检预算二十分钟，探索预算三十分钟。
两配置构建分别九百秒，原生四帧九百秒。
短时原生命令三百秒，设备预检按既有期限执行。

## 执行结果

两配置各十九项 CPU 检查及十二项双设备 GPU 检查通过。
原生四帧与冻结参考逐字节一致。
实际末帧加载 374 份绑定姿态，860 个实例按值复制。
详细来源及边界见[验证记录](../acceptance/nr/loaded-bind-pose.md)。

短时 CPU 工作 P95 为 20.68 毫秒，GPU 帧为 33.77 毫秒。
运行中的热状态未通过，整帧因果收益资格未成立。
CPU、GPU、长跑及整体用户画质继续按原标准验收。
