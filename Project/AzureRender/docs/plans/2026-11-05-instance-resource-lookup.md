# 实例资源查询

## 目标与来源

状态：资源键功能受检，完整帧预算未通过。
完整中庭以 1080p 原生分辨率采集两千一百帧。
预热三百帧后，CPU 工作 P95 为 56.46 毫秒。
原八毫秒目标保持有效，该采集为失败控制。

六份原生采样中，五份停在实例资源身份查询。
私有链接映射的代码节与生产程序逐字节一致。
采样和映射限定所属函数，运行报告仅在退出时序列化。
当前输入包含 374 份网格和 1,679 个节点。

## 实现范围

修改归属 `CharacterSceneRenderer::rebuildSceneInstances`。
每帧先取得各可见节点的资源键。
实例继续按资源顺序及节点顺序生成。
局部数组随本帧释放，资源变更在下一帧重新解析。

该机制适用于完整场景、材质变体及独立预览。
几何、材质、矩阵、包围盒及程序字节保持所属输入。
未知身份和不可见节点沿用现行处理条件。

## 执行与验证

1. 保存原失败计时、六份栈及代码节指纹。
2. 将重复资源身份查询移到资源遍历之外。
3. 构建 Release，执行受影响场景和记录检查。
4. 按原帧数复测完整场景，比较各阶段计时。
5. 核对四帧画面、程序字节及零资源卸载。
6. 验证 Debug，并同步收据、入口和状态。

定位十分钟，候选修改与短检二十分钟。
每次构建和完整采集的命令预算各为九百秒。
原始失败和热状态条件持续保留。
GPU 场景成本及运行时身份查询按实际采样接续。
