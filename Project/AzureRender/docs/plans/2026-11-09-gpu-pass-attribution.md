# GPU 通道成本归因

状态：归因完成。

## 范围与契约

渲染图提供可选的主命令边界回调。
回调包围资源依赖、通道命令及通道结束操作。
图形、计算及主机录制通道共用此接口。
并行录制保持原有命令顺序与生命周期。

宿主按帧槽拥有至多六十四组时间戳。
显式选项 `--gpu-pass-timing` 启用通道计时。
普通性能入口保留原有四个时间戳。
查询在所属栅栏后回收，缺失结果保持缺失状态。

时间戳采用通道两端的完成阶段。
结果包含资源等待及管线排空影响。
通道分段用于归因，正式净收益单独比较。
数据与临时产物均写入 D 盘项目目录。

## 执行门槛

1. 复现边界回调及显式参数接口缺失。
2. 实现有界通道时间戳、回收及精简报告。
3. 集中核对主机、图形及并行执行边界。
4. 一次短原生采集确定快照、反射及主绘制成本。
5. 按实际成本和收益上限选择后续实现。

原画质、帧预算及正式采样条件保持有效。
本单元不执行正式长采样及画质截图。

## 执行结果

四项所属检查及一次原生采集通过。
实际十九个通道的结果全部可用。
蒙皮输出的数据宽度进入后续优化评估。
详见[验收记录](../acceptance/nr/gpu-pass-attribution.md)。
