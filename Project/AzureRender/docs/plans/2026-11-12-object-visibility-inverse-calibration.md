# 对象可见量逆投影标定

场景参考视图可持有独立的可见量逆投影。
标定参数来自实际原生片元常量。
深度、法线、对象身份及 D16 图集仍由当前场景生产。
对象记录投影使用相同的标定坐标帧。

## 数值约定

逆投影矩阵使用列主序单精度数据。
标定坐标继承所选参考视图的有符号轴。
位置偏移单独定义该坐标的原点。
图集的正向深度及对象记录顺序沿用场景契约。
