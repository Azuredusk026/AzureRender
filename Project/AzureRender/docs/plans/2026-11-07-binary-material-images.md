# 材质图像二进制准备

## 依据与边界

角色十四份材质的独立采样合计约 17.28 秒。
图像解码约 3.98 秒，材质解释约 1.29 秒。
其余耗时包含输入读取、文本组装及解析。
本批目标为减少至少 30% 的角色材质准备耗时。

实现归属 `MaterialData::interpret` 的完整表面分支。
图像输入使用内存 GLB 的二进制缓冲视图。
现有解码器、图像设置及嵌入资源边界保持有效。
持久文件格式、材质语义和公共接口保持当前定义。

该机制同时适用于原生角色与普通完整材质文档。
单图与合计压缩输入各至多为六十四 MiB。
图像顺序、四字节对齐和来源设置按既定索引对应。
读取失败或尺寸变化产生明确错误。
