# 参考光栅位置实施计划

参考视图提供光栅横纵位置及齐次尺度。
场景设备投影提供最终深度及屏幕偏移。
本单元将两类输入组合为公开渲染数学接口。
场景绘制和独立校准工具共用该契约。

## 接口与生命周期

实现归属 RenderCore 的参考投影模块。
配置来自已准备的参考相机视图。
上传结构占 112 字节，持有数值副本。
调用方拥有 GPU 资源及在途工作。

设备基础位置和最终位置表达屏幕变形。
组合保留最终设备归一化深度。
零齐次尺度或运算溢出时返回设备最终位置。
CPU 接口拒绝非有限输入。
