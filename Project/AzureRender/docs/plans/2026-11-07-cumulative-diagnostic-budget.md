# 诊断累计空间预算

## 规则

普通任务的占用与预计新增量合计至多为 2 GiB。
低空间诊断采用相同的累计核算方式，上限为 64 MiB。
诊断写入预留后，卷余量至少为 5 GiB。
自动清理按现有授权先预览，再分批应用完整路径清单。

现有诊断判断只检查单次预计新增量。
同一目录的连续写入需要计入既有占用。
修复归属为 `tools/artifact_budget.py` 的纯预算判断。
新建目录和既有目录继续共用该判断。

相关清理单元检查一并运行，使用临时夹具验证删除边界。
