# 参考算术主线集成

目标为验证公共屏幕可见量配置的主线接入。
实现来源为 `da56ac4`，主线接入为 `1ee5757`。
公共契约见[参考算术](../acceptance/nr/visibility-reference-arithmetic.md)。

## 范围与保护

变更属于 RenderCore、RHI 及其独立 GPU 工作流。
设备算术与版本化参考配置共享类型化输入。
主宿主沿用默认设备算术及现有场景装配。
原生完整区域的结果保持所属校准范围。

十三份用户原有文件按交接摘要保护。
配置查询通过 RHI 末尾接口及所属后端实现。
Vulkan 容量覆写位于 `VulkanRhi.hpp`。
受保护的实现文件保持原字节。

## 预算与判据

各配置构建预算六百秒，检查预算二百四十秒。
原生四帧预算六百秒。
任务预留 512 MiB，资产沿用既有共享路径。
全部重负载共用统一队列。

原四帧要求 RGB 零像素差。
实际 GPU 用例要求验证错误及释放残留为零。
CPU 八毫秒、GPU 16.6 毫秒及原画质门槛有效。
当前场景深度及完整头发颜色继续独立处理。
