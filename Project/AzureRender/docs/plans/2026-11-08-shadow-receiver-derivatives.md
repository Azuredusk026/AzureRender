# 阴影接收面导数计划

## 范围与契约

本单元归属于 RenderCore 的片元着色。
普通场景和角色材质共同使用级联阴影接收面。
导数属于当前片元调用，计算位置须满足控制流要求。
覆盖判定、材质退出、阴影采样及输出继续遵循各自契约。

基线提交为 `70c3e7f`，运行时生产输入为 `e6c5b3e`。
主程序、生产着色器、原始资产及用户差异保持冻结。
候选通过独立资源根目录加载，资产沿用原挂载。

## 已证实的范围

Intel 原时序用例在零历史输出一致性检查失败。
独立回读中，TAA 输入与零历史输出逐字节一致。
重复渲染的阴影深度与范围表一致，关闭阴影贡献后输出一致。
浮点诊断记录了零值、有效值与 NaN 之间的梯度差异。
这些观察将问题限定到接收面计算，具体驱动触发条件另行归因。

细粒度导数候选仍有重复渲染差异。
片元入口候选将接收面导数放在覆盖与材质分支之前。
该候选的重复 HDR 与最终输出均为零差异。
原 Intel 时序用例通过，原测试代码与门槛保持有效。

导数规则依据为 [Vulkan 着色规范](https://docs.vulkan.org/spec/latest/chapters/shaders.html)。
局部对照证明当前输入的执行位置影响，设备覆盖按实际结果记录。
