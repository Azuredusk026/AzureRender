# 加载会话的活动路径表

## 来源与契约

源码基线为 `26a73cb`。
路径解析的二十次局部均值为 3.353 毫秒。
候选归属于资源模块，宿主持有独立实例。
Player 与批量资产检视是两种使用方式。

路径表持有资源定位器的副本，按主线程调用。
每批只保留当前请求中的路径与解析结果。
新路径经过正式定位接口，重复路径共享结果。
成功后整体替换活动表，失败保留已确认状态。

资源加载、显式重载及宿主重开建立新的解析周期。
稳定输入复用当前周期的成功结果。
文件变化通过重载进入新的周期。
直接资源定位接口继续逐次检查文件。

## 实施与验证

先以真实临时文件验证复用、失效及失败恢复。
覆盖重复路径、活动表裁剪及两个独立资源根。
宿主在资源定位器安装及渲染器创建时重设路径表。
场景节点、材质及变换继续逐帧物化。

同输入控制交替执行正式定位和活动表解析。
全部解析输出逐字节核对，收益限于局部成本。
原生四帧与冻结参考逐像素比较。
相关机制检查及双配置构建按实际范围执行。

## 预算与通过条件

候选修改与短检二十分钟，两配置构建各十五分钟。
私有控制编译五分钟，原生控制五分钟。
原生四帧十五分钟，严格兼容门槛保持有效。
正式帧预算及环境资格独立验收。

## 当前结果

活动路径表通过双配置及原生四帧严格兼容。
同输入局部均值为 3.425 与 0.554 毫秒。
全部路径原字一致，失败恢复和双资源根检查通过。
