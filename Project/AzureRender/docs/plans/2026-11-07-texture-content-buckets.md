# 纹理内容分桶计算

## 依据与边界

当前场景材质哈希耗时约 7.49 秒。
该记录对应约六点三七 GB 解码像素。
逐字节乘法形成串行依赖。
本批目标为减少至少一半的局部哈希耗时。

实现归属 `SampledTextureCache` 内部内容分桶。
分桶覆盖全部输入字节，精确匹配决定资源复用。
上传参数、像素、纹理层级及所有权契约有效。
用途覆盖独立材质共享及带原生层级的图像。
