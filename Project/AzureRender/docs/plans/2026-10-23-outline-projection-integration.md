# 描边投影与深度壳接入计划

状态：公共机制交付验证通过，原生联合验收继续实施。
归属 NR6-C18，承接 C17 的边缘光覆盖缺口。
来源及已通过的数学见[深度来源验证](../acceptance/nr/outline-depth-source.md)。
正式阶段状态沿用 NR0 至 NR12 的联合门禁。

## 目标与边界

同一材质投影同时服务颜色轮廓和外扩深度壳。
主视口、辅助视口与 Player 共用资源和计算契约。
源身份、原始流及纹理转换归属离线内容工具。
实际颜色照明与投影覆盖分别验收。

基础材质表保持 192 字节和九个片元纹理槽。
基础顶点布局保持现行结构。
第二组 UV 作为可选具名流，由资产和渲染资源分别持有。
描边遮罩使用顶点阶段的独立输入。

## 公共材质契约

下列字段构成 `outlineSurface` 版本一。
缺省材质继续使用固定像素描边契约。
`silhouette-outline` 控制颜色壳的参与。
`depthPrepass` 独立控制外扩深度覆盖。

| 字段 | 类型及规则 |
| --- | --- |
| `schemaVersion` | 整数一 |
| `mode` | `view-scaled` |
| `width` | 形状倍率，零至八；零关闭扩张 |
| `minimumPixels` | 屏幕下限，零至八，缺省 0.5 |
| `depthOffset` | 有符号视深度偏移，负四至四米，缺省零；乘遮罩 G |
| `normalSource` | `geometry`、`tangent-uv1` 或 `tangent-octahedral-uv1`；缺省首项 |
| `depthPrepass` | 布尔，缺省假 |
| `maskTexture` | 可选纹理索引；缺省 R 为一、G 为零 |
| `uvScaleOffset` | 四个有限数，缺省 `[1,1,0,0]` |
| `color` | 线性 RGB，零至六十四；缺省使用公共轮廓颜色 |

遮罩消费 UV0、线性 RG、零级线性钳制采样。
外部图像元数据须与该固定语义相容。
`tangent-uv1` 显式消费 `TEXCOORD_1` 的两个有符号分量。
该消费者要求逐顶点有限值，范围为负一至一。

半球 Z 由平方和重建，当前切线帧提供世界方向。
八面体编码在同一可选流中表达完整球面方向。
原始方向需先转换到导入后的正交切线帧。
负半球、接缝和零分量各有独立数值检查。
缺失流、错误数量或不合法组合在上传前拒绝。
完整材质文档、资源依赖和重新导入共用解释链。
参数覆盖继续沿用 C15 的既定语义。

## 文件与所有权

| 文件或模块 | 职责 |
| --- | --- |
| `src/assets/GltfLoader.hpp`、`GltfLoader.cpp` | 材质类型、严格解析及可选 UV1 流 |
| 独立描边资产解析文件 | 遮罩所有权、采样和组合校验 |
| `src/runtime/MaterialDocument.cpp` 及转换工具 | 完整画像、UUID 依赖及编辑消费 |
| 渲染模块的描边资源对象 | 独立材质记录、可选流、遮罩及销毁顺序 |
| `src/scenes/CharacterSceneRenderer.*` | 当前快照、材质身份、提交和两类壳体绘制 |
| `shaders/outline_projection.glsl` | 共享 XY、视深度及平滑方向计算 |
| `shaders/outline.vert` 及深度输出着色器 | 读取当前姿态、材质记录、UV1 和遮罩 |
| `tests/CharacterRepairTests.cpp` 及 GPU 夹具 | 非法输入、独立图像、生命周期及实际模型 |

独立记录按稳定材质顺序读取。
版本一采用每材质 64 字节记录。
第二组 UV 使用每顶点八字节的独立只读区。
大小、偏移、整数地址和设备容量均需自动检查。

纹理容量分别核算顶点、片元及描述符集合。
固定和索引路径均声明完整阶段可见性。
同一资源对象集中处理初始化失败和在途退役。
材质或资产错误通过公共诊断关联来源。
