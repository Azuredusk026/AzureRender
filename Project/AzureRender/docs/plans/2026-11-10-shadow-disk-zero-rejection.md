# 阴影圆盘零权重排除

目标为减少圆盘过滤中已确定为零的权重计算。
当前四点权重逐项计算距离、平方根及边界斜坡。
隔离控制先核对零结果，再核对实际着色成本。
生产采样、权重和视觉门槛保持原定义。

## 机制与范围

候选取得四个采样点中最小的横纵绝对距离。
仅在其平方距离超过圆盘范围及保守余量时返回零。
其余输入执行原始四点权重运算。
保守余量用于隔离浮点舍入边界。

实际输入覆盖一至十六的过滤半径。
查询包含原循环锚点、分数坐标及圆周邻域。
GPU 原始函数作为设备位值参考。
所有被排除的分量必须与原函数逐位一致。
