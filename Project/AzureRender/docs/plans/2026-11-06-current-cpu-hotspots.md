# 当前原生 CPU 热点定位

## 来源与交付物

源码基线为 `2fad7ef`。
当前短时 CPU 工作 P95 为 23.91 毫秒。
完整 CPU 目标为八毫秒，状态保持未通过。
原生负载与设备条件见[阴影验证](../acceptance/nr/depth-only-shadow.md)。

本单元采样当前实际 Player 的稳态原生调用栈。
输出记录采样时间、符号、调用位置与来源指纹。
采样运行只用于定位，性能结论由正式计时持有。

## 观察与预算

输入沿用同一联合项目、固定步长与一千零八十像素高度。
采样从两份帧资源完成初始化后开始。
最多十二次采样，单次命令期限三十秒。
原生宿主持有六百秒总期限。

定位预算十分钟，观察期间源码与运行产品保持一致。
候选选择以重复出现的生产调用位置为依据。
单个调用栈用于定位，耗时归因需对应控制或计时。
正式画质、双设备和 CPU 帧预算保持有效。

实际观察与适用范围见[采样记录](../acceptance/nr/current-cpu-hotspots.md)。
