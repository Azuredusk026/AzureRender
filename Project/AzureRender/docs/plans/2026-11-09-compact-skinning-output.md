# 紧凑蒙皮输出

状态：布局优化通过，正式帧预算待通过。

## 范围与依据

实际蒙皮通道约为 0.60 毫秒。
输出还由快照、阴影、描边和最终绘制共同读取。
下游通过存储缓冲读取形变后的位置、法线和切线。
原始网格属性由独立顶点输入持有。

输出契约采用十个单精度字，共四十字节。
字段依次为三维位置、三维法线及四维切线。
切线第四分量保留源值的位模式。
形变算术、输入布局及提交顺序保持原有契约。

帧槽继续持有独立输出及静态内容有效性。
扩容、取消和提交沿用现有生命周期规则。
CPU 分配、计算写入与三个读取程序同步使用该布局。
资产导入及磁盘缓存格式保持现有版本。

## 实施与验收

1. 复现公共布局契约缺失。
2. 集中实现分配、计算输出和下游读取布局。
3. 检查独立实例、形态权重、规范化及邻接范围保护。
4. 完成双设备、双配置检查后核对严格原生四帧。
5. 布局及指令写入门槛满足后，执行一次成本对照。

单顶点输出空间目标为减少至少六成。
原生图像继续要求 RGB 零差异。
整体画质、CPU 八毫秒及 GPU 16.6 毫秒门槛有效。
所有临时内容及精简证据保存在 D 盘项目目录。
