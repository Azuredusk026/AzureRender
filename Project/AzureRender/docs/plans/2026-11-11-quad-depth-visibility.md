# 四像素组深度可见性核验

## 目标与来源

核对现有场景深度副本提供的遮挡筛选依据。
源码基点为 `88d84fb`，候选保存在任务目录。
前项透明裁剪控制的六附件核对通过，效率未准入。
本项独立检查深度遮挡，原始裁剪及着色表达式保留。

## 资格与执行

仅主颜色的非普通透明裁剪材质进入候选判断。
节点透明度须恰为一，采样坐标位于副本范围内。
副本深度须为有限正数，当前深度保留相对安全余量。
整组没有有效非辅助可见片元时结束着色。

存在可见片元时，整组执行原始接收及着色计算。
副本沿用现行渲染图的采样依赖。
私有设备已启用四像素组及最大重汇合特性。
十份程序通过编译及 Vulkan 1.1 中间码验证后回放。

独立深度控制与所选接收状态、默认视图进行一次组合控制。
组合保留各机制的独立结果及实际相机参数断言。
完整材质范围按相同原始输入和附件门槛评估。

## 验收与预算

六份附件逐字节一致，全部事件参加交替计时。
参考和候选各自预热十六次，切换前清空替换关系。
热点须占四分之一帧成本，且减少至少 20%。
整帧节省 GPU 三毫秒也可进入原生核验。

定位预算十分钟，实现与短检预算二十分钟。
失败结果保留原始来源及单独归因。
原始四帧、正式帧预算及完整画质按所属条件验收。
