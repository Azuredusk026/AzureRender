# 主 UV 绑定实施计划

目标是通过公开材质输入选择主 UV 足迹。
公共梯度依据见[梯度助手验收](../acceptance/nr/material-uv-gradients.md)。
既有失败边界见[候选验收](../acceptance/nr/material-mirrored-uv-candidate.md)。
本单元以具备确定性证据的接收循环为验证基线。

## 数据与生命周期

版本二材质通过 `mirrored-coarse-uv` 声明策略。
场景深度、阴影、轮廓及主表面使用对应梯度程序。
独立程序族持有显式片元四像素组能力要求。
默认程序族及材质布局保持各自既有契约。

渲染器在创建材质管线的首个程序模块前核对设备支持。
已识别材质类别参与有限位集索引。
未知类别在索引前报告输入错误。
管线、程序及在途工作沿用所属场景的所有权。

- [x] 修正类别边界并通过十二项输入拒绝检查。
- [x] 将设备预检安排在材质管线的首个程序模块创建前。
- [x] 引入已通过门禁的接收循环修正来源。
- [x] 构建两配置并核对程序清单及族容量。
- [x] 核对两配置材质类型、管线及保存重开。
- [x] 检查双设备公开覆盖、阴影及取样正控制。
- [x] 检查缺失程序的错误与资源释放。

- [x] 同步文档及证据，核对暂存后创建独立提交。

## 验收范围

接收循环的确定性修正是 GPU 批次的前置输入。
独立工具证明足迹策略确实改变所选纹理层级。
公开材质同时验证索引与固定描述符路径。
保存重开须保留特性及原有材质参数。

程序集总数至多为 1024。
全部原画质门槛及 Intel 九十六处深度失败保留。
重试依据、输入、程序摘要与设备结果共同归档。
失败候选按单元规则隔离，后续任务继续推进。

结果见[公开材质验收](../acceptance/nr/material-primary-uv-policy.md)。

单元探索预算三十分钟，构建预算二十分钟。
GPU 批次预算八十分钟，按四张图分块持有队列。
产物预计至多 256 MiB，各块分别记录结果。
