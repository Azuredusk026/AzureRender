## 路径选择

| 路径 | 首项验证 | 采用条件 | 切换条件 |
| --- | --- | --- | --- |
| 现有完整工具 | 核对发行包与实际对象读取 | 能读本机版本且输出依赖 | 分发不可得或失败层已定位 |
| 补全公开工具 | 确定容器或序列化扩展接口 | 缺口局部且接口稳定 | 适配范围超过独立转换成本 |
| REA 辅助独立读取 | 追踪游戏资源读取函数 | 可验证输入、输出和字段含义 | 静态证据不足以确定变换 |
| 运行时辅助恢复 | 观察已加载资源与读取边界 | 能保留对象身份及资源语义 | 只能取得画面或缺少关键依赖 |

优先验证成本最低、语义保留最完整的路径。
REA 用于回答具体格式问题，并提供实现依据。
运行时调查按已定位函数缩小观察范围。
图形帧抓取可辅助校对材质与几何。
动画、骨架、表情和场景层级需各自验证。

## 文件职责与输出契约

以下路径均相对于 `Project/AzureRender/`。

| 文件或目录 | 职责 |
| --- | --- |
| `tools/probe_resource_reader.py` | 保留工具发现及环境探针 |
| `tools/endfield_native/inventory.py` | 容器分组、头部样本与版本清单 |
| `tools/endfield_native/reader.py` | 统一读取接口与诊断 |
| `tools/endfield_native/adapters/` | 依据证据选定的读取实现 |
| `tools/endfield_native/export.py` | 对象选择、依赖闭包与导出 |
| `tools/test_endfield_native.py` | 格式边界与依赖回归 |
| `tools/blender/export_scene_exchange.py` | 复用已有场景交换入口 |
| `docs/research/endfield-validation/native-findings.json` | 结论、来源、置信度和未知项 |
| `docs/acceptance/ev/native-assets.md` | 原生资产验收结果 |
| `build/runs/<任务目录>/` | 探针、REA 证据及短期输出 |
| `assets_private/endfield_native/` | 本机原资产和派生产物 |

接口在文件格式得到证实后实现。
`inventory(root) -> Inventory` 返回路径、大小和格式分组。
`read_objects(source, options) -> ReadResult` 返回对象与依赖。
`export_selection(ids, destination) -> ExportResult` 输出依赖闭包。

对象身份包含源文件哈希、容器项和对象 ID。
读取结果包含类型、引用、有效载荷位置和支持状态。
诊断包含阶段、源文件、偏移及失败原因。
导出清单包含来源、工具版本、损失和输出哈希。

## 重点失败条件

| 条件 | 验证归属与预期 |
| --- | --- |
| 索引存在但资源未下载 | N0 登记缺失文件与覆盖范围 |
| 截断、错误长度或异常偏移 | N1 拒绝越界并报告源位置 |
| 工具支持其他游戏版本 | N1 明确版本拒绝或验证兼容性 |
| 对象引用跨容器且 ID 重复 | N2 按完整身份解析依赖 |
| 肌肉曲线与骨骼曲线混用 | N2 验证 Avatar 绑定和采样结果 |
| 表情含材质与骨骼组合驱动 | N3 分别验证各驱动通道 |
| 场景共享实例与镜像变换 | N4 保留实例及正确空间关系 |

## 推进规则

每次失败都记录假设、输入、结果和下一验证点。
重试需要新的证据、输入或实现变化。
一路受阻时，按上表评估其他可行路径。
读取器缺失首先作为技术调查项处理。

引擎扩展由已取得资产暴露的兼容需求触发。
每项扩展进入现有通用模块，并验证其他使用场景。
当前阶段优先完成原资产获取与最小播放闭环。
无法自行取得的关键输入才作为外部阻塞报告。
