# 对象接收坐标与精度核对

## 输入与目标

生产入口为 `18b66cf`。
本单元处理 Q1 头发区域中对象阴影接收输入的差异。
原门槛为 17017 个像素及每通道一字节误差。
已保存的原生深度、法线、矩阵及可见量作为只读输入。
记录格式和参考范围见[采样边界](../acceptance/nr/hair-sampling-boundary.md)。

原生重建位置处于约三百米的绝对坐标。
当前接收位置采用原点附近的坐标及半像素偏移。
坐标加回原点、深度重建、法线解码及投影的舍入边界分别核对。
浮点乘加按原程序的指令顺序建模。
实际 GPU 结果用于判断 CPU 模型的适用范围。

## 执行

- [x] 核对源文件、深度、法线、矩阵及四处冻结位置。
- [x] 比较相对坐标与绝对坐标下的浮点控制。
- [x] 使用原生输入核对独立 GPU 接收与过滤模型。
- [x] 根据已证实的输入差异确定公共机制的实施范围。
- [x] 保存来源、结果与剩余条件。

CPU 数值控制与实际 GPU、图像门禁分别记录。
只有完整输入关系得到验证后，才实施生产配置或渲染机制。
正式画质、CPU 八毫秒及 GPU 16.6 毫秒标准持续有效。

## 预算

任务预留三十二 MiB，位于 D 卷，完成后保留一天。
历史输入采用活动引用，原始资产按既有路径读取。
GPU 夹具只上传所需深度、法线和常量，结果保持小型数值记录。
单次编译至多一百八十秒，功能进程至多一百二十秒。

## 结果与实施方向

四处控制点复现原生可见量，完整遮罩的 17017 处均在一字节内。
实际 `R8G8_UNORM` 图形附件转换后，17017 处全部逐字节一致。
计算结果与显式整数舍入之间的 105 处差异得到独立附件对照。
公共机制采用深度重建、类型化法线及对象身份、完整精度计算与八位附件。
当前逐材质接收路径的替换须通过独立机制及场景集成阶段。
完整头发颜色及整体画质继续待验收。
详细结果见[接收模型核验](../acceptance/nr/object-receiver-input-model.md)。
