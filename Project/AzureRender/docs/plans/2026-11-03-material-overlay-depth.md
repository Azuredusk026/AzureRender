# 材质覆盖层深度计划

## 目标与依据

状态：执行中。
公共深度策略已通过[专项验收](../acceptance/nr/material-overlay-depth.md)。
来源材质的内容接入与完整区域验证继续执行。
本项属于 Q1，联合画质继续验收。
有效区域 SSIM 门槛为 0.95。
中位亮度误差门槛为 10%。

原生服饰二的指定片元包含额外特效贡献。
其主纹理为白色，噪声纹理参与颜色及覆盖率。
几何法线决定视角渐变，采样使用来源 UV。
来源证明保存在本轮材质阶段核验目录。

## 公共契约

分层无光照材质声明 `depthCompare`。
合法值为 `less` 和 `less-or-equal`。
缺省值为 `less`，深度写入保持关闭。
透明混合、加法混合及场景雾共享该契约。

配置由资产解析器校验并随材质值持有。
渲染器按需创建管线，并在卸载时释放。
片元程序、采样布局及顶点格式保持现行契约。
同平面发光覆盖和工具标注共同验证复用。

## 执行与验收

1. 核验来源纹理、常量及片元合成顺序。
2. 添加解析、错误输入与实际绘制的失败用例。
3. 实现深度策略及管线资源所有权。
4. 验证同平面覆盖、遮挡及缺省输出。
5. 验证两种混合、描述符路径及场景雾。
6. 核验保存重开、卸载及受影响既有测试。
7. 更新运行文档、验收记录及来源清单。

内容转换通过追加覆盖图元表达来源特效。
覆盖图元共享位置、骨骼和动画数据。
来源 UV 通过显式转换绑定到覆盖层。
转换器记录输入、输出及采用的来源参数。

内容接入后核验冻结姿态的完整有效区域。
联合候选继续验证动作、反射和遮挡。
服饰一、头发、皮肤和场景光照各自持有验收。
随后按总计划接续 Q2、Q3 及 Q4。
