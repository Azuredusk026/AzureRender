# 材质槽位元数据读取计划

日期：2026-10-25。
范围为 NR8-V2 的完整材质接入与启动成本。
主场景候选保留九条动画，并绑定十三份完整画像。

## 职责与数据

Assets 提供源模型材质槽位的只读查询。
查询读取 glTF 的材质名称及显式身份。
身份分配复用 `materialSlotIds` 的现行规则。
完整几何、纹理、骨架和画像由模型准备阶段验证。

JSON 文档与输入流由当前调用持有。
运行时按模型路径保存当前解析中的槽位列表。
编辑事务及命令行工具使用同一查询。
源文件变化后的查询读取当前文件内容。

## 实施与验收

- [x] 核对具名、匿名、重复名称及隐式材质的身份。
- [x] 覆盖显式身份冲突、非法头部及截断输入。
- [x] 验证材质元数据查询的独立读取范围。
- [x] 接入场景绑定、编辑操作与命令行检查。
- [x] 双配置构建并回归相关项目、文档及槽位检查。
- [x] 在真实九动画角色上测量读取耗时。
- [x] 复核完整画像的主场景及可玩入口。

模型准备的失败诊断和发布事务保持原有门禁。

独立阶段通过后同步证据并提交。
