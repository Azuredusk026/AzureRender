# 材质管线朝向需求

日期：2026-11-09。
状态：实现及受影响验证通过，正式帧预算待验。

## 目标与归属

角色渲染器按加载后的材质集合创建类别管线。
需求分别记录普通材质及各材质类别。
每种单双面需求均覆盖正常与镜像朝向。
镜像变换、节点透明度和交换链重建保持有效。

该机制适用于独立模型与多资源场景。
材质集合与 GPU 资源共享加载生命周期。
场景复用以资源布局身份核对材质绑定。
资源销毁继续由渲染器持有，失败沿现有清理路径。

## 实施步骤

- [x] 增加独立空后端回归，证明未使用朝向被预建。
- [x] 按材质组收集朝向需求并约束创建循环。
- [x] 核对两配置构建及受影响材质场景。
- [x] 集中核对原四帧、管线数与加载记录。
- [x] 保存结果，收尾受管目录并提交阶段。

## 验证门槛

单种单双面类别应仅创建两个朝向。
混合类别保留四个朝向。
关闭面剔除时仍保留镜像正面定义。
普通与类别路径均覆盖透明度及重建。

原四帧要求 RGB 差异为零。
既有六百七十五份主着色器保持逐字节一致。
本项以管线创建数量和初始化耗时评估效率。
每帧 CPU 与 GPU 预算继续独立验收。

## 基线与参考

最近一次原四帧加载的管线阶段为 162406 毫秒。
该阶段还包含运动资源及场景状态初始化。
图形与计算管线合计请求 645 次，缓存命中 507 次。
材质上传阶段为 13452.3 毫秒。

参考 Khronos 的[管线管理样例](https://docs.vulkan.org/samples/latest/samples/performance/pipeline_cache/README.html)。
项目沿用有容量预算的现有管线缓存。
本项在加载阶段收敛确定无需求的材质组合。

## 实施结果

两配置的二十四组朝向与重建组合均通过。
原四帧及六百七十五份主着色器保持逐字节一致。
完整场景的管线请求减少八十八次，约为 13.64%。
详见[验证结果](../acceptance/nr/material-facing-demand.md)。
