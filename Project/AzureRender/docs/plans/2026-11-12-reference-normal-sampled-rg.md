# 参考法线采样后重建

参考场景的法线生产通道支持显式采样 RG 重建。
材质画像通过 `referenceNormal` 声明法线编码。
参考片元从标准法线纹理采样红绿分量，重建正向 Z，并使用当前插值切线帧。
背面方向由参考光栅朝向决定。

## 来源与范围

基线为 `98e6c2c`。
原生帧 10401 的事件 377 在采样后执行 RG 解码和切线空间换算。
事件 377 的冻结区域为 16,629 个位置，完整接收为 49,384 个位置。
每通道继续执行一字节门槛。
来源见[服饰接收法线绿色方向](../acceptance/nr/cloth-receiver-normal-y.md)。
