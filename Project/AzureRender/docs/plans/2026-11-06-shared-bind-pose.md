# 静态实例共享绑定姿态

## 当前状态

实现已进入受影响验证。
两配置各三十二项 CPU 检查及原生四帧严格兼容通过。
二十四项 GPU 检查中，二十二项通过。
Intel 时间解析的既有失败和正式帧预算继续保留。

实际每帧有八百六十个实例共享加载姿态。
局部复制及释放的同帧控制已记录。
结果及限制见[验证记录](../acceptance/nr/shared-bind-pose.md)。

## 目标与依据

当前 CPU 阶段采样的姿态选择均值为 2.34 毫秒。
来源为提前深度候选的私有插桩版本。
同帧有八百六十个实例复制加载资源的绑定姿态。
本单元验证静态实例共享只读姿态的成本与兼容。

所属模块为场景渲染器的实例姿态准备。
加载资源持有不可变的绑定姿态。
实例通过共享所有权持有本帧读输入。
动态动画、表情及形变修改拥有独立姿态。

## 所有权与边界

共享姿态按加载资源身份索引。
每个实例保留独立模型矩阵、形变参数及 GPU 区间。
需要写入姿态时先取得独立可写值。
拾取、运动、阴影与透明排序消费同一只读姿态。

实例数据和加载缓存分别持有共享所有权。
卸载释放加载缓存，实例引用按所属准备周期持有。
重载按新资源创建内容，帧记录沿用所属快照契约。
录制、取消及帧槽复用保持现有资源完成规则。

## 验证与预算

先验证同资源静态实例的共享读取及动态隔离。
失败测试必须经过实际场景渲染器的准备入口。
两种描述符路径覆盖动画、形变、重载和场景复用。
逐帧分配检查验证静态骨架规模的影响。

构建和受影响检查覆盖 Release 与 Debug。
原生四帧及全部五百三十五份程序保持冻结字节。
蒙皮、运动及时间视图按相关设备范围核验。
