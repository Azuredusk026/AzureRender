# glTF 采样器接入计划

阶段归属为 NR6-C15-S1。
输入为物流环带的真实硬件采样与普通材质加载路径。
普通材质读取图像导入设置，专用图层另有采样器映射。
本阶段统一来源映射及覆盖规则。

## 已知输入

原版环带使用线性缩放过滤及最近层级过滤。
图像 mip 偏置为负一，各有十一层来源载荷。
单独指定最近层级过滤后，十处颜色通过原有预算。
该输入作为普通材质采样器接入的真实回归。

现有图像设置声明过滤、寻址、mip 和各向异性。
RHI 采样器描述提供过滤及层级选择。
独立放大与缩小过滤须核对类型和后端支持。
字段及兼容规则通过失败夹具先行固定。

## 所属模块

| 责任 | 位置 |
| --- | --- |
| 公共图像与采样设置 | `src/assets/TextureImportSettings.*` |
| glTF 来源与材质绑定 | `src/assets/GltfLoader.cpp` |
| 描述符、后端及缓存身份 | `src/rhi/`、`src/render/` |
| 类型及元数据回归 | `tests/TextureImportContractTests.cpp` |
| 普通材质导入回归 | `tests/TextureMaterialImportTests.cpp` |
| 同图像复用回归 | `tests/SampledTextureCacheTests.cpp` |

图像解码与材质绑定分别持有数据及采样语义。
公共采样描述表达后端需要的有限状态。
图像元数据的显式覆盖沿现有解析接口完成。
专用表面的固定采样约束继续接受校验。

## 实施与验收

1. 定位公共声明、后端实现及相关测试。
2. 核对六种缩小过滤、两种放大过滤和三种寻址。
3. 固定缺省、非法索引及元数据覆盖的失败用例。
4. 补齐公共描述及 glTF 采样器映射。
5. 将新增状态纳入采样器缓存键和释放检查。
6. 验证同图像的不同材质绑定及双配置 GPU 输出。
7. 回归现有专用材质、主场景及真实环带。
8. 同步格式、来源、可视记录及独立提交。

GPU 材质、相机和着色模块的变化按实际需要说明。
新增状态以采样语义为界，游戏身份留在项目内容中。
环带动态时钟及整体 AA 门禁沿各自任务执行。
