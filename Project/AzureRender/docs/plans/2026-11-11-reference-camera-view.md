# 参考相机视图实施计划

目标是统一参考投影、拾取射线及保守剔除的输入。
依据为[实际主坐标来源](../acceptance/nr/actual-geometry-uv-source.md)。
实现归属渲染数学与参考深度配置适配。
当前工作树逐项执行本页任务，独立验收后提交。

## 文件与接口

`ReferenceCameraView.hpp` 声明版本一视图及准备类型。
视图包含坐标帧、参考投影、尺寸、深度约定及纵轴翻转。
`PreparedReferenceCameraView` 持有校验后的配置副本及双精度逆矩阵。
矩阵准备完成后，查询共用不可变状态。

`clip` 按公开坐标帧和参考投影的单精度边界计算。
`project` 返回连续像素坐标及设备深度。
`unproject` 返回声明深度处的世界位置。
`pickRay` 的原点位于近裁剪面，方向指向可见深度区间。

`intersectsBounds` 核对六个齐次裁剪平面。
边界误差按单精度运算幅度保守扩张。
相交及数值不确定的包围盒保持可见。
尺寸范围与公开深度生产一致，为一至八千一百九十二。

`ReferenceDepthConvention.hpp` 持有共享深度约定。
该类型保持现行名称及枚举值。
`ReferenceCameraDepth.hpp` 从准备后的视图装配版本二深度配置。
CPU 查询及 GPU 深度输入使用相同的坐标帧和投影参数。

矩阵须可逆，条件估计至多为一万亿。
输入版本、保留值、数值及包围盒范围在使用前核对。
视图准备与查询持有纯 CPU 状态。
GPU 资源和在途工作沿用深度生产器的契约。
