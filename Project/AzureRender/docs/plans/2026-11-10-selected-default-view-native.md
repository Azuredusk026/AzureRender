# 所选状态与默认视图原生验证

目标为核定组合的原生画质及实际帧成本。
来源为 `264dd76` 的隔离组合结果。
受检热点约占 57.66%，局部减少约 21.28%。
六个实际附件逐字节一致。

## 范围与交付

候选程序保存在独立任务目录。
常规材质程序使用已核对的所选级联状态。
普通主颜色使用既有默认视图管线入口。
该实验固定输入符合已核对的视图资格。

生产采用需要公共资格选择及动态回退契约。
本项先判断原生兼容及有效净收益。
临时构建选项及宿主在采集前恢复默认状态。
隔离宿主、程序及输入记录独立来源。

## 验收步骤

- [x] 编译全部受影响程序并执行 SPIR-V 校验。
- [x] 运行所属录制、生命周期及原始四帧检查。
- [x] 核对四帧 RGB 零差和 PNG 摘要一致。
- [x] 核对同步验证、卸载计数及实际候选选择。
- [x] 画质通过后执行短时三进程成对计时。
- [x] 根据兼容和净收益决定正式接入范围。

GPU 均值须减少至少 2%，且达到两倍参考漂移。
受影响场景区间均值须减少至少 5%。
参考漂移上限为 3%。
CPU 八毫秒、GPU 16.6 毫秒及原画质门槛保持有效。

## 预算

定位十分钟，实现及短检二十分钟。
宿主构建及私有程序编译预算八百秒。
严格四帧预算六百秒，计时每端三百秒。
任务预留九百兆字节，全部重负载使用共享锁。

## 结果与接续

四份 PNG 摘要一致，RGB 零差，验证与卸载通过。
GPU 均值减少约 12.64%，场景区间减少约 12.91%。
参考漂移约为 2.45%，短时效率条件通过。
生产接入按实际视图参数选择，并保留动态回退。
GPU P95 约为 17.287 毫秒，正式预算继续验收。
