# 产物维护技能实施计划

## 交付

目录维护属于开发工具，运行时验收保持所属范围。
本机技能通过项目脚本执行创建、封存、巡检及每日清理。
项目数据与必要恢复包均保存在项目目录。

## 空间模型

普通任务完成后保留一天，必要诊断选择三天或七天。
单任务上限为 2 GiB、10000 个文件，受管池上限为 16 GiB。
精简证据每任务至多 8 MiB，总池 2 GiB，保留三十天。
显式必要恢复包在项目内保存，总池 8 GiB。

资产、程序与着色器通过已有路径引用。
任务保存新增结果、源码差异、命令和输入锁。
普通生成文件在保留期后直接回收。
完整恢复包只用于显式声明的必要唯一输入。

## 自动维护

轻量状态查询读取索引与目录根标记。
每日维护最多处理十个受管任务，预算一百二十秒。
冗余缓存使用一次性清单及存活原始资产证明。
每天至多清理十 GiB，当前工程缓存继续保留。

活动构建、测试和采集期间延后维护。
Git 文件、嵌套工作树、活动引用及审查拒绝目标持续保护。
纯维护执行工具检查及主产物摘要核对。
正式性能、画质及长跑按所属开发阶段安排。
