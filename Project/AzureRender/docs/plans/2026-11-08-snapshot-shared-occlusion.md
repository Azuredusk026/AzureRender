# 快照预填与多阶段遮挡消费

本单元入口为 `27d2160`。
候选复用快照与主通道共有的预填覆盖。
同一深度层级预期供快照颜色、主预填及主颜色消费。
现有主通道深度复用保持受检参考。

## 候选覆盖契约

快照预填的公共部分先生成深度。
场景染色及乘法合成保留所属的后续预填。
两部分合计执行原有快照预填几何一次。
颜色绘制前加载并补齐原有深度。

层级只采用同时满足主预填规则的覆盖。
同一相机、投影、视口、深度格式及采样数为前置条件。
阴影、描边、运动及半透明各自保留消费资格。
公共部分不满足条件时，使用受检的主深度路径。

## 工作量准入

先读取已有捕获的几何绑定及合格历史计时。
按缓冲、索引区间、实例及绘制参数对应阶段。
读取快照颜色之前的实际深度，核对保守覆盖。
新增 GPU 计时及完整场景采集在此阶段保持待执行。

成本核对区分快照颜色、主预填及已有主颜色收益。
当前已取得的主颜色收益计入参考。
增量工作量不足时，保存分析并推进独立任务。
整体画质与原帧预算保持有效。

## 预算与资源

初始分析预算为十分钟，必要只读重放至多四分钟。
通过准入后，实现预算为九十分钟，所属检查为二十分钟。
本次预留 64 MiB，普通产物保留一天。
捕获、资产与主构建通过原路径引用。

候选沿用 RenderCore 的通道拆分与保守剔除机制。
宿主与渲染器分别持有所属图像。
全部消费退役后释放通道、层级及命令资源。
临时内容和必要证据均保存在项目目录。

## 分析结果

已有捕获的 1439 项绑定及快照预填深度读取完成。
新增两阶段的乐观消除上界约为 0.3210 毫秒。
该值约占目标组的 4.44%，未达到本批门槛。
候选保持提案状态，生产使用已受检的主深度实现。
