> 状态：生效

## 目标与范围

完成当前 R3 实现的性能预算、功能回归、发布验证和阶段提交。使用当前 Windows 主机的 MSVC 构建，所有证据记录源码版本、设备、驱动和采样条件。阶段状态由实际验收结果决定。

## 执行步骤

- [x] 重建 Release，确认工具链、设备和运行路径。
- [ ] 满足多资源预算。在独占 GPU 条件下采样 32 个独立资源、300 帧、三轮；验证 CPU 录制改善至少 5%，GPU 平均时间增长至多 5%。
- [x] 采样 256 实例、300 帧、三轮；验证并行 GPU 路径 CPU 录制低于 0.5 ms，GPU 平均时间低于 3 ms。
- [x] 对失败项定位分段耗时，以行为测试或性能基线验证定向修复。
- [x] 执行 Debug 完整 CTest 与 Release 发布门禁，覆盖五路径、透明、固定描述符和三场景。
- [x] 同步总计划、实施清单、运行时说明、README、变更记录及验收证据清单。
- [ ] 满足全部门禁后创建阶段 Complete 提交。当前实现与验收进展单独提交。

多资源 CPU 性能预算失败，R3 保持 Active。当前结果见 [阶段验收](../acceptance/r3/2026-10-03.md)。

## 证据与边界

验收证据保存到 `docs/acceptance/r3/evidence/`。原始性能与测试产物保存在对应构建目录。RTX 2060 的历史采样与当前 RTX 4060 Laptop GPU 采样分别标识，跨设备数据用于各自环境的验收说明。

录制快照持有只读逐帧数据；加载期资产和 GPU 句柄由资源所有者保持到对应 fence 完成。串行和并行路径执行相同渲染工作与状态缓存优化，图像对照要求逐帧哈希一致。
