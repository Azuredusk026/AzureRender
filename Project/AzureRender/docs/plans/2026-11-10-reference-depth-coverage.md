# 深度透明覆盖与剔除

状态：公共契约及 NVIDIA 原生来源通过，Intel 来源待修正。
依据为[几何深度与可见量](../acceptance/nr/geometry-depth-visibility.md)。
本单元扩展 RenderCore 的公开深度生产机制。

## 表面契约

`ReferenceDepthSurface` 为版本一表面描述。
每个绘制指定正面方向及剔除规则。
透明覆盖通过可选的 `ReferenceDepthAlpha` 声明。
既有绘制默认使用双面不透明表面。

覆盖输入借用 UV 缓冲、纹理视图及采样器。
参数定义采样通道、阈值和纹理层级偏移。
有限数值、布局、版本及句柄均在录制前校验。
纹理覆盖使用小于阈值的片元丢弃规则。

`ReferenceDepthShaders::loadMasked` 装配覆盖程序。
`load` 保持既有不透明装配契约。
每帧槽至多包含一百二十八个覆盖绘制。
管线及描述符由深度生产器持有。

结果见[深度透明覆盖验收](../acceptance/nr/reference-depth-coverage.md)。
NVIDIA 的 17017 个原生深度及可见量均精确一致。
Intel 的 97 处可见量超差按设备来源继续修正。

位置和 UV 均由几何生产者提供。
借用资源的生产依赖由调用方发布。
帧槽退休及销毁遵循既有深度通道契约。
输入契约同时用于原生来源和独立遮挡工具。

## 范围与预算

来源采集预留四分钟，定位预留十分钟。
同一问题探索预算为三十分钟。
双配置构建各预留九百秒，设备检查预留四分钟。
默认四帧预留六百秒，任务产物预留一百二十八 MiB。

原生壳层位置按所属几何生产规则继续接入。
深度浮点间隔用于诊断，实际可见量持有判据。
完整遮罩与一字节门槛保持既定要求。
整体状态保持 `failed-user-review`。
