# 计算反射视图控制流核对

目标为核对固定视图候选的精度边界。
源码基点为 `0e0833e`。
依据为[计算反射材质记录](../acceptance/nr/computed-material-view.md)。

## 范围与假设

既有失败尚未确定具体浮点变换。
当前精确累加机制已通过普通材质的四帧核对。
本单元将固定视图限定于该材质范围。
照明分量组合沿用现有精确边界。

候选位于受管任务的独立着色目录。
基准宿主、原有着色程序及项目资产保持冻结。
主 Release 临时启用既有隔离管线入口。
实验限定场景照明、默认效果及计算反射。
普通材质以专用常量零为真作为程序边界。

## 执行步骤

- [x] 核对旧候选的控制与数值替换位置。
- [x] 生成独立控制流程序，并执行静态校验。
- [x] 核对当前输入资格、来源及严格四帧。
- [x] 通过后集中执行短时成对计时。
- [x] 根据精度和有效收益决定运行时接入。
- [x] 封存证据，同步状态并继续独立任务。

## 预算与判据

定位预算十分钟，候选与短检二十分钟。
宿主及所属程序构建预算六百秒。
私有控制流程序的编译预算一百二十秒。
严格四帧预算六百秒，计时每端三百秒。
任务空间预留 512 MiB。

既有匹配绘制约占捕获 GPU 成本的 50.5%。
既有控制减少约 20.07%，保持历史范围。
本轮数值边界变化构成精度问题的新候选。
实际收益及当前适用范围以本轮结果为准。

四帧的 RGB 差异像素必须为零。
前后参考的 GPU 均值漂移至多为 3%。
整帧均值须减少至少 2%，且达到两倍参考漂移。
受影响场景区间的均值须减少至少 5%。
热状态和交流供电另按实测记录。
CPU 八毫秒、GPU 16.6 毫秒标准保持有效。
候选失败时保留来源，生产使用受检路径。

## 本轮结果

实际启用八条候选管线，原四帧 RGB 零差。
整帧 GPU 均值名义减少约 2.46%。
场景区间减少约 2.94%，效率门槛未通过。
两种主配置的默认隔离选项均为关闭。

恢复后的两项录制检查通过。
两配置的源码及产物来源核对通过。
706 份既有常驻程序保持原摘要。
