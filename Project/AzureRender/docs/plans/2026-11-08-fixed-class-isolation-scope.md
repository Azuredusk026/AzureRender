# 固定材质类别的隔离范围

本单元入口为 `437e0f3`。
生产继续使用已交付的普通材质隔离策略。
本单元读取既有捕获及当前实际专用常量。
完整资产与原始捕获沿用已有路径。

## 范围与准入

首先按实际类别、程序和阶段汇总历史成本。
实际专用常量须与当前运行清单一致。
固定类别与动态材质入口分别记录。
当前生产程序与历史成本的适用关系单独核对。

静态候选保留全部现行材质专用常量。
只核对固定隔离零带来的编译资源差异。
队列提交及新增 GPU 计时次数均为零。
功能接入继续遵守原热点和收益门槛。

定位预算为十分钟，必要静态查询为二十分钟。
任务预留十六 MiB，普通产物保留一天。
本单元按范围证据决定后续实现资格。
原画质、设备及完整帧预算保持有效。

## 范围结论

固定类别范围为 129 次绘制及约 3.784 毫秒。
其历史事件占比为 22.67%，未达到独立热点门槛。
本单元的静态查询、构建及原生采集次数均为零。
