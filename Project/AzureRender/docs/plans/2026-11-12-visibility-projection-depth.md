# 对象可见量深度方向

图集附件和各对象的接收投影分别具有深度方向。
图集方向定义纹素到统一反向深度的转换。
对象方向定义投影结果到统一反向深度的转换。
对象方向缺省时采用图集方向。

## 核对项目

- [x] 保存缺少逐记录深度方向的失败结果。
- [x] 验证正向与反向记录共用同一图集。
- [x] 验证图集切换及第八条记录的选择。
- [x] 验证无效方向在记录命令前拒绝。
- [x] 核对当前场景双设备输出和原始四帧。

对象记录容量为八，图集和投影分别在原有参数块内传递。
同一管线处理普通算术及参考算术。
冻结区域继续采用每通道一字节门槛。

分项结果见[专项验收](../acceptance/nr/visibility-projection-depth.md)。
