# 材质一致索引局部核验

## 目标与范围

检查绘制级一致的材质描述符索引。
纹理基址来自推送常量，九个槽位使用固定偏移。
候选在任务目录生成，生产源码保持受检状态。
坐标、梯度、接收计算及相机参数保持实际输入。

## 检查顺序

先编译十份实际材质程序并验证中间码。
记录非一致装饰数量及程序摘要。
随后在冻结捕获中比较全部相关附件。
参考与候选均使用替换管线并预热十六次。

计时按参考、候选、候选、参考排列。
全范围覆盖 1006 次材质绘制及全部 3453 个事件。
普通主颜色、快照及全材质分别计算成本。
所有角色切换前清空替换关系。

## 准入条件

六份附件逐字节一致。
热点至少占处理器帧成本四分之一且减少至少 20%。
整帧节省 GPU 三毫秒也可进入原生核验。
原始四帧与正式帧预算按所属门禁继续验收。

定位预算十分钟，实现与短检预算二十分钟。
相同问题最多追加一次有新依据的控制。
结果和失败原因写入所属验收报告。
