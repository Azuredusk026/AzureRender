# 材质纹理共享实施计划

> 执行方式：自主实施，按任务逐项验证。

目标是让相同材质纹理共享完整精度的 GPU 资源。
缓存属于通用渲染资源层。
角色渲染器与合成多资源夹具消费同一契约。
实现使用 C++、既有 RHI 和纹理过滤规则。

依据为 `AGENT.md` 的资源所有权与复用规则。
本阶段属于 NR1 大场景接入支持。
阶段提交由主执行流程统一处理。

## 资源契约

`SampledTextureCache` 集中拥有图像、视图和采样器。
`SampledTextureBinding` 仅暴露借用的视图和采样器。
缓存使用宿主提供的 RHI 与分配器。
宿主在提交完成后清理缓存。

相同内容在一个渲染器会话内共享。
请求在加载线程按顺序执行。
环境纹理与动态附件保持各自所有权。
描述符顺序与材质槽位保持现有契约。

缓存键包含处理后的像素与尺寸。
键还包含格式、层级、过滤语义及透明度阈值。
采样器的完整有效描述同样参与判定。
哈希命中后按完整输入比较，确认内容等同。

自动层级沿用 `buildTextureMipChain`。
创作层级按原字节上传。
采样器最大层级等于实际末级。
无效输入在分配前拒绝。

## 审查重点

1. 同字节使用不同色彩或法线语义时独立存储。
2. 透明度阈值与采样规则变化时独立存储。
3. 哈希冲突需比较完整输入。
4. 上传异常需释放部分对象并允许重试。
5. 卸载与重新加载需清除借用关系。
