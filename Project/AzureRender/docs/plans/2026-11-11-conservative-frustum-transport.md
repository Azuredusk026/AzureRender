# 保守剔除参数实施计划

本单元承载参考光栅所需的保守余量及退化区间。
公共视锥和 GPU 参数使用相同数值规则。
GPU 推送参数至多为 128 字节。
参考横纵位置与设备深度的混合平面随后准备。

## 接口与所有权

视锥追加保守余量和齐次尺度平面。
余量为负一时使用现行普通剔除。
非负余量启用保守舍入边界及零尺度区间保留。
有界但数值不确定的结果保持可见。

GPU 管线通过特化常量显式启用该能力。
默认值为关闭，普通管线保持所属运算路径。
启用前检查着色器的能力标记与推送布局。
配置、缓冲、同步及资源关闭由现有剔除资源类持有。
