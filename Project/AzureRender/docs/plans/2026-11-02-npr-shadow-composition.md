# NPR 色带颜色合成

状态：公共机制及受影响回归通过，完整画质继续验收。
归属：Q1 角色与场景联合画质。

## 目标

通过材质画像表达视角色带参与的颜色混合。
八个原生片元的颜色重建误差保持小于 0.000001。
既有默认材质保持原有程序及输出兼容。
完整服饰外观继续执行原有区域及运动验收。

## 来源

原生服饰的实际绘制已核对纹理及常量。
服饰四的四个片元具有完整中间值追踪。
其余四份服饰各有一个独立的漫反射重建片元。
来源资格见[服饰输入核验](../acceptance/nr/native-cloth-inputs.md)。

原生混合权重为视角色带透明度乘以遮蔽权重。
该结果加上主光色带透明度，再限制到零至一。
室内颜色使用相同的视角加权遮蔽量。
材质阴影比例与全局比例共同决定阴影反照率。
完整帧输出与片元重建分别核验。

## 配置与归属

`AssetMaterial::NprDiffuse` 持有有类型的 `RampComposition`。
配置字段为 `rampComposition`。
`mask-visibility` 为缺省策略。
`view-ramp-alpha` 选择视角色带参与阴影及室内混合。
显式策略要求 NPR 漫反射及漫反射色带输入。

加载器严格校验类型、枚举及所有者组合。
完整材质文档、参数覆盖及图保存消费相同语义。
GPU 画像使用 NPR 所属的预留分量。
布局版本与发布契约在实现时同步登记。

`materialNprDiffuseResponse` 负责画像与纹理适配。
`characterDiffuseWeightedResponse` 持有公共颜色计算。
视角采样使用相机前向及表面法线。
新策略进入独立的材质光照程序族。

响应中的遮蔽量继续保存未乘视角色带的值。
镜面及头发消费者按各自契约施加一次视角权重。
颜色合成单独使用乘过视角色带的室内权重。
各项边界通过实际原生中间量及公共夹具核对。

原生材质身份、纹理及光色归属于内容工具。
核心通过画像配置接收策略及参数。
普通通用表面和织物分别验证公共复用。
