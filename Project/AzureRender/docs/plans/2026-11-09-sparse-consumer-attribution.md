# 稀疏照明消费归因

状态：归因完成。生产实验入口默认关闭。

## 问题与范围

四像素组候选通过严格四帧，未取得显著净收益。
绘制资格不能证明消费端实际缓存命中。
本单元只采集真实消费阶段的稀疏计数与失配数据。
采集结果用于选择优化热点，不用于帧收益结论。

## 诊断契约

普通诊断保留现有六字计数契约。
帧选择诊断每隔三十二像素采样一次。
每槽至多保留十六条十二字失配记录。
记录包含原因、位置、模式位及请求和观察数据。

原因分别表示模式拒绝、逐像素失配及四像素组失配。
记录缓冲由照明缓存按所属帧槽持有。
GPU 完成后按现有栅栏回收，取消录制不增加结果。
记录总数与存储截断分别可查询。

## 实施与检查

1. 复现记录容量及回收接口缺失。
2. 实现有界记录、稀疏着色程序及元数据。
3. 集中核对帧槽、截断、真实 GPU 载荷和设备回退。
4. 执行一次三十二帧原生诊断，不保存截图。
5. 根据实际模式和身份差异登记接续范围。

临时产物、证据及必要恢复数据均写入 D 盘项目。
单任务预算为 2 GiB，普通任务保留一天。
原生输入通过活动引用及摘要锁共同保护。

## 验收边界

本单元不启动帧收益、正式长采样及长跑。
GPU 16.6 毫秒及 CPU 八毫秒标准保持有效。
整体画质、正式性能及人工项继续待通过。

## 执行结果

二十三项检查通过，两项按设备能力跳过。
一次原生诊断回收三十个有效槽。
消费采样的四像素组接受率约为 30.23%。
