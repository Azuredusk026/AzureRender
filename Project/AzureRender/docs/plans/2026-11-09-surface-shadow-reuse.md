# 同帧表面阴影复用

状态：整帧收益未成立，候选隔离保存。

## 范围与成本依据

快照与最终绘制共同调用级联阴影接收。
已有消融中，主通道阴影相关差值约为 2.75 毫秒。
该差值包含绘制及编译影响，单独核定实际收益。
本批优先减少同一表面的重复阴影过滤。

资源归属于 RenderCore 的同帧表面照明缓存。
阴影载荷采用 R32 浮点值与四个整数身份字。
身份包含精确深度、实例、源索引及材质。
每像素二十字节，两个帧槽分别持有。

像素身份及合法可见量匹配时消费缓存。
未匹配、透明、渐隐或缺少资源时执行原计算。
接收面导数继续在统一入口准备。
阴影采集读取基础层，范围内没有隐式材质采样。

普通及风格化不透明表面共用机制。
独立 GPU 夹具验证匹配、失配及像素边界。
场景外观与局部契约分别验收。
原画质及帧预算保持有效。

## 执行与验证

1. 保存阴影载荷接口缺失的失败结果。
2. 实现有界载荷、资源能力和帧槽生命周期。
3. 接入可选生产与消费程序，保留完整着色回退。
4. 集中执行所属资源、GPU、材质及视图检查。
5. 有效兼容通过后执行一次严格四帧。
6. 像素零差异成立后执行一次短时前后参考比较。

局部检查与场景工作量共同决定原生评估资格。
整帧收益未成立时，实验入口继续关闭。
临时内容与比较副本保存在 D 盘，并按天回收。
正式长采样、长跑及人工项按原条件执行。

基础层采集依据见 [GLSL 纹理采集函数](https://docs.vulkan.org/glsl/latest/chapters/builtinfunctions.html#texture-gather-functions)。

## 结果与接续

候选的两种诊断配置均保持严格四帧零差异。
最终所属检查与成本控制共三十六项通过。
诊断开启版本的 GPU 均值比参考高约 4.39 毫秒。
关闭诊断后的候选仍比同批新参考高约 0.34 毫秒。

高像素命中率没有形成整帧净收益。
最终绘制局部差值约为减少 0.078 毫秒。
快照局部差值约为增加 0.455 毫秒。
同类候选重试须有新的实际成本依据。

生产恢复 `64e7cc3` 的源码与程序。
后续优先处理管线缓存达到上限后的重复准备。
工具专用缓存路径纳入 D 盘维护规则。
结果见[候选验收](../acceptance/nr/surface-shadow-reuse.md)。
