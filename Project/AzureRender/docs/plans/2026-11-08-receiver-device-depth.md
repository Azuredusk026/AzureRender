# 屏幕接收深度输入核对

## 目标与输入

公共屏幕通道已在同输入下复现 NVIDIA 的 17017 处原生可见量。
场景接入前核对当前设备深度、快照深度和相机的实际关系。
源数据为现有 `receiver-current-gpu_frame2.rdc`，按只读输入使用。
原生深度、矩阵及完整遮罩沿用已保留数据。
本单元读取既有捕获中的资源，完整新采集由后续接入候选调度。

## 执行

- [x] 提取主绘制及不透明快照的设备深度与对应相机。
- [x] 核对坐标方向、深度编码和原生重建矩阵的适用范围。
- [x] 使用同输入模型区分深度生产与接收过滤差异。
- [x] 记录场景接入所需契约及剩余条件。

资源通过实际绘制和绑定关系定位。
原始捕获、主程序、源码及项目输入保持原字节。
结果按四处控制点及完整遮罩分别解释。
整体画质、完整颜色及帧预算持续按原标准验收。

## 预算

任务位于 D 卷，预留六十四 MiB，完成后保留一天。
现有捕获与原始资产采用活动引用。
单次资源提取进程至多一百二十秒，输出只包含必要深度和小型记录。
定位预算十分钟，来源关系成立后再实施生产接入。

## 结果

四处控制点复现参考，完整遮罩的显式舍入仍有 221 处超差。
主深度与快照在该遮罩的 17017 处逐字节相同。
当前深度的单精度间隔为原生的十六至三十二倍。
源投影及深度生产的精度为后续实施范围。
图像行号与过滤相位的公共配置独立实施。
详细结果见[深度输入核验](../acceptance/nr/receiver-device-depth.md)。
