# 透明几何的 GPU 准备

本单元入口为 `16f6f18`。
范围为 CPU 透明排序所需的顶点变形。
既有定位的透明准备均值约为 1.03 毫秒。

本次按变形键生成、稳定排序及索引写入分层实施。
第一阶段交付通用的 GPU 分段稳定键排序器。
调用方提供无符号整数键及附属值。
相同键按输入顺序输出，分段范围分别排序。

第二阶段接入透明变形、深度键及索引写入。
逐分量计算次序及稳定深度排序保持原契约。
机制适用于透明排序及独立工具的批量键排序。

排序器使用有界双缓冲和明确的帧槽生命周期。
调用方退役帧槽后，才能改写该槽的输入和段信息。
内部归并发布计算读写依赖。
外部输入发布及输出消费依赖由调用方提供。
