## 实施范围与源码依据

仓库优先编译 `third_party/imgui`，使用 GLFW 和 Vulkan 后端。`IMGUI_HAS_DOCK` 已启用，现有编辑器支持停靠恢复。依赖版本满足本批需求，实施复用现有后端。

`src/main.cpp` 负责启动参数和项目上下文。`AzureRenderApp::run` 启动运行系统并初始化场景渲染资源。项目中心需在这些场景初始化之前显示。

`ProjectOpenService` 提供创建、校验、打开和最近记录。`EditorSession` 拥有项目切换、文档保护及生产操作。`GameBuildJob` 调用 `tools/build_game.py` 发布。游戏包以项目命名的原生程序作为入口。

## 模块边界

| 层 | 本批职责 | 主要文件 |
| --- | --- | --- |
| 应用生命周期 | 启动决策、项目中心、加载、编辑和关闭 | `src/main.cpp`、`src/app/ProjectCenterHost.*` |
| 平台与渲染 | 复用窗口、设备、ImGui 后端和视口 | `AzureRenderApp.*`、`GlfwFrontend.*` |
| UI 框架 | 主窗口、面板、命令和通知 | `ImGuiEditorLayer.*`、`IEditorPanel.hpp` |
| 设计系统 | 样式、尺度、常用控件与反馈 | `src/editor/ui/`、`EditorTheme.*` |
| 业务服务 | 项目、文档、缓存和发布 | `ProjectOpenService.*`、`Project.*`、`GameBuildJob.*` |
| 业务面板 | 项目与发布先迁移，其他面板保持可用 | `ProjectBrowserPanel.cpp`、`BuildPanel.cpp` |

项目中心与编辑器在同一进程顺序运行。项目中心仅持有窗口、UI 与基础设备资源，释放后初始化编辑器。窗口及后端的重新初始化需验证资源和回调所有权。

本计划按阶段维护实际结果。占位界面、候选截图和机器回放分别标注，完整工作流需要生产路径证据。
