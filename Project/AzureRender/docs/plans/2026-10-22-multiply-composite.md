# 乘法材质合成实施计划

日期：2026-10-22。
阶段归属为 NR6-C3，依据本会话授权连续实施。
目标是提供可复用的光栅乘法覆盖层。
来源见[角色场景验收](../acceptance/nr/character-scene-lighting.md)。

## 架构与契约

材质画像版本 2 声明 `multiply-composite` 特征。
`composite` 对象包含 `schemaVersion: 1`。
`mode` 的有效值为 `multiply`。
类别允许 `generic` 与 `overlay`，透明模式为 `BLEND`。

线性颜色遵守 `Cout = Cdst * mix(1, tint, alpha)`。
透明度同时消费纹理、材质因子和节点透明度。
合成颜色只影响主颜色附件，目标 alpha 保持有效。
法线附件、深度及其他透明材质沿用自身规则。

材质解析归属资产模块，管线状态归属 RHI。
角色渲染器装配合成管线及其资源生命周期。
资产名称、游戏标识及固定颜色属于内容工具。
技术栈为 C++17、Vulkan、GLSL 与 Python。

## 校验范围

画像版本、未知字段和未知模式在加载时拒绝。
