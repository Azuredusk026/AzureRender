# 项目参考视图实施计划

项目将具名参考视图保存到独立配置文件。
运行装配及独立校准工具显式读取该配置。
数据来源为已验收的参考相机视图契约。
本单元交付版本化读写及项目重开。

## 文件与契约

渲染模块拥有参考视图的 JSON 编解码。
运行模块拥有项目配置路径、读写和替换。
配置位于 `config/reference-views.json`。
文件至多 1 MiB，具名视图至多六十四个。

视图名称使用一至六十四个字母、数字、点、横线或下划线。
文件及嵌套视图使用版本一，未知字段按错误处理。
投影、坐标帧、尺寸及数值共用准备类型的校验。
文件缺失时返回空集合。

保存先校验完整集合，再在目标目录写入临时文件。
刷新并关闭临时文件后，原子替换目标。
失败时清除所属临时文件，目标保持现有内容。
调用方串行管理同一项目配置的写入。
