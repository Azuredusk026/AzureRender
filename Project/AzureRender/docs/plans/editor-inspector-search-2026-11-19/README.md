# 属性面板搜索验收

属性面板按组件与字段的名称、译名和标识筛选。
搜索直接显示匹配字段，保留原有折叠状态。
无匹配时显示提示，搜索框旁提供清除入口。
筛选范围为当前选中的对象及其共享组件。

## 实现与接入

属性面板复用反射元数据、搜索控件和编辑操作。
搜索分组直接显示匹配字段，展开状态由浏览视图维护。
对象操作、材质槽和物理专用区域保留各自入口。
即时筛选与明确的清除入口参考 Unreal 官方说明。 [Unreal 属性面板](https://dev.epicgames.com/documentation/en-us/unreal-engine/level-editor-details-panel-in-unreal-engine)

生产变更涉及属性面板与界面词条两个文件。
候选基于数值拖动取消交付 `f0de6d0`。
包含两项交付的面板与词条补丁可应用于 `9b0b705`。
接入检查使用隔离索引，主线合入归属集成线。
