# 原生角色材质组合计划

日期：2026-11-03，归属为 Q1。
状态：P0 至 P2 的本轮受影响检查完成。
目标为核对固定原生姿态的完整材质消费。
规格及最终条件由[开发总计划](azure-engine-plan.md)持有。

## 架构与输入

固定模型、机位及灯组采用已归档的截帧对照。
十三份有效材质来自现行联合动态项目。
材质绑定通过场景槽位及完整材质文档配置。
Asset、RenderCore 和 Player 沿用既有契约。

材质的四分之一辐亮度与场景曝光共同核对。
原生输出按所属显示条件转为可比较的颜色。
几何遮挡、透明混合及边界像素分别保存资格。
源像素及原始失败结果保持原有门槛。

## 文件与阶段

P0 在独立任务目录保存输入、脚本及实际采集。
源资产采用只读共享，场景和材质文本独立持有。
分析结果进入 `docs/acceptance/nr/` 的证据索引。

`tools/normal_map_orientation.py` 持有显式方向转换。
角色工具检查由新建的方向测试文件持有。

P1 的公共机制先建立实际失败检查。
机制进入既有模块，具体参数归属于项目内容。
普通表面或材质检视夹具验证第二种使用方式。
测试通过后同步来源、契约及独立提交。

P2 在近侧动态项目核对受影响结果。
角色、物流、场景及反射保留现行输入。
图形作业串行执行，编译期间冻结采集。
各阶段按检查结果更新状态。

## 检查重点

- 原模型的内嵌画像与场景有效材质分别核验。
- 辐亮度和曝光保留实际倍率及来源。
- 材质身份、可见像素及透明覆盖按实际绘制确认。
- 主光、对象阴影及环境贡献保持独立所有权。
- 完整头发的一字节门禁及既有静态门槛保持有效。
