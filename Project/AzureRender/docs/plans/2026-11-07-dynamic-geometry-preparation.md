# 动态几何准备优化

## 范围与成本

当前生产来源为 `adfdc00`。
原生 CPU P95 约为 15.28 毫秒，八毫秒门槛保持有效。
既有匹配源码的分项中，透明准备约为 2.65 毫秒。
运动数据准备约为 1.81 毫秒。
两项共同消费本帧实例、姿态及不可变几何。

透明路径采用紧凑的顶点并集与三角形局部索引。
大型顶点并集通过宿主线程池计算互不重叠的区间。
深度键及稳定排序在完整顶点结果就绪后执行。
运动路径复用姿态容器，并在身份顺序相同时共享索引。
索引变化时按原身份规则构建有效查找表。
几何顺序、深度键、运动字及提交语义保持有效。
