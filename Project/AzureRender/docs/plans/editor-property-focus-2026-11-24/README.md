# 数值拖动失焦验收

拖动属性数值时，窗口失焦会取消编辑。
恢复焦点及释放鼠标后，原数据继续有效。
连续修改使用已有编辑事务和历史检查点。
正常释放提交一次编辑，Esc 取消同样恢复原值。

## 回放记录

生产基线为 `191d7a1`，配置为 Release。
批次 `2405` 在探索项目复现失焦后数值残留。
窗口失焦清除鼠标状态，控件进入释放路径。
候选使用焦点状态区分中断与正常提交。

| 操作 | 通过条件 |
| --- | --- |
| 多选后拖动 X 轴，中途切出窗口 | 原始混合值、选择、摘要、保存状态和撤销计数恢复 |
| 返回窗口并松开鼠标 | 当前值与拖动前的场景一致 |
| 再次正常拖动并松开 | 产生一条可撤销记录，撤销和重做均可执行 |
| 按 Esc 取消并保存重开 | 恢复内容稳定，已有重做仍可执行 |
