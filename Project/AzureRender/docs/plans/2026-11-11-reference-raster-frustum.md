# 参考光栅混合视锥实施计划

本单元为参考光栅准备保守剔除参数。
横纵平面来自参考视图，深度平面来自设备视图。
准备器覆盖声明的世界坐标包围域。
返回结果持有平面、误差余量及适用域副本。

## 数值与边界

准备后的参考视图提供只读线性系数与误差幅度。
准备器统一归一化平面，并计入单精度参数转换误差。
余量包含参考投影舍入、坐标帧及设备投影误差。
参考与设备的零尺度区间均保持可见。

设备深度平面要求声明域内的设备尺度确定为正。
其他情况以参考横纵平面执行保守检查。
不可界定的投影范围返回显式的全保留状态。
GPU 参数转换核对输入包围盒属于声明域。
