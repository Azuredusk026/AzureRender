# 帧场景快照复用

## 目标与归属

状态：功能验证完成，完整性能采集待空闲 GPU。
宿主命令记录消费 `SceneFrameData::sceneSnapshot`。
该快照包含当前场景、节点、照明与已解析资源路径。
场景更新和命令记录使用同一帧的不可变输入。

上下文持有所需场景数据副本。
快照生命周期覆盖当前帧，GPU 资源遵守原退役边界。
初始化及重建通过文档解析生成完整上下文。
编辑视图、独立 Player 和多视图继续使用现有公共契约。

## 诊断来源

实际 CPU 工作 P95 为 33.85 毫秒，八毫秒门槛失败。
二十四次扰动间隔采样已记录实际模块基址。
私有符号映射与生产程序的机器代码字节一致。
调用栈与源码共同确认两处重复转换和文件查询。

## 执行与验证

1. 保存来源、原生栈与生产机器代码摘要。
2. 为上下文构造传入当前帧的可选场景快照。
3. 无快照的调用沿用完整文档及资源解析。
4. 完成双配置构建与受影响的既有 CPU 检查。
5. 对照四帧原生输出及生产着色程序字节。
6. 独立采集原帧数的联合性能，保留失败与热状态。

定位十分钟，候选修改与短检二十分钟。
探索总预算三十分钟，构建与采集各九百秒。
完整画质、支持设备和实时预算保持既有验收标准。
