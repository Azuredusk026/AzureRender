# 稳定三角形深度排序

## 来源与目标

源码基线为 `8f4c330`。
同输入控制记录透明准备均值约为 3.94 毫秒。
世界坐标复用的局部均值差约为 0.27 毫秒。
本单元验证排序本身及两项机制的组合成本。

参考、基数排序、基数排序加世界坐标复用分别计时。
三组交替改变执行顺序，全部索引及绘制元数据必须一致。
质心、相机深度及同深度三角形的稳定顺序保持现行语义。
正负零使用相同排序键，非有限值沿用标准比较路径。

## 借鉴与边界

参考 NVIDIA Warp 的[主机排序](https://github.com/NVIDIA/warp/blob/06034452007d67d2713c71e84062aa9f9dc8e31f/warp/native/sort.cpp)。
固定提交为 `06034452007d67d2713c71e84062aa9f9dc8e31f`。
许可为 Apache-2.0，原件及摘要保存在研究证据中。
借鉴范围为浮点排序键及稳定桶分发的算法结构。

候选使用八位桶及调用内工作区。
深度和顶点计算遵循当前算法。
生产公共能力需验证重复值、正负零、边界及非法索引。
资源、图形数据布局及覆盖资格遵循所属机制。

## 验证与预算

私有控制先核验实际帧的输出和局部收益。
生产采用执行受影响 CPU、图像及机制回归。
完整帧收益、热状态及用户画质保持原验收标准。
定位十分钟，候选及短检二十分钟，探索总预算三十分钟。

私有构建三百秒，私有原生诊断三百秒。
正式构建每配置九百秒，原生四帧九百秒。

## 实施结果

稳定深度排序及实例内世界坐标复用进入生产实现。
二十帧的全部索引及绘制元数据一致。
组合配置的局部均值差为 1.408 毫秒。
两配置各三十七项 CPU 及十二项 GPU 检查通过。

原生四帧与冻结参考 RGB 逐像素一致。
全部六百六十三份程序保持原字节。
完整帧预算、热状态及用户画质继续集中核验。
结果与范围见[验证记录](../acceptance/nr/stable-depth-sort.md)。
