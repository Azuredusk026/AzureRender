# 线性纹理通道存储

目标为保持完整 RGBA 采样值并减少纹理驻留。
来源见[基础通道核查](../acceptance/nr/texture-channel-scope.md)。
实际缓存以全部处理后 mip 字节决定资格。
完整图像的颜色与既有共享身份继续保持精确。

## 所属模块与契约

RenderCore 的采样纹理缓存选择物理存储表示。
RHI 提供可查询的图像视图分量映射能力。
Vulkan 后端实现该能力，其他后端保留完整表示。
绑定及 GPU 对象继续由缓存持有至清空。

资格范围为完整的线性 UNORM mip 链。
一至两个独立通道可使用 R8 或 RG8 存储。
全部 mip 共用同一映射，常量仅取零或一。
采样边界、过滤能力及设备格式均需满足契约。

sRGB 及 GPU 生成 mip 的输入使用 RGBA 存储。
需要边框采样的输入使用 RGBA 存储。
缓存结束写入和失败输入所有权沿用现行契约。
统计分别记录逻辑请求、实际驻留和收窄字节。
