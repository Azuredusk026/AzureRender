# 投影表面与屏幕法线

## 范围

本项归属于 Q1 的发片轮廓与透明阶段。公共能力服务于按视口宽度投影的着色表面，接收常规材质、蒙皮、变形和节点变换。角色及关卡身份由项目资产声明。

## 来源

原生事件 1138 与 1314 使用同一外扩顶点阶段。1138 根据外扩前的世界位置投影坐标读取屏幕法线。动态诊断复用现有描边投影函数。实际轮廓、几何归属和屏幕采样坐标分别核对。

## 公共契约

现有描边投影数据持有宽度、最小像素宽度、深度偏移、第二套纹理坐标及线性遮罩。着色表面显式选择投影目标。缺省目标按当前描边行为解释。表面投影随镜头、视口、骨骼及变形更新。阴影投射消费所属几何及阴影材质契约。

屏幕法线使用已有正深度、八面体法线和粗糙度快照。材质按原始世界位置计算采样坐标。屏幕法线接收表面参与颜色绘制，快照的原始表面拥有独立输入。缺少有效深度时采用声明的表面法线。快照分配核验纹理格式、采样数和设备预算。

## 执行顺序

1. 对照原生最差像素的世界位置、采样坐标、法线与硬件输出。
2. 在独立诊断中复现动态投影和屏幕采样。
3. 为有明确差异的公共契约建立失败用例。
4. 实现配置解析、投影数据、顶点程序与快照消费。
5. 验证固定和索引描述符、计算和顶点蒙皮、多重采样、节点镜像与相机变化。
6. 核验完整发片颜色和联合动画。
7. 复跑可玩入口、保存重开与独立发布。

## 验收

缺省工程的实际输出与既定兼容用例保持一致。独立夹具覆盖投影表面和屏幕法线的不同合法组合。原生诊断记录像素归属、坐标及颜色误差。联合动画保持材质语义、几何连续性和资源释放。完整画质采用当前正式门槛。

材质表面投影接口已完成。Debug 与 Release 各覆盖三种采样配置，每种配置验证十二个用例。九项既有描边用例在两种构建中通过。独立的形状参考、绑定路径、实际蒙皮路径、第二个变形权重及材质文档重开均有对应记录。完整发片颜色继续执行，数据见[表面投影核验](../acceptance/nr/evidence/2026-11-04/projected-surface/results.json)。

屏幕法线生产和消费通过两种构建的八十四项采集。
空背景、不透明表面、裁剪和透明表面分别核验。
