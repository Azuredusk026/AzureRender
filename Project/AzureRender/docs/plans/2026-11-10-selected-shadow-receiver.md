# 所选级联接收状态

目标为缩小阴影接收中间状态的保留范围。
四级投影及导数保持原始求值表达式。
后续过滤只保存当前级联和相邻级联需要的结果。
控制先核对实际附件和局部效率。

## 状态与运算

入口按原相机数据计算视线深度和级联编号。
四级导数继续在一致控制流中完整计算。
每级结果完成后，保留所需的投影坐标及梯度。
过滤使用这些坐标，其他输入保持原定义。

主颜色与不透明快照共用同一接收状态契约。
状态只属于当前片元，覆盖与资源布局保持现行定义。
投影、曲率、混合和过滤的浮点表达式分别保留。
非法外部输入按既有相机及材质契约校验。
