状态：公共能力已实现。阶段索引为 NR5。
原生场景的联合验收按总计划执行。

场景持有一个可选的局部反射探针。

## 配置与资源

关卡配置使用顶层 `reflectionProbe` 字段。
该字段的 `version` 为 1。
`texture` 使用项目资源 URI 或资源标识。
资源数据库记录纹理依赖及内容指纹。
关卡保存与重开保留配置和资源引用。

文本场景的模式版本为 6。
读取器接受模式版本 1 至 6。
文本场景的纹理字段使用文件系统路径。
未声明的探针使用空纹理配置。

| 字段 | 类型和含义 |
| --- | --- |
| `center` | 三维浮点数，世界空间体积中心 |
| `halfExtents` | 三维正浮点数，世界轴向半尺寸 |
| `capturePosition` | 三维浮点数，反射捕获位置 |
| `intensity` | 非负浮点数，局部镜面辐射倍率 |
| `blendDistance` | 非负浮点数，体积内边缘过渡距离 |
| `boxProjection` | 布尔值，启用盒投影修正 |

数值使用引擎世界坐标及场景米制单位。
边缘权重使用最近边界距离除以混合距离。
零混合距离表示硬体积边界。
全局反射的剩余权重为一减局部权重。

渲染器在片元阶段使用独立绑定 23。
普通描述符和索引描述符共享采样语义。
局部强度独立于天空强度。
纹理缺省时绑定全局纹理并关闭局部贡献。

`.azenv` 保留线性 HDR 及原作层级。
普通图像提供单层反射纹理。
粗糙度按已有层级范围选择采样层级。
探针体积支持世界轴对齐盒。

## 公共工具

`tools/native_render/probe_lab.py` 执行 GPU 夹具。
参数为 `--player` 和 `--output`。
运行前将 `PYTHONPATH` 设置为 `tools`。

`tools/native_render/cubemap_environment.py` 转换纹理。
输入为 DDS 约定的六面 RGBA32F 数据。
文件名形如 `face0_mip0.rgba32f`。
参数声明输入目录、输出、面尺寸和层级数。

转换逐层执行双线性重采样。
输出为线性 RGBA16F，保持 HDR 数值。
方向约定与 `EnvironmentAsset.cpp` 一致。
转换器测试验证方向和独立层级的保真。
