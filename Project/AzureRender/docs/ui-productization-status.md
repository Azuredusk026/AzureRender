# 项目中心与独立游戏交付状态

本页说明安装版引擎能完成哪些制作步骤。
当前范围为 Windows x64、ImGui、GLFW 与 Vulkan。
引擎启动、独立工程和 GUI 发布已实现。
完整制作流程通过生产控件的输入回放。

## 可以怎样使用

双击安装目录的 `bin/AzureRender.exe`，进入项目中心。
创建 Monica 后，编辑器打开独立项目目录。
保存并关闭程序，再从最近项目继续编辑。
完整操作步骤见[项目中心指南](tutorials/project-center.md)。

编辑器的 Build Game 面板使用安装树发布工具。
输出目录包含 `Monica.exe`、Runtime、资源和配置。
复制整个目录后，游戏依据入口位置找到这些文件。
自动检查已验证原工程目录不可用时仍能运行。

## 交付限制

实体双击、键鼠操作和中文输入法组合待集中复核。
桌面限制使本轮实体鼠标注入无法完成。
生产 ImGui 输入回放提供自动操作证据。
该证据的范围见[交付验证](acceptance/ui4/2026-10-12.md)。

Debug 万文件目录测试仍有 180 秒超时记录。
Release 同一用例通过，初检耗时为 132.25 秒。
完整 CPU 回归结果与诊断保留在交付验证页。
当前状态包含这一未通过项。
