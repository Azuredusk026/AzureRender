# 深度层级资源

`DepthPyramidGpu` 持有逐帧的 `R32F` 层级图像。
调用者提供完整的单样点采样视图。
输入基础层尺寸须与资源创建尺寸一致。
深度值来自红通道，并须为有限浮点数。

## 归约与用途

基础层逐像素复制输入。
`Minimum` 用于正线性深度的最近表面。
`Maximum` 用于反向投影深度等最大值层级。
偶数维度采用两点核，奇数维度采用三点重叠核。

宽高各限制为一至 8192，在途槽位为一至八。
层级数受完整图像尺寸约束。
所有输出的总预算为 512 MiB。
格式须同时支持存储写入及最近邻采样。

## 同步与生命周期

输入视图由调用者持有，并准备计算采样可见性。
输出禁止作为自身任意槽位的输入。
资源持有逐级视图、描述符及参数缓冲。
每个层级完成写入后进入可采样布局。

通过 `output(slot)` 借用输出图像、视图及采样器。
输出采样器允许读取已分配的全部层级。
对应提交及消费者完成后才能复用槽位。
销毁前由宿主等待全部使用者完成。

## 验证入口

`AzureRender.DepthPyramid` 核对边界和资源契约。
`AzureRender.DepthPyramidGpu` 核对两种归约及槽位隔离。
真实输入通过测试程序的可选夹具目录参数传入。
原版深度来自已保存的七级真实载荷。
