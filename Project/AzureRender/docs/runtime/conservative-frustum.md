# 保守剔除参数

`FrustumPlanes` 承载六个平面、保守余量及参考齐次尺度平面。
`GpuCullParameters` 使用同一组数值，推送布局占 128 字节。
余量为负一时执行普通剔除。
非负余量启用保守边界及零尺度区间保留。

## 数值规则

保守余量使用各平面系数对应的距离尺度。
调用方为采用相同尺度的平面准备统一余量。
每个包围盒另加六十四倍单精度相对舍入界限。
绝对界限包含六十四倍最小正规数。

齐次尺度区间触及零及其误差边界时，包围盒保持可见。
该规则承载参考光栅的零尺度回退。
保守距离求值出现非有限中间结果时，包围盒保持可见。
输入平面及余量须有限，包围盒须有限且有序。

## 管线与资源

保守能力由特化常量零显式启用，默认值为关闭。
`GpuCullingResources::initialize` 的保守参数默认为关闭。
启用前检查计算阶段、能力标记及追加字段的布局。
不兼容模块在 GPU 分配前拒绝。

`record` 校验余量及平面。
非负余量要求已启用保守能力的管线。
启用管线也可用负一余量执行普通剔除。
绘制编号、表面编号及命令顺序保持所属稳定契约。

帧资源在上传和释放前由调用方退休所属栅栏。
缓冲、描述符及管线沿用现有资源类的所有权。
参考横纵位置与设备深度的混合平面由后续适配器准备。
专项结果见[保守剔除验收](../acceptance/nr/conservative-frustum-transport.md)。
