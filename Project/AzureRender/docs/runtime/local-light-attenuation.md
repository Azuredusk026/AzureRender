# 局部灯光距离衰减

阶段索引为 NR3。
灯光形状契约提供距离衰减模型和指数。
场景文档、关卡、预设与场景交换共享该契约。
光栅及路径追踪通过同一着色函数消费显式模型。

## 配置

关卡灯光的 `shape` 字段支持以下配置：

```json
{
  "type": "point",
  "falloff": "smooth-inverse-square",
  "falloffExponent": 2
}
```

`falloff` 默认为 `legacy`。
该值保持各渲染路径的默认衰减契约。
`falloffExponent` 默认为二，合法范围为 `(0, 64]`。
未知模型与非法数值在内容加载时拒绝。

距离和灯光半径均采用世界米制单位。
令 `s` 为距离平方，`r` 为灯光半径。
显式模型定义如下：

| 模型 | 距离权重 |
| --- | --- |
| `smooth-inverse-square` | `max(1-(s/r²)²,0)² / (s+1)` |
| `range-power` | `max(1-clamp(s/r²,0,1),0)^falloffExponent` |

平滑距离平方模型的分母偏移为一平方米。
范围指数模型使用范围内归一化距离。
两者在半径处及范围外的权重均为零。
聚光锥角权重随后与距离权重相乘。

## 运行契约

形状配置随灯光进入场景渲染快照。
逐帧灯光缓冲区保留现有所有权和释放顺序。
GPU 灯光结构为 128 字节，包含独立作用体积。
模型和指数使用 `coneType.zw`。

路径追踪累计指纹包含模型与指数。
更改配置会使累计历史失效。
自发光三角形保留其面积光采样契约。
显式模型可用于室内照明与风格化范围灯。

## 验证

公开数值探针包含 60 项检查。
其中八项覆盖两种模型的中心、内部与边界。
关卡测试覆盖保存重开、默认值及非法配置。
路径追踪测试覆盖参数打包及历史失效。

`tools/native_render/light_lab.py` 提供五组实际画面。
夹具覆盖无光、点光、聚光及两种显式模型。
八位输出的衰减比值误差阈值为 3%。
精确算法由浮点数值探针独立验证。
路径追踪的三组实际画面验证显式模型的距离响应。
两种模型的最大八位比值误差均低于 0.55%。

原生来源与接入范围见[衰减证据](../acceptance/nr/light-attenuation.md)。
