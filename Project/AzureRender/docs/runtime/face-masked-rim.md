# 脸部遮罩轮廓光

`nprDiffuse.rimResponse` 选择轮廓光响应。
`face-masked` 用于头部朝向控制的脸部轮廓光。
它要求版本二脸部材质及版本二双图脸部模型。
材质同时声明 NPR 漫反射及脸部功能归属。

遮罩采用 `faceSdf.maskTexture` 的透明度通道。
采样使用材质坐标和零级纹理层。
头部横向坐标取自 `faceSdf.headNode` 及 `headBasis`。
运行时沿用实例的脸部坐标及既有纹理槽。

相机轴投影到头部横向平面后归一化。
投影与头部前轴的夹角控制朝向权重。
其绝对余弦在 0.9 至一之间平滑过渡。
朝前和朝后采用相同的朝向权重。

视角带采用脸部光照法线与视线的夹角。
脸部图蓝通道生成头部坐标中的法线。
遮罩绿通道控制该法线与几何着色法线的混合。
光源宽度控制带区间及遮罩混合比例。
混合比例为 `clamp(width * 10 - 3, 0, 1)`。
局部灯染色的中性值为 0.5，基础颜色系数为 0.96。

光源方向投影到相机平面后参与法线响应。
轮廓光继续消费光源衰减、可见性及接收开关。
该模式使用扩展材质着色程序。
背景深度不参与该响应的计算。

缺省模式为 `screen-depth`。
`view-facing` 提供通用表面视角响应。
各模式通过明确枚举选择，非法组合在加载和打包时拒绝。
完整材质文档保留枚举、遮罩及头部坐标声明。

配置归属见[材质编写](material-authoring.md)。
验收执行见[实施计划](../plans/2026-11-04-face-masked-rim.md)。
