# 表面朝向

材质的剔除模式与正面绕序分别配置。
双面材质保留两面的几何，并按实际正面判断翻转法线。
镜像实例按模型与编辑变换的组合确定绕序。
规则适用于普通模型、薄片角色材质及透明表面。

## 朝向策略

`surfaceFacingIndex` 统一返回四种配置的索引。
镜像状态由模型行列式与编辑变换共同确定。
连续实例批次按镜像状态分组。
摄像机位置决定当前观察到的几何面。

| 索引 | 材质 | 实例 | 正面绕序 |
| --- | --- | --- | --- |
| 0 | 单面 | 普通 | 逆时针 |
| 1 | 单面 | 镜像 | 顺时针 |
| 2 | 双面 | 普通 | 逆时针 |
| 3 | 双面 | 镜像 | 顺时针 |

单面表面按视图配置决定背面剔除。
双面表面使用无剔除状态。
片元仍依据正面绕序解释 `gl_FrontFacing`。
法线、GI 和反射共享这项判断。

## 绘制与资源

普通、不透明、透明、乘法及着色快照消费同一索引。
折射色调通道保留两种绕序。
积分头发的主通道与快照各自覆盖四种朝向。
纯深度及覆盖路径按各自使用的片元输入配置。

像素积分的不透明主通道与快照共八份管线状态。
透明积分主通道使用四份状态。
同时包含两类材质时，总数为十二。
四倍几何采样通过已有材质通道消费积分特征。

这些状态共享已有着色器及材质缓冲布局。
每个场景持有独立管线，并按既有同步顺序释放。
场景资源重建和异常回滚都释放完整状态集合。
朝向及联合路径的实测范围见[朝向验收](../acceptance/nr/surface-facing.md)。
