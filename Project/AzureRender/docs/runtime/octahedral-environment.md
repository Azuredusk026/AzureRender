# 八面体环境数组

`OctahedralEnvironment` 属于 RenderCore。
它保存二维 HDR 数组、作者层级及有效采样区域。
用途包括导入反射环境及独立多层环境预览。
GPU 所有者通过既有 RHI 接口上传资源。

## 资产契约

版本一标识为 `AZOA0001`，文件头为 48 字节。
整数和浮点位按小端存储。
载荷编码为 `R11G11B10_UFLOAT`，编码编号为一。
排列顺序为层级、数组层、行和列。

| 字节偏移 | 内容 |
| --- | --- |
| 0 | 八字节格式标识 |
| 8、12 | 宽、高 |
| 16、20 | 数组层数、层级数 |
| 24 | 四浮点有效区域缩放与偏移 |
| 40 | 编码编号 |
| 44 | 零符号折叠约定 |
| 48 | 原始打包 HDR 载荷 |

图像为正方形，尺寸介于一至 4096。
数组层数介于一至 256，载荷预算为 256 MiB。
层级数受图像尺寸约束，每层尺寸最小为一。
长度、版本、区域及有限值在 GPU 分配前校验。

有效区域按 `uv * scale + offset` 应用。
缩放为正，变换后的区域须位于单位正方形内。
折叠约定零使用数学符号，约定一将零视为正值。
默认约定为一，导入器按来源显式设置。

## 采样与所有权

`directionUv` 接受有限且非零的方向。
着色器消费有限的单位方向及显式有效区域。
两个入口共同执行八面体折叠及区域变换。
数学符号约定下，负 Z 轴映射到中心。

`OctahedralEnvironmentGpu` 持有图像、视图和采样器。
设备须支持该格式的线性采样。
采样器采用边缘夹持及三线性过滤。
显式层级由调用方提供，并由采样器夹持。

上传完整保留作者层级，临时缓冲随上传释放。
两个参数向量共 32 字节，由调用方选择传输位置。
RHI 生命周期覆盖资源所有者。
销毁前由调用方完成已提交用途的同步。

## 验证入口

CPU 检查覆盖文件往返、边界及无效输入。
资源检查核对原始载荷、格式能力和分配归零。
GPU 检查覆盖层间插值及两种折叠约定。
原生参考及生产接入范围见[数组验收](../acceptance/nr/octahedral-environment.md)。
