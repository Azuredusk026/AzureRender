# 有序反射探针

反射探针版本四接收一个八面体环境数组及有序体积集合。
用途包括完整关卡和带嵌套区域的室内环境。
资源定位沿用场景反射纹理入口。
数组格式见[八面体环境](octahedral-environment.md)。

## 数据配置

根对象包含 `version: 4`、`texture` 和 `field`。
可选的 `lodMapping` 使用[公共层级规则](reflection-lod.md)。
体积字段由集合对象持有。
集合版本一最多接收三十二个局部体积。

集合声明 `worldToField` 正交矩阵。
矩阵将世界位置、方向和法线映射到采样空间。
正交映射支持旋转及镜像，矩阵按行保存。
默认环境层与亮度参考分别由集合声明。

每个体积声明数组层、半尺寸及三行局部变换。
局部变换的线性部分须正交。
混合宽度使用各轴宽度的倒数。
球体使用一致半径，并与盒体共用显式投影开关。

参数 `fade` 位于零至一，`intensity` 为非负有限值。
`luminanceSH` 保存四个线性亮度系数。
集合的 `adaptation` 位于零至一。
数组层在资源装配时按真实层数再次校验。

## 查询与混合

查询接收世界位置、反射方向、单位法线及入射辐照亮度。
体积按列表顺序占用剩余权重。
盒体按最小边界距离混合，球体按径向平方距离混合。
边界覆盖量乘体积淡入权重。

剩余权重大于 `0.01` 时继续查询。
默认环境层接收剩余量。
盒投影使用局部空间的射线出口。
关闭投影时，数组按集合空间中的方向采样。

亮度参考为 `max(dot(sh, normalWithOne), 0.0001)`。
适配比例由当前辐照亮度和该参考共同确定。
比例为 `(L + 2 * min(abs(L / reference), 1)) / (reference + 2)`。
`adaptation` 在线性单位增益与该比例之间插值。

## 资源与运行

体积配置属于场景装配，变更经场景重建进入资源。
资源所有者保留原始 HDR 数组及作者层级。
反射纹理复用绑定二十三，体积缓冲使用绑定三十三。
缓冲包含七行集合参数及每体积七行参数。

三十二体积的缓冲上限为 3696 字节。
每个片元最多遍历三十二个体积。
能力检查覆盖缓冲数量、范围及线性采样支持。
资源释放遵循场景的同步与卸载顺序。

材质变体按集合是否启用进行装配。
普通片元、快照、描述符路径和多重采样共享同一查询。
主场景的实际范围见[探针验收](../acceptance/nr/reflection-probe-fields.md)。
