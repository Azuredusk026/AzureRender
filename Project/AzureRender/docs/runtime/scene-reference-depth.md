# 场景参考深度

具名参考视图以 `produceSceneDepth` 启用深度通道。
该通道使用反向深度及单样本空间绘制。
项目宿主在加载时准备所需程序和帧槽。
当前相机选中该视图时，渲染器绘制参考附件。

## 绘制输入

深度通道复用场景实例、网格、姿态和节点覆盖。
遮罩材质消费绑定的底色或独立覆盖纹理。
独立覆盖沿用材质指定的选级及镜像梯度策略。
场景深度覆盖不透明及遮罩图元。

顶点使用参考裁剪坐标。
片元深度写入 `R32_SFLOAT`，硬件深度使用 `D32_SFLOAT`。
两份附件按零清除并执行大于比较。
每个帧槽各持有两份附件，帧退役后可复用。

深度通道提交场景的可绘制实例。
参考裁剪区间决定附件中的几何覆盖。

## 采集格式

Player 采集在设备完成提交后读取最后的场景附件。
清单中的 `referenceSceneDepth` 记录尺寸、提交序号及文件名。
`reference-depth-r32.bin` 保存片元深度。
`reference-depth-d32.bin` 保存硬件深度。

数据保存 IEEE 754 单精度位值，首行对应场景底边。
行原点由 `rowOrigin` 记录，尺寸对应当前渲染区域。
参考深度用于明确选择该附件的消费通道。
主颜色及快照继续使用各自的设备深度。

## 可见量输入

`produceSceneVisibilityInputs` 启用法线和对象身份。
法线、身份及参考深度共享同一图元覆盖与深度比较。
压缩法线使用 `A2B10G10R10_UNORM_PACK32`。
红绿通道保存以 Y 轴为极点的八面体编码。
方向使用参考视图坐标帧的有符号轴。

对象身份使用 `R8_UINT`。
正值选择当前帧的对象阴影记录，零表示无对象。
背景法线和身份均清除为零。
全部输入按参考深度的行原点和帧槽发布。

启用时，四份附件每槽每像素共占十三字节。
所有帧槽的逻辑附件载荷上限为 256 MiB。

采集清单通过 `packedNormals` 及 `objectIds` 标注文件。
`normalFrame` 记录参考坐标约定 `reference`。
已选择的参考视图决定需要读回的附件。
调用方使用所属提交及尺寸匹配采集。

## 对象可见量

具名视图通过 `objectVisibility` 启用对象可见量。
公共通道读取同一槽位的 R32 深度、法线及对象身份。
当前场景的正向 D16 图集与对象记录提供遮挡输入。
位置、法线、灯向及对象投影使用同一参考坐标帧。

`pixelOffset` 每轴使用负一至一的像素偏移。
泊松过滤相位使用参考附件的行号。
无对象的场景输出全可见。
关闭对象可见量时，选中的其他参考附件仍可采集。

采集清单的 `objectVisibility` 标注 `R8G8_UNORM` 文件。
红通道为全可见，绿通道保存对象可见量。
两个通道按红、绿顺序交错存放。
尺寸、行原点及提交序号与参考深度一致。

`calibration` 提供独立的逆投影矩阵及参考原点。
位置重建与当前对象记录共用该原点。
压缩法线沿用选中视图的有符号轴。
图集、深度及对象身份继续读取实际场景附件。

`objectRecords` 按图集页为接收投影提供原生标定。
锚点采用保存的投影及光方向位值。
对象或灯光变化时，记录按当前生成投影换算。
反向接收投影读取实际正向 D16 图集。

标定页使用同页投影生成图集裁剪矩阵。
光栅顶点使用当前姿态、实例及编辑变换。
参考坐标经绝对原点换算后，按原生次序计算裁剪位置。
图集分区使用 Vulkan 纵向坐标及正向深度。
