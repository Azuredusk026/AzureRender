# 场景可见性与裁剪

> 文档类型：运行时说明
> 状态：生效
> 更新日期：2026-10-05
> 源码入口：`CharacterSceneRenderer.*`、`CameraProjection.hpp`、`TransformParity.hpp`

## 镜头与距离

角色渲染使用正高度 Vulkan 视口。投影翻转 Y，焦距系数为 1.6。主通道、视锥、聚簇深度与拾取射线读取同一镜头契约。

`RenderSettings` 版本为 8。关卡与场景保存以下距离，单位为米。

| 字段 | 默认值 | 有效范围 |
| --- | --- | --- |
| `cameraNear` | 0.1 | 0.01 至 10 |
| `cameraFar` | 100 | 大于近裁剪距离，至多 5000 |
| `shadowDistance` | 100 | 大于近裁剪距离，至多为远裁剪距离 |

公开探索关卡使用近裁剪 0.1、远裁剪 500、阴影距离 100。级联阴影按阴影距离划分。缺少这些字段的场景使用默认值。无效关卡候选保留活动场景。

## 几何与变换

glTF 单面材质的正面按逆时针绕序提交。运行时线性变换的行列式为负时，主体、透明与轮廓选择镜像绕序。双面材质提交两面。阴影通道提交两面并执行深度写入。

导入器烘焙镜像变换时交换三角形的第二、第三个索引。法线使用逆转置。切线方向与法线正交化，切线手性包含镜像奇偶性。

运行时模型与编辑变换的法线使用逆转置。切线手性包含两种变换的行列式符号。缩放各轴绝对值至少为 0.001，至多为 100000。分量必须有限。

## 可见性与深度

CPU 与 GPU 使用 Vulkan 裁剪范围，深度满足 0 至 w。包围盒与视锥相交时保留实例。动画包围盒覆盖关节变换和 Morph 位移。材质位移与轮廓扩张进入保守边界。

不透明表面执行深度测试与写入。透明表面执行深度测试，按已有排序规则混合。可见性决定实例是否提交，背面剔除决定表面朝向，深度测试决定像素遮挡。

## 显示诊断

固定相机捕获同一帧，再按表中开关定位异常。捕获清单记录开关、镜头距离与状态哈希。

| 开关 | 诊断用途 |
| --- | --- |
| `--disable-gpu-culling` | CPU 可见性与直接提交 |
| `--disable-culling --disable-gpu-culling` | 全部实例提交 |
| `--qa-disable-face-culling` | 表面朝向与镜像绕序 |
| `--qa-disable-depth-test` | 深度遮挡与提交顺序 |

正式验收使用默认状态。近远裁剪始终由投影执行。背面或深度诊断开关分别控制主体材质状态。

运行公共专项夹具：

```powershell
python tools/test_scene_visibility_gpu.py --executable build/ninja-msvc-release/AzurePlayer.exe --output build/r6/visibility
```

夹具覆盖镜像、混合奇偶性批次、双面、透明、深度与裁剪边界。法线与切线比较使用导入烘焙结果作为独立参照。每次捕获检查验证层与资源释放。
