# 引擎交付与证据范围

> 文档类型：交付说明
> 适用范围：Windows x64 与当前引擎接口

## 交付组成

引擎安装树提供编辑宿主、Player 和构建工具。
探索游戏与场景检视采用独立项目内容。
两种工作流通过同一运行时契约装配。
项目可以移动到其他目录并独立启动。

接口位于 `share/AzureRender/contracts/`。
该目录提供接口源码快照与版本化模式。
`manifest.json` 记录接口、采用范围与文件哈希。
项目扩展按仓库构建目标及依赖编译。

接口快照用于阅读、契约追踪和模式消费。
预编译的通用 C++ SDK 属于后续专项范围。
默认脚本为 Lua，托管后端为可选原型。
后端条件见[脚本服务](script-services.md)。

## 来源与字节核对

本次源码归档按原始字节复制文件。
归档清单记录文件路径、大小和 SHA-256。
生产输入与冻结的构建来源清单逐项核对。
源码、素材、许可和运行结果分别保存清单。

源码快照用于核对冻结的生产输入。
开发构建使用具有历史和文档的完整 Git 仓库。
阶段覆盖检查依赖对应提交与原始验收证据。

历史证据保留各阶段的原始记录与哈希。
历史源码按对应阶段的 Git 提交定位。
精确换行记录通过还原后的原始哈希校验。
无法还原原始字节的输入列入单独审计限制。

严格审计使用 `exact-bytes`。
覆盖核查使用 `committed-content` 并报告字节限制。
覆盖通过证明接口、任务、测试和提交关联完整。
历史字节审计的完成状态单独报告。

## 校验安装中的接口

以下命令在引擎安装目录执行。
需要 Python 3.11 或更高版本。
成功时输出接口数量和完整文件数量。

```powershell
python share/AzureRender/tools/write_engine_contracts.py --verify --output share/AzureRender/contracts
```

校验拒绝缺失、额外文件、路径逃逸和字节篡改。
独立游戏的运行条件见[游戏发布](game-publishing.md)。
复用步骤见[引擎复用工作流](../tutorials/engine-reuse.md)。
