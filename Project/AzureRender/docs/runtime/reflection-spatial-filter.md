# 反射空间过滤

`ReflectionSpatialFilterGpu` 持有反射过滤的计算资源。
调用者提供深度、表面数据及颜色层级。
资源按在途槽位隔离，调度使用 `ComputePass`。
主场景的反射生产与历史由宿主另行组织。

## 输入与参数

输入为完整的二维图像视图。
深度读取红通道，表面的红、绿通道表示粗糙度和可信度。
颜色层级使用线性浮点格式，原始层级由调用者提供。
最大分量压缩先于颜色层级生成。

| 参数 | 默认值 | 规则 |
| --- | --- | --- |
| maxLod | 6 | 非负整数，低于两个输入的层级数 |
| sharpLod | 0.25 | 0 至 1 |
| depthFalloff | 0.01 | 0 至 1000，按视深度单位衰减 |
| minimumWeight | 0.01 | 大于零且不超过一 |
| depthDecode | `[1,0]` | 有限的仿射深度解码参数 |
| reciprocalDepth | false | 启用后对仿射深度取倒数 |
| encoding | MaxComponent | 线性 HDR 或最大分量压缩 |

倒数深度的仿射分母须在 `[0,1]` 上保持正值。
公共颜色辅助函数校验有限的非负输入。
压缩结果须在浮点精度下保持小于一。
非法数值在分配或记录命令前返回诊断。

## 帧布局

参数由三行向量组成，共 48 字节。
宽高各限制为一至 8192。
在途槽位为一至八，输出总预算为 512 MiB。
最大层级受输入尺寸及实际层级数共同约束。

| 行 | 数据 |
| --- | --- |
| 0 | 宽高倒数、最大层级、锐利阈值 |
| 1 | 深度仿射参数、倒数开关、深度衰减 |
| 2 | 最小归一化权重、颜色编码、输出宽高 |

每个槽位拥有参数缓冲、描述符和 `RGBA32F` 输出。
过滤使用自身的六个描述符绑定。
相机、材质及应用描述符保持各自布局契约。

## 同步与生命周期

输入在记录前进入 `SHADER_READ_ONLY_OPTIMAL`。
调用者负责输入的计算着色可见性。
过滤资源同步自身输出的存储写入及后续采样。
输出通过 `output(slot)` 借用句柄。

宿主在对应提交完成后复用槽位。
同次提交可记录使用不同参数的两个槽位。
销毁前由宿主等待全部消费者完成。
输入图像及其视图由调用者持有。

空视图、尺寸不符及输出别名在记录前被拒绝。
失败校验保持描述符与命令记录不变。
构造失败及销毁沿 RHI 释放已创建资源。

## 计算与验证

每级执行深度加权的 4×4 核，并混合相邻层级。
锐利分支采用基础层最近邻采样。
`precise` 与显式 `fma` 固定坐标运算次序。
可信度独立写入输出 Alpha。

验证覆盖常量层级、压缩颜色、深度分离及尾部工作组。
真实输入保留原版 `R11G11B10_FLOAT` 颜色格式。
跨 API 误差按原版输出格式的量化单位核对。
结果见[公共过滤验收](../acceptance/nr/reflection-spatial-filter.md)。
