# 材质输入与实例坐标系

日期：2026-10-23。
本页定义现行布局、资源所有权和新增输入准入规则。
画像版本和材质文档版本分别维护。
特殊表面通过公共解释器形成运行材质。

## 纹理语义

现行每材质有九个索引纹理槽。
固定描述符与索引路径使用相同语义。
下表的绑定号指固定描述符路径。
共享环境、主阴影及宿主目标使用独立输入。

| 槽 | 固定绑定 | 语义与所有者 |
| --- | --- | --- |
| 0 | 1 | 基础颜色；画像决定颜色空间 |
| 1 | 2 | 表面法线；线性数据 |
| 2 | 3 | 金属粗糙度；可由明确画像消费 Alpha 镜面 |
| 3 | 5 | 镜面或自发光；Alpha 来源由 `specularInput` 声明 |
| 4 | 6 | 风格遮罩、漫反射色带、SDF 遮罩或折射扰动 |
| 5 | 7 | Matcap、传统高光色带、二维头发色带或双域 SDF 色带 |
| 6 | 8 | 头发独立双法线；一般材质使用缺省值 |
| 7 | 12 | 面部 SDF 或投影头发参数图 |
| 8 | 25 | 影色查找表 |

眼睛拥有槽 0、4、5 的显式颜色空间与采样规则。
投影头发独占槽 5、6、7 的对应语义。
双域 SDF 拥有槽 4、5、7。
折射和合成分支通过合法组合检查声明所有权。

普通 PBR、服饰和金属保留标准四槽。
`specularInput` 只选择已有 Alpha 来源及倍率。
皮肤和脸部的环境漫反射通过具名参数声明。
非法重叠由加载器拒绝。

## 材质参数布局

绑定 27 使用 `PackedMaterialSurfaceProfile`。
布局版本为 1，大小为 96 字节，对齐为 16 字节。
六行数据由稳定材质索引读取。
CPU 大小、偏移和表面选择均有自动检查。

| 所有者 | 使用规则 |
| --- | --- |
| 投影头发 | 双叶参数、边缘及法线、次级颜色、对象三轴 |
| 径向眼睛 | 形状、高光、散射、Matcap、直接光及 UV |
| NPR 漫反射 | 首行记录阴影和法线输入策略 |
| 通用、服饰、金属 | 第六行 ZW 声明独立镜面来源及倍率 |

新增条纹和距离描边须有具名输入及显式所有权。
容量扩展同时调整 CPU 布局、程序声明和版本检查。
纹理扩展需要固定与索引两条路径的实际消费证据。
每阶段采样器和集合预算分别核对设备限制。

## 实例坐标系

投影头发可声明 `hair.projectedRamp.frame`。
版本 1 字段为 `schemaVersion`、`node`、`basis`。
`node` 指向唯一命名节点，`basis` 是九个列主序数值。
基底必须正交且各轴归一。

双域 SDF 通过 `headNode` 与 `headBasis` 声明同类帧。
同一网格资源中的显式帧必须一致。
缺失节点、重名节点及冲突基底产生加载错误。
材质覆盖后再次检查完整资源的帧关联。

运行帧由实例模型矩阵、当前节点姿态和基底形成。
每个实例分别消费自身姿态。
顶点程序通过派生功能位消费显式头发帧。
未声明显式帧的投影画像使用对象帧。

显式帧与绘制用的 gizmo 变换共同组合。
坐标系机制支持独立头发资产和带 SDF 的完整角色。
源角色节点名称及常量转换归属项目内容。
原生坐标系等价还需实际帧和动态姿态证据。

## 资源所有权

`SampledTextureCache` 归属单个渲染器和设备。
纹理输入不可变，缓存键包含像素及上传语义。
格式、尺寸、mip、过滤、包裹及 Alpha 规则参与身份。
加载宿主串行访问缓存。

描述符借用缓存拥有的图像和采样器。
命中会释放重复的 CPU 像素，未命中转移像素存储。
上传失败保留输入，临时对象负责回收资源。
所有 GPU 使用退休后，宿主方可销毁所属渲染器。

材质表、实例数据和纹理分别持有生命周期。
预览视图使用宿主的在途提交与退休规则。
跨视图的共享优化以测量为依据。
资源计数、常驻字节和进程峰值分别记录。
