# 图像导入与精度

## 支持范围

公共导入接受注册表声明的图像格式。
格式能力通过 `asset.formats` 查询。
文件筛选与资产分类使用同一注册描述。
图片按独立资源保存，材质通过引用使用。

| 格式 | 像素范围 | 解码器 |
| --- | --- | --- |
| PNG | 八位、十六位、灰度及透明 | stb |
| JPEG | 八位颜色与灰度 | stb |
| BMP、TGA | 八位像素与受支持透明通道 | stb |
| PPM、PGM 内容 | P2、P3、P5、P6，至十六位 | 有界解析器 |
| HDR | 线性浮点 RGBE | stb |
| EXR | 扫描线 RGB 或 Y，及可选透明 | OpenEXR |
| TIFF | 连续扫描线 RGB 或灰度 | libtiff 4.7.2 |
| WebP | 静态八位颜色及透明 | libwebp 1.6.0 |
| DDS、KTX2 | 二维 RGBA、BC 与 Basis，及原始 mip | DirectXTex、KTX-Software |

PNM 使用 `.ppm` 扩展名接入。
TIFF 接受 `.tif` 与 `.tiff`。
JPEG 接受 `.jpg` 与 `.jpeg`。
扩展名和内容共同决定可用格式。

TIFF 支持八位、十六位整数及三十二位浮点。
方向标记一至四统一为左上起始行序。
关联透明通道转换为直通透明。
分块、调色板和分离平面布局返回明确诊断。

EXR 的数据窗口可以包含负坐标。
输出尺寸由数据窗口确定。
RGB 或灰度保留线性范围。
静态 WebP 使用单幅图像解码契约。

## 像素与预算

`DecodedImage` 记录尺寸、源通道和颜色空间。
像素使用直通透明及左上起始 RGBA 行序。
八位、十六位和浮点存储各自保留精度。
每次任务独立拥有解码器和像素缓冲。

单幅来源上限为 64 MiB。
宽高分别位于一至 8192。
单幅解码像素上限为 256 MiB。
尺寸和乘法预算在像素分配前校验。

PNG、JPEG 等整数图像默认标记为 sRGB。
HDR、EXR 和浮点 TIFF 标记为线性。
法线、遮罩和粗糙度由材质槽定义数据语义。
透明通道始终按线性数值处理。

## 材质与环境

材质运行存储采用八位 RGBA。
高精度输入在材质槽转换时记录精度损失。
超出零至一区间的数值记录裁剪损失。
颜色槽编码线性 RGB，数据槽保留线性数值。

独立图片预览使用相同解码与转换接口。
glTF 的外部和内嵌图片使用同一接口。
转换损失进入导入摘要或运行诊断。
法线 mip 沿用归一化过滤规则。

环境贴图使用线性 RGBA16F。
HDR 的亮度在半精度有限范围内保留。
超过绝对值 65504 的像素返回范围诊断。
灰度、透明和偏移窗口统一由解码层解释。

## 导入与重导入

图像准备使用共享复制与指纹校验。
发布前再次核验来源和暂存产物。
取消、来源变化和目标冲突清理任务暂存。
中文路径及大写扩展名使用 UTF-8 契约。

重导入要求已保存且空闲的项目。
`settings.texture` 使用纹理设置字段。
后台验证解码、采样设置与 mip 生成。
内容事务维持稳定标识和引用。

阶段证据见 [G19 验收](../acceptance/g19/2026-10-12.md)。
人工操作和最终性能在 P8 集中复核。

二维容器的设置与范围见[纹理容器交换](texture-containers.md)。
