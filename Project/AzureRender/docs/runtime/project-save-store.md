# 项目存档与内容目录

`AzureRuntime` 提供 `ProjectSaveStore`。
持久实例接收根目录和项目身份。
默认实例将状态保留在当前会话内。
脚本存档、媒体清单和独立工具共用该契约。

## 槽与版本

槽名使用小写字母、数字、短横线或下划线。
长度为 1 至 64 个字符。
项目身份按原始字节编码，大小写保持隔离。
持久文件的外层 `schemaVersion` 为 1。

`read` 返回当前槽的 `payload`。
缺失、损坏或不兼容的外层返回空值。
`write` 写入完整 JSON 快照，上限为 1 MiB。
较新外层版本拒绝写入，并保留已有文件。

`writeIfUnchanged(slot, expected, payload)` 比较当前值。
快照匹配时提交并返回 `true`。
快照过期时保留当前值并返回 `false`。
内容版本及业务合并由调用方校验。

## 并发与生命周期

持久读写通过槽级文件锁协调。
读取使用已有锁文件的共享只读句柄。
写入持有独占锁，随后校验版本并发布快照。
会话实例在同一互斥区内比较及更新。

读取缺失槽时保持文件系统原状。
Windows 使用候选文件及带备份的替换操作。
替换异常时尝试恢复已有文件，恢复失败时保留备份。
调用方接收异常并保留未提交的业务状态。

`AzureFoundation` 的 `FileLock` 提供共享和独占模式。
默认等待期限为 5 秒，支持取消回调。
共享模式只打开已有普通文件。
作用域退出及构造失败均释放原生句柄。

## 内容目录

`contentDirectory(name, kind)` 返回项目内受控路径。
名称沿用槽名校验，查询保持只读。
`Published` 定位 `content-<name>`。
`Staging` 定位同级 `.content-<name>-staging`。

会话实例拒绝持久内容目录请求。
项目和内容目录须解析至各自分配的位置。
调用方持有内容文件的创建、发布及释放责任。
暂存内容经验证后进入发布区，再提交清单引用。
