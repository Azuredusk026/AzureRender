# 灯光接收范围

灯光的 `shape.receivers` 选择直接光的接收表面。
省略该对象时，场景与角色均接收该灯。
对象使用版本一，三个字段均须显式提供。
非法版本、未知字段和非布尔开关触发导入错误。

```json
{
  "receivers": {
    "schemaVersion": 1,
    "surfaces": true,
    "characters": false
  }
}
```

场景角色依据显式的角色表面画像识别。
显式 `nprDiffuse` 表面也归入角色接收组。
两个开关均为假时，该灯的直接贡献为零。
间接光照与反射探针各自消费所属资源。

## 运行与保存

灯光快照持有接收配置，GPU 缓冲按帧上传。
每灯维持一百二十八字节布局。
盒参数第四分量保存场景位与角色位。
光栅分支在累加该灯的任何贡献前检查接收位。

路径追踪的通用表面消费场景接收位。
发光几何通过所属材质提供照明。
接收配置参与路径追踪历史指纹。
修改配置时，后端重建对应的累积历史。

`.azscene` 版本十一保存 `lightReceivers`。
版本一至十采用全部接收的默认值。
关卡 JSON 与编辑保存共用同一类型化配置。
原生参数由离线转换提供，渲染器消费公共接收位。

## 原生转换

`decode_character_light_data` 读取三十二字节附加结构。
入口位于 `tools/endfield_native/lighting_ecs.py`。
结果保留四维参数、模式、专用开关和散射参数。
结构偏移由原生访问器与结构写入程序交叉核验。

`render_light_receivers` 转换接收范围。
源模式十六令角色接收位为假。
角色专用开关令场景接收位为假。
原生各模式的颜色响应与运行激活继续独立验收。

## 类型归属

`LightShape`、`LightInfluenceBox` 和 `LightReceivers` 归属 ECS 值契约。
其头文件位于 `src/ecs/`，供组件、反射和渲染共同消费。
值类型只依赖标准库，描述符与 GPU 打包归属渲染模块。
场景解析和编辑操作沿用同一组字段及校验。
