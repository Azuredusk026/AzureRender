# 屏幕反射生产组合

`ScreenReflectionGpu` 负责组合本帧屏幕反射资源。
它依次执行深度层级、射线、信号层级及空间过滤。
启用时间过滤时，射线信号先经过历史合成。
输入借用不透明颜色和[表面快照](reflection-surface-snapshot.md)。
独立 GPU 夹具与角色场景共享此生产接口。

## 输入与预算

输入尺寸须与构造尺寸一致，且视图有效。
宽高限制为一至 8192，在途槽位为一至八。
层级上限为一至十四，默认七级。
实际级数同时受输入尺寸约束。
`resolutionDivisor` 接受一或二，默认一。
二表示按各轴整除二生产，最小尺寸为一。
源输入保持完整分辨率，输出和层级使用生产尺寸。
基础深度先执行最近表面归约，再生成层级。
射线与过滤共享整数像素选择规则。
每轴源索引为 `((2*p+1)*sourceSize)/(2*outputSize)`。
整数除法向下取整，选中像素的完整元数据保持关联。
相机与射线参数沿[射线契约](reflection-ray.md)校验。

资源采用保守的浮点回退预算。
图像预算为各级像素数乘 24 字节。
另加基础像素数乘 16 字节，再乘槽位数。
合计上限为 512 MiB。
源附件及宿主的其他资源分别核算。

构造参数 `temporal` 默认关闭。
启用时另计每个基础像素 20 字节，再乘槽位数。
该预算覆盖单层当前颜色及可信度的浮点回退。
历史继续使用既有信号层级的基础图像。
组合总上限保持 512 MiB。

`supported` 查询实际格式能力和组合用途。
信号格式沿[信号层级](reflection-signal-pyramid.md)选择。
主场景同时检查所属队列的计算能力。
捕获清单记录实际准备结果、启用状态及级数。

## 输出与同步

输出为线性 `RGBA32F` 图像。
RGB 保存反射辐射，Alpha 保存命中可信度。
输出采用 `GENERAL` 布局及只读存储访问。
构造时将输出清零，并建立读取可见性。
宿主可在首次生产前发布稳定的描述符。

场景材质使用绑定 37 读取输出。
片元程序显式执行四点插值。
材质采样器额度沿既有布局计算。
只读存储声明遵守 [Vulkan 存储访问约束](https://docs.vulkan.org/spec/latest/appendices/spirvenv.html)。

输入在记录前进入 `SHADER_READ_ONLY_OPTIMAL`。
宿主建立附件写入到计算读取的可见性。
组合资源持有内部图像转换及过滤输出屏障。
资源图登记输出生产到主场景消费的依赖。
直接记录路径使用同一资源及生产顺序。

## 时间过滤输入

`record` 可借用 `ScreenReflectionHistoryInputs`。
该输入要求构造时已启用时间过滤资源。
输入包含前帧颜色、可信度、解码运动和接收权重。
历史使用与当前射线相同的颜色编码和图像格式。
运动为当前减前帧的 UV 位移。
接收权重包含调用者完成的遮挡显露检查。
公共运动可由[重投影资源](reflection-reprojection.md)转换为这些输入。
运动及权重的归一化坐标应与生产输出关联。
全部视图在录制前进入采样布局。

`history(slot)` 返回信号基础层的颜色及可信度。
成功完成 `record` 后，这些视图可作为后续历史输入。
有效历史的前帧视图须完整且与当前输出分离。
无效历史可省略前帧视图，组合使用当前信号占位。
无效历史仍要求完整的运动及接收权重视图。
没有历史输入时，组合直接生产本帧信号。

时间参数沿[公共过滤契约](reflection-temporal.md)检查。
非法参数及输出别名在写入描述符前被拒绝。
单层当前信号转换为采样布局后，执行历史合成。
后续层级与空间过滤消费合成结果。

## 生命周期与诊断

每个槽位独立持有图像、参数和描述符。
复用槽位及销毁资源前，宿主等待消费者完成。
输入视图及相机快照由宿主持有。
非法输入在记录计算命令前返回诊断。
输入引用自身过滤输出时，记录操作被拒绝。

历史有效性、成功提交及槽位选择由宿主管理。
读取前帧历史与覆盖当前槽位须遵守所属队列顺序。
取消记录保持上次实际提交的历史身份。
当前槽位与所选历史图像相同时，调用者拒绝该历史。
主场景的运动前置生产及时间历史调度继续按计划接入。

场景通过 `screenReflectionComputePrepared` 记录准备状态。
`screenReflectionComputeActive` 记录当前帧实际启用状态。
`screenReflectionPreparation` 记录准备结果。
`screenReflectionLevels` 记录实际层级数。
条件不足时，场景选择现有片元射线路径。

## 验证范围

`AzureRender.ScreenReflection` 覆盖预算及非法输入。
`AzureRender.ReflectionRayGpu` 覆盖独立及组合生产。
投影覆盖透视、正交、偏移、旋转及移动遮挡。
两种格式及两个槽位分别验证输出和释放。
主场景由镜面和表面快照工具继续验收。

原版层级射线等价与动态时间历史仍有独立验收项。
完整画面及持续帧预算按开发总计划验收。
