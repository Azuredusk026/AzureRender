# 加载会话的资源路径

## 所有权与输入

`PreparedResourcePaths` 归属于资源模块。
对象持有资源定位器的副本，并由宿主主线程使用。
Player 与批量资产检视可各自持有独立对象。
每批输入为有序的 UTF-8 路径数组。

新路径通过 `ResourceLocator::resolveAsset` 解析。
当前周期已确认的路径直接返回同一结果。
重复路径共享一次解析结果，并保留输出顺序。
成功后，活动表只保留当前批次的请求。

## 失败与失效

解析成功后整体提交活动表。
路径解析或内存分配失败时，已确认状态保持有效。
空批次清空活动表，`clear` 建立新的查询周期。
各个对象的资源根和状态彼此独立。

文件变动通过显式重载进入新的解析周期。
直接资源定位接口逐次执行当前文件检查。
周期内的稳定路径按已确认的加载结果使用。
宿主重开及渲染器资源创建会重设解析周期。

## 宿主接入

宿主每帧物化当前场景节点、材质和变换。
随后将本帧资源路径交给活动表解析。
完整结果生成后，写入当前场景描述。
资源加载失败沿用正式宿主错误路径。

显式资产重载使用渲染器创建入口重设路径表。
项目配置重新安装资源定位器时重设表实例。
路径文字变化会触发新路径的正式解析。
活动表的保留规模跟随本批请求数量。
