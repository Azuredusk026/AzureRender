# 顶点颜色输入

资产的可选 `vertexColors` 保存线性 RGBA。
颜色与基础顶点采用相同索引。
基础顶点大小为 108 字节，计算蒙皮步长为 27 字。
颜色具有独立的 GPU 顶点流。

## 资产格式

glTF 的 `COLOR_0` 支持三分量和四分量。
三分量颜色的透明度为一。
支持浮点、归一化无符号字节和归一化无符号短整数。
值须有限且位于零至一。

连续及交错存储均校验偏移、步长和缓冲范围。
每个颜色访问器的数量须与位置数量一致。
稀疏颜色及其他布局在加载时报告诊断。
混合图元为缺少颜色的顶点提供白色。

## 公共绑定

`GraphicsPipelineDesc.vertexBindings` 描述显式顶点流。
各项提供绑定号、字节步长和输入频率。
`VertexAttributeDesc.binding` 指明属性来源。
重复绑定、重复位置及缺少来源均在创建前失败。

单流简写使用空绑定列表及 `vertexStride`。
显式列表使用零值的 `vertexStride`。
公共预算为十六个绑定及十六个属性位置。
Vulkan 后端同时检查设备的顶点格式支持。

`bindVertexStream` 更新指定绑定。
`bindVertexBuffer` 提供绑定零的既有入口。
零步长让共享白色缓冲提供常量输入。
绑定与寻址依据 [Vulkan 顶点输入规范](https://docs.vulkan.org/refpages/latest/refpages/source/VkVertexInputBindingDescription.html)。

## 材质消费

公共无光照图层通过 `vertexColor` 布尔值选择乘法。
默认值为假，颜色数据与材质消费分别拥有。
颜色在采样通道解释之后与材质倍率共同消费。
亮部、软交界、深度淡出及节点透明度沿用图层规则。

完整材质文档保存相同字段。
材质表版本为十五，大小为 272 字节。
第十二行的第二分量记录颜色消费标记。
参数定义见[无光照图层](unlit-texture-layers.md)。

## 资源与录制

有颜色的网格上传独立 RGBA 缓冲。
共享白色缓冲为十六字节。
录制快照保存对应的不可变缓冲句柄。
加载、使用和关闭采用网格的生命周期。

颜色缓冲覆盖基础网格及附加资源。
透明颜色管线按实际颜色输入选择步长。
上传失败释放当次的暂存与目标缓冲。
交换链重建与场景关闭分别回收对应资源。
