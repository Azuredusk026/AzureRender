# 视口导航与辅助显示

> 文档类型：运行与制作说明
> 日期：2026-10-10
> 适用范围：编辑态视口与用户工作区

## 漂浮与环视

在视口按住右键进入漂浮模式。
鼠标向右移动时向右看，向上移动时向上看。
环视保持相机位置，移动同时平移位置和观察中心。
首帧按下右键保持视角稳定。

| 输入 | 操作 |
| --- | --- |
| 右键与 WASD | 前后与左右移动 |
| 右键与 E/Q | 世界竖直方向升降 |
| 右键与 Shift | 按设置倍率临时加速 |
| 右键与滚轮 | 调整基础飞行速度 |
| 松开右键或 Esc | 退出漂浮并恢复光标 |
| Alt 与左键 | 围绕观察中心旋转 |
| 中键 | 平移视图 |
| 普通滚轮 | 透视调整距离，正交调整显示高度 |

飞行输入使用归一化方向，斜向移动保持同一速度。
默认基础速度为五米每秒，加速倍率为四。
右键滚轮按指数比例调整速度。
速度范围为每秒 0.01 至 10000 场景单位。

视口底部显示投影模式和操作提示。
漂浮期间显示实际速度及退出方法。
设置面板的 `editor.camera` 字段控制导航参数。
基础速度属于用户设置，项目文档保持独立。
默认捕获优先采用设备原始鼠标输入。
`editor.camera.rawMouse` 可选择常规相对输入。
原始输入根据平台能力启用，释放时恢复常规模式。

窗口失焦、弹窗或关闭视口会释放导航。
运行预览和操纵器拖动由各自输入状态管理。
右键拥有移动输入，释放后 W/E/R 切换变换工具。
大纲单击选择，双击或 F 定位选择集合。

## 投影与方向

视口右上角方向控件提供六轴方向操作。
View 菜单同时提供六向和两种投影入口。
轴方向操作进入正交视图，并保留观察中心。
顶部和底部视图使用合法的 Z 轴向上向量。

渲染、拾取、构图和操纵器共享相机描述。
正交拾取使用平行射线及各像素的独立起点。
F 根据世界边界、视口比例和投影预留构图边距。
灯光分区按投影类型解释屏幕覆盖范围。

## 辅助显示

网格、相机和光源由辅助提供者注册。
View 菜单为每类选择隐藏、选中或全部显示。
默认显示网格，并显示选中对象的相机与光源辅助。
显示策略保存在用户工作区。

网格按相机尺度选择十进制步长。
光源辅助使用实际范围绘制环线。
辅助线先经共同投影的齐次裁剪，再绘制到视口。
单次提供者集合最多输出 4096 条合法线段。

辅助线作为编辑叠加层显示，具有独立透明度。
场景深度遮挡不参与其显示策略。
提供者消费只读场景，操作通过生产编辑服务执行。

## 公共操作与来源

| 操作 | 参数或结果 |
| --- | --- |
| `viewport.describe` | 当前相机描述 |
| `viewport.orientation` | `axis` 为正负 X/Y/Z |
| `viewport.projection` | `value` 为 perspective 或 orthographic |
| `viewport.fly-speed` | 有限滚轮步数 `steps` |
| `viewport.overlays` | 注册类别与当前策略 |
| `viewport.overlay-policy` | `category` 与 `policy` |

漂浮状态组织参考 Fermion 的编辑相机。
版本与许可见方向控件的 `source.json`。
方向绘制适配 ImViewGuizmo，采用 MIT 许可。
相机所有权、输入捕获及投影解释由引擎服务维护。
