# 脚本服务与托管原型

> 文档类型：运行契约
> 适用范围：Windows x64、Lua 与可选托管后端

## 服务与模块

`IScriptRuntime` 定义脚本服务生命周期。
Player 与编辑预览通过项目装配选择服务。
运行时核心持有接口与注册表。
语言实现归属于独立构建目标。

| 目标 | 职责 |
| --- | --- |
| `AzureRuntime` | 服务接口、项目配置与注册表 |
| `AzureScriptingHost` | 绑定描述、对象守卫、事务与回调会话 |
| `AzureLuaScripting` | Lua 值转换、沙盒与脚本生命周期 |
| `AzureManagedScripting` | CoreCLR、NativeAOT 与托管入口 |
| `AzureProjectRuntime` | 后端注册与项目装配 |

服务具有初始化、固定步、事件与关闭接口。
关闭具有幂等语义，关闭后拒绝调度。
宿主回调和组件操作在创建线程执行。
错误列表保留最近 128 条不同诊断。

## 项目与内容

项目的 `scripting` 字段选择后端。
默认值为版本 1 的 `lua` 配置。
托管配置中的模块采用资产引用。
`--check-project` 验证后端装配与模块入口。

| 字段 | 契约 |
| --- | --- |
| `schemaVersion` | 整数 `1` |
| `backend` | `lua`、`coreclr` 或 `nativeaot` |
| `module` | 托管模块的挂载路径或资产标识 |
| `runtimeConfig` | CoreCLR 运行配置的资产引用 |

Lua 配置包含版本与后端两个字段。
托管项目通过 `azure.script` 引用 `.azscript`。
该清单声明版本、类型及可选程序集引用。
资产数据库追踪程序集依赖和内容指纹。

```json
{
  "schemaVersion": 1,
  "type": "Azure.Samples.SceneAnnotator",
  "assembly": "assets:/managed/Azure.Samples.dll"
}
```

CoreCLR 要求 `assembly` 指向用户程序集。
类型继承 `Azure.Engine.ScriptBehaviour`。
类型提供公开的无参数构造函数。
NativeAOT 类型由发布期清单直接注册。

## 绑定与对象身份

唯一描述为 `schemas/script_bindings.json`。
生成器输出 Lua 描述与 C# 包装。
构建前的检查模式拒绝生成漂移。
托管握手同时核对版本和描述哈希。

`AzureObject.Id` 为只读节点标识。
公共宿主提供查询、输入与组件操作。
它还提供结构修改和关卡、声音、界面请求。
参数类型与权限来自同一份描述。

对象携带实体编号、世代、节点与场景版本。
编号复用、世界交换与场景切换使旧对象失效。
会话使用进程内唯一令牌访问公共宿主。
保存的回调在关闭后返回过期错误。

参数具有 16 层深度与 1024 项数组预算。
请求与响应的字节预算各为一 MiB。
调用者先提供完整响应缓冲区再执行操作。
语言边界复制字符串和数组，保留各自所有权。

## 初始化与运行回调

初始化暂存组件属性与宿主效果。
候选失败时取消暂存并保留有效脚本。
提交校验属性、对象身份和结构队列。
提交失败恢复属性与原有队列。

旧实例在候选提交后执行关闭回调。
候选组件值具有交接时的写入优先级。
旧实例关闭错误进入脚本诊断。

结构操作在下一帧边界应用。
初始化的外部宿主事件在提交后交付。
交付失败属于运行期事件错误。
已交付的应用效果由应用负责恢复。

普通运行回调具有即时组件写入语义。
回调异常使对应脚本停止执行并记录诊断。
其他实体的有效脚本继续运行。
脚本拥有的语言状态随实例分别管理。

## 能力与部署

| 后端 | 重载 | 内容权限 | 部署条件 |
| --- | --- | --- | --- |
| Lua | 源码候选验证后替换 | 有界沙盒与指令预算 | 引擎 Lua 依赖 |
| CoreCLR | 用户程序集与清单重载 | 受信任编译扩展 | 安装 .NET 9.0.11 运行库 |
| NativeAOT | 重建模块并启动新进程 | 受信任编译扩展 | 编译后的原生模块 |

CoreCLR 从内存加载用户程序集。
每个候选使用可回收加载上下文。
诊断通过弱引用与实际垃圾回收检查卸载。
原型支持单个用户程序集及引擎 API 引用。

托管引擎入口与原生模块映射保留至进程退出。
会话关闭释放脚本对象、候选和宿主令牌。
NativeAOT 使用发布期直接类型构造。
后端能力查询明确报告其重载范围。

托管构建选项默认为关闭。
开启时使用 .NET SDK 9 与 MSVC。
构建产物、生成文件和中间文件位于 `build/`。
安装清单与构建来源记录包含可选模块。

教程见[托管脚本工作流](../tutorials/managed-scripts.md)。
源码许可见 `third_party/dotnet/source.json`。
阶段范围见[实施步骤](../plans/g11-implementation.md)。
