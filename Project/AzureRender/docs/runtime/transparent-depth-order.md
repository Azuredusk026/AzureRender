# 透明三角形深度准备

## 数据与调用

场景渲染器按实例计算透明三角形的相机深度。
当前姿态及形变首先产生顶点位置。
不可变资产拓扑保存所用顶点并集及三角形局部索引。
当前实例按该并集计算紧凑的世界坐标数组。
三角形质心及深度遵循当前浮点计算顺序。

世界坐标缓存属于当前实例和当前准备调用。
模型、姿态、形变及相机分别使用实际帧输入。
三角形按深度降序排列，相同深度保持输入顺序。
排序结果写入当前帧的透明索引缓冲。

至少 4096 个顶点时，宿主准备线程池处理互不重叠的顶点区间。
位置回调须支持并发只读访问，任务汇合后执行深度与排序。
关闭并行录制或缺少线程池时，当前调用采用串行准备。
拓扑由渲染器持有，资产索引存储在其生存期内保持有效且不可变。
索引地址、数量、顶点数或图元范围改变时重新准备。
工作数组复用容量，卸载释放拓扑及临时存储。

## 稳定排序接口

公共入口为 `stableDepthOrder`。
输入为索引序列及只读的单精度深度数组。
结果更新索引序列，深度原字节保持一致。
越界索引在输出修改前报告异常。

大型、有限且尚未有序的输入使用稳定基数排序。
四轮八位桶分发保持相同键的相对次序。
正零与负零使用相同键。
小型或非有限输入使用标准稳定比较排序。

每次调用拥有独立工作区，可用于独立任务。
临时索引容量与输入规模成正比，桶计数固定为二百五十六项。
绘制、资源绑定及图形数据布局遵循所属通道。
图形程序和相机深度计算按所属输入契约执行。
