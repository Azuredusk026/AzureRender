# 独立裁剪图

状态：公共输入、来源层级及错误退出已验证。
生成层级的覆盖保持继续验证。
适用范围为版本二画像的 `MASK` 表面。
材质类别支持通用、织物和头发。

颜色、深度、描边、阴影与运动共享覆盖输入。

## 输入契约

`azureRenderMaterial.coverageTexture` 声明独立图像。
对象版本为一，`texture` 引用材质纹理表。
`channel` 支持 `red` 和 `alpha`，缺省为 `red`。
裁剪阈值由标准材质的 `alphaCutoff` 持有。

图像保留自身的尺寸、完整层级及采样设置。
导入器将选定通道逐级复制到内部透明通道。
基础颜色及其透明度继续用于颜色计算。
覆盖的层级计算使用独立图像的实际尺寸。

完整材质文档通过纹理 UUID 解析该输入。
材质图保存和重开保留同一表面定义。
参数覆盖可调整颜色及常量物理参数。
参数图覆盖须遵守纹理槽所有权。

## 纹理所有权

独立覆盖拥有金属粗糙度纹理槽。
该槽透明通道保存裁剪覆盖。
RGB 分别保存常量 AO、粗糙度及金属度。
常量数值沿用无参数图时的因子换算。

金属粗糙度图与独立覆盖构成互斥输入。
对应镜面透明度和 NPR AO 消费同样检查冲突。
图层表面、眼睛及脸部 SDF 使用各自专用所有权。
非法版本、通道和图像引用返回明确诊断。

纹理色彩空间固定为线性数据。
过滤、寻址、层级偏移及异向过滤按所属图像解释。
完整 DDS 层级按来源逐级保留。
普通图像按现行纹理导入规则生成所需层级。

## 渲染契约

材质特性位二十五标记独立覆盖。
主颜色、颜色快照及深度采用 `_coverage` 程序。
扩张深度、描边颜色及实例遮罩同样选择覆盖变体。
显式照明与覆盖组合采用 `_lighting_coverage` 程序。

级联阴影和对象图集按所属材质选择覆盖变体。

时间采样与多重采样沿用既有覆盖足迹。
运动通道借用同一图像及采样器。
阴影的几何覆盖及平方根覆盖按现有模式解释。
程序和管线随场景重建及关闭释放。

画像布局为二十一，大小为 352 字节。
每材质继续拥有九个纹理槽。
场景渲染器 API 为九，能力名为 `supportsMaterialCoverage`。
缺省材质采用既有程序及纹理语义。

采集清单的 `materialCoverageSources` 记录实际输入。
每项包括材质身份、通道、尺寸、层级及采样器。
来源及检查范围按[实施计划](../plans/2026-11-02-independent-coverage.md)维护。
完整角色及场景画质按[开发总计划](../plans/azure-engine-plan.md)验收。
