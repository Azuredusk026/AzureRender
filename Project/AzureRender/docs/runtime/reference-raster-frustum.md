# 参考光栅混合视锥

`prepareReferenceRasterFrustum` 准备参考光栅的保守剔除参数。
输入为参考视图、设备视图及声明的世界包围域。
输入视图均须已完成参考相机准备。
矩阵描述须对应消费方实际采用的裁剪运算。

## 平面与误差

左右和上下平面来自参考横纵坐标及尺度。
设备深度平面仅在声明域内的设备尺度确定为正时启用。
其他情况通过参考横纵平面执行保守检查。
`usesDeviceDepth` 提供实际采用状态。

`conservativeClipDescription` 返回线性系数及运算幅度副本。
线性系数用于边界准备，单精度裁剪仍由原投影接口执行。
准备器加入投影舍入、坐标帧及系数转换误差。
保守余量向单精度的较大相邻值转换。

设备零尺度区间与包围域的交点采用参考尺度求包络。
该包络扩展参考尺度的保留区间。
参考和设备零尺度回退因此共用现有 128 字节参数。
不可界定的中间范围返回显式全保留状态。

## 适用域与所有权

`PreparedReferenceRasterFrustum` 独立持有平面和适用域。
`bounded` 表示投影范围是否已成功界定。
CPU 查询超出声明域时保持可见。
非法数值及倒置包围盒提供输入异常。

`parameters` 接收即将使用的 GPU 包围盒集合。
全部包围盒须处于声明域内。
校验成功后返回保守剔除参数副本。
GPU 资源、同步及管线能力沿用[保守剔除参数](conservative-frustum.md)。

准备器服务于参考深度生产和主场景光栅组合。
主场景的设备描述须包含其实际裁剪运算的误差。
光栅及拾取宿主消费在对应单元装配。
专项结果见[混合视锥验收](../acceptance/nr/reference-raster-frustum.md)。
