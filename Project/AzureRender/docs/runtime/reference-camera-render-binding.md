# 参考相机渲染与拾取

共享相机描述的布局版本为三。
`referenceCalibration` 持有参考视图、锚点姿态及屏幕缩放。
场景游戏相机和编辑相机各自持有该数据副本。
参考视图文件采用[项目参考视图配置](project-reference-views.md)。

## 场景与宿主装配

游戏相机选择服务将具名参考标定写入共享描述。
`resolveReferenceCamera` 按当前姿态准备参考视图。
姿态等于锚点时，参考参数保持逐位一致。
场景移动通过同一标定及姿态转换消费。

项目加载阶段声明 `RenderContext::referenceCameraPrograms`。
角色渲染器据此准备独立参考顶点程序。
直接使用渲染接口时，调用方在加载前声明该能力。
加载时已带参考标定的相机同时声明所需能力。

场景渲染器接口版本为十一。
`supportsReferenceCamera` 显式声明参考相机支持。
宿主在分派前校验选中相机及渲染器能力。
缺失能力或加载后晚启用提供明确诊断。

## 光栅与缓冲

主视图、深度快照、轮廓及轮廓遮罩提供参考顶点族。
参考横纵坐标及齐次尺度来自统一准备视图。
设备深度和屏幕位移沿用[光栅位置组合](reference-raster-projection.md)。
模块创建核对并准备三处受控融合乘加。

相机缓冲共 800 字节。
参考投影参数位于偏移 688，大小为 112 字节。
既有字段的偏移保持各自契约。
关闭参考标定时，参数控制位关闭参考投影。

普通项目选择普通顶点程序。
参考能力项目可在普通及参考相机之间选择。
程序族通过 `AZURE_REFERENCE_CAMERA` 显式编译。
参考顶点族包含二十六个程序，程序集上限为 1024。

视图可声明独立[场景参考深度](scene-reference-depth.md)。
该通道使用相同的参考标定及当前帧绘制数据。

## 剔除与拾取

剔除准备采用当前场景世界包围域。
参考横纵平面与零尺度回退使用[混合视锥](reference-raster-frustum.md)。
设备深度剔除保留在所属运算序列资格中验证。
带屏幕轮廓或投影位移的参考帧保留绘制候选。

CPU 与 GPU 消费相同的保守余量及尺度平面。
`cameraPickRay` 从统一参考视图返回射线。
编辑辅助线按参考横纵坐标及设备深度组合裁剪。
普通相机保持共享接口的普通投影分支。

## 编辑与兼容范围

跳转游戏相机时同时传递参考标定。
平移和旋转保留锚点关系。
正交缩放更新有限的 `screenScale`。
屏幕缩放范围为 `1e-6` 至 `1e6`。

选择普通投影类型后，编辑视口使用普通相机模式。
选中对象取景由普通投影提供。
参考模式的取景请求返回诊断并保留当前状态。
参考投影的镜头参数来自标定视图。

参考帧支持空间抗锯齿模式。
参考时间运动、屏幕空间反射及视雾需分别取得资格。
这些组合在装配时提供明确诊断。
世界空间光照及设备深度由当前渲染机制消费。

所属检查见[参考相机生产接入验收](../acceptance/nr/reference-camera-render-binding.md)。
主线复验见[参考相机渲染主线验收](../acceptance/nr/reference-camera-binding-main-integration.md)。
