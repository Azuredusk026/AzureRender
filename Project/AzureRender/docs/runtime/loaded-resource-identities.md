# 加载资源身份映射

场景渲染器持有资源标识到网格键的值映射。
映射来源为加载场景的 `ResourceLayout::identities`。
路径及材质绑定确定网格顺序，资源别名按现有布局解析。
每帧节点通过映射选择已加载网格。

不可见节点及未知资源使用范围外网格键。
稳定分组继续决定实例顺序及连续绘制范围。
身份映射的容量由已装配资源集合决定。
当前帧动态输入按原节点、姿态及照明规则更新。

兼容场景复用先检查现有资源条件及网格键。
成功后更新场景与身份映射，保留加载的网格顺序。
失败的兼容判定保留当前内容。
加载、卸载及重新加载分别建立、清空及刷新映射。

`loadedResourceIdentityEntries` 表示当前映射中的身份数。
该字段与已加载网格数分别记录。
运行契约及范围见[实施计划](../plans/2026-11-06-loaded-resource-identities.md)。
