# 反射信号层级

`ReflectionSignalPyramidGpu` 管理颜色和可信度层级。
调用者持有深度层级，并写入两份基础信号。
过滤使用深度加权的 4×4 核。
边界外信号为零，深度采样钳制到边缘。

## 格式与所有权

优先格式为 `R11G11B10_FLOAT` 和 `R8_UNORM`。
格式能力通过 RHI 分别查询存储和采样支持。
浮点回退采用 `RGBA32F` 和 `R32F`。
强制紧凑格式时，能力不足会返回诊断。

宽高限制为一至 8192，在途槽位为一至八。
输出总预算为 512 MiB，层级数受图像尺寸约束。
各级参数缓冲和描述符按槽位隔离。
深度视图由调用者持有，禁止与输出别名。

## 记录顺序

1. 等待该槽位的全部消费者完成。
2. 调用 `beginBaseWrite` 准备基础写入。
3. 完整写入颜色和可信度的基础层。
4. 调用 `record` 生成后续层级。
5. 通过 `output` 借用可采样视图。

基础写入支持计算存储写入和传输写入。
资源所有者记录逐级屏障及最终采样屏障。
调用者保证深度输入的布局与计算可见性。
销毁前须等待所有使用该资源的提交完成。
