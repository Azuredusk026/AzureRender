# 角色漫反射组合

材质画像版本二支持 `nprDiffuse` 子对象。
该能力组合基色、影色色表与色带四通道。
光照消费线性颜色响应，镜面与自发光独立累加。
公共函数位于 `shaders/character_diffuse.glsl`。

## 材质参数

版本一的五项基础字段须显式提供。
未知字段触发导入错误。
材质须声明 `shadowColorLut`，采用完整立方条带。
适用类别为通用、皮肤、面部、织物及金属。
头发和眼睛由各自表面模型持有参数。

```json
{
  "nprDiffuse": {
    "schemaVersion": 1,
    "shadowScale": 1,
    "lightingInputs": "host-scene-radiance",
    "shadowMask": "none",
    "baseAo": "albedo-alpha"
  }
}
```

`shadowScale` 取零至六十四的有限数值。
`shadowMask` 可选 `none` 或 `style-mask-gb`。
后者消费风格遮罩的绿、蓝通道。
风格遮罩与漫反射色带的纹理槽具有互斥所有权。

`baseAo` 可选 `one` 或 `albedo-alpha`。
后者消费基色纹理及材质因子合成后的 Alpha。
该值属于漫反射选择量，独立于物理遮蔽纹理。
无子对象的材质遵循所属表面模型的规则。

`indirectNormal` 为可选字符串，默认 `surface`。
该模式使用完成法线贴图后的表面法线。
`world-horizontal` 保留世界 X、Z 分量。
其 Y 分量取 `2^-14`，随后将向量归一化。

正负垂直输入及零向量均得到世界向上的法线。
非法类型与未知模式触发导入错误。
该法线只用于场景环境漫反射与辐照体积。
直接光、镜面及颜色选择的相机方向分别持有输入。

## 着色与所有权

影色色表按线性基色的 sRGB 坐标采样。
色带 RGB 控制色度，Alpha 控制亮部选择。
相机朝向、遮罩和可见度共同参与阴影选择。
响应中的亮度补偿具有一千分之一的分母下限。

方向灯按各自方向求值色带并累加入射能量。
投影方向灯的入射能量消费主灯阴影可见度。
颜色选择中的可见度与能量遮挡分别计算。
环境、局部灯和辐照体积使用主方向的颜色响应。
局部灯保留宿主的余弦入射权重。
宿主的两个可见度输入共用主灯阴影图。
本适配的入射能量显式来自引擎场景照明。

材质加载时完成字段校验与参数打包。
绑定二十七的静态材质表持有参数。
每项维持六行布局，由材质特征选择解释。
首行 W 分量记录环境漫反射法线模式。
资源按场景材质表的生命周期统一释放。

## 来源与验证

颜色组合依据已保存的原生片元程序。
源运行全局常量与宿主照明分别记录来源。
影色强度须由内容配置明确指定。
原生完整照明等价按实际帧证据独立验收。
原生局部灯的模式、能量压缩及筛选继续核验。

检查覆盖独立公式、生产像素和普通材质。
固定与索引描述符使用同一颜色组合函数。
角色近景与中庭联合画面具有独立观察范围。
