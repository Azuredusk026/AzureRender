# 角色漫反射组合

材质画像版本二支持 `nprDiffuse` 子对象。
该能力组合基色、影色色表与色带四通道。
光照消费线性颜色响应，镜面与自发光独立累加。
公共函数位于 `shaders/character_diffuse.glsl`。

## 材质参数

版本一的五项基础字段须显式提供。
未知字段触发导入错误。
材质须声明 `shadowColorLut`，采用完整立方条带。
适用类别为通用、皮肤、面部、织物及金属。
头发和眼睛由各自表面模型持有参数。

```json
{
  "nprDiffuse": {
    "schemaVersion": 1,
    "shadowScale": 1,
    "lightingInputs": "host-scene-radiance",
    "shadowMask": "none",
    "baseAo": "albedo-alpha"
  }
}
```

`shadowScale` 取零至六十四的有限数值。
`shadowMask` 可选 `none`、`one` 或 `style-mask-gb`。
`one` 对全部片元应用角色可见量，采用常量接收遮罩。
`style-mask-gb` 消费风格遮罩的绿、蓝通道。
风格遮罩与漫反射色带的纹理槽具有互斥所有权。

`characterVisibility` 为可选字符串。
默认 `scene-visibility` 采用传入的场景可见量。
`main-light-shadow` 采用宿主主灯阴影图的实际结果。
场景覆盖、亮部选择和角色遮罩分别保留各自消费者。

```json
{
  "shadowMask": "one",
  "characterVisibility": "main-light-shadow"
}
```

场景 `shadowOverride` 只改变场景可见量。
常量接收遮罩与漫反射色带可共同使用。
版本六材质表首行 Y 记录接收模式，第四行 X 记录来源。
该输入沿用宿主阴影资源、同步及关闭顺序。

原生对象阴影图的范围、偏置及过滤独立验收。
捕获像素与宿主阴影图的等价需要实际生产证据。

`baseAo` 可选 `one` 或 `albedo-alpha`。
后者消费基色纹理及材质因子合成后的 Alpha。
该值属于漫反射选择量，独立于物理遮蔽纹理。
无子对象的材质遵循所属表面模型的规则。

`lighting` 为可选的版本一对象。
完整字段为 `schemaVersion`、`ambientColor` 及 `mainColor`。
两组线性颜色均包含三个零至 64 的有限数值。
缺省采用场景光色，启用时采用材质的显式光色。

```json
{
  "lighting": {
    "schemaVersion": 1,
    "ambientColor": [1.2, 0.8, 0.6],
    "mainColor": [0.7, 0.9, 1.1]
  }
}
```

光色覆盖由场景 NPR 照明组合消费。
主灯强度、方向及局部灯继续由场景拥有。
场景辐照启用时，环境入射量采用实际辐照结果。
完整材质文档与 glTF 共用解析和校验。

`rimResponse` 为可选字符串，默认 `screen-depth`。
`view-facing` 为版本五材质边缘灯选择视角带状响应。
灯响应及规范公式见[局部灯契约](character-local-light-response.md)。

`rimOrigin` 为可选的版本一对象。
完整字段为 `schemaVersion` 和 `node`。
节点名称须在所属模型中唯一，消费当前动画姿态。
适用类别为普通表面、皮肤、织物及金属。

```json
{
  "rimOrigin": {
    "schemaVersion": 1,
    "node": "BodyOrigin"
  }
}
```

节点原点经过实例及操纵器变换后参与径向可见量。
省略字段时采用实例共享材质帧的原点。
完整材质文档按名称对接目标模型中的节点。
版本、字段、类别或节点不合法时返回加载诊断。

场景快照持有不可变的材质实例映射。
同一物理实例与相同节点复用一份附加记录。
每份记录为 496 字节，归属现有实例缓冲及帧栅栏。
姿态、投影、透明排序及对象阴影各自保留物理身份。

显式原点材质采用连续实例批次直接绘制。
材质表为 192 字节，实例布局版本为二。
节点引用及姿态映射由资源和场景渲染层持有。
其他材质继续消费其所属的面部或头发帧。

`viewTint` 使用可选版本一对象。
完整字段为 `schemaVersion`、`scale` 和 `color`。
倍率及三个线性颜色分量均为零至 64 的有限数值。
省略对象时，亮部基色保持原值。

```json
{
  "rimResponse": "view-facing",
  "viewTint": {
    "schemaVersion": 1,
    "scale": 0.595,
    "color": [0.38, 0.12, 0.14]
  }
}
```

颜色权重为 `clamp((1-clamp(dot(N,V),0,1))*scale,0,1)`。
亮部基色乘以单位色与声明颜色的线性混合。
视角边缘响应消费该亮部基色。
影色查找表及基色 Alpha 继续消费原始输入。

`indirectNormal` 为可选字符串，默认 `surface`。
该模式使用完成法线贴图后的表面法线。
`world-horizontal` 保留世界 X、Z 分量。
其 Y 分量取 `2^-14`，随后将向量归一化。

正负垂直输入及零向量均得到世界向上的法线。
非法类型与未知模式触发导入错误。
该法线只用于场景环境漫反射与辐照体积。
直接光、镜面及颜色选择的相机方向分别持有输入。

径向模式通过双配置数值与真实角色近景检查。
范围见[脸部法线验收](../acceptance/nr/face-radial-indirect.md)。
接续状态见[还原交接](../plans/2026-10-22-native-render-restoration-handoff.md)。

`face-frame-radial-horizontal` 采用显式头部帧。
该模式须使用面部类别与版本二距离场画像。
原点为 `faceSdf.headNode` 当前动画姿态的世界位置。
世界位置减去该原点后，按水平规则归一化。

几何法线按同一水平规则归一化。
距离场遮罩 G 混合径向与几何向量，再归一化。
混合的平方长度至多为 `1e-12` 时回退几何向量。
距离场关闭时，环境消费默认表面法线。

该原点具有显式内容配置与实例动画来源。
原生预留骨骼帧的身份等价继续独立核验。
SDF 蓝通道的局部光照法线保留其原有消费者。

## 主光色带坐标

`mainRamp` 为可选的版本一对象。
完整字段为 `schemaVersion` 和 `bias`。
偏置为负一至一的有限数值，材质须声明 `diffuseRamp`。
该对象与风格阈值模式具有各自明确的坐标消费者。

```json
{
  "mainRamp": {
    "schemaVersion": 1,
    "bias": 0
  }
}
```

主光坐标为 `0.5*clamp(dot(N,L)+bias,-1,1)+0.5`。
`N` 为法线贴图后的单位世界法线。
`L` 为宿主主灯的单位入射方向。
色带以原始归一化坐标、固定 Y 值 0.5 采样。

采样采用线性过滤、边缘夹取和零级纹理。
RGB 与 Alpha 共同参与颜色及照明选择。
省略对象时采用所属表面的风格阈值坐标。
双域面部距离场采用其独立坐标规则。

主光与角色局部灯适配共用材质颜色响应。
局部灯的方向、包裹量和能量压缩分别计算。
参数使用材质联合表第二行的 Y、Z 分量。
完整材质文档及稀疏覆盖沿用公共解释器。

## 局部漫反射下限

可选字段 `localDiffuseFloorScale` 默认为一。
数值须有限，允许范围为零至四。
完整材质文档保存该值，稀疏覆盖保留来源画像。
绑定二十七的第四行 Y 保存倍率。

带角色响应的局部灯提供漫反射下限和压缩系数。
材质倍率仅乘下限，压缩、距离及发射形状仍归属灯。
实际下限为 `floor = lightFloor * localDiffuseFloorScale`。
包裹权重为 `floor + clamp(NdotL + 0.5, 0, 1) * (1 - floor)`。

普通局部灯消费宿主余弦响应。
头发的独立表面画像消费灯自身的角色响应。
主灯、环境、镜面及发射形状按各自契约处理。

## 着色与所有权

影色色表按线性基色的 sRGB 坐标采样。
色带 RGB 控制色度，Alpha 控制亮部选择。
相机朝向、遮罩和可见度共同参与阴影选择。
响应中的亮度补偿具有一千分之一的分母下限。

方向灯按各自方向求值色带并累加入射能量。
投影方向灯的入射能量消费主灯阴影可见度。
颜色选择中的可见度与能量遮挡分别计算。
环境、局部灯和辐照体积使用主方向的颜色响应。
局部灯按响应策略消费余弦或包裹权重。
角色可见度按材质声明选择来源。
场景可见度按宿主照明及覆盖参数计算。
本适配的入射能量显式来自引擎场景照明。

材质加载时完成字段校验与参数打包。
绑定二十七的静态材质表持有参数。
每项采用十二行共享布局，由材质特征选择解释。
首行 W 分量记录环境漫反射法线模式。
资源按场景材质表的生命周期统一释放。

## 来源与验证

颜色组合依据已保存的原生片元程序。
源运行全局常量与宿主照明分别记录来源。
影色强度须由内容配置明确指定。
原生完整照明等价按实际帧证据独立验收。
原生局部灯的模式、能量压缩及筛选继续核验。

检查覆盖独立公式、生产像素和普通材质。
固定与索引描述符使用同一颜色组合函数。
角色近景与中庭联合画面具有独立观察范围。
