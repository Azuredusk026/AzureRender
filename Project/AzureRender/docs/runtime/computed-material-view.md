# 材质视图组合

## 能力与选择

材质视图组合复用同帧不透明深度及阴影接收状态。
渲染器同时拥有参考管线及有界优化管线。
设备启用四像素组控制及最大重收敛后参与资格判断。
当前设备资格覆盖 NVIDIA，其他设备消费参考族。

优化族用于单采样的绑定数组材质路径。
视图须启用深度测试，独立管线采用通过资格的深度比较。
当前比较范围为 `LESS`、`LESS_OR_EQUAL` 及 `EQUAL`。

场景启用参考 UV 或实验缓存时使用对应参考族。
装配参考相机程序的项目使用对应参考族。
项目保持既有材质、照明及覆盖配置的来源契约。
各管线共享布局、专用常量及附件规则。

当帧判断消费实际上传的相机参数。
场景照明为一，隔离与效果模式均为零。
效果启用为一，计算反射来源为二。
同帧不透明深度的视图及尺寸须匹配当前渲染范围。

任一条件失配时选择参考管线。
诊断模式切换、视图尺寸变化及帧槽复用逐帧判断。
缺失可选优化程序时记录原因并选择参考族。
参考 UV 的必需程序按既有失败契约处理。

## 深度与导数

主颜色透明裁剪材质可使用现有不透明深度。
节点透明度须为一，深度须为有限正值。
深度边界包含与幅值相关的保守余量。
完整四像素组均不可见时，片元工作可以结束。

幸存组保留全部四份原始阴影导数及着色。
快照材质按同一接收状态保存当前及相邻级联。
普通主颜色视图在精确资格域内消费固定逻辑分支。
颜色与资源释放按所属设备和实际输出验收。

## 构建与诊断

构建选项为 `AZURE_ENABLE_COMPUTED_MATERIAL_VIEW`。
默认值为 `OFF`，标准构建采用参考族。
显式设置为 `ON` 时构建 128 份候选程序。
程序总数须满足 1024 份目录上限。
实验缓存及隔离专用构建按各自程序配置装配。

环境变量 `AZURE_DISABLE_COMPUTED_MATERIAL_VIEW=1` 选择参考实现。
该控制用于同一宿主的成对测量与诊断。
捕获及计时清单记录准备管线数、当帧资格及原因。
累计请求与实际选择计数使用独立字段保存。

优化管线由渲染器持有并在所属生命周期内销毁。
记录线程共享只读映射，累计计数使用原子操作。
交换链重建按新范围准备资源及管线。
视图释放后，优化资源与其他材质资源共同退休。

资格来源见[局部组合验收](../acceptance/nr/quad-depth-visibility.md)
及[原生资格](../acceptance/nr/quad-depth-combination-native.md)。
候选状态见[材质组合深度策略验收](../acceptance/nr/material-viewquad-production.md)。
