# 描边投影计算

共享核位于 `shaders/outline_projection.glsl`。
本页定义数值接口和输入单位。
生产材质、顶点流及深度壳接入由 C18 验收。

## 输入与输出

`outlineHalfFov(projectionY)` 计算半视场角。
输入为投影矩阵的垂直缩放项。
计算采用固定多项式及互补角分支。
极小投影值具有有限的输入钳制。

`outlineViewScaledOffset` 返回二维裁剪空间偏移。
调用方将结果加到裁剪位置的 XY。
该偏移已包含宽度遮罩，调用方直接使用。
颜色壳与深度壳可消费同一计算接口。

| 参数 | 单位与规则 |
| --- | --- |
| `clipW` | 裁剪 W；透视时为正向视深度，正交时通常为一 |
| `projectedNormal` | 中心投影后的法线 XY；计算先归一化 |
| `extent` | 实际渲染目标的宽高；非正尺寸返回零偏移 |
| `projectionY` | 投影矩阵的垂直缩放项 |
| `width` | 非负形状倍率；零值返回零偏移 |
| `minimumPixels` | 屏幕下限倍率；实际下限同时受距离与视场角约束 |
| `widthMask` | 线性遮罩样本；非正值返回零偏移 |

法线投影方向先归一化，再乘宽高比修正。
调用者在方向计算中排除投影中心偏移。
形状倍率采用半视场角和近处衰减。
两个屏幕分量分别应用下限及方向符号。
零长度法线返回零偏移。

`outlineShiftedClipDepth` 计算有符号视深度偏移。
输入包含裁剪位置、深度斜率及米制偏移。
计算保留 XY 与 W，并按移动后的视深度重建 Z。
移动位置越过相机平面时，输出有限的裁剪深度。

深度斜率分别对应裁剪 Z 与 W 的视深度导数。
透视、反向深度和正交投影共用该接口。
平滑法线解码和图像采样由调用者持有。
材质数据需先通过所属契约的数值及范围检查。

## 材质与资源

`outlineSurface` 版本一定义材质的距离描边。
字段及范围见[接入计划](../plans/2026-10-23-outline-projection-integration.md)。
颜色参与由 `silhouette-outline` 控制。
`depthPrepass` 独立控制外扩深度壳。

颜色壳与深度壳共用当前蒙皮、形变和节点透明度。
深度壳写入硬件深度和线性视深度附件。
场景颜色附件通过独立写掩码保持原值。
有符号偏移按遮罩 G 缩放。

遮罩 R 控制宽度，G 控制深度偏移。
遮罩消费 UV0，采用线性零级钳制采样。
平滑方向消费 UV1 的两个有符号分量。
半球 Z 由平方和重建，当前切线帧提供世界方向。

`tangent-octahedral-uv1` 使用八面体编码重建完整球面。
源方向按导入后的切线帧转换，再写入可选流。
动态资产的方向转换使用绑定姿态的切线帧。
运行时按当前蒙皮及形变重建世界方向。
执行后顶点用于对应捕获姿态的来源验证。

基础材质表为 192 字节，片元纹理槽为九个。
描边独立记录为 64 字节，头部为 16 字节。
可选 UV1 区使用每顶点八字节。
记录按稳定材质身份排序，UV1 按资产排序。

绑定 30 为顶点阶段的只读记录与坐标区。
绑定 31 为顶点阶段的独立材质遮罩。
固定和索引路径分别检查阶段与集合容量。
资产追加展示台时，可选坐标区同步补齐。

描边资源对象持有缓冲，图像由共享纹理缓存持有。
初始化成功后释放原始遮罩像素。
宿主退役在途提交后销毁描边资源和共享缓存。
采集清单记录布局版本、材质数、坐标数及字节数。

## 验证

`AzureRender.SurfaceResponseGpu` 执行数值检查。
数值检查包含 305 项，其中二十项覆盖 XY 投影。
六组原生顶点提供十二个独立裁剪坐标期望。
其固定绝对误差预算为 `1e-5`。

八项边界控制的预算为 `1e-8`。
覆盖零遮罩、零宽度、零法线和非正视深度。
小正宽度、近处深度与双倍尺寸分别核验。
原有 260 项使用各自既定预算。

七项深度偏移的绝对误差预算为 `1e-6`。
覆盖透视、反向深度、正交及相机平面边界。
十八项方向解码检查正负半球及八面体接缝。
其绝对误差预算为 `1e-6`。

公共图像夹具位于 `tools/test_outline_projection_gpu.py`。
真实角色对照见[材质与深度壳验证](../acceptance/nr/outline-material-integration.md)。

来源及生产待项见[描边深度来源](../acceptance/nr/outline-depth-source.md)。
