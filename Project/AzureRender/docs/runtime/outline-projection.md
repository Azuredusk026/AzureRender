# 描边投影计算

共享核位于 `shaders/outline_projection.glsl`。
本页定义数值接口和输入单位。
生产材质、顶点流及深度壳接入由 C18 验收。

## 输入与输出

`outlineHalfFov(projectionY)` 计算半视场角。
输入为投影矩阵的垂直缩放项。
计算采用固定多项式及互补角分支。
极小投影值具有有限的输入钳制。

`outlineViewScaledOffset` 返回二维裁剪空间偏移。
调用方将结果加到裁剪位置的 XY。
该偏移已包含宽度遮罩，调用方直接使用。
颜色壳与深度壳可消费同一计算接口。

| 参数 | 单位与规则 |
| --- | --- |
| `viewDepth` | 正向视深度；非正值返回零偏移 |
| `viewNormal` | 视空间 XY 法线；计算先归一化 |
| `extent` | 实际渲染目标的宽高；非正尺寸返回零偏移 |
| `projectionY` | 投影矩阵的垂直缩放项 |
| `width` | 非负形状倍率；零值返回零偏移 |
| `minimumPixels` | 屏幕下限倍率；实际下限同时受距离与视场角约束 |
| `widthMask` | 线性遮罩样本；非正值返回零偏移 |

视空间方向先归一化，再乘宽高比修正。
形状倍率采用半视场角和近处衰减。
两个屏幕分量分别应用下限及方向符号。
零长度法线返回零偏移。

该核只计算 XY 投影。
深度偏移、平滑法线解码和图像采样由调用者持有。
材质数据需先通过所属契约的数值及范围检查。

## 验证

`AzureRender.SurfaceResponseGpu` 执行数值检查。
两种构建各包含 280 项，其中二十项覆盖本核。
六组原生顶点提供十二个独立裁剪坐标期望。
其固定绝对误差预算为 `1e-5`。

八项边界控制的预算为 `1e-8`。
覆盖零遮罩、零宽度、零法线和非正视深度。
小正宽度、近处深度与双倍尺寸分别核验。
原有 260 项使用各自既定预算。

来源及生产待项见[描边深度来源](../acceptance/nr/outline-depth-source.md)。
