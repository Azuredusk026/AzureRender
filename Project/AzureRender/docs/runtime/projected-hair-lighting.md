# 投影头发照明

投影头发可声明 `hair.projectedRamp.lighting`。
该输入属于版本二的头发材质画像。
它要求 `strand-diffuse` 和独立漫反射色带。
加载器校验全部字段、范围和输入所有权。

```json
{
  "schemaVersion": 1,
  "shadowBrightness": 0.55,
  "shadowSaturation": 1.1,
  "shadowScale": 0.55,
  "ambientColor": [0.88, 0.93, 1.12],
  "mainColor": [1.0, 1.0, 1.0],
  "characterVisibility": "object-shadow"
}
```

版本、三个阴影标量及两组颜色为必填。
`characterVisibility` 为独立的可选字段。

三个阴影标量接受零至十六的有限数值。
两组颜色各有三个线性分量，范围为零至六十四。
未知字段、布尔数值和错误版本产生加载错误。

角色可见量来源与通用 NPR 材质共享解释。
头发的缺省来源为 `one`。
`object-shadow` 使用所属实例的对象图集。
实例缺少对象记录时，其对象可见量为一。

| 来源 | 输入 |
| --- | --- |
| `one` | 常量一 |
| `scene-visibility` | 场景可见量，包含场景覆盖设置 |
| `main-light-shadow` | 宿主主灯阴影图 |
| `object-shadow` | 对象记录、接收偏置及图集过滤 |

## 输入与组合

该适配要求场景照明和场景 NPR 照明同时启用。
省略输入或关闭场景 NPR 时，采用头发默认路径。
`diffuseScale` 定义发丝漫反射的基色倍率。
材质光色控制所选主灯和常量环境的颜色。

主灯方向、强度和稳定身份由场景提供。
场景选择辐照输入时，环境来自实际环境和体积。
环境权重、方向增益及内外混合由场景持有。
参数图 B 提供材质遮蔽量。
所选角色可见量参与亮暗选择及主灯镜面权重。
环境入射使用独立的环境权重和物理遮蔽量。
原生深度副本与法线输入的生产等价继续验收。

漫反射色带分别按主灯方向和相机后轴采样。
采样使用原始归一坐标和零级纹理。
视线色带 Alpha、角色可见量及遮蔽独立参与权重。
阴影颜色由基色、亮度及饱和度生成。

颜色求值复用 `characterDiffuseWeightedResponse`。
照明求值复用 `characterDiffuseIllumination`。
两层主灯 KK 乘以环境和主灯照明之和。
其倍率为 `mix(shadowScale,1,weight)*(.5+.5*weight)`。

`weight` 按场景可见量混合视线遮蔽和亮部权重。
局部灯保留独立的主叶消费路径。
额外方向灯保留各自直接照明贡献。
主叶上限、专用开关和条纹目标保持显式配置。

## 布局与生命周期

该输入复用绑定 27 的 192 字节材质表。
布局版本为十，记录保持十二行。
第六行 W 保存阴影倍率，第七行 W 保存启用位。
最后两行保存两组光色、亮度及饱和度。
纹理继续使用已有九槽，资源随场景统一释放。

`rows[6].x` 使用零至七的整数标志。
最低位声明虚拟主灯，其余两位声明可见量来源。
四类来源的基础编码依次为零、二、四、六。
来源编码与虚拟主灯开关独立组合。

glTF 和完整 `.azurematerial` 共用生产解析器。
编辑、保存、发布及重新打开保留完整材质字段。
原生常量的行号及事件身份由离线工具解释。
引擎仅消费版本化的材质和场景输入。
