# 网格辐照度资源

原生场景的覆盖与来源见[中庭验证](../acceptance/nr/irradiance-coverage.md)。

`AZIV0001` 保存通用规则网格的方向辐照系数。
资源属于 RenderCore 的数据契约。
数据文件自包含，路径由项目资源配置提供。
文件加载后由渲染调用方持有和释放。

## 文件格式

所有整数与浮点数均采用小端编码。
浮点格式为 IEEE 754 单精度。
文件头固定为 36 字节，每格固定为 64 字节。
文件大小须精确等于 `36+64*nx*ny*nz`。

| 偏移 | 内容 |
| --- | --- |
| 0 | 八字节版本标识 `AZIV0001` |
| 8 | 网格原点，三个浮点数 |
| 20 | 等距采样间隔，一个正浮点数 |
| 24 | 网格尺寸，三个正的 32 位无符号整数 |
| 36 | 依次排列的网格采样 |

采样按 `x+nx*(y+ny*z)` 排列。
每格包含红、绿、蓝三组四维浮点系数。
每组顺序为世界空间 `X、Y、Z、常量`。
其后保存有效权重，以及三个零值保留字段。

系数与坐标须全部有限。
有效权重范围为 `[0,1]`。
尺寸乘积上限为 `1,048,576`。
加载器拒绝未知版本、错误长度和非零保留字段。

## 查询与求值

入口为 [IrradianceVolume.hpp](../../src/render/IrradianceVolume.hpp)。
`load(path)` 加载文件，`decode(bytes)` 加载内存。
`encode()` 可生成对应文件字节。
直接构造网格后须调用 `validate()`。

`query(worldPosition)` 对八个相邻格点做三线性插值。
各格系数先乘有效权重，再累加。
查询结果的 `weight` 是相同权重的插值结果。
范围外查询返回零系数与零权重。

`sample.evaluate(unitWorldNormal)` 评价方向系数。
每色结果为 `max(dot(linear,normal)+constant,0)`。
插值发生在系数阶段，钳位发生在最终求值阶段。
单位法线以外的输入会被拒绝。

查询所得系数已经包含有效权重。
调用方直接使用求值结果作为体积贡献。
剩余环境贡献乘以 `1-sample.weight`。
缺失格点的有效权重为零。

## 场景绑定与 GPU 消费

关卡通过 `irradianceVolume` 绑定资源。
绑定版本为 1，默认强度为 1，默认关闭。
强度须为有限非负数，启用时须提供资源。

```json
{
  "irradianceVolume": {
    "version": 1,
    "asset": "assets:/field.aziv",
    "intensity": 1,
    "enabled": true
  }
}
```

资源引用参与依赖扫描、打包与内容指纹。
项目迁移通过资源数据库解析相对引用。
场景文档版本为 7，并保存同一绑定契约。
版本 6 及更早的文档默认关闭该能力。

渲染器持有加载后的 CPU 网格与 GPU 缓冲。
每格按四组 `vec4` 上传，步长为 64 字节。
存储缓冲绑定为 24，两种纹理路径共用。
三个相机参数保存原点、间距、尺寸和强度。

片元按世界位置插值系数与有效权重。
着色法线参与方向求值，最终结果乘配置强度。
漫反射环境项乘剩余权重后与网格贡献相加。
网格贡献同时使用材质漫反射颜色和环境遮蔽。

存储范围须满足设备的缓冲大小上限。
资源替换触发场景重载，强度与启用支持快照更新。
场景卸载释放网格与缓冲。
缺省场景使用零值占位缓冲。

## 验证与使用范围

CPU 夹具使用独立的彩色方向场。
夹具覆盖边界、缺失格点及插值后钳位。
文件测试覆盖版本、尺寸、有限值和保留字段。
原生数据导出是该公共契约的另一种使用方式。

GPU 夹具入口为 `python -m native_render.irradiance_lab`。
运行目录位于 `build/runs/20261017-175206-nr-playable-integration-d4e789/`。
`irradiance-lab-relocation/` 保存六组像素对照。
最大线性颜色误差为 0.00520，阈值为 0.012。

用例覆盖开关、方向场、强度、空洞和范围外。
固定纹理路径同时覆盖项目目录迁移。
验证层与资源释放检查全部通过。
`probe-lab-gi-regression/` 的八组反射回归通过。

此格式表达已采样的候选方向场。
数据生产者负责源坐标、系数语义和激活规则。
原生场景的区域覆盖及层级过渡另有消费契约。
