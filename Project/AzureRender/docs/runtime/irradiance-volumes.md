# 网格辐照度资源

原生场景的覆盖与来源见[中庭验证](../acceptance/nr/irradiance-coverage.md)。
三维资源的上传规则见[体积纹理](volume-image-upload.md)。
场景绑定也支持[三层辐照资源](irradiance-clipmaps.md)。
运行时按版本文件头选择对应加载器和着色程序。

`AZIV0001` 保存通用规则网格的线性方向系数。
`AZIV0002` 保存二阶方向系数。
资源属于 RenderCore 的数据契约。
数据文件自包含，路径由项目资源配置提供。
文件加载后由渲染调用方持有和释放。

## 文件格式

所有整数与浮点数均采用小端编码。
浮点格式为 IEEE 754 单精度。
文件头固定为 36 字节。
每格长度按文件版本解释。
文件大小须精确等于文件头与全部格点的总长。

| 版本 | 每格字节 | 方向表达 |
| --- | ---: | --- |
| `AZIV0001` | 64 | 线性三项与常量 |
| `AZIV0002` | 128 | 二阶九项 |

| 偏移 | 内容 |
| --- | --- |
| 0 | 八字节版本标识 `AZIV0001` 或 `AZIV0002` |
| 8 | 网格原点，三个浮点数 |
| 20 | 等距采样间隔，一个正浮点数 |
| 24 | 网格尺寸，三个正的 32 位无符号整数 |
| 36 | 依次排列的网格采样 |

采样按 `x+nx*(y+ny*z)` 排列。
线性格点包含红、绿、蓝三组四维浮点系数。
每组顺序为世界空间 `X、Y、Z、常量`。
其后保存有效权重，以及三个零值保留字段。

二阶格点按红、绿、蓝依次保存八个系数。
顺序为 `X、Y、Z、常量、XY、YZ、Z²、XZ`。
随后保存三色的 `X²−Y²` 系数及有效权重。
末尾四个浮点位置为零值保留字段。

系数与坐标须全部有限。
有效权重范围为 `[0,1]`。
尺寸乘积上限为 `1,048,576`。
加载器拒绝未知版本、错误长度和非零保留字段。

## 查询与求值

入口为 [IrradianceVolume.hpp](../../src/render/IrradianceVolume.hpp)。
`load(path)` 加载文件，`decode(bytes)` 加载内存。
`encode()` 可生成对应文件字节。
直接构造网格后须调用 `validate()`。

`query(worldPosition)` 对八个相邻格点做三线性插值。
各格系数先乘有效权重，再累加。
查询结果的 `weight` 是相同权重的插值结果。
范围外查询返回零系数与零权重。

`sample.evaluate(unitWorldNormal)` 评价方向系数。
每色结果为线性方向项、常量及二阶项之和。
最终颜色按零值下限钳位。
插值发生在系数阶段，钳位发生在最终求值阶段。
单位法线以外的输入会被拒绝。

`IrradianceBasis` 声明网格的方向表达。
二阶附加项使用独立格点数组 `quadraticCells`。
数组长度与网格格点数量一致。
格式、存储归属和非有限系数均参与校验。

查询所得系数已经包含有效权重。
调用方直接使用求值结果作为体积贡献。
剩余环境贡献乘以 `1-sample.weight`。
缺失格点的有效权重为零。

## 场景绑定与 GPU 消费

场景图形入口按文件头消费两种网格格式。
公共上传入口为 `packIrradianceGridCells`。
共享求值程序位于 `irradiance_grid.glsl`。
二阶房间画面按[房间环境光](../acceptance/npr-room/windows-atmosphere.md#原版环境光探针)继续验收。

关卡通过 `irradianceVolume` 绑定资源。
绑定版本为 2，默认强度为 1，默认关闭。
强度须为有限非负数，启用时须提供资源。
采样规则见[辐照接收位置](irradiance-query.md)。

```json
{
  "irradianceVolume": {
    "version": 2,
    "asset": "assets:/field.aziv",
    "intensity": 1,
    "enabled": true
  }
}
```

资源引用参与依赖扫描、打包与内容指纹。
项目迁移通过资源数据库解析相对引用。
场景文档版本为 7，并保存同一绑定契约。
版本 6 及更早的文档默认关闭该能力。

渲染器持有加载后的 CPU 网格与 GPU 缓冲。
线性格点按四组 `vec4` 上传，步长为 64 字节。
二阶格点按八组 `vec4` 上传，步长为 128 字节。
上传字节与对应版本文件的格点载荷一致。
存储缓冲绑定为 24，两种纹理路径共用。
三个相机参数保存原点、间距、尺寸和强度。
查询标志的位三表示二阶系数布局。
网格关闭时，完整查询标志为零。

片元按世界位置插值系数与有效权重。
着色法线参与方向求值，最终结果乘配置强度。
漫反射环境项乘剩余权重后与网格贡献相加。
网格贡献同时使用材质漫反射颜色和环境遮蔽。

存储范围须满足设备的缓冲大小上限。
资源替换触发场景重载，强度与启用支持快照更新。
场景卸载释放网格与缓冲。
缺省场景使用零值占位缓冲。

## 验证与使用范围

CPU 夹具使用独立的彩色方向场。
夹具覆盖边界、缺失格点及插值后钳位。
文件测试覆盖版本、尺寸、有限值和保留字段。
原生数据导出是该公共契约的另一种使用方式。

`AzureRender.IrradianceGridGpuData` 核对上传布局与加载分派。
`AzureRender.IrradianceGridGpu` 使用生产求值程序。
通用夹具覆盖两种格式、有效权重、边界及最终钳位。
原版方向的双设备证据见[环境光探针](../acceptance/npr-room/windows-atmosphere.md#原版环境光探针)。

GPU 夹具入口为 `python -m native_render.irradiance_lab`。
运行目录位于 `build/runs/20261017-175206-nr-playable-integration-d4e789/`。
`irradiance-lab-relocation/` 保存六组像素对照。
最大线性颜色误差为 0.00520，阈值为 0.012。

用例覆盖开关、方向场、强度、空洞和范围外。
固定纹理路径同时覆盖项目目录迁移。
验证层与资源释放检查全部通过。
`probe-lab-gi-regression/` 的八组反射回归通过。

此格式表达已采样的候选方向场。
数据生产者负责源坐标、系数语义和激活规则。
原生场景的区域覆盖及层级过渡另有消费契约。
