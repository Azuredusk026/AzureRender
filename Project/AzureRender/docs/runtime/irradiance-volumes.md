# 网格辐照度资源

`AZIV0001` 保存通用规则网格的方向辐照系数。
资源属于 RenderCore 的数据契约。
数据文件自包含，路径由项目资源配置提供。
文件加载后由渲染调用方持有和释放。

## 文件格式

所有整数与浮点数均采用小端编码。
浮点格式为 IEEE 754 单精度。
文件头固定为 36 字节，每格固定为 64 字节。
文件大小须精确等于 `36+64*nx*ny*nz`。

| 偏移 | 内容 |
| --- | --- |
| 0 | 八字节版本标识 `AZIV0001` |
| 8 | 网格原点，三个浮点数 |
| 20 | 等距采样间隔，一个正浮点数 |
| 24 | 网格尺寸，三个正的 32 位无符号整数 |
| 36 | 依次排列的网格采样 |

采样按 `x+nx*(y+ny*z)` 排列。
每格包含红、绿、蓝三组四维浮点系数。
每组顺序为世界空间 `X、Y、Z、常量`。
其后保存有效权重，以及三个零值保留字段。

系数与坐标须全部有限。
有效权重范围为 `[0,1]`。
尺寸乘积上限为 `1,048,576`。
加载器拒绝未知版本、错误长度和非零保留字段。

## 查询与求值

入口为 [IrradianceVolume.hpp](../../src/render/IrradianceVolume.hpp)。
`load(path)` 加载文件，`decode(bytes)` 加载内存。
`encode()` 可生成对应文件字节。
直接构造网格后须调用 `validate()`。

`query(worldPosition)` 对八个相邻格点做三线性插值。
各格系数先乘有效权重，再累加。
查询结果的 `weight` 是相同权重的插值结果。
范围外查询返回零系数与零权重。

`sample.evaluate(unitWorldNormal)` 评价方向系数。
每色结果为 `max(dot(linear,normal)+constant,0)`。
插值发生在系数阶段，钳位发生在最终求值阶段。
单位法线以外的输入会被拒绝。

查询所得系数已经包含有效权重。
调用方直接使用求值结果作为体积贡献。
剩余环境贡献乘以 `1-sample.weight`。
缺失格点的有效权重为零。

## 验证与使用范围

CPU 夹具使用独立的彩色方向场。
夹具覆盖边界、缺失格点及插值后钳位。
文件测试覆盖版本、尺寸、有限值和保留字段。
原生数据导出是该公共契约的另一种使用方式。

此格式表达已采样的候选方向场。
数据生产者负责源坐标、系数语义和激活规则。
原生场景的区域覆盖及层级过渡另有消费契约。
