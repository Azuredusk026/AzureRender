# 角色局部灯颜色响应

点光源和聚光灯可声明 `shape.characterResponse`。
输入控制角色漫反射与头发 KK 的局部灯颜色。
普通表面与物理路径追踪使用物理照明。
省略该对象时，局部灯沿用默认响应。

```json
{
  "schemaVersion": 1,
  "diffuseFloor": 0.25,
  "compression": 1.0
}
```

三个字段均为必填，版本为整数一。
两个参数接受零至一的有限数值。
布尔值、未知字段及方向灯组合产生加载错误。
该响应的启用由对象是否存在决定。

## 颜色与能量

入射光先计算距离、圆锥和影响体积的衰减。
最大入射通道与场景可见量决定压缩分母。
分母为 `max(max(incident)*(.5+.25*visibility),1)`。
`compression` 在原始能量和压缩能量间混合。

漫反射权重由参数下限和包裹夹角混合。
包裹夹角为 `clamp(dot(normal,light)+.5,0,1)`。
材质主方向的颜色响应乘以调整后的入射能量。
多个局部灯独立计算压缩，再按加法累计。

头发主叶另乘入射夹角正值及 `specularScale`。
局部灯的次叶保持其材质路径的既有规则。
场景 NPR 设置提供可见量的显式覆盖。
该颜色响应的启用独立于场景 NPR 开关。

## 数据与兼容

`LightShape` 持有配置及合法域校验。
关卡、场景和编辑上下文共用该类型。
编辑场景的 ECS 灯发射器保留完整参数。
`.azscene` 版本十二保存 `lightCharacterResponse`。

文本场景以 JSON `null` 表示缺省响应。
读取版本一至十一时，采用缺省响应。
JSON 关卡使用省略对象表示缺省。
保存和重开保留版本化输入。

GPU 灯记录布局版本为二，大小为 144 字节。
末行保存启用位、漫反射下限及压缩倍率。
记录按稳定灯身份排序，聚簇仍使用同一索引。
材质表、纹理槽和描述符数量保持现行容量。

资源归属场景渲染器的在途灯缓冲。
更新和释放沿用所属帧的同步规则。
线形发射、屏幕边缘及有序替换具有独立消费者。
原生模式和字段位由离线工具解释。
