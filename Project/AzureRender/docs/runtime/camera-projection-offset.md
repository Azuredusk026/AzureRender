# 相机投影偏移

## 参数与坐标

`azure.camera` 版本二声明两个投影参数。
`projectionOffsetX` 与 `projectionOffsetY` 默认为零。
取值须为 `[-2,2]` 内的有限数值。
版本一相机经类型迁移补齐零值。

偏移单位为归一化设备坐标（NDC）。
正横向偏移使成像向右移动，正纵向偏移使成像向下移动。
像素位移为偏移量乘以对应分辨率的一半。
透视与正交相机采用同一成像方向。

以下参数在 2560×1440 画面中移动约四分之一像素。
编辑属性保留八位小数，用于子像素输入。

```json
{
  "type": "azure.camera",
  "version": 2,
  "data": {
    "fieldOfView": 35,
    "projectionOffsetX": 0.00019532595,
    "projectionOffsetY": 0.00023145805
  }
}
```

## 消费与版本

共享相机投影负责矩阵、拾取及辅助线投影。
编辑器取景使用偏移视锥容纳选中边界。
聚簇覆盖和级联阴影范围消费实际投影。
天空与路径追踪使用共享射线偏移函数。

`CameraViewDescriptor::kLayoutVersion` 为二。
渲染器注册 API 为二，工厂声明须与注册器一致。
支持者通过 `supportsProjectionOffset` 声明能力。
不支持该能力的渲染器遇到非零偏移时给出诊断。

角色、空场景和路径追踪渲染器支持投影偏移。
黑洞渲染器采用自身射线构造，要求零偏移。
路径追踪相机缓冲布局二占用 144 字节。
修改偏移会使路径追踪重新累积。

## 记录与来源

捕获清单的 `cameraProjection` 记录布局与实际偏移。
非零偏移进入捕获状态指纹。
捕获矩阵的坐标解释归属离线适配工具。
项目通过相机组件保存通用数值及来源收据。

实际验证见[相机投影验收](../acceptance/nr/camera-projection-offset.md)。

## 截帧姿态接入

离线工具 `decode_raster_camera` 读取逆视图与透视矩阵。
调用方显式提供列主序的三维正交空间映射。
输出包含位置、目标、上向量、镜头及场景欧拉角。
场景欧拉角遵循 `LinearMath` 的 X、Z 旋转符号。

映射同时作用于几何、灯光和空间照明输入。
映射后的相机须具有右手正交单位基底。
剪切、缩放、非有限值及不兼容的镜头产生错误。
两处万向节边界具有确定的角度分解。

生成方案通过现有场景层级、相机组件和 GI 变换接入。
来源及实际检查见[原生反射绑定](../acceptance/nr/native-reflection-bindings.md)。
