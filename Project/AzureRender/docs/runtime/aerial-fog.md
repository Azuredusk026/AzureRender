# 光谱大气传输

`ExponentialAerialFog` 描述指数高度密度及光谱传输。
`evaluateAerialFog` 接收同一世界坐标系的线段端点。
高度采用世界坐标的 Y 分量。
结果使用公共 `FogTransport` 的散射与透射语义。
数据由调用方拥有，评价函数提供独立返回值。

## 参数

全部数值必须有限。
方向经过归一化并要求非零。
非法输入通过 `std::invalid_argument` 报告。

| 字段 | 规则 |
| --- | --- |
| `density` | 非负密度，默认零 |
| `heightFalloff` | 非负高度衰减率，默认零 |
| `referenceHeight` | 密度参考高度，默认零 |
| `startDistance` | 非负路径起始距离，默认零 |
| `extinction` | 三通道非负消光系数，默认零 |
| `rayleighColor` | 瑞利相函数的非负 RGB 系数，默认零 |
| `mieColor` | 米氏相函数的非负 RGB 系数，默认零 |
| `ambientColor` | 非负 RGB 常量，默认零 |
| `sunDirection` | 指向光源的方向，默认正 Y 轴 |
| `anisotropy` | 严格位于负一至一之间，默认零 |
| `radianceScale` | 非负辐射倍率，默认一 |
| `phaseDenominatorFloor` | 正数相函数分母下限，默认 0.001 |
| `minimumHeightDelta` | 可选无量纲积分下限，范围为负八十至八十 |

端点坐标必须有限。
零密度和起始距离以内的线段产生恒等传输。
默认高度积分按实际端点计算。
可选下限用于显式控制端点积分响应。

## 高度积分

密度按参考高度和高度衰减率作指数变化。
积分使用对数形式处理水平及极端高度射线。
高度平均密度取完整线段的高度区间。
起始距离缩减有效路径长度。
相函数方向由完整线段确定。

启用积分下限时，设线段高度差为 `dy`。
无量纲值 `q` 为 `-heightFalloff * dy` 与下限的较大值。
积分以终点密度乘 `(1 - exp(-q)) / q` 评价。
零值通过连续极限处理。

最终源颜色为相函数及常量颜色的和。
该值限制在零至一，再乘辐射倍率。
每个通道通过自身消光系数评价透射率。
散射颜色为源颜色乘不透射比例。

## GPU 布局

`pack` 产生版本一的 `PackedAerialFog`。
布局含六行十六字节数据，共九十六字节。
方向归一化和完整校验发生在打包之前。
GPU 消费方接收经过校验的参数。

| 行 | RGB 或 XYZ | W |
| --- | --- | --- |
| 零 | 消光系数 | 密度 |
| 一 | 瑞利颜色 | 高度衰减率 |
| 二 | 米氏颜色 | 参考高度 |
| 三 | 常量颜色 | 起始距离 |
| 四 | 光源方向 | 各向异性 |
| 五 | 辐射倍率、分母下限、积分下限 | 积分下限启用值 |

共享着色函数位于 `shaders/fog_analytic.glsl`。
它同时提供高度传输及有序传输合成。
独立计算验证采用测试专用着色模块。
场景资源和视图参数接入按视图雾计划实施。

来源与结果见[解析雾验收](../acceptance/nr/analytic-fog.md)。
