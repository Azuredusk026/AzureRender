# 材质主 UV 取样策略

版本二材质通过 `mirrored-coarse-uv` 声明主 UV 足迹。
默认材质使用设备的隐式梯度。
该特性适用于受光不透明表面和遮罩表面。
普通 PBR 与投影头发使用相同的策略入口。
投影头发可在单采样颜色路径声明[主纹理层级](projected-hair-lighting.md#主纹理层级)。

## 输入与数值

主 UV 来自导入器选定的表面坐标流。
材质纹理角色统一声明所用来源索引。
选择第二套来源坐标时，切线及保留流遵循导入契约。
片元入口在一致控制流中计算横纵细粒度梯度。
横向梯度读取四像素组下行，纵向读取左列。
计算发生在节点透明度、裁剪与覆盖分支之前。

基础颜色、法线、参数和主 UV 遮罩消费这些梯度。
深度、阴影和轮廓的覆盖取样使用对应图元的足迹。
多重采样保留所属接口的四分之一足迹倍率。
显式固定层级和其他坐标域按各自的取样契约执行。

眼睛径向坐标、折射和积分取样拥有独立契约。
这些特性与主 UV 镜像策略组合时提供明确错误。
非受光表面、合成表面与透明表面也由加载器拒绝。
类型化打包与文本解释器共同校验所有权。

## 程序与资源

宿主查询片元阶段的四像素组操作能力。
预检在材质管线的首个程序模块创建前完成。
缺失能力时报告错误，并执行所属加载失败清理。
能力要求见[公共梯度助手](material-uv-gradients.md)。
默认策略沿用所属设备路径。

参考程序族包含类型化照明实现。
场景、独立裁剪、多重采样与环境场保持各自配置。
程序文件保留现行资源和覆盖后缀。
`_uvquad` 后缀标识参考足迹的程序。

场景渲染器拥有参考管线及源程序对应关系。
创建发生在场景准备期间，绘制只选择已有管线。
材质关闭该特性后使用所属默认管线。
关闭场景前等待在途工作结束，再销毁参考管线。

## 布局与验证

特性使用材质标志位二十七。
材质表为二十三行及 368 字节。
保存和重新打开保留特性名称及原有材质参数。
非法版本和输入组合提供特性名称关联的诊断。
未知材质类别在类别位集索引前拒绝。

参考程序族与设备程序族分别进入程序集清单。
程序总数保持现行 1024 项预算。
数值、公开材质与原生区域分别验收。
专项结果持续维护于原生画质实施计划。
