# 音频导入与播放

WAV、MP3、FLAC 与 Ogg Vorbis 使用统一注册入口。
Opus、AAC 与 M4A 沿用同一导入与播放契约。
AAC/M4A 使用 Windows 系统媒体解码服务。
公共导入操作复制来源，并验证完整音频样本。
导入摘要记录采样率、声道、帧数和播放策略。
音频资源通过稳定资产标识引用。

## 解码契约

解码输出为交错排列的三十二位浮点样本。
采样率范围为 8000 至 192000 Hz。
声道范围为一至八声道，时长上限为两小时。
转换设置的零值表示保留来源规格。

来源文件上限为 128 MiB。
单次预解码输出上限为 256 MiB。
完整样本验证使用每块 4096 帧的缓冲。
读取与解码按块检查取消状态。

时长超过三十秒的声音采用流式播放。
其他声音采用预解码播放。
运行时描述查询返回实际数据源策略。
流式策略限制解码样本驻留。

Windows 文件读取使用宽字符路径接口。
夹具覆盖中文、表情字符及大写扩展名。
容器、样本截断及非有限数值产生诊断。
重导入沿用内容事务和来源指纹校验。

## 编辑与生命周期

导入入口为 `asset.import`。
音源组件标识为 `azure.audio-source`。
组件配置资产、音量、循环、自动播放与启用状态。
界面和自动工具共用公共编辑操作。

保存重开保留音频资产标识及音源字段。
项目资源包包含导入的音频容器。
来源移除后，资源包仍可独立解码。
音频资源目录由项目资源系统管理。

暂停保存声音恢复状态，并停止输出。
恢复后继续有效声音的播放。
实体销毁及场景替换释放音源所有权。
重复释放同一声音保持安全。

设备不可用时，运行时提供离线混音。
离线测试验证波形、频谱、循环和静音。
实体听感及输出设备在 P8 记录。
自动结果按阶段证据维护。

依赖来源见[音频源码清单](../licenses/audio-codecs-source.json)。
生成夹具采用 `CC0-1.0`。

压缩音频规则见[压缩音频交换](compressed-audio.md)。
