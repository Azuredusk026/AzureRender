# 径向眼表面

该能力属于公共材质导入和角色表面着色。
角色眼睛与独立材质面板共用该契约。
照明可选宿主朗伯响应或 NPR 主灯与环境合成。
原生光照绑定与画面等价性具有独立验收范围。

## 材质配置

父画像使用版本二，类别为 `eye`。
特征名称为 `eye-radial-surface`，占第 17 位。
`eyeSurface` 子对象使用版本一。
画像可组合 `silhouette-outline` 与 `geometry-shadow`。

绘制模式为 `OPAQUE`。
省略 `alphaMode` 使用 glTF 的不透明默认值。
显式值按原始 JSON 类型和内容校验。

基色 Alpha 作为眼表面遮罩参与颜色计算。
公共节点透明度继续管理几何覆盖。

配置结构见[眼表面模式](../../schemas/eye_radial_material.schema.json)。
加载器检查纹理索引、图像和采样器。
全部必需字段均需显式提供。
未知子字段、空值和非有限数均拒绝。

材质和纹理扩展需具有独立适配契约。
当前眼表面接受直接声明的 glTF 纹理。

颜色以线性值输入，范围为零至六十四。
有符号 UV 参数范围为正负六万五千五百三十六。

## 纹理与参数

| 材质槽 | 内容 | 颜色传输 |
| --- | --- | --- |
| 0 | 基色 RGBA | RGB 解码一次，Alpha 保持线性 |
| 4 | 单行 RGBA 色带 | 四通道均为线性 |
| 5 | RGBA Matcap | RGB 解码一次，Alpha 保持线性 |

色带至少包含两个横向纹素。
色带使用钳制线性采样、零级纹理及各向异性一。
宿主朗伯模式的 Matcap 采用相同状态。
NPR 模式的 Matcap 消费所声明的纹理采样器。
其 mip、层级过滤及偏移遵循公共图像元数据。

NPR Matcap 支持线性过滤与最近层级选择。
原生压缩 DDS 可保留已有的逐级图像。
RGB 解码一次，Alpha 使用线性数据。
源采样器及图像元数据共同声明实际状态。

基色保留所支持的源线性采样配置。
外部元数据遵守固定颜色传输语义。

原 UV 经 `uvScaleOffset` 变换后决定圆域。
视差仅改变基色采样坐标。
横向与纵向视差比例为一比四分之一。
视差计算使用归一化切线视线。

其公式保留正视与掠射方向的有限结果。

照明法线和 Matcap 法线分别由圆域构造。
两者消费原始插值法线和切线。
镜像手性由切线第四分量传递。
Matcap 使用当前相机的实际视图旋转。
视图旋转保持独立于视野和天空投影缩放。

源 UV 与切线基的坐标约定须共同核对。
法线与切线方向相同时，V 反向对应手性反向。
烘焙进顶点的 UV 变换须与画像参数保持一致。
动态资产的转换保留骨架、权重和动画通道。

零长度向量使用明确的宿主回退规则。

## 宿主照明

`lightingInputs.source` 为 `host-authored`。
`illuminationModel` 选择 `host-lambert` 或 `npr-main-ambient`。
`matcapShadowFloor` 和 `directWeights` 均显式填写。
这些值由内容作者持有。

每盏场景灯提供实际方向与辐亮度。
朗伯项、基色、颜色乘子和色带组成漫反射。
漫反射另乘显式 Alpha 预乘因子。
Matcap 的 RGB 与 Alpha 分别贡献颜色。

该项乘独立照明和色带 Alpha 因子。
直接颜色项按配置只合成一次。
关闭场景灯后，直接颜色仍可保留能量。

方向灯使用宿主阴影可见性。
阴影选择量取一减宿主阴影可见性。
局部灯使用零阴影选择量。
展示照明使用宿主主方向灯。

宿主朗伯模式提供直接灯与显式直接颜色。
NPR 模式复用场景的 `nprLighting` 主灯与环境合成。
该模式另需 `ambientColor`、`mainColor` 和 `shadowScale`。
颜色范围为零至六十四，阴影倍率范围为零至一。

NPR 模式使用径向照明法线的世界水平投影。
色带 Alpha 与视角色带分别控制明暗和室内响应。
Matcap 使用独立照明、色带权重及虹膜圆域遮罩。
材质直接颜色按声明的权重合成一次。

主灯、环境与 Matcap 先形成 HDR 组合。
组合亮度超过二分之一时计算饱和度增益。
增益为一加亮度超量的平方，超量上限为二分之一。
局部灯响应按自身通道独立合成。

场景需启用正式灯光及 NPR 合成。
其关闭状态使用宿主朗伯照明。
完整原生等价性还需眼白、附加主光及动态对照。
原生配方的 `readyForImport` 继续由完整验收决定。

## 材质表

绑定 27 保存每材质十二行、共 192 字节。
公共布局版本为九。
纹理块和材质表共享稳定材质索引。
头发与眼睛通过各自的类型函数打包。
大小、对齐、偏移和全部参数进入检查。

首六行保存眼表面的基础参数。
NPR 第七行 X 保存阴影倍率，W 保存启用标志。
第八行 RGB 保存环境颜色，第九行 RGB 保存主灯颜色。
其余扩展分量为零，纹理槽总数为九。

场景加载器拥有该不可变缓冲区。
所有在途帧共享同一分配。
卸载在渲染工作结束后释放分配。
眼表面复用既有纹理描述符。

## 验证

加载红测进入 `AzureRender.CharacterRepair`。
它先验证真实生产加载路径的缺失行为。
实现验收覆盖合法输入和非法配置。
类型检查比较全部眼睛参数及头发布局。

GPU 夹具使用固定纹理和独立像素期望。
覆盖视差、圆边界、颜色传输和 Alpha。
灯光零能量、线性响应和颜色响应各有控制。
固定与索引描述符路径比较完整画面。

`AzureEngine.EyeNprGpu` 验证 NPR 适配器。
常量纹理提供独立颜色期望，线性误差预算为 `0.008`。
用例覆盖独立主灯、环境、HDR 饱和度及 mip 偏移。
完整材质文档与内嵌画像使用相同参数解释。

旋转夹具使用显式的场景欧拉角映射。
解析正向 Z 旋转对应负向场景欧拉角。
独立像素期望与误差预算在复验期间保持固定。

校验日志和卸载资源计数属于验收条件。
构建与 GPU 结果以实际运行收据为准。
