# 参考光栅位置

`ReferenceRasterProjection.hpp` 提供光栅位置组合。
参考视图决定横纵位置及齐次尺度。
设备最终位置决定归一化深度。
屏幕变形由设备基础位置与最终位置的差表达。

## 输入与计算

`composeReferenceRasterPosition` 接收三组裁剪坐标。
参考坐标来自已校验的投影。
设备基础坐标表示变形前位置。
设备最终坐标包含深度偏移及屏幕变形。

组合保留参考横纵位置和齐次尺度。
最终深度按设备深度除以设备尺度再乘参考尺度计算。
横纵偏移按两组设备归一化位置相减计算。
偏移乘参考尺度后加入参考横纵位置。

乘法、除法和加法各自保留单精度边界。
横纵位置及尺度相同时直接保留参考横纵位值。
关闭、任一尺度为零或组合溢出时返回设备最终位置。
CPU 组合接口拒绝非有限输入。

## 配置与所有权

`projectReferenceRasterPosition` 消费准备后的相机视图。
该入口共用坐标帧、参考投影及纵轴方向。
相机投影输入及溢出遵守参考视图的校验契约。
GPU 调用方提供已校验的有限输入。

`referenceRasterProjectionParameters` 返回上传数据副本。
结构占 112 字节，包含投影、坐标帧及控制字段。
版本值为一，标志位一表示启用，标志位二表示纵轴翻转。
配置通过准备对象及工厂生成。

`reference_raster_projection.glsl` 提供同名组合能力。
模块创建沿用参考融合乘加的显式准备入口。
调用方拥有 GPU 资源、同步及关闭顺序。
数学接口拥有数值副本，支持场景绘制及独立校准工具。
