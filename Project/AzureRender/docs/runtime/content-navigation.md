# 内容导航与基础创建

> 文档类型：操作说明与接口参考
> 状态：生效

## 浏览与打开

内容浏览器提供目录树、面包屑与导航历史。
单击目录树进入目录，双击文件夹进入子目录。
Back 与 Forward 浏览当前会话的历史。
All 展示全部资产，类型和搜索共同筛选内容。

单击资产选择条目，Ctrl 单击增减选择。
双击资产按注册类型打开。
模型打开独立预览，图片打开纹理设置。
其他已注册类型打开只读资产诊断。

模型与 Prefab 可拖入视口。
右键菜单的 Place in scene 提供显式放置。
放置与变换形成一个撤销单元。
文件操作及影响确认见[内容事务](content-transactions.md)。

列表和网格仅绘制当前可见行。
紧凑面板使用列表，并在加号入口提供目录导航。
网格的 Thumbnail size 调整缩略图尺寸。
用户设置键为 `editor.thumbnailSize`。
有效范围为 64 至 192，默认值为 96。

目录树保留空目录。
项目挂载提供浏览范围与写入边界。
外部目录变动通过后台增量扫描发现。
后台结果在文档版本仍匹配时发布。

## 创建基础对象

在 Import / Create 中打开 Generate primitive。
选择形状，填写尺寸、分段与文件名。
Generate asset 在当前目录生成 GLB 模型。
生成后选择资产，再使用明确的放置入口。
创建入口要求新的文件名，重名时保留已有资产。

| 参数 | 有效范围 |
| --- | --- |
| `kind` | `cube`、`plane`、`sphere`、`cylinder` |
| `size` | 三个正有限数，各不超过 10000 |
| `segments` | 1 至 128 的整数 |
| 球与圆柱分段 | 4 至 128，且为四的倍数 |
| 文件格式 | `.glb` |

尺寸表示模型三个轴上的总跨度。
平面位于 XZ 平面，其 Y 跨度为零。
球与圆柱支持非均匀尺寸和单位法线。
GLB 包含顶点、索引、法线、UV 与默认 PBR 材质。

生成来源记录 `azure.primitive` 与版本 1。
参数哈希与输出哈希参与来源校验。
生成结果通过正式 glTF 加载器验证。
同参数产生相同的模型字节。

Create object 提供注册对象预设。
Point light 创建节点及关联点光源。
Third-person camera 创建第三人称相机组件。
相机的目标字段可通过属性面板选择节点。

预设创建、组件初始化与灯光归属共用事务。
撤销同时恢复节点、组件及灯光。
扩展预设通过 `NodePresetRegistry::add` 注册。
组件字段消费现有默认值和引用默认策略。

## 公共操作

| 操作 | 参数与结果 |
| --- | --- |
| `content.directory` | `mount`、`path`、`type`、`search`、`refresh`。返回目录快照 |
| `asset.open` | `asset`。返回类型、标签与目标操作 |
| `asset.place` | `asset`、`origin`、`direction`。执行场景放置 |
| `asset.generate` | 生成器、输出、参数、来源许可。返回资产 UUID |
| `node.presets` | 查询已注册对象预设 |
| `node.create-preset` | `preset`、可选 `id`。创建可撤销对象 |
| `path.reveal` | `path`。通过 Windows 文件管理器揭示来源 |

目录路径使用挂载内的相对路径。
父级越界、绝对路径及未知挂载会被拒绝。
快照包含版本、目录、资产、诊断与统计。
搜索为不区分 ASCII 大小写的路径子串匹配。

目录模型缓存不可变快照。
资产版本或场景资源使用关系变化时刷新内容。
筛选组合拥有独立快照，缓存最多保留 64 项。
目录状态与场景内容分别管理生命周期。

目录时间戳的检查间隔为 300 毫秒。
首次索引和变动后的结果发布具有独立成本。
后台扫描使用资产数据库的源文件复用机制。
切换项目、关闭服务与文件写入会取消活动扫描。
失败诊断留在目录快照中，当前场景内容保持有效。

固定步长运行时，编辑器与宿主共用时间步长。
双击识别及相机输入因此消费同一时间来源。
常规运行使用 GLFW 提供的实际时间。

## 验证入口

在工程目录运行以下测试。

```powershell
ctest --test-dir build/ninja-msvc-debug `
  -R 'ContentNavigation|ContentDirectoryScale|PrimitiveGenerator' `
  --output-on-failure
```

目录夹具覆盖空目录、一万条资产与外部变化。
几何夹具通过正式加载器检查尺寸、法线与绕序。
输入回放检查导航、双击打开与显式放置。
实体键鼠及文件管理器窗口复核按实际执行情况记录。
