# 材质显示变换

材质画像版本二提供 `displayTransform` 字段。
枚举为 `scene` 和 `linear`，缺省为 `scene`。
版本一显式声明该字段会触发加载错误。
未知值及非字符串输入也会返回字段诊断。

`scene` 消费视图的调色表、色调映射及颜色调整。
`linear` 消费曝光后裁切至零至一的线性颜色。
目标表面继续负责输出的颜色编码。
完整材质文档和内嵌画像共用该契约。

```json
{
  "azureRenderMaterial": {
    "schemaVersion": 2,
    "class": "generic",
    "features": [],
    "displayTransform": "linear"
  }
}
```

## 计算顺序

材质照明、反射及辐亮度倍率先完成计算。
雾、泛光和曝光继续按所属视图配置运行。
最终显示按片元的显示归属权重组合两种变换。
反射表面使用自身策略显示完整反射结果。

含雾纹理层在雾传输之前应用材质辐亮度倍率。
雾散射保留所属视图的辐射单位。

不透明及裁切片元直接写入所属显示策略。
普通透明片元按实际 Alpha 合成显示权重。
乘法及加法覆盖继承已有表面的显示归属。
这两类覆盖要求 `displayTransform` 为 `scene`。

具名轮廓采用所属材质的策略。
视图预设轮廓、天空及背景采用场景策略。
诊断视图继续使用各自的数据单位。
时间重建按同一运动及深度规则累计显示归属。
累计值与显示重建值分别保存于双通道历史图像。
最终显示消费当前提交的显示重建值。

## 资源与接口

公共画像布局为十九，每项二十二行，共 352 字节。
`rows[21].x` 保存枚举：场景为零，线性为一。
`rows[19].w` 继续保存辐亮度倍率。
场景渲染器接口版本为六。

主视图和编辑视图持有单通道 `R8_UNORM` 附件。
附件记录场景显示权重，清除值为一。
材质在同次绘制中写入实际覆盖。
加法和乘法覆盖保留附件已有数值。

四倍多重采样按覆盖样本平均解析显示权重。
时间历史采用两份 `R16G16_SFLOAT` 图像。
红通道保存累计权重，绿通道保存显示权重。
该历史额外占用每像素八字节。

帧图声明附件的生产、读取和解析依赖。
附件随所属视图创建、重建及释放。
`supportsMaterialDisplayTransform` 声明后端支持能力。

捕获清单列出 `materialDisplayTransforms` 非缺省项。
清单同时记录附件格式、数量及逻辑字节数。
画面状态指纹版本四包含主资产的显示枚举。
验证入口为 `tools/test_material_display_gpu.py`。

来源画面的外观验收由[开发总计划](../plans/azure-engine-plan.md)持有。
