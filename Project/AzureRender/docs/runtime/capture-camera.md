# 捕获相机来源

捕获清单消费帧内选定的 `CameraViewDescriptor`。
近远裁剪字段与该视图保持相同来源。
关卡后备设置按所属文档独立保存。

## 镜头与方向

`cameraLens` 使用版本一，保存实际镜头输入。
透视镜头记录以弧度表示的垂直视场。
正交镜头记录世界单位的可见高度。
两类镜头共同记录近远裁剪与 NDC 偏移。

`cameraUp` 保存选定视图的上向量。
相机位置与目标继续通过既有 QA 字段查询。
镜头对象及上向量按完整单精度值序列化。
未选定显式视图时，两处字段保存 `null`。

`cameraProjection` 保留版本二的偏移描述。
偏移单位及方向见[相机投影偏移](camera-projection-offset.md)。
报告字段描述捕获时的选定视图。
各渲染器按已声明的相机能力消费该视图。

## 状态指纹

`qaStateFingerprintVersion` 为二。
指纹纳入实际裁剪、镜头及完整精度的姿态。
姿态包含位置、目标点与上向量。
镜头与姿态以独立版本标记进入既有 FNV-1a-64 输入。

不同镜头或姿态可以产生不同指纹。
超出可见几何的裁剪变化仍属于不同输入状态。
指纹用于识别输入，图像结果另行比较。
来源版本共同限定跨批次指纹的解释范围。

操作检查见[捕获相机验收](../acceptance/nr/capture-camera.md)。
