# 蒙皮位置契约

关节调色板消费仿射矩阵及导入后的蒙皮权重。
加权矩阵作用于形变后的局部位置。
其 XYZ 结果作为仿射点保存，齐次 W 固定为一。
权重的浮点舍入仍参与 XYZ 运算。

共享函数为 `shaders/skin_position.glsl` 的 `azureSkinPosition`。
计算、顶点、描边及阴影路径消费同一约定。
当前运动顶点及上一姿态也使用该函数。
模型、操纵器及相机投影随后按各自矩阵作用。

计算蒙皮存储位置的三个浮点分量。
顶点读取该位置时恢复 W 为一。
透视投影产生的 W 保留其真实符号及大小。
投影裁剪和运动有效性继续消费该值。

本契约使用既有调色板、实例和运动缓冲。
资源布局、描述符及帧所有权保持现行规则。
CMake 将共享函数列入所属着色器的构建依赖。
验证及实际画面见[位置一致性验收](../acceptance/nr/skinning-position-consistency.md)。
