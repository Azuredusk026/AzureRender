# 刚体节点动画

阶段索引为 NR7，公共入口为 glTF 导入与动画姿态。
未蒙皮网格可由自身或祖先节点的动画驱动。
同一资产可以组合刚体节点与一个 glTF 蒙皮。
具体场景和资源名称由项目内容持有。

## 数据与生命周期

导入器保留刚体网格在绑定姿态中的烘焙位置。
包含动画或蒙皮的资产为刚体网格分配虚拟关节。
虚拟关节追加到既有关节调色板。
源蒙皮的关节编号保持稳定。

虚拟关节矩阵等于当前节点世界矩阵乘绑定逆矩阵。
刚体顶点只绑定对应的虚拟关节，权重为一。
节点姿态、实例时钟及混合使用既有动画接口。
GPU 计算、顶点着色及 CPU 查询消费同一调色板。
GPU 路径按[位置契约](skinning-position.md)保存仿射点。

共享资产持有绑定数据，实例持有独立姿态。
当前姿态参与包围盒计算和拾取。
缓冲上传、快照与释放沿用场景渲染器生命周期。
纯静态资产使用绑定几何和单位调色板。

## 输入边界

支持平移、旋转、缩放及祖先层级的姿态变化。
零缩放可用于对象寿命结束后的几何消隐。
绑定矩阵须为有限且可逆的仿射矩阵。
矩阵创作节点的直接动画仍按导入规则拒绝。

动画插值、循环与混合遵循既有曲线契约。
动态反射手性与非均匀缩放的着色需专项验证。
透明图元仍按既有透明排序机制处理。
粒子随机值、逐对象透明度及发射状态属于内容转换。

## 检查

`AzureRender.AnimationPose` 使用公开嵌入式夹具。
夹具验证动画父节点、静态兄弟与零缩放边界。
混合夹具验证真实蒙皮编号及刚体节点的联合运动。
同时验证绑定姿态和当前姿态包围盒。

受影响检查包含 MorphTargets 与 AssetDeformation。
TextureMaterialImport 验证导入侧既有纹理行为。
独立动画 GPU 回归覆盖实例时钟及 CPU 路径。
原生物流资产以[物流证据](../acceptance/nr/logistics-evidence.md)单独验收。
