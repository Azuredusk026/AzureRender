# 时序帧状态与提交

本契约属于渲染模块。
主宿主、Player 和辅助视图共用提交通知。
场景渲染器注册 API 为版本三。
相机历史按独立渲染器实例持有。

运动附件及历史图像按 NR7-AA 继续接入。

## 相机状态

`TemporalViewState` 持有已提交和待提交的状态。
`prepare` 检查尺寸、场景代次、投影和有限值。
重复准备保持上次已提交状态及采样序号。
`commit` 仅接受递增的非零提交号。

首帧、尺寸、场景、切镜标记和投影分别使历史失效。
连续相机运动保留前帧矩阵。
曝光变化保留前帧曝光，供颜色历史换算使用。
`cancel` 丢弃待提交状态，`clear` 清理相机历史。

八相位抖动使用居中的 Halton 采样。
相位随该视图的成功提交推进。
全局跳帧和帧环槽位保持独立。
采样序号用于提交观察，时序投影由输出阶段装配。

角色渲染器保存当前投影与视图投影矩阵。
场景复用、资源重建和卸载清理相机历史。
缺失尺寸或非有限矩阵使本帧历史不可用。
采集清单记录提交号、相位及相机状态有效性。

## 宿主通知

`ISceneRenderer::onFrameSubmitted` 在队列接受后调用。
`onFrameAbandoned` 处理录制或提交失败。
通知由拥有者线程执行，并遵守不抛异常的契约。
录制工作线程在通知前完成会合。

辅助视图通过 `RenderViewService::submitted` 分发通知。
仅本次实际参与且完成录制的视图接收通知。
静态缓存和跳帧视图保持其上次提交。
退役视图仍接收所属已录制帧的通知。

`cancel` 仅用于队列尚未接受的工作。
取消恢复请求，供下一次调度重试。
被丢弃的渲染图持有租约，直到回调随图销毁。
`complete` 表示围栏完成，负责资源退役。

## 运动投影

`motion_projection.glsl` 消费前后帧未抖动裁剪位置。
坐标采用 Vulkan 深度范围与正高度视口。
输出 XY 为当前减前帧的归一化 UV 位移。
输出 Z 为前帧设备深度，W 为显式有效标记。

非有限、相机后方及裁剪域外输入输出无效零值。
可用性由调用方与位置检查共同确定。
不存在的前帧实例必须传入无效状态。
片元插值后执行透视除法，保留前帧投影关系。

GPU 数值检查包含十八组、七十二项标量。
方向、透视缩放、近平面、远平面和无效值分别检查。
该检查验证公共投影数学。
逐实例前帧变形、覆盖与最终画面分别验收。
