# 三层辐照体积资源

`IrradianceClipmap` 属于 RenderCore 的资源契约。
它保存三层浮点幅度、方向 RGBA 和默认球谐。
独立查询与运行时着色消费相同的坐标及组合规则。
GPU 接入按所属场景生命周期验收。
入口见[资源类型](../../src/render/IrradianceClipmap.hpp)。

## 坐标与覆盖

`worldToField` 包含三个四维仿射行。
前三列构成正交单位轴，允许轴向镜像。
第四列提供平移，层中心与纹理坐标均位于场空间。
返回系数的线性项转换到世界法线的基底。

每层保存中心、格距、水平半径、垂直半径和过渡宽度。
格距与过渡宽度必须为正，其余半径须非负。
三层中心与边界由内容提供，运行时按查询位置求权重。
资产中的轴向与位置具有独立字段语义。

## 纹理与组合

三层幅度共享尺寸，采用 `R11G11B10_FLOAT` 编码。
方向场采用八位 UNORM，Y 方向依次排列三个颜色块。
每块高度与幅度高度相同，四个通道完整保存。
幅度使用三线性重复采样，方向使用三线性钳制采样。

方向坐标在颜色块内限制到半像素边界。
层权重、方向解码和默认环境采用显式三层组合。
第零组方向 Alpha 参与默认环境的权重计算。
外层范围之外及资产禁用时返回完整默认球谐。

`query(worldPosition)` 返回三色四维世界系数。
结果包含已组合的默认环境，其有效权重为一。
法线求值调用现有 `IrradianceSample::evaluate`。
原生像素的法线偏移、抖动及最终增益属于消费者。

## 文件格式

文件采用小端整数和 IEEE 754 单精度。
文件头固定为 224 字节，标识为 `AZIC0001`。
每层按幅度载荷、完整方向载荷的顺序排列。
体素按 X、Y、Z 依次递增。

| 偏移 | 内容 |
| --- | --- |
| 0 | 八字节版本标识 |
| 8 | 三个无符号幅度尺寸 |
| 20 | 启用值，零或一 |
| 24 | 三个坐标变换行 |
| 72 | 红、绿、蓝默认球谐行 |
| 120 | 三层中心格距行与边界行，逐层交替 |
| 216 | 两个零值保留整数 |
| 224 | 三层幅度及方向载荷 |

尺寸乘积最多为 4,194,304。
文件长度必须精确等于 `224+48*体素数`。
加载器拒绝未知版本、非法结构及非有限幅度。
全部变换、边界及默认系数须有限。

`encode` 和 `decode` 提供内存往返。
`load` 在读取载荷前检查文件大小预算。
直接构造资源后调用 `validate` 验证全部载荷。
`shaderParameters` 提供十三行同布局参数。

## GPU 资源

`IrradianceClipmapGpu` 持有六份三维图像和两个采样器。
参数缓冲为十三个四维行，共 208 字节。
GPU 纹理的每个轴最多为 256，方向高度计入三色块。
加载前检查格式采样能力与完整数据。

构造期间完成上传，后端生命周期覆盖全部资源。
调用方等待相关帧完成后销毁所有者。
构造失败释放已取得的资源，析构释放完整所有权。
场景通过描述符数组绑定六份纹理及参数缓冲。
共享着色函数位于 `shaders/irradiance_clipmap.glsl`。

独立 GPU 检查支持普通、禁用和镜像体积。
资源路径与点位文件可用于逐点原始查询。
`--sample-only` 输出设备结果，并检查有限值及资源释放。
该模式的数值预算由外部来源参考负责验收。
