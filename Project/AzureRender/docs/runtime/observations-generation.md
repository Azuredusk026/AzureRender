# 观察验证与内容来源

> 文档类型：运行时设计
> 适用范围：观察、自动工具与资产生成

## 模块与线程

`ObservationRegistry` 属于 Runtime。
应用注册名称和只读回调。
值支持布尔、整数、有限浮点和字符串。
读取在注册表所属线程执行。

`AzureValidation` 消费观察契约和宿主回调。
编辑回调使用 `EditService`。
输入回调使用正式输入回放路径。
截图回调使用渲染读回路径。

网络线程负责解析、鉴权与排队。
宿主线程执行世界读取和操作。
关闭时完成排队请求，再回收传输线程。
独立 Player 按需提供运行观察。

## 查询与操作

基础查询包括 `engine.status` 和 `engine.frameCount`。
`scene.nodeCount` 返回当前场景节点数。
编辑宿主追加文档版本与稳定选择身份。
应用可注册自己的命名空间。

`editor.workspace` 返回当前工作区的 JSON 字符串。
字段包含相机、工具、选择、捕获和未保存状态。
实时查询包含历史条数，输入历史写入运行报告。
`editor.dirty` 返回当前文档的未保存标记。

`document.version` 返回完整版本的规范 JSON 字符串。
工具一次查询即可取得同一时刻的基础版本。
编辑自动脚本也支持 `wait-until` 与 `assert-query`。
两种脚本消费同一只读观察注册。

| 操作 | 语义 |
| --- | --- |
| `describe` | 发现观察与可用操作 |
| `query` | 获取注册值 |
| `assert` | 检查值与 `equals` 一致 |
| `wait-until` | 等待注册值满足条件 |
| `wait-frames` | 等待指定宿主帧数 |
| `edit` | 执行携带基础版本的生产操作 |
| `input` | 排队正式输入事件 |
| `screenshot` | 安排截图并返回标签 |

协议为版本 1 的 JSON 行消息。
控制通道使用非空会话令牌。
错误令牌与未知操作均得到明确失败。
端点只接受 IPv4 回环地址。

输入请求使用 `domain` 声明归属。
编辑器默认使用 `editor`，Player 默认使用 `game`。
游戏输入进入生产回放队列，按宿主帧消费。
编辑器的游戏输入要求运行预览已启动。

游戏回放期间由回放队列拥有按键状态。
`engine.gameInputSource` 报告当前输入来源。
非法游戏事件保持有效输入来源。

待消费事件至多 8192 项，累计计数独立保存。
编辑事件支持键、文本、鼠标、滚轮与拖动。
游戏事件支持键、焦点、相机与关卡操作。

## 预算与报告

单请求至多 64 KiB，单响应至多 1 MiB。
队列至多 64 项，请求期限至多 60000 ms。
连接至多八个，条件等待保持其他连接可查询。
未完成的消息帧期限为两秒。

验证脚本至多 1024 步、2 MiB 和 300 秒。

等待在帧边界推进。
超时、断言失败与非法输入分别记录诊断。
步骤报告包含实际耗时。
宿主报告声明正式模式和测试选项。

## 生成注册与清单

`GeneratorRegistry` 属于资产层。
注册项声明生成器 ID、版本和工厂。
工厂接收参数、解析后的输入与取消检查。
运行时负责项目挂载和资产身份解析。

`GenerationManifest` 保存输入与依赖哈希。
它还保存参数、输出哈希和许可来源。
内容指纹使用带前缀的 FNV-1a 64 位值。
来源清单版本为 1。

确定输入产生确定内容指纹。
源数据变化使对应生成版本失效。
输出篡改由资产刷新拒绝。
当前有效缓存保持其所属版本。

## 候选提交

`AssetDatabase::generateAsset` 接收项目输出路径。
生产生成操作要求项目会话具备资产服务。
普通场景会话得到明确拒绝并保持文档。

生成结果先通过调用者的领域校验。
候选再经过资产依赖与引擎格式校验。
成功提交保留资源 UUID。
资产版本变化使已有编辑提案过期。

关卡、Prefab 与动画图使用现有解析器。
glTF 和 GLB 使用现有加载器。
失败或取消恢复有效源文件与元数据。
资产数据库与历史缓存保持有效。

生成参数至多 2 MiB。
输入及依赖总计至多 256 MiB。
输出至多 128 MiB，引用总计至多 1024 项。
领域生成器还可声明自己的规模预算。

程序化领域注册几何、刚体动作与动作图生成器。
它们消费同一来源、许可与资产安装契约。
编译预算与源语义见[程序化内容说明](procedural-content.md)。

运行时在读取前检查源文件总量。
源文件分块读取，每块检查取消状态。
读取期间源文件大小变化得到明确拒绝。
读取失败保持已提交资源与缓存。

## 导入与交付

glTF 导入记录复制输入与输出的来源清单。
清单保存在主资产的 `.azmeta` 中。
导入副本相对路径参与完整性检查。
候选通过检查后提交资产与编辑文档。

`LicenseRef-External-Asset` 指向项目的资产授权记录。
项目交付时应提供对应来源与许可说明。
生成资产使用调用者提供的许可来源。
公开包保留 `.azmeta` 与来源信息。

项目移动保留虚拟路径、UUID 与内容哈希。
包清单关联输出和来源记录。
操作入口见[开发命令参考](../reference/developer-cli.md)。
