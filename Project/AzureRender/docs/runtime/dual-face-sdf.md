# 双图脸部距离场

阶段索引为 NR6。
通用入口位于 glTF 材质加载与角色渲染模块。
该能力消费独立距离图、遮罩和线性色带。
适用于角色脸部及使用相同输入的风格化表面。

## 配置

在材质的 `extras.azureRenderMaterial` 中配置：

```json
{
  "schemaVersion": 2,
  "class": "face",
  "features": ["face-sdf-eligible"],
  "faceSdf": {
    "schemaVersion": 2,
    "texture": 0,
    "maskTexture": 1,
    "rampTexture": 2,
    "texCoord": 0,
    "headNode": "Head",
    "headBasis": [1, 0, 0, 0, 1, 0, 0, 0, 1],
    "lightAdjustment": [0, 0, 0]
  }
}
```

三张图均引用同一 glTF 的有效纹理索引。
颜色空间为线性，距离图与遮罩保留完整 RGBA。
采样采用 UV0、边缘钳制和零级纹理。
色带通过材质槽 5 消费，遮罩使用槽 4。

`headNode` 必须唯一解析到节点。
`headBasis` 按列依次给出右、上、前方轴。
九个分量须组成正交单位基底。
允许左右手基底，以表达源坐标系的反射。

`lightAdjustment` 为可选三元数组，默认全零。
首项范围为零至一，控制背光修正的禁用比例。
第二项范围为负一至一，控制几何光照偏置。
末项范围为负一至一，控制距离场包裹偏置。

同一网格资源中的脸部材质共享一个头部基底。
混用版本、头节点或基底时，加载器报告错误。
不同资源及其实例可各自声明头部配置。
版本 1 的单通道距离场具有独立解析路径。

## 运行机制

头节点从当前动画姿态取值。
实例变换与材质基底共同生成世界方向。
每个实例增加 64 字节的头部矩阵。
顶点路径同时应用编辑变换中的旋转。

当前方向转换要求头部变换各轴正交且非退化。
各轴的尺度通过归一化去除。
包含剪切的层级变换需另行验证。
原生角色候选使用单位尺度骨架。

水平光在头部右轴为正时，使用原始 U。
其余方向使用 `1-U`，V 保持原值。
距离阈值取距离图 RG 的平均值。
遮罩 G 控制距离场与几何余弦的混合。

距离图 B 构建随主光侧镜像的头部法线。
世界法线归一化后，与几何法线按遮罩 G 混合。
混合向量的平方长度至多为 `1e-12` 时回退几何法线。
该回退确保反向法线等权混合时输出有限。

角度包裹与背光修正共同确定色带坐标。
最终坐标按边缘采样语义钳制到零至一。
垂直光与垂直相机使用显式水平回退方向。
公开 GPU 数值测试覆盖该退化条件。

材质自身选择双图色带响应。
场景照明中的每盏局部灯独立计算脸部色带。
头部方向、遮罩与灯到表面的方向共同参与采样。
色带响应乘以该灯的颜色、强度及形状衰减。

环境漫反射和辐照体积保留各自的采样契约。
工作区径向候选通过[角色漫反射组合](npr-diffuse.md)选择。
该模式消费头节点位置与遮罩 G，生成环境法线。
其帧原点与原生动画附加帧的等价性独立验收。

脸部轮廓光与局部灯余弦消费 B 通道混合法线。
该法线复用主光色阶的同一次镜像距离图采样。
方向光余弦、镜面视角及半角点积消费几何法线。
完整逐灯色阶继续使用当前公共材质响应。

脸部特征开关与诊断禁用仍控制其生命周期。
固定纹理绑定与纹理索引路径使用相同算法。
网格、蒙皮与动画资产沿用通用资源所有权。

## 已验证范围

加载测试覆盖独立 RGBA、线性色带和版本 1。
非法纹理、非正交基底和共享基底冲突均被拒绝。
87 项 GPU 数值探针包含 41 项脸部探针。
探针覆盖左右光、背光、几何混合与 UV 镜像。

世界法线探针覆盖旋转、归一化顺序及反向回退。

Player 夹具使用自包含的公开合成资产。
27 帧覆盖双图响应与 B 通道法线消费。
头部旋转、独立遮罩和头部动画均有回归。
正常场景画面验证局部灯下的头部与遮罩响应。

无光场景的表面最大通道值为零。
固定绑定与默认路径的画面平均差为零。
运行校验错误为零，卸载后资源计数为零。

公开命令如下：

```powershell
ctest --test-dir build/ninja-msvc-debug -R 'AzureEngine.DualFaceSdfGpu|AzureRender.SurfaceResponseGpu|AzureAssets.TextureMaterialImport' --output-on-failure
```

当前生产路径消费距离阈值、法线与线性色带。
其余遮罩和轮廓组合按原生着色模型逐项验收。
逐灯色带属于引擎的公共材质响应。
原生附加灯的组合语义仍需独立核验。

影色表已有独立输入与查表验证。
显式漫反射组合见[颜色组合](npr-diffuse.md)。
脸部环境方向法线与原生附加帧继续独立核验。
皮肤镜面按其原生着色来源继续接入。
原生参数和画面证据见[脸部证据](../acceptance/nr/character-face-sdf.md)。
法线分项证据见[B 通道法线验证](../acceptance/nr/face-sdf-normal.md)。
