# 静态变形输出复用

## 输入与归属

场景渲染器为每个帧槽持有变形输出及内容记录。
宿主在该帧槽围栏退休后准备新的帧输入。
命令状态由本次录制独立持有。
内容记录对应当前输出缓冲区的生命周期。
加载后的顶点源和绑定姿态在该渲染器生命周期内保持只读。

可复用输入要求无蒙皮、动画片段及形变范围。
当前实例还需缺少动画呈现输入。
旧式形变权重必须为正零。
世界模型矩阵及材质效果继续由后续图形程序消费。

首次计算使用现行计算程序，生成完整的归一化顶点字节。
内容身份由网格、顶点起点及顶点数共同确定。
对应来源保持静态时，后续请求可直接消费这些字节。
动态输入和来源变化要求重新生成。

## 生命周期

`StaticSkinningOutputCache` 只持有内容元数据。
`begin` 创建当前准备版本，并保留符合身份的有效内容。
`prepareRange` 返回当前范围是否需要生产。
`commit` 按准备版本及单调提交序号发布待提交内容。

录制回调保留帧槽和准备版本的值票据。
工作线程通过受锁队列记录实际录制的生产票据。
提交事件须对应这些录制结果的真实队列提交。
同一帧槽出现多个准备版本时，按保守失效处理。

取消丢弃待提交记录，并保留已经有效的内容。
输出缓冲区的分配、销毁及重建会清空内容记录。
资源与计算程序的生命周期由场景渲染器持有。
加载与卸载按既有围栏及关闭顺序执行。

## 观察字段

| 捕获清单字段 | 含义 |
| --- | --- |
| `computeSkinningPreparedDispatches` | 本帧准备的计算调度数 |
| `computeSkinningPreparedVertices` | 本帧准备计算的顶点请求数 |
| `staticSkinningReusedInstances` | 本帧复用有效内容的实例数 |
| `staticSkinningReusedVertices` | 本帧复用有效内容的顶点请求数 |

这些字段说明准备阶段的工作量与内容选择。
整帧时间、环境及正式性能预算由对应计时记录持有。
