# 不可变字节载荷

`ImmutableBytePool` 将完整字节规范化为共享只读载荷。
池的调用由所属加载任务串行执行。
池使用弱引用，载荷由调用者的共享引用持有。
载荷生命周期独立于池。

## 身份与存储

`intern(bytes)` 保留输入，返回完整内容对应的载荷。
分桶读取全部机器字及末尾字节。
碰撞继续比较完整表示或还原内容。
相同字节在池中共享同一存活对象。

纹理缓存先核对上传参数与不可变载荷身份。
共享载荷命中时直接复用图像和采样器。
上传或原始字节比较按需还原载荷。
[预备纹理缓存命中成本](../acceptance/nr/prepared-texture-cache-hit-cost.md)记录实际工作量。

64 KiB 至 256 MiB 的输入尝试一级 Zstandard 压缩。
压缩载荷包含内容校验，至少节省八分之一才采用。
其余输入使用完整原始字节。
成功压缩使用按结果大小分配的缓冲。

载荷通过共享只读引用使用，类型的拷贝赋值已禁用。
`read()` 返回独立字节向量，支持并发调用。
各次还原独立持有工作状态及输出。
长度或编解码错误通过异常报告。

池的 `statistics()` 统计当前存活的载荷。
`decodedBytes` 为完整内容字节。
`storedBytes` 为载荷字节缓冲的容量。
该值与对象元数据及整个进程工作集分别计量。

## 纹理缓存输入

`SampledTextureCache::acquirePrepared(payload, upload)` 接收有效载荷。
缓存按完整身份及有效上传参数共享资源。
向量输入与载荷输入支持双向共享。
调用者可独立保留或释放自身引用。

上传使用还原后的完整字节及既有 mip、格式规则。
缓存持有身份阶段的载荷引用。
`seal()` 解除身份引用，GPU 绑定保持有效。
独立载荷所有者继续保留其数据。

结束写入后，申请在还原及 GPU 操作前报告错误。
空引用、错误请求及上传失败保留调用者所有权。
清空释放 GPU 对象并恢复可写状态。
默认场景的载荷预备与消费按所属加载流程装配。
