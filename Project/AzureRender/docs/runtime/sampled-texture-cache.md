# 材质纹理共享

缓存身份包含缩放过滤、层级过滤及层级偏移。
相同像素使用不同采样设置时拥有独立绑定。
默认偏移为零，设备在创建采样器时限制其范围。

`SampledTextureCache` 管理不可变的 RGBA8 材质纹理。
缓存集中拥有图像、视图与采样器。
材质通过 `SampledTextureBinding` 借用描述符值。
主资源与附加资源可在同一缓存中共享。

## 接口与生命周期

缓存构造时借用 `IGpuAllocator` 与 `IRhi`。
两者的生命周期需覆盖缓存。
宿主在加载线程顺序调用 `acquire(pixels, upload)`。
缓存绑定限于创建它的设备与会话。

常量引用入口保留调用者输入。
右值入口在成功时接管输入分配。
唯一内容直接移交缓存，重复内容释放源分配。
校验或上传失败时，源像素保持完整。

全部 GPU 使用完成后，宿主释放描述符并调用 `clear()`。
清理使全部借用值失效，并重置统计。
析构同样释放全部唯一资源。
重新加载可创建新的缓存或复用已清理实例。

角色渲染器的全部材质槽使用此缓存。
上传成功后，渲染器释放对应 CPU 像素。
几何、动画与材质参数继续保留。
共享的预解码资产由渲染器复制后使用。

环境图、反射图与动态复制附件各自持有资源。
交换链重建可以复用材质绑定。
关卡资源变化按渲染器现有生命周期处理。

## 内容等同性

缓存使用处理后的像素判断身份。
glTF 的颜色、粗糙度与法线因子已参与像素处理。
相同来源图像可以产生不同的上传内容。
资产路径与材质名称用于定位来源。

完整身份包含以下参数：

| 参数 | 作用 |
| --- | --- |
| 像素字节、宽度与高度 | 确认完整内容和布局 |
| Vulkan 格式 | 区分线性与 sRGB 图像 |
| 请求层级数 | 区分自动过滤与创作层级 |
| 过滤语义 | 保持颜色、法线与打包法线规则 |
| 透明度阈值 | 保持覆盖率过滤结果 |
| 过滤器与三轴寻址 | 保持纹理采样行为 |
| 有效最大层级 | 保持采样范围 |
| 层级过滤与各向异性 | 保持缩小和倾斜采样行为 |

内容哈希用于查找候选桶。
命中后比较完整参数与像素字节。
哈希冲突可以在同一桶内保存多个资源。
相等判定通过后才返回已有绑定。

## 层级与采样

支持 `R8G8B8A8_UNORM` 与 `R8G8B8A8_SRGB`。
请求层级数为零时生成完整 CPU 层级。
过滤使用 `buildTextureMipChain` 的既有语义。
正层级数可携带完整创作层级。

创作层级按原字节上传。
仅提供基础层时可由 RHI 生成指定层级。
单层策略上传基础层。
采样器最大层级按实际末级限制。

尺寸、字节数和采样数值在分配前校验。
设备需支持请求格式及过滤方式。
上传失败会释放部分创建的对象。
失败请求可以使用相同输入重试。

## 诊断统计

角色截图清单和 GPU 计时报告提供 `materialTextureCache`。
请求与驻留数值记录成功操作。
哈希字节和阶段耗时记录实际执行的工作。

GPU 字节数按纹理尺寸与层级计算。
实际显存同时参考分配器的驻留和峰值。

| 字段 | 含义 |
| --- | --- |
| `requests` | 成功的材质槽请求数 |
| `hits` | 复用已有绑定的请求数 |
| `uniqueTextures` | 集中拥有的唯一资源数 |
| `requestedBytes` | 全部成功请求的逻辑图像字节 |
| `residentBytes` | 唯一图像的逻辑驻留字节 |
| `retainedPixelBytes` | 用于精确等同性比较的 CPU 像素字节 |
| `hashedPixelBytes` | 已参与完整哈希的输入字节 |
| `copiedPixelBytes` | 常量入口为唯一身份复制的字节 |
| `transferredPixelBytes` | 右值入口移交唯一身份的字节 |
| `discardedPixelBytes` | 命中后释放的重复输入字节 |
| `hashMs` | 完整输入哈希的 CPU 时间 |
| `matchMs` | 候选匹配及命中输入释放时间 |
| `mipMs` | 层级生成或基础层选择时间 |
| `uploadMs` | 暂存、图像传输及描述符对象创建时间 |

精确比较为每个唯一输入保留完整像素。
大场景需同时观察主存和显存预算。
逻辑图像统计包含完整层级。
分配器还计入对齐、附件和其他资源。

截图清单的 `sceneLoad` 提供资源加载耗时。
其中包含 CPU 准备、几何、材质和共享纹理。
缓冲区、蒙皮、描述符与管线分别计时。
耗时表示宿主墙钟时间，GPU 耗时由专用分析记录。

`decodedMaterialPixelBytes` 记录九个材质槽的输入总量。
`remainingMaterialPixelBytes` 记录渲染器剩余输入。
关闭的可选脸部槽可以保留未上传像素。
缓存身份像素由 `retainedPixelBytes` 单独记录。
