# 六面反射资源

局部反射探针使用线性 HDR 立方体贴图。
`EnvironmentCubeTexture` 持有图像、视图和采样器。
渲染后端及已退役的帧栅栏须覆盖其生命周期。
该能力可用于室内探针与独立材质预览。

## 资源格式

`AZENV002` 保存原始六面和已制作的层级。
头部依次为八字节标识及三个小端无符号整数。
整数表示单面宽度、单面高度和层级数。
每个像素保存四个线性半浮点通道。

数据先按层级排列，再按六面排列。
面顺序为正 X、负 X、正 Y、负 Y、正 Z、负 Z。
面内像素按行从左至右、从上至下排列。
方向及纹理基底遵循 DDS 与 Vulkan 立方体约定。

每个面均须为非空正方形。
面宽上限为 16384，层级数须符合实际尺寸。
数据长度须与全部层级及六面精确匹配。
非有限半浮点值、未知版本和投影冲突均拒绝。

资源上传保留所有输入半浮点位。
原生已制作层级直接进入六层图像。
硬件执行面间无缝过滤及层级间插值。
该资源使用固定绑定 23，占一个采样器。

## 经纬图兼容

`AZENV001` 继续保存经纬图及已制作层级。
局部探针装载时将各层独立转为六面。
经度使用循环双线性过滤，纬度在极点钳制。
输出保留层级数量及各层独立的辐射来源。

全局环境和天空通道消费经纬图。
这两个入口对六面资源给出投影错误。
全局环境与局部探针分别声明资源引用。

## 投影原点

探针 JSON 使用版本二。
读取入口兼容版本一与版本二。
`projectionOrigin` 为可选世界坐标三元组。
省略该字段时，投影原点随 `capturePosition` 求值。

捕获位置、影响盒中心和投影原点分别持有。
盒投影从表面沿反射方向求出离开盒子的点。
采样方向为离开点减去投影原点。
CPU 求值与 GPU 上传消费相同字段。

显式原点要求三个有限数值。
空值、布尔值、尺寸错误和浮点溢出均拒绝。
版本一携带版本二字段时给出版本错误。
解析失败保持目标探针原值。

## 转换与验证

转换入口为 `tools/native_render/cubemap_environment.py`。
使用 `--projection cube` 保存六面原生层级。
默认经纬图输出使用版本一格式。
转换收据记录每个源面、摘要及输出摘要。

生产加载检查覆盖格式、保存重开和资源释放。
GPU 夹具覆盖六方向及独立投影原点。
粗糙度夹具检查原始层级和层级间插值。
原生粗糙度映射及环境响应另有还原验收。

面内梯度与对象旋转检查六面纹理基底。
每配置分别执行固定和索引描述符，共 56 次捕获。
正式误差采用 sRGB8 量化区间的线性距离。
区间距离预算为 0.004，中心解码误差同时保留。

验收范围与结果见[六面反射验收](../acceptance/nr/reflection-cube.md)。
公共夹具、原生候选和实景等价分别登记状态。
