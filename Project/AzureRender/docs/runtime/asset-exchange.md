# 资产交换与后台导出

格式注册声明写入器、规划器和设置校验器。
扩展通过 `AssetFormatRegistry::add` 接入。
任务持有注册表副本及来源快照。
编辑器与独立工具使用相同的传输契约。

## 输出范围

| 领域 | 格式 | 保真与损失 |
| --- | --- | --- |
| 模型 | glTF、GLB | 几何、材质、骨架及受支持动画 |
| 模型 | OBJ | 静态几何、材质及独立 PNG 贴图 |
| 模型 | STL、PLY | 静态几何。其他字段由损失报告声明 |
| 图像 | PNG、TGA、WebP | 八位 RGBA。PNG 支持十六位样本 |
| 图像 | BMP、JPEG | 整数颜色。JPEG 使用固定质量设置 |
| 图像 | HDR | 非负线性 RGB，采用共享指数精度 |
| 图像 | EXR、TIFF | 线性浮点范围及透明通道 |
| 图像 | DDS、KTX2 | 原始 mip、颜色空间及压缩损失计划 |
| 音频 | WAV | 交错 Float32 样本 |
| 音频 | FLAC | 二十四位整数 PCM，声明量化及裁剪 |
| 音频 | Ogg Vorbis | 有损编码，记录质量及采样转换 |
| 音频 | Opus、MP3 | 有损编码，记录比特率、延迟及有效帧 |

项目脚本、物理及任务配置保存在项目格式中。
模型输入与贴图共用有界读取服务。
容器拥有贴图，OBJ 输出拥有材质及 PNG 依赖。
场景子树描述节点标识、父子关系和局部变换。

## 规划与发布

`planAssetExport` 校验来源、设置和版本。
规划返回入口、依赖、来源指纹和转换损失。
规划阶段保持输出目录尚未创建。
生成通过 `AssetExportJob` 在后台准备。

任务保存不可变子树描述，并核对来源指纹。
调用线程在任务就绪后执行 `finish`。
目标已占用时，需要显式允许覆盖。
覆盖采用目录备份，失败或取消时恢复原目标。

取消与析构清理任务拥有的暂存目录。
生成记录输入、输出、参数及生成器版本。
模型输出预算为 512 MiB。
图像及音频输出预算分别为 64 MiB 和 128 MiB。

## 独立工具

安装中的 `bin/AzureAssetExchange.exe` 执行交换。
请求文件使用 UTF-8 JSON。
相对路径以请求文件所在目录为基准。
结果以 JSON 输出，失败返回退出码一。

```json
{
  "source": "assets/模型.glb",
  "format": "gltf",
  "destination": "exchange/模型",
  "settingsVersion": 1,
  "settings": {}
}
```

```powershell
AzureAssetExchange.exe plan request.json
AzureAssetExchange.exe export request.json --deadline-ms 300000
AzureAssetExchange.exe export request.json --replace
```

默认期限为五分钟，最长允许一小时。
Ctrl+C 请求取消当前生成任务。
设置由目标格式校验，未知字段产生错误。
图像质量取一至一百，默认值为一百。

音频设置包含 `sampleRate` 和 `channels`。
零表示采用来源值。
采样率范围为 8000 至 192000，声道为一至八。
Vorbis 质量范围为零至一，默认值为 0.6。

`scene` 数组可提供模型节点描述。
每个节点具有 `id`、`parent`、`source` 和 `transform`。
变换采用列主序的十六个有限数值。
空来源表示组节点，节点总数至多 4096。

重复标识、缺失父节点及循环关系产生诊断。
静态格式烘焙父子变换，容器保留节点标识。
## 编辑器操作

保存项目文档后，在资产浏览器选择来源。
通过创建菜单或右键菜单打开导出窗口。
场景层级的操作菜单可导出选中子树。
子树根保留世界位置，子节点保留局部变换。

选择目标格式，并填写其注册设置。
输出目录使用绝对路径，可通过路径选择器填写。
中文及表情字符采用完整 Unicode 路径。
最近目录由编辑器路径服务维护。

点击预览，检查来源、依赖和转换损失。
确认后启动任务，并查看进度和发布路径。
目标目录占用时，显式允许覆盖后重新规划。
任务允许取消，失败诊断显示在同一窗口。

公共操作为 `asset.formats`、`asset.export-plan`。
`asset.export` 消费规划标识并返回任务标识。
规划绑定文档、资源数据库和来源指纹。
发生修改后，需要保存并重新规划。

导入、运行预览和构建期间保持交换保护。
生成期间修改文档会拒绝发布并清理暂存。
图像及音频设置由对应格式校验器解释。
实体操作及反馈理解性在 P8 集中复核。

二维容器设置见[纹理容器交换](texture-containers.md)。

压缩音频设置见[压缩音频交换](compressed-audio.md)。
