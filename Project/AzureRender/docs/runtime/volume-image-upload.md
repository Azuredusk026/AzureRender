# 三维纹理上传

GPU 分配结果保留宽、高、深度、层数和层级数。
二维纹理的深度为一，三维纹理的数组层数为一。
体积资源通过现有 `IGpuAllocator::createImage` 创建。

创建信息使用 `VK_IMAGE_TYPE_3D` 和实际三维尺寸。
视图调用 `IRhi::createImageView`，类型为 `VK_IMAGE_VIEW_TYPE_3D`。
格式与线性过滤能力通过所属设备接口核对。
资源所有者负责视图、图像和暂存缓冲的生命周期。

`IRhi::copyBufferToImage` 在加载阶段提交并等待完成。
载荷按层级、数组层、Z 切片、行和列顺序紧密排列。
每级宽、高和深度分别减半，最小值为一。
每级偏移计入该级深度与全部数组层。

上传前将目标转入传输目标布局。
上传完成后转入着色读取布局，再发布描述符。
调用者提供合法尺寸、层级数及足量的无压缩载荷。
每像素字节数按实际格式传入。

二维图像、立方体与体积纹理共享该上传路径。
体积辐照和其他三维查找资源按所属格式加载。
空设备保存体积深度，上传记录包含完整载荷。
空设备的基础内存估算同时计入深度。

GPU 验收入口为 `AzureRender.VolumeImageUploadGpu`。
测试逐字节核对非方形体积的三层上传。
六面立方体的三层上传验证共享路径。
