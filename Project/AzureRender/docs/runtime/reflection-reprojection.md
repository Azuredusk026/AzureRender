# 反射历史重投影

`ReflectionReprojectionGpu` 为反射时间过滤生成运动和接收权重。
输入借用表面快照、公共运动及前帧选样结果。
图像拥有者等待全部消费者退役后复用槽位或销毁资源。

## 输入与输出

表面输入采用 RGBA32F，R 为正向视图深度。
零深度及达到 100000 的背景清除值属于空表面。
公共运动沿[时序抗锯齿](temporal-antialiasing.md)的编码解释。
输入尺寸与构造的源尺寸保持一致。
全部借用视图在录制前进入采样布局。

输出运动采用 RGBA32F。
XY 保存当前减前帧的 UV 位移。
Z 保存当前选样表面的正向视图深度。
W 的一与零分别表示可用表面与空表面。
该 W 表示当前表面有效性，独立于历史接收结果。
非有限运动输出零位移，非有限或空表面输出零深度。

接收权重采用独立 R32F 图像。
权重范围为零至一，供[时间过滤](reflection-temporal.md)消费。
`output(slot)` 返回这两张图像、视图及生产尺寸。
`record` 完成后，两张图像均处于采样布局。

## 选样与历史

分辨率除数接受一或二，默认一。
半尺寸按各轴整除二，最小尺寸为一。
源像素索引沿反射射线的整数选择规则。
每轴采用 `((2*p+1)*sourceSize)/(2*outputSize)`。
表面深度与公共运动读取同一源像素。

前帧输入借用所属历史槽位的输出运动。
历史尺寸与当前生产尺寸保持一致。
成功提交身份、切镜和尺寸变化由调用者检查。
`historyValid` 默认关闭。
无效历史可省略前帧视图，录制使用当前运动占位。
有效历史须提供与当前输出分离的前帧视图。

公共运动中的前帧设备深度按投影参数还原。
参数顺序为 `P[10]`、`P[14]`、`P[11]`、`P[15]`。
前帧输出的 Z 提供实际选样深度。
深度差须满足绝对容差加相对容差乘期望深度。
绝对容差默认为 0.001，合法范围为零至一百。
相对容差默认为 0.02，合法范围为零至一。
投影参数须有限，深度映射须可逆。

完整跟踪表面的接收权重为一。
部分响应按公共编码缩减权重。
无历史、缺失匹配、完整响应及屏外像素的权重为零。
无效投影、空历史表面及深度不匹配同样拒绝历史。

## 资源与失败

每个槽位拥有两张图像和 48 字节私有参数。
图像预算为每个生产像素每槽位 20 字节。
槽位数量为一至八，图像总上限为 256 MiB。
源尺寸每轴限制为一至 8192。
格式要求支持单样点存储、采样和传输读取。

预算、参数和别名检查发生在命令录制前。
当前输入须与资源自身的输出图像分离。
同槽位历史在写入描述符前被拒绝。
每次记录完整替换输出，转换时丢弃目标的旧内容。
取消录制不会推进内部图像布局状态。
历史身份和队列成功提交仍由宿主管理。

该组件提供公共计算步骤。
主场景按[反射计划](../plans/2026-10-28-reflection-filter-integration.md)接入。
