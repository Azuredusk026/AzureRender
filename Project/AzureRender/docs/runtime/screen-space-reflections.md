# 屏幕空间反射

该能力使用本帧不透明颜色及线性视深度。
公共设置由 `RenderSettings.screenSpaceReflection` 持有。
室内场景和独立材质夹具共同使用该接口。
配置默认关闭，并由场景内容显式启用。

## 配置与保存

渲染设置版本为 16，反射子版本为 1。
关卡字段为 `screenSpaceReflection`。
文本场景保存并读取完整子对象。
旧版本场景迁移为关闭状态。

| 字段 | 默认值 | 合法范围 |
| --- | ---: | --- |
| enabled | false | 布尔值 |
| maxDistance | 20 | 0.1 至 200 米 |
| thickness | 0.15 | 0.001 至 2 米 |
| normalBias | 0.03 | 0.001 至 0.5 米 |
| maxSteps | 96 | 8 至 256 的整数 |
| maxRoughness | 0.7 | 0.05 至 1 |
| edgeFade | 0.08 | 0.001 至 0.5 |
| strength | 1 | 0 至 1 |

未知字段、版本及非法数值触发解析失败。
解码采用临时副本，失败时保持目标设置。
距离及偏移使用世界单位，边缘宽度采用屏幕比例。
原生游戏的运行参数另有来源核验范围。

## 采样与合成

射线从表面法线偏移后在世界空间推进。
实际相机矩阵将采样点投影至屏幕。
深度交叉采用六步细化及厚度校验。
粗糙度、射程和屏幕边缘共同决定可信度。

环境与局部探针组成回退辐射。
命中颜色按可信度混入该辐射。
材质的镜面积分响应随后统一相乘。
未命中、越界及高粗糙度区域使用探针回退。

颜色源包含本帧角色蒙皮及节点动画。
快照采用与主表面一致的单面及镜像剔除。
反射隔离诊断仍采样完整受光颜色。
镜面总开关同时约束反射消费与快照需求。

## 资源与范围

快照沿用绑定 18 的深度及绑定 19 的颜色。
每个在途帧分别持有图像和帧缓冲。
尺寸变化与卸载通过渲染器生命周期处理。
快照着色分支排除反射采样，避免读取自身输出。

当前路径采用单次屏幕反射。
颜色源覆盖不透明及透明裁剪表面。
透明混合源、多次反射及离屏物体依赖其他机制。
粗糙度当前控制回退权重，时域滤波另有扩展范围。

CPU 检查入口为 `AzureRender.ScreenSpaceReflection`。
GPU 入口为 `tools/test_screen_space_reflections_gpu.py`。
`--suite extended` 验证运动、遮挡和回退。
原生逐像素对照需要对应帧的绑定与图像证据。
