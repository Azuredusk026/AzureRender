# 屏幕空间反射

该能力使用本帧不透明颜色及线性视深度。
公共设置由 `RenderSettings.screenSpaceReflection` 持有。
室内场景和独立材质夹具共同使用该接口。
配置默认关闭，并由场景内容显式启用。

## 配置与保存

渲染设置版本为 20，反射子版本为 2。
关卡字段为 `screenSpaceReflection`。
文本场景保存并读取完整子对象。
渲染设置版本一至十五按关闭反射读取。

反射子版本一按线性算法读取。
子版本二使用 `algorithm` 字段选择追踪方式。
默认算法为 `linear`，投影算法名为 `projected`。

| 字段 | 默认值 | 合法范围 |
| --- | ---: | --- |
| enabled | false | 布尔值 |
| algorithm | linear | linear 或 projected |
| maxDistance | 20 | 0.1 至 200 米 |
| thickness | 0.15 | 0.001 至 2 米 |
| normalBias | 0.03 | 0.001 至 0.5 米 |
| maxSteps | 96 | 8 至 256 的整数 |
| maxRoughness | 0.7 | 0.05 至 1 |
| edgeFade | 0.08 | 0.001 至 0.5 |
| strength | 1 | 0 至 1 |

未知字段、版本及非法数值触发解析失败。
解码采用临时副本，失败时保持目标设置。
距离及偏移使用世界单位，边缘宽度采用屏幕比例。
原生游戏的运行参数另有来源核验范围。

## 追踪算法

步数、边缘宽度、粗糙度和强度作用于两种算法。
距离、线性厚度及法线偏移作用于线性追踪。
算法在视图资源装配时选择。
影响资源的算法切换通过视图重建应用。

投影算法消费当前表面及不透明颜色快照。
它组合反向深度、投影射线、信号金字塔及足迹过滤。
场景输出通过绑定 37 参与现有探针和材质合成。
接口及预算见[公共组合](projected-screen-reflection.md)。

当前主场景投影生产使用当前帧模式。
投影历史按成功提交、抖动差及运动有效性另行接入。
相机须采用有限远平面的透视投影。
条件不满足时，清单记录实际生产和回退原因。

## 线性追踪

射线从表面法线偏移后在世界空间推进。
实际相机矩阵将采样点投影至屏幕。
深度交叉采用六步细化及厚度校验。
粗糙度、射程和屏幕边缘共同决定可信度。

投影和正视深度沿世界射线预计算常量与方向项。
每个距离从原点求值，避免逐步累积误差。
细化过程保存高端命中样本并直接复用。
浮点纹素边界与实际开销通过设备专项核验。

## 探针与材质合成

环境与局部探针组成回退辐射。
命中颜色按可信度混入该辐射。
材质的镜面积分响应随后统一相乘。
未命中、越界及高粗糙度区域使用探针回退。

颜色源包含本帧角色蒙皮及节点动画。
快照采用与主表面一致的单面及镜像剔除。
反射隔离诊断仍采样完整受光颜色。
镜面总开关同时约束反射消费与快照需求。

## 资源与范围

快照沿用绑定 18 的深度及绑定 19 的颜色。
每个在途帧分别持有图像和帧缓冲。
尺寸变化与卸载通过渲染器生命周期处理。
快照着色分支排除反射采样，避免读取自身输出。

颜色需求与硬件深度测试启用时，快照先预填不透明深度。
预填复用当前附件，全部颜色写掩码为零。
正向最小偏置为完整颜色绘制保留严格小于比较。
完整颜色按原有顺序写入未偏置深度。

节点透明度、双面及镜像使用公共覆盖输入。
裁剪材质、混合层与外扩深度壳按所属阶段处理。
预填管线随渲染器重建、退役和卸载。
验证范围见[不透明预填验收](../acceptance/nr/opaque-snapshot-depth-prefill.md)。

两种算法均生成单次屏幕反射。
颜色源覆盖不透明及透明裁剪表面。
透明混合源、多次反射及离屏物体依赖其他机制。
粗糙度控制反射足迹及回退权重。

命中距离和实际投影决定椭圆足迹。
足迹最长半径为八像素，使用中心及两环采样。
命中过滤最多读取 16 次颜色和 20 次深度。

局部平面预测使用线性或倒深度梯度。
各采样通过厚度校验，缺失权重回退到探针。
半径不超过半像素时使用锐利采样路径。
单条射线的轮廓覆盖及时间滤波另有扩展范围。

CPU 检查入口为 `AzureRender.ScreenSpaceReflection`。
GPU 入口为 `tools/test_screen_space_reflections_gpu.py`。
`--suite extended` 验证运动、遮挡和回退。

原生逐像素对照需要对应帧的绑定与图像证据。
粗糙过滤的实际结果见[专项验收](../acceptance/nr/reflection-roughness.md)。

投影主场景的检查入口为 `tools/test_projected_scene_reflections.py`。
清单提供请求算法、实际生产、回退原因和图像预算。
