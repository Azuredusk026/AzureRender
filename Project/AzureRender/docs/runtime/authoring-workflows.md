# 文档与内容制作工作流

> 文档类型：操作与开发参考
> 日期：2026-10-10
> 适用范围：编辑器制作工作区

## 场景文档

在内容浏览器双击关卡，打开对应场景标签。
每个文档持有独立上下文、选择、历史与版本。
切换标签保留未保存修改与视图方向。
运行与模拟期间由预览会话持有活动文档。

Ctrl+S 保存活动文档。
关闭已修改标签时，选择保存、丢弃或取消。
工作区最多保留三十二个场景文档。
至少保留一个场景标签。

项目文档位于已声明的内容挂载内。
同一路径重复打开时，激活已有文档。
切换项目前，保存或关闭其他已修改文档。
退出编辑器的保存决定覆盖全部已修改文档。

| 操作 | 参数与结果 |
| --- | --- |
| `document.open` | `path` 为场景路径、虚拟引用或资产标识 |
| `document.activate` | `id` 为打开文档的稳定标识 |
| `document.describe` | 查询路径、版本、历史、活动与脏状态 |
| `document.save` | 可选 `id`。默认保存活动文档 |
| `document.close` | `id` 与可选 `decision`。关闭指定标签 |

文档激活在下一次会话轮询时完成。
保存只写目标文档对应的文件。
缺失路径和未知文档产生明确诊断。
未保存关闭需要显式用户决定。

## 动画检视

选择配置了动画组件的对象，打开动画检视面板。
通过语义状态、时间与混合时长检查姿势。
播放、暂停和清除预览使用公共动画操作。
切换对象时，各对象保持自己的时间轴。

每个文档持有独立的对象时间轴集合。
活动文档的播放时间轴随编辑帧推进。
文档修改或资产版本变化使相关预览失效。
动画检视保持场景字段、脏状态和历史。

| 操作 | 参数与结果 |
| --- | --- |
| `animation.seek` | `node`、`time`，以及可选状态和混合参数 |
| `animation.play` | `node`。创建或继续对应时间轴 |
| `animation.pause` | `node`。冻结对应时间轴 |
| `animation.clear` | 可选 `node`。释放指定或全部时间轴 |
| `animation.describe` | 查询各对象的状态、时间、播放及混合 |
| `animation.configure` | `node`、`speed` 与 `loop`。设置独立播放策略 |

时间定位范围为零至六百秒。
状态与骨架引用遵守动画组件的领域校验。
非法定位请求保持原有时间轴。
设置初始语义状态属于场景编辑事务。

播放倍率范围为 0.05 至四倍。
单次播放在模型片段的实际结束时间停止。
骨架辅助消费同一采样姿势与场景世界变换。
每个文档最多保留三十二个动画时间轴。

模型和图版本变化使相关时间轴失效。
重新定位时校验片段与当前绑定模型。
片段越界产生结构化操作诊断。
模型的骨架元数据由时间轴持有并随清除释放。

## 脚本制作

脚本模板由后端描述与生成函数注册。
Lua 模板生成 `.lua`，托管模板生成 `.cs`。
托管文件名作为 `ProjectScripts` 中的类名。
托管文件名需为合法的 ASCII 类标识符。

模板目标位于可写项目挂载。
已有文件得到明确拒绝。
新源文件通过临时写入和验证进入资产数据库。
失败恢复本次创建的源文件与元数据。

| 操作 | 参数与结果 |
| --- | --- |
| `script.backends` | 查询后端、扩展名与模板版本 |
| `script.template` | `backend` 与 `path`。返回资产标识 |
| `script.reveal` | `asset`。在内容浏览器揭示对应脚本 |
| `script.reload` | `backend`。检查与活动运行后端一致 |

Lua 模板可通过脚本组件直接装配。
托管源码按[脚本服务](script-services.md)构建。
项目配置选择运行后端与编译产物。
重载能力由对应运行后端声明。

制作面板、快捷键与自动工具共用编辑注册表。
场景状态由文档持有，源文件由内容服务持有。
操作结果与错误可通过观察服务查询。

## 问题定位

问题面板展示来源、错误码、消息与发生次数。
来源记录文档、对象、资产、路径和可用行号。
点击问题后，激活所属文档并选择对应对象。
资产问题同时请求内容浏览器揭示。

对象标识来自实际操作或运行回调。
定位时检查文档、对象和资产仍然存在。
未知或已释放的目标产生明确拒绝。
场景中同名对象由文档标识区分。

操作、脚本与着色器编译错误进入问题集合。
导入操作保留输入路径，脚本错误保留实际回调对象。
问题集合容量为五百一十二条。
重复记录合并次数，超限淘汰最早记录并累计丢弃数。

| 操作 | 参数与结果 |
| --- | --- |
| `diagnostic.query` | 按来源、严重性、错误码、文档或文本筛选 |
| `diagnostic.reveal` | `id` 为问题标识。排队执行目标定位 |

## 领域内容辅助

独立辅助面板通过注册描述列出制作领域。
场景、资产参数、材质、纹理和物理各有校验器。
领域提供目标、快照、候选差异与应用范围。
模型服务关闭时，面板提供手动制作说明。

材质候选复用字段编辑与文件历史。
纹理候选复用内容事务与版本化导入设置。
物理候选使用对象稳定标识与批量编辑事务。
预览保持源文件、文档与历史状态。

应用前检查源指纹与文档版本。
过期候选需重新生成或完成领域重验。
应用与恢复通过普通制作操作完成。
完整生命周期见[内容提案](content-proposals.md)。

## Prefab 制作

选择根对象，在 Prefab 面板输入源文件路径。
创建范围包含选中对象及其后代。
资源与光源跟随所属对象进入源文档。
组件对象引用由注册元数据统一映射。

源文件位于可写项目挂载，扩展名为 `.azureprefab`。
已有源文件与范围外的对象依赖得到明确拒绝。
创建源文件保持当前场景内容。
源文件创建通过内容事务恢复。

从内容浏览器放置实例后，可查看字段覆盖列表。
勾选字段并还原时，只恢复选择范围。
实例覆盖使用场景的普通撤销与重做。
保存保持继承字段与最小覆盖文档。

应用字段至源资产时，先校验源版本与所有打开文档。
每个文档先生成独立候选，再共同发布。
源字段传播到继承该字段的实例。
其他实例的独立覆盖保留在其所属文档。

源应用支持专用撤销与重做，容量为八次。
恢复要求源文件与受影响文档保持对应版本。
文档修改、关闭或源文件变化使恢复明确拒绝。
发布失败时，恢复源文件与全部场景历史。

源文件外部变化时，保存场景后重新加载以确认来源。
放置实例也检查已有实例的来源版本。
嵌套源通过已有展开契约加载。
字段应用操作的目标为直接源文档。

| 操作 | 参数与结果 |
| --- | --- |
| `prefab.create` | `nodes` 与 `path`。返回源资产和内容事务 |
| `prefab.overrides` | `instance`。返回来源指纹、冲突与字段范围 |
| `prefab.revert` | `instance` 与 `fields`。按场景事务还原 |
| `prefab.apply` | `instance`、`fields` 与 `baseFingerprint` |
| `prefab.undo-apply` | 恢复最近一次源应用及受影响文档 |
| `prefab.redo-apply` | 重做最近一次源应用及受影响文档 |

每个字段由局部对象标识与 JSON Pointer 指定。
选择范围、字段类型和对象引用均经过领域校验。
引擎模块持有制作与事务机制。
项目源资产定义具体机构、角色或场景组合。
