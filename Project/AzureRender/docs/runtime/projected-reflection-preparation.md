# 投影反射表面准备

`ProjectedReflectionPreparationGpu` 将公共快照转为射线输入。
类型声明位于 `src/render/ProjectedReflectionPreparation.hpp`。
所属模块为 RenderCore，计算和分配通过公共 RHI 执行。
相机系数由[相机适配](projected-reflection-ray.md)提供。

## 输入与输出

构造输入为源尺寸、槽位数、程序和分辨率除数。
尺寸范围为 1 至 8192，槽位为一至八。
除数取一或二，半尺寸按整数向下取整且至少为一。
计算程序使用有界 SPIR-V，最大一 MiB。

输入表面为可采样的 RGBA32F 图像。
R 为正向线性深度，GB 为 Z 极八面体世界法线。
A 为粗糙度，合法范围为 `[0,1]`。
像素选样使用 `(2*p+1)*sourceExtent/(2*traceExtent)`。

| 输出 | 格式 | 内容 |
| --- | --- | --- |
| `depth` | R32F | 反向设备深度 |
| `normalRoughness` | RGBA32F | RG 为 Y 极法线，B 为粗糙度，A 为零 |
| `mask` | R8_UNORM | 有效表面使用完整射线步数 |
| `footprint` | RG16_UNORM | 供射线写入运动衰减和过滤层级 |
| `tiles` | 四字节整数列表 | 覆盖输出的唯一 8×8 瓦片 |

前四项图像由准备对象按槽位持有。
瓦片列表在构造时生成，所有槽位共享。
瓦片的高十六位存 X，低十六位存 Y。
边界瓦片由射线逐线程核对输出范围。

`ProjectedReflectionEligibilityTarget` 借用 R8_UNORM 可信度。
调用者提供图像、视图和输出尺寸。
准备步骤覆盖全部可信度像素。
其格式、大小及图像与视图的对应关系由调用者保证。

## 转换与参数

深度系数满足 `linearDepth=1/(A*deviceDepth+B)`。
准备使用 `(1/linearDepth-B)/A` 计算反向深度。
系数要求 A 为正，B 非负，且数值及两者和有限。
设备深度须位于 `[0,1]`。

法线先按公共快照规则解码为世界方向。
随后编码为投影射线的 Y 极八面体坐标。
两类极向及正负半球均有独立 GPU 检查。
粗糙度直接写入法线输出的 B 通道。

| 参数 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `maxRoughness` | `[0.05,1]` | 0.7 | 可信度的粗糙度终点 |
| `strength` | `[0,1]` | 1 | 可信度乘数 |

初始可信度公式如下。

```text
(1-smoothstep(0.75*maxRoughness,maxRoughness,roughness))*strength
```

有效表面要求各分量有限，GB 和 A 位于 `[0,1]`。
线性深度须大于零且小于 100000。
投影范围外及非法表面写入零可信度和零掩码。
这些像素使用零设备深度及默认向上法线。

## 记录与同步

1. 调用者退休当前槽位的全部先前消费者。
2. 发布表面的采样可见性，可信度目标进入可写 GENERAL。
3. 调用 `record` 转换表面并初始化可信度。
4. 通过 `output(slot)` 取得采样输入和瓦片。

5. 公共射线写入颜色、足迹及可信度。
6. 调用者发布足迹和信号，继续金字塔及空间过滤。

`record` 完成后，深度、法线及掩码可供着色器采样。
可信度保持 GENERAL，其写入对后续计算读写可见。
足迹保持 GENERAL，供公共射线完整覆盖。
足迹内容在首次射线写入前由调用顺序约束。

槽位图像每次记录采用完整覆盖及丢弃转换。
取消录制后可直接重新记录。
跨帧历史读取和槽位退休由装配者维护。
同队列的先前读写通过显式屏障排序。

参数、别名及范围检查在描述符和命令变化前完成。
借用目标及源视图须与各槽位图像保持独立。
销毁前须等待全部 GPU 消费完成。
对象自身持有描述符、参数、程序、采样器及瓦片。

## 预算与验证

图像预算为每像素每槽位 25 字节，上限 256 MiB。
瓦片列表单独计入，最多 65,535 项及 262,140 字节。
构造时检查各格式的采样、存储及单样点支持。
设备支持范围随实际执行来源记录。

CPU 契约和独立 GPU 转换见[表面准备验证](../acceptance/nr/projected-surface-preparation.md)。
主场景快照、过滤足迹和历史身份按装配任务验收。
