# 资源访问与可见性契约

> 文档类型：运行时设计
> 状态：实现，阶段验收通过
> 日期：2026-10-07

## 设备与访问方式

`ResourceAccessProfile` 使用实际设备容量。
配置声明采样槽、固定槽与片段缓冲数量。
索引功能同时满足支持、启用和五项容量。
容量未知时，固定布局使用 Vulkan 保证范围。

固定布局也超出容量时，返回不可用诊断。
资源数量以 64 位值校验，求和采用减法边界。
设备地址要求设备功能与分配器标记均启用。
更新后绑定要求启用功能并满足查询容量。
该请求描述一个布局及其所属描述符池容量。
多池装配由调用方核对设备级总量。

能力报告版本为 3。
报告分别列出支持、启用和资源容量。
现行宿主启用普通描述符索引。
资源更新遵循帧退休后的重建契约。

## 资源索引与所有权

`ResourceIndexTable<T>` 由创建线程拥有。
句柄包含表身份、槽位与 64 位世代。
快照持有资源提供者的共享所有者引用。
原生对象的销毁行为由资源提供者定义。

提交和完成序号遵循单调规则。
在途替换使用新槽，旧句柄立即失效。
完成信号到达后，退休槽释放所有者引用。
CPU 快照仍可独立保留该引用。

容量满时，替换失败保留有效资源。
已经完成的槽允许原位替换并增加世代。
世代达到最大值后，该槽永久停止复用。
调用方在销毁表前完成全部 GPU 退休。

角色材质通过索引表组装实际描述符数组。
表拥有不可变绑定值，渲染器拥有原生纹理。
共享槽位在前，每个材质随后占用八个槽。
固定路径每材质使用十一项采样绑定。

## 可见性与稳定标识

`--visibility-prototype` 选择可见性原型。
具备计算与间接实例能力时，该选项生效。
计算存储缓冲容量至少为五项。
容量未知或不足时，宿主采用现行可见性路径。
原型按视锥输出间接命令和表面标识。
标识包含实例、图元、全局材质与可见状态。

正式绘制消费原型产生的间接命令。
主相机可见性与阴影投影集合独立。
透明顺序、蒙皮边界和镜像变换沿用公共契约。
CPU 可见性筛选继续参与正式提交。

主绘制按 CPU 可见跨度提交间接命令。
GPU 输出保留所有实例的稳定命令槽。
每级阴影视锥拥有独立的提交跨度。
帧快照保存这些跨度，供录制线程消费。

计算蒙皮按主视图与阴影的需求调度。
连续且参数兼容的实例使用二维派发。
每个实例读取独立骨骼区，写入独立顶点区。
形态权重、网格或连续地址不同会拆分批次。

`SkinningBatch` 使用 28 字节推送常量。
单批实例数至多为 65535。
原生 GPU 回读验证批次与逐实例输出一致。
专项同时验证边界、空闲输出区和资源释放。

公共 `VisibilityPrototype` 保存不可变帧映射。
调用者提供场景、相机与帧身份。
拾取校验完整结果并拒绝过期或错序标识。
GPU 表面读取由独立探针验证。

本原型范围为视锥与稳定表面数据。
历史遮挡数据不参与剔除判断。
层级深度遮挡和可见性缓冲着色属于后续候选。
原型采用范围由测量与阶段验收确定。

## 实验预算与验证

规模对照使用 100、500 和 10000 实例。
正式宿主图像为 960×540，质量采用默认值。
公开模型包含蒙皮、透明与多材质。
每种路径预热 30 帧，随后测量 120 帧。

100 和 500 实例要求 GPU P95 至多 16.6 ms。
其 CPU 工作 P95 至多 8 ms。
万实例实验要求 GPU P95 至多 100 ms。
其 CPU 工作 P95 至多 250 ms。

独立计算探针预热两次，再采样三十次。
GPU 与 CPU 录制均值各至多 2 ms。
输出命令逐字节一致，表面数据符合独立参考。
同步错误和退出后资源数量均为零。

上述预算在实验采集前固定。
探索项目的九轮正式预算独立执行。
