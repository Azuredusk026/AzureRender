# 资产格式注册与传输

## 格式能力

资源类型描述编辑用途及放置能力。
格式注册描述内容探测、读写能力及领域。
模型、图像和音频分别使用明确的领域标识。
可读取与可写入能力分别查询。

当前模型注册包含 glTF 2.0 与 GLB 2.0。
两格式使用生产模型加载器验证内容。
公共操作 `asset.formats` 返回格式能力。
界面文件筛选使用同一注册描述。

注册在任务启动前完成，任务共享只读描述。
准备报告由任务拥有。
调用线程负责发布或清理暂存。

每种格式声明稳定标识、扩展名和设置版本。
扩展名按大小写无关规则匹配。
内容探测读取有界前缀，解析器校验完整内容。
多个匹配探测器返回歧义诊断。

## 准备与发布

`AssetTransferRequest` 声明操作、来源和目标。
请求指定设置版本、取消观察及输入大小预算。
来源、任务暂存目录和发布目录各有独立所有权。
已占用的任务目录返回冲突诊断。

后台准备复制并验证容器与外部依赖。
中文、空格与大写扩展名均按 UTF-8 路径处理。
依赖通过规范路径校验，限定在来源目录内。
复制前后核对来源和产物的内容指纹。

报告记录产物、依赖、设置、警告及转换损失。
生成清单记录输入、输出与生成器版本。
主线程发布前再次核对来源和输出指纹。
来源过期、取消或目标冲突时清理本任务暂存。

`AssetImportJob` 使用共享传输服务。
异步失败由任务记录保留输入路径与诊断。
模型重导入使用相同的准备与内容校验。
重导入的标识及引用由既有内容事务维护。

## 保存与交付

虚拟资源路径及文本元数据使用 UTF-8。
资源包按标识记录可移动路径及字节指纹。
中文资源名在保存重开和资源包解析中保持一致。
格式支持状态以实际验证和阶段证据为准。

新增领域适配器通过 `AssetFormatRegistry::add` 登记。
转换设置及生成器版本纳入生成指纹。
模型、图像和音频的转换损失由领域适配器报告。
输出交换验收见[格式实施计划](../plans/2026-10-11-asset-format-expansion.md)。
