# 资产格式注册与传输

## 格式能力

资源类型描述编辑用途及放置能力。
格式注册描述内容探测、读写能力及领域。
模型、图像和音频分别使用明确的领域标识。
可读取与可写入能力分别查询。

模型输入包含 glTF、GLB、OBJ、STL、PLY、DAE 与 FBX。
glTF 与 GLB 使用生产模型加载器验证内容。
交换格式通过独立模型适配器生成 GLB。
公共操作 `asset.formats` 返回格式能力。
界面文件筛选使用同一注册描述。

注册在任务启动前完成，任务共享只读描述。
准备报告由任务拥有。
调用线程负责发布或清理暂存。

每种格式声明稳定标识、扩展名和设置版本。
扩展名按大小写无关规则匹配。
内容探测读取有界前缀，解析器校验完整内容。
多个匹配探测器返回歧义诊断。

## 准备与发布

`AssetTransferRequest` 声明操作、来源和目标。
请求指定设置版本、取消观察及输入大小预算。
来源、任务暂存目录和发布目录各有独立所有权。
已占用的任务目录返回冲突诊断。

后台准备复制并验证容器与外部依赖。
中文、空格与大写扩展名均按 UTF-8 路径处理。
依赖通过规范路径校验，限定在来源目录内。
复制前后核对来源和产物的内容指纹。

模型适配器使用固定版本 Assimp 6.0.4。
交换格式的来源及产物分别记录内容指纹。
外部材质和贴图受来源目录与总字节预算约束。
贴图嵌入 GLB，项目发布按产物收集依赖。

模型设置 `unitScale` 指定单位倍率。
`upAxis` 接受 `y` 或 `z`，默认采用 `y`。
默认倍率为一，输出使用右手坐标及米制约定。
来源坐标约定由制作工具及导入设置共同确定。

材质槽、骨架与动画通过规范运行容器保存。
镜像层级和非均匀缩放沿用运行加载器的变换规则。
约束、程序着色和动画曲线解释写入损失报告。
来源相机及灯光通过场景制作入口配置。

报告记录产物、依赖、设置、警告及转换损失。
生成清单记录输入、输出与生成器版本。
主线程发布前再次核对来源和输出指纹。
来源过期、取消或目标冲突时清理本任务暂存。

`AssetImportJob` 使用共享传输服务。
异步失败由任务记录保留输入路径与诊断。
模型重导入使用相同的准备与内容校验。
重导入的标识及引用由既有内容事务维护。

## 保存与交付

虚拟资源路径及文本元数据使用 UTF-8。
资源包按标识记录可移动路径及字节指纹。
中文资源名在保存重开和资源包解析中保持一致。
格式支持状态以实际验证和阶段证据为准。

新增领域适配器通过 `AssetFormatRegistry::add` 登记。
`transformsSource` 声明输入与输出的转换关系。
数据库依据格式注册及生成器版本验证转换来源。
转换设置及生成器版本纳入生成指纹。
模型、图像和音频的转换损失由领域适配器报告。
输出交换验收见[格式实施计划](../plans/2026-10-11-asset-format-expansion.md)。

## 图像输入

图像格式通过同一只读注册与传输服务接入。
PNG、JPEG、BMP、TGA、PPM、HDR、EXR、TIFF、WebP 可读取。
材质、预览与环境共用精度及颜色描述。
转换范围见[图像导入](image-format-import.md)。

图片复制容器并校验实际像素。
图像导入摘要记录精度、方向及材质损失。
纹理重导入校验设置、解码与 mip。
图像标识沿用内容事务的保存与发布契约。
