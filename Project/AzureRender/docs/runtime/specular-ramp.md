# 二维高光色带

版本二材质画像可声明 `specularRamp`。
通用、织物及金属类别组合 `nprDiffuse` 使用该输入。
主光、局部灯及环境反射各自持有照明来源。
公共响应核为 `shaders/specular_ramp.glsl`。

## 材质输入

```json
{
  "specularRamp": {
    "schemaVersion": 1,
    "texture": 2,
    "flipV": false,
    "iridescence": 0,
    "lightingInputs": "host-main-light"
  }
}
```

五项字段须显式提供，未知字段触发加载诊断。
`texture` 引用有效的二维图像，横纵尺寸均至少为二。
`flipV` 控制生成坐标的纵向方向。
`iridescence` 为零至一的有限混合权重。

`lightingInputs` 使用 `host-main-light`。
相机方向及选定主灯提供半角构造输入。
场景可见量控制主灯与视向的混合。
纹理使用线性颜色、线性钳制及显式零级采样。

该输入与既有 MatCap 的纹理槽互斥。
面部、头发、眼睛、叠层及透射表面持有各自契约。
完整材质文档按 UUID 保存纹理及依赖。
参数覆盖保留来源中的完整画像。

## 响应计算

感知粗糙度来自金属粗糙度图的绿通道。
微表面参数为粗糙度平方，下限为 `1/128`。
法线与半角的点积按明确顺序累计。
该顺序用于保持尖锐分布项的数值一致性。

二维横轴混合分布项与视角平方项。
纵轴为感知粗糙度乘以非金属量。
零权重保留分布坐标，一权重使用视角坐标。
零长度的中间方向采用确定的有效方向回退。

反射率消费现有基色、金属度及 `specularInput`。
主光将反射率、色带及几何项相乘。
原生参数图的绿通道可按既有 ORM Alpha 规则接入。
通道转换见[镜面输入](specular-input.md)。

完整照明权重按以下步骤计算：

1. 视角色带 Alpha 乘以材质 AO 遮罩。
2. 根据场景可见量混合该值与亮区遮罩。
3. 主光照明乘以该权重的一半加一半。
4. `nprLighting.specularFloor` 设置独立的照明底值。

宿主主灯通过独立直接项参与组合。
普通局部灯消费现有微表面响应。
虹彩权重同时调制环境和局部灯所用的反射率。
无有效主光时，专用主光贡献为零。

## 存储与边界

实现复用现有十二行、192 字节的表面画像。
第四行 Z 保存虹彩权重。
第四行 W 的正负号分别表示原方向和纵向翻转。
W 为零时采用所属表面的标准镜面响应。

场景镜面底值复用 `nprLightingParameters.w`。
材质表、实例表及描述符布局保持现行值。
帧所有权及卸载规则沿用既有材质资源生命周期。
来源与实际绘制见[服饰验收](../acceptance/nr/cloth-specular-ramp.md)。
