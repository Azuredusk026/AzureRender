# 材质像素预备

`MaterialPixelStorage` 管理材质的 CPU 像素持有方式。
范围覆盖十三类像素字段，包括投影头发、描边及透射。
宽高、mip、颜色空间及过滤语义保留在材质元数据中。
预备状态使用共享不可变载荷。

## 准备与还原

`prepareMaterialPixels(material, pool)` 按字段准备载荷。
默认阈值为 64 KiB，小字段保留直接移交的向量表示。
准备成功后释放对应向量分配。
已有载荷通过池的 `adopt` 共享规范化引用。

调用者可通过阈值参数声明自己的准备范围。
每个字段的完整字节保留在向量或载荷中。
异常可能保留混合状态，各字段的内容仍然完整。
共享源及其他材质副本独立持有自身引用。

修改图像前，调用 `restoreMaterialPixel` 还原所需字段。
`restoreMaterialPixels` 还原整个材质。
还原结果为独立向量，载荷所有者保持原内容。
`materialPixelLogicalBytes` 支持查询字段的完整长度。

## 加载流程

角色渲染器应用材质绑定后，准备各资源的像素。
上传作业逐槽消费向量或预备载荷。
成功后解除该材质槽的载荷引用。
采样缓存继续持有身份阶段所需的引用。

描边资源构建前还原其遮罩字段。
材质参数解释在副本中还原输入。
后台关卡预解码逐资源准备载荷，再发布共享只读资产。
渲染器复制元数据及引用后完成所属加载。

`RenderContext.preparedMeshes` 可包含预备像素状态。
其他渲染器通过本接口读取、还原及消费对应字段。
预解码源由其共享所有者持有。
取消、重载和失败清理分别释放所属引用。

## 统计

`materialPixelPayloads` 统计所属渲染器池登记的存活载荷。
`decodedBytes` 为完整内容字节，`storedBytes` 为缓冲容量。
独立预解码所有者可继续保留其载荷。
该组值与整个进程工作集分别计量。

采样缓存分别记录逻辑身份及后备引用容量。
结束写入解除缓存身份引用，GPU 绑定保持有效。
正式内存预算使用实际进程及设备的对应测量。
