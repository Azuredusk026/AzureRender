# 颜色分级查找表

## 数据契约

查找表属于 RenderCore 的后处理资源。
关卡通过 `gradeLut.asset` 引用 `.azlut` 文件。
引用支持资源 UUID 与项目虚拟路径。
运行时解析路径，文档保存保留原始引用。
独立场景支持相对文件路径。
路径以场景文件所在目录为基准。

文件使用 `AZLUT001` 标识与版本化 JSON 头。
数据为小端浮点 RGBA，布局为二维横向切片。
尺寸为 `N*N` 乘 `N`，`N` 范围为 2 至 64。
切片内横轴为红通道，纵轴为绿通道。
蓝通道选择切片，并在相邻切片间插值。

输入域明确选择 `linear` 或 `logc3-full-log`。
输出域固定为 `linear`，各通道范围为 0 至 1。
来源包含生成器、版本、输入指纹与证据状态。
证据值零为创作，一为候选，二为运行时采集。
加载校验版本、尺寸、字节数和有限数值。

`linear` 输入直接钳制到 0 至 1。
`logc3-full-log` 使用以下完整对数分支。
对数参数小于等于零时取下边界。
其余结果钳制到 0 至 1。

```text
argument = linear * 5.555555820465088 + 0.047995999455451965
coordinate = log2(max(argument, 0))
           * 0.3010300099849701 * 0.244160994887352
           + 0.3860360085964203
```

采样限制在首尾切片与纹素中心之间。
末切片使用同一片作为相邻片，防止边界串色。
CPU 输入与像素数据要求有限数值。
显式资源使用单级浮点纹理与线性过滤。
设备须支持 `VK_FORMAT_R32G32B32A32_SFLOAT`。
该格式须同时支持采样与线性过滤。
默认占位使用二阶恒等表。
占位格式为 `VK_FORMAT_R8G8B8A8_UNORM`。
占位像素仅含零和一，可精确表示。

## 生产消费

资源启用时，场景线性色先乘独立曝光乘数。
随后执行输入域变换与三线性查找。
查找表包含完整调色与色调映射。
独立曝光档位在查找表采样前应用。

关卡字段使用以下结构。
曝光乘数的合法范围为大于零且至多 65536。

```json
{
  "gradeLut": {
    "schemaVersion": 1,
    "asset": "assets:/grading/showcase.azlut",
    "exposureMultiplier": 1.0
  }
}
```

未配置资源时使用默认 ACES 调色路径。
诊断视图和辉光隔离继续使用独立输出。

主视口的着色器分项隔离在设置层解析后应用中性传输。
该策略令零贡献保持黑色，并排除调色与辉光。
捕获清单记录实际生效的调色设置。

命令录制使用不可变帧快照提供渲染设置。
上下文的构造保留该快照的设置归属。

宿主按附件格式明确提供输出编码。
sRGB 附件接收线性值，普通附件接收编码值。
地面网格合成后统一编码，避免重复转换。

## 所有权与生命周期

公共 GPU 资源通过 RHI 上传浮点像素。
资源拥有图像、视图与线性钳制采样器。
宿主在加载边界创建，在设备空闲后替换。
主视口在编辑和运行状态确定后同步资源。
同帧撤销、重做和运行切换使用最终绑定。
描述符销毁后释放查找表资源。
关卡依赖和重载指纹包含查找表。
资源类型标识为 `color-grading-lut`。
主视口与辅助视口共用资源类和采样公式。
编辑操作先完成解析校验，再提交可撤销修改。
主视口每帧查询启用资源的大小与修改时间。
查询用于识别文件替换，不逐帧读取像素。
资源变化时存在设备空闲等待与重新上传成本。
采集清单记录资源引用、曝光乘数与文件指纹。
采集状态哈希包含同一组查找表信息。

## 验证与用途

生产视口与离屏计算夹具共享 GLSL 公式。
线性夹具验证通道顺序和切片插值。
对数夹具验证高动态范围输入和域变换。
非法资源、保存重开和项目移动另行覆盖。
数值夹具独立验证纹素读取与三线性公式。
生产过滤按设备亚纹素精度计算误差上界。
理想误差、量化参考残差与上界分别记录。
Player 夹具验证主视口的输出编码与诊断旁路。
默认回退、固定描述符和资源释放同时覆盖。
编辑器夹具逐帧验证撤销、重做与运行切换。
这些夹具验证公共契约，原生画面对照另行验收。

原生候选生成器置于 `tools/endfield_native/`。
候选使用已恢复的完整矩阵与调色链。
CPU 参数换算与运行时常量作为待验证项记录。
候选资源不代表当前游戏已激活的调色状态。

实际纹素导入使用同一工具的采集入口。
输入为原始 RGBA16F 条带及成功的重放收据。
工具校验尺寸、子资源、字节数和 SHA-256。
输出证据值为二，半精度纹素精确展开为浮点。

```powershell
python tools/endfield_native/color_grading.py `
  --captured-strip <原始条带.bin> `
  --capture-receipt <纹理导出收据.json> `
  --output <采集资源.azlut>
```

实际绑定与输入域须通过来源着色器核对。
独立曝光、辉光、暗角及锐化分别接入。
锚帧证据见[捕获顶点与实际调色表](../acceptance/nr/captured-vertex-and-grading.md)。

候选生成命令如下。
来源参数指向已恢复的原生着色器证据。
生成结果包含输入指纹和待验证项清单。

```powershell
python tools/endfield_native/color_grading.py `
  --source-shader <原生着色器证据路径> `
  --output <候选资源路径.azlut> --dimension 32
```
