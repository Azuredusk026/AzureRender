# 材质辐亮度

`azureRenderMaterial` 版本二使用 `radianceScale` 声明线性倍率。
字段为零至十六的有限数值，缺省为一。
完整材质文档与内嵌画像使用同一个加载器。
普通表面、风格化表面和无照明表面均可使用。

```json
{
  "azureRenderMaterial": {
    "schemaVersion": 2,
    "class": "generic",
    "radianceScale": 0.25,
    "features": []
  }
}
```

## 输出与单位

材质先完成自身颜色、照明、高光及自发光响应。
倍率随后作用于完整线性输出及辐射诊断分项。
专用眼睛的直接颜色和头发 KK 能量采用相同倍率。
后续雾、泛光、视图曝光和调色消费该线性输出。

倍率保持覆盖 Alpha、法线、粗糙度及可见量的单位。
基色及数据诊断继续显示各自的原始表面量。
材质声明的具名轮廓颜色使用所属材质的倍率。
视图预设轮廓由其自身的显示配置持有。

乘法合成表面提供无量纲颜色系数。
这类材质要求倍率为一，其他值触发加载诊断。
普通透明合成将倍率应用于出射颜色，覆盖权重独立计算。
非法版本、类型及数值范围均返回包含字段名的错误。

## 曝光换算

源输出与目标视图使用同一线性颜色基底时，换算关系为：

```text
radianceScale = 2 ^ (源曝光 EV - 目标曝光 EV)
```

源曝光负二档、目标曝光零档时，倍率为四分之一。
项目数据负责记录曝光来源及适用的材质集合。
光源强度和材质响应具有各自的计算顺序。
换算后的最终外观继续包含目标视图的雾及调色影响。

## 画像与诊断

公共画像版本为十九，每项二十二行，共 352 字节。
`rows[19].w` 保存倍率，其他分量按所属表面契约解释。
无照明纹理层的坐标扰动继续使用其专用分量。
GPU 摄像机常量及材质纹理槽采用既有布局。

捕获清单的 `materialRadianceScales` 列出非单位倍率。
记录包含 GPU 材质索引、名称及实际标量。
主资产的材质清单也记录该字段。
画面状态指纹版本四包含主资产材质的倍率及显示策略。

独立验证入口为 `tools/test_material_radiance_gpu.py`。
该入口以视图曝光核对线性输出换算。
它还核对眼睛公开像素参考及普通表面控制。
原生联合外观的状态由[开发总计划](../plans/azure-engine-plan.md)持有。
