# 完整覆盖深度预填充

场景渲染器在快照及主颜色通道执行深度预填充。
不透明且节点透明度恰为一的单样本实例使用纯深度管线。
全部颜色写掩码为零，深度偏置为常量一、斜率零。
颜色绘制使用严格的 `LESS` 深度比较。

每个通道持有三种剔除及正面方向变体。
顶点程序、描述符、实例区间及变形输入沿用所属通道。
管线选择在每段透明度区间执行。
淡出实例使用含覆盖测试的片元程序。

遮罩、混合、叠加材质按原提交规则参与所属通道。
四样本配置使用含片元程序的预填充管线。
阴影专用标志由阴影策略解释。
重建及卸载释放各通道持有的管线。

本机制通过现有设备抽象的可选片元阶段实现。
颜色附件的格式及数量由所属通道描述。
同步及资源关闭遵守场景渲染器的生命周期。
范围及验证见[实施计划](../plans/2026-11-06-covered-depth-prefill.md)。
