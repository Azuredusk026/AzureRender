# 动画循环闭合

内容工具入口为 `tools/bake_animation_loop.py`。
工具向嵌入式 GLB 追加一个循环片段。
原始片段、节点、蒙皮、网格和纹理完整保留。
输出资产通过既有动画状态图选择新增片段。

## 时间与姿态

片段起点为各轨道首时刻的最小值。
终点为各轨道末时刻的最大值。
循环时长等于终点减起点。
闭合片段保留这两个时刻及首帧姿态。

线性轨道在末尾窗口向首姿态平滑收敛。
窗口权重使用五次平滑函数。
旋转使用同半球四元数并归一化。
窗口起点插入边界采样，保持前段插值范围。

阶跃轨道保留内部离散状态。
末端采样恢复首姿态。
较短轨道延伸至整个片段的公共终点。
常量轨道保留其姿态。

## 使用与边界

```powershell
python tools/bake_animation_loop.py --input character.glb `
  --output character-loop.glb --clip 0 `
  --name idle-loop-closed --blend-seconds 0.15
```

输入为一个嵌入式缓冲的 GLB。
轨道支持平移、旋转和缩放。
支持 `LINEAR` 及 `STEP` 插值。
其他轨道与三次曲线进入显式拒绝路径。

输出路径须为新文件。
插入时刻按单精度量化后去重。
时刻须有限、非负且严格递增。
来源摘要、工具摘要与时间范围写入收据。

## 验证

十项工具检查覆盖时间原点及单精度边界。
同时验证旋转、短轨道、常量和离散状态。
原生角色结果见[待机循环验收](../acceptance/nr/joint-idle-loop.md)。
运行时的循环及实例时钟沿用既有动画契约。
