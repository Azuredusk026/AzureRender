# 项目入口与工作区

> 文档类型：使用与接口参考
> 更新日期：2026-10-10

## 创建和打开项目

从 `File → Projects...` 打开项目面板。
选择项目文档，点击 `Open project`。
项目文件扩展名为 `.azureproject`。
最近项目记录显示项目名与文档位置。

新建项目时先选择模板并填写名称。
再选择父目录，点击 `Create project`。
名称对应父目录下的新子目录。
目标目录已存在时，创建操作报告失败。

场景模板用于独立场景检视。
游戏模板包含可运行内容与运行配置。
创建任务在后台生成和校验临时项目。
宿主线程提交产物并请求激活。

当前文档有修改时，会显示保存对话框。
保存写入当前文档，然后切换项目。
放弃允许切换，取消保留当前文档。
目标项目校验失败时，当前文档保持可用。

缺失的最近项目保留定位入口。
点击 `Locate document` 后重新选择项目文件。
最近记录最多保存十六项。
记录归属于编辑器用户配置。

## 面板职责与布局

对象属性和组件显示在 `Details` 面板。
场景表现参数显示在 `Environment` 面板。
项目文档和模板入口显示在 `Projects` 面板。
设置面板按四类职责组织。

四类设置为编辑器偏好、项目配置、渲染诊断。
内容辅助配置具有独立类别。
项目类别显示启动关卡与配置文件位置。
运行系统与输入绑定由项目文档定义。

在 `View` 菜单选择 `authoring` 或 `debugging`。
制作布局显示视口、大纲、属性和内容。
调试布局同时显示控制台、捕获与玩法诊断。
扩展面板保留注册时声明的显示状态。

关闭面板后，可从 `View` 菜单再次打开。
布局和预设随工作区配置保存。
损坏配置使用可操作的默认布局。
布局状态与项目内容分别保存。

## 公共操作

以下操作经 `EditorSession::edit` 执行。
调用结果遵守[编辑事务契约](edit-operations.md)。

| 操作 | 参数 | 结果 |
| --- | --- | --- |
| `project.templates` | 无 | 模板标识与名称 |
| `project.recent` | 无 | 最近项目及可用状态 |
| `project.open` | `path` | 已校验项目标识及待激活状态 |
| `project.create` | `templateId`、`destination`，可选 `name` | 可取消任务标识 |
| `tasks.describe` | 无 | 任务状态、进度与结果 |
| `tasks.cancel` | `id` | 请求取消目标任务 |
| `workspace.preset` | `id` | 制作或调试布局请求 |

模板标识为 `scene` 和 `game`。
`destination` 是新项目的最终目录。
名称默认采用目标目录的名称。
既有 `path`、`name` 调用创建游戏且保留活动项目。

预设标识为 `authoring` 和 `debugging`。
项目激活和布局变更在帧边界消费。
切换项目后，选择与撤销历史归新文档。
渲染预览依照既有提交与释放规则失效。
