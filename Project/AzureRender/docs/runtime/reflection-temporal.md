# 反射时间过滤

`ReflectionTemporalGpu` 更新颜色与可信度信号。
调用者借用当前输入、历史输入、运动及接收比例视图。
输出借用[信号层级](reflection-signal-pyramid.md)的基础视图。
计算资源持有参数、描述符和管线。
图像、历史交换及成功提交状态由宿主持有。

## 输入与输出

当前颜色、当前可信度及两份历史采用同一尺寸。
历史接收比例采用该尺寸，范围为零至一。
运动提供当前减前帧的归一化 UV 位移。
原点为左上，历史坐标为当前 UV 减去位移。
运动视图可以保持完整场景分辨率。

输入颜色须为有限非负值，并使用相同的工作空间。
可信度输入范围为零至一。
接收比例由调用者完成遮挡、有效性及响应检查后提供。
位移的附加通道由所属运动消费者另行解释。

输出格式支持 `R11G11B10_FLOAT` 与 `R8_UNORM`。
浮点输出采用 `RGBA32F` 与 `R32F`。
输出视图、格式及尺寸须与创建参数一致。
任一输入视图与输出视图相同时，记录操作被拒绝。

## 参数与计算

| 参数 | 默认值 | 范围或语义 |
| --- | --- | --- |
| varianceScale | 1.25 | 有限值，零至十 |
| historyWeight | 0.97 | 有限值，零至一 |
| minimumColor | 0.001 | 有限值，零至一 |
| historyValid | false | 已提交历史是否可用 |
| rejectOutside | true | 拒绝历史坐标落在屏外的像素 |

颜色在亮度与色度空间（YCoCg）中建立约束。
三乘三邻域提供方差范围及交叉邻域范围。
历史颜色沿约束盒裁剪，可信度采用标量范围。
有效接收比例与 `historyWeight` 共同决定合成量。
输出颜色保留工作空间，并应用最小颜色值。

无效历史、屏外坐标及零接收比例输出当前信号。
非有限运动或历史输入使对应像素使用当前信号。
当前颜色和可信度遵守上述有限值契约。

## 布局与生命周期

私有参数使用两行向量，共 32 字节。
该步骤独立持有九个描述符绑定。
六项采样输入、两项存储输出及参数分别绑定。
宽高限制为一至 8192，在途槽位为一至八。
该计算资源借用图像，图像预算由所有者核算。

全部输入须处于 `SHADER_READ_ONLY_OPTIMAL`。
输出须处于 `GENERAL`，并准备计算写入可见性。
首次使用前，输入视图及图像布局均须有效。
调用者在过滤结束后发布输出的采样可见性。

同次提交可以记录使用不同参数的两个槽位。
每个槽位在一次提交中记录一次生产。
复用槽位及销毁资源前，宿主等待全部消费者完成。
非法参数、尺寸和别名在写入描述符前返回诊断。
