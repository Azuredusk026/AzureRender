# 空间抗锯齿

`render.antiAliasing` 控制场景输出采样。
主视口、辅助视口和 Player 使用同一实现。
默认值为 1，合法范围为 0 至 4。
模式三的采样、历史与回退见[时序抗锯齿](temporal-antialiasing.md)。
配置写入关卡后可保存与重开。

| 值 | 行为 | 场景尺寸 |
| --- | --- | --- |
| 0 | 直接输出调色结果 | 输出尺寸 |
| 1 | 方向跨度与亚像素边缘过滤 | 输出尺寸 |
| 2 | 四个子像素的线性覆盖合成 | 输出宽高各乘二 |
| 3 | 原生尺寸时序重建 | 输出尺寸 |
| 4 | 四个几何样点逐样点着色 | 输出尺寸 |

命令行使用 `--anti-aliasing`。
取值为 `off`、`edge`、`supersample`。
时序与多样点分别使用 `temporal`、`multisample`。
模式四的能力与回退见[多样点契约](multisample-shading.md)。
原生场景预设按关卡中的设置生效。
辅助视口描述可设置整数 `antiAliasing`。
`transfer` 接受 `linear` 与 `srgb`。
空值按宿主附件的编码格式选择输出。
其他非空传递函数返回参数错误。

## 输出顺序

场景先生成 HDR 颜色、法线和深度。
调色阶段完成曝光、描边和颜色映射。
结果写入线性 RGBA16F 显示色纹理。
公共输出阶段读取该纹理并执行采样。

模式 1 使用平方根亮度进行边缘判断。
九点邻域确定边缘方向与局部反差。
跨度搜索和亚像素项决定过滤位置。
沿边变化控制对齐直线的亚像素项。

颜色插值在线性显示域执行。
sRGB 附件由硬件完成最终编码。
UNORM 输出由着色器完成最终编码。
诊断视图绕过空间边缘过滤。

## 资源与失败状态

`SpatialAntiAliasing` 持有显示色中间资源。
其生命周期归属于宿主帧或辅助视图。
渲染图声明中间写入与采样依赖。
调用者维护提交完成与在途资源退役。

主视口重建等待相关帧完成。
辅助视口通过提交序号延迟释放。
初始化失败会释放部分创建的资源。
失败后的视图服务可继续接受合法请求。

设备需要支持 RGBA16F 线性采样。
辅助视口输出尺寸范围为 1 至 4096。
扩大后的场景尺寸还需满足设备图像上限。
超限请求在分配附件前返回错误。

## 验证入口

`tools/test_spatial_antialiasing_gpu.py` 验证公共夹具。
它独立渲染横纵四倍尺寸的参考图。
边缘误差、运动差分和积分亮度单独统计。
八个相机位置覆盖一个像素内的连续移动。

CTest 入口为 `AzureRender.SpatialAntiAliasingGpu`。
辅助视口入口为 `AzureRender.SpatialAntiAliasingAuxiliaryGpu`。
`AzureRender.RenderView` 覆盖尺寸与资源退役。
既有采样、调色和编辑器门禁共同回归。

采集清单记录 `antiAliasing` 与实际场景尺寸。
`antiAliasingPipeline` 标识输出实现版本。
空间输出标识为 `linear-display-spatial-v1`。
辅助视口诊断还提供 `sceneExtent`。
`frameExtent` 表示渲染器接收的物理场景尺寸。
它与 `sceneExtent` 保持一致。
模式 2 的输出 `extent` 保持请求尺寸。

空间过滤使用当前帧的可见颜色。
完全缺失的亚像素覆盖需要额外采样恢复。
时域稳定性与原生画面一致性单独验收。
阶段证据见[实施计划](../plans/2026-10-22-spatial-antialiasing.md)。
