# 二维内容与投影标签

二维场景使用版本一的 `.azure2d` 文档。
场景包含画布尺寸和有序图元集合。
图元支持矩形、精灵和中文文本。
位置与尺寸采用像素，图层采用稳定排序。

示例见 `assets_public/samples/2d/scene.azure2d`。
通过已有 `game.ui` 资源引用选择二维文档。
运行入口将文档转换为 RmlUi 内容。
字体使用 `AzureGame` 和中文回退字体。

每项包含唯一 `id`、`kind` 和 `rect`。
可选字段为 `layer`、`color` 和 `fontSize`。
文本使用 `text`，精灵使用相对路径 `image`。
图片相对二维文档所在目录解析。

资产数据库校验文档并发现图片依赖。
图片内容变化使场景指纹失效。
移动发布包保持相对资源布局。
无效版本、字段、规模和缺失图片会拒绝。

RenderCore 提供 `Renderer2D` 图元接口。
调用者提交矩形、精灵和有宽度的线段。
`flush` 按图层稳定排序并合并相邻纹理批次。
每帧最多提交一万个图元。

纹理由后端持有，调用者遵守纹理释放契约。
瞬态几何在三个在途帧后退休。
顶点颜色与纹理采用预乘透明度。
后端沿用 `GameUiRenderer` 的提交和销毁规则。

三维标签使用 `projectLabel` 取得屏幕位置。
相机后方、深度越界和屏幕外标签返回空结果。
调用者将位置与文本交给同一二维内容机制。
验证见[G14 实施记录](../acceptance/g14/2026-10-12.md)。
