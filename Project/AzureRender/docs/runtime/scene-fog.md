# 场景雾

`ViewFogBinding::analytic` 配置公共解析介质。
字段通过场景、关卡和渲染快照接入。
GPU 资源由 `ViewFogGpu` 持有。
独立解析、捕获体积和实时高度雾场景共用该契约。

## 绑定格式

版本二具有六个必需字段。
它们为 `schemaVersion`、`asset`、`enabled`、
`projection`、`captureView` 和 `analytic`。
`schemaVersion` 为二，解码拒绝未知字段。

`analytic` 具有版本一及 `aerial`、`height` 字段。
两个介质字段接受对象或 `null`。
至少一个介质必须有效。
资源为空时，启用绑定报告 `analytic-only`。

版本一绑定具有体积和捕获视图五个字段。
保存捕获体积绑定使用版本一，解析绑定使用版本二，实时高度雾绑定使用版本三。
文本场景使用版本十四保存完整绑定。
解码失败保持目标对象原值。

## 大气介质

`aerial` 对象使用版本一。
参数、单位和范围见[光谱大气](aerial-fog.md)。
JSON 使用该页同名参数及 `schemaVersion`。
`minimumHeightDelta` 接受有限数值或 `null`。

大气沿当前相机到表面的射线评价。
太阳方向使用场景世界坐标。
来源转换负责坐标基准及单位换算。
投影偏移和正交投影使用公共相机规则。

## 高度介质

`height` 对象使用下列五个字段。
所有数值要求有限，长度以场景世界单位表达。

| 字段 | 含义与范围 |
| --- | --- |
| `schemaVersion` | 一 |
| `layers` | 一至两层，按数组顺序组合 |
| `startViewDepth` | 起始视图深度，默认零，非负 |
| `minimumTransmittance` | 最小透射率，默认零，范围零至一 |
| `transmittanceBias` | 四分量透射偏置，默认全零 |

每层具有 `density`、`heightFalloff`、
`referenceHeight` 和 `scatteringColor` 四个字段。
密度、衰减及三分量颜色均非负。
参考高度允许任意有限数值。

高度层沿起始视图平面至表面的线段积分。
透射偏置由两组距离仿射函数组成。
每组按零至一裁剪，结果加入最小透射约束。
最终透射率裁剪至零至一，散射按剩余遮蔽比例缩放。

## 实时高度雾体积

版本三绑定包含版本二的字段及 `generatedHeightVolume`。
`asset` 为空字符串，`captureView` 为 `null`，`analytic.height` 提供高度层。
启用后，捕获报告中的 `viewFogMatch` 为 `generated-height`。

| 字段 | 含义与范围 |
| --- | --- |
| `dimensions` | 图像的宽、高和深度。宽、高为 1 至 64，深度为 2 至 128。 |
| `farViewDepth` | 最远视图深度。大于高度雾起点，且不超过 100000。 |

生成体积使用 RGBA16F，RGB 存储散射，A 存储透射率。
各高度层的散射颜色分量至多为 65504。
设备须支持该格式的存储写入与线性采样。
每帧按当前相机和视口计算体积，使用屏幕归一化坐标和对数视图深度采样。
雾起点对应首个深度体素中心，最远深度对应末个体素中心。
体积范围外的高度层及整段光谱大气按片元解析求值。

## GPU 布局与生命周期

逐帧布局版本为二，共二十一行、336 字节。
各在途帧拥有独立缓冲，描述符使用绑定三十四。
体积纹理使用绑定三十五，深度沿用现有快照。
独立解析绑定使用单位传输纹理。

| 行 | 内容 |
| --- | --- |
| 0–2 | 捕获体积投影 |
| 3 | 视口尺寸、体积匹配标志、解析启用标志 |
| 4–7 | 相机位置、投影类型、正交基及射线尺度 |
| 8 | 投影偏移、高度起始深度及层数 |
| 9–12 | 两层高度参数与散射颜色 |
| 13 | 最小高度透射、大气标志、生成标志和生成最远深度 |
| 14 | 透射偏置 |
| 15–20 | 六行光谱大气参数 |

组合顺序为捕获体积、高度层和光谱大气。
捕获体积失配时，解析介质按当前相机继续计算。
不透明表面和透明材质共用传输评价。
四倍采样通过对应样本深度重建世界射线。

实时生成模式为每个在途帧分配一张独立三维图像。
计算写入完成后将图像发布到片元采样阶段。
直接命令记录及渲染图均按该顺序执行。
关卡资源键包含完整雾绑定，重载键包含完整场景。
销毁与重载沿用雾绑定的提交完成边界。
运行报告提供解析启用值和逐帧布局字节数。
采集清单提供 `viewFogGeneratedHeightEnabled`、`viewFogGeneratedHeightDimensions`
及 `viewFogGeneratedHeightFarViewDepth`。
表面路径及体积格式见[雾效传输](fog-transport.md)。

固定步脚本驱动相机，逐帧运行报告提供位置及目标。
验证覆盖体积停用、原机位恢复和解析介质连续计算。
两条描述符路径逐帧比较，并核对资源释放。
`verify_generated_height_fog_replay.py` 复用封存夹具检查实时生成模式。
