# 加载资源绑定姿态

场景渲染器按加载资源顺序持有绑定姿态。
缓冲区准备阶段调用 `bindAnimationPose` 求解各资源。
结果包含局部姿态、节点矩阵、关节矩阵、形变及透明度。
源资源的默认姿态在该加载生命周期内保持只读。

缺少实例动画输入及资源动画片段时，实例按值复制绑定姿态。
实例继续独立修改当前形变权重及求解包围盒。
显式动画输入、资源动画片段、混合及表情按当前帧求解。
角色与场景资源使用相同选择规则。

卸载清空绑定姿态及本帧计数。
重新加载根据当前资源建立独立内容。
世界变换、图形录制及 GPU 输出缓存按所属生命周期消费结果。
载入失败遵循场景加载及卸载恢复规则。

`bindPoseCacheEntries` 表示当前加载的绑定姿态数。
`bindPoseCachedCopies` 表示本帧静态分支的值复制数。
计数描述求解选择，整帧收益由实际计时判断。
范围见[实施计划](../plans/2026-11-06-loaded-bind-pose.md)。
