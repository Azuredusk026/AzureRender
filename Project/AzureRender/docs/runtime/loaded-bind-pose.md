# 加载资源绑定姿态

场景渲染器按加载资源顺序持有只读绑定姿态。
缓冲区准备阶段调用 `bindAnimationPose` 求解各资源。
结果包含局部姿态、节点矩阵、关节矩阵、形变及透明度。
缓存和本帧实例通过共享所有权持有输入。

缺少实例动画输入及资源动画片段时，实例共享绑定姿态。
该实例的模型矩阵、形变参数及 GPU 区间分别持有。
绑定姿态需要写入形变权重时，先建立独立可写值。
显式动画、混合及表情持有当前帧独立求解的结果。

拾取、运动、包围盒及透明排序读取当前实例姿态。
静态形变权重保持默认值时可以共享只读内容。
恢复默认输入后，实例重新引用所属资源的绑定姿态。
角色与场景资源使用相同选择规则。

卸载释放加载缓存，并清空本帧计数。
实例保存的只读结果随下一次准备或渲染器销毁释放。
拾取及运动读取以已加载场景和当前准备周期为有效范围。
重新加载根据当前资源建立独立内容。
图形录制及 GPU 输出缓存遵循各自的完成契约。
载入失败遵循场景加载及卸载恢复规则。

`bindPoseCacheEntries` 表示当前加载的绑定姿态数。
`bindPoseSharedInstances` 表示本帧共享只读内容的实例数。
`bindPoseCachedCopies` 表示本帧建立可写绑定姿态的次数。
整帧收益由独立计时判断。

范围见[共享姿态计划](../plans/2026-11-06-shared-bind-pose.md)。
