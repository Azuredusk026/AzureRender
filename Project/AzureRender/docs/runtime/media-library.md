# 本地媒体库

`AzureRuntime` 的 `MediaLibrary` 管理项目媒体副本。
构造时传入存档实例、槽名及音频或图像领域。
存档实例由调用方持有，生命周期覆盖媒体库使用期。
音乐列表、图片工具和独立导入程序可共用该接口。

## 导入与查询

`importFile` 接收本机文件及可选取消回调。
调用方可在工作线程执行导入。
格式探测、完整解码及暂存复用资产传输服务。
源文件保持原字节，发布区持有独立副本。

媒体发布后，项目存档条件提交清单。
`entries` 返回条目快照，`file(id)` 定位已提交文件。
查询保持只读，缺失缓存通过 `available` 表达。
文件可用性检查覆盖路径、普通文件及声明大小。

相同格式、大小和指纹的候选还需逐字节比较。
内容相同则复用已有条目。
重导入可恢复缺失缓存，并保留条目标识和标题。
重新打开项目使用已导入副本。

## 版本与事务

清单格式为 `[1, rows]`。
每行保存标识、标题、格式、缓存目录、文件名、指纹及大小。
条目标识和缓存目录使用受控名称。
领域、版本、规模及文件路径在发布前校验。

准备工作在槽锁外执行。
提交阶段持有媒体槽锁，重读并校验当前清单。
普通存档写入通过条件比较参与版本协调。
线程和进程可合并各自已完成的导入。

取消、解码失败、较新版本及过期提交均返回异常。
已有清单按原状态保留。
发布后提交失败时，释放本次文件及其空目录。
失败恢复保持其他文件和已提交媒体的所有权。

## 预算

| 字段 | 默认值 | 有效范围 |
| --- | --- | --- |
| `maxSourceBytes` | 128 MiB | 1 字节至 128 MiB。 |
| `maxCacheBytes` | 512 MiB | 1 字节至 16 GiB。 |
| `maxEntries` | 4,096 | 1 至 4,096。 |
| `maxScanEntries` | 16,384 | 1 至 1,000,000。 |

缓存盘点包含发布区内的文件与退役副本。
暂存区与发布区使用[项目内容目录](project-save-store.md#内容目录)。
目录枚举拒绝重定向内容，并按条目预算终止。
缓存回收由拥有对应清单及引用生命周期的上层安排。
