# 物理制作与独立模拟

> 文档类型：操作与开发参考
> 适用范围：编辑器、项目组件与运行时
> 日期：2026-10-10

## 制作流程

在大纲选择对象，从属性面板添加刚体组件。
物理制作区选择盒、球、胶囊或静态网格。
尺寸、运动类型及触发器在组件字段中配置。
模型比例与碰撞尺寸共同确定实际形状。

| 形状 | 参数与合法缩放 |
| --- | --- |
| `box` | `halfExtent` 乘各轴缩放的绝对值 |
| `sphere` | `radius`。各轴绝对缩放相等 |
| `capsule` | `radius` 和圆柱 `halfHeight`。X/Z 绝对缩放相等 |
| `mesh` | `mesh` 模型引用。静态实体，合法三角形 |

静态网格需先设置模型引用，再选择网格形状。
网格使用模型的实际三角形与对象变换。
镜像缩放同时修正三角形绕序。
动态网格、网格触发器及蒙皮网格配置会被拒绝。

形状参数必须有限且大于零。
各轴绝对缩放至少为 `0.001`。
网格预算为一百万个非退化三角形。
非法配置在进入物理库前产生诊断。

## 铰链制作

新建一个对象作为约束所有者，并添加铰链组件。
通过公共引用控件选择两个刚体端点。
至少一个端点使用动态刚体，端点均为实体。
局部锚点以各端点的对象原点为基准。

| 字段 | 解释 |
| --- | --- |
| `bodyA`、`bodyB` | 两个不同刚体对象的稳定标识 |
| `anchorA`、`anchorB` | 对象局部锚点，包含对象缩放 |
| `axis` | 创建约束时的世界旋转轴 |
| `normal` | 与旋转轴垂直的世界参考方向 |
| `minimumAngle`、`maximumAngle` | 角度限制，包含零且位于正负 180 度内 |

物理制作区的 X/Y/Z 按钮同时配置轴与参考方向。
相关字段通过一次组件事务完成修改。
非法轴或引用修改保持文档与历史。
运行中删除端点先释放约束，再释放刚体。

摆臂项目位于 `assets_public/physics_arm`。
旋转门项目位于 `assets_public/physics_door`。
两者使用相同组件与不同轴向、尺寸和角度限制。
项目可用编辑器打开并直接模拟。
在大纲双击运动部件，或选中后按 F 定位。

## 编辑、运行与模拟

工具栏提供 Play 与 Simulate。
Play 装配项目玩法、脚本与表现服务。
Simulate 装配物理，并保留编辑相机。
右键漂浮与方向控件在模拟期间可用。

暂停冻结物理，Step 推进一次六十分之一秒。
Stop 释放预览世界，并恢复编辑场景。
制作修改在编辑模式下通过公共事务执行。
启动失败保持文档与渲染设置的所有权。

View 菜单提供碰撞和铰链辅助显示策略。
盒、球、胶囊显示对应轮廓。
静态网格辅助显示模型包围盒。
实际网格碰撞使用完整三角形。

辅助线属于编辑叠加层。
模拟状态的辅助位置来自运行场景快照。
原生光标捕获由编辑相机拥有。
游戏输入服务按预览模式选择输入所有者。

## 公共接口与来源

| 入口 | 契约 |
| --- | --- |
| `preview.simulate` | 校验并启动独立模拟 |
| `preview.pause/resume/step/stop` | 共用预览生命周期 |
| `component.fields` | `type` 与 `values`。原子修改相关字段 |
| `PhysicsWorld::setMeshResolver` | 使用内容引用解析碰撞三角形 |
| `PhysicsWorld::validateScene` | 启动前校验形状、端点与运动类型 |
| `PhysicsWorld::hingeAngle` | 查询铰链当前角度 |

刚体组件版本为 3。
版本 1 迁移采用默认盒形状。
版本 2 迁移采用静态或动态模式。
运动学模式通过 `kinematic` 字段配置。
领域校验通过组件注册接入类型描述。
UI、自动工具与脚本共用合法类型和字段边界。
形状工厂独立于步进调度，并由物理世界管理资源。

预览生命周期参考 Hazel 的场景副本机制。
形状工厂参考 Fermion 的 Jolt 模块划分。
来源版本见[借鉴清单](../plans/hazel-fermion-manifest.json)。
采用内容为机制设计，代码使用本引擎的公共契约。

## 运动学承载

动态与运动学模式互斥。
静态网格使用静态模式，盒形平台可选运动学。
脚本修改变换时，物理世界计算目标运动速度。
角色主动运动使用相对支撑面的速度。

水平与垂直运动均参与支撑检测。
旋转支撑速度由物理库按接触点提供。
旋转承载的专项设备验收待执行。
已验证场景见[平台跳跃](platformer-gameplay.md)。
