# 投影反射公共组合

`ProjectedScreenReflectionGpu` 组合公共反射生产及过滤。
类型声明位于 `src/render/ProjectedScreenReflectionGpu.hpp`。
对象归属 RenderCore，通过 RHI 持有及记录资源。
源快照和历史身份由场景或独立工具提供。

## 构造与资源

构造输入为 RHI、源尺寸、槽位、程序和质量规模。
源尺寸范围为 1 至 8192，槽位数为一至八。
最大层数范围为一至十四，默认七。
分辨率除数取一或二，默认一。

输出尺寸按整数向下取整且每轴至少为一。
实际层数同时受输出尺寸和最大层数约束。
图像总预算为 512 MiB。
表面准备另有 256 MiB 及 65,535 瓦片上限。

对象持有表面准备、射线、深度及信号金字塔。
空间过滤提供 RGBA32F 输出，布局为 GENERAL。
一像素 RGBA32F 纹理提供恒定零位移运动。
该纹理在构造时上传，记录期间持续借用。

信号使用 R11G11B10 浮点颜色和 R8 可信度。
足迹使用 RG16_UNORM，深度使用 R32F。
所需采样、存储和样点能力在分配前查询。
`supported` 供调用者选择设备路径。

## 参数与输入

| 参数 | 范围 | 默认值 |
| --- | --- | --- |
| `maxSteps` | `[1,4096]` | 96 |
| `jitterSeed` | `[0,16777215]` | 0 |
| `edgeFade` | `(0,1]` | 0.08 |
| `maxRoughness` | `[0.05,1]` | 0.7 |
| `strength` | `[0,1]` | 1 |

这些字段属于 `ProjectedScreenReflectionParameters`。
边缘距离、粗糙度及强度分别按所属公共规则计算。
足迹的归一化层级由实际金字塔层数确定。
相机采用有限远平面的透视投影。

`ProjectedScreenReflectionInputs` 借用表面、颜色及运动视图。
源尺寸须与构造时一致。
表面使用[公共快照编码](projected-reflection-preparation.md)。
颜色为有限且非负的 HDR 辐射。

运动采用当前减前帧的线性 UV 位移。
该运动场按归一化 UV 采样，支持一像素恒定场。
运动为空时，当前帧模式借用内部零位移纹理。
非有限线性运动由公共射线归零。

## 当前与历史模式

`record` 默认使用当前颜色和准备后的当前深度。
射线的历史混合设为当前帧模式。
其余生产和过滤契约保持完整。
独立工具可据此生成单帧反射。

`ProjectedScreenReflectionHistory` 提供前帧槽位和颜色。
其中还包含前帧实际采样的相机投影、位置和正交基。
当前与前帧槽位须不同，且须提供运动场。
前帧深度取自本对象已成功提交的对应槽位。

历史模式按位移定位前帧颜色并核对几何。
错误位姿及遮挡变化通过几何检查缩减可信度。
调用者维护切镜、成功提交及取消后的身份有效性。
前帧视图必须对应所借用的颜色和深度。

## 记录顺序

1. 校验参数、相机、输入别名和历史槽位。
2. 开始信号写入并转换公共表面。
3. 通过投影射线写入颜色、足迹及可信度。
4. 发布足迹，按最大值生成反向深度金字塔。

5. 按反向深度的解码系数生成信号金字塔。
6. 用足迹 G 通道选择空间过滤层级。
7. 发布存储读取输出，交由调用者完成场景合成。

过滤按相机倒数系数恢复正向深度。
深度金字塔消费已清理的准备结果。
背景和非法表面的反向深度均为零。
初始可信度及非法表面按准备模块规则处理。

`output(slot)` 返回最终颜色及可信度。
`prepared(slot)` 和 `signal(slot)` 提供观察用资源身份。
记录完成后，原始信号及足迹已发布为采样布局。
足迹 R 通道保留射线生产的运动衰减。

## 生命周期与验证

调用者在记录前发布借用图像的采样可见性。
对象负责其全部中间图像和最终输出的同步。
调用者退休包括历史在内的槽位消费者。
关闭和销毁同样要求 GPU 工作完成。

记录取消后可直接重新记录。
同一提交内支持两个槽位的独立参数及历史读取。
参数、资源和历史拒绝均先于描述符和命令变化。
构造失败按资源所有权回收已建立的子组件。

独立镜面、错误控制及双配置来源见[组合验证](../acceptance/nr/projected-reflection-composition.md)。
主场景的类型化选择、实际提交和连续采样按所属计划接入。
