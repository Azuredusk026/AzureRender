# 场景节点稳定分组

`scene::stableMeshNodeOrder` 接收网格键数组及有效网格数。
数组位置标识输入节点，返回值按值拥有源节点索引。
输出先按网格键升序排列，再保留组内输入顺序。
范围外网格键对应未绘制输入，空范围产生空结果。

实现依次统计数量、生成起点并稳定散布索引。
时间与输入节点数及网格数之和成正比。
临时内存由调用拥有，函数没有跨帧状态。
分配失败遵循标准容器异常规则。

场景渲染器将不可见节点映射为范围外键。
世界变换、模型矩阵、包围盒及源身份按该顺序构建。
连续实例范围继续供阴影、运动、材质及绘制路径消费。
单节点压力网格沿用所属生成规则。

完整范围见[实施计划](../plans/2026-11-06-stable-instance-grouping.md)。
