# 材质照明接收

本契约用于场景照明模式中的有光照材质。
材质声明环境来源及普通照明的主光阴影来源。
具体灯组、对象图集及环境资源由场景持有。
完整材质文档、材质图及内嵌画像使用同一解释器。

## 环境来源

画像版本二支持 `environmentLighting` 子对象。
子对象版本为一，未知字段触发加载错误。
漫反射与反射可分别选择来源。
两项的缺省值均为 `scene`。

```json
{
  "environmentLighting": {
    "schemaVersion": 1,
    "diffuse": "global-environment",
    "reflection": "global-environment",
    "globalIntensity": 0.5
  }
}
```

| 字段 | 输入与作用 |
| --- | --- |
| `diffuse` | `scene` 消费场景辐照，`global-environment` 消费全局环境图 |
| `reflection` | `scene` 消费探针及屏幕空间反射，`global-environment` 消费全局环境图 |
| `globalIntensity` | 可选的零至十六有限值，供已选择的全局来源消费 |

全局来源使用视图中已有的环境图与旋转。
省略强度时继承视图的全局环境强度。
显式强度要求至少一项选择全局来源。
材质自身的反射率、漫反射及镜面模型继续有效。

漫反射选择全局来源时，当前材质跳过场景辐照混合。
反射选择全局来源时，当前材质跳过探针及屏幕空间反射。
其他材质继续消费各自声明的场景来源。
NPR 的显式常量光色继续由对应颜色契约持有。

场景探针的适配量继续消费自身的场景辐照。
漫反射来源的材质选择与该适配量分别计算。

## 对象阴影

画像版本二支持 `mainLightShadow`。
缺省值 `scene` 使用现有场景阴影规则。
`object-shadow` 为普通照明材质选择角色接收组。
该组主方向光消费已有对象图集的可见量。

```json
{
  "mainLightShadow": "object-shadow"
}
```

对象来源适用于普通照明的通用、织物及金属材质。
它与专用 NPR、眼睛及投影头发可见量互斥。
无光照及覆盖材质使用自身的合成契约。
非法类型或不兼容组合触发明确的加载错误。

`azure.object-shadow` 组件提供图集页与接收参数。
图集缺失或组件关闭时，可见量按既有契约返回一。
主光方向与图集投影消费相同的角色主光。
其他局部灯保持各自的照明响应。

全局级联阴影的诊断开关用于对应场景阴影。
对象阴影通过组件启停独立核对。
方向灯接收组及对象图集沿用现有类型和生命周期。

## 布局与兼容

GPU 画像布局版本为二十一，大小为 352 字节。
第二十一行依次保存显示策略、环境位、强度及阴影来源。
缺省环境位和阴影来源均为零。
全局来源的继承强度以负一作为内部标记。

默认策略使用场景着色程序。
显式环境来源及对象阴影使用 `_lighting` 编译变体。
主视图与颜色快照按同一材质条件选择管线。
两类程序共享画像布局、描述符及渲染资源。

管线按当前资源中的材质类别创建。
着色模块在管线创建结束时释放。
管线资源随场景关闭或渲染配置重建释放。

场景渲染器 API 版本为九。
角色渲染器声明 `supportsMaterialLightingReception`。
采集清单以 `materialLightingReceivers` 记录显式选择。
每项包含材质身份、两类来源、强度及阴影来源。

来源差异与执行范围见[实施计划](../plans/2026-11-01-material-environment-reception.md)。
整体联合画质按[开发总计划](../plans/azure-engine-plan.md)验收。

## 材质反射

二版受光材质在 `environmentLighting` 中声明反射来源。通用、布料和金属材质可以将 `specularModel` 设为 `ggx-multiscatter-fit`，按粗糙度、法线与视线夹角以及基础反射率计算多次散射响应。缺省值 `scene` 沿用场景的响应方式。

使用八面体反射图集的关卡可以通过 `reflectionLayer` 指定材质的反射层。层号从零开始，实际图集必须包含该层，且 `reflection` 须为 `scene`。着色器按世界反射方向与关卡的粗糙度映射采样该层。图层内的线性辐亮度包含材质所需的强度。空间探针混合及屏幕空间反射继续服务于由场景决定反射的表面。漫反射按材质的 `diffuse` 设置取样。

## 径向照明法线

二版的通用、皮肤、布料和金属材质可在 `nprDiffuse` 中将 `lightingNormal` 设为 `origin-radial-horizontal`。材质必须通过 `rimOrigin` 显式绑定原点节点。世界位置减去该节点的世界原点后，纵轴分量取 1/16384，其余分量归一化后参与 NPR 照明。原点随节点动画更新。缺省值 `surface` 使用表面法线。

混合透明材质可将 `nprDiffuse.transparentHighlights` 设为 `true`，接收已配置的角色高光与轮廓光。该值缺省为 `false`。配置解析同时核验材质版本、透明队列及原点绑定。独立夹具覆盖两个原点、变换、镜像、固定描述符、外部材质和动画。
