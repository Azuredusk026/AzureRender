# 关卡刷新数据释放

`LevelSession` 在后台准备关卡及资产数据库候选。
未变化的刷新结果保留当前场景，并发布当前资产数据库。
会话通过值交换取得数据库，将候选与退休数据库一起持有。
该持有区最多容纳一个已完成的未变化结果。

下一次后台工作取得该结果的所有权。
工作函数先显式清空退休数据，再开始当前刷新。
显式清空限定大数据的正常释放位置。
异步共享状态的清理由原有 `future` 生命周期管理。

场景提交、版本判定、预加载及取消保持所属流程。
未变化结果的持有持续至下一后台工作或会话关闭。
后台启动失败及关闭遵守会话错误与清理规则。
GPU 资源继续由渲染器的帧围栏及卸载流程管理。

验证区分轮询中的大块释放、持有量和关闭释放。
这些结果描述数据生命周期，帧时间按实际原生采集判断。
范围见[实施计划](../plans/2026-11-06-level-refresh-retirement.md)。
