# 完整覆盖阴影提交

## 管线契约

`GraphicsPipelineDesc.fragmentShader` 为空时只提交顶点阶段。
调用方提供兼容的渲染通道、深度附件与布局。
存在颜色附件时，片元输出值由调用方负责定义。
阴影使用零颜色附件及原有深度测试、写入和偏移。

完整覆盖策略由 `fullyCoveredShadow` 判定。
节点透明度恰为一时，几何覆盖标志优先生效。
普通不透明材质同时要求平方根覆盖标志关闭。
裁切、混合及节点淡出按对应片元程序计算覆盖。

## 所有权与录制

场景渲染器拥有级联与对象图集两份纯深度管线。
两种通道保持各自的渲染通道、深度偏移及精度规则。
管线重建与卸载按既有资源顺序销毁句柄。
材质常量、形变、绘制次序与实例来源共同保留。

管线选择位于每个节点透明度连续区间。
局部绑定状态只服务当前录制调用。
独立覆盖纹理在需要片元覆盖的材质路径中继续生效。
空片元模块使用 Vulkan 核心能力，无额外扩展要求。

验证范围见[实施计划](../plans/2026-11-06-depth-only-shadow.md)及[实际记录](../acceptance/nr/depth-only-shadow.md)。
