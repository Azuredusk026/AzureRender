# 时序抗锯齿

`render.antiAliasing=3` 选择原生尺寸时序重建。
命令行入口为 `--anti-aliasing temporal`。
默认模式为一，画质晋升遵守 NR7-AA 门禁。
实现位于 `TemporalReconstruction` 与 `MotionVectorPass`。

## 材质与运动输入

场景渲染器通过 API 版本四声明运动能力。
视图提供 `RenderContext::motionOutput` 借用目标。
渲染器输出运动向量及颜色表面深度。
硬件深度通过加载与存储保持原值。

运动纹理采用 RGBA32F。
XY 表示当前减前帧的未抖动 UV 位移。
Z 表示前帧设备深度。
W 的一、零、负一分别表示跟踪、背景及响应像素。

颜色表面深度采用独立 R32F 纹理。
颜色描边具有自身覆盖和深度偏移。
其历史检查消费颜色表面深度。
背景通过硬件深度与相机矩阵重投影。

前帧对象按节点、几何资源及副本身份匹配。
保存内容为模型、关节、形变权重和 Gizmo。
资源代次、拓扑或姿态布局变化使匹配失效。
透明与覆盖叠层显式拒绝历史积累。
完全透明像素保持背景运动及背景表面深度。

基础顶点、材质表及实例表沿用现行布局。
当前几何与前帧几何共用不可变形变资源。
运动通道使用独立的精简描述符集合。
前帧上传仅更新围栏退役后的帧槽。

## 采样与历史

采样投影使用独立的八相位 Halton 抖动。
首帧和历史重置帧采用零抖动。
裁剪、阴影及运动匹配使用未抖动投影。
场景作者配置的投影偏移独立保留。

视图先精确复制当前 HDR，再执行历史合成。
合成同时写入场景 HDR、颜色历史与深度历史。
曝光、调色及输出编码消费合成后的 HDR。
场景 HDR 的既有采样绑定保持有效。

历史采样检查有效性、屏幕范围和线性视空间深度。
5×5 邻域提供前景运动和最近表面深度。
常规区域使用 3×3 颜色范围硬约束。
覆盖边缘使用随运动加强的 5×5 渐进约束。
颜色历史 Alpha 明确记录有效状态。
当前场景 Alpha 保持当前帧的语义。

主视图与每个辅助视图分别拥有历史资源。
合成输入须具有当前视图的运动与表面深度生产者。
历史轮换仅发生于成功录制且队列接受后。
取消操作保留已提交的历史及采样序号。
尺寸、场景、切镜标记和投影变化触发重置。

## 资源与诊断

每视图持有运动、表面深度、HDR 暂存及双份历史。
纹理预算为每像素 52 字节，上限 512 MiB。
运动目标独立检查 256 MiB 上限。
2560×1440 的纹理预算约为 182.8 MiB。

资源与能力不足时，输出采用模式一的空间过滤。
`temporalFallback` 记录失败原因。
采集清单提供历史提交号、资源字节和活动运动输出。
辅助视图诊断提供相同的历史及资源字段。

连续移动、拖影和材质细节按[完整计划](../plans/2026-10-22-spatial-antialiasing.md)验收。
KK 主次带、细发丝和服饰边缘分别统计。
公共四倍尺寸对照见[覆盖与质量验证](../acceptance/nr/temporal-coverage-quality.md)。
输出像素及细线能量契约见[描边采样](../acceptance/nr/outline-temporal-footprint.md)。
默认模式的晋升依赖正式截帧与性能联合门禁。
