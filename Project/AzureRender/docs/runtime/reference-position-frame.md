# 参考位置坐标帧

`ReferencePositionFrame` 声明世界坐标到参考相对坐标的轴向与偏移。
相对坐标随后消费[参考裁剪投影](reference-clip-projection.md)。
静态资产来源及已变形的世界位置流共用该接口。

## 类型与范围

配置版本为一，三个头部保留字均为零。
参数包含四个有符号整数及四个单精度偏移。
参数占 32 字节，对齐为十六字节。
两行的第四分量均为保留值，保持为零。

前三个轴编号的绝对值分别覆盖一、二、三。
正号保留对应分量，负号反射对应分量。
重复编号、零编号及范围外编号提供输入异常。
偏移及输入位置须为有限值。

例如 `{-1,2,3}` 表示横轴反射及其余两轴保持。
`{3,-1,2}` 表示轴向置换及第二个输出分量反射。
默认值为 `{1,2,3}`，偏移为零。
轴向与偏移的来源由所属项目或资产配置持有。

## 数值与编码

转换先选择分量，再按轴符号反射。
偏移通过一次单精度加法加入结果。
CPU 调用 `referenceRelativePosition`，有限溢出通过异常报告。
调用方使用最近偶数舍入，并保留非规格化数。

`referencePositionFrameCode` 将三个轴编码为九位整数。
每个轴使用三位，低两位选择零至二号分量。
第三位表示符号反射，高位保持为零。
默认编码为 136，横轴反射的默认置换编码为 140。

GLSL 调用 `azureReferenceRelativePosition`。
调用前由宿主校验坐标帧，并保证转换结果有限。
该函数复用参考有限乘加的整数实现完成加法。
符号反射及全零输入按位处理，保留符号零及非规格化数。

坐标帧转换的数值边界独立于随后的矩阵投影。
矩阵运算及设备浮点资格遵循投影契约。
输入与输出资源由调用方持有，并保留至所属工作结束。

## 世界坐标深度

`ReferenceDepthConfig` 的版本二包含 `positionFrame`。
版本一的位置流采用相机相对坐标。
版本二的位置流采用该坐标帧所属的世界坐标。
两种配置均接收连续的四分量单精度顶点位置。

调用方加载 `ReferenceDepthPositionFrameShaders`。
该程序束持有世界坐标的不透明及透明覆盖顶点程序。
程序束赋给 `ReferenceDepthShaders::positionFrame`。
表面覆盖与深度约定继续遵循[深度契约](reference-depth.md)。

生产器在资源创建前验证配置与所需程序。
推送参数占 128 字节，符合 Vulkan 的最低保证。
轴编码位于控制行，帧偏移具有独立参数行。
位置缓冲、纹理及槽位的所有权沿用所属深度生产契约。
