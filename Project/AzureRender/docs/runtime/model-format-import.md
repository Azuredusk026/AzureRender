# 模型格式导入

## 输入与运行产物

模型支持 glTF、GLB、OBJ、STL、PLY、DAE 与 FBX 输入。
交换格式生成独立 GLB，运行时加载规范模型容器。
扩展名按大小写无关规则识别。
中文名称及空格路径通过 UTF-8 传递。
Windows 宿主从系统宽字符参数取得路径。
场景描述、模型缓存和加载器共用 UTF-8 标识。

OBJ 的材质文件和外部贴图位于来源目录内。
依赖经规范路径检查，缺失文件返回诊断。
外部贴图嵌入生成容器。
准备阶段按来源总量限制读取预算。

## 单位与保真

共享传输请求通过 `unitScale` 设置单位倍率。
`upAxis` 接受 `y` 或 `z`，输出采用 Y 轴向上。
倍率必须为有限正数，最大值为一百万。
界面设置入口按导入导出体验阶段统一提供。

模型适配器保留网格层级与三角化几何。
材质槽、法线、纹理坐标及透明语义进入 GLB。
骨架、绑定矩阵与动画通道进入运行加载器。
动画时间以秒表达。

来源约束和程序着色使用导入场景的表达。
动画曲线以转换器支持的通道形式保存。
这些语义的转换损失随导入报告返回。
相机与灯光通过项目场景制作入口配置。

## 来源与恢复

每次转换记录来源、依赖及输出指纹。
发布前再次验证来源与生成容器。
取消、目标冲突及过期输入清理任务暂存。
既有资源及占用目录保留所属内容。

项目元数据记录格式生成器及版本。
转换来源由格式注册的能力声明验证。
放置、撤销、重导入及保存使用公共编辑服务。
项目移动和发布依赖规范产物的内容标识。

## 第三方依赖与夹具

转换器为 Assimp 6.0.4，许可为 BSD-3-Clause。
源码提交为 `e0b52347c6e52de2827ec957a9ebf00ce3c54f79`。
项目通过 `cmake/vcpkg-overlays/assimp` 固定构建规则。
支持范围内的导入器及 GLB 输出器参与验收。

项目构建关闭 IFC 与 VRML 导入器。
包补丁按该范围配置所需依赖。
安装目录包含转换器及其依赖的许可文件。
来源归档使用包定义的 SHA-512 校验值。

CPU 夹具由测试中的独立几何和骨架定义生成。
OBJ、STL 与 PLY 使用可审阅的文本数据。
DAE 与 FBX 由固定版本转换库序列化。
几何、材质与动画按独立预期值验证。
