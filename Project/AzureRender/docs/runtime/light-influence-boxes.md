# 灯光作用体积

场景灯光可绑定独立的世界空间盒状作用体积。
该机制适用于室内补光、分区照明及建筑灯组。
所属模块为场景数据、灯光缓冲与两个渲染后端。
场景文档及关卡 JSON 使用相同配置契约。

## 配置

`shape.influenceBox` 配置如下：

```json
{
  "enabled": true,
  "worldToBox": [[0.5, 0, 0, -0.5], [0, 1, 0, 0], [0, 0, 1, 0]],
  "falloffThreshold": 0.5
}
```

三行仿射矩阵将世界位置映射到单位盒。
各轴边界为负一与正一。
示例盒中心为 `(1,0,0)`，半尺寸为 `(2,1,1)`。
旋转、缩放和平移由矩阵共同表达。
体积独立锚定，灯节点变换只影响光源本身。

所有矩阵元素须为有限数。
启用体积时，线性部分须可逆。
阈值范围为零至一，默认值为 0.8。
缺省配置关闭体积，保持完整光源贡献。
非法配置由场景加载或灯光上传入口拒绝。

## 着色与生命周期

盒坐标绝对值的最大分量记为 `e`。
阈值 `t` 对应恒亮边界 `(1+t)/2`。
边界至 `e=1` 之间采用平方衰减。
盒外权重为零，阈值一使用硬边界。
盒边界上的权重为零。

遮罩乘入该灯的漫反射与镜面贡献。
光源类型、距离衰减及阴影继续独立评价。
光栅与路径追踪调用同一着色函数。
光照聚类保留光源范围的保守分配。

场景持有配置，渲染快照持有上传副本。
缓冲随既有帧资源创建及释放。
光栅的每灯 GPU 结构为 144 字节。
路径追踪的每灯记录为 128 字节。
路径追踪历史指纹覆盖矩阵、阈值与启用状态。

`.azscene` 当前版本为十，兼容版本一至九。
每个灯光记录包含 `lightInfluenceBox` JSON。
旧格式加载时使用关闭状态。
版本八的距离衰减信息完整保留。

## 验证入口

`tools/native_render/light_box_lab.py` 生成公开场景。
夹具覆盖关闭、轴向、旋转及平移体积。
`--tracing` 选择 64 采样路径追踪。
测量比较实际线性亮度与独立计算的遮罩权重。
证据范围见[原生灯光作用体积](../acceptance/nr/light-influence-boxes.md)。
