# 参考相机视图

`ReferenceCameraView` 声明同源的投影与空间查询参数。
配置包含坐标帧、裁剪投影、尺寸、深度约定及纵轴翻转。
`PreparedReferenceCameraView` 校验并复制这些值。
准备后的对象持有双精度矩阵、逆矩阵及保守裁剪平面。

## 配置与准备

视图版本为一，三个头部保留字均为零。
坐标帧遵循[参考位置坐标帧](reference-position-frame.md)。
投影遵循[参考裁剪投影](reference-clip-projection.md)。
宽高范围为一至八千一百九十二。

矩阵须可逆，行和范数乘积的条件估计至多为一万亿。
未知版本、深度约定、非法尺寸及病态矩阵提供输入异常。
准备类型持有配置副本，查询共用不可变状态。
CPU 状态和 GPU 资源分别由所属调用方持有。

## 投影与射线

`clip` 按单精度坐标帧和参考投影边界计算齐次坐标。
`project` 返回连续像素坐标及设备深度。
像素零位于目标图像左上角，像素中心使用半整数。
`flipNdcY` 统一影响投影、逆投影及空间查询。

`unproject` 接收归一化视口坐标及零至一的设备深度。
`pickRay` 的原点位于所声明的近裁剪面。
方向经过可见深度区间的中间面，并归一化为世界方向。
正向深度的近值为零，反向深度的近值为一。

非有限位置、非法深度、零 W 及退化射线提供异常。
输出世界位置须能表示为有限单精度值。
矩阵逆变换使用双精度，返回的世界位置采用单精度。
具体来源的往返精度通过所属视图资格核对。

## 保守包围盒

`intersectsBounds` 接收世界坐标的最小及最大端点。
每个分量须有限，并满足最小值至多为最大值。
六个平面分别核对左右、上下及设备深度区间。
只有确定处于外侧的包围盒才被拒绝。

数值余量包含六十四倍单精度相对误差与运算幅度。
另加入六十四倍最小正规数，覆盖设备对非规格化中间值的归零。
接触边界及数值不确定的包围盒保持可见。
边界余量独立于颜色与可见量的验收门槛。

## 深度适配

`referenceCameraDepthConfig` 接收准备后的视图。
返回版本二的世界坐标深度配置。
坐标帧、深度约定及纵轴翻转均来自同一视图副本。
录制时使用该副本的 `projection` 字段。

位置、索引、纹理及槽位沿用[深度生产](reference-depth.md)的所有权。
统一视图同时供纯 CPU 查询与实际深度调用使用。
场景宿主的相机选择及绘制绑定由所属运行接口装配。
专项结果见[参考视图验收](../acceptance/nr/reference-camera-view.md)。
