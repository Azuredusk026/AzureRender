# 内容制作服务

> 文档类型：开发参考
> 状态：生产接口
> 更新日期：2026-10-08

## 类型、引用与复制

资产类型由 `AssetTypeRegistry` 注册。
描述包含身份、标签、扩展名和放置能力。
`assets.catalog` 合并资产数据库与场景资源。
目录条目提供身份、来源、状态与使用数量。

场景资源按文档顺序优先展示。
其余资产按虚拟路径排序。
目录顺序保持独立于随机 UUID。

字段元数据声明节点引用或资产引用。
资产引用同时声明允许的类型。
属性面板和自动入口消费相同的描述。
节点默认引用可声明为当前节点。

`node.duplicate` 复制整个选择子树。
父子共同选择只产生一份子树副本。
内部节点引用按身份映射重写。
外部引用保持原有身份，灯光获得新身份。

`node.reparent` 接收 `id` 与 `parent`。
空父级表示场景根层级。
操作保持世界姿态，并校验循环和合法 TRS。
奇异矩阵及不可表示的剪切返回诊断。

## 放置与组件

`asset.place` 接收资产、射线起点与方向。
宿主提供最近的正向几何交点。
求交使用当前实例的蒙皮与形变数据。
创建和定位形成一个撤销单元。

无几何命中时，射线与回退平面求交。
`fallbackHeight` 默认是零。
平行或背向射线采用 `fallbackDistance`。
距离默认是五，必须为正且有限。

组件删除通过 `component.remove` 执行。
节点的变换和可见性组件具有必需约束。
字段重置通过 `component.reset-field` 执行。
字段值来自注册默认值与引用默认策略。

属性读取合并注册默认值与存储字段。
长名称和普通字符串使用动态缓冲。
字段校验拒绝非法值，并保留当前合法内容。
单次删除与重置各形成可撤销操作。

大纲工具行固定，对象列表独立滚动。
紧凑内容面板保留一行筛选和可见资产行。
加号入口提供导入、创建、目录与刷新。
完整类型菜单支持滚动选择注册类型。

只读查询保持连续编辑的合并状态。
控件完成编辑时调用 `history.end-edit`。
一次输入形成一个撤销单元。
独立输入会话具有各自的撤销边界。

## 会话任务与反馈

`EditorTaskService` 持有任务生命周期。
会话每帧轮询进度、完成、取消和失败。
关闭面板后，任务仍由会话推进。
导入提交经生产操作完成。

预览、构建、活动拖拽与确认弹窗延后写入。
任务状态包括运行、完成、取消和失败。
`tasks.describe` 返回来源、目标和结果。
导入结果包含资源身份与失败诊断。

`EditorFeedback` 为错误分配独立身份。
成功操作保留既有错误记录。
`feedback.describe` 返回来源和错误内容。
`feedback.dismiss` 主动关闭指定记录。

Console 展示任务状态与错误来源。
每条错误提供关闭入口。
字段错误同时显示在属性编辑位置。
自动工具与面板读取相同记录。

## 路径服务与保存

Platform 使用 Windows 文件与目录选择器。
选择器返回 UTF-8 路径、取消或错误。
路径历史按用途保存最近十个目录。
文件用途从历史目录继续选择实际文件。

`path.choose` 接收用途、标题、筛选及目录选项。
`path.remember` 保存目录并去重。
`path.history` 按用途查询历史。
编辑器偏好目录保存 `path-history.json`。

关卡指纹包含实际节点、组件和资源内容。
源文档中的重复表示由现行内容表达。
保存检查点保持相同的语义指纹。
传统文本场景使用可解析的虚拟资源路径。

操作模式与事务边界见[编辑操作参考](edit-operations.md)。
使用步骤见[编辑器交互教程](../tutorials/editor-interaction.md)。
