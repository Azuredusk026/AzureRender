# 运行系统装配

> 文档类型：设计与运行时说明
> 状态：已实现并验收
> 更新日期：2026-10-06

## 职责与所有权

`GameRuntime` 维护固定步、输入与渲染插值。系统注册表根据项目描述创建实例。共享机制由 `AzureGameplay` 提供。应用默认装配由 `AzureProjectRuntime` 提供。

依赖方向为应用、共享机制、Runtime。系统拥有内部运行状态，生命周期由调度器管理。物理、相机和交互查询作为运行服务供系统使用。系统扩展通过工厂进入公共循环。

## 调度顺序

固定步为 60 Hz，每帧最多执行 15 次。场景版本变化先通知系统并清理插值。帧边界提交延迟操作，再保存前帧变换。脚本回调在系统固定步之前执行。

系统按配置顺序执行。探索组合依次为角色移动、物理、动画、相机和交互。应用策略在初始化时安装。交互之后分派物理事件，再清理输入边沿。

关闭按系统创建顺序的逆序执行。初始化失败清理失败实例及已初始化实例。场景检视组合使用独立轨道相机和普通目标交互。项目选择系统与动作配置。

延迟切场景取消当前模拟帧。系统在取消返回前收到场景通知。后续帧使用新的世界与系统状态。暂停单步和渲染插值继续消费固定步结果。

## 配置契约

配置版本为 1，包含 `input` 与 `systems`。输入以动作名映射键码数组。每个系统描述包含 `id` 和 `config`。未知系统、重复实例和非法参数明确拒绝。

字符动作与动画状态通过组件配置。既有组件版本通过迁移获得相同语义默认值。通用交互允许全部合法目标。应用策略判断任务可用状态。

`azure.character.inputProfile` 选择角色动作映射。映射声明左右、前后、跳跃与加速动作。每个动作须在项目输入中绑定。角色版本 1 至 3 均可加载为版本 4。

`azure.animator.locomotionProfile` 选择状态映射。映射声明静止状态、移动状态与速度阈值。播放速率以实际速度除以参考速度。动画组件版本 1、2 可加载为版本 3。

`GameRuntime(runtime)` 创建应用中立的空调度器。带注册表和配置的构造函数创建项目组合。项目省略 `runtime` 时由应用提供探索默认值。项目显式配置使用其声明的全部系统。

## 扩展与使用

实现 `IRuntimeSystem`，通过 `SystemRegistry::add()` 注册工厂。工厂接收 JSON 配置并校验领域参数。实例接收运行世界、输入、物理和固定步上下文。所有回调由宿主主线程执行。

`initialize()` 安装服务或检查跨系统约束。`sceneChanged()` 清理场景相关缓存。`fixedStep()` 执行一个固定步。`shutdown() noexcept` 支持部分初始化状态。

各实例按描述数组顺序执行。相同 ID 在一个组合中只出现一次。系统描述使用 `id` 与 `config`。注册表可在多个独立调度器中复用。

探索配置见 `assets_public/exploration/project.azureproject`。检视配置见 `assets_public/scene_inspector/project.azureproject`。检视工具只装配轨道相机与普通交互。运行方式见该项目的 `README.md`。

动作配置采用 GLFW 合法键码。物理键盘按已配置键集合采集。自动输入回放使用相同输入入口。焦点释放、重绑定与场景重开清理按键状态。

## 验证范围

探索关卡验证任务、3C 与恢复。场景检视项目验证另一种系统组合。独立注册计数系统验证调度扩展。失败、输入重绑定与组件迁移有契约测试。
