# 参考几何深度

`ReferenceDepthGpu` 将已变形几何光栅化为深度。
每个帧槽持有 R32 浮点颜色及 D32 深度。
两份输出来自相同的图形管线和深度测试。
消费者通过输出视图及声明布局取样。

## 投影与深度

顶点位置采用相机相对坐标系。
投影参数遵循[参考裁剪投影](reference-clip-projection.md)。
创建管线时自动准备显式乘加来源标记。
录制每帧时校验投影版本及有限数值。

版本一配置选择正向或反向深度。
正向深度使用小于比较，清除值为一。
反向深度使用大于比较，清除值为零。
`flipNdcY` 控制投影后纵轴的符号。

## 几何输入

`ReferenceDepthGeometry` 借用两个 GPU 缓冲。
位置缓冲具有顶点用途，连续存放四维单精度值。
前三个分量参与投影，第四个分量为布局填充。
索引缓冲具有索引用途，连续存放三十二位整数。

索引数量是三的正整数倍。
每个索引均须小于声明的顶点数量。
输入位置须有限，投影中间值须保持有限。
缓冲大小及内容有效性由所属几何生产者保证。

每次录制接收零至六万五千五百三十六个绘制。
空绘制列表清除所选帧槽。
管线绘制双面不透明三角形。
透明覆盖由所属材质及场景接入通道承担。

## 同步与释放

调用方在录制前发布顶点输入依赖。
位置访问为 `VERTEX_ATTRIBUTE_READ`。
索引访问为 `INDEX_READ`。
输出转换为声明的只读布局后交给消费者。

复用帧槽前，调用方等待该槽的消费者结束。
输出句柄由生产器持有，消费者按帧槽借用。
生产器销毁前，调用方等待所属 GPU 工作完成。
同一实例由一个录制线程顺序使用。

## 范围与失败

输出宽高处于一至八千一百九十二之间。
帧槽数量处于一至八之间。
声明图像预算为宽乘高乘八字节再乘帧槽数。
合计至多二百五十六 MiB。

`supported` 查询格式、用途及预算支持情况。
未知配置版本、深度约定及非法输入提供异常。
错误帧槽通过越界异常报告。
初始化失败时释放本实例已分配的资源。

实际场景的几何、覆盖及接收深度来源分别验收。
原生画质采用固定遮罩及对应输出门槛。
