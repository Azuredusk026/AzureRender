# 参考几何深度

`ReferenceDepthGpu` 将已变形几何光栅化为深度。
每个帧槽持有 R32 浮点颜色及 D32 深度。
两份输出来自相同的图形管线和深度测试。
消费者通过输出视图及声明布局取样。

## 投影与深度

顶点位置采用相机相对坐标系。
投影参数遵循[参考裁剪投影](reference-clip-projection.md)。
创建管线时自动准备显式乘加来源标记。
录制每帧时校验投影版本及有限数值。

版本一配置选择正向或反向深度。
正向深度使用小于比较，清除值为一。
反向深度使用大于比较，清除值为零。
`flipNdcY` 控制投影后纵轴的符号。

## 几何输入

`ReferenceDepthGeometry` 借用两个 GPU 缓冲。
位置缓冲具有顶点用途，连续存放四维单精度值。
前三个分量参与投影，第四个分量为布局填充。
索引缓冲具有索引用途，连续存放三十二位整数。

索引数量是三的正整数倍。
每个索引均须小于声明的顶点数量。
输入位置须有限，投影中间值须保持有限。
缓冲大小及内容有效性由所属几何生产者保证。

每次录制接收零至六万五千五百三十六个绘制。
空绘制列表清除所选帧槽。
每个绘制通过表面描述选择剔除及透明覆盖。
默认表面采用双面不透明三角形。

## 表面与透明覆盖

`ReferenceDepthSurface` 支持版本一和版本二。
表面声明正面方向及正面、背面或双面保留规则。
方向遵循 Vulkan 的帧缓冲有向面积定义。
规则见[光栅化规范](https://docs.vulkan.org/spec/latest/chapters/primsrast.html)。

`ReferenceDepthAlpha` 借用 UV 缓冲、纹理视图及采样器。
UV 缓冲具有顶点用途，连续存放二维单精度值。
纹理视图须匹配浮点取样类型及声明的只读布局。
纹理及采样器的创建和生产同步由调用方持有。

通道位于零至三之间，分别表示 RGBA。
阈值位于零至一之间，默认值为二分之一。
采样值小于阈值时丢弃片元，等于阈值时保留。
纹理层级偏移位于负十六至十六之间，默认值为零。

默认 `Device` 策略由设备决定有效纹理层级。
版本一支持该策略，版本二同时支持显式椭圆策略。
有效偏移遵循所属设备的取样限制。
参数须为有限值，视图使用颜色纹理只读布局。
纹理、UV 及采样器须保持到所属 GPU 工作结束。

`ReferenceDepthShaders::load` 装配不透明程序。
`loadMasked` 同时装配透明覆盖程序。
`loadEllipseMasked` 增加显式椭圆覆盖程序。
调用前查询并传入实际设备的四像素组能力。
覆盖绘制在录制前核对程序及输入是否齐全。
每帧槽支持至多一百二十八个覆盖绘制。

管线按表面状态惰性缓存，实例至多持有十八条管线。
覆盖描述符由生产器按帧槽持有及复用。
输入校验及管线准备先于图像状态和绘制录制。
更新描述符前须完成所属帧槽的退休。

## 椭圆纹理层级

版本二通过 `lodPolicy` 选择显式椭圆模式。
策略标识为 `EllipseMajorAxisMirroredCoarseY`。
该模式要求片元阶段支持四像素组操作。
缺少能力、程序或对应表面版本时报告异常。

镜像粗粒度导数遵循[梯度助手契约](material-uv-gradients.md)。
纹素导数组成二维矩阵，最大奇异值定义主轴长度。
基础层级为该长度的以二为底对数。
表面的层级偏移随后参与显式取样。

函数通过统一缩放限制二次项的数值范围。
基础层级下限为负一百二十六。
零导数采用该下限，由采样器限制有效层级。
输入的纹素导数须为有限数值。

采样器采用各向同性过滤，采样器层级偏移为零。
缩放过滤、层级过滤和纹理边界由采样器声明。
偏移统一使用表面字段，通道及阈值沿用覆盖契约。
实际原生来源与设备数值按所属验收记录核对。

## 同步与释放

调用方在录制前发布顶点输入依赖。
位置访问为 `VERTEX_ATTRIBUTE_READ`。
索引访问为 `INDEX_READ`。
输出转换为声明的只读布局后交给消费者。

复用帧槽前，调用方等待该槽的消费者结束。
输出句柄由生产器持有，消费者按帧槽借用。
生产器销毁前，调用方等待所属 GPU 工作完成。
同一实例由一个录制线程顺序使用。

## 范围与失败

输出宽高处于一至八千一百九十二之间。
帧槽数量处于一至八之间。
声明图像预算为宽乘高乘八字节再乘帧槽数。
合计至多二百五十六 MiB。

`supported` 查询格式、用途及预算支持情况。
未知配置版本、深度约定及非法输入提供异常。
错误帧槽通过越界异常报告。
初始化失败时释放本实例已分配的资源。

实际场景的几何、覆盖及接收深度来源分别验收。
原生画质采用固定遮罩及对应输出门槛。
