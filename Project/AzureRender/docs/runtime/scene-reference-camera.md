# 场景参考相机

`azure.reference-camera` 是版本一的独立组件。
该组件依赖 `azure.camera`，默认关闭。
组件名称引用项目中已装配的具名参考视图。
原始视图与持久锚点共同定义相机的标定状态。

## 锚点与姿态

组件保存锚点位置及右、上、后三个单位轴。
各轴保持正交右手关系。
长度与正交误差至多为万分之一。
位置、方向及视图参数均须有限。

`ReferenceCameraPose` 持有位置及三个轴。
`referenceCameraPose` 根据位置、目标及上方向准备姿态。
`relocateReferenceCamera` 根据锚点与当前姿态转换参考视图。
相同姿态直接保留原投影与坐标帧的参数位值。

移动视图采用当前相机位置的相对坐标。
旋转在双精度中组合，再转换为单精度参数。
原视图的抖动、尺寸、深度约定及纵轴方向保持原值。
转换结果共用参考视图的矩阵条件与数值校验。

## 场景选择

相机服务根据当前帧场景的世界姿态解析相机。
有效相机按优先级选择，同级使用稳定节点名称排序。
启用参考组件时，服务查找具名视图并执行姿态转换。
关闭组件时，选择普通游戏相机。

`GameCameraSelection` 持有共享相机描述及可选参考视图。
`referenceName` 标明选中的参考配置。
失效引用及非法姿态提供节点关联诊断。
选择结果及配置集合各自持有数值副本。

`referenceRejected` 记录参考候选的拒绝状态。
存在有效游戏相机时，选择结果以该相机为准。
没有有效相机且存在参考拒绝时，诊断保持可见。
该情况下跟随相机回退保持关闭。

## 项目装配

`GameRuntime::setReferenceViews` 安装至多六十四个具名视图。
集合校验成功后一次替换，失败时保留现有集合。
项目宿主及编辑器运行预览读取相同的项目配置。
文件格式见[项目参考视图配置](project-reference-views.md)。

共享相机描述持有参考标定与锚点。
光栅、拾取及编辑消费见[参考相机渲染与拾取](reference-camera-render-binding.md)。
专项结果见[场景参考相机验收](../acceptance/nr/scene-reference-camera-selection.md)。
