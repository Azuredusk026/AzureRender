# 表面纹理坐标

普通 PBR 表面使用一套规范化的运行纹理坐标。
glTF 输入可选择 `TEXCOORD_0` 或 `TEXCOORD_1`。
同一材质使用的标准表面纹理须选择同一坐标集。
每个图元按自己的材质独立转换。

## 导入规则

检查范围包括基础色、法线、金属粗糙度、自发光和遮蔽。
缺少 `texCoord` 的纹理按 glTF 约定选择零。
纹理未绑定时，其坐标声明不参与选择。
显式选择只接受零或一。

选中第二组坐标时，导入器将其复制到公共表面 UV。
转换在缺省切线生成及节点变换之前执行。
原始第二组流继续保存在资产的附加坐标表中。
轮廓等专用输入继续遵循各自契约。

已提供的切线方向和符号按作者数据保留。
缺少切线时，生成器消费选定的表面坐标。
普通材质、透明、快照及覆盖通道共用该顶点输入。
GPU 材质和纹理绑定布局保持现行版本。

## 统一采样域

跨坐标集的源材质通过实际网格烘焙形成统一表面。
坐标变换在内容生成阶段处理。
输入纹理混用坐标或包含 `KHR_texture_transform` 时产生明确错误。
所选第二组流缺失时，导入失败。

完整材质文档消费规范化后的表面 UV。
眼睛、径向材质和其他动态采样按对应类型解释。
直接组合多个运行采样域按专项任务扩展。
生成方法见[原生 UV 转换](../development/native-surface-uvs.md)。
