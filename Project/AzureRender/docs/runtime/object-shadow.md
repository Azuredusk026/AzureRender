# 对象阴影配置

`azure.object-shadow` 版本一声明对象的投影参数。
组件通过公共属性、脚本及编辑操作访问。
当前已接入配置、文档与类型化渲染快照。
场景渲染器生产深度图集，并提供对象可见量。

NPR 材质通过 `characterVisibility: "object-shadow"` 消费。
头发在 `hair.projectedRamp.lighting` 中声明该来源。
通用 NPR 材质在 `nprDiffuse` 中声明该来源。

## 参数

| 字段 | 默认值 | 约束与含义 |
| --- | --- | --- |
| `enabled` | `true` | 控制对象是否参与分配 |
| `center` | `[0,0,0]` | 局部中心，各轴范围为正负十万米 |
| `halfExtents` | `[1,1,1]` | 主灯空间半尺寸，各轴为 0.0001 至十万米 |
| `normalBias` | `0.005` | 法线偏置，范围为 0 至一百米 |
| `lightBias` | `0.0025` | 朝光偏置，范围为 0 至一百米 |
| `filterRadiusX` | `4` | 水平过滤半径，范围为 0 至 64 像素 |
| `filterRadiusY` | `2` | 垂直过滤半径，范围为 0 至 64 像素 |
| `atlasPage` | `8` | 0 至 7 指定分区，8 表示自动分配 |
| `receiverPixelOffsetX` | `0` | 接收位置的水平偏移，范围为正负两像素 |
| `receiverPixelOffsetY` | `0` | 接收位置的垂直偏移，范围为正负两像素 |
| `surfaceNormalBias` | `false` | 使用材质表面法线计算接收偏置 |

数值必须有限，未知字段和未来版本均被拒绝。
中心随实例的完整仿射变换移动。
半尺寸使用主灯坐标系中的世界米制尺寸。
内容应为对象的动画活动范围预留投影空间。

## 容量与所有权

投影帧最多拥有八个启用对象。
每个对象拥有独立分区和稳定实例索引。
固定分区先保留，自动分区按输入顺序分配。
重复实例、重复分区及超容量均返回错误。

图集布局为四列两行，每区 1024 像素。
投影记录包含矩阵、偏置、过滤半径及分区范围。
记录采用十六字节对齐，占 112 字节。
版本二头部为十六字节，最多追加八个记录。
末行保存接收像素偏移、法线选择和保留零值。
记录位于逐帧深度范围缓冲的对齐尾部。

图集为 `D16_UNORM`，大小为 4096×2048。
首次出现有效对象时分配十六 MiB 深度图像。
清除深度为一，每个分区保留一像素边界。
投影使用双面绘制、常量偏置八、斜率偏置零。
顶点姿态及逐材质覆盖沿用正式阴影绘制路径。

当前帧槽退休后，宿主更新实例索引和对象记录。
录制快照保留投影矩阵与分区身份。
深度范围计算和对象记录使用独立缓冲区间。
关闭顺序为 GPU 退休、管线、图集、描述符及缓冲。

基础材质布局使用十六个采样器和十六张图像。
对象档位共用深度采样器，并增加一张图像。
启用前检查格式、图像尺寸和各类描述符容量。
动态启用需要当前场景已准备对象档位。
布局未准备时，调用方重新加载具备相应能力的场景。

## 接收过滤

像素偏移以当前渲染分辨率的左上角为原点。
水平向右为正，垂直向下为正。
相机矩阵将偏移换算为等视深度的世界位移。
透视、正交及偏轴相机共用该换算。

缺省接收位置为当前片元，偏置使用几何法线。
开启 `surfaceNormalBias` 时使用材质表面法线。
该法线包含法线贴图和表面模型的有效响应。
两种法线均与主灯方向共同决定米制偏置。
权重为一减法线与灯向点积在零至 0.9 内的截断值。
深度转换为反向值后，最低取 0.01。
投影范围之外返回完整可见。

过滤使用十六个旋转泊松点，每点读取四个深度。
旋转相位采用左下原点的四乘四像素网格。
页面外采样返回远深度，防止邻接对象串扰。
遮挡比例与平均正深度差共同形成可见量。
最终消费者使用八位归一化量化结果。

偏置采用世界米制，半径采用图集像素。
内容须结合投影尺寸、过滤半径和几何厚度配置偏置。
宽范围或大半径需要相应的接收偏置控制。
过滤数学、原生深度对照及实际画面分别验收。

## 可见量诊断

`--qa-isolation object-shadow-visibility` 输出对象可见量。
该视图直接消费当前实例的对象记录和深度图。
零表示全遮挡，一表示完整可见。
无对象记录时返回一。

输出使用中性曝光，关闭色调映射及辉光。
PNG 经过 sRGB 编码，比较线性值时须先解码。
截图清单的 `qaIsolation` 保存该视图名称。
公共夹具覆盖遮挡、亮区与组件关闭。

## 文档与编辑

JSON 关卡在节点的 `components` 内保存组件。
`.azscene` 版本十三保存可选对象阴影信封。
版本一至十二加载时使用空对象阴影。
保存、重开及快照使用相同的注册字段解释。

编辑器可通过组件操作添加、修改和移除配置。
场景撤销及重做同时恢复配置和渲染快照。
运行时的组件变化进入后续场景快照。
新增与移除实例沿用运行时生命周期。
