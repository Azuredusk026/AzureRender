# 对象阴影配置

`azure.object-shadow` 版本一声明对象的投影参数。
组件通过公共属性、脚本及编辑操作访问。
当前已接入配置、文档与类型化渲染快照。
图集绘制及接收过滤处于实施阶段。

## 参数

| 字段 | 默认值 | 约束与含义 |
| --- | --- | --- |
| `enabled` | `true` | 控制对象是否参与分配 |
| `center` | `[0,0,0]` | 局部中心，各轴范围为正负十万米 |
| `halfExtents` | `[1,1,1]` | 主灯空间半尺寸，各轴为 0.0001 至十万米 |
| `normalBias` | `0.005` | 法线偏置，范围为 0 至一百米 |
| `lightBias` | `0.0025` | 朝光偏置，范围为 0 至一百米 |
| `filterRadiusX` | `4` | 水平过滤半径，范围为 0 至 64 像素 |
| `filterRadiusY` | `2` | 垂直过滤半径，范围为 0 至 64 像素 |
| `atlasPage` | `8` | 0 至 7 指定分区，8 表示自动分配 |

数值必须有限，未知字段和未来版本均被拒绝。
中心随实例的完整仿射变换移动。
半尺寸使用主灯坐标系中的世界米制尺寸。
内容应为对象的动画活动范围预留投影空间。

## 容量与所有权

投影帧最多拥有八个启用对象。
每个对象拥有独立分区和稳定实例索引。
固定分区先保留，自动分区按输入顺序分配。
重复实例、重复分区及超容量均返回错误。

图集布局为四列两行，每区 1024 像素。
投影记录包含矩阵、偏置、过滤半径及分区范围。
记录采用十六字节对齐，占 96 字节。
当前 GPU 接入门禁包括在途数据与资源释放。

## 文档与编辑

JSON 关卡在节点的 `components` 内保存组件。
`.azscene` 版本十三保存可选对象阴影信封。
版本一至十二加载时使用空对象阴影。
保存、重开及快照使用相同的注册字段解释。

编辑器可通过组件操作添加、修改和移除配置。
场景撤销及重做同时恢复配置和渲染快照。
运行时的组件变化进入后续场景快照。
新增与移除实例沿用运行时生命周期。
