# 逐灯镜面倍率

灯光的 `shape.specularScale` 控制直接镜面反射倍率。
默认值为一，合法值为有限非负数。
该配置适用于室内补光、环境主光与舞台灯组。
场景、关卡、编辑保存和两个渲染后端共用该契约。

```json
{
  "type": "directional",
  "direction": [0, -1, 0],
  "specularScale": 0.195
}
```

倍率乘入该灯的直接反射高光。
显式角色局部灯响应同时将倍率作用于 KK 主叶。
输入规则见[角色颜色响应](character-local-light-response.md)。
漫反射、间接环境反射和透射各自保持独立评价。
点光、聚光和方向光均支持该参数。
路径追踪的发光几何继续按其材质贡献照明。

灯光快照持有倍率副本，GPU 缓冲按帧上传。
光栅灯记录为 144 字节，盒参数第三分量保存倍率。
路径追踪灯记录为 128 字节。
路径追踪历史指纹包含倍率，修改会重建累积历史。
非法配置在解析及灯光上传入口拒绝。

`.azscene` 当前版本为十三，兼容版本一至十二。
保存记录包含 `lightSpecularScale`。
版本一至九采用默认倍率一。
关卡 JSON 在 `shape` 中保存 `specularScale`。

`tools/native_render/light_response_lab.py` 提供公共验证。
纯金属及混合表面分别渲染零、0.195 与一三组倍率。
`--tracing` 选择路径追踪，默认使用光栅。
测量将图像字节区间还原为线性亮度区间。
误差扣除八位量化可解释范围后，逐像素验证倍率。
来源及实景结果见[镜面倍率证据](../acceptance/nr/light-specular-response.md)。
