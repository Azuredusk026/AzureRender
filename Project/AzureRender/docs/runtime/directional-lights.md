# 场景方向光

阶段索引为 NR3。
方向光属于场景灯光契约，由渲染器消费。
室外日光与室内环境主光共享此能力。
场景文档、关卡及场景交换均可保存方向光。

## 配置

关卡的灯光通过 `shape` 声明：

```json
{
  "type": "directional",
  "direction": [0, -1, 0]
}
```

方向为单位向量，表示光线的传播方向。
节点的世界变换将本地方向转换到世界空间。
表面使用反方向作为入射光方向。
`color` 与 `intensity` 的乘积提供入射光强。

方向光的照明不依赖位置、半径与距离衰减配置。
灯光条目的半径仍须为合法正数。
未知类型、非有限方向与非单位方向均被拒绝。
局部灯及衰减模型见[距离衰减](local-light-attenuation.md)。

## 运行契约

方向光进入相机所有光照聚类。
灯光的稳定排序、数量预算与缓冲所有权保持有效。
GPU 数据仍为每灯 64 字节。
方向光通过类型编号二进入光栅与路径追踪。

光栅路径消费表面材质的漫反射与镜面响应。
场景局部灯及方向光均可评价双图脸部距离场。
光栅场景方向光的遮挡阴影属于待实现能力。
路径追踪使用无限距离的可见性射线。

`.azscene` 的当前版本为八，兼容版本一至七。
版本八保存灯光类型、方向、距离模型及指数。
版本一至七的衰减模型采用 `legacy` 默认值。
非法衰减编号和数值在读取时拒绝。

## 验证

聚类夹具覆盖远离相机且半径极小的方向光。
关卡与场景文档覆盖保存重开及默认值。
场景交换验证方向光身份与方向的保留。
公开 GPU 夹具验证位置无关及背光为零。

原生配置接入及证据范围见[方向光证据](../acceptance/nr/directional-lighting.md)。
