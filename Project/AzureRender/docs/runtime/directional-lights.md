# 场景方向光

阶段索引为 NR3。
方向光属于场景灯光契约，由渲染器消费。
室外日光与室内环境主光共享此能力。
场景文档、关卡及场景交换均可保存方向光。

## 配置

关卡的灯光通过 `shape` 声明：

```json
{
  "type": "directional",
  "direction": [0, -1, 0]
}
```

方向为单位向量，表示光线的传播方向。
节点的世界变换将本地方向转换到世界空间。
表面使用反方向作为入射光方向。
`color` 与 `intensity` 的乘积提供入射光强。

方向光的照明不依赖位置、半径与距离衰减配置。
灯光条目的半径仍须为合法正数。
未知类型、非有限方向与非单位方向均被拒绝。
局部灯及衰减模型见[距离衰减](local-light-attenuation.md)。

## 运行契约

方向光进入相机所有光照聚类。
灯光的稳定排序、数量预算与缓冲所有权保持有效。
GPU 数据为每灯 128 字节，包含独立作用体积。
方向光通过类型编号二进入光栅与路径追踪。

光栅路径消费表面材质的漫反射与镜面响应。
场景局部灯及方向光均可评价双图脸部距离场。
显式场景照明为主方向光生成级联阴影。
主光按强度与线性颜色亮度的乘积选择。
相同乘积按灯光身份的字典序选择。
零强度、关闭及零亮度的灯光参与筛选时跳过。

主光方向驱动级联矩阵、接收偏移与遮挡评价。
每灯标记控制其阴影图绑定。
其他方向光按各自方向参与照明。
单个级联图由主方向光持有。
路径追踪使用无限距离的可见性射线。

`.azscene` 的当前版本为十，兼容版本一至九。
当前版本保存灯光形状、衰减及世界空间作用体积。
版本一至七的衰减模型采用 `legacy` 默认值。
非法衰减编号和数值在读取时拒绝。

## 验证

聚类夹具覆盖远离相机且半径极小的方向光。
关卡与场景文档覆盖保存重开及默认值。
场景交换验证方向光身份与方向的保留。
公开 GPU 夹具验证位置无关及背光为零。
`directional_shadow_lab.py` 验证实际几何遮挡。
夹具同时检查阴影区与无遮挡控制区域。

原生配置接入及证据范围见[方向光证据](../acceptance/nr/directional-lighting.md)。
