# 二维纹理容器交换

## 能力与入口

DDS 与 KTX2 使用公共图像资产操作。
文件筛选、格式发现与导出界面共用注册描述。
导出先预览设置和损失，再启动后台任务。
独立工具使用相同格式与事务接口。

| 容器 | 输入范围 | 输出设置 |
| --- | --- | --- |
| DDS | 二维 RGBA、BGRA 及受支持 BC | `rgba`、`bc1`、`bc3`、`bc5`、`bc7` |
| KTX2 | 二维 RGBA、受支持 BC 与 Basis | `rgba`、`basis` |

BC 输入覆盖 BC1、BC2、BC3、BC4、BC5 与 BC7。
Basis 输出采用 UASTC 编码与四线程预算。
立方体、数组及体纹理返回明确范围诊断。
具体支持状态以阶段夹具和设备证据为准。

## mip 与采样

解码结果显式保存每层尺寸与 RGBA 像素。
容器导出保留来源中的完整 mip 链。
普通图像转换为容器时保留已有基础层。
导出单幅图像时在损失计划中报告 mip 范围。

材料及 glTF 加载使用同一类型化契约。
颜色因子和材质参数逐层一致应用。
`generate` 使用容器提供的层级。
`none` 仅上传基础层。

颜色与数据采样语义由材质设置明确声明。
`filter` 选择缩小过滤，缺省放大过滤与其一致。
设置版本二通过 `magFilter` 独立声明放大过滤。
该字段取值为 `linear` 或 `nearest`。
版本二要求该字段，版本一使用关联过滤。

`mipFilter` 独立选择层级间的线性或最近邻过滤。
该字段缺省时跟随 `filter`。
`mipBias` 默认零，取值范围为负十六至十六。

采样偏移在 Vulkan 后端按设备上限钳制。
设备报告保存 `max_sampler_lod_bias`。
缓存身份包含有效的层级过滤及请求偏移。
非法数值在分配纹理资源前被拒绝。

容器交换保留 sRGB 或线性标记。
解压和格式转换保留 sRGB 的编码字节。
材质的 GPU 图像视图负责颜色解码。
Alpha 通道保持线性数值。
BC5 保存红、绿通道。
法线槽按这些通道重建正向 Z。

## glTF 采样器

普通及自发光材质按纹理绑定读取 glTF 采样器。
来源映射覆盖标准颜色、法线、粗糙度、自发光及遮蔽槽。
专用表面及查找表使用各自的采样契约。
同一图像的不同纹理绑定可声明不同采样器。

| `minFilter` | 缩小过滤 | 层级过滤 | mip 策略 |
| --- | --- | --- | --- |
| 9728 | 最近邻 | 最近邻 | 基础层 |
| 9729 | 线性 | 最近邻 | 基础层 |
| 9984 | 最近邻 | 最近邻 | 完整层级 |
| 9985 | 线性 | 最近邻 | 完整层级 |
| 9986 | 最近邻 | 线性 | 完整层级 |
| 9987 | 线性 | 线性 | 完整层级 |

`magFilter` 的 9728 和 9729 分别对应最近邻及线性。
寻址 10497、33071、33648 分别对应重复、钳制及镜像。
缺省采样器保留材质默认设置。
非法索引及过滤枚举返回加载诊断。

图像元数据按显式字段覆盖来源设置。
仅声明 `mipBias` 时，其余采样参数保留来源值。
版本一的 `filter` 同时控制缩小及放大过滤。
版本二使用 `filter` 和必填的 `magFilter` 分别控制。

枚举依据 [glTF 采样器规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#samplers)。

运行时将压缩输入转换为有预算的 RGBA 链。
材料因子在上传前作用于该链。
Vulkan 查询采样、过滤及传输目标能力。
设备能力不足时返回受控诊断。

## 预算与失败

来源与编码输出各限制为 64 MiB。
宽高分别限制为一至 8192。
解码 mip 总像素限制为 256 MiB。
层级数量按基础尺寸校验。

损坏头部、层偏移和截断数据返回诊断。
BC 编码在工作回调中检查取消。
Basis 任务在库调用边界检查取消。
取消或来源变化按资产事务清理暂存。
