# 二维纹理容器交换

## 能力与入口

DDS 与 KTX2 使用公共图像资产操作。
文件筛选、格式发现与导出界面共用注册描述。
导出先预览设置和损失，再启动后台任务。
独立工具使用相同格式与事务接口。

| 容器 | 输入范围 | 输出设置 |
| --- | --- | --- |
| DDS | 二维 RGBA、BGRA 及受支持 BC | `rgba`、`bc1`、`bc3`、`bc5`、`bc7` |
| KTX2 | 二维 RGBA、受支持 BC 与 Basis | `rgba`、`basis` |

BC 输入覆盖 BC1、BC2、BC3、BC4、BC5 与 BC7。
Basis 输出采用 UASTC 编码与四线程预算。
立方体、数组及体纹理返回明确范围诊断。
具体支持状态以阶段夹具和设备证据为准。

## mip 与采样

解码结果显式保存每层尺寸与 RGBA 像素。
容器导出保留来源中的完整 mip 链。
普通图像转换为容器时保留已有基础层。
导出单幅图像时在损失计划中报告 mip 范围。

材料及 glTF 加载使用同一类型化契约。
颜色因子和材质参数逐层一致应用。
`generate` 使用容器提供的层级。
`none` 仅上传基础层。

颜色与数据采样语义由材质设置明确声明。
容器交换保留 sRGB 或线性标记。
解压和格式转换保留 sRGB 的编码字节。
材质的 GPU 图像视图负责颜色解码。
Alpha 通道保持线性数值。
BC5 保存红、绿通道。
法线槽按这些通道重建正向 Z。

运行时将压缩输入转换为有预算的 RGBA 链。
材料因子在上传前作用于该链。
Vulkan 查询采样、过滤及传输目标能力。
设备能力不足时返回受控诊断。

## 预算与失败

来源与编码输出各限制为 64 MiB。
宽高分别限制为一至 8192。
解码 mip 总像素限制为 256 MiB。
层级数量按基础尺寸校验。

损坏头部、层偏移和截断数据返回诊断。
BC 编码在工作回调中检查取消。
Basis 任务在库调用边界检查取消。
取消或来源变化按资产事务清理暂存。
