# 窗口表面生命周期

平台层通过 `waitForDrawableSurface` 等待有效表面。
宽度和高度均为正值时，等待立即完成。
零尺寸通常对应窗口最小化状态。
窗口关闭时返回失败，由宿主继续关闭流程。

## 等待与服务

宿主可以提供等待回调。
回调在宿主线程执行，返回真值表示继续等待。
返回假值表示宿主已有终止条件。
省略回调时只处理窗口事件。

每次窗口事件等待最多持续 50 毫秒。
`GlfwFrontend` 通过定时事件入口执行等待。
窗口事件可以提前唤醒宿主。
恢复与原生关闭事件均通过该入口处理。

编辑宿主在回调中轮询生产验证服务。
同一回调还轮询编辑任务和文档关闭状态。
查询、请求期限与就绪任务可以继续处理。
文档关闭就绪时，回调终止等待。

## 帧与资源

等待期间保持当前帧号。
帧等待请求依赖真实帧推进完成。
请求的墙钟期限继续生效。
游戏仿真与渲染提交在有效表面恢复后继续。

宿主将实际等待时间计入暂停偏移。
上一帧时间原点同步平移相同长度。
恢复后的实时步长保留正常帧间时间。
固定步长模式继续使用配置的仿真步长。

编辑任务通过生产事务提交文档。
资源重载请求由渲染主流程消费。
GPU 退役和交换链重建在表面有效后执行。
表面等待本身只拥有事件与服务轮询。

## 验证入口

`AzureRender.SurfaceLifecycle` 验证等待契约。
用例组合真实验证服务和编辑任务服务。
`AzureEngine.Observation` 覆盖协议与请求期限。
实际窗口、交换链与仿真恢复另行执行设备验收。

CPU 结果见[表面等待验收](../acceptance/nr/surface-idle-services.md)。
