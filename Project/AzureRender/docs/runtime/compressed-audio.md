# 压缩音频导入与交换

音频注册支持 Opus、AAC 与 M4A 输入。
公共导出支持 Ogg Opus 与 MP3。
编辑器和独立交换工具共用格式服务。
音源组件通过资产标识加载声音。

## 输入与播放

Opus 使用 libopusfile 解码单段 Ogg 流。
有效帧由 pre-skip 和最终 granule 确定。
输入支持一至八声道，解码采样率为 48000 Hz。
页范围、校验和及结束页经过完整校验。

AAC/M4A 使用 Windows Media Foundation。
系统服务读取 ADTS 或 MP4 音频容器。
完整解码扫描取得实际可读的 PCM 帧数。
容器编码填充保留在实际解码时长中。

验收夹具的作者输入为 48000 帧。
AAC/M4A 解码结果为 48128 帧。
该差异属于夹具的编码填充。
输入摘要如实记录解码帧数。

短声音在 256 MiB 预算内预解码。
超过三十秒的声音采用流式数据源。
公共读取器每次读取至多 4096 帧。
读取可返回部分帧，调用者按返回值推进。

读取器独立持有解码状态。
调用者串行执行读取及定位。
Opus 使用 PCM 定位接口。
平台解码器重开后按帧跳过，保持精确定位。

## 导出设置

`bitrate` 的单位为每秒位数。
默认比特率为 128000。
`channels` 的零值保留来源声道数。
Opus 与 MP3 输出支持单声道及立体声。

Opus 输出固定为 48000 Hz。
比特率范围为 6000 至 512000。
编码使用每包 960 帧与复杂度八。
来源采样率通过公共采样转换适配。

MP3 使用 LAME 3.100 动态库。
输出采用固定比特率与质量二。
采样率和比特率必须组成受支持的组合。
编码器实际规格与请求规格经过核对。

编码摘要记录延迟、填充及有效帧数。
有损编码、标签及幅度归一进入损失报告。
原生输入及编码输出各限制为 128 MiB。
取消通过块检查及资产事务清理暂存输出。
