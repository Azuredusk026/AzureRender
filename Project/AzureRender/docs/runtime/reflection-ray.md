# 反射射线生产

`ReflectionRayGpu` 从场景快照生成基础反射信号。
输入借用完整表面快照及线性 HDR 场景颜色。
两份输入采用相同的完整分辨率。
输出尺寸可以等于输入，或为各轴整除二。
单像素轴继续保留一个像素。
输出借用信号层级资源提供的基础存储视图。
参数、描述符和计算管线由射线资源持有。

## 投影与参数

`ReflectionTraceView` 提供实际采样投影和世界到裁剪矩阵。
相机位置与正交基须对应相同视图。
世界法线及正线性深度沿表面快照契约读取。
半尺寸生产按输出中心选择完整分辨率样本。
深度、法线和粗糙度来自同一个选中像素。
世界位置按该源像素中心重建。
求交与命中颜色继续读取完整分辨率输入。
透视和正交投影分别使用实际逆尺度及偏移。

私有帧参数为十二行向量，共 192 字节。
各在途槽位持有独立参数和描述符。
相机公共布局由所属宿主持有。
投影、姿态、尺寸及射线参数在记录命令前校验。

射线参数沿 `ScreenSpaceReflectionSettings` 校验。
原始命中颜色采用深度选择的级内采样。
粗糙度空间过滤由后续信号层级及过滤资源执行。
颜色可输出线性 HDR 或最大分量压缩信号。

## 资源顺序

1. 准备场景输入的计算采样可见性。
2. 调用信号资源的 `beginBaseWrite`。
3. 调用射线资源的 `record` 写入基础信号。
4. 由信号资源生成层级并发布采样视图。
5. 过滤资源消费层级及可信度，产生合成输入。

输入采用 `SHADER_READ_ONLY_OPTIMAL`。
两份基础输出采用 `GENERAL`，布局由信号所有者管理。
输出格式须与创建射线管线时的格式一致。
借用输入与基础输出视图须保持互不别名。

紧凑格式为 `R11G11B10_FLOAT` 和 `R8_UNORM`。
浮点格式为 `RGBA32F` 和 `R32F`。
宽高各限制为一至 8192，在途槽位为一至八。
全部消费者完成后，宿主才能复用或销毁槽位。

## 验证范围

独立镜面夹具覆盖透视、正交、滚转和投影偏移。
移动遮挡与禁用槽位分别核对命中及可信度。
原版层级、动态场景及连续历史具有独立验收。
完整还原与主场景性能保持 NR5 的联合门禁。
