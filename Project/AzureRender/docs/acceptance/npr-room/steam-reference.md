# Steam 参考版本

> 移植基线为 Recovery Windows 1.17.3。
> Steam 1.18.1 用于核对平台流程和新增内容。

Steam 安装版的应用编号为 `3548580`。
本机 Steam 构建编号为 `26586283`。
其程序使用 Unity `2022.3.62f2`。
[版本清单](steam-reference.json)登记本机程序集和资源目录摘要。

## 本机内容范围

| 项目 | Recovery 1.17.3 | Steam 1.18.1 |
| --- | --- | --- |
| Addressables 键 | 3,687 | 3,713 |
| 加载位置 | 1,845 | 1,858 |
| 内部路径 | 1,832 | 1,845 |

1.18.1 包含生日与万圣节相关语音和一首音乐。
两版各有独立的音频、语音及主数据资源包身份。
剧情读取涉及生日事件条件和收尾参数。
新版内容随实际版本单独登记验收范围。

## 平台程序核对

REA 6.4.0 核验 Steam 主程序集的托管格式。
程序集对照达到工具表示预算。
全程序集成员覆盖状态为部分。
工具入口见 [REA](https://github.com/morluto/rea)。

用本机 ILSpy 比较两版指定类型的反编译文本。
`SteamManager`、`LoginFlow` 和 `SaveDataSync` 的文本一致。
`SteamAchievements` 与 `PomodoroService` 的文本也一致。
`ScenarioReader` 有生日事件的差异。

程序比较支持选择 1.18.1 作为平台参照。
实际成就、云存档和账户验收仍需授权测试会话或实机证据。
游戏安装目录提供程序和资源来源。
真实服务结果按发生时的构建与身份登记。
