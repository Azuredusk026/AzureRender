## 实现范围

阴影比较与接收修正归属共享着色函数。
圆形过滤对覆盖纹素逐一积分。
接触足迹按级联纹素密度缩放。
曲率限制接收平面的外推范围。

阴影图集为 4096×4096，包含四个级联。
每级联为 2048×2048，接触半径为六纹素。
半径受现有最大过滤半径配置限制。
主光、环境和相机使用固定展示输入。

普通表面、衣料与金属采用 GGX 高光。
源介质参数 0.5 对应 4% 的法向反射率。
主光与局部光各自提供颜色和强度。
展示调色的黑位为零，饱和度为 0.98。

身体与脸部色阶的亮部保留暖色。
间接光混合半量归一化色阶色度。
隔离的受光肩部红蓝差达到 8.1094/255。
色阶测试门槛为至少 8/255。

## 视频交付

长视频为 2560×1440、24 帧每秒与 80 秒。
共 1920 帧，采用 H.264 High 与 BT.709。
每段为 384 帧和 16 秒的完整旋转周期。
捕获采用横纵各二倍的超采样。

| 时间 | 内容 |
| --- | --- |
| 0 至 16 秒 | 原模型底色。 |
| 16 至 32 秒 | 最终渲染。 |
| 32 至 48 秒 | 材质分区。 |
| 48 至 64 秒 | 阴影可见度。 |
| 64 至 80 秒 | 世界法线。 |

视频的文字、HUD 与音轨均为关闭状态。
所有段落使用相同镜头和旋转相位。
展示输入采用晚霞环境与固定主光。
完整解码与段首帧顺序检查均通过。

视频路径位于本机证据目录。
文件名为 `laevatain-five-views-1440p24.mp4`。
规格、SHA256 与输入见专项证据清单。

## 性能测量方法

性能采样分别覆盖 1280×720 与 2560×1440。
每组记录 180 帧，剔除前 30 帧。
统计保留的 150 个 GPU 时间戳区间。
捕获与原生窗口具有独立测量记录。

捕获模式采用隐藏的无装饰窗口。
原生测量核对窗口客户区的准确尺寸。
时间戳区间包含提交与窗口调度的影响。
PNG 的 CPU 编码和写盘位于测量区间之外。

| 模式 | 尺寸 | GPU 均值 | GPU P95 |
| --- | --- | --- | --- |
| 原生窗口 | 1280×720 | 10.76 ms | 11.64 ms |
| 原生窗口 | 2560×1440 | 27.11 ms | 29.66 ms |
| 隐藏捕获 | 1280×720 | 60.21 ms | 70.38 ms |
| 隐藏捕获 | 2560×1440 | 77.29 ms | 94.65 ms |

原生窗口通过无装饰客户区获得准确尺寸。
隐藏捕获的时间戳区间存在额外调度开销。
调度差异的驱动层原因仍待独立核实。
当前 1440p 角色的 GPU 开销仍较高。

离线二倍横纵超采样的 GPU 均值约为 84 ms。
五段的设备本地内存峰值均为 1.90 GiB。
该质量档用于逐帧视频输出。

设备本地内存峰值为 0.85 GiB 与 1.07 GiB。
该测量不能直接解释为端到端应用帧率。
样本与输入保存于性能证据文件。

验收清单见[专项证据](evidence/refinement/manifest.json)。
回归范围包含本机既有的 P4 原生输入测试。
