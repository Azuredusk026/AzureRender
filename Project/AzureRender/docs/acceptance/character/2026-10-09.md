## 实现范围

材质导入、叠层、阴影与采样使用公共机制。
角色实例参数由派生资产保存。
实时质量为边缘自适应过滤。
交付质量为横纵各二倍的超采样。

外描边基准为输出图像的 0.8 像素。
内描边采用几何法线与线性相对深度。
AO 作用于间接光，混合金属遮罩保持独立。
头发曲线、方向偏移与视角偏移分别保存。

## 构建与设备

构建配置为 MSVC Release 与 Debug。
实际设备为 NVIDIA RTX 4060 Laptop。

完整回归使用本机工作区与现有 P4 验收入口。
原生回放的增量修正保存在独立补丁中。
Debug 启用 Vulkan 验证，白块捕获无验证错误。
卸载后缓冲与图像计数均为零。

实时性能使用 180 帧的独立采样。
统计剔除前 30 帧，保留 150 帧。
720p 的 GPU 平均值为 3.49 ms，P95 为 3.82 ms。
1440p 的平均值为 7.96 ms，P95 为 8.11 ms。

设备本地内存峰值分别为 0.81 与 1.03 GiB。
纹理准备、上传同步与 IBL 合计约 2.28 秒。
该值包含 CPU 纹理层级生成及共享纹理准备。
详细输入见[实时性能](evidence/performance-edge.json)。

本机原始证据位于 `captures/character/repair-20261009`。
派生资产保存源文件、生成器与输出哈希。
公开回归使用 `assets_public` 夹具。

## 复核入口

图像测量与视频编码使用独立的 Python 工具。
已验证的依赖见 `tools/requirements-character-qa.txt`。
冻结标注保存在 `evidence/annotations`。

```powershell
python -m pip install -r tools/requirements-character-qa.txt
python tools/test_character_temporal.py --executable <程序> --asset <资产> --output <空目录> --annotations docs/acceptance/character/evidence/annotations/temporal.json
python tools/test_character_finish.py --executable <程序> --asset <资产> --output <空目录> --annotations docs/acceptance/character/evidence/annotations/appearance.json
python tools/render_character_delivery.py --executable <程序> --asset <资产> --output <空目录>
```

命令从 AzureRender 项目目录执行。
输入资产采用具有来源清单的派生 glTF。
交付工具核验渲染尺寸、输入哈希与视频容器。

## 视频交付

输出为 2560×1440、24 帧每秒、384 帧与 16 秒。
编码为 H.264 High、8 位 yuv420p 与 BT.709。
参数为 CRF 15、`slow` 预设及无音轨。
视频约为 12.80 MiB，完整解码检查通过。

场景内部尺寸为 5120×2880。
GPU 平均耗时为 75.02 ms，P95 为 79.59 ms。
设备本地内存峰值为 1.86 GiB。
该质量档用于离线渲染，实时档使用独立预算。

捕获耗时约 141 秒，首帧 PNG 约在启动后 5.09 秒生成。
首帧时间包含资产加载、纹理准备、IBL 和捕获。
GPU 计时文件中的 `sceneWidth` 表示逻辑输出尺寸。
内部尺寸以捕获清单的 `sceneRenderWidth` 为准。

384 帧的头发与服装局部已逐帧检查。
整帧复核覆盖第 0、96、192、288 与 383 帧。
正面额发及服装细节另有原尺寸裁剪。
检查范围与页面哈希见[视觉复核](evidence/video-review.json)。

视频及原始帧位于本机捕获目录的 `delivery-final`。
清单包含资产、程序、着色器、源码和逐帧哈希。
详见[交付清单](evidence/delivery.json)与[离线性能](evidence/performance-delivery.json)。
