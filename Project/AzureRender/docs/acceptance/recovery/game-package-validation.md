## 校验预算

完整项目在原六十秒预算下触发实际超时。

发布工具为每次 Player 检查声明秒数预算。
默认值为 1800，合法范围为大于零且至多 3600。

参数接受有限实数，非法类型与范围触发明确拒绝。
命令行为 `--validation-timeout`。
Python 接口使用 `validation_timeout` 关键字。
源项目与候选包使用同一预算完成全部资源检查。

自定义验证器继续使用现有两个参数的契约。
校验超时由既有目录事务处理候选清理及包保留。
离线校验预算、资产合法性及运行性能分别验收。
