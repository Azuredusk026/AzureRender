# 目录维护技能验收

## 交付范围

本机部署 `azurerender-artifact-maintenance` 技能。
[技能源](../../../tools/skills/azurerender-artifact-maintenance/SKILL.md)
及后端工具由项目版本管理。
项目产物与恢复包保持在项目目录。

本单元属于开发工具，运行时源码及着色器保持原输入。
CPU、GPU、画质和长跑标准继续按所属任务验收。
主开发的性能诊断保留在原任务目录。

## 空间原因

当前有四百零七个历史任务尚在原保留体系中。
一百二十个任务根保留标记继续登记用途。
同一任务的多个工程副本分别产生完整资产缓存。
原始扫描的单任务上限不能代表历史目录的累计占用。

`AssetDatabase` 的 `AZCACHE1` 包含二十四字节头及原始文件字节。
大型参考任务中实测有 38791 份此类缓存，约 90.97 GiB。
这些生成副本可通过仍保留的原始资产证明冗余。
正式原始证据及当前实际输入按各自用途保留。

## 每日规则

| 内容 | 规则 |
| --- | --- |
| 普通受管任务 | 完成后保留一天 |
| 必要诊断 | 显式选择三天或七天 |
| 单任务 | 2 GiB、10000 个文件 |
| 受管任务池 | 累计预留 16 GiB |
| 精简证据 | 每任务 8 MiB、总池 2 GiB、保留三十天 |
| 显式必要恢复包 | 项目内 8 GiB 总池，释放后保留七天 |
| 日常状态 | 索引、卷余量及任务根标记，非递归 |
| 每日缓存清理 | 至多 10 GiB，使用缓存清单及源文件证明 |

普通生成产物到期直接回收。
精简证据保存源码、结果、命令、日志摘录和必要截图。
完整恢复包仅适用于显式声明的必要唯一输入。
当前基准、正式长期证据和未提交源码保持所属保留规则。

每日维护最多处理十个受管任务，预算一百二十秒。
外部前台程序通过每秒检查的预算监控运行。
监控是采样保护，文件系统硬配额独立配置。
活动构建、测试或采集期间延后维护。

## 检查与调度

四十三项工具检查通过。
范围覆盖恢复、直接回收、证据期限、累计预算、进程监控，
以及 Git、链接、嵌套工作树、路径边界和并发生命周期。
独立情境检查发现的并发与路径问题已有修正和回归。

一千七百二十九项当前工程输入摘要一致。
一千四百五十八项主构建产物摘要一致。
一千零七十七项运行时输入及历史工作树三十三项源码一致。
用户差异摘要保持原值。

轻量查询在验收核对中用时约 0.17 秒。
本单元没有运行 C++ 重建、GPU 验证或性能测试。
本机调度配置为每天北京时间十点，成功维护只保留收据。
通知设置为 `failed_runs_only`，实际定时触发尚未观察。
