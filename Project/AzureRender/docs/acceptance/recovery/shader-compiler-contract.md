## 问题复现

实际 CMake 清单包含二百一十项 GLSL 程序。
红测快照检查返回 `Invalid shader reload configuration`。
红测程序的数量校验上限为一百二十八项。
失败记录采用实际生成描述及生产快照函数。

逐程序编译配置的红测还触发缺失成员编译失败。
验证目标为编译器、独立参数及输出选项三个字段。
完整清单当前包含二百一十一项程序。
容量检查覆盖五百一十二项接收及五百一十三项拒绝。

## 混合编译

独立夹具读取版本一的完整生成清单。
随后通过同一生产接口编译 GLSL 和 HLSL。
两个真实输出均为有效 SPIR-V 文件。
HLSL 通过逐程序编译器、宏及 `-Fo` 输出。

参数、编译器路径及输出选项的变化均改变指纹。
参数项数、字符长度及非法输出选项按契约拒绝。
源和元数据预算保持独立检查。
参数通过进程数组执行。

## 失败与来源

非法 HLSL 编译保留已接受候选的完整字节。
合法源恢复后继续产生可接受候选。
取消以及缺失逐程序编译器均提供预期状态。
现有共享依赖、活动候选及文件锁退休用例共同回归。

实际投影程序通过完整源快照和生成参数编译。
其 91,480 字节与正式构建逐字节一致。
输出 SHA-256 为 `05e89a2b970ea2f162bbc03b35c40d85382201f2701d29c5c2d119de8cc88017`。
该程序的 GPU 数值来源见[组合验证](../nr/projected-reflection-composition.md)。

## 配置与宿主范围

Debug 和 Release 的编辑宿主及 Player 构建通过。
两种配置各通过五项编译、进程和模块检查。
六份实际 GLSL、HLSL 及投影输出通过 `spirv-val`。
目标环境为 Vulkan 1.1。

Release 的探索和检查项目各完成一百四十一次操作。
完整清单的恢复等待分别为 30.691 秒和 30.378 秒。
两组均通过失败保留、恢复、取消及正常卸载。
实际日志显示验证层关闭，实体键鼠未执行。

Debug 完整编辑回归在资产缩略图刷新处超时。
二十五帧请求的期限为十秒，实际返回 11.939 秒。
该次运行尚未到达着色重载控制，失败现场已保留。

同一时段的五次预览管线创建累计 11.039 秒。
完整源快照的三次 Debug 测量为 34.796 至 39.083 毫秒。
该诊断聚焦预览重建复用，具体修复继续定位。
负责人及重试条件见[环境待项](../p8/2026-10-31-environment.md)。
