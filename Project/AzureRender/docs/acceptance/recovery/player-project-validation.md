# Player 项目资产校验诊断

日期：2026-10-31。
范围为 `--check-project` 的逐项资产校验。
入口位于 `src/player/main.cpp`。
项目、加载器及材质格式保持现行契约。

## 错误上下文

校验覆盖资产库登记的关卡与模型。
单项异常由 Player 附加资产完整路径。
诊断同时保留加载器的原始错误文字。
有效项目继续执行全部登记资产检查。

形态目标与默认权重数量失配触发拒绝。
诊断示例为 `Project asset '<path>': Morph default weight count mismatch`。
路径标明产生错误的资产，调用方据此核对引用及来源。

## 真实来源与夹具

完整场景的项目检查发现一份未引用烘焙探针。
该探针的眉毛节点保留两个权重，形态目标数量为零。
任务副本与元数据按摘要保留在挂载外的诊断目录。
原始备份按既有指纹保留。

公开夹具通过实际 Player 生成同类权重失配。
测试同时要求文件名及原始错误出现在诊断中。
夹具修复权重后，通过同一完整校验入口。
实际项目与公开项目共同覆盖该诊断机制。
