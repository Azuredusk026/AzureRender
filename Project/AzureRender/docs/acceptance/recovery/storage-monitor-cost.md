# 前台空间监控开销

## 范围与实现

本单元入口为 `794aad1`。
受管运行器保持每秒的任务配额与期限检查。
每轮预算检查采用一次任务遍历。
根路径及祖先在扫描边界集中核验。

子项读取不跟随链接的即时文件属性。
接受结果前复核已访问目录及根目录身份。
目录链接、嵌套 Git 及权限错误进入失败路径。
临时文件自然消失沿用现行处理规则。

即时查询避免依赖目录条目的缓存属性。
相关语义见 [Python 文件属性说明](https://docs.python.org/3.11/library/os.html#os.DirEntry.stat)。
每日保留、清理配额及卷余量按现行规则执行。
本机技能通过项目工具使用该实现。

## 局部基准

真实目录为已封存的深度复用任务。
目录包含 110 个文件，逻辑内容为 44682954 字节。
每种实现执行三次只读扫描，表内采用中位值。
两组字节统计完全相同。

| 指标 | 参考实现 | 最终实现 |
| --- | ---: | ---: |
| 单次扫描墙钟时间 | 143.346 毫秒 | 21.574 毫秒 |
| 单次扫描 CPU 时间 | 140.625 毫秒 | 31.250 毫秒 |
| 分析器记录的文件状态查询 | 4163 次 | 225 次 |

扫描墙钟中位值减少约 84.95%。
CPU 时钟具有本机计时粒度，原始样本分别保存。
该结果只说明目录扫描的局部成本。
主程序帧时间保持独立的验收范围。

监控夹具另使用一百个空文件和三秒子进程。
监控父进程 CPU 从 1.375 秒降至 0.250 秒。
该夹具的父进程 CPU 耗时减少约 81.82%。
任务完成、退出码、临时目录及采样周期均符合契约。
