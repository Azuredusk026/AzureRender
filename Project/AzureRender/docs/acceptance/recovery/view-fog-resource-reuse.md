# 视图雾资源复用验证

日期：2026-11-01。
状态：资源身份、重开复用及受影响检查通过。
联合画质继续按[开发总计划](../../plans/azure-engine-plan.md)验收。

## 资源契约

运行时将完整的解析后雾绑定写入资源键。
绑定包含启停、捕获机位、投影及解析雾参数。
体积资产内容继续通过文件摘要参与身份。
渲染器复用时核对相同的完整绑定。

渲染器持有加载时的绑定与体积资源。
每帧更新当前相机、视口及槽位参数。
同配置重开复用实例，并重置时间与运动历史。
绑定变化时，宿主准备对应资源实例。

公共机制由运行时及渲染模块持有。
具体机位和体积由项目数据声明。
解析雾、捕获式雾和完整原生项目共同验证契约。
执行范围见[实施计划](../../plans/2026-11-01-view-fog-resource-reuse.md)。

## 失败与复测证据

资源键检查保存了捕获机位变化的失败记录。
公开驻留检查保存了同绑定重开产生两个实例的记录。
时间重建模式下也复现了重复准备。
最终检查保留这些失败与对应复测证据。

捕获机位、投影相位、偏移和启停均覆盖身份检查。
体积内容及解析参数的既有检查继续执行。
相同绑定保持一个实例，变化绑定进入独立身份。
缓存驱逐与最终卸载分别核对资源上限及归零。

首轮复测遇到一次工具读取超时。
管线冷准备耗时约 12.39 秒，随后正常提交并释放。
驻留工具将单次读取期限绑定到剩余转场期限。
转场仍限 45 秒，进程仍限 300 秒。

默认协议读取行为保持现行契约。
两配置的实际协议探针分别通过兼容检查。
夹具版本错误、读取超时及最终复测均保留日志。

## 两配置检查

Release 与 Debug 各通过十一项相关 CPU 检查。
各配置执行四种公开工作流及 32 次转场。
覆盖解析雾、捕获式雾、平台玩法及场景检视。
含雾工作流使用时间重建模式。

两配置各完成完整项目的 540 帧操控路线。
每帧均与对应配置的冻结基准逐像素一致。
每条路线包含十三项输入及同关卡重开。
角色移动、动画、相机、失焦及出生恢复检查通过。

每条完整路线仅记录一次渲染器 CPU 准备。
加载、重开及采帧的总耗时受缓存状态影响。
准备次数用于判断本项复用效果。
正式持续帧时按所属性能阶段验收。

固定全景另外完成十二帧采集。
全部与材质显示阶段的冻结基准逐像素一致。
本项实际保留 1092 帧图像的摘要。
十一组成功 GPU 进程的资源卸载均归零。

成功运行的结构化日志及标准输出均完成检查。
