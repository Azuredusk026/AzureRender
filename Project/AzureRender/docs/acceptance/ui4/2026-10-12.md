# 项目制作与独立游戏交付验证

本阶段验证安装版引擎的完整制作流程。
平台为 Windows x64，发布配置为 Release。
输入通过生产 ImGui 队列，操作调用生产服务。
实体操作按独立待项记录。

## 完整制作流程

`tools/test_gui_delivery_flow.py --replay` 完成以下步骤。

1. 无参数启动安装版编辑器，进入项目中心。
2. 从 GUI 创建 C 盘中文与空格目录中的 Monica。
3. 编辑对象的中文名称，保存并关闭程序。
4. 再次启动，从最近项目打开 Monica。
5. 继续编辑，取消未保存关闭，再保存文档。
6. 从 GUI 发布到独立输出目录。
7. 移动发布目录，并移走原始工程。
8. 在隔离 PATH 下运行 `Monica.exe`。

游戏完成六十帧真实渲染，并输出运行报告。
PATH 仅保留 Windows 系统目录。
工程、安装树和输出目录分别位于独立位置。
源码目录与原始工程均非包运行的资源入口。

## 错误恢复

`tools/test_gui_project_recovery.py` 验证项目中心恢复。
失效最近项目保持可见，打开失败显示具体错误。
项目 API 99 被拒绝，随后仍可打开合法工程。
移动工程按身份更新最近记录，并去重保存。

中文用户配置目录、中文工程和空格路径通过。
未保存修改的关闭取消经过生产弹窗控件。
缺少包内 Player 时，原生游戏入口返回失败。
安装树附带 Python 可在隔离 PATH 下执行构建。
