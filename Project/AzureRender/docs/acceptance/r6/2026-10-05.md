# R6 场景可见性与裁剪验收

> 文档类型：验收记录
> 状态：通过
> 更新日期：2026-10-05
> 适用范围：Windows x64、Vulkan 与公开探索关卡

## 问题与实现

单面薄片的正面在错误绕序下完全消失。背面产生 39244 个表面像素。正确绕序使正面产生 39244 个像素，背面为零。

导入烘焙镜像时，立方体索引与法线方向相反。索引翻转后十二个三角形均朝外。运行时正负缩放按线性变换奇偶性选择管线。

硬编码的 100 米远裁剪使声明 500 米范围内的目标消失。关卡镜头字段与版本 8 场景保存通过往返和无效输入验收。主通道、视锥、聚簇与拾取共享镜头。

非均匀缩放的法线图像差异为 26.67 个色阶。镜像切线的光照差异为 34.67。逆转置与切线手性修复后，两项差异均为零。

## 专项验收

GPU 夹具覆盖正缩放、单轴与双轴镜像、导入镜像、双面和透明表面。混合批次、近远裁剪与视锥边界通过。近处绿色表面遮挡后提交的红色表面。

关闭背面剔除可显示背面，关闭深度测试可显示后提交表面。清单保存开关、镜头与状态哈希。正式通过捕获使用默认状态。

CPU 与 GPU 图像差异为零。蒙皮与顶点回退、多角色动画、阴影和固定描述符回归通过。每次专项捕获均无验证层错误，退出后缓冲与图像计数为零。

## 视觉参考

七张角色参考图使用外侧表面和对应轮廓。更新前保存原图、失败报告与逐图哈希。正面绕序证据与法线图确认了表面变化的原因。

严格容差保持零。默认、固定描述符与顶点蒙皮路径均通过七视图比较。黑洞参考与门禁保持现行值。

## 回归与性能

Debug 79 项、Release 81 项完整回归通过。发布门禁通过安装、移动、隔离运行与打包。文风与严格站点构建通过。
