# 程序化内容契约

> 文档类型：接口说明
> 适用范围：Windows、MSVC 与编辑宿主
> 阶段：G10，验收通过

## 模块与生命周期

`AzureProcedural` 拥有几何和刚体文本编译。
公共头文件暴露请求、结果与编译服务。
Manifold 3.5.2 属于模块实现依赖。
Player 通过标准 glTF 与动画图消费生成结果。

编辑宿主注入 `IGeometryCompiler`。
`GeometryProcessCompiler` 启动独立编译器。
每次请求拥有唯一候选目录。
退出、取消与失败均清理候选目录。

生产操作为 `asset.generate`。
生成来源记录输入、版本、许可和输出哈希。
候选成功后经资产数据库安装。
无效候选保留有效资产与来源文件。

编译服务同步返回结果，内部进程受期限控制。
Windows Job Object 管理进程退出。
生成资产以项目身份供预览和 `node.place` 使用。
放置时资源附加与节点创建属于一个撤销事务。

## 请求与预算

三个生成器的版本均为 1。

| 生成器 | 输出 | 用途 |
| --- | --- | --- |
| `azure.procedural` | `.gltf` | 参数化几何 |
| `azure.rig-text` | `.gltf` | 刚体骨骼与关键帧 |
| `azure.rig-animation-graph` | `.json` | 同源动作状态图 |

参数使用 `source` 或 `sourceReference`。
内联源与声明输入互斥。
引用源要求一个已声明输入。
依赖通过生成请求显式提供。

`values` 提供参数覆盖，`seed` 为非负整数。
刚体请求的 `scale` 范围为 `(0,10000]`。
预算字段均要求正整数。
调用方可在以下上限内缩小预算。

| 字段 | 默认与上限 |
| --- | --- |
| `schemaVersion` | 1 |
| `sourceBytes` | 2097152，含依赖文本 |
| `depth` | 64，含模块与依赖展开 |
| `triangles` | 1000000，含基础体展开与中间结果 |
| `timeoutMs` | 60000 |

内部节点上限为 16384，模块上限为 1024。
单个布尔节点的子项上限为 1024。
候选文件上限为 128 MiB。
嵌入网格缓冲区上限为 96 MiB。
提案另须满足 G9 的 2 MiB 内容预算。

## 受限源语义

源使用版本为 1 的 JSON 对象。
它是参数化几何的等价受限文本表达。
完整 SCAD 语言属于独立评估范围。
未知字段、递归、越界与退化结果返回诊断。

| 操作 | 专用字段 |
| --- | --- |
| `cube` | `size`、`center` |
| `sphere` | `radius`、`segments` |
| `cylinder` | `radius`、`height`、`segments`、`center` |
| `union`、`difference`、`intersection` | `children` |
| `module` | `name`、`arguments` |
| `mesh` | `vertices`、`triangles` |

所有操作接受 `scale`、`rotate` 与 `translate`。
变换依次执行缩放、旋转与平移。
旋转使用 XYZ 角度，球体默认 32 段。
分段范围为 4 至 256。

模块支持具名参数、范围与默认值。
数值表达支持 `parameter` 和 `random`。
固定种子复现相同输出字节。
布尔运算与输入网格要求闭合实体。

`coordinates` 可为 `engine` 或 `scad`。
SCAD 位置映射为 `[x,z,-y]`。
几何域的结果使用一个材质。
材质色、金属度与粗糙度进入标准 glTF。

## 刚体动作

骨骼使用唯一 `bone_` 名称。
父子层级要求单根与无环。
部件可分别声明几何、材质与初始变换。
每个顶点绑定一个骨骼，权重为 `[1,0,0,0]`。

动作使用唯一 `anim_` 名称。
通道包含 `pos`、`rot` 和 `scale`。
关键帧为 `[时间,三维值]`。
时间严格递增，范围为 0 至 3600 秒。

每通道最多 4096 个关键帧。
总关键帧上限为 65536，骨骼上限为 256。
最多 64 个动作，缩放始终为正。
动作变换语义为 `Lbind * T(delta) * R(delta) * S(delta)`。

输出包含逆绑定矩阵、skin 与标准动画。
旋转关键帧转换为四元数。
同源状态图声明循环与非循环播放。
多个 Animator 实例拥有独立播放时钟。

## 工作流与采用范围

探索项目生成建筑，检视项目生成道具。
两者共享源与参数契约。
文本部件和动作使用现有资产预览服务。
固定模型响应经领域校验和生产操作应用。

glTF 候选通过真实导入器验证。
嵌入候选的文件回调拒绝外部资源读取。
运行时仍使用既有 glTF 加载与动画机制。

纹理访问按实际设备容量与全部材质数选择。
固定材质路径保留完整的纹理与着色质量。
教程见[生成几何与刚体动作](../tutorials/procedural-content.md)。

当前二进制写出范围为 Windows 小端平台。
依赖版本的几何实现按串行配置构建。
实体键鼠复核按验收记录的实际范围报告。
