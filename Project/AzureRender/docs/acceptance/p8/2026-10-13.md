## 安装检查的退出码契约

图形进程启动后，检查器等待其完整退出。
版本及资源检查分别读取实际退出码。
非零退出码保留命令名称和具体数值。
隔离 PATH 期间仅保留 Windows 系统目录。

测试使用中文及空格目录中的图形进程。
成功、版本失败和资源失败分别验证。
实际安装入口另执行两条检查命令。
原始失败与修复记录保存在本批证据中。

## 历史原因的调查边界

三项归因继续使用原始失败记录。
内存追踪尚未复现原有工作集超限。
创建失败缺少当时的句柄与权限快照。
目录超时缺少资源加载步骤的分段记录。

成功复测证明当前路径可用。
历史原因的完成仍需失败现场证据。
