## 范围与环境

集成 Lua 5.4.8、sol2 3.5.0、实体环境与玩法回调。环境为 i9-13900HX、RTX 4060 Laptop、驱动 595.79、MSVC 14.44 和 Vulkan SDK 1.4.350。源码基准为 f8af584，接口见 [脚本与玩法](../../runtime/scripts-gameplay.md)。

## 契约与玩法闭环

反射读写、错误隔离、死循环预算、触发事件与初始化事务通过。语法、顶层修改和初始化错误均保留当前脚本。延迟删除在脚本对象释放后安全执行，失效句柄拒绝访问。

Lua 源变化保留场景版本、实体身份与 World。成功重载的脚本使用新代码更新属性。公开双关卡示例在实际 Vulkan Player 中贯通角色运动、触发传送、关卡切换与继续游玩。

Debug Player 运行 180 帧，报告 179 个固定步，第二关卡角色横坐标约 7.35。故障脚本单独禁用，其余脚本继续执行。日志无 Validation 错误，卸载缓冲与图像存活计数均为零。

## 回归与发布

Debug 与 Release 完整 CTest 各为 49/49，通过三场景、固定描述符、窗口恢复、物理和资产回归。Release 发布门禁通过。最终结果保存为 `evidence/2026-10-04/manifest.json`。

移动安装树中的独立 Player 运行公开玩法项目通过。Lua、sol2 与 Jolt 许可证完整，安装清单校验与发布包生成通过。完成状态文档同步后刷新安装清单与发布包，受测二进制保持同一哈希。

复现命令为 `ctest --test-dir build/ninja-msvc-debug --output-on-failure`。发布门禁使用 `cmake -DBUILD_DIR=build/ninja-msvc-release -P tools/run_release_gate.cmake`。门禁验证安装树移动、独立 Player、公开玩法项目、许可、清单与发布包。

## 性能与验收口径

黑洞电影档沿用 G0 的 1280×720、正面相机、每轮 300 帧与三轮中位数口径。每轮起始温度至多 55°C，整帧 GPU 中位数须严格低于 20 ms。复现工具为 `tools/measure_runtime_performance.py`。

三轮整帧 GPU 均值为 18.541475、18.851835 和 19.269886 ms。中位数为 **18.851835 ms**，通过 20 ms 门禁。起始温度分别为 51、53 和 55°C。

玩法模拟计时包含脚本、物理、输入和固定步操作。Player 的 `simulationMilliseconds` 是全部固定步的累计 CPU 时间，平均值按固定步次数计算。渲染 GPU 时间与玩法 CPU 时间分别记录。

Release 安装树的示例累计模拟耗时为 12.2184 ms，固定步数为 179。平均约 **0.0683 ms/固定步**，包含切关后物理初始化和错误隔离。此记录描述公开小场景的成本，实体规模由后续压力场景测量。

本阶段使用现行验收标准。热负载与近景性能边界见 [G0 验收](../g0/2026-10-03.md)，持续热负载的性能由独立条件记录。
