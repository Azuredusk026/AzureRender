# G13 独立模拟与物理制作验收

> 文档类型：阶段验收记录
> 状态：Complete
> 日期：2026-10-10
> 构建：Windows x64，MSVC 14.44，Debug 与 Release

## 交付范围

工具栏提供独立模拟、暂停、单步与停止。
模拟装配物理系统，并保留编辑相机。
右键漂浮、六向方向控件与辅助显示保持可用。
停止释放预览资源，并恢复编辑文档。

刚体支持盒、球、胶囊和静态三角网格。
形状工厂负责尺寸、缩放和模型合法性。
铰链描述包含端点、局部锚点、轴与角度限制。
约束与刚体资源由物理世界统一持有。

制作区通过公共属性与引用操作配置组件。
相关字段通过一次事务校验和写入。
领域校验由组件注册接入反射契约。
碰撞与铰链辅助由视口提供者注册。

摆臂与旋转门项目验证相同契约的不同用法。
两项目位于 `assets_public/physics_arm` 与 `physics_door`。
制作说明见[物理制作](../../runtime/physics-authoring.md)。

## 行为与失败验证

| 验证项 | 验证方式 |
| --- | --- |
| 独立装配与实际重力 | CPU 模拟世界与位置检查 |
| 暂停与单步 | 暂停保持步数，单步严格增加一次 |
| 停止与循环启停 | 文档内容保持，连续六轮释放与创建 |
| 启动失败保护 | 非刚体端点拒绝，文档、历史与设置附件保持 |
| 原子字段校验 | 非法轴拒绝并恢复历史 |
| 形状行为 | 球与胶囊落地，镜像网格射线命中 |
| 约束行为 | 摆臂锚定，门角度受限，端点删除释放约束 |
| 组件版本 | 版本 1 加载与编辑写入版本 2 |
| 实际 UI 制作 | 双项目形状选择、撤销与模拟工具栏 |
| 模拟输入归属 | 暂停时右键飞行，释放恢复正常光标 |
| GPU 生命周期 | 验证层诊断与退出资源计数 |

GPU 回放通过公共操作选择运动部件并构图。
暂停时移动编辑相机，物理步数保持不变。
形状编辑与撤销检查脏状态和撤销计数。
完整模拟过程校验编辑文档内容哈希。

## 验收结果

Debug 全目标与 Release 双宿主构建通过。
最新源码的 143 项非 GPU 回归全部通过。
十项受影响 GPU 回归通过。
其中六项基于最终重建的宿主运行。

摆臂与旋转门均有一个实际约束。
暂停后步数为 5，单步后为 6。
相机导航、停止恢复和形状制作检查通过。
证据见[清单](evidence/manifest.json)。

启动、UI 时序及构建文件锁失败记录一并保留。
对应修复与复测日志包含在证据清单中。
