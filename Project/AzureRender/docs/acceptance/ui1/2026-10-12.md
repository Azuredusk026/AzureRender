# 项目中心与启动验证

当前使用 ImGui 1.92.8 docking，后端为 GLFW 与 Vulkan。无参数启动显示项目中心，直接项目入口接受 `--project` 和单个项目路径。

项目中心复用项目创建、校验、打开和最近服务。创建和打开在后台执行，成功后初始化现有编辑器。中心阶段使用基础窗口和呈现资源，场景运行系统由编辑器阶段初始化。

Debug 编辑器及命令行、项目流程目标构建通过。命令行中文路径和项目流程两项检查通过。无参数窗口、原生关闭及 Vulkan 验证短检通过。

首次短检发现呈现信号量复用错误。实现按交换链图像选择完成信号量，修复复测通过。记录位于 `build/ui-productization-2026-10-12/ui1/`。

进入编辑器、制作发布和实体输入由集成阶段继续验证。启动中心与编辑器在同一进程顺序初始化，各自持有并释放窗口。
