# 地面网格深度修复记录

日期：2026-10-16。状态：完成。
范围为编辑态网格和世界 X/Z 坐标轴。
操作说明见[视口导航](../../runtime/viewport-navigation.md)。

## 显示规则与代码归属

网格位于世界 Y=0 平面，格距为一米。
范围固定为正负二十米，物体按场景深度遮挡网格。
位于物体前方的网格保持可见。
两种渲染模式共享相同的深度合成规则。

编辑器维护辅助显示策略和设计颜色。
宿主管理合成参数、逐图像缓冲及释放。
后处理着色器投影地面交点并比较场景深度。
相机、灯光与变换控件保留各自的辅助显示语义。

路径追踪输出像素中心首交点的投影深度。
首交点在重新累积的第一帧生成并复用。
光照累积继续使用随机子像素射线。
游戏视图与 Player 保持场景输出。

## 启动与复测

日常安装入口为：
`build/ux-2026-10-14/Engine/bin/AzureRender.exe`。
启动后打开项目，即可观察网格遮挡。

在引擎源码目录创建任务目录，再执行画面回归：

```powershell
python tools/artifact_cleanup.py --new-run grid-depth
python tools/test_grid_depth_gpu.py --executable build/ux-2026-10-14/Engine/bin/AzureRender.exe --output build/runs/<任务目录>/grid
```

每个用例比较网格开启和关闭的最终截图。
用例同时检查执行结果、错误日志与资源释放。
单元测试包含网格世界坐标稳定性与辅助显示策略。
