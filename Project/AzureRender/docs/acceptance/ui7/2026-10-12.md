# 场景视口迁移验证

视口绘制维护于独立的 `ViewportPanel.cpp`。
工具栏使用公共按钮、尺度和语义颜色。
相机、选择、变换和资源放置使用现有服务。
使用步骤见[场景视口指南](../../tutorials/viewport-workspace.md)。

## 实现与检查

投影按钮显示相机服务的实际状态。
无选择时，聚焦按钮按选择状态禁用。
工具栏按可用宽度换行，图像使用剩余空间。
窗口、导航捕获与 Vulkan 资源继续按既有契约管理。

| 检查 | 结果 |
| --- | --- |
| Release 受影响构建 | 编辑器与相机、工作区等目标通过 |
| CPU 回归 | 6 项通过，覆盖相机服务、手柄、覆盖层与工作区 |
| 投影与布局 | 两工程的普通、紧凑与 1.5 倍 DPI 共六组通过 |
| 相机导航 | 六方向、加速、滚轮、Esc、焦点与捕获恢复通过 |
| 完整工作区回放 | 8 组 DPI、焦点、布局恢复、拾取与三种手柄模式通过 |

投影回放分别切换正交与透视，并检查服务结果。
工具栏和图像边界依据实际面板位置校验。
运行检查 UI 错误、Vulkan 验证与资源释放。
输入来自生产 ImGui 队列，实体操作独立记录。
