# Windows 可玩包三十分钟长跑

## 标准探索包

2026-11-15 使用 NVIDIA 595.79 验证标准 Release 可玩包。测试采用独立 Player、1920 × 1080 视口和 60 Hz 帧率上限。场景包含 100 个实体、四个动画角色和八盏点光源。运行前后核对播放器和包清单摘要。构建收据记录的基点为 `9a14411`，受检源码摘要覆盖 `c2971a4` 的管线缓存保留实现。

空闲预检连续三次记录 GPU 占用为 0%。实测持续 1800.33 秒，记录 100,671 帧，完成 33 次切关、34 次重启和 67 次关卡提交。最小化、恢复、缩至 960 × 540 与恢复至 1920 × 1080 均通过。Player 正常退出，缓冲和图像计数归零，验证层、脚本、画面呈现和关卡加载错误均为零。

## 平台关可玩包

2026-11-16 使用 NVIDIA 595.79、同一 Release Player 和 1920 × 1080 视口验收平台关。包移动后从独立目录启动，工程源目录和引擎安装目录在实测期间隔离。空闲预检连续三次记录 GPU 占用为 0%。

调度批次 1266 实跑 1800.062 秒，记录 100,089 帧，完成 169 次切关、84 次重启和 253 次关卡提交。完成 84 趟平台路线，主路线收集八枚金币。路线记录包含 592 次必经落点、85 次起点坠落恢复、85 次检查点坠落恢复、85 次水平平台搭乘和 84 次垂直平台搭乘。
