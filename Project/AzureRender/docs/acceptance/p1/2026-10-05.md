## 独立包

公开包采用标准探索关卡。负载为 100 实体、四个动画角色和八灯。质量说明记录 1080p、四级阴影和完整材质。操作说明和质量配置进入不可变清单。

实际编辑器保存关卡并构建游戏。测试移动包至含空格路径，移走自建引擎与项目输入。隔离 PATH 后，包内 Player 完成收集、开门和目标任务。

完整任务路线为 940 帧、38 个输入，参考完成时间为 221 秒。任务报告验证三个收集物、开门、检查点和室内遮挡。两次重开恢复任务与对象状态，退出资源全部释放。

独立包包含 207 个不可变文件与 20 份第三方许可。公开角色和场景采用 CC0 测试资产。清单篡改探针修改操作说明，验证器按哈希拒绝该包。

循环任务执行 20 次切关与 20 次重开。40 次提交的额外耗时 P99 为 4.156 ms。提交帧 P99 为 13.872 ms。稳定驻留首尾相同，增长为零。

## 稳定性与设备

长跑以真实时钟计时，至少连续运行 1800 秒。测试检查最小化、恢复和尺寸变化。正常关闭窗口后检查资源释放。逐帧 GPU 数据与周期 CPU、驻留记录覆盖全过程。

实测连续运行 1800.531 秒，GPU 记录 760,259 帧。完成 253 次切关和 254 次重开，合计 507 次提交。最小化、恢复及两次尺寸变化通过。正常关闭后缓冲与图像全部释放。

GPU 全程 P95 为 1.539 ms，CPU 末段 P95 为 2.892 ms。物理单步 P95 为 0.461 ms。固定间隔 CPU P95 为 2.997 ms。每分钟 GPU 窗口均满足 16.6 ms 预算。

提交额外耗时 P99 为 4.402 ms。提交帧 P99 为 11.143 ms。工作集增长为 3.21%，缓冲数量范围为 49 至 51。活动图像与图像字节保持稳定，驻留增长均在 5% 以内。

周期 CPU 使用每 240 帧的固定间隔样本。提交记录单独检查 8 ms 与 33.3 ms 门禁。原始采样和复核源码分别记录指纹。复核核验运行时、包与原始数据哈希。

本机私有主角完成 940 帧、38 个输入的完整任务。参考完成时间为 221 秒，两次重开恢复状态。Validation 错误为零，退出资源全部释放。公开包用于分发，私有资产与媒体保留在本机。
