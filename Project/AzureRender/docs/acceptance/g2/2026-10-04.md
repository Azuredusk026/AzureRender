# G2 资产与关卡验收

> 文档类型：验收记录
> 状态：生效
> 更新日期：2026-10-04
> 适用范围：Windows MSVC Debug 与 Release

## 范围与环境

完成 UUID 资产数据库、依赖失效、版本化缓存、目录资源包、JSON 关卡与 Prefab 覆盖。环境沿用 G0 本机记录，源码基准为 754a021。接口见 [资产、关卡与 Prefab](../../runtime/assets-levels.md)。

## 契约与集成

资源和侧车共同移动后 UUID 保持稳定。损坏缓存可重建，依赖修改触发引用资源失效。循环依赖拒绝导入，候选导入失败后可读取有效缓存。

Prefab 实例覆盖可编辑、保存和重开，未知节点覆盖返回错误。目录资源包保留原引用目录结构，损坏条目和越界路径产生错误。

关卡切换先验证候选 World 与 GPU 准备回调。无效路径和准备失败保持当前 World。Vulkan Player 通过 JSON 关卡启动及损坏文件修复后的热重载，退出后缓冲与图像分配为零。

## 回归与证据

Debug 与 Release 完整 CTest 各 45/45 通过。覆盖既有视觉、生命周期与新增资产、关卡和 Player 集成。复现入口为 `ctest --test-dir build/ninja-msvc-debug --output-on-failure`，Release 使用对应目录。

构建与测试记录保存在 `evidence/2026-10-04/`，源码哈希按 LF 规范化。阶段提交标题为 `feat(g2): 完成资产数据库与关卡Prefab运行闭环`。

## 边界与来源

扫描与提交由主线程执行，资源观察间隔为 500 ms。成功热重载重新初始化关卡状态，GPU 缓存与渲染资源由 Render Core 管理。缓存指纹使用 FNV-1a，数据格式与事务代码由项目实现。
