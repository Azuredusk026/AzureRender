# U2 编辑器工作区与教程验收

> 文档类型：验收记录
> 状态：通过
> 更新日期：2026-10-05
> 适用范围：Windows、MSVC、RTX 4060 Laptop 与公开项目

## 工作区与显示

九个面板使用稳定身份，默认停靠覆盖制作、运行与构建。菜单、工具栏、创建区和状态栏提供对应入口。工具面板在标签页显示，关键操作无浮动遮挡。

1920×1080、1280×720 与三档 DPI 通过。各档视口至少为 480×270。动态 DPI 从基础样式计算，关闭、拖动、重开与恢复布局通过。损坏 JSON、停靠文件与未来版本恢复默认配置。

正文与辅助文字在面板上的对比度分别为 12.94 与 7.20。Noto CJK SC 提供中文输入与显示。sRGB 交换链中的面板像素为指定主题颜色。字体与 SIL OFL 1.1 许可进入安装树。

## 实际交互

UI 回放注入鼠标、文字与键盘事件，由 ImGui 处理命中。测试覆盖中文命名、保存重开、运行按钮与文字焦点。WASD、Delete、Ctrl+D、Ctrl+Z/Y/S 在文本框内保持场景状态。停靠拖动先悬停，再按下并移动标签。

三种 Gizmo 模式修改位置、旋转与缩放。操作柄按图像实际像素计算方向与位移。独立投影与截图像素检查覆盖六档显示，偏差小于 1 像素。视口点击真实网格后选中对应角色。

Content Browser 展示场景资源与资产数据库。脚本筛选读取实际 Lua 记录。目录、搜索和网格入口可用，制作操作按需展开。Console 提供等级、搜索、复制与节点定位。

实体键鼠复核需要可交互前台环境。本机缺少对应输入工具，报告保留该验证限制。生产命令与 ImGui 事件各自保存结果。界面截图已逐张检查。
