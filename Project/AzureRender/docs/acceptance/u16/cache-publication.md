> 日期：2026-10-11。

## 根因与边界

原始并行规划使用同一项目的缓存目录。
三个进程写入同名 `.tmp` 文件。
九次规划中五次发生缓存写入失败。
独立串行对照的三次规划通过。

独立暂存目录解决写入文件的所有权冲突。
Windows 发布同时涉及目标的删除访问。
既有缓存读取出现原生错误码 32。
该错误表示文件共享冲突。

持有删除访问句柄的用例稳定复现该错误。
缓存读取按共享删除规则打开完整文件。
同一指纹的完整获胜缓存由多个调用者复用。
内容一致性仍由完整缓存格式校验确定。

修改归属于 `AssetDatabase` 的缓存读写。
公共资产接口、指纹计算和格式保持兼容。
验证覆盖已有侧车的独立项目副本。
新侧车创建和并发源内容编辑各有所属契约。
