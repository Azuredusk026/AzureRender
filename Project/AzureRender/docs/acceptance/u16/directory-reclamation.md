## 实现契约

回收由 `ContentDirectoryModel` 拥有。
扫描取消仍等待自有扫描任务结束。
目录模型将缓存与快照所有权交给回收任务。
可见目录在重置时清空。

模型同时保留至多一个回收任务。
下一次移交前等待该任务完成。
模型关闭时等待所有自有任务结束。
回收任务仅持有缓存数据。

线程内局部变量负责释放最终所有权。
任务的调用对象在完成后保持空载荷。
外部持有的不可变快照保持有效。
文档和运行资产仍由原有服务拥有。

目录重建沿用相同的回收机制。
实现适用于游戏和机械检视制作项目。
全部后台任务均有可确定的关闭顺序。
取消耗时继续按一百毫秒验收。
