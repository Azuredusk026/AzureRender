# 原生输入与选择框验收

> 文档类型：独立测试修复验收
> 日期：2026-10-11
> 状态：两配置生产输入复核通过

## 输入契约

原生输入测试使用实际时钟。
单击与双击之间等待双击期限结束。
相对鼠标与 Browse 点击使用系统输入。
选择框打开前，测试取得编辑器实际前台。

窗口输入线程关联在取得前台后解除。
测试窗口使用独立项目与配置目录。
测试结束恢复原始系统光标位置。
实际执行期间需保持桌面输入独占。

## 实际结果

用户提供独占桌面后执行两配置复核。
Release 用时 14.73 秒，Debug 用时 23.98 秒。
探索与检视两工作流均通过原有断言。
测试属于系统注入，实体键鼠保持待复核。

覆盖单击选择、双击定位及 W/E/R/Q。
右键环视、漂浮、释放与失焦停止分别验证。
选择框验证取消、文件、目录与中文路径。
各操作均验证项目内容保持不变。

混用焦点消息与实际前台曾造成点击失败。
非独占输入期间的其他失败保留原始记录。
记录见[证据清单](native-input-evidence/manifest.json)。
完整 GPU 回归按当前来源继续执行。
