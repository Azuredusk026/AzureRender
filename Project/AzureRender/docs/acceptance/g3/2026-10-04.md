# G3 物理与输入验收

> 文档类型：验收记录
> 状态：生效
> 更新日期：2026-10-04
> 适用范围：Windows MSVC Debug 与 Release

## 范围与环境

集成 Jolt 5.6.0、60 Hz 固定步长、角色、刚体、查询、触发器和输入动作。环境沿用 G0 本机记录，源码基准为 e37ad07。接口见 [物理与输入](../../runtime/physics-input.md)。

## 契约与集成

角色落地、横向运动、跳跃和射线查询通过。触发事件使用窄相位形状查询，进入与退出通过。删除实体和切换关卡重建物理状态通过，暂停与单步符合固定步契约。

相同模拟时长使用不同渲染帧划分，固定步次数与角色位置一致。动作重复按键产生一个按下沿，失焦清空输入。Player 实际 Vulkan 运行 180 帧，角色落到地板，最终报告为 179 个固定步。

## 回归与证据

完整 Debug 与 Release CTest 各 47/47 通过。复现命令为 `ctest --test-dir build/ninja-msvc-debug --output-on-failure`，Release 使用对应目录。构建、测试及依赖元数据保存在 `evidence/2026-10-04/`。

阶段提交标题为 `feat(g3): 集成Jolt物理与固定步长输入运行时`。

## 来源与边界

Jolt 5.6.0 使用 MIT 许可证，通过 vcpkg 固定基线安装，许可进入发布目录。调用顺序参考上游 HelloWorld 和 CharacterVirtual 示例，适配仅使用公开 API。当前任务系统为单线程，容量与累计时间上限见运行时接口。
