# G1 反射与序列化验收

> 文档类型：验收记录
> 状态：生效
> 更新日期：2026-10-03
> 适用范围：Windows MSVC Debug 与 Release

## 范围与环境

完成 C++ 注解生成器、稳定类型标识、属性元数据和事务式 JSON 迁移。环境沿用 G0 本机记录，源码基准为 c8ff91e。接口见 [反射与序列化](../../runtime/reflection.md)。

## 契约与集成

生成器保持相同内容的输出时间戳。字段类型错误包含源码行列，重复类型返回失败，失败生成保留有效输出。类型名称映射为稳定的 FNV-1a 64 位标识。

组件存档往返、缺省字段、旧版本迁移、未来版本和未知字段拒绝通过。范围错误保留目标组件原值。Inspector 的变换标签、范围和字段访问使用生成元数据。

## 回归与证据

Debug 与 Release 完整 CTest 各 43/43 通过。覆盖既有 GPU 视觉、生命周期、Player 和新增反射契约，着色器算法保持现行实现。命令为 `cmake --build build/ninja-msvc-debug` 及 `ctest --test-dir build/ninja-msvc-debug --output-on-failure`，Release 使用对应目录。

构建和测试记录保存在 `evidence/2026-10-03/`，源码哈希统一 LF 后计算。阶段提交标题为 `feat(g1): 完成反射生成与版本化组件存档`。

## 边界与来源

解析范围为一个限定命名空间内的受注解结构体，支持五种当前组件字段类型。生成器使用标准库，Registry 使用 nlohmann/json。通用 C++ 语法扩展以新组件需求安排，G2 接入资产与 JSON 关卡。
