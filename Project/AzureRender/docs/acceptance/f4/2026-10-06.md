> 适用范围：Windows x64、编辑器、Player 与扩展宿主

## 来源与采用范围

本阶段落实 A1 的职责边界和 A2 的类型契约。依据为[gkNextEngine 架构评估](../../research/2026-10-06-gknextengine.md)。参考提交与文件哈希保存在研究清单中。实现采用本项目的 ECS、反射和宿主接口。

模块装配拥有启动与关闭回调。注册组件绑定元数据与 ECS 操作。两项能力均通过公共入口扩展。具体资产检视行为属于独立测试宿主。

## 装配与依赖

`ModuleAssembly` 验证模块 ID、版本和依赖图。启动按拓扑顺序执行，关闭按逆序执行。启动失败保留原始异常并记录模块 ID。关闭异常形成诊断，后续模块继续关闭。

模块图在启动时封存。重复关闭保持有效，启动仅执行一次。装配与生命周期操作由创建线程承担。回调捕获的服务在装配关闭前保持有效。

Player 装配世界与可选项目服务。编辑预览装配文档、世界和玩法服务。预览关闭依次释放脚本、玩法、表现与关卡。编辑文档在 Play/Stop 后保持有效。

依赖检查读取 CMake File API 的实际目标图。工具同时检查第一方 include 的传递关系。条件编译按目标的宏定义解析。第三方与生成文件按其归属处理。

夹具覆盖合法依赖、逆向引用与 include 环。Player 条件编译与无条件编辑器引用分别验证。公共组件值类型位于 `src/ecs/`。文件读取工具位于 `src/resources/`。

## 类型与生产消费者

`ComponentRegistry` 提供注册、安装、编码和移除。默认组件绑定由注解生成。属性描述包含分类、提示与访问权限。封存后查询集合保持稳定。

加载器、编辑器与 Lua 使用同一组件注册表。加载允许合法只读值，字段编辑检查写入权限。单字段校验与完整候选校验分别执行。迁移按版本契约处理。

外部组件夹具验证编辑、保存重开与 Lua 读写。独立 Vulkan 宿主通过静态注册安装资产检视组件。属性面板在选中外部组件时实际绘制。自动命令验证只读拒绝及预览恢复。

该路径验证真实宿主与生产编辑接口。实体键鼠操作按实际执行情况另行记录。公开测试资源来自 `assets_public/gameplay/`。私有动画保持本机范围。
