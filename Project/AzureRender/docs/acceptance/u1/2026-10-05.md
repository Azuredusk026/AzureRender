# U1 关卡制作与调试验收

> 文档类型：验收记录
> 状态：Complete
> 环境：Windows、MSVC 14.44、Vulkan SDK 1.4.350、RTX 4060 Laptop

## 制作流程

验收从空 JSON 关卡开始。编辑命令导入三个模型资源，配置 21 个节点。角色、相机、碰撞、动画和任务规则共用生产编辑接口。脚本、界面与 Prefab 作为可复用制作资源。

203 条命令覆盖配置、预览、Prefab、历史和构建。保存重开保持实体身份、资源与组件。Play 从编辑状态创建独立 World。Stop 恢复编辑状态与操作历史。

脚本运行故障由实体回调隔离。恢复源码后，八份脚本恢复运行。无效资源引用保留有效组件。调试叠加与语义动画预览在真实 Vulkan 编辑器绘制。

## 候选与历史

组件候选校验反射类型、数值范围和引用。动画图逐项检查语义状态与模型片段兼容。相机目标和上下界在提交前验证。角色和刚体通过独立节点持有物理对象。

Prefab 放置先解析完整候选，再提交编辑状态。历史保存场景、组件、来源和资源引用。重复实例和失败候选保留当前关卡。节点、灯光与覆盖随保存重开恢复。

导入准入反馈包含模型复杂度与动画片段。测试覆盖缺失依赖、取消和无效引用。碰撞叠加按运行时形状尺寸生成。脚本与交互诊断提供节点定位。

## 验证入口

`AzureEngine.EditorWorkflow` 验证命令和事务。`AzureEngine.EditorHost` 验证实际编辑宿主。`AzureEngine.EditorPlayable` 执行空关卡制作。Debug 75/75、Release 76/76 与发布门禁通过。

Release 编辑器完成独立 Player 构建。实际包执行 940 帧与 38 个输入动作。任务在 221 秒完成，随后连续重开两次。Validation 为零，退出时缓冲与图像全部释放。

移动安装树登记 254 个文件与 20 份许可。源码关联、清单和文档检查通过。构建机与验收设备为本机 Windows x64。额外设备验证按后续交付阶段登记。
