# 公共 UI 与项目界面验证

项目中心、项目面板与发布面板复用公共控件。
标题、卡片、任务反馈和结果信息使用统一主题。
项目中心提供中文文字、空项目引导与错误提示。

编辑器默认从安装位置填写引擎目录。
发布面板显示工具实际报告的阶段。
结果区域提供输出目录与构建日志入口。
失效项目通过文件选择重新定位。

属性面板优先显示对象身份、名称与可见状态。
工作区继续使用现有面板注册和停靠恢复。
Windows 编辑器采用 GUI 子系统入口。
用户配置与资源环境路径使用原生宽字符。

Debug 和 Release 的工作区与项目流检查通过。
工作区尺寸、停靠、文字和 DPI 回放通过。
完整 GUI 制作流程在交付阶段独立记录。

观察文件仅在显式配置后生成。
输入回放通过 ImGui 队列触发控件。
编辑器验证通道沿用回环地址与会话令牌。
自动回放和实体操作分别记录。
