## 契约与采用范围

RenderCore 定义重载接口与独立视图。
AzureDevtools 拥有快照、监听和后台编译。
Platform 管理受控进程组及总期限。
UI 与自动工具共享生产编辑操作。

开发操作由编辑会话注册。
宿主关闭时解绑服务回调。
同一会话支持后续宿主的重新挂接。
解绑后调用得到服务不可用诊断。

工具视图由创建它的调用方释放。
相机和缩略图句柄由所属服务管理。
通用释放入口校验调用方的所有权。

候选先加载，再等待 GPU 完成并提交。
编译和加载失败保留有效场景渲染器。
资源替换覆盖已注册的场景渲染器。
宿主合成、HUD 和 UI Pipeline 按构建加载。

每个次视图拥有相机、设置、历史和输出。
代次句柄在释放与服务重建后保持失效。
采样登记 GPU 提交，退役资源计入容量。
调尺寸期间暂停采样，完成后重建资源。

操作和预算见[开发预览说明](../../runtime/development-previews.md)。
C++ 热编译完成接口、ABI 与成本评估。
C++ 更新采用构建与进程重启。
Live++ 属于后续候选。

## 专项与真实工作流

进程测试覆盖 Unicode、引用、期限和取消。
输出洪泛、退出失败和缺程序均有诊断。
重载覆盖依赖、重复请求和文件占用清理。
退出时取消、等待并回收编译资源。

视图覆盖三种渲染器、独立相机与调色。
GPU 回读证明不同设置产生实际像素差异。
模型缩略图消费包围盒适配。
静态输出暂停更新，隐藏面板停止请求。

每帧模拟生成一次不可变快照。
主视口和辅助预览共同消费该快照。
固定九帧运行对应九次物理步进。
编辑器切关验证渲染器与图回调生命周期。

图像夹具按声明的模型路径选择资产。
宿主由生产关闭操作和测试总期限控制。

探索和检视项目回放真实编辑器控件。
验收包含指纹、文档、Play/Stop 和窗口恢复。
已移动的安装树使用同一生产操作回放。
RTX 和 Intel 均执行工具及编辑器预览。
