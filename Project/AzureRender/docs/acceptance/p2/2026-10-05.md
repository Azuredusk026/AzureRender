## 展示来源

三张公开图展示编辑器、机器人侧面行走和探索关卡。图片均为 1920×1080，由 RTX 4060 Laptop 捕获。编辑器和探索场景使用 100 实体、四角色与八灯。侧面动作使用公开主角、地面和相机。

图片已逐张检查文字、布局、任务界面与物体可见性。捕获帧、输入、场景、源码和运行文件哈希进入展示清单。根 README、工程 README 与站点首页展示最终图片。

## 从空项目制作

按[制作教程](../../tutorials/editor-first-game.md)从空关卡准备公开资源。自动执行模式经生产编辑命令完成 205 项操作。制作 21 个节点，登记 3 个模型资源。保存重开、历史、脚本错误恢复、Play/Stop 与构建通过。

制作与构建实际耗时为 5.27 秒。该时间统计自动命令执行和包构建。人工学习与实体键鼠操作时间需要前台复核。生产命令与 ImGui 事件具有各自验收证据。

制作得到的独立包在隔离 PATH 下完成全部任务。运行时隐藏源项目，确认包内资源可用。角色两次重开、任务状态复位与退出释放通过。

## 三轮性能

每轮预热 300 帧，再采样 1800 帧。标准、编辑器和压力负载分别运行三轮。各轮独立满足既定预算。表中为各轮 P95 的中位数，单位为毫秒。

编辑器窗口为 1920×1080，实际场景视口为 1230×759。Play 模式运行标准公开负载。面板显示状态与用户布局摘要进入性能工作区记录。

## ZIP 与长跑

ZIP 解压到 `Clean Azure Exploration` 含空格路径。PATH 隔离为 Windows System32。`start-game.cmd` 启动包内 Player。完整任务和清单验证通过。

ZIP 只包含清单文件与清单本身。长跑与交付 ZIP 使用同一份游戏文件清单。

长跑使用实际时钟，持续 1800.14 秒。完成 760945 帧、253 次切关与 254 次重开。窗口最小化、恢复及两档尺寸切换通过。结束时正常关闭，自有 GPU 缓冲和图像全部释放。

GPU P95 为 2.644 ms。CPU 工作 P95 为 3.601 ms。物理单步 P95 为 0.589 ms。每分钟 GPU 窗口和全程固定间隔 CPU 记录满足预算。

提交额外 P99 为 4.415 ms。提交帧 P99 为 11.929 ms。稳定工作集增长为 2.275%。驻留增长、工作集峰值和设备本地内存满足门禁。
