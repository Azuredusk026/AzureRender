## 公共实现契约

`PipelineInspection` 属于渲染硬件层。
设备拥有方创建检查器并串行调用。
检查器借用设备和管线句柄。
管线销毁仍由其原有调用方负责。

图形、计算和界面管线共享检查器。
设备扩展、特性和入口共同决定启用状态。
显式诊断开关为 `--disable-pipeline-inspection`。
关闭或不支持时保持常规渲染路径。

每次查询最多读取三十二个执行对象。
枚举变化最多重试一次。
报告最多保留六十四条管线记录。
达到记录上限后仍检查后续创建的管线。

GPU 计时报告包含 `pipelineInspection`。
该字段提供支持、请求、启用和入口状态。
成功、失败、跳过次数和失败返回值可查询。
记录包含名称、描述、着色器阶段和子组大小。
