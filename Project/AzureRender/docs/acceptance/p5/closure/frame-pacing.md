## 实现与所有权

Foundation 提供帧剩余时间的纯计算接口。
宿主拥有单调时钟、等待和累计诊断。
Runtime 注册类型、范围、来源和启动约束。
RHI 按设备能力选择交换链呈现模式。

编辑器和 Player 使用相同设置契约。
帧调度保持每帧输入、渲染和模拟工作。
超预算帧继续执行正常调度。
运行诊断单独记录等待量与实际呈现模式。

配置与使用见[帧调度说明](../../../runtime/frame-pacing.md)。
实施范围见[对照计划](../../../plans/2026-10-11-frame-pacing.md)。
