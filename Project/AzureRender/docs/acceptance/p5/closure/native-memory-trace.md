# 进程内虚拟内存诊断验收

> 文档类型：局部诊断验收
> 日期：2026-10-11
> 状态：调用与驻留关联通过，正式根因待闭环

## 采集契约

原型仅在本任务创建的诊断子进程中运行。
它记录 NT 虚拟内存申请及释放的返回结果。
记录包含线程、状态、地址、大小和调用栈。
栈深度上限为十六帧，缓冲容量为 262144 条。

初始化前预分配并触碰固定记录缓冲。
录制使用线程重入保护，并保留错误状态。
正常退出按原字节写入调用记录。
丢弃、重入排除和未完成写入各有计数。

原型覆盖三个进程内 NT 虚拟内存接口。
映射、内核申请和堆子分配各有独立边界。
周期模块快照可能遗漏短暂加载的模块。
该结果用于诊断，正式性能采用正常启动。

## 已知调用验证

八线程探针声明四十个已知调用。
每线程包含两次申请、两次释放及一次失败。
验证按线程调用顺序分配唯一记录。
地址复用通过事件顺序区分。

最终原型准确匹配全部四十个调用。
该次采集的四类异常计数均为零。
独立索引匹配曾将复用地址误判为重复。
原判定与有序验证结果均保留。

## 真实探索诊断

正常运行完成 2100 帧并释放引擎 GPU 资源。
原型记录 2804 个 NT 调用。
丢弃、重入排除、非法参数及未完成写入均为零。
采集保存二十五份驻留快照。

| 关联项 | 实际结果 |
| --- | --- |
| 返回提交大小 | 14749696 字节 |
| 来源栈 | 包含 `nvoglv64.dll` |
| 部分取消提交 | 同区域 20480 字节及区域内 4096 字节 |
| 随后私有驻留 | 12632064 字节 |
| 后续观察 | 二十个快照保持该区域驻留大小 |
| 外部捕获模块 | 存在 `graphics-hook64.dll` |

调用时刻与驻留快照使用可关联计时器。
同一地址范围中的返回结果与页面变化已关联。
此证据确认该区域的驱动调用来源。
其余增长来源及正式失败仍需因果复核。

## 原型失败与修复证据

静态线程存储版本在诊断 Player 中发生访问异常。
系统记录定位到诊断 DLL 的偏移 `0x15ab`。
反汇编对应线程存储数组读取。
该位置可在部分线程初始化期间不可用。

原型采用动态线程槽并限制槽号小于六十四。
该限制保证录制期间使用线程内固定存储。
初始化后注入曾因槽号超限明确拒绝。
最终版本在自有子进程启动前初始化后通过。

全部失败记录、源码、依赖与成功结果均归档。
原型使用 MinHook 标签 `v1.3.4`。
来源提交为 `c3fcafdc10146beb5919319d0683e44e3c30d537`。
版权与许可证随诊断材料保存。
