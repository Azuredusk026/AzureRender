# 外部文件恢复与文档保护复核

> 日期：2026-10-11。
> 状态：两配置局部复测与完整回归通过。

## 失败机制

文档保护测试用外部目录模拟保存失败。
取消后恢复关卡文件，再请求重新加载。
Debug 回归在该请求处收到 `StaleVersion`。
原始失败日志和控制请求保留。

内容目录在后台扫描文件变化。
扫描完成后更新资产数据库和文档修订号。
查询版本与提交请求属于两次协议调用。
期间的修订变化会使请求过期。

版本拒绝符合生产编辑服务契约。
调用方在已知外部变更后等待目录扫描完成。
文档内容、选择和文件恢复分别核验。
过期请求继续通过生产入口拒绝。

## 等待与恢复契约

`editor_content_wait.py` 提供测试客户端等待能力。
外部变更前记录目录枚举计数。
等待计数增加且后台扫描处于空闲状态。
每次等待通过公共帧推进入口继续执行。

默认期限为十秒，超时明确失败。
查询异常按原错误向调用方传播。
完成后重新读取文档版本并提交请求。
保存失败后的内容和选择必须保持一致。

此能力用于外部文件操作的宿主验证。
客户端保留所有控制请求与响应。
编辑、保存和重新加载均使用生产操作。
文档与资产的所有权保持其公共契约。
