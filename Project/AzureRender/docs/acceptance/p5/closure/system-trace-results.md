## 已知调用覆盖

探针成功申请四十个六十四 KiB 区域。
每个区域均写入数据并按原地址释放。
系统事件按进程、地址、区间与标记核验。
该探针的未配对存活大小为零。

## 分析器与归因限制

匹配的 WPA 配置导出虚拟提交生命周期。
首轮目标进程包含 3455 行生命周期记录。
另有五十三份运行期工作集快照。
结果保留提交、取消提交、地址和模块帧。

生命周期行数按分析器的区间拆分解释。
模块帧仅代表调用栈中的实际出现位置。
逻辑所有者仍需结合对应服务的生命周期。
提交量与实际驻留分别计量。

模块导出采用三位小数的 MiB 数值。
完整堆分配与映射所有权另需补充覆盖。
运行期驻留来自持续观察和系统快照。
退出后的驻留集合仅解释退出后的状态。

分析器对停止阶段的内存事件发出解析警告。
事件编号为 `0x64`，版本为四。
该警告与事件丢失统计分别记录。
成功退出码按有效输出表另行核验。

当前诊断均未复现正式工作集超限。
OBS 的影响仍按既有有无捕获对照解释。
P5-B 的完整因果与 P5-C 的修复继续待验。
正式门禁见[设备环境验收](device-environment.md)。
