  --package <移动后的探索发布目录> `

## 路线与覆盖

每轮在起点主动跌落，验证恢复。
随后完成七次必经跳跃和八枚金币收集。
两种移动平台分别实际承载至少 2.1 秒。
检查点跌落验证恢复位置与金币保持。

通关核验大门、任务与音效事件。
重开后切换探索与平台，继续完整路线。
正式门禁要求至少十次通关与七十次落地。
重开与切关均至少十次。

角色与平台的相对误差须小于 0.06 米。
实际平台位移须超过 0.05 米。
音效启动事件用于反馈触发核验。
实体输入与主观听感由操作者另行复核。
