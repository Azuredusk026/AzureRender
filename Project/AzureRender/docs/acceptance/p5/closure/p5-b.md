# P5-B 驻留诊断工具验收

> 文档类型：子任务验收记录
> 日期：2026-10-10
> 状态：诊断工具通过，引擎根因待确认

## 诊断契约

`collect_memory_residency.py` 启动并观察自有子进程。
观察包含工作集、私有提交量及驻留区域。
区域按图像、映射与未归因私有页分类。
并发释放的页面单独记录为竞态观察。

诊断结果始终标记 `diagnosticOnly`。
驻留减少按页面变化解释。
成功申请与完整释放事件可进入有限覆盖账本。
重复封装、未知释放和覆盖缺口记录歧义计数。

## 实际验证

六项分类与账本测试通过。
真实自检申请 4 MiB，并触碰全部页面。
驻留查询确认 4194304 字节私有页。
成功释放后，区域消失且账本存活量为零。

自有 Python 子进程的采集与正常退出通过。
超时夹具保存错误，并清理自有进程。
首轮页面身份竞态引发的失败日志保留。
针对未知身份的失败用例与修复复测通过。

证据位于 `build/p5-p6-implementation-2026-10-10/`。
分类工具重新分析已有 LLDB 驻留记录。
该区间净驻留增长为 26316800 字节。
其中未归因私有页为 22917120 字节。

## 返回值与释放追踪

`trace_virtual_allocations.py` 启动自有调试进程。
目标在加载入口暂停后安装本地内存断点。
入口保存参数、线程、时间与调用栈。
返回断点读取 NTSTATUS 和申请的输出地址。

追踪覆盖三个本地虚拟内存入口。
分别为 `NtAllocateVirtualMemory`、其 Ex 版本及释放入口。
成功预约进入有限覆盖账本，完整释放配对移除。
提交、取消提交与未知释放登记部分覆盖。

已知探针直接执行七个本地调用。
两次成功申请分别为 4 MiB 和 1 MiB。
两次完整释放及三次失败调用均匹配返回事件。
探针配对后的存活量为零。

真实驻留自检另验证 4 MiB 触页与释放。
事件上限夹具记录丢弃计数并返回失败。
超时夹具终止工具创建的调试进程树。
参数传递验证空格、引号、中文与反斜杠。

入口安装时序及重复返回断点的失败记录保留。
正式实现显式禁用并删除已消费的返回断点。
调试输出、事件与分类结论归档至证据清单。
该结果仅证明工具契约与已知探针。

覆盖限于当前进程伪句柄对应的调用。
系统堆、映射及显式进程句柄需另行归因。
预约字节、驻留字节与泄漏具有独立含义。
引擎真实负载及生命周期关联保持待执行。

追踪入口使用新的输出目录：

```powershell
python tools/trace_virtual_allocations.py --output build/local-allocation-trace --timeout 600 -- build/ninja-msvc-release-symbols/AzureRender.exe <运行参数>
```

结果包含原始事件、失败、待返回和漏采计数。
原始调用栈包含模块、地址及可用源码行。
普通启动性能测量使用独立入口。
