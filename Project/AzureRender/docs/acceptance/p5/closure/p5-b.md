# P5-B 驻留诊断工具验收

> 文档类型：子任务验收记录

> 状态：诊断工具通过，引擎根因待确认

## 诊断契约

`collect_memory_residency.py` 启动并观察自有子进程。
观察包含工作集、私有提交量及驻留区域。
区域按图像、映射与未归因私有页分类。
并发释放的页面单独记录为竞态观察。

诊断结果始终标记 `diagnosticOnly`。
驻留减少按页面变化解释。
成功申请与完整释放事件可进入有限覆盖账本。
重复封装、未知释放和覆盖缺口记录歧义计数。

## 实际验证

六项分类与账本测试通过。
真实自检申请 4 MiB，并触碰全部页面。
驻留查询确认 4194304 字节私有页。
成功释放后，区域消失且账本存活量为零。

自有 Python 子进程的采集与正常退出通过。
超时夹具保存错误，并清理自有进程。
首轮页面身份竞态引发的失败日志保留。
针对未知身份的失败用例与修复复测通过。

证据位于 `build/p5-p6-implementation-2026-10-10/`。
分类工具重新分析已有 LLDB 驻留记录。
该区间净驻留增长为 26316800 字节。
其中未归因私有页为 22917120 字节。
