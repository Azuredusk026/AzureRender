## 根因与修复范围

Debug 全 GPU 回归中，连续关卡测试失败。
探索已完成，平台只收集四枚金币。
测试使用固定九十帧作为切关等待。
异步加载在该次运行中超过此间隔。

Release 在第 1377 帧提交平台关卡。
Debug 在第 1495 帧提交平台关卡。
相同输入在 Debug 提交前已开始平台路线。
原始失败报告与输入按原字节保存。

运行时回放提供有界 `wait-level` 动作。
它等待目标引用和版本完成提交。
后续动作保留原有相对时序。
实现范围见[回放接口](../../../runtime/game-input-replay.md)。
