## 检查点测试前置

首轮诊断探针在检查点重生断言失败。
侧面落地时，中心金币尚未拾取。
开始横向移动测试掉落时，角色拾取该金币。
恢复后的金币数因此多于测试起始快照。

路线控制器先将角色移至检查点中心。
地面状态及主路线金币拾取均确认后开始掉落。
掉落与重生继续比较完全相同的金币数。
最终八枚主路线金币及全部落点要求保持有效。

五项前置规则先复现三项失败。
修正后全部二十六项发现规则通过。
原始响应、输入和失败日志保留。
实体操作与听感继续维护独立状态。
