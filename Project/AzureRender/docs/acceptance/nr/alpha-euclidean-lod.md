日期：2026-11-10。

## 尺度契约

Vulkan 允许设备近似计算纹理导数尺度。
显式导数仍经过该尺度计算。
显式层级直接提供所需层级。
范围见[纹理尺度规范](https://docs.vulkan.org/spec/latest/chapters/textures.html#textures-scale-factor)。

本候选使用已核对的四片元导数。
纹素导数的欧氏长度决定基础层级。
随后叠加原生偏移 `-1`。
纹理、阈值、几何及采样器保持原值。
