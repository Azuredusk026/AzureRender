# 材质组合深度策略验收

日期：2026-11-11。
状态：显式构建候选，标准构建采用参考族。
候选通过精确图像和短时净收益条件。
峰值工作集及最新短时 GPU P95 超出对应目标。

## 深度策略

关闭深度测试时，渲染器选择参考管线。
独立优化管线要求有效深度测试及合格的比较方式。
NVIDIA 两配置各验证启用和关闭两种状态。
Intel 两配置均选择参考管线。

实际宿主在关闭深度测试时完成同条件两次采集。
共 12288 个 RGBA 像素及 PNG 摘要精确一致。
候选及参考均通过验证层与资源释放检查。
候选的原始四帧摘要及 RGB 同样精确一致。

## 工作集与帧时延

同一 Release 宿主以相同项目和参数采集两次。
参考进程峰值工作集为 2045272064 字节。
候选峰值为 2990366720 字节，增量为 945094656 字节。
峰值工作集观测采用 50 毫秒采样间隔。

参考准备阶段耗时约 40.57 秒，候选约 181.80 秒。
候选准备 464 份额外管线，运行选择累计 2992 次。
两组 GPU 分配器计数一致。
该工作集结果属于四帧加载场景。

1080p 短测按参考、候选、参考顺序采样。
候选 GPU 均值约为 16.22452 毫秒，降幅约为 14.72%。
两侧参考漂移约为 1.45%，受影响范围降幅约为 15.10%。
候选 GPU P95 约为 17.02988 毫秒，CPU 约为 5.47768 毫秒。

正式 80W 条件要求设备接受固定功率上限。
当前设备返回不支持设置，正式性能与内存仍待验收。
