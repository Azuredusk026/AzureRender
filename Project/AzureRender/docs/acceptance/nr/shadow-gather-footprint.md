# 对象阴影固定采样足迹

日期：2026-11-09。
状态：实现及受影响验证通过，正式帧预算待验。

## 问题与实现

实测接收坐标在 Intel 上出现九十处过滤超差。
采样器直接取点与原生八位网格采用不同足迹。
将 D16 展开为浮点深度保持相同的九十处超差。
输入格式转换未解释本批差异。

过滤器显式按八位子纹素网格确定纹素组。
页内硬件四点采样使用该组中心坐标。
跨页路径按照同一纹素组逐项核对边界。
页外深度继续表示完整可见。

实现沿公共对象阴影过滤器接入。
图集、记录布局、资源数量和生命周期保持一致。
单页对象与多对象图集共享该契约。
该规则与完整接收位置重建分别验收。

## 局部验证

生产回归先在 Intel 上复现边界回退失败。
其期望可见量为 0.8625，实际为一。
新增三个接近纹素边界的查询覆盖该问题。
两配置、两设备各通过二十七条记录及查询。

受检区域包含四万九千三百八十四个像素。
Intel 的一字节以上超差数由九十降为零。
手动网格读取与固定足迹的硬件读取结果一致。
NVIDIA 的完整浮点结果与原过滤器逐位一致。

| Intel 对照 | 超过一字节 | 最大字节误差 |
| --- | ---: | ---: |
| D16 硬件读取 | 90 | 22 |
| 浮点深度硬件读取 | 90 | 22 |
| 直接逐纹素读取 | 90 | 22 |
| 网格确定足迹，逐纹素读取 | 0 | 1 |
| 网格确定足迹，硬件四点读取 | 0 | 1 |

## 独立效率

计时使用同一批接收输入和已有原始图集。
每个角色预热三十二次，采集六十四个时间戳。
顺序为前参考、候选、后参考。

| 角色 | GPU 均值 |
| --- | ---: |
| 前参考 | 0.645105 毫秒 |
| 固定足迹 | 0.639960 毫秒 |
| 后参考 | 0.645079 毫秒 |

参考漂移约为 0.004%。
该独立输入下的候选均值约降低 0.80%。
硬件四点读取仍为每个泊松点一次。
局部计时用于成本核对，整帧收益另行验收。
