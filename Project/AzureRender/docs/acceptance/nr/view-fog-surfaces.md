# 预积分视图雾表面验收

日期：2026-10-28，阶段为 NR3-F1E。
范围为 GPU 所有权、视图匹配及表面组合。
原版来源为第 9160 和 10875 次绘制。

## 公共契约

场景通过版本化绑定选择预积分体积。
每个在途帧拥有独立的六十四字节参数。
相机失配及比例失配提供恒等传输。
资源沿渲染器的重载与关闭边界释放。

不透明表面采用两次主颜色混合。
透射与散射分别通过乘法和加色应用。
法线、深度和其他附件保留其写入规则。
透明图层通过 `fogMode` 选择场景雾。

无光照雾入口共享完整的图层采样函数。
编译指针操作检查约束其资源访问。
四种入口均通过 GI 与反射资源隔离检查。
应用着色模块总数为 198。

材质表版本为十七，每项二十一行。
每项大小为 336 字节，相机常量为 688 字节。
合法输入、非法输入和设备拒绝分别验证。
原版资源身份与颜色参数由内容转换持有。

## 实际片元

两项实际网格均含二十四个顶点及三十六个索引。
原版 UV 与顶点输出的最大差值为零。
顶点重投影误差小于 0.000000152。
体积载荷保留原始半精度位。

官方着色调试取得六处实际片元输出。
像素历史同时记录十个片元及原版混合顺序。
独立绘制解除原版环境的深度拒绝。
参考结果按同一片元序列合成清屏背景。

对照采用负一档曝光并还原线性值。
全部采样通道保留在显示范围内。
真实独立绘制的最大线性误差为 0.005077。
预算保持 0.008。

## 回归结果

Debug 与 Release 各通过十三项 CPU 与接口检查。
两配置各通过二十六项实际 GPU 组合。
两配置各完成四次实际网格绘制。
配置及描述符路径的全部对照图像逐像素一致。

组合覆盖透明、加色、关闭和视图失配。
近端权重、正交视图和视口缩放分别验证。
完整材质文档与四倍采样内部像素通过对照。
Debug 的完整既有图层 GPU 回归通过。

Release 默认完整主场景保持逐像素一致。
主场景已接入原版体积及两项真实网格。
全图平均绝对字节误差为 13.302927。
两项来源区域的误差均约为 23.8。

实际运行均通过资源释放检查。
Debug 运行通过验证层检查。
1080p 小场景分别记录九十六帧 GPU 范围计时。
该检查使用单体素雾场，正式预算继续验收。
