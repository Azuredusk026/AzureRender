# 时序覆盖与独立参考验证

日期：2026-10-24。
范围为 NR7-AA1 至 AA4 的覆盖和公共质量检查。
公共接入基础见[时序重建验证](temporal-reconstruction-integration.md)。

## 输入与覆盖

时序合成要求运动与颜色表面深度均有生产者。
资源标识必须属于当前视图的两个独立输出。
缺失或错误输入在图修改前被拒绝。
前帧状态保持原有成功提交边界。

完全透明的混合材质保持背景运动语义。
其颜色表面深度保持目标的背景清除值。
非零覆盖的透明表面继续标记为响应像素。
GPU 附件检查扩展至 22,500 个标量。

辅助视图将当前相机姿态与显式镜头参数组合。
投影参数保持作者配置的值。
实际图像的前景重心确认相机移动已被消费。
主宿主和 Player 的输入契约保持 API 版本四。

HDR 检查包含 38,768 个输出标量。
独立数值参考覆盖亚像素平移与历史采样。
遮挡显露及对象重新出现分别检查深度拒绝。
曝光变化保留曝光前 HDR 的历史语义。

当前颜色 Alpha、历史有效性和响应覆盖分别核对。
首帧、切镜、重复提交及取消继续使用原门禁。
检查同时覆盖角色渲染图与公共运动绘制。
GPU 校验和资源释放保持通过。

Debug 与 Release 各通过十八项受影响检查。
两种配置各完成十六帧真实角色采集。

七十七份着色器产物在两种配置间一致。

## 四倍尺寸参考

参考图横纵尺寸各为原生输出的四倍。
原生输出为 96×64，参考输出为 384×256。
参考使用模式零，并在线性显示域按 4×4 平均。
相机、曝光及动画时间在静态对照中固定。

边缘由参考图完整 3×3 邻域的反差生成。
完全平坦区域要求该邻域逐项一致。
孤立子像素细节归入边缘与细节检查。
静态边缘误差上限保持关闭抗锯齿时的 80%。

| 资产 | 边缘像素 | 时序误差比 | 平坦区域最大字节误差 |
| --- | ---: | ---: | ---: |
| 公共立方体 | 1,362 | 0.6370 | 0 |
| 带蒙皮及透明材质的公共模型 | 3,636 | 0.6560 | 0 |

独立原生模式零与时序首帧逐字节一致。
运动阶段单独推进相机和角色动画。
两个资产均覆盖独立历史、取消及尺寸重建。
这些结果用于公共机制验收。
