# 当前场景 GPU 成本

## 来源与分组

生产来源为 `35cc28f`，设备为 RTX 4060 Laptop。
完整联合场景的第三百二十帧在 720p 诊断分辨率捕获。
记录为 2,116,148,716 字节，任务总量约为 1.97 GiB。
正式性能负载保持 1080p，冻结图像保持 1440p。
源码、构建产物及全部挂载输入在捕获前后摘要一致。

重放取得 3424 个事件，总时间约为 16.56 毫秒。
下列分组为受检高成本事件，各程序与当前产物字节匹配。

| 程序用途 | 事件数 | 时间，毫秒 |
| --- | ---: | ---: |
| 主颜色通用提前深度 | 49 | 2.776 |
| 快照通用提前深度 | 17 | 1.569 |
| 主颜色通用 | 29 | 1.524 |
| 主颜色扩展照明 | 4 | 0.736 |
| 阴影边界计算 | 1 | 0.556 |
| 蒙皮计算 | 1 | 0.544 |
| 反射追踪 | 1 | 0.448 |

其余未查询程序身份的事件合计约为 5.94 毫秒。
该分组包含多类绘制，具体归属按完整原始记录解释。
事件重放用于成本定位，原生 P95 按独立条件验收。

## 视图模式局部控制

隔离程序将场景照明及正式颜色模式固定为实际常量输入。
十个受检材质程序保留各自的宏及管线专用常量。
摄像机缓冲中的照明值与诊断模式逐项核对。
机制参考 [Vulkan 官方专用常量示例](https://docs.vulkan.org/samples/latest/samples/performance/specialization_constants/README.html)。

预热后执行基线、候选、候选、基线的交替控制。
受检材质事件均值约为 8.323 与 7.259 毫秒，减少约 13%。
完整重放总时间包含其他工作及驱动波动，保持单独记录。
部分高精度中间结果存在字节差异，最终显示输出逐字节一致。
单帧显示一致仅覆盖该次重放输出。

本候选的所属事件减少未达到 20% 集中验证门槛。
候选保存在隔离目录，生产源码及产物保持冻结摘要。
本项没有启动额外原生图像、成对计时或正式长跑。
CPU、GPU 帧预算及整体画质继续待验收。
