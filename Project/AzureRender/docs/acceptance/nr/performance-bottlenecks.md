# 性能瓶颈归因

## 当前判断

GPU 场景工作主导当前完整联合帧的时间。
CPU 场景准备也独立超出原八毫秒预算。
显存带宽、纹理延迟及算术吞吐尚缺有效硬件采样。
当前结论限定为已取得的工作量与阶段证据。

GPU 事件来源为 `0694263` 的实际原生第三百二十帧。
该帧的运行源码与 `f224da9` 基线逐文件一致。
[事件分解](current-gpu-events.md)记录捕获及程序身份。
重放的主颜色与快照通用程序合计约 17.86 毫秒。

选中事件已有深度预填充，仍存在被遮挡的片元调用。
GPU 叶级片元调用总数为 27,853,535。
这些证据支持优先减少重复和无效的表面着色。
事件重放时间用于定位，原生帧预算单独判断。

## CPU 阶段

私有插桩以当前源码和提前深度候选构建。
测量记录固定步长的第三百一十至三百二十九帧。
插桩、运行产物及项目输入均按摘要核对。
下表为同一批记录的阶段均值。

静态实例的[只读姿态共享](shared-bind-pose.md)已取得独立验证。

## 计数器与存储

官方 Nsight Graphics 2026.4 安装包已校验签名及摘要。
工具位于 `D:/Tools/NsightGraphics/2026.4`。
RenderDoc 已接入 NVIDIA 性能计数库。
实际可枚举三千六百三十一项计数器。

混合计数与单独 DRAM 计数均返回零条厂商样本。
同一重放的通用计时返回三千四百二十四条样本。
官方 Perf SDK 2025.1 的控制也未取得厂商样本。
接口未返回有效错误信息，原因继续保留为未确定。

Nsight 的本机接口已完成协议和工具清单查询。
其实际跟踪启动返回分发后的工具失败。
该启动拥有的场景进程及本机服务已经停止。
工具连接成功和指标枚举成功分别保留适用范围。

短时记录的设备本地分配峰值约为 3.29 GB。
设备容量为 8 GB，容量指标与带宽指标分别解释。
当前未取得有效 VRAM、SM、缓存或 PCIe 吞吐样本。
内存忙碌比例和资源容量仅作为设备状态。

## 措施与限制

[提前深度候选](ordinary-early-depth.md)通过原生四帧严格兼容。
其 Intel 时间检查及热状态仍保留失败。
候选已隔离，生产源码及默认程序采用受检输入。
