# 性能瓶颈归因

## 当前判断

GPU 场景工作主导当前完整联合帧的时间。
CPU 场景准备也独立超出原八毫秒预算。
硬件计数已取得局部字节、指令及停顿样本。
显存总线与算术单元的峰值饱和度继续独立核验。
当前结论限定为已取得的工作量与阶段证据。

GPU 事件来源为 `0694263` 的实际原生第三百二十帧。
该帧的运行源码与 `f224da9` 基线逐文件一致。
[事件分解](current-gpu-events.md)记录捕获及程序身份。
重放的主颜色与快照通用程序合计约 17.86 毫秒。

选中事件已有深度预填充，仍存在被遮挡的片元调用。
GPU 叶级片元调用总数为 27,853,535。
这些证据支持优先减少重复和无效的表面着色。
事件重放时间用于定位，原生帧预算单独判断。

私有插桩以当前源码和提前深度候选构建。
测量记录固定步长的第三百一十至三百二十九帧。
插桩、运行产物及项目输入均按摘要核对。

实际可枚举三千六百三十一项计数器。

非管理员会话的权限失败见[权限记录](evidence/2026-11-06/gpu-counter-permission/results.json)。
