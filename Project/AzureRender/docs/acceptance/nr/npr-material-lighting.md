# 逐材质 NPR 光色验证

日期：2026-10-23。范围为 NR6-C11-R7。
引擎接收显式线性光色，捕获行身份归属离线工具。
皮肤、面部及独立织物夹具复用同一契约。
皮肤完整外观继续按 C9 及 C16-R1 验收。

## 公共契约

`nprDiffuse.lighting` 使用可选的版本一对象。
两组 RGB 分别提供环境颜色与所选主灯颜色。
每个分量须为零至 64 的有限数值。
省略对象时，材质采用场景光色。

数据及解析归属已有材质模块。
布局版本三使用联合表第十一、十二行。
参数表保持 192 字节，纹理保持九槽。
捕获清单记录实际布局版本。

主灯方向、强度及局部灯由场景拥有。
场景辐照启用时，采用实际辐照输入。
稀疏参数覆盖保留光色及其他源字段。
完整文档与 glTF 共用生产解释器。

## 原生依据

依据为帧 10401 的皮肤事件 783 和面部事件 804。
完整反汇编分别包含 2047 和 1684 行。
两类材质读取环境常量行 113、主灯行 114。
头发及服饰的实际光色来源分别保留。

环境 RGB 为 `[1.187010, 0.927229, 0.812990]`。
主灯 RGB 为 `[1, 0.926182, 0.866667]`。
影色另乘以全局常量 `0.5500000119`。
该倍率由现有 `nprDiffuse.shadowScale` 消费。

两个真实皮肤片元具有独立的色带及光照核对。
颜色公式误差小于 `3e-8`。
照明公式误差小于 `1.3e-7`。
像素历史确认对应图元实际通过深度检查。

## 图像与回归

双配置构建及各五组 CPU 检查通过。
三十四次公共 NPR 与八次头发 GPU 检查通过。
六次实际捕获覆盖缺省、候选、固定路径及主场景。
固定与索引路径、glTF 与完整文档分别保持画面一致。

真实候选依次接入光色、影色倍率及零全局边缘光。
两个脸部片元的光色误差由 10、11 降至 3 字节。
腿部片元在影色倍率接入后由 26 降至 4 字节。
肩部片元仍相差 66 字节，完整外观继续待验。

缺省角色与主场景保持各自参考画面。
所有通过运行均检查验证告警及脚本错误。
卸载后的缓冲与图像计数均为零。
材质图像字节及纹理常驻量见结构化收据。
