# 空闲显卡复测

## 机制与图像

Release 与 Debug 在 NVIDIA 和 Intel 上各执行三项检查。
十二项 GPU 检查通过，源码及受检产物保持一致。
蒙皮逐条与批量缓冲屏障的输出按完整字节一致。
各用例启用同步验证，并检查资源释放。

NVIDIA Release 的原生四帧与冻结参考 RGB 逐字节一致。
四帧的差异像素数均为零，卸载后缓冲与图像计数为零。
两配置各五百三十五份生产着色程序保持基线字节。
项目挂载的 1,729 份文件在捕获与性能采集后保持一致。

原生四帧使用 2560×1440、场景机位与灯组。
Release 应用的验证层关闭，机制用例的同步验证开启。
实际设备、检查范围及原始输出分别保留。
当前机制兼容检查通过，用户整体画质验收保持未通过。

## 原生性能

完整联合场景按 1920×1080 原生分辨率运行。
预热三百帧，统计一千八百帧，共运行两千一百帧。
交流供电和八十瓦功耗上限保持稳定。

这些数字表示本轮测量，收益归因需匹配实际热状态。
