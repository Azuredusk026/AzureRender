# 运行时实体身份验证

## 实现范围

实体身份查询使用现有 `NodeIdentity` 组件。
查询同时核对世界存活状态与文档所属关系。
接口供运行插值、物理与交互使用。
实现及任务边界见[实体身份计划](../../plans/2026-11-05-runtime-node-identity.md)。

## 验证结果

Release 与 Debug 完整来源构建通过。
两配置各十九项运行时、玩法及生命周期检查通过。
世界交换、编号回收、场景替换及失败恢复均有覆盖。
延迟生成与停止状态遵守原身份提交边界。

四帧联合输出与冻结参照逐字节一致。
现场基线的第四帧有十四个一字节差异，独立保留。
两配置各 535 份生产着色程序与受检基线一致。
实际联合宿主正常退出，卸载后缓冲与图像数量均为零。

## 性能记录

原始资源键候选的 CPU 工作 P95 为 46.35 毫秒。
实体身份候选在交流供电下为 38.30 毫秒。
GPU 帧 P95 为 40.38 毫秒。
八毫秒 CPU 与 16.6 毫秒 GPU 门槛均未达到。

采样沿用 300 帧预热与 1,800 帧统计。
实际场景尺寸为 1920 × 1080。
全程交流供电，GPU 功耗上限为八十瓦。
后段触发热状态条件，完整性能验收保持失败。

窗口最小化导致启动后的绘制暂停。
恢复窗口后完成全部 2,100 帧，命令总耗时 847 秒。
原九百秒采集预算保持有效。
该暂停及后续供电观测均保存在原始记录中。

另一次采样期间设备降至四十瓦电池供电。
该控制保留为不可比较结果。
联合画质状态继续为 `failed-user-review`。
