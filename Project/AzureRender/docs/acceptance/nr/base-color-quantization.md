# 基色因子的量化验证

日期：2026-10-21。
范围为 NR2 的无纹理 glTF 基色导入。
所属模块为材质加载器。

## 运行契约

`baseColorFactor` 的 RGB 分量为线性颜色。
Alpha 分量为线性覆盖度。
无底色纹理时，加载器生成常量颜色图。
该图采用两乘二的 RGBA 八位存储。

各通道先限制在零到一之间。
RGB 按 sRGB 传输函数编码，Alpha 保持线性。
四个通道均使用最近量化生成字节值。
默认白材质的四个通道均为 255。

材质的色彩空间和采样契约由既有槽位持有。
含底色纹理的材质在因子相乘后使用相同量化。
该规则适用于独立工具和项目中的无纹理模型。

## 导入检查

测试通过写盘和重新加载进入生产路径。
固定字节值作为独立期望，逐通道核对四个像素。
每组显式因子同时核对白纹理相乘路径。

| 线性 RGBA 输入 | 期望字节 RGBA |
| --- | --- |
| 默认白 | 255、255、255、255 |
| 0.0005、0.003、0.01、0.5 | 2、10、25、128 |
| 1、1、1、1 | 255、255、255、255 |
| 0.18、0.04、0.7、1 | 118、56、218、255 |
| 0、0、0、0 | 0、0、0、0 |

测试首先在默认白断言处得到预期失败。
Debug 与 Release 的所属目标构建均通过。
两种配置的受影响 CPU 回归各六项通过。

回归包含纹理导入、影色表和材质文档。
同时覆盖命令行、资源访问及资产往返。

## 数值范围

GPU 夹具使用独立的立方体八邻点插值。
输入期望按最近量化的基色编码构建。
PNG 逐通道比较门限为一个字节。
Debug 运行要求十个用例均开启 Vulkan 校验层。

本次实测使用 RTX 4060 Laptop。
分辨率为 128×128，十个用例各采样一帧。
八个数值用例的实际与期望字节差均为零。
暗部输出为 7、27、45，白端点均为 255。

固定与索引描述符的画面差为零。
源图翻转归一化前后的画面差为零。
仅绑定查表资源时，完整画面的差为零。

脚本、表现及运行校验错误均为零。
十个用例的卸载缓冲区和图像计数均为零。

八位输入与显示输出均含量化误差。
本验证说明导入字节和端到端显示查表行为。
线性 HDR 分项的百分之一目标保持独立验收。
该目标需要浮点附件或着色器中间量证据。

当前验证产物位于以下目录：

```text

```

`red.log` 记录默认白断言的预期失败。

`verification.json` 保存源码与编译产物摘要。
该收据同时核对独立期望函数的来源一致性。

原始影色表测试的收据保留于以下目录：

```text
build/runs/20261021-172156-native-render-evidence-623c52/shadow-lut/gpu-public-debug/
```
