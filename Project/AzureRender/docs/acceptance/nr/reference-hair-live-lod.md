# 参考头发片元层级

隔离探针使用头发选层候选的同一 Player。两个参考可见量片元程序先按候选补丁重建并核对摘要，再把片元计算的基础层级编码为 32 位字写入法线附件。两设备各读回 17,017 个冻结头发点，深度与对象标识逐字节匹配同设备候选。

## 半层边界

最近层级直接向上取整的模型在 NVIDIA 的 17,017 个位置和 Intel 的 17,016 个位置，与候选对应的原生显式层级相差至多一个压缩法线单位。Intel 的覆盖异例沿用冻结点集。

NVIDIA 在完整附件中只有 8 处法线变化。其实际层级距半层边界均小于 `1/256`，8 处基线法线都与冻结原生值逐位一致。两个冻结头发可见量超差点的实际层级约为 `3.499438763`，对应候选层级 3。完整接收的另一个新增超差点实际层级约为 `0.502359390`。

Intel 的完整法线附件有 1,061 处变化，其中 27 处位于同一半层范围。根据实际层级和法线读回，在该范围采用基线采样的离线对照得到 NVIDIA 0 处和 Intel 25 处冻结法线超差。可见量和颜色继续使用实际场景的逐通道一字节门槛。
