## 重放控制

同一批次依次测量基线、候选和基线。
三组均有三千四百二十四个叶级事件。
各事件的绘制参数及通过样本分别一致。
整帧通过样本均为 64,679,603。

| 配置 | 片元调用 | 事件耗时合计 |
| --- | ---: | ---: |
| 首次基线 | 27,849,008 | 40.333 毫秒 |
| 提前深度 | 24,994,062 | 32.358 毫秒 |
| 末次基线 | 27,852,148 | 40.075 毫秒 |

基线时间漂移约为百分之 0.64。
候选的重放耗时相对基线均值降低约百分之 19.52。
片元调用相对基线均值减少 2,856,516 次。
这些结果描述冻结捕获的工作量及重放时间。

重点主颜色绘制的片元调用为 185,347 与 52 次。
该绘制的通过样本均为五十二。
快照重点绘制的片元调用为 371,593 与 93,542 次。
该绘制的通过样本均为 93,542。

受检程序的变化仅有提前深度执行模式。
选取的角色、透明自发光及计算程序保持原字节。
本批管理员启动被 Windows 取消，使用通用计数完成对照。
