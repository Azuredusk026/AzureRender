# 阴影过滤范围判定评估

本单元归属于 RenderCore 的级联阴影接收。
候选利用既有 8×8 深度界限判定四元组的比较结果。
相邻查询共享最近一次界限读取。
生产实现保持受检状态，候选处于隔离状态。

## 操作量

实际捕获为 1280×720 的完整联合场景。
四份快照程序对应三百五十四次绘制。
统计只覆盖最终可见快照，被覆盖片元及主颜色单独解释。

| 项目 | 四元组数 |
| --- | ---: |
| 过滤深度读取 | 7684969 |
| 四个纹素属于同一范围块 | 5880156 |
| 界限可证明全部可见 | 332623 |
| 界限可证明全部遮挡 | 4428286 |

可省去的深度采集约占 61.95%。
按每次深度采集十六字节、范围读取八字节估算，
即使每次都重新读取范围，请求字节仍可减少约 23.69%。
这些数值只描述逻辑操作量，缓存和指令成本由计时判定。

## 机制与兼容

四个纹素及其夹取结果均位于同一范围块时，才使用界限。
接收平面的四个值均有限时，执行保守比较。
全部不大于深度下界时，比较结果为一。
全部严格大于上界时，比较结果为零。

其余情况执行完整深度采集与原比较。
权重、接收平面表达式及累加次序保持原范围。
界限缓存仅属于当前片元调用。
该机制共同覆盖普通主颜色与不透明反射快照。

十一份私有程序通过 SPIR-V 校验。
实际重放的九项附件全部逐字节一致。
统计替换撤销后的快照也逐字节一致。
功能重放调试消息为空。

每个阶段均通过连续三次百分之三以内的预热条件。
匹配范围包含一千零九次绘制。
