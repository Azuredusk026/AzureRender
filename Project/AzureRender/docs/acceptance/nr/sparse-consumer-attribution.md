# 稀疏照明消费归因

## 结果与范围

本单元完成一次 1080p、三十二帧原生诊断。
二十三项检查通过，两项按设备能力跳过。
同步日志无错误，卸载分配残留为零。
诊断配置默认关闭，正式帧预算继续待通过。

## 实际消费

三十个退役槽采用三十二像素网格采样。
生产调用为 59241 次，消费访问为 136950 次。
全部消费通过模式检查，逐像素命中为 49734 次。
完整四像素组接受为 41402 次。

逐像素命中占消费访问约 36.32%。
完整四像素组接受占消费访问约 30.23%。
逐像素匹配但整组拒绝的采样调用为 8332 次。
这些数量表示采样调用，独立像素数量另行统计。

最近完成槽共有 3184 次失配记录请求。
有界缓冲保存前十六条完整记录。
十五条是身份失配，一条是四像素组拒绝。
全部记录的模式位均为 31。

十五条身份失配均具有相同实例与材质。
请求三角形与缓存三角形不同，请求深度更远。
该样本表明隐藏三角形参与了轻量片元执行。
有界记录的顺序不代表全部失配的分布。

## 开发结论

轻量绘制资格与消费接受量分别统计。
消费阶段需要支付隐藏片元、身份核对及附件读取成本。
完整补充绘制与其他主场景阶段继续参与整帧成本。
接续优化按实际 GPU 分段和收益上限选择。

本单元没有执行性能对照、长采样或截图采集。
诊断进程总时长约 269.75 秒，包含内容及管线准备。
该过程总时长与稳定帧成本分别解释。
CPU 八毫秒及 GPU 16.6 毫秒标准保持有效。
