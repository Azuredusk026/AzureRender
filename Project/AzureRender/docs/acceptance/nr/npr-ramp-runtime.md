## 公共契约

材质通过有类型的颜色合成策略选择计算。
`mask-visibility` 为缺省策略。
`view-ramp-alpha` 将视角权重用于阴影和室内颜色。
具体参数及纹理身份归属于内容数据。

加载器和画像打包共同校验合法组合。
完整材质文档、图编译及参数覆盖共享该语义。
画像布局为二十一，保持二十二行及 352 字节。
渲染器 API 为八，显式报告该能力。

显式策略使用独立的材质光照程序族。
默认程序继续按既有材质契约消费输入。
采集清单记录选择视角策略的实际材质。
使用方法见[运行契约](../../runtime/npr-ramp-composition.md)。

完整资格见[原生合成核验](npr-view-ramp-composition.md)。
