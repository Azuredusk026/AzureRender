663 份着色程序保持原字节。

## 成对短检

每端预热三百帧，统计一百二十帧。
两端使用相同原生联合项目及 1080p 分辨率。

| 指标 | 基线 | 候选 |
| --- | ---: | ---: |
| CPU 均值，毫秒 | 15.0804 | 15.5417 |
| CPU P95，毫秒 | 16.4028 | 16.9568 |
| GPU 均值，毫秒 | 24.9549 | 24.2727 |
| GPU P95，毫秒 | 29.4538 | 24.9499 |

CPU 均值差为负 0.4613 毫秒，P95 也未改善。
本批只改变 CPU 准备，GPU 读数具有漂移边界。
两端均未通过八十瓦稳定观察条件。
本轮取得工作量减少证据，整帧收益资格未成立。

手工向量原型另用相同顶点输入作局部对照。
207364 个顶点的输出字节一致。
标量均值约为 3.394 毫秒，原型为 7.317 毫秒。
该原型保持私有诊断用途。
