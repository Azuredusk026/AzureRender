- 头发绑定姿态的平滑方向使用八面体编码。
- 眼睛 UV 的 V 方向与原生采样约定对应。
- 眼睛切线第四分量与该 V 方向配对。
- 身体与第四号服饰的 UV 和切线第四分量采用配对转换。

头发方向转换覆盖 11,564 个顶点。
