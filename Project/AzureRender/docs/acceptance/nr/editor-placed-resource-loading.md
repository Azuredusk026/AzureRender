# 编辑器视口模型加载

日期为 2026-11-12。

导入任务完成后将模型登记到项目资产和场景资源列表。
编辑视口根据节点引用准备模型资源，首次放置时纳入对应模型。
渲染资源签名和文件时间戳扫描均按节点引用选择模型。
保存和重开保留导入身份。
已放置模型的外部文件写入触发渲染资源刷新。

## 回归范围

`AzureEngine.EditorPlayable` 保留 240 秒时限。
用例执行 529 个编辑器操作，保存 83 个节点和 11 个模型资源。
检查包含撤销和重做、脚本恢复、编辑状态恢复及资源卸载。

`AzureEditor.TaskService` 检查后台导入、取消、失败、首次放置及文件更新。
`AzureRender.EditorSession` 检查待放置资源、放置后的资源顺序、材质变化和失败后的重试。

两种配置完成全目标构建。
Debug 的注册测试为 605 项，Release 为 607 项。
