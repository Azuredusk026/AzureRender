## 公共契约

场景渲染器拥有一个延迟分配的 D16 图集。
四列两行共八个分区，每区为 1024 像素。
图像占十六 MiB，采样借用绑定 28 的共享采样器。
绑定 29 仅保存图像。

实例版本二保持 496 字节。
对象索引使用偏移 424 的无符号整数。
逐帧绑定 20 的对齐尾部保存版本一对象记录。
深度计算与主机记录分别使用独立同步范围。

投影绘制共用当前蒙皮、节点透明度及材质覆盖。
固定与索引路径共用同一分区和过滤数学。
NPR 材质布局版本七保留 192 字节及九个纹理槽。
来源字段 `object-shadow` 选择实例对象的可见量。

基础固定布局支持十六张图像。
对象档位使用十七张图像及十六个采样器。
片段总资源同时计算七个缓冲和两个颜色附件。
当前帧图像绑定未变化时，宿主保留现有描述符。

## 数值对照

原生证据来自帧 10401 的对象深度与事件 699。
原始 D16 深度逐字转换为公共正向深度输入。
四个真实点的十六组采样旋转坐标完全一致。
GPU 过滤最大误差为 `2.98e-8`，预算为 `2e-7`。

原生腿部有 61 个遮挡样本。
未量化可见量约为 `0.01842177`。
版本一消费者输出八位可见量 `5/255`。
肩部及两个面部点的结果为完整可见。

合成数值检查覆盖全遮挡、零遮挡及部分覆盖。
两个独立深度图像共用一个采样器。
记录检查覆盖奇数深度范围、相邻记录及无效索引。
分页外采样返回远深度，避免相邻分区串扰。
