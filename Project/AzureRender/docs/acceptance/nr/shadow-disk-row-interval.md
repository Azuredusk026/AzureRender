# 阴影圆盘行范围成本

日期为 2026-11-12。
候选按每行最近纵向距离计算圆盘覆盖的横向区间。
横向区间保留原循环的步长、奇偶性和累计顺序。
平方距离余量为 0.001。

## 代表输入

采用[圆盘权重局部成本](shadow-disk-kernel.md)中保存的 48 类形状与 921600 个像素索引。
其中 136908 个像素包含过滤工作。
候选跳过 11917189 个原循环组中的 4232176 个零权重组，约占 35.51%。

额外核对 131072 组单精度形状，覆盖 20893319 个原循环组。
输入包含圆周两侧相邻浮点值，所有正权重组均落在保留区间内。
实际回放使用十份已合格组合程序及对应的十份候选程序。
候选程序全部通过 SPIR-V 验证。

## 实际回放

完整场景 720p 捕获包含 3453 个计时事件及 1006 个材质绘制事件。
测量顺序为参考、候选、候选、参考，每次统计前预热十六遍。
六份快照及最终输出附件逐字节一致。

材质事件的参考均值为 7.80109 毫秒，候选为 7.71659 毫秒。
材质耗时减少约 1.08%，参考漂移约为 0.83%。
完整事件均值分别为 11.36078 和 11.26432 毫秒。
局部降幅低于 20% 的准入门槛，候选保留在隔离验证目录。
