# 公共顶点颜色流

日期：2026-10-28，阶段为 NR7-L4F。
范围为资产颜色、公共绑定和有类型材质消费。
契约见[顶点颜色输入](../../runtime/vertex-color-inputs.md)。

## 输入与边界

资产读取保留线性 RGBA 及图元索引。
格式覆盖归一化 RGBA8、RGB16、浮点及交错数据。
缓冲跨度和颜色范围在 GPU 分配之前校验。
缺少颜色的图元使用白色。

公共 RHI 描述多流与属性来源。
空后端和 Vulkan 使用相同的结构校验。
实际颜色流与共享常量流采用明确的步长。
基础顶点与计算蒙皮保留 108 字节和 27 字步长。

材质明确选择顶点乘法。
通道解释、材质倍率及颜色乘法先于亮部扩展。
覆盖率和节点淡出按公共次序消费。
完整材质文档与模型共用同一解释器。

## 实际来源

候选包含同一原生程序族的二十二个实例。
三项新增输入具有逐顶点颜色或透明度。
实例淡出由同次绘制常量提供。
零贡献状态独立于颜色输入保留。

部分静态绘制的原始 UV 绑定需要继续核定。
其坐标通过已核对的顶点阶段仿射变换反算。
原生顶点输出、旋转、缩放和滚动共同核对。
该来源边界记录于每个实例的转换凭据。
