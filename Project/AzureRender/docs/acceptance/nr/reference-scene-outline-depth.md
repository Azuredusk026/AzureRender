# 参考场景外扩深度

参考场景按材质的 `outlineSurface.depthPrepass` 绘制外扩几何。
外扩几何写入反向 R32 和 D32，保留已写入的法线与对象身份。
图元位置使用当前模型姿态、形变和参考投影。
遮罩覆盖沿用材质选择的纹理、层级与梯度。

## 冻结区域

原生帧 10401 的事件 440 提供外扩深度的逐位置对照。
接收区域包含 49,384 个位置，完整头发包含 17,017 个位置。
头发外扩区域取事件 440 写入且位于完整头发遮罩之外的 2,046 个位置。
可见量及颜色按每通道最多一字节验收。

| 设备 | 外扩区域可见量超差 | 完整接收可见量超差 | 完整头发可见量超差 | 完整头发颜色超差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 46 | 1,712 | 0 | 0 |
| Intel | 66 | 1,976 | 208 | 575 |

两块设备均有 2,042 个外扩位置的深度更接近原生写入。
NVIDIA 的深度误差中位数为 31 ULP，Intel 为 30 ULP。
两块设备的完整头发深度与基线逐字节一致。
完整法线及对象身份附件也与基线逐字节一致。
同一设备的 Release 与 Debug 对应附件和三帧颜色逐字节一致。
事件 377 写入的 16,629 个法线位置中，NVIDIA 和 Intel 分别有 1,350 处及 1,349 处可见量超差。

## 回归

Release 通过六项 CPU 检查，Debug 通过五项 CPU 检查。
两种构建在 NVIDIA 和 Intel 上各通过五项 GPU 检查。
默认场景的原始四帧 PNG 全部逐字节匹配冻结摘要。
891 份既有着色器保持逐字节一致。
独立的 128 × 128 对照使用非零深度偏移，新增 144 个深度位置。
固定纹理、索引纹理和仅深度模式的深度读回逐字节一致。
开启外扩的对照保留全部法线及对象身份位值。

## 深度来源

原生外扩投影使用独立的深度斜率和截距。
离线替换投影系数后，NVIDIA 在 2,042 个已改变的位置中有 1,897 个处于一 ULP 内，Intel 有 1,560 个。
该对照使用实际深度读回，用于定位系数误差。
外扩精确覆盖、服饰法线和 Intel 头发纹理层级继续按冻结区域验收。
