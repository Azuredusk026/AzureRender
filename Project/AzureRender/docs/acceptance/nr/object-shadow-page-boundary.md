# 对象阴影页边界

日期：2026-11-09。
状态：边界缺陷修复通过，原生整体外观继续验收。

## 原因与修复

片元内取整与采样器坐标量化有不同边界。
接近页边界的硬件四点采样可能读到相邻页。
独立 D16 输入中，完整白色页应保持可见量一。
原 NVIDIA 用例实际返回 0.5，确认邻页遮挡进入结果。

`objectShadowGather` 为硬件足迹保留一纹素余量。
边界路径逐纹素检查当前页，页外返回远深度。
过滤分布、量化公式、记录布局及资源数量保持原契约。
机制供普通 NPR 表面及投影头发共同使用。

精度依据为 [Vulkan 采样规范](https://docs.vulkan.org/spec/latest/chapters/textures.html)。
原生接口规则见 [Direct3D 11.3 规范](https://microsoft.github.io/DirectX-Specs/d3d/archive/D3D11_3_FunctionalSpec.htm)。

## 集中验证

独立夹具新增九组页边界输入。
三个距离分别覆盖右边、上边与角落。
相邻黑色页与完整白色页用于检查隔离。

Debug、Release 各在 NVIDIA 与 Intel 上运行一次。
四项 GPU 检查全部通过，每项包含 24 组记录或查询。
同步验证无错误，检查后的资源释放正常。
两配置主程序及 675 份着色产物通过来源核验。

原始联合场景沿用固定机位、灯光及四帧命令。
四帧的 RGB 差异像素为零，PNG 摘要均一致。
1729 项项目输入、运行源码与程序在采集内保持一致。
原生进程卸载后的缓冲与图像计数均为零。

本单元属于边界正确性修复，整帧计时次数为零。
CPU 八毫秒与 GPU 16.6 毫秒预算继续待通过。
整体画质状态仍为 `failed-user-review`。

## 接收输入范围

同批只读分析覆盖原生对象的 49384 个矩形区域像素。
七个既有控制点确认深度与压缩法线布局。
离线位置的控制偏差至多为 `2^-15` 米。
该结果属于 CPU 算术近似，完整 GPU 等价仍需验证。

两个已定位阴影点的法线分量差约为 0.00093 与 0.00249。
接收位置差约为 `3.46e-5` 与 `8.13e-6` 米。
纹理层级边界点具有独立的较大法线差。
这些输入与完整头发的七十三处超差分别登记。
页边界修复的结果保持本页所述范围。
