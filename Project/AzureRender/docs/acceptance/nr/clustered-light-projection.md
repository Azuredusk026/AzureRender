# 聚簇灯投影验证

日期：2026-10-23。范围为 NR6-C11-R3。
真实点光捕获要求 CPU 与 GPU 使用相同投影方向。
本项修正投影符号及包围区间排序。

## 来源与职责

实际捕获的头部点光已经通过公共输入上传。
角色片元追踪给出其明确的正向照明贡献。
失败捕获中的 CPU 范围未覆盖头部屏幕瓦片。
上下偏置灯夹具独立复现相同问题。

渲染宿主向聚簇网格传入实际矩阵倍率。
视空间包围盒按带符号倍率投影端点。
屏幕区间由投影结果的最小值和最大值定义。
直接屏幕坐标输入使用绝对倍率计算半径。

规则适用于正交、透视及镜像投影。
方向灯继续覆盖全部聚簇。
输入、缓冲和材质布局保持现行容量。
契约见[聚簇照明](../../runtime/clustered-lighting.md)。
