# 软阴影接收成本分项

## 输入与控制

私有目录持有当前五百三十五份着色程序。
四份原始片元程序重编译后与生产字节一致。
四份控制程序通过 SPIR-V 校验。
生产程序及项目挂载文件保持原有字节。

控制只令通用程序的级联阴影接收函数返回完全可见。
阴影深度生成及其他程序按原流程执行。
依赖该结果的计算可能随编译消除。
该输入用于测量接收路径，当前生产画面保持完整阴影。

## 原生分项结果

各运行使用 1080p、三百帧预热及一百二十帧统计。
完整验收继续采用一千八百帧统计。

| 顺序 | GPU 帧均值 | GPU 帧 P95 | 环境检查 |
| --- | ---: | ---: | --- |
| 基线一 | 35.33 毫秒 | 36.62 毫秒 | 热状态未通过 |
| 接收控制 | 25.18 毫秒 | 25.70 毫秒 | 通过 |
| 基线二 | 34.59 毫秒 | 35.48 毫秒 | 热状态未通过 |

两次基线均值漂移约百分之 2.10。
控制相对基线均值差约 9.78 毫秒。
两次基线的热状态未满足既定比较条件。
该差值保留为诊断线索，优化收益尚未成立。

控制四帧均产生可见差异，确认实际使用了私有程序。
末帧约二百八十万像素变化，最大通道差为 208。
该结果只验证控制生效，用户画质状态保持未通过。

## 后续方向

接收路径与重复不透明着色需要共同评估。
保留完整阴影的照明复用按独立候选验证。
纯深度提交按其适用材质和覆盖规则另行评估。
本轮正式预算和既有失败继续有效。
