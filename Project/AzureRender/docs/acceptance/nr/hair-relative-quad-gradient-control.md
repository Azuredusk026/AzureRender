# 头发相对投影与四像素组梯度控制

日期：2026-11-10。
状态：私有组合通过完整头发颜色门槛，公共接入待验。

## 来源与控制

输入沿用相对投影及既有可见量和颜色来源控制。
二十二处材质取样先计算细粒度梯度。
横向梯度读取四像素组的第二号通道。
纵向梯度读取第零号通道。

该选择对应两端附件纵轴关系下的粗粒度取值。
私有程序使用 Vulkan 1.1 子组四像素广播。
原始坐标、颜色表达式和资源绑定保持既有来源。
公共能力仍须声明支持条件及失败策略。

## 完整区域结果

原始 17017 个头发像素的逐通道峰差为一字节。
超差像素为零，原始 73 处失败全部进入门槛。
相对原始生产基线新增的超差同样为零。
整个区域的平均通道误差约为 0.1364714 字节。

控制改变两个头发像素，闭合最后一处失败。
原始遮罩、曝光及一字节门槛保持有效。
此结果来自实际 GPU 最终附件。
生产深度和完整场景接入继续独立验收。
