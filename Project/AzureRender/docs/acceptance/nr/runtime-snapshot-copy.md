## 实现与契约

失效节点通过稳定压缩处理。
存活顺序、材质槽、资源、灯光及阴影配置共同保留。
返回文档和源文档具有独立的值所有权。

适用入口包含独立 Player 和编辑播放呈现。
规则见[呈现快照](../../runtime/game-render-snapshot.md)。

## 分配检查

夹具持有一千零二十四节点及四组材质槽。
节点包含长字符串、已解析纹理路径及对象阴影。
工作预算为一次场景复制加六十四 KiB。
该预算定位重复分配，完整帧 CPU 预算保持八毫秒。

Release 失败控制的快照分配为 8,512,487 字节。
同一输入的一次场景复制分配为 4,301,847 字节。
候选的快照分配为 4,301,847 字节。
该结果表示夹具的动态分配量，不代表实际帧耗时。

内容检查覆盖稳定顺序和失效父节点引用。
节点变换、可见性、对象阴影及灯光筛选通过检查。
修改返回的材质及节点保持运行时源数据完整。
较早快照保持独立值和原有世界状态。
