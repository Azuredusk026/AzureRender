# 反射可信度消费验收

阶段为 NR5-R8-D，验收对象为公共空间过滤资源。
主场景生产和连续历史仍按接入计划实施。
结果见[结构化证据](evidence/2026-10-28/reflection-confidence-consumer.json)。

## 输入与调度

可信度由独立采样层级提供。
粗糙度通道和八位量化具有显式输入选项。
私有调度为 64 字节，公共参数保持 48 字节。
七个描述符按在途槽位隔离。

可信度使用粗糙度层级的向下整数。
级内使用线性采样，层级间采用最近邻。
输出 Alpha 携带可信度，颜色沿公共空间过滤生成。
最终场景消费者使用其权重混合探针反射。

## 数值范围

真实对照保留七级原版八位可信度输入。
Debug 和 Release 各核对 921,600 个像素。
颜色与已验收过滤结果逐位一致。
两种配置的完整浮点输出逐位一致。

23,409 个可信度像素与原版存在一个字节差异。
最大差异为一个八位量化单位，超出该值的像素为零。
该跨 API 采样结果按量化预算登记。
完整场景质量及持续性能仍保留独立门禁。
