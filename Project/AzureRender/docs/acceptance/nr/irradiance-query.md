二十八个已知浮点值校准首批回读。
编码通过 R11 目标保存全部浮点位。

## 运算顺序

相位向零截断，像素坐标向下取整。
融合乘加顺序显式保持来源设备的实际结果。
交换点积的融合顺序会改变噪声，失败记录单独保存。
CPU 与 Vulkan 以同一来源输入共同验收。

零偏移与零幅度返回原表面位置。
查询参数使用现有相机行的三个分量。
主颜色与快照在进入体积查询前消费相同的位置函数。
资源类型、描述符布局及体积载荷保持各自契约。

身体皮肤变体 69 的体积坐标直接使用表面位置。
物理表面采样与 NPR 查询具有明确的调用边界。
NPR 对照在非零表面采样参数下保持原查询位置。
两种着色模型通过公共材质配置分别验证。

双配置各二十一个生产场景用例通过。
覆盖三层体积、网格、物理表面、NPR 和快照。
最大线性像素误差为 `0.004084`，预算为 `0.012`。
NPR 的开启与关闭对照逐像素一致。

四类查询的缺失效果偏差均超过预算两倍。
独立计算的十一个 GPU 输入点通过。
七个来源点的 CPU、GPU 位置误差均为零。
来源噪声保持逐位一致，位置预算为 `2e-6`。

两配置各八项 CTest 覆盖保存重开与旧版本读取。
资源复用、相位报告、有限值及卸载归零检查通过。
