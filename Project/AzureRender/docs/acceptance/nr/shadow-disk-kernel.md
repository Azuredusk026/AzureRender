# 阴影圆盘权重局部成本

## 输入与方法

生产来源为 `b1451cf`，当前主构建保持受检输入。
计算夹具按原捕获的像素顺序消费 921600 个形状索引。
其中 136908 个像素具有滤波调用，其余像素保留空工作分布。
原始调用次数为 11917189，保守空覆盖次数为 4232176。
原始数据及其范围见[圆盘空覆盖](shadow-disk-work.md)。

四十八类代表输入匹配每个像素的调用数及空覆盖数。
半径与小数坐标通过有限搜索选择，属于代表几何输入。
计数程序在 GPU 上逐像素核对全部输入的调用及分支次数。
这些输入保持实际工作形状，准确采样坐标及其他阴影工作分别解释。

基线及候选使用相同输入、设备本地缓冲及输出布局。
三份程序分别实现基线、保守空覆盖及独立计数。
每阶段先连续执行 256 次相同基线预热。
阶段顺序为基线、候选、候选、基线。
每阶段记录八组时间，每组连续执行八次。
数据回读发生在计时区间之后。

## 结果

设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
全部分支计数匹配，基线与候选的 921600 份向量逐位一致。
同步验证错误为零，资源释放后图像及缓冲计数归零。

| 阶段 | 每次均值，毫秒 |
| --- | ---: |
| 前基线 | 0.090485 |
| 前候选 | 0.100894 |
| 后候选 | 0.100681 |
| 后基线 | 0.090665 |

基线合计均值约为 0.090575 毫秒，候选约为 0.100787 毫秒。
候选在该夹具中约慢 11.27%，每次增加约 0.0102 毫秒。
前后基线漂移约为 0.20%。
本结果限定为独立权重计算，纹理读取、光栅化及整帧成本另有归属。
各项分支、运算及硬件资源的单独贡献未测量。
平方根省略比例未形成可采用的局部收益。

## 决策与证据

本单元未启动原生四帧、整场景成对测量或生产集成。
主程序、663 份着色器及源码输入摘要保持一致。
独立目录保存小型形状索引与参数表，完成后保留一天。
原生阶段所需的整套程序目录未创建。
正式供电、CPU 八毫秒、GPU 16.6 毫秒及整体画质继续待验收。
