# 场景直接光机制验收

日期：2026-10-17。
状态：点光、聚光及显式场景照明通过分项验证。
原生单位、局部阴影和空间约束继续实施。

## 数据与生命周期

`LightShape` 定义点光和聚光。
方向为单位向量，指向光源发射方向。
锥角采用弧度半角，内外角相等表示硬边界。
节点变换将本地方向转换到世界空间。

场景文档版本为 5，兼容版本 1 至 4。
关卡、场景交换、编辑事务及预设共享形状契约。
光栅与路径追踪均读取聚光参数。
形状变化使路径追踪历史指纹失效。

聚类分配根据视空间影响体积投影。
跨越相机近平面的光源仍参与分配。
光源缓冲沿用渲染器的逐帧所有权与释放规则。

## 显式场景照明

关卡通过 `renderSettings.sceneLighting` 启用。
该模式使用声明的局部光、环境和自发光。
展示补光、轮廓光及角色亮度下限由展示模式提供。
无光验证同时将环境强度和自发光置零。

现阶段环境漫反射仍采用现有环境近似。
原生 GI、局部反射和角色专用着色另行验收。
局部光支持平滑距离平方与范围指数衰减。
配置、默认值及跨路径语义见[距离衰减](../../runtime/local-light-attenuation.md)。
原生字段与算法见[衰减证据](light-attenuation.md)。
原生强度、灯组激活及画面等价保持待验证。

## 公开夹具

工具为 `tools/native_render/light_lab.py`。
夹具使用正交相机、白色平面与确定性录帧。
平面范围为八米，输出分辨率为 256×256。
分别测量无光、点光和聚光画面。

运行证据位于 `build/runs/20261017-151417-native-render-restoration-e7723b`。
`light-lab-final/metrics.json` 保存实际测量。
无光平面区域最大通道值为零。
聚光外部为黑色，点光对应区域保持受光。

聚光边界误差为 0.4634 像素。
四个角度采样的最大相对误差为 0.5390%。
测量先将输出颜色转换到线性空间。
点光与聚光的比值消除相同表面响应。

七项受影响 CTest 回归通过。
覆盖光缓冲、聚类、路径追踪、保存和场景导入。
源灯光适配器另有角度与非法形状测试。
相等锥角的硬边界由独立 CPU 用例验证。
