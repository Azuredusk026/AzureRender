## 静态运动公式

离线数学入口为 `tools/endfield_native/spline_motion.py`。
其职责是验证导入侧路径与时间换算。
采用 Python 浮点精度，逐位一致性尚未验证。
公共夹具覆盖多槽路径及跨帧批量发射。

创建链 `0x186ada750` 传入完整缓存数组。
原生候选入口为 `0x180507c60`。
绑定名称与函数数组对应，注册控制流仍待核对。
托管入口含热更新分支，当前运行分支尚未观察。

`0x180251f20` 按累计模拟时间计算发射数。
模拟时间增量等于帧增量乘模拟速度。
每次发射保留该帧内已过去的年龄。
发射后的余数留至下一帧。

`0x180507860` 汇总全部槽的源长度。
常量速度分支的寿命等于长度除速度，再乘寿命比例。
寿命比例限制在零到一之间。
`0x1805329a0` 按发射间隔生成预热对象。

`0x1800e7ba0` 按保存的段长选择路径槽。
段内参数为剩余距离除该槽长度。
`0x1800e8970` 使用三次贝塞尔多项式。
到达总长度时取样返回无位置。

`logistics-timing-evidence.json` 保存 21 个发射器结果。
本机描述的寿命与速度均使用常量分支。
计算的墙钟寿命范围约为 13 至 140 秒。
该范围包含中庭外实例，实际可见周期仍待验证。
