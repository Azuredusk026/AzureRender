# 公共采样器验收

阶段为 NR6-C15-S1，公共采样器分项通过。
输入包含标准 glTF 纹理绑定及原版物流环带。
完整还原及持续性能由各自阶段验收。
来源与指纹见[结构化证据](evidence/2026-10-28/gltf-sampler-contract.json)。

## 公共契约

普通及自发光材质读取标准纹理的采样器声明。
映射覆盖六种缩小过滤、两种放大过滤和三种寻址。
同一图像的不同绑定分别保存有效采样状态。
图像元数据按声明字段覆盖来源值。

设置版本二通过 `magFilter` 表达独立放大过滤。
版本一的 `filter` 同时控制缩小和放大。
无采样器时使用材质默认设置。
专用图层及查找表执行各自固定采样约束。

采样缓存按有效放大过滤区分绑定。
关联过滤与显式过滤取值相同时可复用资源。
非法过滤在资源分配前返回诊断。
字段规则见[纹理采样](../../runtime/texture-containers.md)。

## 验证结果

Debug、Release 各通过五项 CPU 回归。
用例覆盖同图像绑定、局部覆盖及非法来源。
查找表复用普通图像时保持自身采样约束。
固定查找表拒绝改变放大过滤的元数据。

独立夹具完成十二组 GPU 捕获及二十四处颜色核对。
最大线性误差为 0.003018867，预算为 0.008。
六组配置配对的图片逐像素一致。
眼睛表面、眼睛 NPR 和投影头发表面完成双配置回归。

真实环带去除补偿用的层级过滤元数据。
公共映射直接消费 `minFilter=9985`。
四组捕获的四十处原版探针通过预算。
最大线性误差为 0.003718728。

全部捕获核对验证诊断及资源释放。
相机数据保持 688 字节，材质数据保持 336 字节。
材质布局为版本十七，着色模块共 199 项。
采样状态沿现有导入、RHI 及缓存传递。
