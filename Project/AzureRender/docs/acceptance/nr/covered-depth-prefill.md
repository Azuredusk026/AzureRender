缺少策略函数的编译失败保留为实际失败控制。

Release 及 Debug 各三十二项 CPU 检查通过。
范围包括两通道、两种描述符及透明度区间。
重建、卸载、四样本回退及原阴影检查共同回归。
运行时刷新及既有资产、脚本和呈现检查通过。

两配置分别在 NVIDIA 及 Intel 执行实际 GPU 读回。
每组覆盖 D16、D32 及零、二、三个颜色附件。

颜色内容保持清除值，同步验证及资源释放检查通过。
