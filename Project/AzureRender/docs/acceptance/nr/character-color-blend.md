日期：2026-10-23。范围为 NR6-C11-R5。

## 输入与实现

公共版本三声明强度、朝向、投影距离和顺序。
目标色使用所属灯的颜色与强度。
契约及分项归属见[运行说明](../../runtime/character-local-light-response.md)。

实际输入使用轴向投影距离及二次范围窗口。
其原始负衰减指数具有模式内覆盖。
离线适配器将已确认参数映射至公共契约。
发射身份、原始常量及坐标来源保存在收据中。

实际混合权重为 0.0363053419。
独立距离公式及最终 RGB 与片元追踪相符。
最大线性误差小于 `1e-7`。
数值符合与完整外观分别记录。

加法灯后执行排序后的混合操作。
漫反射、镜面、双叶、自发光及边缘保持分项可查。
共享函数计算入射方向、距离、圆锥及影响体积。
灯记录保持 144 字节，材质保持 192 字节。
