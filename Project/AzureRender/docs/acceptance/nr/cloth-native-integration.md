# 服饰原生输入与组合照明

日期：2026-10-26。范围为 NR6-C9-S1 的真实输入。
公共响应见[二维高光色带](../../runtime/specular-ramp.md)。
完整服饰区域与 C16 的硬件输出门禁继续验收。

## 输入与绑定

原生绘制 868、853 对应 `cloth_04`。
其范围为 2820 个顶点、7698 个索引。
动态网格由单骨骼 `quan_jnt` 驱动。
静态参考保存捕获姿态下的顶点。

静态顶点与真实截帧的位置误差最大约为 25 微米。
UV 纵向对应的最大误差约为 `2.98e-8`。
切线方向误差小于 `3.88e-7`。
原生纹理约定由 UV 及切线手性共同表达。

基色、参数图和法线保留十二层原生输入。
参数图逐层转换为 `(P.B,255-P.A,P.R,P.G)`。
每层保留独立尺寸及像素摘要。
材质以线性钳制、零级采样消费二维色带。

原生镜面强度一通过 `styleParameters` 显式保存。
材质 AO 由 NPR 颜色响应消费。
间接照明使用独立的场景遮蔽量。
服饰的间接照明法线使用表面法线。

## 照明消费

主灯提供方向及有效性。
定向镜面复用 `characterDiffuseIllumination` 的组合结果。
其入射量为环境项与主光项之和。
四处实际片元的重建误差小于 `1.68e-7`。

捕获候选按原生常量保存材质照明输入。
主候选通过场景 GI 提供间接照明。
普通局部灯继续消费各自的公共响应。
有效主灯缺失时，定向镜面贡献为零。

机制复用现有照明、纹理槽和表面画像。
材质表、实例表及描述符布局保持现行值。
环境照明正控制验证实际能量传递。
原始失败与通过后的同一检查均保留收据。
