# 计算反射材质执行成本

## 结构化归因

本批复用当前 720p 捕获及原事件时间。
录制的命令缓冲绑定状态关联全部 3394 个叶绘制。
已知着色器身份全部匹配，未映射事件为零。
归类过程读取结构化 API，采用已有时间样本。

| 程序组 | 绘制数 | 原记录耗时，毫秒 |
| --- | ---: | ---: |
| 普通提前深度主颜色 | 528 | 5.345 |
| 普通提前深度快照 | 301 | 2.045 |
| 通用主颜色 | 113 | 1.859 |
| 深度专用 | 1478 | 1.588 |
| 扩展照明主颜色 | 4 | 0.736 |

上述为捕获事件的计量，原生帧时间独立验收。
主颜色与快照继续作为主要着色范围。

## 局部控制

仅常量化视图模式的控制未取得足够收益。
首次基线为 30.249 毫秒，末次基线为 16.480 毫秒，首项按漂移排除。
末次基线及独立已有控制支持受检事件约 13% 的改善范围。
该控制保持私有状态。

组合控制进一步限定四个主颜色绘制的提前深度资格。
两个绘制为节点透明度一的不透明材质，两个绘制为混合材质。
主颜色中的实际丢弃条件与深度写入分别核对。

拟采用的实现使用专用常量编号四，默认值保留动态参数。
两端各自预热，按基线、候选、候选、基线记录。

| 范围 | 基线均值，毫秒 | 候选均值，毫秒 |
| --- | ---: | ---: |
| 既有捕获预选的重点事件 | 8.317 | 6.648 |
| 全部记录事件 | 16.471 | 14.604 |

重点事件减少约 20.07%，约占原记录 GPU 时间的 50.5%。
同视野像素规模推算的 1080p 预期节省约为 3.756 毫秒。
该推断供集中评估，原生带宽、调度及完整帧收益继续待验证。

动态回退的九项附件均逐字节一致。
优化控制的最终显示逐字节一致，中间浮点附件有差异。
原生四帧零像素门槛、正式帧预算和整体画质继续有效。
本批生产程序与源码保持原状态，实施见[计算反射视图计划](../../plans/2026-11-07-computed-material-view.md)。
