# 参考深度模板覆盖

版本二材质画像可通过 `referenceDepthStencil` 声明参考深度模板角色。字段包含 `schemaVersion: 1` 与 `role`，用于不透明及裁剪表面。

| 角色 | 参考深度绘制 |
| --- | --- |
| `protect` | 深度和材质裁剪通过后写入保护位 |
| `respect` | 保护位为零时执行原有深度和材质裁剪条件 |
| 普通材质 | 深度和材质裁剪通过后清除保护位 |

含模板角色的参考场景使用 D32S8 附件。每帧清零模板位，先绘制普通及保护表面，再绘制尊重保护位的表面。后者的外扩深度同样读取保护位。外扩阶段写入深度，基础表面保有法线和对象标识的写入权。

参考深度读回采用 D32S8 的深度分面。附件布局迁移覆盖深度和模板两个分面。缺省参考场景使用 D32。模板状态和附件清零由场景扩展 API 17 的 RHI 描述提供。[Vulkan 分面复制](https://docs.vulkan.org/spec/latest/chapters/copies.html)

## 实际附件核对

参考夹具在眉部与虹膜材质声明 `protect`，在头发材质声明 `respect`。纹理、几何及采样器沿用同一份输入。

64 × 64 对照覆盖保护表面、前景清位、后景深度失败、裁剪丢弃和无遮挡。两块设备的固定与索引绑定结果分别逐字节一致，仅深度模式的读回也一致。Intel 对照使用 56 个采样器槽。版本二画像中的无效角色由加载器拒绝，注册检查覆盖场景扩展 API 1 至 17。

实际采集覆盖 49,384 个冻结接收位置和 17,017 个冻结头发位置。下表统计逐通道误差超过一字节的位置。

| 设备 | 完整接收 | 眉部接收 | 头发可见量 | 头发颜色 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 410 | 30 | 0 | 0 |
| Intel | 742 | 30 | 208 | 575 |

两块设备分别有 110 和 109 处原超差位置进入门槛，新增超差均为零。附件变化位于原生保护区域，深度变化 153 处，压缩法线变化 135 处。冻结头发颜色和可见量在各设备逐字节复现。

按同设备原生附件核对 135 个重叠位置，两块设备各有 126 处深度逐位一致。NVIDIA 其余 9 处相差一个浮点编码步长。Intel 有 7 处相差一个步长，2 处相差两个步长。完整可见量继续使用原冻结输入和一字节门槛。

## 构建与验收

Release 和 Debug 分别通过 8 项和 7 项 CPU 检查，各配置在两块设备上各通过 5 项 GPU 检查。895 份着色器程序集均匹配冻结摘要。每块设备的两配置在五类附件和三帧 PNG 上逐字节一致。所有成功采集通过同步验证，卸载时分配计数归零。

原始场景四帧回归用时 144.015 秒。四份 PNG 均逐字节匹配冻结参考，采集清单只包含该场景所用附件。

整体状态为 `failed-user-review`。眉部和脸部的几何法线、接收深度精度及 Intel 头发采样继续按原门槛验收。
