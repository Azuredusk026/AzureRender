## 宿主图像生命周期

正式帧入口见 `src/app/AzureRenderFrame.cpp`。

## 工具布局改写

官方源码定位至 `vk_cmd_funcs.cpp`。
函数为 `WrappedVulkan::vkCmdPipelineBarrier`。
1.46 的第 4716、4717 行重复处理 `newLayout`。
该路径无 `DescriptorBuffers()` 条件。

`vk_common.cpp` 定义对应清理函数。
它把两种呈现布局都转换为 `GENERAL`。
真实交换链的显式呈现屏障因此受到改写。
本候选仅启用交换链设备扩展。

`vkCmdPipelineBarrier2` 存在同类处理。
本轮下载的 `v1.x` 源码也保留该逻辑。
升级到该分支不能直接视为修复证据。
源码来源与 SHA-256 保存在 `sources.json`。

官方入口为[屏障转发源码](https://github.com/baldurk/renderdoc/blob/v1.46/renderdoc/driver/vulkan/wrappers/vk_cmd_funcs.cpp)。

修复候选以描述符缓冲模式作为转换条件。
该条件内同时处理 `oldLayout` 和 `newLayout`。
补丁为 `renderdoc-v1.46-present-layout.patch`。
补丁的 GPU 效果仍需独立候选验证。
