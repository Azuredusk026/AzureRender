静态实例通过共享所有权引用同一读输入。
模型矩阵、形变参数及 GPU 区间继续分别持有。

动态动画及表情拥有独立求解结果。

## 分配与局部成本

六万五千节点夹具检查静态骨架的逐帧分配。
固定描述符路径的分配为 376,551 字节。
索引描述符路径的分配为 376,359 字节。
值复制配置的固定路径为 7,716,988 字节。

两路径都保留逐帧节点透明度输入及原录制命令。
该夹具用于验证规模影响，整帧收益另行测量。
完整场景中的静态资源大多只有一个姿态节点。
大骨架夹具的比例仅适用于该夹具。

私有控制在二十个实际帧内测量同一份静态姿态。
每帧控制覆盖八百六十个实例及八百六十一个节点。
值复制的全部姿态字节按当前读输入核对。
下表保留原始计时开销，各操作独立解释。

| 操作 | 每帧局部均值 |
| --- | ---: |
| 共享引用赋值 | 0.030 毫秒 |
| 姿态值复制 | 0.128 毫秒 |
| 姿态值释放 | 0.074 毫秒 |

共享引用的释放没有计入赋值这一项。
私有控制增加了复制与校验工作，整帧计时属于诊断。
该批热状态检查失败，正式帧时间收益资格未成立。
主要 CPU 热点继续按场景准备、透明排序及动态求解定位。
