# 虹膜覆盖来源

原生帧 10401 的虹膜绘制事件为 846。
该绘制在不透明附件中保留 255 个位置。
全身对照使用同一机位及最终原生颜色。

## 原生绘制顺序

事件 1245 在后续颜色附件中改变 94 个位置。
这 94 处均产生可见的八位颜色变化。
其余所检后续绘制保留虹膜区域的原始值。

| 设备 | 覆盖区域相对绘制前超差 | 覆盖区域相对绘制后超差 | 覆盖区外超差 |
| --- | ---: | ---: | ---: |
| NVIDIA | 3 | 94 | 37 |
| Intel | 6 | 94 | 39 |

各通道按一字节容差计算。
覆盖后附件的 255 个值匹配最终原生颜色。
全身候选的虹膜亮度及相似度见[静态对照](projected-hair-reference-grid.md)。

## 颜色系数对照

从原生绘制前后的线性颜色求出逐点颜色系数。
应用该系数后，覆盖区域超差为八处和十一处。
该对照用于验证原生覆盖的贡献。
生产候选须通过实际材质及图元绘制验收。

近景采用独立的联合显示对照。
NVIDIA 关闭泛光后，左眼矩形内的峰差为一字节。
全身虹膜继续按原生覆盖及底层着色验收。
