# 辐照查询坐标

日期：2026-10-27。范围为 NR4-G7 的查询坐标契约。
运行参数见[接收位置](../../runtime/irradiance-query.md)。
原始浮点来源见[精确查询](irradiance-query.md)。

## 来源与坐标

参考为官方 3534 帧照明事件 8912 的七个硬件查询。
呈现图像与来源缓冲的纵轴相反。
候选世界使用 X 轴镜像，场矩阵保存同一转换。
法线偏移在世界空间计算，场内抖动按逆方向转换。

噪声像素使用明确的左上或左下原点。
视口高度参与纵轴转换，像素坐标先向下取整。
场方向支持正交旋转及镜像，平移独立于方向。
标量抖动保持三个场坐标轴各自的幅度。

## 验证范围

CPU 与 GPU 覆盖七个来源点及七个镜像点。
计算夹具另含既有边界和旋转用例，共十九个输入。
来源噪声逐位一致，最大查询位置误差为零。
位置误差预算为 `2e-6`。

Debug 与 Release 各通过三项 CPU 回归。
版本三支持关卡及场景文档的保存重开。
默认策略使用版本二，版本一提供零偏移参数。
非法策略、像素高度及场方向均有失败检查。

两配置各三十次 GPU 场景采集通过。
覆盖三层场、规则体积、快照、NPR 及两种描述符路径。
配置间及描述符路径间的对应图像逐像素一致。
最大线性误差为 `0.004084`，预算为 `0.012`。

NPR 使用原表面位置，对照图像逐像素一致。
两配置的一百九十三份着色器逐字节一致。
采样复用现有视口、相机行及场矩阵。
验证层诊断及卸载归零纳入每次场景检查。

## 验收边界

默认参数的 2560×1440 图像与既定有效候选逐像素一致。
原生参数诊断图像的平均绝对误差为 `30.282`。
既定候选的对应误差为 `28.803`，单位为八位颜色值。
视觉基准使用既定候选，原生参数快照用于分项诊断。

固定相位 `49` 用于同帧查询核对。
连续帧相位、角色环境量及完整照明继续验收。
实际镜头采用来源选择及 UV1 已核对的独立快照。
正式 NR0 至 NR12 的图像与性能门禁按总计划执行。
