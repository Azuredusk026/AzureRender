# 材质画像输入校验

日期：2026-10-23。范围属于 NR6-C15。
glTF 画像版本仅接受整数 1 和 2。
显式参数向量需要四个有限数值。
功能数组需要互不重复的字符串。

加载器使用保留的原始 JSON 检查字段类型。
领域诊断保留合成、眼睛与无光表面的上下文。
缺省向量继续使用所属材质类别的默认值。
GLB 与 glTF 共用同一解释函数。

新增用例首先因小数版本被接受而失败。
修复后 `AzureRender.CharacterRepair` 通过。
该检查同时覆盖投影头发、眼睛、合成与无光表面。
材质文档检查亦通过，完整统一 Schema 仍待实施。

布局夹具显式设置眼睛和头发类别。
其二十四个浮点分量及逐字节断言保持原条件。
这使输入符合加载器的类别与布局所有权约束。

源码范围为 `GltfLoader.cpp` 和 `CharacterRepairTests.cpp`。
本项校验非法输入，实际渲染外观按各专项验收。
