## 独立材质解释入口

`loadEmbeddedGltfMaterials` 接收嵌入式 glTF 或 GLB。
其输出仅包含原文声明的材质表。
命名节点用于解析 SDF 坐标系，输入无需网格。
图片、采样器和特殊表面共用既有解释器。

输入解析与模型加载共用 128 MiB 字节预算。
所有图片与缓冲必须嵌入，外部资源访问被拒绝。
当前入口用于独立文档接入的公共解释基础。
UUID 依赖及编辑文档接入继续按 C15 实施。

角色夹具验证模型和独立材质的公共参数一致。
外部图片拒绝检查通过。
角色画像、动画姿态及形变加载三项回归通过。
该结果限定于 CPU 解释，新增文档格式尚待接入。
