# 屏幕对象可见量

## 公共接口

`RenderCore` 的 `ScreenObjectVisibilityGpu` 提供独立屏幕图形通道。
输入为设备深度、压缩法线、整数对象身份和对象深度图集。
输出为 `R8G8_UNORM`，红通道为全可见，绿通道为对象可见量。
接收位置重建、偏置、过滤及附件转换在单个片段程序中完成。
同输入模型的依据见[接收输入核验](object-receiver-input-model.md)。

对象身份一至八选择对应记录，零及超出当前记录数的值返回全可见。
记录显式包含列主序仿射投影、单位光方向、光向偏置、法线偏置、图集范围及归一化采样半径。
光方向保持输入精度，长度平方须在 0.99 至 1.01 内。
两项偏置均为零至一万，采样半径为零至一。
图集范围完整位于单位正方形，越过所属范围的采样按全可见处理。
最小接收深度位于大于零、至多一的范围，默认值为 0.01。

视图包含可逆的设备投影逆矩阵、像素偏移和垂直轴约定。
像素偏移每轴位于负一至一，默认值为半像素。
投影逆矩阵定义设备深度重建，对象投影和图集共用独立的正向或反向约定。
深度中的非有限值及越界值返回全可见。
法线采用以 Y 轴为极点的八面体编码，存放于红绿通道。

| 输入 | 支持格式 |
| --- | --- |
| 设备深度 | `R32_SFLOAT`、`D32_SFLOAT`、`D16_UNORM` |
| 压缩法线 | `A2B10G10R10_UNORM_PACK32`、`R16G16_UNORM` |
| 对象身份 | `R8_UINT`、`R16_UINT`、`R32_UINT` |
| 对象图集 | `R16_UNORM`、`D16_UNORM` |

所有输入均为借用的视图，实际格式和范围须符合声明。
法线、身份和普通颜色格式输入位于只读采样布局。
深度格式还支持只读深度附件布局。
调用方发布输入依赖，等待槽位消费者结束后重用，并在销毁前等待在途命令完成。
输出录制提交后可用，消费者保持其只读采样布局。

实例拥有逐槽图像、参数、描述符和图形管线。
每槽图像的逻辑载荷为每像素两字节，参数为 992 字节。
2560×1440 双槽位合计为 14747584 字节，约 14.06 MiB。
维度范围为一至 8192，槽位范围为一至八，逻辑资源累计上限为 256 MiB。
非法配置在上传及命令录制前拒绝，输入视图与所有自有输出保持互斥。

## 构建与设备检查

公共契约用例先保存缺失实现的失败结果，再执行生产实现。
Debug、Release 的主程序、公共模块及关联工具均构建通过，来源清单验证通过。
集中执行两配置各一项公共契约及 NVIDIA、Intel 各一项实际 GPU 用例，共六项通过。
两配置的引擎契约生成步骤均通过。

实际 GPU 用例每设备每配置核对六组、共 1254 个像素。
覆盖正反深度、背景、八个对象记录、越界身份、空记录、邻接图集隔离及槽位重用。
另一组输入使用十六位双通道法线及三十二位对象身份。
同步验证错误为零，释放后的图像及缓冲数量均为零。
这些用例验证独立工具场景，原生校准区域单独核验。

## 原生校准区域

校准夹具把捕获常量转换为公共类型，原始深度和法线直接从保留目录读取。
公共实现消费类型化矩阵、偏置及方向。
参考范围沿用原遮罩的 17017 个像素及每通道一字节门槛。

| 设备 | 逐字节一致 | 一字节以内 | 最大误差 |
| --- | ---: | ---: | ---: |
| NVIDIA GeForce RTX 4060 Laptop GPU | 17017 | 17017 | 0 |
| Intel RaptorLake-S Mobile Graphics Controller | 16719 | 16842 | 33 |

两个设备的同步和释放检查均通过。
NVIDIA 结果证明完整精度计算和真实附件转换可在单个图形通道复现参考。
Intel 有 175 处超出原一字节门槛，该校准项保持未通过。

独立计算诊断记录了重建位置、法线、投影和过滤计数。
相同程序在两设备上的绝对位置及投影出现浮点差异，部分临界采样的计数随之变化。
局部 `precise` 控制仍有 205 处超出一字节，候选保留于诊断目录。
具体编译变换及跨设备数值契约继续待确认。
乘加的规范入口为 [GLSL 扩展指令](https://registry.khronos.org/SPIR-V/specs/unified1/GLSL.std.450.html)。

## 状态与后续

公共通道可独立装配，主场景集成继续待实施。
当前结果分别为公共契约通过、NVIDIA 原生区域通过和 Intel 原生区域未通过。
Intel 后续检查由明确的运算实现或编译控制变更触发，沿用原遮罩和误差门槛。
当前结果进入 P8 的设备精度待项，整体画质维持 `failed-user-review`。
完整头发颜色、CPU 八毫秒及 GPU 16.6 毫秒预算持续有效。
本单元的功能检查与数值对照分别保存，整帧性能在场景集成及收益依据成立后评估。
