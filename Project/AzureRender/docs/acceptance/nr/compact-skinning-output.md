## 输出容量

切线第四分量保持源值位模式。

前后保护区及原始网格均保持字节一致。

容量减少约 62.96%，约为 125.65 MiB。

计算端每顶点写入十个单精度字。
缓冲扩容、取消和成功提交保持原有所有权。
两种配置各有十五份计算或顶点程序改变。
其余 659 份程序保持摘要一致，片元程序全部一致。
