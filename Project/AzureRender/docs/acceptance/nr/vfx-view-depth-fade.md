# 特效视图深度淡出

日期：2026-10-28，阶段为 NR7-L4E。
范围为公共深度范围、材质文档及实际片元消费。
参数规则见[无光照图层](../../runtime/unlit-texture-layers.md)。

## 公共契约

资产模块拥有可选的 `viewDepthFade` 对象。
近端和远端范围采用同单位的绝对视图深度。
各范围非负且严格递增。
解析同时检查单精度转换后的范围。

CPU 评价在启用范围时要求明确的视图深度。
实际片元使用位置与相机前向的点积。
近端、远端及软交界共同决定覆盖权重。
覆盖率限制之后消费一次节点透明度。

材质表版本为十二，大小为 192 字节。
范围与活动标记使用最后两行。
默认画像的保留行继续为零。
模型和完整材质文档共用相同解释及打包。

## 原生来源

正式截帧的绘制 10366 启用了深度淡出。
该次绘制改变颜色目标的 704,777 个像素。
近端范围为 0.5 至 1，远端范围为 100 至 150。
参数与同次绘制的材质常量逐项核对。

候选集合包含十九个明确实例。
各实例保留来源的纹理、采样、坐标和时钟。
几何表达截帧姿态，动画曲线继续独立验收。
逐顶点颜色及透明辅助目标另有接入任务。
