# 材质光照回归矩阵

日期为 2026-11-12。
在对应配置的构建目录运行 `ctest -R '^AzureEngine\.MaterialLightingGpu'` 可执行完整矩阵。

## 采集范围

通用材质及织物分别执行 30 个环境光照用例。
两类材质共执行 24 个对象阴影用例。
三个测试各使用 600 秒时限，覆盖索引绑定及固定绑定。

环境组核对漫反射、反射和探针输入。
对象阴影组核对参考接收、遮挡、禁用、旧照明及材质文档绑定。
每组执行所属像素断言及两种绑定的逐字节图像比较。
线性颜色误差门槛为 0.008。

## 执行记录

首轮 Debug 在 600 秒处停止，已完成的 53 个用例及原始日志保留。
封存该运行释放了活动空间预留。
两种配置共通过六项测试和 168 个采集用例，无跳过。
全部 84 个对应采集的 PNG 摘要在两种配置间一致。
Debug 三组耗时分别为 323.12、394.70 和 245.02 秒。
Release 三组耗时分别为 223.43、311.67 和 169.87 秒。
重新配置后，Debug 登记 604 项，Release 登记 606 项。
两种配置的现有构建产物通过逐项摘要核对。
