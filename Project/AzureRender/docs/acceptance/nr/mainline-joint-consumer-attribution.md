## 定向计时

共享资源队列的批次 `2235` 使用 1920 × 1080 视口、场景机位和灯光、固定 60 Hz 更新步长。
总计运行 360 帧，统计第 121 至 360 帧的 240 份样本。
GPU 阶段与整帧使用相同帧号；CPU 工作与等待采用对应区间。

| 指标 | 均值 | P95 | GPU 整帧均值占比 |
| --- | ---: | ---: | ---: |
| GPU 整帧 | 20.091 毫秒 | 20.894 毫秒 | 100% |
| 主颜色 `character-main` | 8.970 毫秒 | 9.374 毫秒 | 44.65% |
| 不透明快照 `character-opaque-depth` | 5.714 毫秒 | 5.980 毫秒 | 28.44% |
| 阴影 `character-shadow` | 1.836 毫秒 | 1.932 毫秒 | 9.14% |
| 计算反射 `character-compute-reflection` | 1.787 毫秒 | 1.852 毫秒 | 8.89% |
| CPU 工作 | 6.205 毫秒 | 7.106 毫秒 | — |
| CPU 等待 | 13.746 毫秒 | 15.150 毫秒 | — |

`character-opaque-depth` 调用 `recordOverlayDepth`，同时挂载快照颜色与深度附件。
其计时包含这一整段工作，单独的颜色着色成本需要按实际材质范围确定。
主颜色与该通道合计为 14.684 毫秒，占 GPU 整帧的 73.08%。
本场景的主导优化对象为 GPU 上的两个通道。

全部 360 帧的提交计数为平均每帧 1,845.711 次绘制调用及 8.986 次描述符绑定，CPU 记录均值为 1.992 毫秒。
这些计数用于描述提交规模，材质适用比例及像素工作量独立核算。

首轮批次 `2234` 在首帧之前触及 180 秒启动上限，日志保存于归档。
复测将启动上限设为 480 秒，实际进程运行约 181 秒并正常退出，卸载后缓冲和图像计数均为零。
两次启动与一次有效帧采样属于本单元的定向诊断。
本次采样使用设备当时的电源与风扇状态，起止温度读数为 60 °C 和 71 °C，用途为阶段归因。
正式帧率、功率稳定性和长跑状态沿用各自的验收范围。

## 材质组合候选

候选批次限定为既有普通与固定材质的专用片元管线，入口为 `AZURE_ENABLE_COMPUTED_MATERIAL_VIEW`。
渲染器根据设备、深度、视图及已加载材质的照明、覆盖和朝向组合选择管线；资格失配时采用参考族。
契约见[材质视图组合](../../runtime/computed-material-view.md)。

| 项目 | 证据与准入判断 |
| --- | --- |
| 所属热点 | 主颜色与快照颜色、深度整段合计占 GPU 帧时间 73.08%，热点占比条件成立 |
| 预期工作量 | 在实际适用材质域内减少无效片元组工作及动态分支；本次标准程序的优化请求和选择均为零，当前减幅待量化 |
| 整帧收益 | 当前版本待实测。联合两阶段成本的 20% 为 2.937 毫秒，仅表示规模门槛；它依赖实际可优化工作比例 |
| 历史依据 | `01cc6b2` 的同宿主参考、候选、参考短测节省 3.139 毫秒；该值属于历史候选和当批输入，作为方向依据保存 |
| 关联修改 | 有界候选族、按材质组合准备、运行资格与回退，以及着色程序目录约束应在同一批次审阅 |
| 画质成本 | 同源参考与候选需通过受影响输出核对；导数、深度、覆盖及透明顺序保持现有契约 |
| 实现成本 | 增加 128 份候选程序及按材质准备的管线，需要测量准备耗时、进程工作集与设备本地内存 |
| 目录边界 | 当前 897 份程序加 128 份候选程序的静态枚举为 1,025，CMake 的上限为 1,024；需在现有容量内形成可构建方案 |
| 当前结论 | 保留为待准入候选；当前版本的工作量减幅和整帧预期收益尚待建立，运行实现保持现行默认值 |

历史[材质组合管线范围验收](material-viewquad-pipeline-scope.md)记录四帧累计请求 3,004 次、选择 2,816 次、准备 108 份管线及约 47.94 秒准备耗时。
选择次数描述资格覆盖，性能收益按实际消费工作量核算。
[主线材质候选采样](material-viewquad-integration.md)保存历史同宿主计时、图像及内存证据。

## 集中验证条件

候选按 [AGENT.md](../../../../../AGENT.md) 的调度规则进入实施：热点占相关处理器帧时间至少四分之一且预期减少其工作量 20%，或预期整帧节省 GPU 3 毫秒、CPU 2 毫秒。
成本依据须匹配当前程序、实际适用材质及冻结输入。
本单元记录的阶段占比满足热点定位用途，候选的当前减幅证据属于后续准入输入。

候选具备准入条件后，在同一来源、产物、驱动、视口及固定更新步长下集中执行一次参考、候选、参考短测。
两端参考需保持足够稳定，以判断净收益。
同批核对受影响画面、深度与覆盖模式、设备回退、描述符兼容、资源释放及准备和内存成本。
显著收益成立后按交付范围安排 1,800 帧采样。

阴影梯度与重复采样探针采用既有淘汰记录。
快照零样本绘制的历史耗时上界为 0.120832 毫秒，属于 720p 捕获，其绘制数量比例独立于耗时比例。
表面辐亮度缓存采用既有性能及内存结论。
这些证据用于限定当前候选范围。
