# 级联遮挡深度验收

日期：2026-10-27，阶段为 NR3-S1。
范围为公共级联阴影及实际主场景。
完整视觉与性能门禁继续按总计划执行。

## 原因与复现

来源为官方 3534 帧及相同相机的实际候选。
两处面板都处于第二级联。
右侧遮挡点位于级联中心上游 24.133 米。
失败投影的上游范围为 23.5 米。

CPU 射线击中候选中已有的墙体三角形。
左侧遮挡点位于上游 21.468 米，处于失败投影范围内。
三份实际网格组成最小 GPU 场景。
失败画面中左侧遮挡，右侧错误受光。

## 公共机制

级联接收范围沿用相机切片与阴影距离。
遮挡范围沿光线向上游覆盖一个阴影距离。
横向投影与像素对齐保持各自计算。
上游距离取两倍半径与半径加阴影距离的较大值。

深度范围与世界直径分开上传。
滤波偏移按横向世界像素计算。
深度比较及遮挡间距按实际深度范围换算。
机制支持透视、正交及不同阴影距离。

## 验证边界

数值夹具覆盖实际遮挡、窄正交范围及宽切片。
非法距离、非有限值及溢出半径产生错误。
GPU 场景覆盖 50 米和 80 米距离及两种描述符。
两配置分别执行级联、滤波、块界及录制回归。

完整场景按默认查询与原生查询策略复采。
独立阴影诊断核对两处实际面板。
原版遮罩在整张图的主光通道均为零。
其他物体、材质与组合照明仍按正式 NR 门禁核对。

默认查询的完整画面误差为 19.1048 字节。
原生查询候选的对应误差为 20.6241 字节。
实际左右面板的阴影可见性均为零。
两种配置和描述符的最小场景图像逐字节一致。

每配置的五项 CTest 和二十七组可见性采集通过。
镜像、双面、透明、深度及裁剪边界具有既有回归。
法线与切线的平均图像差均为零。
全部运行的资源卸载检查通过。

2560×1440 单帧 GPU 记录为 338.91 毫秒。
其中阴影记录为 53.61 毫秒。
该记录用于分项观测，持续性能另按 NR12 验收。
