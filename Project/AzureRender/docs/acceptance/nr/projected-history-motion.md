# 投影历史运动验证

日期：2026-10-31。
本项为 NR5-R8-R8 的公共运动契约。
场景成功提交历史由后续装配任务持有。
范围及接续见[实施计划](../../plans/2026-10-31-projected-history-motion.md)。

## 公共参数

线性 UV 位移可附加实际采样抖动差。
两个偏移分量均须有限，范围为负一至一。
响应要求及偏移采用公共组合与独立射线的同一契约。
非法值及编码组合在记录状态变化前拒绝。

常量布局为四百八十字节。
两个偏移分量及响应开关占用既定空闲分量。
输入绑定和在途槽位的所有权保持现行契约。
设置范围见[射线接口](../../runtime/projected-reflection-ray.md)。

## 红测来源

接口红测因缺少位移和响应成员而编译失败。
冻结 GPU 程序接收了二千四百三十二个无效历史样本。
同一程序遗漏 UV 校正时，预期镜面命中数为零。
两次运行的验证层及资源计数均正常。

独立部分混合控制使用四分之一的历史位移。
遗漏响应检查时，无效历史仍产生二千四百三十二次命中。
该控制验证 `motionBlend` 小于一的接收要求。
当前帧模式使用自己的颜色和深度完成生产。

## 运动与响应控制

独立镜面由固定相机、倾斜平面和双色墙构成。
每个案例包含二千四百三十二个检查像素。
既有位置、颜色及百分之七十五的命中门槛保持有效。
位移校正通过独立前帧相机和带偏移的运动场核对。

裁剪及部分响应分别产生四分之一接收权重。
完整可信度缓冲按该比例检查，量化误差至多一个字节。
两类响应的颜色和足迹与完整接收逐字节一致。
过滤后的可信度同时进入最终结果检查。

背景、缺失、强反应及非有限响应具有拒绝控制。
运动深度越界、前帧深度为零及 UV 越界分别核对。
默认响应要求与完整跟踪控制使用相同的数值对照。
公共组合和逐个装配的组件分别生成 GPU 输出。

## 来源与装配边界

冻结来源采用三份完整图像及两种瓦片顺序。
默认运动选项以完整输出的零字节差异为门槛。
已有相机、表面准备和过滤组合按完整读回回归。
实际 Player 使用当前帧路径核对默认图像。
