## 运行契约

能力归属场景渲染器的公共表面响应。
材质使用二版脸部 SDF 配置。
启用条件包含脸部类别、有效头部及场景开关。
纹理与头部状态沿用现有材质和实例所有权。

该能力可供其他具有双图脸部 SDF 的角色使用。
固定描述符和索引描述符消费同一着色算法。
独立平面夹具验证公共契约。
角色项目消费同一材质与实例路径。

头部矩阵的三列分别为右、上、前方向。
动画头节点与配置基底组合后进入实例数据。
主光转入头部空间，以其横向分量选择镜像。
法线复用主光色阶的同一次 SDF 采样。

```text
F = mat3(instanceFaceFrame)
localLight = transpose(F) * mainLightDirection
positive = localLight.x > 0
sampleUv = [positive ? u : 1-u, v]
S = sampleLod0(SDFLightmap, sampleUv)
nx = (2*S.b-1) * (positive ? 1 : -1)
localNormal = normalize([nx, 2^-14, 1-abs(nx)])
worldNormal = normalize(F * localNormal)
Nsdf = normalize(mix(worldNormal, geometryNormal, SDFMask.g))
```

矩阵变换后先归一化，再执行遮罩混合。
独立遮罩的绿色通道决定几何法线权重。
权重为一时使用几何法线。
