# 分量曝光与高光采样核验

日期：2026-10-24。
本项属于 NR7-AA4 的测量能力及输入诊断。
配置见[分量测量](../../runtime/component-radiometry.md)。
完整高光、发丝和服饰的动态门禁保持待验。
程序、输入及结果见[证据清单](evidence/2026-10-24/component-radiometry.json)。

## 公共能力

命令行通过 `--qa-exposure` 设置诊断曝光。
缺省为零，支持负八至正八 EV。
非有限值、越界值和不兼容隔离被明确拒绝。
分类、法线及完整画面使用各自规定的曝光入口。

显式曝光复用现有调色通道。
历史合成及作者场景数据保持现有职责。
采集清单同时记录请求值与实际调色值。
材质表、纹理槽及渲染器 API 保持现行布局。

公共平面分别验证直接漫反射与自发光。
每个分量检查缺省、零、负二及正二 EV。
缺省与零 EV 的图像逐字节一致。
正负曝光与独立线性量化区间的误差小于一字节。

两种配置各通过十九项受影响检查。
两种配置各保留八组公共 GPU 采集收据。
场景卸载后 GPU 缓冲与图片均归零。
命令行保留缺失值、边界及组合冲突的红绿验证。

## 实际角色参考

原生姿态、材质文档、图片字节及灯组均被冻结。
原生输出为 1280×720，参考为 5120×2880。
参考采用模式零，并在线性显示域按 4×4 平均。
最小描边宽度及接收像素偏移按采样尺度换算。

原生头发可见遮罩生成内部与一像素边界区域。
时间序列保留三十二帧，末八帧分别统计。
隔离视图的场景曝光由诊断传输规则解释。
定量高光参考使用显式负四 EV，饱和像素数为零。

| 采样输入 | 发冠八相位能量比 | 头发内部八相位能量比 |
| --- | ---: | ---: |
| 来源采样 | 0.9012–0.9053 | 0.9085–0.9122 |
| 双法线采用细两级层级 | 0.8880–0.8909 | 0.8905–0.8931 |
| 参数图采用细两级层级 | 1.0086–1.0116 | 1.0115–1.0143 |
| 参数图与双法线均采用细两级层级 | 0.9953–0.9974 | 0.9921–0.9949 |
| 双法线采用线性层级过滤 | 0.9002–0.9037 | 0.9070–0.9097 |

单独改变参数图可显著改变高光能量。
该变化用于定位采样与非线性响应的耦合。
层级候选仍有发丝边界相位超出 2% 预算。
主次叶、条纹、峰值及动态残差继续独立核验。

## 后续验证

完整高光响应按采样足迹进行积分验证。
参数、双法线、二维色带及条纹共同进入检查。
每个采样位置先计算贡献，再统计组合能量。
来源采样与输入字节作为兼容对照保留。

公共夹具和实际角色均须通过独立高采样参考。
参数图层级偏移候选保留为诊断输入。
正式入口晋升继续遵守 NR8-V2 与 NR12。
