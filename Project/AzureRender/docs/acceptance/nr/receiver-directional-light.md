## 机制与来源

场景表面与角色分别选择所属接收组的主方向光。
有效能量由强度和线性颜色亮度共同确定。
同能量使用稳定身份决定顺序。
关闭、零能量及接收位关闭的条目按所属规则筛选。

`primaryDirectionalLight` 接收明确的接收组类型。
默认查询保留全部条目的既有调用方式。
非法接收类型触发错误，结果指针由源集合持有。
接口归属既有 `src/scene/` 模块。

表面主光持有场景级联阴影及其接收偏移。
角色主光驱动色带、头发、脸部坐标及对象阴影。
两组通过既有 GPU 灯索引与阴影所有者标记装配。
相机常量布局、材质布局及文件格式保持原契约。

独立角色主光的主光阴影输入为一。
对象阴影和材质遮罩继续按各自声明采样。
所选主光的直接贡献保持接收位检查。
规则见[方向光](../../runtime/directional-lights.md)及[接收范围](../../runtime/light-receivers.md)。
