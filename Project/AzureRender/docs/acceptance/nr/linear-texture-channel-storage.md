# 线性纹理通道存储

日期：2026-11-10。
状态：公共契约、双设备及原生四帧通过。
实现范围为 RHI 分量映射与采样纹理缓存。
正式内存、性能及完整颜色继续验收。

## 存储契约

共享身份使用完整 RGBA8 字节及有效上传参数。
完整线性 mip 链逐字节确认通道关系。
一至两个独立通道使用 R8 或 RG8 存储。
视图分量映射保持全部 RGBA 采样值。

尺寸、mip 数量及采样器保持有效请求值。
sRGB、边框采样及 GPU 生成 mip 使用 RGBA。
设备或格式能力不足时使用完整 RGBA 表示。
失败申请、封存及清空遵循现行缓存所有权。

三个新增契约先取得 API 缺失的预期编译失败。

原超时日志及十二项实际结果保持原记录。
补验耗时约 10.12 秒，验收门槛保持有效。

NVIDIA 与 Intel 的两配置各通过 486 组 GPU 条件。
每组设备与配置实际覆盖 378 组收窄表示。
每组完成 7962624 次分量逐位比较。
验证检查包含告警、错误及销毁边界，结果均为零。

夹具覆盖完整 mip、奇数尺寸和单行图像。
过滤范围包含显式层级、梯度及各向异性。
重复、镜像重复及边缘夹取分别核对。
