# 独立覆盖椭圆选级

覆盖对象版本二通过 `lodPolicy` 声明椭圆选级。
独立图像保留来源层级、采样偏移和透明通道。
主颜色、深度、描边和阴影共享选级函数。
参数和配置范围见[独立裁剪图](../../runtime/material-coverage.md)。

## 材质契约

材质解析核对版本、策略及图像采样器。
完整材质文档通过纹理 UUID 解释图像。
材质图保存和重开保留策略字段。
单样本空间配置使用该策略。

## 合成层级

测试图像有七个来源层级。
第一级不透明，其余层级透明。
两轴梯度均约为每像素 2.4 个纹素。
层级偏移为负一，椭圆计算值约为 0.763。

固定不透明及固定透明图像分别提供对照。
Debug、Release 双设备均与不透明对照逐像素一致。
透明对照与该结果相差 65536 个覆盖像素。
NVIDIA 上的时序和多重采样均返回明确的配置诊断。

## 原生头发

实际 Player 通过公开材质字段加载同一覆盖图。
采集清单记录十个来源层级与负一采样偏移。
每配置及设备采集四帧，共十六帧。
每帧的 17017 个遮罩像素与隔离对照一致。

同设备的 Debug 与 Release PNG 摘要一致。
原生颜色的超差按各设备的完整区域统计。

| 设备 | 超过一字节的像素 | 最大通道误差 |
| --- | ---: | ---: |
| NVIDIA | 43 | 5 |
| Intel | 597 | 97 |

Intel 在坐标 `[1326,177]` 的通道最大误差为两字节。
该点的颜色为 `[71,20,23]`，原生颜色为 `[69,18,23]`。

头发颜色采用完整遮罩及每通道一字节门槛。
覆盖选级的来源对照见[头发覆盖层级](native-hair-coverage-lod.md)。

## 深度输入

头发图元的 43044 个索引与参考来源逐位一致。
11564 组 UV 与参考来源逐位一致。
应用模型节点矩阵后，34692 个坐标分量逐位一致。
项目声明的参考投影和位置帧与来源逐位一致。

实际参考深度和可见量按各自门槛验收。

## 构建与回归

Release 构建编辑器、Player 和启动器。
Debug 构建 Player，两个配置的材质测试均通过。
程序目录包含 885 份产物，两配置摘要完全一致。
44 份覆盖变体通过 SPIR-V 校验及选级指令检查。

设备选级通过索引与固定描述符回归。
每配置核对四个生成层级用例。
两配置的实际采集均正常释放缓冲和图像。

当前 Release 重采冻结场景四帧。
四份 PNG 摘要均与冻结记录一致。
整体画质状态为 `failed-user-review`。
