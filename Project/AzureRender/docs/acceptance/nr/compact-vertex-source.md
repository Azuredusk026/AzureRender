## 成本结果

28 字节布局采用前参考、候选、后参考三个独立进程。
分辨率为 1920×1080，固定步长为每秒二十四帧。
每个进程预热三百帧，再选取三百帧。

| 指标 | 两侧参考均值 | 候选均值 | 名义减少 |
| --- | ---: | ---: | ---: |
| GPU 整帧 | 22.836130 ms | 22.506210 ms | 0.329919 ms，1.44% |
| 阴影区间 | 2.270518 ms | 1.969412 ms | 0.301106 ms，13.26% |
| 场景区间 | 20.220788 ms | 20.189867 ms | 0.030921 ms，0.15% |

整帧参考漂移约为 1.33%。
采用门槛要求整帧至少减少 2%，且差值达到两倍参考漂移。
本候选未达到门槛。
候选 GPU P95 约为 22.678478 毫秒，CPU 工作 P95 约为 6.394995 毫秒。
固定功率及正式热条件仍需独立验收。

24 字节候选的短时名义整帧差为 0.642594 毫秒，约为 3.22%。
其六十帧预热与六十帧样本仅属于该来源，画面门禁失败。
该数据保持诊断范围。
