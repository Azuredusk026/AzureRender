# GPU 光照夹具运行时间

日期：2026-11-13。

NPR 光照夹具覆盖 54 个场景，角色局部光照夹具覆盖 33 个场景。
每组最多同时启动四个独立 Player，每个场景拥有独立工作目录、截图目录及验证层临时目录。
采集完成后，运行器按原场景顺序汇总证据并执行跨场景比较。
每次启动限时 120 秒，两个注册用例各限时 300 秒。
Debug 启用 Vulkan 验证层，Release 按发布配置运行。

| 注册用例 | Release | Debug |
| --- | ---: | ---: |
| NPR 光照 | 123.13 秒 | 207.17 秒 |
| 角色局部光照 | 71.33 秒 | 130.90 秒 |
| 聚类光照投影 | 8.44 秒 | 16.63 秒 |
| 投影头发光照 | 86.80 秒 | 130.97 秒 |

八个场景的重复对照中，串行耗时 91.00 至 93.98 秒，四路并行耗时 26.17 至 26.41 秒。
各场景的截图文件摘要一致。
