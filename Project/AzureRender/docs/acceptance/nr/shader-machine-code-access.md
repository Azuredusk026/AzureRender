该视图返回统计文本，未取得 NVIDIA 机器指令。
普通主颜色绘制的基线报告为 128 个临时寄存器。
相应二进制大小为 108928 字节，执行组大小为 32。

替换后的反射对象具有新的资源身份。
直接查询出现片元请求返回顶点统计的阶段错配。
使用原资源身份可恢复片元标签，数值仍与原统计相同。
该结果不具备证明替换程序资源用量的资格。

本地内存原始字段缺少合理的物理容量解释。
该字段保留在记录中，内存预算继续使用分配器计量。
本单元未读取性能计数器，生产源码及程序保持原内容。
