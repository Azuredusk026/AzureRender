# 裁剪纹理层级生成成本

本项优化资源加载阶段的双线性覆盖率计算。
场景纹理上传与资源导入共用层级生成入口。
性能结果按 CPU 层级生成阶段统计。

## 覆盖率求解

每轮面积估计使用同一个透明度缩放值。
层级超过 64 个纹素时，先量化 256 种输入值。
双线性面积估计从表中读取四个角点。
至多 64 个纹素的层级直接量化。

以 2,048 × 2,048 输入的首个缩小层为例。
单轮覆盖率扫描读取 4,194,304 个角点。
该轮的透明度量化次数上界为 256。
点采样、插值次序和覆盖率求解契约见[裁剪纹理缩小覆盖验证](alpha-mip-footprint.md)。

## 配对计时

参考为主线 `9b0b705` 的层级生成函数。
参考和查表版本编入同一 MSVC Release 测量程序。
各组预热后交替运行七对，统计完整层级生成的中位数。
五组输入的全部层级字节与参考一致。

| 输入 | 采样 | 参考 | 查表版本 | 耗时变化 |
| --- | --- | ---: | ---: | ---: |
| 512 × 512 周期裁剪 | 双线性 | 31.920 毫秒 | 13.288 毫秒 | 减少 58.4% |
| 2,048 × 2,048 周期裁剪 | 双线性 | 557.979 毫秒 | 263.025 毫秒 | 减少 52.9% |
| 1,001 × 513 连续透明度 | 双线性 | 71.472 毫秒 | 26.688 毫秒 | 减少 62.7% |
| 1 × 513 单列纹理 | 双线性 | 0.192 毫秒 | 0.143 毫秒 | 减少 0.049 毫秒 |
| 512 × 512 周期裁剪 | 最近邻 | 10.663 毫秒 | 10.804 毫秒 | 增加 0.141 毫秒 |

结果适用于表中的加载工作量。
时间包含颜色过滤与层级输出。
场景整体加载与运行帧耗时分别按其所属范围测量。

## 回归

Release Player 与两个受影响测试目标完成构建。
两项 CTest 覆盖层级面积、来源字节和纹理缓存。
实际 Player 在 NVIDIA 595.79 上完成九组裁剪覆盖检查。
双线性探针的最大相对覆盖误差为 1.05%。

独立覆盖纹理的四组采集均通过。
标准与独立覆盖路径的图像一致。
绑定数组与固定描述符的对应图像一致。
GPU 采集的缓冲和图像卸载计数归零。
