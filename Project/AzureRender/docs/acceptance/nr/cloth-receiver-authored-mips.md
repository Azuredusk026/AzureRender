# 服饰接收法线层级

服饰一的参考夹具使用原生 BC5 十二级法线纹理。
夹具按现有 UV 方向保存每一级压缩块。
块内像素索引及块行执行纵向翻转，端点及绿色通道保持原值。
十二级均通过压缩块往返和解码逐位置核对。

## 夹具范围

夹具仅替换服饰一材质的法线纹理绑定。
场景、几何缓冲、材质采样器及 Player 使用固定输入。
运行日志确认 Player 为目标法线槽载入十二级数据。
纹理来源及采样状态见[原生服饰接收法线输入](native-cloth-receiver-normal-input.md)。

## 接收可见量

事件 377 的法线区域包含 16,629 个位置，完整接收区域包含 49,384 个位置。
每通道采用一字节容差。

| 设备 | 服饰法线区域超差 | 服饰法线区域新增超差 | 完整接收超差 | 完整头发可见量超差 | 完整头发颜色超差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVIDIA | 1,345 | 42 | 1,707 | 0 | 0 |
| Intel | 1,339 | 38 | 1,966 | 208 | 575 |

参考深度、对象身份及完整头发的颜色和可见量逐字节匹配固定对照。
其余原生法线写入区域的可见量逐字节匹配固定对照。
同一设备的 Release 与 Debug 对应附件和三帧颜色逐字节一致。
默认四图使用相同的 Player 和固定场景输入。
完整接收及联合画质状态为 `failed-user-review`。

## 层级分布

CPU 对照按引擎的法线平均方法重建 PNG 层级。
第一级的 RG 最大通道误差在第 95 百分位为 6 字节，第二级为 9 字节。
有效三角形的 100,152 个角点中，有 100,049 个切线符号与夹具 UV 推导的符号一致。
正式验收使用实际 Player 的附件读回。
原生采样参数和采样后法线重建继续分别核对。
