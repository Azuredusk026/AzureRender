# 场景角色材质验收

日期：2026-10-22。
范围为 NR6-C1 的场景着色与 NR6-C2 的原生材质画像。
实施依据见[角色与物流计划](../../plans/2026-10-22-character-logistics-restoration.md)。
原生角色外观继续按 NR6 和 NR12 的完整门禁验收。

## 公共着色能力

材质画像版本 2 的角色表面消费实际场景灯光。
漫反射色带、双叶高光与轮廓光逐灯合成。
光源颜色、强度、衰减和阴影进入同一计算。
普通 PBR 表面使用通用照明分支。

`diffuse-ramp` 绑定线性单行漫反射色带。
`silhouette-outline` 为材质启用外轮廓。
头发数据纹理保留漫反射与高光两组法线。
字段及采样契约见[角色材质画像](../../runtime/character-material-profile.md)。

## 原生资产范围

莱万汀候选包含 13 份材质。
其中 12 份具有显式角色画像，特效保留通用类别。
分类为皮肤 2、衣料 5、覆盖层 2、脸 1、发 1、眼 1。
源容器、对象编号、纹理摘要和未消费槽位均有收据。

画像绑定原生头发四通道数据及漫反射色带。
脸部 SDF、影色表和原有材质参数保持有效。
灰度遮罩覆盖层采用基础颜色与透明度转换。
该转换仍需原生乘法混合及模板测试验证。

输入与候选的二进制尾块逐字节相同。
9 段原生动画的 JSON 也完全相同。
每段包含 939 个通道，合计 8451 个通道。
来源指纹见[结构化验收收据](evidence/2026-10-22/character-scene-lighting.json)。

## 原生着色器与画面对照

原包已提取头发、眼睛及覆盖阴影的 DXBC。
匹配的头发像素程序为 263，眼睛为 52。
变体选择消费源材质关键词，字节码摘要可复核。
提取使用只读资源解析，实时帧绑定仍待采集。

覆盖阴影颜色通道使用 `Zero/SrcColor` 乘法混合。
该通道关闭深度写入，模板读取遮罩为 20。
深度预通道具有独立的深度与模板规则。
这些证据要求补齐覆盖层的颜色合成和遮挡语义。

真实角色近景可见较密的白色发丝高光。

头发数据通道有来源依据，具体坐标系需逐项复核。
