## 所有权与边界

缓存的可写阶段保留完整身份像素。
内容碰撞仍按全部像素及有效上传参数核对。
`seal()` 结束写入并释放 CPU 身份分配。
GPU 图像、视图及采样器继续由缓存拥有。

结束写入支持空缓存和重复调用。
后续申请在哈希、分配及统计修改前报告错误。
被拒绝的右值输入保持内容和分配。
`clear()` 销毁资源并恢复可写状态。

渲染器在全部加载任务成功完成后结束写入。
材质和描边资源在同一可写阶段完成共享。
完整加载及分步加载使用相同完成边界。
交换链重建继续借用既有材质绑定。
