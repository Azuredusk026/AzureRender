日期：2026-10-22。范围为 NR6-C12。

原生完整角色外观仍按 NR6 独立验收。

## 公共契约

`nprDiffuse.indirectNormal` 为可选字符串。
`surface` 为兼容默认，`world-horizontal` 为水平模式。
水平模式将世界法线的 Y 分量设为 `2^-14`。
归一化结果进入环境漫反射和辐照体积。

该输入来自已完成法线贴图处理的世界法线。
直接光、镜面和颜色相机方向分别保持其输入。
静态材质表首行 W 分量持有模式。
布局保持九十六字节，纹理槽数量保持九个。

字段与生命周期见[角色漫反射组合](../../runtime/npr-diffuse.md)。
非法模式与非字符串输入触发导入错误。
既有五项基础字段仍须显式提供。
