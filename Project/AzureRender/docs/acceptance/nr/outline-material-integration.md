## 平滑方向

几何法线、半球方向及八面体方向共用可选 UV1。
输入为 `FLOAT VEC2`，分量范围为负一至一。
基础顶点及蒙皮布局保持现行结构。
八面体模式可表达负半球方向。

源切线帧的最大法线切线内积约为 `0.012207`。
导入帧执行归一化与正交化。
原始方向需转换到该帧后编码。
直接沿用源坐标的投影偏差可达 `0.9961` 像素。

真实样本包含 11,564 个平滑方向。
计入节点变换后，79 个方向位于负半球。
八面体重建的最大分量误差为 `7.35e-8`。
源事件 440 的六个独立投影控制保持既定预算。
共享数学与候选原始顶点分别保存验证结果。
实际捕获的扩张投影最大误差为 `0.000758` 像素。

转换函数位于 `tools/native_render/outline_directions.py`。
其输入包含源帧、导入帧及坐标变换。
转换工具持有源身份和数据解释。
引擎按公共编码读取方向。
