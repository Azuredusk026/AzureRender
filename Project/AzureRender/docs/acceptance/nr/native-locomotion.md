## 共享动作与剩余输入

两份角色控制器均精确引用共享 Lady 行走和跑步。
控制器也引用莱万汀专属附加动作层。
对应控制器与引用证据保存在 `nr9-controllers/`。
运行时选用哪份控制器仍需继续确认。

共享动作有 32 条变换路径不存在于目标角色层级。
目标 Avatar 的路径表及骨架编号表也没有这些路径。
显式目标投影允许将这些轨道保留为未绑定记录。
默认严格策略要求全部轨道具有有效目标。
原始 ACL、全部轨道采样及常量验证均保留。
目标 Avatar 引用但源层级缺失的路径会拒绝导入。
CRC 歧义、变换块不对齐和全轨道未绑定也会拒绝。
专属附加层需要与其原生基础层共同评价。

行走入口片段携带恒定 `MagicaClothWeight=1`。
参数名通过实际控制器字符串表的 CRC32 确认。
该值证明动作声明了衣物物理权重。
物理解算器、碰撞与衣摆状态仍需独立恢复。
