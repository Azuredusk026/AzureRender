# 管线直接编译定位

本轮使用独立进程创建并查询同一管线句柄。
设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
片元索引由实际执行阶段确定。
查询使用 Vulkan 的管线可执行信息扩展。

## 输入与范围

片元输入匹配当前普通材质提前深度程序。
按生产命令重编译的原程序逐字节一致。
私有夹具显式选择普通不透明专用常量。
顶点输入、三个颜色输出及深度状态均有固定描述。

每项查询均直接关联本次创建的管线。
私有描述符容量及附件格式保存在复现源码中。
这些状态与原生完整管线分别持有身份。
本轮结果用于编译定位，整帧耗时独立验收。

所有控制的片元寄存器数保持一百二十八。
标准序列的机器代码增大约 5.4%。
其余规模差异没有形成显著收益依据。
这些候选保持隔离，本轮原生批次未启动。

提前阴影候选用于缩短表面数据的存活范围。
普通材质保留相同阴影输入和运算表达式。
均匀缓冲原型仅声明一百二十八份描述。
实际采用还需容量、设备及生命周期设计。

## 查询边界

创建标志显式请求统计及内部表示。
受检计算与图形管线均返回空的内部表示列表。
驱动未提供可读取的机器指令。
局部内存原始值仍存在不合理的高位数值。
该字段原样保存，容量及寄存器溢出结论另行取证。

全部最终夹具通过验证层检查，告警和错误均为零。
诊断过程的队列提交数为零。
编译统计和机器代码大小分别记录。
这些数值不能单独证明运行时的停顿原因。

生产一千六百一十五份输入保持原摘要。
实际生产程序及六百六十三份着色程序保持一致。
原 CPU、GPU、图像及完整画质条件继续验收。

## 环境与接续

驻留重放的重新预检报告电池电量百分之六十九。
驱动功率限制为四十瓦，GPU 空闲且温度四十八度。
交流供电门禁立即拒绝，重放进程未启动。
原八十瓦稳定条件继续保留。

后续优先建立实际工作量下降及有效成对计时。
编译规模不足的候选按现有调度条件结束评估。
图像采样边界按 Q1 的来源与像素条件继续定位。
