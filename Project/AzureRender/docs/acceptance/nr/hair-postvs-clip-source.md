## 顶点配对

两端均有 11564 个顶点及 43044 个索引。
三角形逐一配对，索引顺序逐三角形反向。
原生和 Vulkan 步长分别为 132、256 字节。
实际签名、缓冲长度及 SHA-256 均已记录。

全部顶点的 U 分量逐位一致。
V 分量的最大差为 `2.9802322387695312e-8`。
裁剪 X、Y、W 的峰差分别约为
`1.3411e-7`、`1.4305e-6`、`9.5367e-7`。

两端深度采用不同约定。
原始裁剪 Z 数值分别保留于实际缓冲。
本项通过 X、Y、W 核对投影及插值来源。

## 原生投影重建

实际常量提供投影矩阵及帧内抖动。
实际顶点输出提供摄像机相对位置。
重建保留乘法、融合乘加及独立加法边界。
全部 11564 个裁剪向量逐位一致。

CPU 使用单精度视口变换及二百五十六分之一像素网格。
再以透视权重计算最接近实测 UV 的三角形。
五处模型与实际取值的最大差约为 `1.1303e-7`。
其中四处对应已知较大 UV 差异。

该模型为几何投影提供后续控制依据。
三角形可见归属及候选颜色仍需实际 GPU 核对。
完整颜色继续按原始区域及一字节门槛验收。
