## 结果与范围

原生成对短检的 GPU 收益未成立。
生产已恢复至 `8c78732` 的运行实现。
完整画质、原帧预算及正式持续性能继续待通过。

实现边界见[批次计划](../../plans/2026-11-07-shadow-visibility-reuse.md)。

## 机制与检查

候选保存同帧的完整精度阴影值。
身份包括深度位、实例、源索引三角形及材质。
缓存读取前完成原导数计算，未命中执行完整入口。
导数控制依据 [GLSL 函数规范](https://docs.vulkan.org/glsl/latest/chapters/builtinfunctions.html)。

首批七项检查有六项通过。
GPU 校验发现整数纹理使用了线性层级采样。
修复采用缓存模块拥有的最近邻专用采样器。
受影响的三项检查随后通过。

NVIDIA 与 Intel 的 GPU 机制均通过。
检查包含相交表面、同深度赢家及采样匹配。
实例、深度、三角形、材质及帧槽分别触发失效。
固定描述符、绑定数组及卸载由录制夹具覆盖。

原有 663 份着色程序逐字节一致。
新增一百五十一份程序具有独立身份接口或夹具用途。
原生四帧与冻结参考的 RGB 差异均为零。
1440p 的逻辑纹理内容为 147456000 字节。

## 分支执行

隔离标记只替换主颜色的六十四份缓存程序。
命中时输出高动态范围品红色。
四帧均有超过三百二十三万像素出现显著颜色差。
该结果确认原生场景确实执行复用分支。

标记影响范围包含合成及后处理传播。
这些像素数具有分支诊断范围。
原生产程序、资产及四帧冻结结果保持原摘要。

每端预热三百帧，统计一百二十帧。
两端共用原生 1080p 项目及相同资产。
