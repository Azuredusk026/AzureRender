# 头发几何基底颜色归因

日期：2026-11-10。
状态：单因素来源控制完成，完整颜色未通过。

## 输入与资格

本项沿用原 17017 像素遮罩及一字节门槛。
基线采用原生可见量来源控制，保留 31 处超差。
片元法线与切线来自[实际输入位值](hair-interpolated-basis.md)。
它们仅在既有 31 个诊断位置参与替换。

选择器同时匹配像素及原始向量位值。
可见片元的 31 个选择器全部实际激活。
激活探针的全裁剪蓝通道逐位保持。
向量不匹配的遮挡片元保留自身输入。
辅助调用按相同选择条件处理。

恒等控制送回实测 Vulkan 向量。
其 HDR 与最终裁剪均逐字节匹配基线。
所有版本撤销后，原 HDR 裁剪恢复基线。
六个程序均通过 SPIR-V 校验。

## 附件边界线索
