# 联合场景 GPU 通道成本

日期为 2026-11-14。计算材质和非本地纹理候选在 NVIDIA 595.79 上以 1920 × 1080、固定 60 Hz 步长运行。图形通道计时启用，19 个通道各记录 1,200 帧。

| 通道 | GPU 均值 |
| --- | ---: |
| 主颜色 | 6.736 ms |
| 不透明快照 | 4.882 ms |
| 反射计算 | 1.741 ms |
| 级联阴影图 | 1.613 ms |
| 反射运动数据 | 0.549 ms |

GPU 帧均值为 16.74 毫秒，主颜色与快照的区间均值之和约占 69.39%。运行期间有七次软件热降频观测。通道时间用于成本定位，正式性能使用无通道插桩的独立采样。

## 持续采样的耗时缺口

非本地纹理候选在固定 80 W 下预热 300 帧，连续统计 1,800 帧。
该批 GPU P95 为 18.61 毫秒，最后 300 帧为 18.73 毫秒，
分别超出 16.6 毫秒门槛约 2.01 毫秒和 2.13 毫秒。

按实测帧内耗时估算，若收益只来自场景阶段，
需分别削减整个采样段及末段约 12.49% 和 13.15% 的场景耗时。
若收益只来自阴影阶段，所需降幅分别为 91.69% 和 96.45%。
这些数值按实测帧独立计算，用于安排候选验证；正式验收仍需端到端运行并检查热状态。

同一来源代码在 595.79 上复现了当前画面。与 592.82 冻结来源比较，
四帧差异分别为 228、330、397 和 421 像素，其中 11 个像素超过一个色阶。
原生冻结验收采用 RGB 零差异门槛。

## 阴影矩形范围查询

主颜色和不透明快照在判断级联阴影时共同读取分块深度极值。隔离内核为 3×3、3×4、4×3 和 4×4 基础块矩形预计算深度极值。在原有捕获的 921,445 项查询和 2,304 项补充边界查询中，候选读取次数减少 90.30%。NVIDIA 和 Intel 的结果均与逐块参考逐位一致，验证层和资源释放检查通过。

| 设备 | 参考查询中位数 | 候选建表和查询中位数 |
| --- | ---: | ---: |
| NVIDIA | 0.0778 ms | 0.1295 ms |
| Intel | 0.6852 ms | 0.5110 ms |

Intel 的参考取前后两轮中位数的平均值。候选为每个 512² 基础网格增加 12 MiB。NVIDIA 计入建表后耗时增加约 66.45%，保留隔离结果。算量变化属于历史可见快照的查询范围，整帧性能、热状态及原生冻结画面继续按原条件核验。
