# 头发着色双法线采样

原生帧 10401 的事件 950 以 `t18` 读取投影头发的双法线纹理。该绑定与参考法线使用同一份纹理内容。实际着色同时使用 RG 漫反射法线和 BA 高光法线。

独立覆盖程序只替换着色阶段的 `t18` 选层，使用轴向与对角足迹，并在半层边界的 `1/256` 范围内采用材质原有采样。两个采样调用消费同一规则。Player、工程、纹理、采样器和参考通道沿用同一份输入。

## 实际输出

两块设备各采集三帧。每台设备的五类参考附件逐字节匹配冻结对照。三帧均使用同一组结果。

| 设备 | 冻结对照 RGB 超差 | 双法线控制 RGB 超差 | 进入门槛 | 新增超差 | 受检颜色变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVIDIA | 0 | 0 | 0 | 0 | 0 |
| Intel | 568 | 449 | 166 | 47 | 635 |

颜色范围包含 17,017 个冻结位置，沿用逐通道一字节门槛。NVIDIA 三张完整 PNG 逐字节匹配冻结对照。Intel 每帧共有 720 个颜色像素变化，均位于头发裁剪范围。

八份固定纹理覆盖程序通过 SPIR-V 校验。两台设备的执行收据分别为 38.125 秒和 42.609 秒，验证层检查通过，分配器清零。覆盖目录的 895 份程序通过摘要核对及受管清理。
