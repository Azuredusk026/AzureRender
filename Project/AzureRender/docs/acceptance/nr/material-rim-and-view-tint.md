日期：2026-10-23。范围为 C11-R8 及 C16-R1。
机制归属已有材质、灯、表面函数及 glTF 导入模块。

## 输入与布局

灯响应版本五声明材质边缘模式、宽度及着色量。
材质通过 `nprDiffuse.rimResponse` 选择消费者。
屏幕深度和视角带状响应具有独立数值检查。
版本四屏幕边缘灯采用其明确的深度响应。

`nprDiffuse.viewTint` 声明亮部基色的视角调制。
影色查找表和基色 Alpha 保留原始输入。
字段、范围及公式见[材质契约](../../runtime/npr-diffuse.md)。
两条描述符路径和完整文档共用该解释。

灯布局版本三保持 144 字节。
材质布局版本四保持 192 字节和九槽。
模式和颜色分别消费第二、第三行的预留容量。
捕获清单记录两项实际布局版本。

## 真实片元

依据为帧 10401 的皮肤事件 783。

独立 GPU 探针直接使用真实法线、视线和光向。
方向投影退化、径向遮挡及零倍率分别验收。

## 切线失败与复测记录

视角色彩夹具使用 X 轴单位法线。
UV 导出的切线经正交化后长度为零。
固定 X 轴回退与该法线平行。
静态变换后的切线长度为零，法线图输出无效值。
原图像检查在线性误差 `0.008595` 处失败。

导入器共用确定的正交单位回退。
生成及静态变换的切线保持有效基底与手性。
同一夹具的法线显示为 `[255,188,188]`。
原输入和 `0.008` 误差预算下的复测通过。
