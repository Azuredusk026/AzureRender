# 当前 GPU 事件分解

## 来源与采集

运行源码基线为 `0694263`。
实际宿主为当前 Release 的 `AzurePlayer.exe`。
设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
完整联合场景以原生一千九百二十乘一千零八十运行。

RenderDoc 1.46 捕获第三百二十帧。
捕获文件为 2,204,755,187 字节。
捕获、重放及材质查询分别核对冻结输入。
源码、运行产物及 1,729 份项目文件字节保持一致。

工具使用 `qrenderdoc` 内嵌的 Python 接口。
两次独立模块路径探测失败发生在工具启动前。
实际工具可执行文件及所用动态库按摘要记录。
接口字段按 [RenderDoc 1.46 源码](https://github.com/baldurk/renderdoc/blob/v1.46/renderdoc/api/replay/vk_pipestate.h)核对。
