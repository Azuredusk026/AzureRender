## 纹理层级

原生帧 10401 的事件 950 提供头发采样来源。
候选来自精确偏置批次的 Vulkan 事件 493。
像素采用左上原点；原生 Y 为 `1439-y`。

原生有偏硬件层级为 `1.5`。
候选硬件层级为 `1.49609375`。
最近层级过滤在该位置选择不同的图像层级。

基础颜色、参数图及双法线同时存在采样差异。
该点最终颜色误差为六字节。
两边梯度长度的解析层级约为 `1.4646`。
原生着色器偏移和候选采样器偏移均为负一。

另三处控制点的硬件层级相同。
两张原生及候选程序均直接查询实际纹理。
层级值通过三个六位分量编码，分辨率为 `1/4096`。
探针使用独立替换资源，并在结束时恢复原程序。

该边界与[眼睛层级核对](eye-npr-inputs.md)具有同类来源。
后续共同核对插值精度及层级边界的连续采样。
颜色、峰值及细线能量继续采用所属冻结门禁。

## 对象过滤

两处其他超差点的表面法线与纹理基本一致。
位置 `(1324,289)` 的原生可见量为 `86/255`。
候选的实际 GPU 可见量为 `69/255`。
位置 `(1322,320)` 的对应值为 `95/255` 与 `116/255`。

离线十位八面体量化对照未改善所选过滤值。
离线过滤在第二处位置也有 GPU 重现残差。
因此该近似只用于定位，实际 GPU 继续提供判据。
图集、重建、采样坐标及固定精度分别核对。
