## 原生深度来源

普通深度绘制 422 与着色绘制 950 的裁剪位置相同。
外扩深度绘制 440 具有独立裁剪偏移。
其普通世界位置、法线、切线和 UV 保持相同。
11564 个顶点及 43044 个索引均已核对。

候选普通头发与原生的世界位置误差为零。
原生深度壳的屏幕位移中位数约为 0.66 像素。
最大位移约为 0.88 像素。
事件 541 将其深度复制到后续边缘光输入。

两个实际边缘光采样点的深度由事件 440 写入。
其视深度分别约为 3.23085 和 3.23200 米。
原生深度差未达到边缘光起始条件，权重为零。
候选缺少外扩深度覆盖，发冠出现额外强边缘光。

八个最差发冠点的关闭对照误差为零至一字节。
该对照用于定位生产缺口。
正常边缘光、完整环带和正式描边继续分别验收。

## 顶点与纹理输入

外扩绘制从独立顶点流读取有符号平滑坐标。
原生流按每顶点十二字节保存 UV 和四个有符号字节。
共享解码采用切线空间半球坐标构造平滑方向。
实际姿态下的法线与切线由当前顶点状态提供。

512×512 的线性遮罩提供宽度和深度两个通道。
顶点程序使用零级线性采样。
该头发的宽度倍率为 0.5，深度倍率为零。
颜色描边事件 1138 使用同一遮罩资源。

遮罩宽度、深度偏移及颜色照明具有独立消费者。
顶点采样容量按实际着色阶段核算。
可选顶点流和材质记录需要明确的资产与 GPU 所有者。
