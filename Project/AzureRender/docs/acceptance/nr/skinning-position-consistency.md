# 蒙皮位置一致性

日期：2026-10-26。范围为 NR7 的变形输入。
状态：仿射位置契约通过，严格整图一致性继续验收。
目标为计算、顶点及运动路径的仿射位置一致性。

## 原因与契约

主场景的两条蒙皮路径存在六十一个差异像素。
最大通道差为十字节。
单独关闭计算蒙皮可完整复现固定路径的差异。
当前角色的独立项目复现十三个差异像素。

源权重归一化后的浮点和可偏离一。
加权矩阵的齐次行因此产生相同量级的偏差。
计算蒙皮和描边把位置恢复为 W 等于一的仿射点。
完整顶点及运动路径须使用同一位置约定。

私有着色器分别隔离重复归一化与齐次位置。
归一化对照保留原图及十三个差异像素。
齐次位置对照与计算路径逐像素一致。
生产规则见[蒙皮位置契约](../../runtime/skinning-position.md)。

## 回归范围

上一姿态 GPU 用例包含一附近两侧的相邻浮点权重。
新用例要求仿射位置的 W 精确为一。
原始失败已保存，生产修复后通过同一检查。
相机后方的裁剪测试使用投影矩阵表达。

表面、描边、阴影及当前和历史运动共用位置函数。
Debug 与 Release 的受影响目标分别构建。
两配置各通过五项 GPU 及七项 CPU 检查。
GPU 检查包含蒙皮、运动投影及材质原点。

录制、姿态数据及模块边界通过所属 CPU 检查。

实际角色分别覆盖两种构建及两条蒙皮路径。
两配置各比较三十二帧动作，两路径共捕获一百二十八帧。
每组的三十一帧逐像素一致。
第二十三帧仅一个像素相差一个输出字节。

主场景继续使用冻结的材质和灯光输入。
默认路径的图像摘要为 `1a5f5698…`，与冻结图一致。
顶点路径仅背景坐标 `(63,185)` 的绿通道相差一字节。
严格整图相等的诊断继续保留未通过记录。

逐帧差异、验证层及卸载计数保留原始记录。
完整图像与产物指纹见[结构化证据](evidence/2026-10-26/skinning-position-consistency.json)。
