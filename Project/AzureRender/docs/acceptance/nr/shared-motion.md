# 共享运动附件验证

日期：2026-10-29。阶段为 NR5-R8-L。
公共运动附件支持外部拥有与默认拥有两种装配。
主场景使用外部拥有，辅助视图覆盖默认拥有。
契约见[时序抗锯齿](../../runtime/temporal-antialiasing.md)。

## 公共资源

借用入口检查后端身份、尺寸、格式及深度视图顺序。
非法输入在分配历史图像前拒绝。
共享目标占每像素 20 字节，历史占 32 字节。
组合预算保持每像素 52 字节及 512 MiB 上限。
重建资源销毁后，共享目标继续保持有效。

CPU 夹具覆盖身份、预算、顺序及释放边界。
GPU 夹具连续提交两帧。
反射计算和时序抗锯齿读取同一运动及表面深度。
HDR 输出逐位一致，反射颜色误差小于 `2e-6`。
可信度保持一，最终图像和缓冲数量归零。
Debug 与 Release 各通过三项受影响检查。
两种配置的 Player 和编辑宿主均完成构建。

## 主场景兼容性

默认拥有路径的对照源为提交 `5fe1caa`。
对照仅替换主宿主的运动目标装配代码。
当前头文件、核心库、项目和着色器保持相同。
对照路径报告自身拥有，共享候选报告外部借用。
128×128 视图的组合资源均为 851968 字节。
同一薄透明项目的 80 帧 PNG 全部逐字节一致。
比较及构建记录位于本机运行目录 R83。
