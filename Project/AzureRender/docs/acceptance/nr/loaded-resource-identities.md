## 实现与来源

源码基线为 `e0ecf1a`。
场景渲染器按装配生命周期保存资源标识到网格键的映射。
帧更新按现有节点输入查表，保持稳定的实例顺序。
所有权及兼容复用规则见[运行说明](../../runtime/loaded-resource-identities.md)。

加载及兼容场景复用分别取得当前身份映射。
网格顺序与材质绑定按已有资源布局判定。
卸载清空映射，重载建立当前资源内容。
GPU 缓冲布局、帧图及生产着色程序保持原契约。

## 分配及绘制

实际渲染器的别名规模输入先取得预期分配失败。
未使用别名增加至一千零二十四个时，分配为 964,975 字节。
该失败控制的普通输入分配为 117,114 字节。
两种输入的渲染网格及物理节点保持相同。

两种描述符路径分别核对普通及别名规模输入。
原不透明顶点容量检查继续执行。
绘制命令逐项比较名称及全部参数。
分配预算与来源见[实施计划](../../plans/2026-11-06-loaded-resource-identities.md)。

Release 普通及别名输入在独立描述符路径均分配 114,772 字节。
索引描述符路径的两种输入均分配 114,580 字节。
两路径的别名增量均为零。
该结果描述逐帧分配，整帧收益由实际计时判断。

## 场景生命周期

实际渲染器覆盖加载、卸载及重载后的资源别名。
兼容场景复用覆盖资源标识变更及共享网格。
该边界先取得实例解析失败，再验证映射刷新。
当前实例姿态及两个可选对象共同核对消费结果。

原静态变形、暖内容、负零及旧图录制检查保留。
形变、表情、透明度、运动及阴影按所属回归执行。
完整用户画质及原 CPU、GPU 预算继续按原条件验收。
