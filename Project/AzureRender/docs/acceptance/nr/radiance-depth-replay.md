# 照明复用深度重放验收

## 结果与范围

独立深度重放通过共面胜出面及精度检查。
原生四帧保持 RGB 零差异，PNG 摘要相同。
两个原生退役槽仍采用完整着色。
原生轻量激活及帧收益尚未成立。

实验入口默认关闭，帧收益计时未启动。
整体画质保持 `failed-user-review`。
CPU 八毫秒及 GPU 16.6 毫秒标准有效。
正式采样、长跑及人工项继续按原条件验收。

## 机制与检查

每个在途帧持有独立 D32 深度附件。
副本总预算为 64 MiB，验证按原顺序写入深度。
严格 LESS 比较保留首次胜出的共面三角形。
主深度的布局在复制后恢复。

真实 GPU 上传、复制与回读核对正常浮点位值。
零值、次正规数及异常值请求完整着色。
NVIDIA 和 Intel 的精度子检查均通过。
Intel 的四像素组能力缺失按所属用例记录跳过。

同深度胜出面用例先复现失败，再验证实现。
命令行检查覆盖默认值、显式关闭及帮助文本。
独立视图在两设备各检查三十个状态。
每设备十五组输出比较一致，释放计数均为零。

两种配置共记录二十八项 CTest。
其中二十五项通过，三项按能力条件跳过。
默认配置分别核对 674 份程序的原始字节。

## 原生结果

本单元只执行一组原生严格四帧。
1729 项输入与运行程序摘要保持一致。
同步验证日志无错误，卸载后的分配计数为零。
运行及冷启动共约 364.59 秒，未作为帧成本使用。

共面顺序可以解释独立夹具中的保守回退。
原生仍有回退，当前证据不足以确定全部原因。
后续候选须处理资格判定的影响范围。
实际轻量激活通过后，才安排短时净成本比较。
