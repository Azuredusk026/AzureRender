# 不透明主通道深度预填

日期：2026-10-26。范围为 MS5 的主通道着色成本。
主场景、可玩入口和四样点近景采用冻结输入。
公共 GPU 回归及实际图像对照通过。
正式 1080p、60 帧预算继续验收。

## 生产规则

场景灯光与硬件深度测试共同启用时，主通道预填不透明深度。
预填在背景之后、完整不透明着色之前执行。
完整着色保留严格小于测试及共面表面的先后规则。
两个颜色附件的写掩码均为零。

预填采用常量因子一及斜率因子零的正向深度偏置。
裁剪材质、混合层、覆盖层、染色和乘法合成使用所属路径。
节点透明度、镜像、双面、形变及编辑变换消费冻结快照。
外扩壳按所属颜色与深度阶段记录。

## 职责与资源

主通道与颜色副本共用 `recordDepthCoverage`。
四种内部模式区分完整副本、仅深度及两类预填。
三种主通道管线由角色渲染器持有。
管线参与正常卸载、重建、退役及异常恢复。

预填复用当前附件、描述符与深度着色器。
公共材质布局、配置格式和纹理槽位沿用现行契约。
绘制、管线、描述符和推送计数包含主通道预填。
背景及描边的实际提交也进入所属计数。

## 已验证范围

Debug 与 Release 的十项相关 CPU 检查全部通过。
录制测试覆盖二百四十种组合。
两种描述符、两类形变和两种样点模式分别核对。
每组检查主通道提交计数及全部资源释放。

关闭场景灯光、关闭深度测试和乘法合成具有负控制。
预填与完整颜色的顺序逐次检查。
裁剪、渐隐、隐藏、双面和镜像保留独立检查。
背景、描边和预填的提交计数与实际命令一致。

## GPU 与真实场景

双配置合计通过十六组专项 GPU 检查。
静态覆盖包含一百七十八次捕获。
角色运动与相机平移合计验证九百六十帧。
共面、折射、反射、渐隐及四样点覆盖均保持门禁。

原生发冠的双配置、双采样模式共四张图像保持冻结指纹。
单样点的八个原生控制点误差为零至一字节。
四样点控制点最大误差为五字节。
四样点图像与所属模式的冻结来源逐字节一致。

最终主入口、可玩入口及四样点近景均逐像素一致。
两种构建的一百一十二个着色器均与冻结输入逐字节一致。
本阶段使用相同的材质、动画、灯光和辐照来源。
完整原生外观及正式动态质量继续验收。

## 成本与存储

设备为 RTX 4060 Laptop GPU，分辨率为 1920×1080。
各模式运行九十六帧，预热十六帧后统计八十帧。
帧率限制与垂直同步关闭。
计时期间串行使用 GPU。

模式一的 GPU P95 为 72.11 毫秒。
四样点的 GPU P95 为 277.31 毫秒。
引擎分配器峰值分别为 3,145,782,400 和 3,692,844,160 字节。
两种模式均继续按正式 60 帧预算优化。

可玩入口的一次缓存写入失败保留独立日志。
存储诊断时，D 盘可用空间约为 58 MB。
约 2.37 GB 的引擎截帧产物保存于 C 盘。
原访问路径通过目录连接消费相同摘要的文件。

释放空间后的可玩入口和近景重试均通过图像检查。
完整缓存的重复暂存写入继续按 NR0-A1 单独处理。
