# 资产快照空间控制

## 实现与范围

本单元源码入口为 `ae7bc80`。
资产数据库通过公共编解码机制保存源文件快照。
源文件修改后，旧数据库继续读取原指纹对应的字节。
缓存同时服务资产检视及项目打包。

64 KiB 至 256 MiB 的快照记录无损压缩决策。
编码大小至少节省八分之一时使用压缩载荷。
其余输入采用原始载荷，暖缓存复用已有决策。
多个硬链接名称共享的旧缓存保持其物理存储。

源内容在刷新时先核对摘要。
暖缓存再与已验证的源字节比较。
正常读取仍按资产指纹、长度及内容摘要验证。
完整契约见[源文件快照](../../development/asset-source-cache.md)。

## 真实语料

三份输入来自冻结联合项目。
每份在调用前后核对原 SHA-256。
表中数值为单次 Release 局部测量。
原生画面和整帧性能均属于独立验收范围。

| 输入 | 原编码字节 | 当前编码字节 | 编码耗时，毫秒 | 解码耗时，毫秒 |
| --- | ---: | ---: | ---: | ---: |
| GLB | 119293032 | 91301830 | 129.846 | 219.157 |
| DDS | 22369772 | 9740700 | 72.456 | 52.415 |
| PNG | 8322556 | 8322572 | 4.404 | 8.129 |

三份编码合计减少约 27.08%，还原字节均与源输入相同。
PNG 的原始载荷带有四十字节的决策头部。
暖缓存核对的三份局部值分别约为 132.866、34.069 和 0.408 毫秒。
局部值包含对应核对工作，完整启动及帧成本另行验收。
