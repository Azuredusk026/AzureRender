# Lit 法线解码

日期：2026-10-27。范围为 NR1-S3 的来源法线转换。
运行流程见[表面转换](../../runtime/native-surface-conversion.md)。

## 来源与公式

参考为官方 3534 帧事件 5299 的实际片元字节码。
同一来源程序保存于地面材质绑定证据。
十六进制反汇编确认阈值 `0x3c449ba6`。
Z 下限的精确位值为 `0x3a000000`。

解码将有符号 XY 的微小分量归零。
Z 使用归零后的 XY，在强度缩放前重建。
最终切线转换消费缩放后的 XY 及受限的 Z。
适配范围为已核验的 Lit 双纹理三通道分支。
