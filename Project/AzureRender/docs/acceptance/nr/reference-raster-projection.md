## 公开接口

组合采用参考横纵位置、设备最终深度及屏幕偏移。
该接口支持场景位置组合及独立 GPU 校准工具。
上传结构持有数值副本，资源生命周期由调用方持有。

缺失接口检查在实现前按预期失败。
CPU 检查覆盖深度、偏移、关闭和退化输入。
零尺度及组合溢出返回原设备位置。
三类非有限输入分别拒绝。
