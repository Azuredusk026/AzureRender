## 原生素材

来源为原生事件 422 和 440。
透明覆盖图采用 512×512 的 BC7 格式。
十个纹理层级分别保存原始压缩字节及摘要。
原生阈值为 0.5，着色器层级偏移为负一。

原生采样器采用环绕寻址。
水平和垂直过滤为线性，层级过滤为点取样。
采样器层级偏移为零，透明覆盖取红色通道。
几何输入来自同次原生捕获的实际顶点与 UV。

私有素材夹具显式启用设备支持的 BC 纹理功能。
该功能用于直接上传原生压缩字节。
公共夹具和运行宿主保持各自设备创建契约。
原生几何的壳层位置按所属单元继续接入。
