# 同帧照明复用原型

## 状态与来源

原型完成像素兼容及实际分支检查。
性能收益未成立，当前生产保持受检实现。
候选、设备能力与来源规则见[原型计划](../../plans/2026-11-06-opaque-lighting-reuse.md)。

私有目录只替换两份通用主场景片元程序。
当前帧不透明源颜色为候选的照明输入。
普通不透明材质在子组一致且反射贡献为零时尝试复用。
角色、选中状态及诊断模式沿用完整入口。

## 兼容与执行检查

NVIDIA Release 的四帧与原冻结参考 RGB 逐字节一致。
独立标记令复用分支输出品红色。
一帧的标记改变 919,809 个像素，确认分支实际执行。
恢复普通原型后，四帧的差异像素数均为零。

两配置的受检生产程序保持五百三十五份基线字节。
项目挂载文件、程序及源码在运行后保持一致。
两台设备均报告片元子组投票和四元组能力。
原型模块使用 Vulkan 1.1 编译目标，实际图像仅在 NVIDIA 运行。

## 成本与范围

短时采集预热三百帧，统计一百二十帧。
候选 GPU 帧均值为 34.39 毫秒，P95 为 35.90 毫秒。
相邻未修改基线均值约为 34.96 毫秒。
约 0.57 毫秒差异未形成合格的性能收益证据。

相邻基线漂移约百分之 2.10，且基线热状态未通过。
候选的热状态同样未通过。
该比较只作诊断，正式一千八百帧与画质门槛保持有效。
当前证据证明兼容与执行，主要 GPU 成本的减少仍需证明。
