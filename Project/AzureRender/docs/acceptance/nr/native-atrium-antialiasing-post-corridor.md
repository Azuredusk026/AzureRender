# 后廊补包中庭抗锯齿验收

当前生产内容候选通过三模式抗锯齿检查。
范围包含莱万汀、场景材质与动态传送仓。
默认 Player 的有效采样模式为 1。
完整场景复刻继续由 NR12 联合验收。

采集与分析方法见[原生中庭抗锯齿验收](native-atrium-antialiasing.md)。
公共实现见[空间抗锯齿验收](spatial-antialiasing.md)。
来源、日志与摘要见[结构化清单](evidence/2026-10-22/native-atrium-antialiasing-post-corridor.json)。

## 来源与采样

本批来源为后廊补包后的生产工程与场景。
[冻结收据](../../../build/runs/20261021-172156-native-render-evidence-623c52/rear-corridor-extension/final-source-snapshot/receipt.json)绑定工程、场景、程序与 47 份着色器。
快照字节及摘要均已逐项核对。
三组使用同一 Release Player 与着色器集合。

验收副本启用固定场景相机，并使用场景灯光。
视场角为 55 度，近裁剪为 0.1 米。
场景配置与相机组件均显式设置 1000 米远裁剪。
三组输出清单均记录实际远裁剪为 1000 米。

每组输出 96 张 1280×720 PNG。
固定步长为每帧 1/60 秒，采集时间轴为 1.6 秒。
模式 0、1 的场景附件为 1280×720。
模式 2 的场景附件为 2560×1440。

三组回放相同的七条输入事件，覆盖 D、W、A。
96 帧的六类确定性字段逐帧严格对齐。
字段为帧号、相机、目标点、角色、动画与刚体。
加载等待标志独立统计，资源就绪另行验收。

48 个测量样本中，各模式有 39 个仍标记加载。
三组共同非加载的测量帧仅 PNG 下标 16。
该批次的资源就绪覆盖具有此项限制。

分析按两帧间隔取得 48 组样本。
静态输入占 8 组，运动输入占 40 组。
运动残差使用相邻样本的 47 对变化。
九项原生候选检查全部通过。
