# 多样点副本与描边验证

日期：2026-10-25。
范围为 MS4 的场景副本、深度壳及外壳覆盖。
材质逐样点输入见[材质验证](multisample-character-material.md)。
正式画质与性能继续按 MS5 联合验收。

## 通道与所有权

角色副本复用公共 `SceneMultisampling`。
两个源槽分别持有颜色、硬件深度及线性深度。
颜色按样点平均，两种深度均取最近值。
目标视图由角色渲染器持有，解析模块借用目标。

资源图记录副本生产、解析与主通道消费。
直接录制路径调用相同的公共解析绘制。
销毁前退役提交，再释放解析模块和目标视图。
非法源槽及目标索引在录制前拒绝。

## 外壳覆盖

外壳遮罩的样本数与主视图一致。
每个实例持有独立图块及所属样点覆盖。
颜色外壳通过 `gl_SampleID` 读取对应样点。
深度壳消费相同的 UV、透明裁剪及节点透明度。

空遮罩使用一个像素的四样点图像。
描述符类型与着色器保持一致。
遮罩预算按样本数折算，帧预算为 128 MiB。
图块索引和实例布局保持公共契约。

## 图像测量

原有三十三项描边检查保持单样点验收规则。
四样点另用十项覆盖与独立参考检查。
近、远距离均以线性描边能量衡量亚像素覆盖。
纯色像素计数用于原有单样点控制。

近距离能量偏差约为 0.38%。
远距离能量偏差约为 1.99%。
两项均遵守原有 2% 门禁。
隐藏、透明裁剪为空及仅深度外壳分别检查。

屏幕边缘光按四个标准样点计算独立期望值。
深度差、朝向、局部灯及关闭对照分别验证。
物理材质、固定描述符及计算蒙皮兼容同时检查。
各通道记录实际样本数、分配字节及释放状态。

## 真实角色

原生角色的 2560×1440 原图保留冻结指纹。
八个官方头发边缘光控制点误差为零至一字节。
四样点图像保留同一角色、材质、相机及灯光。
发梢、角部和额前轮廓使用实际截帧复核。

四样点输出在上述控制点相差一至五字节。
原图片元控制与多样点覆盖属于不同测量条件。
该结果单独记录，完整后处理来源匹配继续验收。
完整外观、镜头运动和性能门禁归属 MS5。
