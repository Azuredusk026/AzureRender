# 材质图像二进制准备

完整材质解释使用内存 GLB 的二进制缓冲视图。
图像按原索引对应，起始偏移按四字节对齐。
解码器、图像设置及材质解释规则保持当前定义。
资源访问继续受现有嵌入边界约束。

单图及合计压缩输入各至多为六十四 MiB。
完整内存文档受一百二十八 MiB 上限约束。
空图、读取失败及读取期间的尺寸变化产生错误。
材质文件及公共接口沿用现行格式和契约。

## 验证结果

十四份原生角色材质使用相邻的成对程序运行。
基线合计 27.095 秒，候选合计 5.135 秒。
局部准备耗时降幅约为 81.05%。
该结果属于一次局部 CPU 对照，整帧收益保持待测。

十三类像素的完整 SHA256 核对一致。
其输入像素合计约为 471 MB。
着色打包参数、图像设置、层级及渲染状态一致。
另两份受影响地面材质的摘要核对也通过。

一百一十五个源文件与原冻结摘要一致。
Debug 和 Release 各通过八项所属检查。
检查覆盖空图、多图、四种对齐余数和坏图拒绝。
角色、普通材质、创作层级与来源边界共同验证契约。

两配置各六百六十三份着色程序字节一致。
当前批次的[原生集中验证](consolidated-preparation-images.md)通过原四帧零像素条件。
整体画质、正式性能及原供电条件继续验收。

## 准备阶段与环境

纯 CPU 观察覆盖三百七十四个资源。
项目初始化约 71.53 秒，模型加载合计约 82.75 秒。
材质绑定合计约 25.14 秒，关节包围盒约 0.022 秒。
该观察受后台活动影响，用于划分工作范围。

代表模型的图像解码约占其加载时间的三分之二。
角色材质的文本准备开销由局部对照进一步验证。
模型解码成本作为后续独立优化范围。
项目初始化成本保持待细分。

驻留重放的空闲预检未通过，重放进程未启动。
后台 GPU 占用改善后，才具备重试资格。
原 80W 条件及 CPU、GPU 帧预算保持有效。
