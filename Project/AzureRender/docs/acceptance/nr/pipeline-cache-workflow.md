# 管线缓存与迭代效率

## 机制与边界

本单元以 `8b6caac` 为源码起点，渲染结果沿用原冻结输入。
RHI 的图形与计算入口消费设备所有者持有的 Vulkan 管线缓存。
缓存保存驱动编译数据，支持同进程重复创建及跨进程复用。
依据为 [Khronos 管线缓存示例](https://docs.vulkan.org/samples/latest/samples/performance/pipeline_cache/README.html)。

开发构建共享 `build/cache/vulkan/`。
安装宿主采用项目所在目录的 `.azure/cache/vulkan/`。
没有项目的宿主使用进程内缓存。
当前项目缓存、证据及运行输出均位于 D 卷。

单文件上限为 128 MiB，总池为 256 MiB，至多八项。
闲置七天过期，原子替换期间的磁盘峰值至多为 384 MiB。
设备、驱动、UUID、长度及完整性不符时使用空缓存。
保存失败保持正常创建路径，缓存句柄在设备销毁前释放。

## 实际复用

代表管线在两个独立进程中分别创建一次，队列提交数均为零。
首次创建约为 1064.76 毫秒，读取后约为 93.94 毫秒。
后次取得应用缓存命中反馈，禁止即时编译的创建条件通过。
该夹具用于机制准入，整场景另行核对。

完整联合项目使用同一程序、着色器、资产、相机及分辨率。
首次运行采集四帧，缓存复用运行采集一帧。
管线加载任务在画面采集前完成。

管线任务耗时降低约 99.36%，差值约为 21.59 秒。
