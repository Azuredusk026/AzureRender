# 独立裁剪图生成层级

日期：2026-11-03，归属为 Q1。
状态：生成层级及受影响的来源层级检查通过。
完整头发、皮肤、服装和场景画质继续验收。
所属运行契约见[独立裁剪图](../../runtime/material-coverage.md)。

## 覆盖归属

纹理上传根据裁剪来源选择覆盖保持阈值。
独立裁剪图使用材质的 `alphaCutoff`。
基础颜色透明度使用颜色过滤语义。
具有来源层级的图像按所属数据直接上传。

所属实现为 `CharacterSceneRenderer.cpp` 的纹理上传。
材质接口、画像布局及纹理槽沿用现行契约。
本项覆盖运行时生成的斜线与圆环裁剪层级。
原生头发使用具有十级来源数据的独立裁剪图。

## 失败控制

冻结程序在相同 PNG 输入下产生覆盖差异。
第四级斜线对照具有 15,008 个不同像素。
最大通道误差为 135 字节。
原始输入、日志和两张实际输出均保存于归档。

## 实际验证

Release 与 Debug 各通过十九项受影响 CPU 检查。
两配置的 991 份编译输入具有相同摘要。
523 份着色程序与所属冻结来源逐字节一致。
检查使用实际 Player 进程及正式纹理上传流程。

每配置运行十六个生成层级用例。
两种形状分别覆盖第三、第四层级及两条描述符路径。
独立输入与标准透明裁剪参考要求逐像素一致。
可见对照同时检查图像具有实际明暗差异。

来源层级回归覆盖通用平面、曲面头发及两类阴影。
实际原生裁剪图在两条硬件路径均匹配来源遮罩。
正常退出的缓冲及图像卸载计数均归零。
Debug 验证层未报告错误或资源泄漏。
