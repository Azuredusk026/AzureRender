# 逐采样视图雾验收

日期：2026-10-28，阶段为 NR3-F1F。
范围为不透明深度依赖及多重采样轮廓。
场景和材质沿用既有视图雾契约。

## 深度与所有权

雾效绑定声明对不透明深度快照的消费。
普通无光照场景同样生成有效几何深度。
四倍采样全屏入口读取对应样本的深度。
背景样本保留其清屏颜色。

多重采样所有者提供有界的借用图像视图。
视图按在途帧区分并沿所有者边界释放。
渲染图声明主绘制对该图像的采样依赖。
描述符预算同时覆盖雾场和深度图像。

单采样及四倍采样使用独立的全屏入口。
应用着色模块总数为 199。
快照图像分配量保持相同。
材质表每项 336 字节，相机参数为 688 字节。

## 像素验证

斜向多边形采用四个标准采样位置作解析对照。
用例覆盖四分之一、二分之一及四分之三覆盖率。
双深度台阶分别评价前景与后景的近端权重。
相机失配、两种尺寸和单采样场景分别验证。

解析边界容差为二百五十六分之二像素。
四倍采样的 128 像素用例排除二十个歧义像素。
192 像素用例排除十三个歧义像素。
其他内部、轮廓与背景像素均进入严格比较。

双配置各通过十种描述符与场景组合。
每种组合分别捕获雾效开启和关闭状态。
最大线性误差为 0.003268，预算为 0.008。
配置与描述符路径的全部图像逐像素一致。

错误的已解析深度入口用于独立负例。
该入口产生 0.161111 的轮廓误差并被测试拒绝。
正常单采样场景与逐采样场景均通过对照。

## 回归与范围

双配置各通过十项 CPU 与接口检查。
双配置各通过既有二十六项雾效 GPU 组合。
多重采样所有权、遮罩和折射通过受影响回归。
实际运行通过验证层和卸载资源检查。

Release 的原版内容候选保持逐像素一致。
默认完整场景同样保持逐像素一致。
原版片元对照的捕获视图与材质表达继续有效。
原版光谱大气及移动视图生成仍按专项计划实施。

1080p 双深度小场景各记录九十六帧 GPU 计时。
该测量使用单体素体积与四倍采样。
关闭与开启的平均 GPU 范围分别为 25.827 和 27.047 毫秒。
正式全场景性能和抗锯齿门槛继续验收。
