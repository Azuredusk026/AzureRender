# 参考接收输入对照

在同一可见量计算程序内逐项替换深度、法线和阴影图集。对象标识、相机参数、对象记录和可见量数值画像在所有对照中固定。受检范围包含 49,384 个接收点及 17,017 个冻结头发点，沿用逐通道一字节门槛。

## 完整附件复现

两块设备各自使用当前帧的深度、法线、对象标识及同设备缓存的 D16 图集，完整 RG8 附件逐字节复现。交换设备的缓存图集会改变附件。每个图集替换用例均按相应图集的深度方向读取。
