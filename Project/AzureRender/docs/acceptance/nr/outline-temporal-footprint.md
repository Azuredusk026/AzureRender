# 描边采样与时序覆盖

日期：2026-10-24。
范围为 C18 采样尺度及 NR7-AA3、AA4 的公共机制。
角色完整外观、材质运动和默认模式继续验收。
原始输入与结果见[证据清单](evidence/2026-10-24/outline-temporal-footprint.json)。

## 输出像素契约

距离描边的最小宽度以最终输出像素表示。
模式二按二倍采样尺度换算最小宽度。
颜色壳与深度壳消费相同尺度及冻结姿态。
模式零、一、三的采样尺度为一。

壳通道使用现有八十字节推送常量。
采样尺度占用其首个浮点字段。
材质记录、实例布局及公共 API 保持版本四。
形变输入继续由实例及独立权重缓冲提供。

独立参考采用横纵各四倍尺寸的模式零。
参考在线性显示域按 4×4 平均。
红色轮廓使用正向红绿差积分测量覆盖能量。
最小宽度分支及远处衰减分支分别记录。

## 历史覆盖契约

实现标识为 `native-hdr-temporal-v2`。
当前颜色保持原始采样，不进行空间平均。
有界 5×5 邻域提供前景运动及最近表面深度。
响应像素始终拒绝历史积累。

历史深度按前帧投影还原为视空间距离。
容差为绝对 0.001 加相对距离的 2%。
透视与正交投影使用相同系数求解。
最近表面深度随颜色历史同步提交。

常规像素使用当前 3×3 颜色范围硬约束。
覆盖边缘使用 5×5 范围的渐进约束。
静止约束强度为 0.01，运动一像素时达到一。
覆盖边缘同时要求几何深度差及有效颜色反差。

深度差门槛为绝对 0.001 加最近距离的 5%。
颜色反差门槛为最大颜色与一之较大值的 0.1%。
该门槛使低反差平坦区域保持硬约束。
私有合成参数为 176 字节，纹理预算保持有效。

## 验收范围

GPU 数值检查包含远处遮挡及前景显露。
五十米前景与两百米遮挡使用独立透视参考。
小三角形平移两像素后检查残留轮廓。
输出共检查 55,152 个 HDR 标量。

两个公共资产分别执行独立四倍尺寸参考。
边缘误差上限为关闭抗锯齿时的 80%。
平坦区域最大误差上限保持一个输出字节。
近远细描边的八个收敛相位逐项检查 2% 能量预算。

实际角色分别对照原生材质事件与时序输出。
冻结发冠控制点、完整头发遮罩及误差单独保存。
控制点通过仅证明对应输入及覆盖。
C17、C18 和 NR7-AA6 依赖完整区域与动态验收。

## 验证结果

Debug 与 Release 各通过十八项受影响检查。
两种配置各通过三十三组描边图像检查。
七十七份着色器二进制逐项一致。
所有 GPU 资源在场景卸载后归零。
