# 接收运算的浮点精度

本单元入口为 `1d47d65`。
范围为既有接收模型的 17017 处区域输入。
齐次位置及倒数通过附加输出直接读取。
两设备的世界位置和可见量均保持原输出。

## 齐次位置

CPU 控制按原顺序逐步模拟单精度乘加。
本次输入的乘积和求和以双精度计算后舍入。
NVIDIA 的全部 68068 个齐次分量逐位一致。
Intel 的四个分量分别有以下逐位一致数量。

| 分量 | 一致数量 | 最大绝对差异 |
| --- | ---: | ---: |
| X | 12996 | `7.62939453e-6` |
| Y | 8465 | `7.62939453e-6` |
| Z | 11945 | `7.62939453e-6` |
| W | 16473 | `2.98023224e-8` |

横向标准化坐标在 Intel 上的 17017 处均一致。
两种乘加舍入组合均未复现全部齐次结果。
Intel 报告支持整型六十四位及浮点控制扩展。
该设备报告的双精度浮点功能为关闭。
具体指令收缩和后端求值方式仍需独立证据。

## 倒数与世界位置

齐次 W 的范围为 `0.29661563` 至 `0.31552231`。
下表按各设备自身的 W 核对倒数。
参考值采用最近偶数舍入。

| 设备 | 低一个末位 | 逐位一致 | 高一个末位 |
| --- | ---: | ---: | ---: |
| NVIDIA | 502 | 14521 | 1994 |
| Intel | 1015 | 14992 | 1010 |

两设备的全部世界位置均等于齐次位置乘以各自倒数。
CPU 残差修正可令各自倒数全部满足参考舍入。
参考倒数乘法仅匹配 NVIDIA 的 14576 个世界位置。
该修正尚不具备保留原生输出的依据。
