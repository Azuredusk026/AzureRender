# 直接灯零贡献效率评估

日期：2026-11-09。
状态：局部效率门槛失败，候选隔离。

## 数值与工作范围

夹具包含 131072 组单精度输入。
覆盖微表面镜面、幂函数镜面及不同粗糙度。
一致分组和混合分组均包含零入射与正入射。
每组处理八盏灯，两份表达式的 RGB 位模式一致。
候选的 65536 组零入射输入跳过显式半角计算。

零入射推导依据现有镜面公式及其余弦因子。
公共物理解释见 [Filament 光照文档](https://google.github.io/filament/main/filament.html)。
当前 `directSurfaceSpecular` 自身已拒绝零入射。
源码中的显式跳过次数与硬件实际工作分别解释。

## 独立效率

NVIDIA 对照采用前参考、候选、后参考。
每角色预热 128 次，再读取 64 次 GPU 时间戳。

| 角色 | 均值 |
| --- | ---: |
| 前参考 | 0.022301 ms |
| 候选 | 0.022529 ms |
| 后参考 | 0.022335 ms |

参考漂移约为 0.15%。
候选均值约增加 0.94%，未达到减少 20% 的门槛。
该夹具只表达独立输入分布，原生发生比例尚未测量。
本单元原生截图与整帧计时次数均为零。
第二设备及完整回归依据局部门槛停止。
