# 混合细线覆盖验证

日期：2026-10-24。
本项属于 NR7-AA3、AA4 的透明覆盖分项。
实施顺序见[运动覆盖计划](../../plans/2026-10-24-material-motion-coverage.md)。
裁剪覆盖、服饰及完整角色运动分别验收。

## 输入与归属

公共材质使用斜向 Alpha 细线及单关节平移动画。
序列包含十六帧预热、三十二帧移动和三十二帧停留。
关闭抗锯齿、候选时序及四倍参考分别采集。
相机、纹理及动画在修复前冻结。

颜色与运动生产者共用十六点覆盖积分。
积分中心补偿光栅抖动，子样本使用四分之一足迹。
透明颜色继续遵循现有混合与深度写入规则。
覆盖为零的片元保持背景运动。

运行期特征位三十选择混合 Alpha 的像素积分。
状态归属当前视图，作者材质中的该位被清除。
覆盖积分独立于历史采样，可用于首帧及历史重置帧。
覆盖叠层沿用所属着色契约。
场景染色、折射、乘色合成及径向眼球使用专用覆盖规则。

混合像素继续使用完整响应并拒绝历史。
材质表、纹理槽、相机表和运动附件保持现有布局。
时序纹理预算保持每像素五十二字节。
首帧、双构建及卸载分别核验。

## 质量门禁

移动内部与静止末八相位的能量误差至多为 2%。
图像误差、误差变化及几何边缘误差比至多为 0.8。
两像素之外的历史残留为零。
平坦区误差至多为一个输出字节。

细节检查将候选投影到参考信号。
每帧先扣除各自空间均值，再计算相关幅度。
移动三十二帧的幅度比须处于 0.8 至 1.2。
常量及无关噪声分别由独立统计测试拒绝。

## 失败证据

来源混合序列的图像误差比约为 1.779。
误差变化比约为 1.754，几何边缘误差比约为 2.063。
该序列的能量误差低于 0.2%。
因此能量正确须与细节及动态稳定性共同检查。

裁剪红测出现缩小覆盖损失。
裁剪积分候选恢复能量，但移动细节仍受历史过滤影响。
部分候选通过能量和误差门禁，相关幅度仍不足。
裁剪候选及诊断截帧保留在本机验收批次。

服饰直边运动序列仍存在边缘误差失败。
裁剪与服饰保持专项待验状态。
完整原生外观、性能及正式入口晋升按 NR12 验收。

## 验收结果

两种构建各通过二十八项检查及三十三组描边采集。
八十五个着色器指纹跨构建一致。
混合与乘色兼容序列分别保存八十帧产物。
乘色类别对照的最大输出差异为零字节。

| 检查 | Release 实测 | 门禁 |
| --- | ---: | ---: |
| 首帧内部误差比 | 0.0247 | 0.8 |
| 移动内部误差比 | 0.0339 | 0.8 |
| 误差变化比 | 0.0346 | 0.8 |
| 几何边缘误差比 | 0.5049 | 0.8 |
| 扣除背景的最大覆盖能量误差 | 0.071% | 2% |
| 移动相关细节幅度 | 0.9960 至 0.9984 | 0.8 至 1.2 |
| 两像素之外的历史残留 | 0 | 0 |
| 平坦区域字节误差 | 0 | 1 |

真实头发可见区的三十二帧跨构建逐字节一致。
发冠、内部及细发边界均通过末八相位的 2% 门禁。
关闭时序的完整原图保持既定指纹。
八个发冠源对照点的误差为零至一字节。

交替计时采用相同程序、机位及默认管线检查。
对照与候选的 GPU 中位数分别约为 11.232、11.252 毫秒。
相对差异为 0.18%，本项预算上限为 5%。
计时尺寸为 1280×720，NR12 正式条件单独验收。

节点渐隐、裁剪细线及服饰高频输入继续专项验证。
完整收据见[结构化证据](evidence/2026-10-24/blend-temporal-coverage.json)。
