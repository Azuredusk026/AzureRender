# 捕获头发照明验证

日期：2026-10-23。范围为 NR6-C11 和 C17 的共享响应。
参考为 10401 帧、事件 950、可见图元 1017。
本项核对颜色和照明公式，绑定闭合继续按 C17 验收。

## 公共颜色响应

共享函数接收亮部、影部、色带和显式权重。
可见性、环境遮蔽及遮罩的来源由调用者提供。
皮肤的既有适配器继续计算所属遮罩权重。
头发样本直接使用原生追踪中的已确认输入。

颜色核统一处理饱和度、亮暗混合及亮度归一化。
完整照明继续使用共享环境与主灯组合函数。
两项函数均使用线性颜色输入。

## 原生输入

样本位置为左上原点的 `[1280,1244]`。
参数图 B 为 0.8828107119，基础颜色 Alpha 为 1。
屏幕遮蔽采样为 1，全局环境权重为 0.2877224684。
这些数值属于该片元的来源证据。

视向色带 Alpha 为 0.9231860638。
受光色带 Alpha 为 0.9588921666。
影部颜色由亮度 0.55 和饱和度 1.1 调整得到。
照明中的阴影混合尺度另为 0.55。
