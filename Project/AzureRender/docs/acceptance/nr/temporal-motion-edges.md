# 时序运动边缘验证

日期：2026-10-29。阶段为 NR7-AA5-E1。
本项验证普通几何与裁剪表面的运动搜索范围。
实现位于 `shaders/temporal_resolve.frag`。
私有参数、资源预算及公共材质布局保持现行契约。

## 运动及颜色范围

普通几何在三乘三邻域选择前景运动。
裁剪表面在五乘五范围搜索覆盖运动。
颜色上下界继续由五乘五邻域提供。
普通几何边缘完整约束历史颜色的上下界。
裁剪覆盖保留部分约束以支持覆盖积累。
镜面材质的内部采样策略由公共材质画像选择。

## 动态质量

KK 夹具使用公开相机脚本驱动连续移动。
每种配置分别采集控制、候选和四倍尺寸参考。
每组采集 80 帧，移动区间为第 16 至 47 帧。
Debug 启用 Vulkan 校验，Release 使用构建默认设置。
两种配置均通过原有完整动态质量脚本。

| 指标 | 实测值 | 门槛 |
| --- | ---: | ---: |
| 移动平均误差比 | 0.290155 | ≤0.8 |
| 残差变化比 | 0.629250 | ≤0.8 |
| 几何边缘误差比 | 0.762646 | ≤0.8 |
| 高频相干幅度 | 0.945992 至 0.998977 | 0.8 至 1.2 |
| 移动积分能量比 | 0.999536 至 1.000783 | 0.98 至 1.02 |
| 两像素范围外拖影 | 0 | 0 |
| 平坦区最大字节误差 | 0 | ≤1 |

双配置全部 240 张 PNG 的对应文件逐字节一致。
Debug 与 Release 的时间合成着色器指纹相同。
每种配置另通过四项运动与资源回归。
GPU 检查覆盖响应释放、远深度、切镜及移动轮廓。
运行结束的缓冲及图像数量均归零。

## 剩余门槛

薄透明候选的边缘误差比为 0.944033。
服饰候选的边缘误差比为 1.581669。
两项仍未达到 0.8 的现行门槛。
薄透明的相干细节继续保持未通过状态。
服饰内部的接近零误差须与几何边缘分开解释。
完整角色、官方连续截帧及持续性能继续验收。
NR7-AA5、AA6 和默认模式晋升保持待验。
