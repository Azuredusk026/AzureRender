# 三层辐照资源与硬件采样

日期：2026-10-27。范围为 NR4-G6 的资源及采样基础。
公共格式与查询见[三层辐照资源](../../runtime/irradiance-clipmaps.md)。
正式 NR4、场景绑定及最终照明保持待验。

## 资源契约

`AZIC0001` 保存坐标变换、三层覆盖和默认球谐。
六份原始体积载荷保留幅度及全部方向 RGBA。
CPU 查询支持八邻点插值、层间过渡及外层回退。
世界法线的系数变换支持正交轴及镜像。

GPU 所有者持有六份体积、两个采样器和参数缓冲。
参数缓冲固定为十三个四维行，共 208 字节。
格式能力、纹理尺寸和载荷在分配前检查。
合成体积与实际中庭载荷共同验证公共契约。

## 活动片元输入

来源为官方截帧 3534 的活动照明事件 8912。
该程序的三对体积绑定为片元槽 19 至 24。
各份载荷的哈希与 8944 的槽 21 至 26 一致。
相关中心轴、覆盖参数及默认球谐逐位一致。

8912 和 8927 的替换探针实际写入照明目标。
8944 的探针保持原目标，失败记录单独保存。
活动事件和寄存器映射分别记录来源。
资源身份通过实际载荷摘要核对。

采样探针显式替换活动片元输出。
七个输入点处于原生位置偏移之后。
315 个采样分量及二十八个校准值通过浮点位回读。
四位数字编码支持 R11 目标的浮点位恢复。

## 数值与回归

片元探针与独立 D3D11 计算采样逐位一致。
硬件采样与源汇编组合工具建立独立系数参考。
Vulkan 系数的最大误差为 `5.15e-8`，预算为 `1e-5`。
方向 Alpha 的最大误差为 `3.69e-10`，预算为 `1e-6`。

理想三线性参考与设备结果最大相差 `7.37e-4`。
其 `1e-4` 诊断门限保持原值，并验证预期拒绝。
该诊断与原生硬件对照分别保存结果。
设备还原的数值判断采用已核对的原生采样输入。

双配置各六项 CTest 通过，其中各含三项 GPU 检查。
覆盖禁用、镜像、边界、独立颜色和完整 Alpha。
文件重开、格式拒绝、尺寸预算及资源释放检查通过。
实际载荷的 CPU 查询最大误差为 `5.73e-7`。

两配置的 Editor 与 Player 构建通过。
既有 117 份着色器保持冻结字节一致。
全部 118 份着色器在两配置间逐字节一致。
实际角色与主场景图像见[上传验收](volume-image-upload.md)。
