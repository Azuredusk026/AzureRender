# 原生反射过滤来源验收

阶段为 NR5-R8-A，原生过滤核的重建验证通过。
输入来自官方 3534 帧的实际计算事件 8811。
公共生产资源、连续历史及主场景接入继续实施。
完整指纹见[结构化证据](evidence/2026-10-28/reflection-filter-source.json)。

## 资源与采样

输入包含七级深度、七级压缩颜色及双通道表面数据。
输出为 1280×720 的 `R11G11B10_FLOAT` 反射颜色。
实际采样器分别使用最近邻和线性缩放过滤。
两个采样器均采用最近层级及边缘钳制。

表面数据第二通道的层级系数乘六后选择相邻层级。
该系数由射线的过滤足迹生产。
每级使用轴权重 `[1,3,3,1]` 的 4×4 过滤。
深度差按实际指数系数进入权重，并逐级归一化。
两级结果插值后执行最大分量颜色压缩的逆运算。

锐利分支的层级阈值为 0.25。
视深度由实际投影参数重建。
事件 8912 另读半分辨率 `R8_UNORM` 可信度。
该权重用于混合探针辐射及屏幕反射颜色。

## 验证结果

重建程序复用原版实际资源、常量及硬件采样器。
全部 921,600 个输出像素逐字节一致。
完整输出为 3,686,400 字节，摘要与原版相同。
独立常量写入实验确认本设备的输出向下量化。

CPU 参考采样了 6,534 处位置，状态保持诊断。
逐线程调试分别保存颜色、深度及层级计算。
部分最近邻采样位于纹素边界。
源 GPU 的整图字节对照承担本阶段等价验收。
