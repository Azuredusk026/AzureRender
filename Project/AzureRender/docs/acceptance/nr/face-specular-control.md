# 脸部高光正控制

日期：2026-10-22。
范围为 `DualFaceSdfGpu` 的方向灯高光控制。
本项验证测试刺激与生产输出之间的数值关系。
生产着色实现保持本批次冻结来源。

## 输入与门槛

粗糙度为 0.6，介电镜面权重为 0.03。
解析峰值为 `0.08 × 0.22 × 0.352 × 0.03 × intensity`。
强度 8 的线性峰值为 0.001486848。
对应 sRGB 量化峰值为 5 字节。

主控制使用强度 16，解析峰值为 0.002973696。
有效门槛保持 `maximum > 5`。
SDF 蓝通道变化与头部旋转的逐像素相等断言保留。
强度 8 的额外捕获验证解析结果及两倍线性响应。

## 实际验证

Debug 完整套件完成 28 次 GPU 捕获。
强度 8 和 16 的实际峰值分别为 5 和 10。
线性两倍响应的最大量化误差为 0.000304。
主镜面、固定描述符和几何遮罩的图像差均为零。

独立蓝通道、头部旋转及动画具有有效响应。
场景无灯控制为零，验证错误数为零。
资源卸载检查通过，程序及着色器已独立归档。
证据见[结构化收据](evidence/2026-10-22/face-specular-control.json)。

原始强度 8 的失败记录继续保留。
该记录的正控制输入不足已由解析值确认。
本项未修改生产高光，也未改变验收阈值。
完整脸部还原及正式 NR6 保持各自验收范围。
