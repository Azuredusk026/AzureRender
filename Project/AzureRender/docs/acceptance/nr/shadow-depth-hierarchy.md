# 阴影深度范围分层观察

## 候选与来源

状态为隔离候选，源码基线为 `9a9d9aa`。
正式生产入口采用受检的单层深度范围。
候选保留八像素细分块，并追加三十二像素粗分块。
粗分范围只用于保守预判，PCSS 过滤沿用原输入及运算。

[NVIDIA 软阴影资料](https://developer.download.nvidia.com/presentations/2008/GDC/GDC08_SoftShadowMapping.pdf)提供层级范围的调研依据。
来源摘要记录 PDF 字节摘要及所用页码。
缓冲布局、工作组归约和消费代码由本项目实现。
源代码、运行程序及着色产物分别保留于隔离目录。

## 成本与接续

原生一千九百二十乘一千零八十负载采集四百二十帧。
预热三百帧，统计一百二十帧。

GPU 帧均值为 32.21 毫秒，P95 为 33.65 毫秒。
