# 原生 CPU 阶段成本

## 采集与来源

源码基线为 `724a202`。
私有诊断程序使用正式 Player 的编译参数与当前链接依赖。
本轮记录稳态第三百一十至三百二十九帧。
正式源码、运行产品及挂载项目文件在运行后保持一致。

首轮只编译两份宿主实现的诊断副本。
细分轮追加场景渲染器的实现副本。
两轮均保持现行类布局，计时状态位于调用栈。
私有计时与日志代码保留在任务目录。

## 阶段观察

首轮环境检查通过，取得二十组宿主与场景准备记录。
宿主渲染器更新均值为 10.64 毫秒。
帧准备均值为 6.63 毫秒，命令录制为 3.14 毫秒。
场景物化与资源解析约为 2.86 毫秒，属于帧准备内部。

首轮依据用于选择一次渲染器内部细分。
细分轮取得二十组宿主、场景准备与渲染器记录。
子阶段按时间包含关系解释，日志开销具有独立边界。
细分轮出现一次热状态失败，结果只用于定位。

私有程序的整体帧时间包含诊断输出成本。
