# 不透明快照深度预填

日期：2026-10-26。范围为 MS5 的颜色副本成本。
主场景、可玩入口及四样点近景使用冻结材质输入。
正式 1080p、60 帧预算继续验收。

## 生产规则

快照有完整颜色需求时，先预填不透明几何深度。
预填要求硬件深度测试处于启用状态。
管线复用现有深度程序、描述符和快照附件。
两个颜色附件的写掩码均为零。

预填采用常量因子一及斜率因子零的正向深度偏置。
完整颜色保持严格小于测试，并按原有顺序绘制。
颜色阶段写入实际未偏置深度。
共面表面的先后规则由该阶段保持。

透明裁剪、混合材质及覆盖层使用所属绘制路径。
外扩深度壳在完整颜色之后记录。
仅深度消费者保持所属的单次覆盖绘制。
节点透明度、双面、镜像及形变沿用公共输入。

三种预填管线由角色渲染器持有。
管线参与重建、退役、异常恢复和正常卸载。
本阶段复用全部一百一十二个冻结着色器。
材质、纹理槽及渲染器接口保持现行契约。

## 录制与构建

录制契约覆盖二百二十四种组合。
检查包含预填顺序、零颜色写入和正向偏置。
镜像、双面、渐隐、裁剪及关闭深度测试分别覆盖。
每份夹具验证全部管线及资源释放。

Debug 与 Release 各构建十二个相关目标。
两种构建的十项 CPU 检查全部通过。
范围包含录制、多样点视图、RHI 和运行生命周期。

NullRhi 场景检查链接现有 RenderCore 模块。
测试读取当前构建的着色器目录。
源码依赖和着色器依赖分别进入构建目标。
测试断言保留所属配置的启用规则。

两种构建合计通过一百五十二次 GPU 捕获。
共面折射分别覆盖单样点与四样点。
扩展反射各四十四次，节点透明度各二十四次。
验证层状态、运行诊断及资源释放分别核对。

## 真实场景与预算

主入口与可玩入口的最终图像均与冻结来源逐像素一致。
四样点角色近景的完整主场景图像也逐像素一致。
两种构建的全部着色器与本阶段冻结输入逐字节一致。
完整原生外观及连续高频质量继续验收。

测量使用 RTX 4060 Laptop GPU。
分辨率为 1920×1080，关闭帧率限制及垂直同步。
每组运行九十六帧，预热十六帧后统计八十帧。
统计来自通过运行及资源释放检查的完整批次。

模式一的 GPU P95 为 84.96 毫秒。
四样点的 GPU P95 为 320.89 毫秒。
引擎分配器的峰值分别为 3,145,782,400 和 3,692,844,160 字节。
两种模式均继续按正式 60 帧预算优化。
