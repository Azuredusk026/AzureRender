# 表面朝向验收

日期：2026-10-27，范围为 NR5-R10 的双面镜像实例。
公共策略见[运行契约](../../runtime/surface-facing.md)。

## 问题复现

独立夹具使用明确的正面、背面及法线纹理。
普通实例的两个观察方向符合预期。
镜像实例的前后法线发生反向，失败结果保留。
源码核对显示双面着色依赖正面绕序。

## 公共检查

四种朝向使用统一索引，剔除与绕序分别配置。
不透明、普通、透明和乘法通道共同消费。
快照及积分头发保留对应的镜像双面状态。
实例批次继续按组合变换的镜像状态分组。

双配置各二十四次真实 Player 采集通过。
场景覆盖前后两面、镜像、透明、父级组合及四倍采样。
法线三个分量按既有 `0.004` 量化区间预算检查。
实际最大区间误差为零。

两种描述符路径及双配置的朝向图像逐像素一致。
普通单面镜像作为兼容控制参与检查。
GPU 卸载后的图像与缓冲计数归零。
Debug 验证层检查未报告错误。

## 头发与探针

双配置各二十次头发与探针联合采集通过。
覆盖不透明、透明组合、镜像、快照及四倍采样。
用例同时装配三层 GI 和积分头发。
数组与等值立方体的完整图像逐像素一致。

积分变体通过已有场景装配标志选择探针集合。
所有数组层采用可精确表示的固定 HDR 颜色。
兼容参考具有非零反射输出。
两种描述符及双配置图像共同核对。

双配置各十五次既有积分质量采集通过。
原预算要求能量偏差至多百分之二。
实际最大偏差为百分之一点零七一。
最大误差比例为 `0.701`，预算为 `0.8`。

完整四朝向的不透明与快照集合包含八份管线。
初始计数断言的失败及核对结果保留。
视觉精度和能量预算保持原定数值。
一百九十三份着色器与上一阶段逐字节一致。
