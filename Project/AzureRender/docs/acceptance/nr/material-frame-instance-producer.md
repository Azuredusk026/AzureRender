# 材质帧实例来源

日期：2026-10-26。范围为 NR6-C16 的原生实例帧。
两份原生捕获分别核对脸部与头发的实际绘制。
本项记录实例、调色板及跨姿态基底的来源。

实例身份来自执行后顶点流中的无符号整型输出。
顶点程序直接传递实际实例索引。
像素程序以平面整型输入消费该索引。
两阶段均按十六行、256 字节定位实例记录。

四次绘制的记录标志均为 `52`。
顶点阶段的 `t0` 与像素阶段的 `t1` 绑定同一资源。
保留帧位于各自调色板的前三行。
两阶段读取的保留帧矩阵逐分量一致。

每份捕获中，脸部与头发的保留帧矩阵也逐分量一致。
头发与面部据此共同消费当前姿态的材质帧。
来源包含实际描述符偏移、原始记录及着色器指令。
数据解码分别核对十六进制和 Base64 的来源编码。
