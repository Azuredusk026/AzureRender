# 特效视角覆盖率与加色合成

日期：2026-10-28，阶段为 NR7-L4G。
范围为公共图层的视角覆盖率与独立合成。
原版来源为 3534 帧的柱面绘制。

## 输入与计算

`viewCoverage` 持有偏置、幂次、反转和权重。
视线采用透视相机的位置或正交相机的前向。
法线采用顶点阶段归一化后的片元插值。
该输入保留原始表面朝向。

材质透明度先限制范围，再乘视角响应。
交界、近远淡出及节点透明度分别消费。
`softIntersection.enabled` 明确选择深度交界。
`composite` 明确选择透明混合或加色合成。

公共加色路径以覆盖率加权独立 RGB。
目标透明度保持既有值。
其他附件沿用各自的覆盖规则。
