# 可映射缓冲内存选择

`GpuAllocator::createBuffer` 根据用途选择分配偏好。
着色、几何及间接读取缓冲优先设备本地内存。
纯传输映射缓冲优先主机内存。
主机可见、连贯及持久映射属于必需条件。

设备缺少兼容类型时，由分配器选择合法回退。
公共接口、数据布局及同步契约保持有效。
该机制适用于材质上传、几何上传和纯传输回读。

## 验证结果

旧策略在新增真实设备检查中触发预期失败。
Debug 与 Release 各通过六项所属检查。
Intel 的两配置各通过五项 GPU 检查。
合计二十二项通过，包含七种独立用途。

每种用途使用独立分配器，隔离历史堆峰值。
实际 GPU 复制及回读字节一致。
验证层和资源释放检查通过。
原生四帧符合原冻结参考的零像素条件。

六百六十三份着色程序的字节保持一致。
一千七百二十九份挂载输入摘要保持一致。
整体画质仍处于用户复核未通过状态。
原驻留候选的像素差异根因仍未验证。
