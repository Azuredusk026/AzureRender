# 裁剪纹理缩小覆盖验证

日期：2026-10-24。
本项属于 NR7-AA4 的纹理覆盖分项。
执行顺序见[运动覆盖计划](../../plans/2026-10-24-material-motion-coverage.md)。
连续运动、极小层级及服饰细节按各自条件验收。

## 输入与归属

斜线与圆环采用 512×512 的二值 Alpha。
来源覆盖率分别约为 28.125% 与 6.1615%。
两种图形提供周期细线及封闭曲线输入。
来源图像与测试阈值在实现前冻结。

自动层级生成归属 `TextureMipChain.hpp`。
共享缓存和独立上传依据实际缩小过滤器选择覆盖足迹。
最近邻过滤使用纹素中心，线性过滤使用双线性面积估计。
缓存身份、纹理槽及渲染接口沿用现有契约。

面积估计在每个纹素单元内采用四乘四点。
Alpha 缩放经十二轮定界搜索选择。
常量单元通过上下界直接计数。
来源层及 RGB 通道按现有规则保留。

## 独立检查

CPU 验证采用每单元 32×32 个采样点。
二至四级双线性覆盖面积的相对误差上限为 2%。
最近邻完整 Alpha 层级按冻结指纹检查。
颜色通道另做保持检查。
来源 RGBA 字节必须一致。

GPU 序列通过公共模型、图像元数据及 Player 执行。
六十四个几何瓦片覆盖横纵各八个子像素相位。
正交投影使纹理足迹对应明确的二至四级层级。
单张输出同时包含全部相位及几何外部区域。

不透明控制核对全部几何覆盖。
实际像素须属于既定前景或背景颜色。
覆盖计数使用已冻结的几何区域。
固定与索引描述符路径另做逐字节对照。

最近邻序列验证缩小过滤方式的独立语义。
层级间过滤与层内过滤分别解释。
创作层级的保留行为由原有层级偏移夹具回归。
验证层及卸载归零继续作为必需条件。

## 失败证据

纹素中心计数的斜线第四级面积误差约为 86.8%。
圆环第四级面积误差约为 35.6%。
最近邻输入使用双线性估计时出现约 55.6% 覆盖误差。
实际缩小过滤器因此参与覆盖生成策略。

纹理面积通过须与运动、能量及可辨细节共同解释。
本项验收范围为指定可辨层级的生成与实际采样。
裁剪运动序列与 NR12 正式入口继续分别验收。

## 运动范围

八十帧裁剪序列继续检查默认采样与时序合成。
当前序列的能量及参考相关细节仍有失败。
面积估计、层级间插值与各向异性按实际消费共同核对。
原有 2% 能量及 0.8 误差门禁保持有效。

## 验收结果

Debug 与 Release 各通过四项受影响 CPU 检查。
六组双线性面积探针的最大 CPU 误差约为 1.42%。
最近邻全链指纹及来源 RGBA 检查通过。
颜色层级保持对应过滤语义。

两种构建各通过九组实际覆盖采集。
六组双线性 GPU 面积探针的最大误差约为 1.05%。
最近邻第四级覆盖率为 28.125%，误差为零。
固定与索引描述符的对应图像逐字节一致。

两种构建各通过六组创作层级回归。
采样颜色的最大误差处于一个输出字节以内。
各三十三组距离描边、覆盖和生命周期回归通过。
八十五个着色器产物与冻结参考一致。

真实头发的三十二帧与冻结产物逐字节一致。
完整来源姿态原图保持既定指纹。
八个发冠源对照点的误差为零至一字节。
完整外观及动态条件按各自阶段验收。

证据见[专项收据](evidence/2026-10-24/alpha-mip-footprint.json)。
