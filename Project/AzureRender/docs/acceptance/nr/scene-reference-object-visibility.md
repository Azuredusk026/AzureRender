# 场景参考对象可见量验收

日期：2026-11-12。
范围为实际 Player 的参考对象可见量通道。
整体画质状态为 `failed-user-review`。

## 场景装配

具名视图通过 `objectVisibility` 选择输出。
当前帧的 R32、压缩法线和对象身份提供屏幕输入。
对象深度来自当前场景的正向 D16 图集。
位置重建和对象记录使用相同的参考坐标帧。

公共通道使用已有顶点和片元程序。
输出为 `R8G8_UNORM`，红通道保存全可见值。
绿通道保存对象可见量。
采集按最后提交的帧槽和附件行原点读取。

## 功能对照

合成场景由可见接收面和斜向投影遮挡面组成。
指定阴影像素的绿通道为零。
背景、遮挡面及指定亮区为 255。
输出有 1,144 个像素的绿通道低于 255。

交换并反射参考坐标轴后，整张可见量逐字节一致。
仅选择参考输入时，深度、法线及对象身份逐位一致。
无对象场景输出两通道全 255。
三帧覆盖两个帧槽及首次重用。

GPU 夹具在录制后放弃命令缓冲并复用同一槽位。
逐项核对普通过滤、参考算术及无对象清除。
两设备在两配置各通过四项 GPU 检查。
两配置的五项 CPU 检查通过。

## 冻结区域

实际头发区域包含 17,017 个位置。
完整接收区域包含 49,384 个位置。
两个区域继续按每通道一字节判据核对。

| 设备与区域 | 逐字节一致 | 超过一字节 | 最大误差 |
| --- | ---: | ---: | ---: |
| NVIDIA 头发 | 16,540 | 391 | 39 |
| Intel 头发 | 16,350 | 502 | 55 |
| NVIDIA 完整接收 | 45,522 | 3,309 | 255 |
| Intel 完整接收 | 45,257 | 3,437 | 255 |

NVIDIA 头发的 391 处超差均具有逐位一致的深度。
其中 390 处的压缩法线也逐位一致。
Intel 有 201 处超差同时满足两项输入一致。
对象图集、逆投影和记录分别核对来源。

两设备的参考深度、法线及对象身份摘要与输入分项一致。
实际三帧颜色摘要保持当前场景对应值。
同设备的五份参考附件及颜色在两配置逐位一致。
材质消费及完整颜色按所属门槛继续验收。

## 对象输入来源

Vulkan 捕获的事件 406 绑定实际场景的 D16 图集。
图集为 4096×2048，正向深度。
重放的深度、法线、对象身份及可见量摘要逐项匹配。
片元常量缓冲读回包含逆投影及当前对象记录。

冻结图集采用反向深度。
方向统一后，两份图集共同覆盖 182,211 个纹素。
其中 176,136 个纹素的差异至多一个 D16 单位。
2,380 个纹素的差异超过两个单位。

独立 GPU 控制使用 NVIDIA 及公共参考算术。
各单项将实际输入映射到冻结输入的坐标与深度约定。
其余输入保持冻结值，完整组合使用实际附件和记录。

| 输入组合 | 头发超差 | 完整接收超差 |
| --- | ---: | ---: |
| 冻结输入 | 0 | 0 |
| 实际 D16 图集 | 182 | 425 |
| 实际逆投影 | 189 | 525 |
| 实际对象记录 | 126 | 331 |
| 全部实际输入 | 391 | 3,311 |

全部实际输入控制复现 17,017 个生产头发可见量字节。
完整接收区域有 49,382 个位置与生产输出逐字节一致。
另外两个位置的最大差异为七字节。
后续按来源核对图集生产与参考坐标标定。
