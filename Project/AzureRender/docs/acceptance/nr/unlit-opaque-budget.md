# 普通无光照表面预算验收

日期：2026-10-28，阶段为 NR3-F1G。
范围为普通不透明无光照内容的最终颜色评价。
来源和实际片元契约沿用公共材质语义。

## 颜色与附件

通用类和发光类按基色与自发光评价最终颜色。
着色入口按明确的特性集合选择合法评价路径。
透明内容、扩展特性和隔离视图各有完整评价。
选择高亮、节点覆盖率和几何附件保持规定语义。

实现复用既有输入、材质表及生命周期。
相机参数仍为 688 字节，材质表每项 336 字节。
应用着色模块总数为 199。
场景和材质通过现有文档及公共接口装配。

RenderDoc 对照读取同场景的主颜色与法线附件。
1920 × 1080 四倍采样的解析附件逐字节一致。
两项附件分别保存半精度颜色与八位法线。

## 设备与预算

设备为 RTX 4060 Laptop GPU。
双深度小场景采用单体素雾场和四倍采样。
每项测量纳入完整九十六帧。
第九十五百分位耗时的预算为 16.667 毫秒。

| 场景雾 | 平均 GPU 范围 | 第九十五百分位 |

计时对照使用同一运行程序和相同项目。
来源着色器逐项匹配已记录指纹。
隔离着色器采用独立文件副本。
原始计时、启动峰值和逐绘制计数分别保留。

## 回归结果

双配置各通过二十九次材质捕获。
最大线性误差为 0.001356，预算为 0.008。
六项照明隔离视图保持零能量。
PBR 的直接光、GI 和反射正例均有响应。

双配置各通过十种雾效边缘组合。
四十幅图像与逐采样基线逐像素一致。
两配置的二十九幅材质图像逐像素一致。
普通材质、两种描述符及四倍采样分别验证。

双配置各通过五项 CPU 与接口检查。
Release 的完整原版内容候选与基线逐像素一致。
默认完整场景同样通过逐像素兼容检查。
实际运行通过资源卸载及验证层检查。
