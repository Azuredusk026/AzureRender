# CPU 准备批次评估

## 范围与实施

本单元入口为 `0a0429c`。
场景沿用冻结联合项目及 1729 份输入。
源码、着色程序和主程序在每批执行期间保持一致。
每版执行四十帧，第五至四十帧用于局部统计。

本轮使用电池环境，结果属于准备成本诊断。
两版使用相同的粗粒度计时装饰。
正式供电、CPU 八毫秒及 GPU 16.6 毫秒门槛持续有效。
完整画质保持 `failed-user-review`。

候选包含透明任务调度、共享姿态边界及运动绑定复用。
绑定状态按已退役帧槽保存，并支持显式生命周期失效。
材质位移范围按本帧资源求值。
相同静态姿态及逐位相同形态权重复用本帧边界。

描述符的使用及更新遵循
[Vulkan 绑定规则](https://docs.vulkan.org/refpages/latest/refpages/source/vkCmdBindDescriptorSets.html)
及[主机同步要求](https://docs.vulkan.org/refpages/latest/refpages/source/vkUpdateDescriptorSets.html)。
全部未完成使用退役后，调用方才能更新对应绑定。

## 调度结果

按实例分派的首个候选使更新均值增加约 2.49%。
其中大实例的顶点准备集中于单线程。
该结果及完整候选源码保存在精简证据。

分阶段候选分别调度跨实例顶点区间和独立图元。
工作池包含四个工作线程，调用线程参与执行。
本批一次基线及候选的局部均值如下。

| 范围 | 基线，毫秒 | 候选，毫秒 |
| --- | ---: | ---: |
| 资源绑定准备 | 0.19944 | 0.04148 |
| 透明准备 | 1.06087 | 0.77832 |
| 实例准备 | 1.15160 | 1.25447 |
| 运动准备 | 0.56517 | 0.43219 |
| 渲染器更新 | 3.49376 | 3.23316 |

统计窗口的缓冲描述符写入由 166320 次降至零。
图像描述符写入由 83160 次降至零。
透明准备均值降低约 26.63%，绑定准备降低约 79.20%。
这些结果分别描述对应操作及局部成本。

更新整体均值降低约 7.46%，本批门槛为 20%。
候选保持隔离，生产入口使用受检基线。
原生画面、正式性能采样及长跑均未启动。
重试需要覆盖更大成本的实施依据。

七份生产源码及检查源码按原字节恢复。
两配置完成所属目标构建和恢复检查。
