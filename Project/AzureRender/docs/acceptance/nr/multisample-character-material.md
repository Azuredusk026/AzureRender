# 角色逐样点材质验证

日期：2026-10-25。
范围为 MS3 的角色材质与动态覆盖。
质量契约见[多样点运行说明](../../runtime/multisample-shading.md)。
深度副本和描边覆盖继续按 MS4 接入。

## 材质采样

模式四使用四个真实几何样点。
片元 UV、位置、法线及切线按样点插值。
多层 KK 使用所属图元的基底和方向。
材质、实例与纹理槽保持公共布局。

局部恒定基底使用像素中心的十六点积分。
该积分同时计算纹理参数与非线性高光响应。
基底变化时直接消费真实几何样点。
几何覆盖与透明裁剪由各样点独立判断。

基础颜色与投影头发纹理使用四分之一梯度。
连续透明度在各样点参与混合。
普通材质的其他纹理继续消费所属采样规则。
灯光阴影与深度副本的覆盖由对应阶段验收。

## 失败定位

合成多层 KK 的纯四样点误差比为 0.908。
帧间残差比为 1.253，未通过原有门禁。
高分辨率参考的离线四样点对照复现该失败。
实际 GPU 与离线抽样具有一致的采样限制。

恒定基底积分后，平均误差比为 0.132。
帧间残差比为 0.149，轮廓误差比为 0.149。
能量、平坦区及外溢残影同时通过检查。
验收阈值保持原有定义。

## 动态场景

公开夹具覆盖 KK、裁剪细线及服饰几何边缘。
透明细线、渐隐、往返渐隐与特殊混合分别验证。
各测试记录实际样本数及空间回退状态。
模式四须具有四样点附件，历史分配保持为零。

真实角色使用官方截帧恢复的几何与材质。
序列包含预热、平移和停留，共八十帧。
独立四倍尺寸参考提供线性颜色与高频对照。
头部区域同时检查能量、结构及帧间误差。

原有单样点着色器保留冻结编译指纹。
新增九个变体按实际视图采样状态选择。
注册测试覆盖两种构建及验证层诊断。
完整角色外观与正式画质继续进入 MS4、MS5。
