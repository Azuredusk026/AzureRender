# 对象阴影接收坐标

日期：2026-10-23。范围为 C11-R11 的接收输入。
真实深度数据与原生片元共同提供判据。
该分项验证公共契约及捕获姿态候选。
完整角色外观继续按原有门禁验收。

## 原生证据

事件 699 用整数像素坐标重建接收位置。
屏幕深度在对应像素中心采样。
法线来自编码后的表面法线缓冲。
其方向与身体事件 783 的映射法线一致。

同一原生深度图使用片元位置时，六十四点全遮挡。
使用重建位置时，遮挡数为六十一。
量化可见量为 `5/255`。
两处未遮挡采样位置均无投影三角形覆盖。

## 公共契约

组件提供两轴接收像素偏移及表面法线选择。
偏移采用左上原点，每轴范围为正负两像素。
缺省偏移为零，使用几何法线。
旧版本一内容省略新增字段时使用默认值。

相机矩阵提供等视深度的世界位移。
透视、正交、偏轴及旋转相机均有数值用例。
组件、编辑器、文档和渲染快照共用字段解释。
参数范围与保存规则见[配置文档](../../runtime/object-shadow.md)。

对象记录布局为版本二，每条 112 字节。
八对象及头部的容量为 912 字节。
材质布局仍为版本八、192 字节与九个纹理槽。
深度图像、采样器和实例布局沿用现行所有权。

## 验证结果

Debug 与 Release 的组件、文档及录制检查通过。
两种配置的数值和公共图像验证均通过。
三十八组图像包含偏移与法线的独立正控制。
完整文档、固定与索引路径输出分别逐字节一致。
