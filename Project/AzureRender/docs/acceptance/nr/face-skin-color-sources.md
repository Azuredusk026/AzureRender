### 透明衣料环境反射

Vulkan 事件 967 在三个位置分别读回环境辐亮度、材质响应、反射方向和粗糙度。
环境辐亮度与材质响应相乘，再应用 0.25 的材质辐亮度倍率，重建反射输出的最大线性误差为 0.000025。
原生事件 1383 使用相同显示坐标，三处间接高光的最大通道差分别为 0.01546、0.01632 和 0.00089。
原生事件 1383 从槽位 22 的 BC6_UFLOAT 环境立方体采样。立方体每面 128 × 128，共八级。
着色器以 `5 + 1.2 × log₂(粗糙度)` 选择层级。三个片元的层级分别为 4.32、4.32 和 4.48。
逐点记录立方体采样值、反射方向和材质响应寄存器可复算原生间接高光。
线性差较大的两处，Player 的材质响应约为 0.600，原生各通道为 0.020 至 0.026。
在这两处，单独代入原生材质响应后，线性差为 0.00203 和 0.00192。单独代入原生环境采样时，线性差为 0.06883 和 0.06544。
