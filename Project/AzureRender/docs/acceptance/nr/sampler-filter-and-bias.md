## 公共契约

| 字段 | 规则 |
| --- | --- |
| filter | 线性或最近邻，作用于缩小与放大 |
| mipFilter | 线性或最近邻，独立选择层级过滤 |
| mipBias | 负十六至十六，默认零 |
| anisotropy | 1 至 16，1 表示关闭 |

`mipFilter` 缺省时跟随 `filter`。
稀疏图片元数据继承所属材质输入的默认值。
glTF、完整材质、重新导入及编辑操作共用解析器。
查找表的固定采样规则继续由类型化材质校验。

缓存身份包含层级过滤和请求偏移。
相同像素的不同采样状态具有独立绑定。
非有限偏移在资源分配前被拒绝。
Vulkan 后端按设备上限钳制合法请求。

设备报告公开 `max_sampler_lod_bias`。
本机测试上限为 15，边界夹具请求正负十六。
