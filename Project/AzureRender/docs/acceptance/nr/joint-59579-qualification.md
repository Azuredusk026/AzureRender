# 联合场景 80 W 采样

记录日期为 2026-11-14。受检主线提交为 `01418ed`。
使用 RTX 4060 Laptop GPU、NVIDIA 595.79 和标准 Release Player。
受检程序摘要与冻结画面验收记录一致。
采样命令核对了冻结联合场景的 1729 项输入。

## 空闲检查

启动阶段共采集 25 次设备读数，覆盖约 123 秒。
实际功率上限均为 80 W，GPU 占用为 16% 至 42%。
既定启动门槛要求 GPU 占用至多 10%。
本轮未启动联合场景，正式采样帧数为零。

《杀戮尖塔 2》进程持有独立显卡上下文。
进程退出后，三个启动读数的 GPU 占用均为 0%。

## 自动风扇采样

预热 300 帧后，在 1920 × 1080 下连续统计 1800 帧。
145 次设备读数的实际功率上限均为 80 W。
GPU 峰值温度为 88 °C，运行后段出现软件热降频。
CPU 工作 P95 在预热段为 6.68 毫秒。
六个采样分段分别为 12.34、15.96、16.91、13.38、13.26 和 11.18 毫秒。
每帧平均约 1844 次绘制，物理单步 P95 为 0.11 毫秒。

## 最高风扇档对照

两轮使用相同标准 Player、冻结输入和采样命令。
OMEN 电源模式为平衡，最高档实测为每分钟 6000 转。
71 次功率读数均为 80 W，GPU 峰值为 88 °C。
两轮 GPU 启动温度分别为 61 °C 和 55 °C。

| 指标 | 门槛 | 自动风扇 | 最高档 |
| --- | ---: | ---: | ---: |
| GPU 帧 P95 | ≤ 16.6 ms | 20.98 ms | 19.99 ms |
| CPU 工作 P95 | ≤ 8 ms | 15.74 ms | 6.98 ms |
| 设备本地内存峰值 | ≤ 1.5 GiB | 2.593 GiB | 2.593 GiB |
| 进程峰值工作集 | ≤ 2 GiB | 1.937 GiB | 1.981 GiB |
| 软件热降频读数 | 0 | 15 | 13 |

最高档六个 CPU 分段的 P95 均在 8 毫秒以内。
两轮正常关闭，缓冲区与图像分配计数均归零。
最高档轮次复用了更多管线缓存，启动温度亦有差异。
CPU 降幅属于复测观察，尚需同等起始条件确认归因。
正式热状态、GPU 帧耗时和设备本地容量仍未达标。
采样结束后已恢复自动风扇并核对面板状态。

## 容量归因

本次诊断的设备本地分配峰值为 2,784,680,768 字节。
材质缓存的驻留纹素为 1,852,081,920 字节。
材质纹素比 1.5 GiB 的设备本地门槛多 241,469,184 字节。
设备本地分配峰值超出门槛 1,174,068,032 字节。

[sRGB 通道](resident-srgb-channel-scope.md)的乐观上界为 113,700,984 字节。
[DDS 块载荷](dds-block-storage-scope.md)的乐观上界为 141,848,232 字节。
两项完全兑现且互不重叠时，峰值仍超出 918,518,816 字节。
容量候选需核对实际分配、动态可见范围与冻结画面。

## 纹理层级核查

历史捕获的 364 张单层纹理，最高分辨率层共 1,381,296,260 字节。
其中 1024 和 2048 尺寸组共 1,374,945,280 字节。
若仅从最高分辨率层节省原峰值缺口，理论上需回收约 85%。
该比例按纹素计算，实际分配还受平铺和页粒度影响。

385 个历史缓存条目的采样器上限均覆盖最后一级。
180 张 sRGB 图像的重复层级载荷合计 5,592,636 字节。
两设备均报告稀疏二维图像驻留能力。
候选资格仍需证实实际采样范围、帧间更新和双设备输出。
[层级核查数据](evidence/2026-11-14/material-viewquad-59579/results.json)保存图像范围及原始摘要。

## 纹理访问记录

RenderDoc 1.46 重放 720p 联合场景第 320 帧。
364 张候选图像中，271 张在常规资源表中无事件。
这 271 张图像在捕获中的逻辑容量为 1,252,758,528 字节。
Vulkan 的常规统计跳过超过 1000 项的描述符数组。
[RenderDoc 1.46 源码](https://github.com/baldurk/renderdoc/blob/v1.46/renderdoc/driver/vulkan/vk_core.cpp#L6235-L6244)给出这个边界。

八次绘制的逐事件描述符反馈识别出其中 19 张图像。
这 19 张图像共占 158,018,560 字节。
剔除已观察到访问的图像后，剩余逻辑容量为 1,094,739,968 字节。
该值比联合场景实际分配缺口少 79,328,064 字节。
比较使用捕获逻辑容量，实际节省以分配器高水位验收。
进一步评估需使用逐页或逐层的动态采样证据。

[访问结果](evidence/2026-11-14/joint-texture-usage/results.json)与[回放归档](evidence/2026-11-14/joint-texture-usage/validation.zip)保存描述符反馈、图像身份和失败复测记录。

## 全帧描述符反馈

第 320 帧的 3,453 个绘制及分派事件均已核对。
364 张图像中，252 张取得描述符访问记录。
其中 159 张在常规资源表中没有事件。
其余 112 张的捕获容量为 472,807,424 字节。
该值只覆盖冻结机位的一帧，动态可见范围需另行采集。

关卡引用的 374 个资源包含 395 个显式 glTF 材质槽。
这些槽均被各自默认场景内的几何图元引用。
纹理容量分析继续使用实际采样和层级范围。

## 稀疏页布局与重复

NVIDIA 和 Intel 均通过 22 种实际尺寸及格式的图像创建查询。
四种受检格式的稀疏页均为 64 KiB。
364 张图像的层级尾部约占 23.3 MiB 和 22.8 MiB。
尾部容量采用设备返回的绑定粒度。见 [Vulkan 稀疏资源规范](https://docs.vulkan.org/spec/latest/chapters/sparsemem.html#sparsememory-miptail)。

双设备均可独立绑定的完整页共核对 27,951 张。
同格式、同像素布局的 SHA-256 重复页为 3,432 张。
重复页的潜在容量为 224,919,552 字节，约 214.5 MiB。
回放读取逻辑纹素，实际页别名及采样仍需设备验证。

按单帧无匹配访问图像和重复页的全部容量独立估算，
合计为 697,726,976 字节，距分配缺口仍差 476,341,056 字节。
候选继续核对可见图像内部的层级、页访问及运行时分配。
