## 公共策略

版本二表面支持显式椭圆主轴层级。
设备策略为默认值，版本一和版本二均可使用。
椭圆策略要求实际设备支持片元四像素组操作。
资源与调用规则见[参考深度契约](../../runtime/reference-depth.md)。

纹素导数矩阵的最大奇异值定义主轴长度。
统一缩放限制二次项，基础层级下限为负一百二十六。
采样器使用各向同性过滤，表面字段持有层级偏移。
公共函数和覆盖程序可供独立深度工具使用。

默认设备策略的既有覆盖与几何用例全部通过。
