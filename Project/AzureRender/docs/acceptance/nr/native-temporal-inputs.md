## 运动与抖动

运动采用左上原点的归一化 UV。
每分量先从十位 UNORM 解码为 `c`。
当前减前帧的位移为 `sign(c−0.5)×(2c−1)^4`。
历史坐标为当前像素中心 UV 减去该位移。

附加字段独立参与状态判断。
其全部标记语义继续按生产事件核对。
十位中心两侧保留微小的非零量化位移。
离线解码保留该精度及方向。

常量 `cb0[19].xy` 为像素抖动。
本帧值为 `[-0.25, 0.166666687]`。
其 ZW 为按实际尺寸归一化后的抖动。
当前颜色索引选择与历史坐标计算分别处理。

## 历史合成

历史 RGB 经过多点采样及亮度压缩。
当前颜色的三乘三邻域提供统计约束。
运动、边界及打包状态参与合成权重计算。
最终 HDR 结果在调色前输出。

本帧遮罩全部为 255。
历史与输出 Alpha 全部为零。
三个跟踪片元的历史 RGB 合成权重仍大于零。
Alpha 与历史颜色权重分别解释和验证。
