## 观测契约

本单元沿用原 17017 像素及九十七处可见量超差。
独立探针读取最近前面表面的 Alpha 和 D32。
透明阈值为零，使该控制保留全部前面表面。
生产代码、正式表面和默认取样规则保持同一来源。

每设备的 Alpha 探针与控制拥有相同 D32 输出。
全部 17017 个深度值逐位一致。
控制的 R32 与 D32 也逐位一致。
该控制用于核对探针的可解释范围。

属性探针增加 UV 和层级查询的观测。
使用同一程序及动态通道选择分别读取各字段。
其 Alpha 输出与原探针的全部像素逐位一致。
各字段的 D32 输出也与原控制逐位一致。

所有运行均无验证或同步错误。
每次释放后的图像和缓冲计数均为零。
原生可见量门槛保持一字节。
探针数据用于定位，实际生产附件持有验收判据。
