# 冻结纹理通道范围

日期：2026-11-10。
状态：源图像核查通过，实际驻留收益待验。

## 来源与方法

输入使用冻结原生项目的挂载清单。
核查读取 PNG、DDS 及 glTF 内嵌图像。
541 份实际读取的源文件摘要匹配冻结值。
Pillow 解码取得 476 份内容，去重后为 468 份。

每个通道逐像素检查常量及相互相等关系。
常量范围限定为零和二百五十五。
相同通道可共用一个存储分量。
统计范围为源图像的基础层级。

## 实施边界

实际缓存的处理后像素决定上传表示。
完整 mip 链需要保持同一通道映射。
采样器、设备格式及颜色空间分别参与资格判断。
共享身份继续按完整 RGBA 像素比较。

本项范围包含未进入驻留缓存的源图像。
源图像字节与实际 GPU 分配分别计量。
Pillow 结果用于筛选，运行时解码与采样独立验证。
正式内存、帧预算及原四帧门槛持续有效。

本次只读核查耗时约 34.687 秒。
541 份源文件的摘要复核耗时约 3.656 秒。
生产源码、程序与冻结输入保持原内容。
本项未启动原生画面或整帧计时。
