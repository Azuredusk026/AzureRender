# 联合场景热点纹理分配

受检源码为 `01cc6b2`，显卡为 RTX 4060 Laptop GPU，驱动为 NVIDIA 595.79。隔离 Player 沿用计算材质和原着色程序，按材质纹理的使用记录选择设备本地内存。

## 纹理范围

RenderDoc 回放 720p 联合场景第 320 帧。按实际描述符访问关联绘制的片元调用次数，计算各图像单位容量对应的加权访问。权重表达该帧的绘制工作量，纹理实际读取次数以设备计数为准。

224 张受检纹理中，候选选择 18 张 1024×1024 RGBA8 图像，逻辑层级共占 96 MiB，对应约 79% 的加权访问。尺寸、格式、层级数和基础层采样指纹共同识别图像。具有同一组标识的图像合并计入容量。

## 画面结果

Player 将 18 张图像分配到设备本地内存，共 100,694,016 字节。其余 206 张受检图像位于非本地内存。卸载后缓冲和图像分配计数归零。

2560×1440 的四张 PNG 与 595.79 主线对照逐字节一致。与 592.82 冻结图的差异分别为 228、330、397 和 421 个像素。全程本地内存峰值为 1,705,712,448 字节，1080p60 的容量和帧耗时使用独立计时结果。
