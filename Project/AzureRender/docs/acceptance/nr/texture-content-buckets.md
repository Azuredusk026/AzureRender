# 纹理内容分桶验证

`SampledTextureCache` 按机器字计算候选分桶。
每个输入字节均参与计算，尾部读取限于有效范围。
完整字节及上传参数决定纹理复用。
缓存值的有效期限定于当前进程和设备会话。

## 局部结果

评估使用同一份 2048 方形 RGBA 输入。
每个样本执行三十二次真实缓存命中。
两种实现交替执行三轮，各取得十五个样本。
全部调用检查实际绑定身份及命中数量。

| 中位耗时 | 基线 | 候选 | 降幅 |
| --- | --- | --- | --- |
| 哈希 | 539.574 毫秒 | 142.323 毫秒 | 73.62% |
| 完整命中调用 | 586.774 毫秒 | 186.595 毫秒 | 68.20% |

该结果适用于本机缓存命中的局部工作。
完整场景准备及整帧收益分别保持待测。
原场景记录的哈希成本约为 7.49 秒。
原始记录为单次观察，成对整场景结果另行采集。

## 检查范围

Debug 与 Release 各通过四项所属检查。
缓存用例覆盖字节碰撞及四至三十九字节输入。
每个字节的独立修改拥有不同资源身份。
原生层级、上传字节及失败恢复检查通过。

真实 glTF 夹具覆盖固定与索引描述符。
重复加载、输入所有权及全部资源释放通过。
两配置的六百六十三份着色程序保持字节一致。
本批原生图像复核列入后续合格候选的集中批次。

CPU、GPU 帧预算及整体画质状态保持原验收口径。
