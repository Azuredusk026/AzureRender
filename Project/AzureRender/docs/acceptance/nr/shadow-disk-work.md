# 阴影圆盘空覆盖评估

候选归属于 RenderCore 的阴影权重计算。
当前生产保持既有滤波表达式和程序。
私有候选尚未通过完整附件及耗时验证。

## 机制与工作量

候选先计算四个采样点的距离平方。
四点均超出保守外界时，返回零权重。
其余输入继续使用原平方根和权重表达式。
描述符、深度纹理及采样次序保持既有契约。

保守外界采用半径平方及相对余量。
余量为二的负十八次方。
NaN 比较进入原权重路径。
精度推导依据 [Vulkan 浮点规范](https://docs.vulkan.org/spec/latest/appendices/spirvenv.html)。

功能统计覆盖原捕获的可见不透明快照。
354 次绘制使用四份诊断程序。
统计包含 11,917,189 次圆盘权重调用。
其中 4,232,176 次可跳过平方根，约占 35.51%。

该比例属于当前可见片元的操作量。
被覆盖片元、其他通道及 GPU 耗时分别解释。
移除诊断替换后，原附件逐字节一致。
功能重放正常退出，调试消息为空。
