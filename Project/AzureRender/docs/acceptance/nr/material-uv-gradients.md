# 公共 UV 梯度助手验收

日期：2026-11-10。
状态：公共内核及设备契约通过，材质绑定待验。

## 数值与支持

公共助手先计算细粒度横向与纵向梯度。
横向读取四像素组下行，纵向读取左列。
调用方在一致控制流及片元丢弃前保存结果。
当前接口与[使用规则](../../runtime/material-uv-gradients.md)共同定义调用范围。

策略校验接受设备默认模式。
镜像模式要求片元阶段及四像素组操作能力。
未知枚举、空句柄及缺失能力共五类拒绝检查通过。
设备查询借用句柄，结果不持有 GPU 资源。

## 实际光栅

夹具覆盖 32×32 及 33×35 两种尺寸。
双分量 UV 具有不同符号和比例。
每种尺寸分别核对完整绘制及计算梯度后丢弃片元。
清除值和保留片元均按四通道单精度位值比较。

两配置、双设备各核对 4358 个像素。
每批 17432 个分量逐位一致，四批共 69728 个。
实际设备为 NVIDIA RTX 4060 Laptop 及 Intel RaptorLake-S。
全部日志无验证错误，资源销毁后验证计数为零。

## 构建与兼容

缺失 C++ 与 GLSL 接口检查先于实现并按预期失败。
初次目标构建记录默认目标环境不足的错误。
Vulkan 1.3 目标另引入未启用的丢弃降级能力。
最终四像素程序采用 Vulkan 1.1 及 SPIR-V 1.3。

最终程序保留 `OpKill`，能力声明满足实际设备。
相关编译标记进入编译命令与程序集参数清单。
失败记录及修正后的两配置构建分别保存。
所有数值和验证门槛保持原值。

两配置 Player 及原有 679 份着色程序的摘要均保持一致。
原始四帧按[公共输出精度](material-output-precision.md)的相同来源复用。
本项新增两个测试程序，程序集总数为 681。
生产材质、覆盖、深度和阴影的绑定继续单独验收。

整体状态保持 `failed-user-review`。
