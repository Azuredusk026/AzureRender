# 视图雾资源绑定验收

日期：2026-10-28，阶段为 NR3-F1D。
范围为场景绑定、捕获视图及资源引用。
实际雾效绘制按视图雾效计划继续实施。

## 场景契约

公共绑定持有启用状态、资源及捕获相机。
视图坐标与捕获相机使用完整的版本化字段。
相机匹配区分视线、投影及宽高比失配。
无效解码保持目标绑定的原值。

JSON 关卡解析资源 UUID 和虚拟路径。
内容指纹参与资源键及重载键。
资产数据库记录 JSON 与文本场景的雾依赖。
渲染快照校验并复制完整绑定。

文本场景版本为十四。
版本一至十三采用关闭的默认绑定。
文本场景通过项目服务解析雾资源引用。
雾资产移动后保持 UUID 定位。

## 验证结果

失败测试复现了关卡加载丢失雾绑定。
Debug 与 Release 各通过八项受影响检查。
两配置均构建 Player 和编辑器。
检查覆盖保存重开、内容指纹及非法输入。

Release 主场景以 2560 × 1440 完成截帧。
Debug 采用实际中央材质的独立场景。
默认关闭雾效时，RGB 与既有候选逐像素一致。
两次运行均通过全部资源释放检查。
Debug 验证层未报告错误或警告。

本轮验证资源及默认兼容性。
主场景的雾资源上传及表面绘制继续实施。
NR0 至 NR12 的正式图像与性能条件继续有效。
