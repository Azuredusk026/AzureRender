# 多样点渲染硬件验证

日期：2026-10-24。
范围为 NR7-MS1 的 RHI 声明、能力及 GPU 插值。
契约见[运行说明](../../runtime/multisample-shading.md)。
接入顺序见[四样点着色计划](../../plans/2026-10-24-multisample-shading.md)。

## 独立契约检查

通道及管线默认使用一个样本。
非法样本位、非有限着色比例及附件冲突须明确拒绝。
能力不足及管线样本冲突保持创建前的调用状态。
无附件通道继续消费所属管线的样本声明。

记录后端保存管线的样本数及着色比例。
四样点图像的估算统计按四份覆盖计算。
释放后的图像及缓冲区计数归零。
契约检查采用实际生产描述符与记录后端。

## GPU 输入

独立 Vulkan 夹具创建 32×32 的四样点 HDR 目标。
目标格式为 `VK_FORMAT_R16G16B16A16_SFLOAT`。
片元输入采用样点插值，最小着色比例为一。
标准样点位置先核对设备能力。

第一组按实际插值位置及样点序号输出颜色。
四个样点解析后的参考颜色为 `(0.5,0.5,0.375,1)`。
第二组采用四纹素的透明纹理。
仅四分之一的样点保持颜色覆盖。

第二组解析参考为 `(0.09375,0.03125,0,0.25)`。
纹理裁剪使用作者阈值二分之一。
每组核对全部像素的四个半精度颜色分量。
两组共核对 8,192 个 HDR 数值。

## 驱动与失败检查

驱动入口核对附件样本数及管线样本数。
最小着色比例与启用状态按请求值核对。
不符参数在测试入口返回创建失败。
该检查保持非法配置在 GPU 执行之前终止。

故障注入保留声明的四样点，并传递单样点管线。
同一 GPU 检查须拒绝该输入。
恢复实现后重新编译并执行完整数值检查。
后端能力关闭时，创建须在驱动调用前拒绝。

验证设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
标准样点位置及逐样点着色均可用。
当前 HDR 格式的样本位掩码为十五。
该掩码包含一、二、四及八样点。

## 验收边界

本项验证通用附件、管线、插值和透明覆盖。
真实角色四样点质量仍须接入场景渲染验证。
离线质量预测见[动态细节与几何样点](native-detail-sampling.md)。
主辅视图、深度副本、描边及正式入口继续实施。

两种构建各通过十六项注册检查。
四样点 GPU 检查每种构建均核对 8,192 个数值。
既有运动、时序、透明覆盖与描边检查共同通过。
运行着色器共八十七个，跨构建指纹一致。

既有八十五个着色器的指纹保持冻结值。
原生角色的三十二帧与冻结输出逐字节一致。
原图与八个发冠边缘光对照点保留原有门禁。
完整收据见[专项证据](evidence/2026-10-24/multisample-rhi.json)。
