# 反射历史重投影验证

日期：2026-10-29。阶段为 NR5-R8-N。
公共资源位于 `src/render/ReflectionReprojection.*`。
计算程序为 `shaders/reflection_reprojection.comp`。
接口与数据编码见[运行契约](../../runtime/reflection-reprojection.md)。

## 所有权与拒绝

每槽位持有运动和接收权重两张图像。
运动的 Z、W 同时保存选样深度与表面有效性。
图像预算为每像素每槽位 20 字节。
组合资源上限为 256 MiB，私有参数为 48 字节。
预算、源尺寸、投影和输入别名在录制前检查。
非法输入保持命令及描述符写入数量不变。
同槽位历史被拒绝，其他槽位可提供历史输入。
格式能力及无效着色程序分别检查。

CPU 红测确认缺失的图像所有权未被夹具放行。
GPU 红测确认空背景深度必须被排除。
背景清除值为 100000，与本帧射线保持一致。
非有限输入、投影溢出及零期望深度均拒绝历史。

## GPU 数值

每种配置通过 208 份重投影输出。
独立参考共核对 51,220 个输出标量。
数值预算为 `2e-6`。
尺寸覆盖完整、半尺寸、奇数轴及单像素轴。
两个槽位均覆盖首帧、屏外、响应和深度拒绝。
透视、正交、容差内及容差外分别核对。
部分响应与裁剪响应按公共运动编码检查。

补充序列先在无效历史状态下写入两个槽位。
随后直接借用另一槽位的实际运动输出。
前帧深度通过正确的图像和采样屏障被消费。
该序列的有效接收权重逐像素为一。
初始序列的接收权重逐像素为零。
全部输出保持有限，校验错误与最终资源数量均为零。

Debug 与 Release 各通过十项受影响检查。
补充跨槽位 GPU 用例在两种配置分别复测。
两种配置的 Player 与编辑宿主完成构建。
既有 208 份着色器产物保持指纹一致。
新增重投影程序在两种配置间逐字节一致。
