# 每日模型副本维护

## 范围与规则

目录维护技能装配普通任务、共享管线缓存、历史模型和生成缓存的每日维护。
项目数据、证据及必要恢复依据均位于 D 卷项目目录。
本机技能入口调用版本管理中的工具，规则见[产物管理](../../development/artifact-retention.md)。

历史模型通过一次性清单和当前工程输入锁核对。
当前声明范围为 `20261103-234012-character-reference-stages-5abe6c`。
同名同大小的候选共 13668 份，逻辑合计约 83.10 GiB。
清单生成耗时约 4.81 秒，清单大小约 3.20 MiB。
日常复用清单，删除时核对候选与存活原件的完整 SHA-256。

模型分项每天至多 32 GiB、512 个文件。
生成缓存分项每天至多 10 GiB，全部每日维护共用一百二十秒。
日配额在删除前预留，多次调用累计计入同一天。
当前输入锁、Git 跟踪文件、嵌套工作树及链接受到保护。
活动构建、测试和采集结束后执行维护。

文件身份及输入锁在删除前再次核对。
同一文件身份的内容证明在本次维护中复用。
来源映射及批次记录保留原路径、原件位置和摘要。
源资产按共享路径读取，普通任务完成后保留一天。
