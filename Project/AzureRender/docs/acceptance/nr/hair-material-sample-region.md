# 头发参数与双法线实际取样

日期：2026-11-09。
状态：实际输入核对完成，完整颜色未通过。

## 输入与资格

范围为来源控制后剩余的 31 个颜色失败点。
原生参数图读取事件 950 的纹理 17。
双法线图读取同事件的纹理 18。
Vulkan 从原投影头发函数读取对应实际取样。

两类输入各保存完整 RGBA 单精度位值。
每个分量使用三个十二位输出版本恢复。
整个 290×310 裁剪的蓝通道逐位保持原值。
原片元流程、覆盖和丢弃规则持续保留。

Vulkan 同时记录每类输入的读取状态。
未读取及多次读取不一致分别具有独立标记。
31 个位置的两类输入均已读取，重复读取均一致。
这组数据满足直接比较的调用范围要求。

## 参数图结果

25 个位置的 RGBA 逐位一致。
六个位置存在差异，最大线性分量差约为 0.182422。
差异位置为 1306,156、1319,172、1322,263，
以及 1193,295、1193,296、1193,297。

该集合包含四个[基色取样差异点](hair-base-sample-region.md)。
1306,156 与 1319,172 的基色向量逐位一致。
两处参数及法线取样仍存在独立差异。
后续核对插值位置及实际过滤输入。

## 双法线编码

原生四通道解码为 `2*RGBA-1`。
宿主对 G、A 使用 `1-2*channel`。
R、B 继续采用 `2*channel-1`。
规则见[公共法线计算](../../../shaders/character_surface.glsl)。

原始 RGBA 的差异包含该编码约定。
进入共同切线分量后，六个位置逐位一致。
参数图一致的 25 个位置中，最大分量差为 `5.960464477539063e-8`。
该数值描述输入差异，完整颜色沿一字节门禁验收。

六个较大双法线差异点与参数图差异集合一致。
这六处的共同分量最大差约为 0.197024。
其他位置继续核对基底、归一化和颜色算术。
编码转换本身不作为错误认定。
