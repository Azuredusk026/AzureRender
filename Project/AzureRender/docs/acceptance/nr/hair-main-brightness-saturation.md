# 头发主光亮度饱和度

日期：2026-11-10。
状态：公共契约及所属回归通过，完整颜色未通过。

## 公共输入

版本二的投影头发照明接收布尔字段
`hair.projectedRamp.lighting.mainBrightnessSaturation`。
缺省值为 `false`。
该选项要求发丝漫反射响应及独立漫反射色带。

加载器拒绝错误类型和所属关系。
材质表版本为二十二，大小为 352 字节。
`rows[6].w` 的位三保存该选项。
照明、透明高光及快照法线使用各自标志。

## 颜色组合

环境漫反射与所选主灯漫反射形成基础组合。
条纹先作用于指定的漫反射项。
所选主灯的照明后双叶能量参与该组合。
主叶消费独立的材质高光上限。

亮度采用共享线性 RGB 权重。
饱和度系数为 `1+clamp(亮度-0.5,0,0.5)²`。
组合按该系数增强色度并保留亮度。
局部灯及反射保持各自的照明贡献。

直接漫反射、环境及双叶隔离项同步记录能量。
颜色总和保留对应的合成增量。
转换工具为已确认的原生投影头发照明写入该选项。
标准材质的缺省输入保持其既有定义。
