## 实现与来源

源码基线为 `0f62cb3`。
`PreparedAnimationCurve` 持有校验后的独立输入。
`PreparedAssetAnimations` 持有绑定资源的片段快照。
加载时创建快照，重载时重建，卸载时释放。

单片段、片段过渡及加权混合使用相同数据。
实例分别持有时间、循环、权重和输出姿态。
运行时验证资源归属及采样时间。

借鉴 [ozz-animation 的构建过程](https://github.com/guillaumeblanc/ozz-animation/blob/744eb9d99f606eda849acb0b1204f7a3dc20bca1/src/animation/offline/animation_builder.cc)及[运行时输入](https://guillaumeblanc.github.io/ozz-animation/documentation/animation_runtime/)。

## 同输入成本

私有控制使用一个冻结的完整联合场景。
两种算法交替运行，消费相同资产、片段及时间。
二十帧共二百二十次输出的全部姿态原字一致。
实际负载每帧有十一次受检动画采样。

全量校验的采样合计均值为 2.685 毫秒。
预备曲线的采样合计均值为 0.431 毫秒。
本轮局部差值为 2.254 毫秒，约占百分之八十四。
这些值描述同输入采样成本，整帧收益单独验收。

私有控制增加了参考求值和原字比较工作。
该批热状态检查失败，整帧时间属于诊断范围。
正式快照持有额外的 CPU 片段及曲线数据。
完整帧预算和持续运行内存条件保持有效。
