## 探针输入

照明事件 8912 通过槽位六读取八面体数组。
资源尺寸为 576×576，共三十二层及十个分配层级。
原生格式为 `R11G11B10_FLOAT`，载荷为 56622336 字节。
数组载荷及全部子资源摘要保存于私有任务目录。

实际常量声明十二个局部探针。
局部记录从第十二行开始，每份占八行。
中央白黄色探针对应数组第一层，强度为 `0.5`。
其投影原点、体积、顺序和剩余权重由活动程序消费。

八面体有效区域的缩放为 `8/9`，边缘偏移为 `1/18`。
数组采样器的三个寻址轴均为边缘钳制。
有效粗糙度经过对数映射后进入显式层级采样。
原生输入、公共多探针组合及完整采样等价继续逐项验收。

## 动态反射

事件 8702、8713、8723 写入反射颜色及辅助信号。
事件 8741 使用运动输入和历史颜色执行时序合成。
其后六次计算生成颜色层级，事件 8811 执行深度引导过滤。
事件 8912 从槽位三读取 1280×720 的最终反射颜色。

历史颜色在该截帧中只有读取记录。
它属于捕获初始状态，连续帧的对应写入另行核验。
同一资源的读取、写入及层级范围分别保存。
公共单射线过滤与完整原生生产链按各自范围验收。
