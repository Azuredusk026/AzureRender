## 来源契约

`nprDiffuse.characterVisibility` 支持两类来源。
`scene-visibility` 采用传入的场景可见量。
`main-light-shadow` 采用宿主主灯阴影图的实际结果。
场景 `shadowOverride` 独立控制场景可见量。

`shadowMask: one` 使用常量接收遮罩。
该模式可与显式漫反射色带共同使用。
纹理接收遮罩仍使用独立的绿、蓝通道规则。
字段及范围见[材质契约](../../runtime/npr-diffuse.md)。

材质布局版本六保持 192 字节和九槽。
第四行 X 声明来源，首行 Y 声明接收模式。
阴影图、绘制通道及资源生命周期沿用宿主规则。
普通材质及缺省来源具有逐字节兼容检查。

## 原生生产链

事件 699 写入两通道屏幕遮罩。
红通道保存场景可见量，绿通道保存角色可见量。
事件 783 的两个输入具有独立的实际消费者。
四个参考点的红通道均为 255。

角色通道读取独立的对象深度图。
图像采用 4096×2048 的十六位深度数据。
十次角色绘制写入一个 1024×1024 分区。
其实际分区位于四列两行布局的第三列第二行。

消费者采用接收面法线偏移及沿光方向偏移。
十六次四点聚集采样共取得六十四个深度值。
过滤同时消费遮挡数量、正深度差之和及接收深度。
采样旋转索引由四像素周期的屏幕坐标确定。

原生腿部具有 61 个遮挡样本。
过滤结果为 0.01842177，八位输出为 5/255。
两个面部点及肩部均具有零个遮挡样本。
其角色可见量均为一。

原始深度图与追踪中的 256 个采样值完全一致。
独立过滤复算的最大误差小于 `1e-9`。
对象图范围、偏置与过滤继续接入公共阴影生产路径。
宿主主灯图作为已声明来源具有独立验证范围。
