# 四像素组照明消费验收

## 结果与范围

四像素组检查、片元丢弃及完整补充已经接入。
本单元的一组原生四帧保持 RGB 零差异。
同步日志无错误，卸载分配残留为零。
本地短时比较未观察到显著 GPU 收益。

实验入口默认关闭，正式长采样未启动。
CPU 八毫秒及 GPU 16.6 毫秒标准有效。
整体画质保持 `failed-user-review`。
正式采样、长跑及人工项继续按原条件验收。

## 消费与深度

轻量程序先检查同帧四像素组身份。
失配时丢弃片元，保持原有深度。
合格消费写入缓存颜色及深度。
完整着色随后按原始剔除命令补充其余片元。

完整补充采用严格 LESS 比较。
两个阶段各自保持原始命令顺序。
缓存资格、帧槽与资源预算沿用所属契约。
缺少四像素组能力的设备保持完整着色。

## 机制与兼容

实际 GPU 图案首先复现完整绘制先行的失败。
最终图案覆盖命中、混合失配及三角形边界。
两种配置核对实际颜色及深度覆盖关系。
两个设备的针对性视图输出一致，释放计数为零。

十六份轻量程序均采用延迟深度语义。
程序要求完整四像素组，并包含丢弃操作。
静态可达指令量至少减少约 94.2%。
静态规模与实际消费数量及 GPU 时间分别解释。

本单元仅采集一组 2560×1440 原生四帧。
四帧的 RGB 差异与 PNG 摘要差异均为零。
源码、程序及 1729 项输入摘要保持一致。
两个退役帧记录了轻量绘制资格。

绘制资格与网格见证不表示消费端命中像素数。
本次原生图像证明兼容及回退行为。
后续归因需区分真实消费和其余主场景成本。
