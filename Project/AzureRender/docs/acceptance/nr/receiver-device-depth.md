该捕获形成于十月二十七日，深度数值结论以其输入为范围。

对象接收算法沿用[同输入模型](object-receiver-input-model.md)。
主程序、源码及原始捕获均保持原字节。
完整画面及正式性能采样由接入候选的门槛调度。

绑定 18 的快照资源沿实际写入关系定位到事件 392，其深度资源为 1048。
两者均为 2560×1440 的 `D32`，每份 14745600 字节。

## 坐标与快照

当前纹理采用图像行号，原生参考使用 `1439-y`。
相机逆矩阵及左手、右手坐标基分别参与输入变换。
像素中心和原程序的整数像素重建位置分别核对。

CPU 双精度控制使用当前设备深度及相机逆矩阵。
当前像素中心相对原生 GPU 重建位置的中位距离约为一毫米。
按原整数位置对应的 `(0,1)` 偏移重建，中位距离约为 31.79 微米。
该控制用于区分坐标规则和精度，实际 GPU 结果承担可见量判据。

主绘制与快照在原 17017 像素遮罩内逐字节一致。
全图有 3683210 个位置相同，3190 个位置不同。
因此当前快照可作为该遮罩范围的深度来源，整图范围继续单独核对。
屏幕采样相位还须明确图像行号与反向行号的关系。
接收重建和过滤相位具有各自的坐标契约。

## 深度编码与数值对照

当前深度在该区域约为 0.96854 至 0.97044。
原生深度约为 0.02965 至 0.03154。
单精度相邻值间隔在当前区域为 `5.96046448e-8`。
原生区域的相邻值间隔分别为 `1.86264515e-9` 和 `3.72529030e-9`。
当前间隔是原生的十六至三十二倍。

参考相机及坐标基组成齐次投影关系，CPU 双精度控制据此换算深度。
换算后的深度有 123 个位置与原生逐位相同。
绝对误差中位数约为 `5.96046448e-8`，最大约为 `2.96160579e-7`。
当前结果包含投影、光栅和存储精度的综合影响。
单独改变深度编码尚未建立原生输入一致性。

随后保持原生法线、对象图集、接收算法及采样相位，替换为换算后的深度。
GPU 模型在 NVIDIA 执行完整 17017 像素，并采用显式八位舍入。

| 范围 | 结果 |
| --- | ---: |
| 逐字节一致 | 16664 |
| 一字节以内 | 16796 |
| 超过一字节 | 221 |
| 最大误差 | 39 |

四处控制点均得到 239、86、95、255，与参考相同。
完整遮罩仍未通过，控制点结果只说明对应位置。
真实八位附件转换的原同输入结果保持有效，本次深度替换属于独立分项。
本轮同步验证错误为零，释放后缓冲和图像均为零。
