# 原生头发覆盖层级核对

日期：2026-11-11。
状态：实际覆盖选级的局部改善已复现。
完整头发颜色仍按一字节门槛验收。
整体状态为 `failed-user-review`。

## 图源身份

生产基线的合成颜色图为 2048×2048，包含十二级。
独立原生覆盖图为 512×512，包含十级。
独立解码核对了对应的 349525 个纹素。
原生红通道与合成图的对应透明通道逐字节一致。

独立覆盖通过公开材质字段接入实际 Player。
采集清单确认红通道、十级和线性数据。
采样器使用最近层级、线性过滤及负一偏移。
Intel 图源对照的四份 PNG 摘要精确一致。

## 椭圆层级对照

隔离程序仅替换独立覆盖的选级运算。
颜色、法线及其他材质采样保持各自路径。
84 份受检程序中有 50 份发生变化。
其余 835 份程序集摘要保持一致。

| 设备与用例 | 超差像素 | 最大字节差 | `[1326,177]` 最大字节差 |
| --- | ---: | ---: | ---: |
| NVIDIA 独立图源 | 43 | 5 | 0 |
| NVIDIA 椭圆层级 | 43 | 5 | 0 |
| Intel 独立图源 | 597 | 166 | 166 |
| Intel 椭圆层级 | 597 | 97 | 2 |

Intel 峰值点的 RGB 为 `[71,20,23]`。
对应原生颜色为 `[69,18,23]`。
全区平均误差约为 `0.21296351` 字节。
两设备的超差集合均保持原有成员。

NVIDIA 的 17017 个遮罩像素保持逐位一致。
Intel 遮罩中仅该峰值点的颜色发生变化。

四组用例共采集十六帧。
每组四帧的遮罩像素完全一致。
所有 GPU 运行无验证或同步错误，卸载计数归零。
配置版本不符的初次加载拒绝保存在验证归档中。
