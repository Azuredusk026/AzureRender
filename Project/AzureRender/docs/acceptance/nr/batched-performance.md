## 实现机制

完整覆盖的材质类别使用提前深度程序。
类别与特性专用常量保持所属材质的实际值。
屏幕照明法线、节点淡出及特殊覆盖保留原路径。
主颜色与反射快照按每段节点透明度选择。
四样本继续使用所属采样路径。
管线参与原有重建、失败清理及卸载。

密集透明排序输入每元素计算一次浮点键。
四份直方图共用一次扫描，恒定字节保持次序。
任意索引、非有限值与有符号零保持所属语义。
顶点坐标、标记、深度与排序空间由渲染器复用。

3456 个光照网格单元复用成员容量。
相机参数更新后重新计算成员及 GPU 数据。
GPU 头部与索引输出复用调用方存储。
无效重配置保持前一份网格状态。
这些工作空间在渲染器卸载时释放。
