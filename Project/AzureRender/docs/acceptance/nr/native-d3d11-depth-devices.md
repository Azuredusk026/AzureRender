# 原生深度设备对照

两设备重放同一份原生帧 10401。
设备为 NVIDIA RTX 4060 Laptop GPU 和 Intel UHD Graphics。
重放返回实际设备身份，管线为 D3D11。
捕获文件在运行前后的摘要均与冻结记录一致。

## 深度写入与消费

事件 422 提交 43044 个索引。
目标为 2560×1440 的 `D32S8_TYPELESS` 附件。
每纹素八字节，深度取低位 32 位分量。
格式见 [DXGI 资源格式](https://learn.microsoft.com/en-us/windows/win32/api/dxgiformat/ne-dxgiformat-dxgi_format)。

前后读回确认两设备均改变 19063 个深度值。
设备间的写入位置集合完全一致。
固定头发遮罩的 17017 个位置均有实际深度写入。
每设备的写入深度与事件 699 的深度输入逐位一致。

| 参考范围 | 深度精确点数 | 相差至多一个单精度间隔 |
| --- | ---: | ---: |
| NVIDIA D3D11 对冻结深度 | 17017 | 17017 |
| Intel D3D11 对冻结深度 | 7964 | 15678 |
| Intel D3D11 对同设备 Vulkan 参考深度 | 17014 | 17014 |

Intel 的三处跨接口差异位于 `[1311,355]`、`[1312,355]` 和 `[1326,177]`。
前两处相差九个和五个单精度间隔。
第三处对应透明层级诊断点。

## 可见量输入与颜色

事件 699 的深度、法线和图集均按实际绑定读回。
NVIDIA 的三份全量摘要均匹配冻结来源。
Intel 的三份摘要均存在差异。
可见量的各来源继续按实际生产链验收。

事件 950 读回实际 `R11G11B10_FLOAT` 附件。
NVIDIA 全量摘要匹配冻结来源。
Intel 有 580 处颜色超过一字节，最大误差为 166。
Intel 的生产候选与该重放共享 562 处冻结超差。

同设备对照中，NVIDIA 和 Intel 生产候选各有 43 处超差。
两个同设备集合共享 27 个位置。
Intel 采用设备选级的对照有 42 处超差，最大误差为 39。
该峰值位于 `[1353,325]`。
