# 头发基色实际取样核对

日期：2026-11-09。
状态：取样位值核对完成，完整颜色未通过。

## 范围与资格

本项核对来源控制中的 31 个剩余颜色失败点。
两份捕获保持原片元流程及丢弃规则。
原生探针在基色读取后保存寄存器值。
Vulkan 探针读取原始隐式基色取样结果。

探针以红、绿通道编码每个单精度分量。
每次编码十二位，三个版本恢复完整三十二位。
原蓝通道保持原计算与原附件存储。
资格要求整个 290×310 裁剪的蓝通道逐位一致。

两份捕获各九个版本均通过资格核对。
全部十八个版本在原实际 GPU 上执行。
移除替换后，完整裁剪逐字节恢复原值。
本批进程正常退出，耗时 64.578 秒。

## 实际结果

31 个位置中，27 个基色 RGB 向量逐位一致。
四个位置存在实际取样差异。
它们的最大分量差如下。

| 显示坐标 | 最大线性分量差 |
| --- | ---: |
| 1322,263 | 0.01312255859375 |
| 1193,295 | 0.01123046875 |
| 1193,296 | 0.004638671875 |
| 1193,297 | 0.0028839111328125 |

1322,263 的原生 RGB 为：
`[0.385498046875,0.0885009765625,0.09283447265625]`。
该点匹配既有[精确取样记录](exact-hair-sampling-inputs.md)。
其层级与梯度边界保持原诊断范围。

基色一致的 27 处需要核对其他材质输入及颜色合成。
四处差异需要继续核对梯度、层级和覆盖关系。
[十二级内容](hair-base-color-mip-content.md)的 RGB 均一致。
纹理内容与实际取样结果分别持有证据。
