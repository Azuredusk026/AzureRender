日期：2026-11-02，归属为 Q1。
状态：公共输入、来源层级及错误退出检查通过。
生成层级的覆盖保持通过[专项验收](material-coverage-mips.md)。

渲染器 API 为九，画像布局为二十一。

## 公共输入

版本二画像通过 `coverageTexture` 声明独立裁剪图。
对象版本为一，支持红通道与透明通道。
输入保留图像尺寸、已有层级及采样器。
通用、织物和头发的 `MASK` 表面共享该契约。

裁剪拥有金属粗糙度纹理槽的透明通道。
RGB 保存常量 AO、粗糙度和金属度。
参数图、对应镜面来源与 NPR AO 须遵守互斥所有权。
完整文档、材质图及参数覆盖通过生产解释器检查。

主颜色、快照、深度、描边与阴影选择具名覆盖程序。
运动通道借用相同覆盖图像及采样器。
基础颜色透明度继续表达所属颜色语义。
接口及所有权见[运行契约](../../runtime/material-coverage.md)。

## 原生范围

原生裁剪图为 512×512，具有十个层级。
两条硬件路径均与来源遮罩逐像素一致。
放大裁剪对照在相同平面上产生 62 个不同像素。
实际角色底色的十二级 RGB 均与来源一致。

六个原生强边缘光控制点均在一字节预算内。
完整头发仍有 17,017 个可见来源像素。
其误差 95 分位为 21 字节，最大值为 44 字节。
完整头发的一字节门禁保持未通过。

裁剪采样、着色、高光和皮肤分别保存验收范围。

## 失败控制

冻结失败程序在扩张深度和实例遮罩使用底色透明度。
曲面对照保存 387 个不同像素的失败结果。
具名程序缺失控制另保存两处着色模块泄漏诊断。
对应正常路径和错误退出分别复测。

当前六类缺失程序覆盖两条描述符路径。
Player 给出缺失文件诊断，采集帧数为零。
缓冲与图像卸载计数均归零。
Debug 验证层未报告资源泄漏或其他错误。

夹具的逐级通道对照提供输入资格。
RGBA 预乘缩放产生的非等价夹具保留失败记录。
采样格式控制与未选中程序控制分别保存实际结论。
各项门槛沿用原始预算。
