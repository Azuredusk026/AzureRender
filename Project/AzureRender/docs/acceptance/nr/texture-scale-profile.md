# 纹理导数尺度来源

日期：2026-11-10。
状态：观测控制通过，通用层级候选待验。
前置证据见[显式欧氏层级核对](alpha-euclidean-lod.md)。

## 独立纹理夹具

夹具通过片元坐标生成仿射纹理坐标。
单轴组覆盖 256 种尺度、比例及方向组合。
双轴组覆盖 256 种平行、正交及斜交组合。
每个组合读取硬件层级及对应导数模型。

两设备各完成 512 个组合。
双轴组的层级误差如下，单位为纹理级数。

| 设备 | 列欧氏最大误差 | 行欧氏最大误差 | 椭圆主轴最大误差 |
| --- | ---: | ---: | ---: |
| NVIDIA | 0.541373 | 0.429688 | 0.117190 |
| Intel | 0.010728 | 0.503909 | 0.509313 |

椭圆主轴取导数矩阵的最大奇异值。
NVIDIA 的观测层级更接近该模型。
Intel 的观测更接近列向量长度最大值。
这些结果用于模型选择，精确硬件算法仍待核对。

规范描述椭圆足迹及尺度计算的允许近似。
依据见[Vulkan 纹理采样](https://docs.vulkan.org/spec/latest/chapters/textures.html#textures-scale-factor)。

## 原生几何观测

原生组读取四片元导数、层级和透明值。
每设备八种输出的 D32 均与控制逐位一致。
透明值及硬件层级也与前置观测逐位一致。
各次核对覆盖完整 17017 个位置。

透明判定差位于界面坐标 `[1326,177]`。
该处的观测如下。

| 量 | NVIDIA | Intel |
| --- | ---: | ---: |
| 横向导数 U | 21.246460 | 21.246246 |
| 横向导数 V | 0.305679 | 0.305702 |
| 纵向导数 U | 17.682831 | 17.682648 |
| 纵向导数 V | 0.778236 | 0.778244 |
| 硬件层级 | 4.769531 | 4.433594 |
| 列欧氏层级 | 4.409300 | 4.409286 |
| 行欧氏层级 | 4.788804 | 4.788789 |
| 透明值 | 0.729931 | 0.495644 |
