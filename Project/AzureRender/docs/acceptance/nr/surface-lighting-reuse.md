# 零反射照明复用的覆盖范围

## 提案

本单元入口为 `17df0c6`。
候选保存反射合成前的完整照明。
消费者在反射贡献为零时复用颜色。
其他像素按完整四像素组执行原着色。

提案采用两个附件，分别保存颜色及整数身份。
1440p 双帧槽的逻辑内容为 225 MiB。
公开资源机制和场景集成均保持待实施。
已有照明重组的零像素失败记录持续有效。

## 已有捕获核对

输入为既有 720p 捕获，摘要保持一致。
反射图像为 640×360 的四通道单精度纹理。
其 230400 个位置中有 60569 处反射贡献为零。
纹理只在内存中统计，磁盘保存结果摘要。

核对按实际缩放关系映射到 1280×720 目标。
双线性邻域增加一层保守邻接保护。
四像素组内全部位置均满足条件，才登记为候选。
该类像素共 149724 处，约占全屏 16.25%。

该比例仅说明全屏反射图像的空间分布。
实际普通材质覆盖及片元工作量尚未测得。
三个最高成本事件的前后颜色读回均无差异。
这种读回未形成可用的绘制覆盖计数。

三份事件使用同一实际管线。
颜色写入掩码为 `[15,15,1]`，深度写入开启。
该管线采用严格小于深度比较。
本次证据尚未定位颜色读回相同的具体原因。
