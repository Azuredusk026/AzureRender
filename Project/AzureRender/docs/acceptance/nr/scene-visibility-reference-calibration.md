# 对象可见量逆投影标定验收

日期：2026-11-12。
范围为实际 Player 的参考对象可见量通道。
整体画质状态为 `failed-user-review`。

## 标定来源

参考视图可指定可见量逆投影和位置偏移。
矩阵来自帧 10401 的实际原生对象可见量常量。
位置偏移为 `[-300,300,-300]`，沿参考视图的有符号坐标轴定义。
矩阵按列保存单精度位值。

相机处于标定锚点时使用矩阵原值。
相机移动时按姿态搬移逆投影，屏幕缩放只作用于裁剪平面。
实际对象记录在同一坐标帧中生成。
深度、压缩法线、对象身份和 D16 图集由当前场景写入。

## 坐标核对

CPU 对照覆盖 1,024 组有符号轴、相机姿态及屏幕缩放。
最大位置误差为 `3.03939242e-6`。
配置检查覆盖版本、向量长度、矩阵可逆性及锚点数值。

实际夹具包含斜向投影遮挡面和可见接收面。
有符号轴标定及相机与对象共同移动时，整张可见量逐字节一致。
三个夹具均有 1,144 个像素的绿通道低于 255。
背景为 255，指定阴影点为零。

Debug 与 Release 的五项 CPU 检查分别通过。
双设备在两配置各通过四项 GPU 检查。
同设备的参考附件、颜色及区域统计逐项一致。
两配置各有 891 份着色器程序，摘要逐项匹配。

## 冻结区域

实际 Player 按同一份一字节门槛核对冻结区域。
头发区域包含 17,017 个位置，完整接收区域包含 49,384 个位置。
深度、法线、对象身份及完整颜色的摘要逐项匹配各自控制。

| 设备与区域 | 常规逆投影超差 | 标定逆投影超差 | 标定后逐字节一致 | 最大误差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA 头发 | 391 | 277 | 16,686 | 42 |
| Intel 头发 | 502 | 428 | 16,428 | 55 |
| NVIDIA 完整接收 | 3,309 | 3,129 | 45,769 | 255 |
| Intel 完整接收 | 3,437 | 3,327 | 45,389 | 255 |

NVIDIA 头发超差的 277 处均落在图集或对象记录的单项超差范围内。
其中 276 处的实际深度和压缩法线均与原件逐位一致。
完整接收区域有 910 处的误差超过 64 字节，均位于头发遮罩外。
这些位置的深度或压缩法线与原件存在差异。

图集页 6共有 2,380 个共同覆盖纹素的深度差异超过两个 D16 单位。
这些位置的三乘三邻域均有相应幅度的深度变化。
对象记录与原生常量统一坐标和深度方向后，平移项最大绝对差为 `1.52587891e-5`。
图集、记录及其余材质输入分别继续验收。
