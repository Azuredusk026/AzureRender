# 极点旋转的变换分解

日期：2026-10-22。
范围为通用变换分解与场景导入诊断。
实现归属 `scene::decomposeTrs`。
场景导入、层级换父和变换工具共享该契约。

## 分解规则

矩阵采用列主序，旋转角度以度为单位。
组合顺序为 `T * Rx * Ry * Rz * S`。
缩放符号按调用方偏好与行列式恢复。
旋转列在提取缩放后归一化。

令 `R` 为归一化后的旋转矩阵。
直接从矩阵计算余弦幅值：

```text
c = hypot(R[1,2], R[2,2])
y = atan2(R[0,2], c)
```

`c > 1e-5` 时分别恢复横向和纵向旋转。
极点分支令 `z = 0`，从其余矩阵项恢复 `x`。
分支判断使用矩阵携带的余弦幅值。
因此正弦的浮点舍入与旋转分支各有明确依据。

## 输入与精度门禁

输入必须有限、仿射且可逆。
缩放绝对值必须至少为 `1e-7`。
任意两根旋转列的点积绝对值超过 `1e-4` 时拒绝。
该检查用于拒绝剪切。

分解结果必须按既有组合顺序重建。
每个元素均执行以下精度门禁：

```text
abs(input[i] - rebuilt[i]) <= 2e-4 * max(1, abs(input[i]))
```

矩阵导入失败时保留 `std::invalid_argument`。
错误包含源节点标识及分解原始原因。
编辑事务按既有失败规则保持文档完整性。

## 来源矩阵

原生交换包中两个墙片具有相同的线性部分。
标识为 `structure-native-38805087` 和 `structure-native-54024768`。
首个矩阵按列列出如下：

```text
[  0,                  0.7059292793273926, 0,                 0 ]
[  0,                  0,                 -9.756230354309082, 0 ]
[ -10.965432167053223,  0,                  0,                 0 ]
[ -80.19000244140625,   9.139999389648438,   63.03000259399414, 1 ]
```

该矩阵旋转列互相正交。
其精确极点的余弦分量为零。
倒数乘法归一化得到的正弦约为 `-0.9999999404`。
分解依据矩阵余弦分量选择极点分支。

独立 C++ 探针对交换包的 1346 个矩阵全部通过。
固定回归使用上述字面矩阵。
另有两份独立构造的 `±89.99°` 字面矩阵。
这些矩阵的重建误差均不超过 `2e-6`。
