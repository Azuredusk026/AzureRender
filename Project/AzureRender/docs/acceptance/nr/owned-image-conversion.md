# 图像转换缓冲验证

## 实现范围

图像转换提供借用及消费输入两种入口。
八位消费入口在验证后转移原像素分配。
来源诊断与像素共同交给结果拥有者。
十六位及浮点路径继续采用所属转换公式。

glTF 回调通过两次所有权转移交付八位图像。
材质转换消费独立临时缓冲。
共享模型图像继续供多个材质读取。
独立图像加载通过同一接口交付像素及层级数据。

单份八位结果沿用原分配地址。
调用过程中无需复制该份像素缓冲。
借用入口仍提供独立的可写结果。
该结果证明所有权效率，完整加载耗时另行测量。

## 所属结果

新增失败控制确认原路径产生独立分配。
消费入口通过原地址及逐字节内容核对。
非法长度在转移前拒绝，输入缓冲保持有效。
高精度输出、裁剪、透明度及诊断与借用入口一致。

Debug 与 Release 各四项 CTest 通过。
范围为常见图像、扩展格式、资产往返及纹理共享。
实际加载覆盖格式识别、颜色、透明度及错误输入。
共享夹具覆盖固定与索引访问、层级、重载及释放。

两种配置各 675 份着色程序摘要一致。
本单元的原生采集与整帧计时次数均为零。
GPU 帧预算及完整画质仍按原标准验收。
整体状态保持 `failed-user-review`。
