# 解析雾数值验收

日期：2026-10-28，阶段为 NR3-F1H。
范围为光谱大气、高度积分及有序传输。
场景参数与实际表面见[场景解析雾](scene-fog.md)。

## 来源片元

透明来源为第 9160 和 10875 次绘制。
六处原版片元保存完整的着色指令状态。
大气透射、散射及其组合的最大误差为 0.000000131。

不透明来源为第 8912 次绘制。
深度资源提供 10191 个网格范围以外的像素。
四处采样覆盖约 65 至 145 米的实际距离。
高度雾透射率位于 0.99565 至 0.99963。

远端传输组合的最大误差为 0.000000586。
来源顺序为预积分体积、高度段和光谱大气。
来源的二进制指数密度转换包含自然对数平方。
高度衰减率转换包含一次自然对数。

## 公共数值

`ExponentialAerialFog` 提供独立的光谱参数。
评价支持瑞利、米氏及常量颜色的源项。
方向归一化、参数范围及有限值分别校验。
版本一的 GPU 布局包含六行，共九十六字节。

高度积分使用低端点及对数形式评价。
水平射线、极端高度及长距离分别验证。
CPU 与 GLSL 共享传输及有序组合语义。
所有权由参数调用方及消费资源分别承担。

## 验证结果

Debug 与 Release 各通过八项 CPU 与接口检查。
新增大气单元检查为三十二项。
既有高度传输检查为三十项。
两种宿主均完成 Player 与编辑器构建。

两配置各通过四十四组独立 GPU 样本。
其中十组使用原版实际片元值。
原版组合的 CPU 最大误差为 0.000000589。
GPU 最大误差为 0.000015259，预算为 0.00003。

无效版本、截断、非法标志和超量样本均被拒绝。
GPU 验证层及资源释放检查通过。
独立计算模块由测试目标持有。
应用着色模块保持 199 项，全部指纹一致。
