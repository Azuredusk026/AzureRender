# 原生服饰接收法线输入

帧 10401 的事件 377 在像素纹理槽一绑定资源 87521。
两块设备均使用实际 D3D11 回放读取该资源。
纹理为 2,048 × 2,048 的 BC5，包含十二级。
NVIDIA 和 Intel 读回的各层压缩块逐字节一致。

## 采样契约

像素程序使用线性缩小、线性放大和最近邻层级。
两个纹理轴均采用重复寻址。
采样器的层级偏移为零，像素采样指令的层级偏移为 −1。
顶点程序的纹理坐标变换为单位缩放及零偏移。
像素程序在采样 RG 后重建 Z，以插值切线帧变换法线，并对背面翻转方向。

## 存储方向

当前服饰一的标准材质法线来自嵌入 PNG。
按行翻转 PNG 后，4,194,304 个位置中有 4,189,362 个与解码后的原生 RG 完全一致，4,192,794 个处于一字节内。
PNG 与原生纹理使用相同的绿色通道方向。
同一服饰的图集绘制事件 191 提供顶点 UV 对照。
以半精度配对比较，32,031 个夹具顶点中有 31,988 个可在原生 UV 集合的 `1 − V` 方向找到。

## 验收状态

事件 377 写入的 16,629 个法线位置中，当前实际 Player 在 NVIDIA 上有 1,350 处可见量超差，Intel 有 1,349 处。
下一项对照按夹具存储方向接入原生层级链，并沿用当前材质和采样器。
采样选级与法线重建继续按各自输入逐项核对。
完整接收区域及联合画质状态为 `failed-user-review`。
