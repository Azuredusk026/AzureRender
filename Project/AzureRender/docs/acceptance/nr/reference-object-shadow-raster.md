# 参考对象图集光栅验收

日期：2026-11-12。
范围为实际 Player 的标定对象图集及屏幕可见量。
整体画质状态为 `failed-user-review`。

## 图集生产

标定记录按图集页选择接收投影和光栅投影。
顶点使用当前姿态、实例矩阵及编辑变换。
绝对位置经原生乘加次序换算为裁剪位置。
实际正向 D16 图集提供同帧对象深度。

相机缓冲的基础布局为 800 字节。
选中参考对象功能时，每个图集页分配 128 字节扩展区。
普通对象和级联阴影使用各自的场景投影。

## 绘制来源

原生事件 237 与 Vulkan 计算蒙皮事件 233 对应头发遮挡绘制。
冻结输入的 GPU 对照逐组核对七种图集来源。
仅替换头发组的对照中，17,017 个头发位置逐字节一致。
该对照测量图集来源，生产使用当前场景实际绘制。

实际事件 233 读取绑定的 1,824 字节相机缓冲。
目标页的裁剪矩阵和绝对原点与原生输入逐位一致。
11,564 个顶点中，11,559 个裁剪位置逐位一致。
纵向与深度分量峰差分别为 `3.052e-5` 和 `7.629e-6`。

实际图集由同帧事件 340 消费。
与原生图集共有 182,219 个有效纹素。
其中 180,031 个纹素的深度差至多一码，1,120 个超过两码。
重放无调试消息，屏幕附件摘要与固定绑定采集一致。

头发写入的 11,613 个共同纹素均在一码内。
服饰一和服饰二分别有 209 和 731 个共同纹素超过两码。
逐事件统计见结果清单。

## 场景夹具

夹具覆盖相机换轴、相机与对象平移及灯光转动。
同一场景的标定与常规可见量逐字节一致。
两种灯向分别有 1,144 和 748 个像素的绿通道低于 255。
空图集输出中性可见量。

## 冻结区域

头发可见量与颜色各包含 17,017 个位置。
完整接收区域包含 49,384 个位置。
每个通道的容差为一字节。

| 设备与范围 | 逐字节一致 | 超差位置 | 最大差值 |
| --- | ---: | ---: | ---: |
| NVIDIA 头发可见量 | 17,013 | 0 | 1 |
| NVIDIA 完整接收可见量 | 46,231 | 2,736 | 255 |
| NVIDIA 头发颜色 | 10,910 | 39 | 5 |
| Intel 头发可见量 | 16,645 | 236 | 55 |
| Intel 完整接收可见量 | 45,722 | 3,031 | 255 |
| Intel 头发颜色 | 11,393 | 592 | 97 |

NVIDIA 的 36 处颜色超差位于已确认的可见量影响区域。
同帧可见量已经满足门槛，材质消费者继续验收。

NVIDIA 完整接收区域的超差均伴随深度或法线差异。
原生事件 377 的写入范围包含 1,402 处超差。
原生事件 422 的非头发范围包含 878 处超差。
两处来源分别核对材质法线和接收深度。

Intel 的 236 处头发可见量超差中，21 处的深度与法线均精确。
图集与设备算术继续按实际输入核对。

本次图集输入有 19 个 NVIDIA 接收位置新超差。
Intel 有 28 个接收位置新超差，其中 9 个位于头发区域。
后续仍按完整冻结区域验收这些位置。

## 构建与回归

Release 和 Debug 各通过五项 CPU 检查。
两配置在两设备各通过四项 GPU 检查。
同设备的参考附件及三帧颜色摘要在两配置间一致。
891 份着色器中，本单元更新两份阴影顶点程序。

Release Player 在 131.125 秒内复采原始四帧。
四份 PNG 摘要均匹配冻结值。
普通视图的采集清单保留参考附件字段缺省状态。
同步验证及资源卸载检查通过。
