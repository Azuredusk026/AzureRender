## 纹理与材质

## 辐照场覆盖

实际资源为三层静态辐照场，幅度尺寸为 128×64×128。
固定机位、角色位置及可玩出生点均位于最细层内部。
七个检查位置的最细层权重均为一。
资源坐标及层中心由内容提供，查询使用世界位置。

实际 GPU 查询返回有限的非零辐照系数。
固定角色头部位置沿负 Z 法线的入射量约为 1.415、1.184、1.172。
可玩头部对应数值约为 0.897、0.751、0.754。
这些量尚未经过材质、环境权重、曝光及调色。

上述检查限定覆盖与实际采样结果。
移动视角下的反射、雾及最终间接照明继续验收。
覆盖和查询见[覆盖收据](evidence/2026-11-01/native-material-input-audit/gi-coverage.json)及[GPU 数值](evidence/2026-11-01/native-material-input-audit/gi-query.json)。
