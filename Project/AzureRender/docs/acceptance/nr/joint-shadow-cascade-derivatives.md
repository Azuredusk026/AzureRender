# 联合场景阴影梯度验收

本次验证在四个片元选择同一阴影级联时，只为当前和相邻级联计算梯度。四个片元选择不同级联时，计算全部级联的梯度。共构建并检查 128 个着色器变体。

NVIDIA 595.79 上的四张 2560 × 1440 图像与同驱动参考逐帧一致。性能配对使用相同的联合场景输入、1080p 目标、80 W 功率上限和最高风扇档。每轮预热 300 帧，统计 450 帧。采样期间最低风扇转速为 5900 RPM，三轮均无热降频，运行后核验了风扇和 Windows 电源设置的恢复。

| 轮次 | GPU 帧 P95（毫秒） | CPU 工作 P95（毫秒） | GPU 峰值温度（°C） |
| --- | ---: | ---: | ---: |
| 基准 A | 16.213 | 5.338 | 82 |
| 候选 | 18.141 | 5.555 | 83 |
| 基准 B | 16.329 | 6.129 | 81 |

采用条件要求 GPU 帧 P95 不超过 16.6 毫秒，并且收益超过两轮基准漂移。本次基准漂移为 0.117 毫秒，候选较基准均值增加 1.870 毫秒。候选不予采用，不进入正式采样。
