# 纹理像素无损容量

日期：2026-11-10。
状态：源基础层容量及还原一致性核查通过。

## 来源与结果

输入沿用[冻结通道范围](texture-channel-scope.md)。
468 份唯一解码图像共 2186104960 字节。
Zstandard 1.5.7 的一级压缩得到 528275524 字节。
载荷约为原字节的 24.17%。

全部载荷还原后与原 RGBA 字节完全一致。
压缩调用合计约 4.312 秒，还原约 2.632 秒。
完整解码与核查耗时约 41.407 秒。
上述均为本机单次 CPU 观察。

## 加载持有范围

当前渲染器逐个解码资源并建立上传作业。
初始化结束后，上传作业消费材质像素。
预解码入口使用共享只读资产，渲染器复制后应用绑定。
两条路径均需保持共享源及失败恢复的所有权。

源基础层、运行时处理后像素及完整 mip 分别计量。
压缩比例支持后续不可变载荷的容量假设。
正式内存、GPU 帧预算及完整质量持续待验。
本项只读输入，未启动原生画面或整帧计时。
