# 材质参考对象可见量验收

日期：2026-11-12。
范围为实际 Player 的材质对象可见量和头发颜色。
整体画质状态为 `failed-user-review`。

## 同帧输入

材质从当前帧读取对象身份及八位可见量。
像素坐标按参考附件的纵向行序换算。
不透明及遮罩材质在对象身份匹配时读取绿通道。
透明材质与身份不匹配的片元使用实际对象图集。

材质快照和主通道均等待同帧参考可见量。
普通视图沿用对象图集求值。
每个帧槽按选中视图发布对应的图像描述符。

## 阴影边界夹具

两个参考视图使用相同相机、几何和光线。
屏幕重建偏移改变 181 个阴影边界位置。
固定绑定和索引绑定均复现全部位置的显示响应。
每个通道与同帧可见量的显示换算相差至多一字节。

## 身份回退

两层几何分别在参考附件和主通道占据近层。
1,144 个位置的参考身份与主通道表面身份不同。
这些位置均与图集直接求值的显示结果逐字节一致。
空对象场景的 16,384 个位置均输出全可见。

## 冻结头发颜色

头发颜色与可见量分别核对 17,017 个冻结位置。
NVIDIA 的全部颜色位置满足逐通道一字节门槛。
其中 10,977 个位置的 RGB 逐字节一致。
头发颜色的最大差值为一字节。

同帧参考深度、法线、对象身份及可见量摘要保持匹配。
完整接收区域及其他材质继续按原门槛验收。

## Intel 颜色来源

Intel 的冻结颜色有 580 处超差，峰差为 97 字节。
原生 Intel 重放的冻结颜色也有 580 处超差。
两份超差集合共享 571 个位置。

按同设备的原生颜色核对时，13,887 个位置逐字节一致。
只有 7 个位置超过一字节，坐标见结果清单。
冻结门槛仍使用原始参考颜色。

## 构建与回归

Release 和 Debug 各通过五项 CPU 检查。
两配置在两设备各通过四项 GPU 检查。
同设备的参考附件与三帧颜色摘要在两配置间一致。
四个绑定夹具的全部结果一致。

着色器总数为 891。
320 份对象材质片元程序在两配置间逐项匹配。
两类参考图像均使用独立采样图像描述符。

Release Player 复采原始四帧，耗时 288.203 秒。
四份 PNG 摘要均匹配冻结值。
普通视图的采集清单保留参考附件字段缺省状态。
同步验证及资源卸载检查通过。
