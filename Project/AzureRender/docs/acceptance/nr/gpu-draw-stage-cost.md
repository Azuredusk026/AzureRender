本阶段入口为 `0ac1a44`。
读取既有 1280×720 捕获的流水线统计。
十二类计数覆盖 3424 个事件。
其中 1009 次绘制与既有阴影消融成本对应。

捕获摘要为
`5cbfc0ecf9fa24a7a8d8949ed54c3fc3691b7a1a58075d68f63f257b34ca6942`。
本批读取调用次数，引用已有合格计时作为成本背景。
本次未执行新的 GPU 帧计时。

计数语义依据 [Vulkan 查询规范](https://docs.vulkan.org/spec/latest/chapters/queries.html)。
片元调用及深度通过样本分别计量。
辅助调用的计入方式具有设备相关范围。
调用次数与当前生产程序的帧预算分别验收。

## 主通道普通材质

普通材质的早期深度路径共有 508 次绘制。
输入三角形为 252966 个，顶点调用为 409716 次。
片元调用与深度通过样本均为 891457 次。
该组在已有合格记录中的成本约为 5.0581 毫秒。

385 次绘制的片元调用和通过样本均为零。
这组调用仍实际执行顶点阶段。
其已有成本合计约为 1.7816 毫秒。
对应阴影消融的差值约为 0.3529 毫秒。

阴影消融差值包含片元以外的工作变化。
该差值不能直接解释为片元过滤的独占成本。
读取颜色前后的结果相同，也不能代表片元调用为零。
事件 21311 实际具有 112542 次片元调用。

## 保守剔除依据

508 次普通绘制均核对顶点阶段的实际输出。
多实例绘制保留显式资格筛选。
裁剪空间包围范围覆盖每项实际引用顶点。
跨越相机平面的范围保持可见。

遮挡输入为事件 20836 的主颜色绘制前深度。
图像采用 D32 浮点格式，视口为 1280×720。
屏幕矩形每侧扩展一个像素，深度余量为 0.00001。
逐像素最大深度用于保守比较。

265 次绘制通过该遮挡条件。
这些调用在既有记录中的成本合计约为 1.3658 毫秒。
另有 46 次绘制完全位于同一裁剪平面外。
后者的既有成本约为 0.0445 毫秒。

合计成本为 1.4104 毫秒，占目标热点约 27.88%。
这些候选与非零片元调用的冲突数为零。
该结果支持保守深度剔除机制的有界实现。
生产包围盒的松紧及深度层级成本仍需核对。
