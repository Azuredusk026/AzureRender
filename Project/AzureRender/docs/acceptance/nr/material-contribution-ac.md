# 交流电材质成本分项

## 来源与方法

本批复用 1280×720 的既有合法设备捕获。
原始程序及四组控制共五十五份，全部按摘要复现。
匹配范围为十一份片元程序的一千零九次绘制。
生产源码及当前两配置构建保持冻结。

各控制关闭一个照明分项，画面会发生变化。
差值包括编译器消除相关依赖的影响。
这些值用于筛选方向，兼容优化另行验收。
当前 1080p 整帧预算独立保留。

每角色先连续重放八次，再读取有界时间戳。
连续三次总时间和匹配时间的差异均须在 3% 内。
每个控制的前后参考漂移至多为 5%。
每角色至多十六次采样，失败后停止该批。

其有效工作、接收资格和逐灯计算进入后续审查。

## 采样开销与环境

首轮在每次时间戳之间执行驱动查询及日志写入。
阴影控制十六次采样未满足稳定性门禁。
该轮 GPU 频率在 765 至 2550 MHz 间变化。
失败记录完整保留，结果排除出成本结论。

后续采用连续预热和两秒间隔的异步环境记录。
该组合通过门禁，单独因素的因果关系继续保留边界。
三十七次环境观察均报告交流供电，监控错误为空。
硬件及软件热降频标志均未触发。

驱动功率限制在约 75.9 至 88.1W 间变化。
该条件只用于本批稳定的局部描述。
原定 80W、正式长采样和长跑继续待验收。
本单元没有启动新的原生进程或保存原生截图。
