# GPU 硬件性能归因

## 来源与采样

设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
RenderDoc 1.46 使用官方 NVIDIA 性能库。
管理员会话取得三万四千二百四十条厂商样本。
通用计时取得三千四百二十四条样本。

受检捕获来源为 `0694263`，帧号为三百二十。
捕获摘要与[事件分解](current-gpu-events.md)的记录一致。
当前 CPU 实现来源为 `390e1e6`。
GPU 捕获结果与当前 CPU 实现分别持有来源。

分析会话使用 Windows 管理员令牌。
驱动的全局性能计数访问设置保持原有配置。
普通会话的失败来源见[权限记录](evidence/2026-11-06/gpu-counter-permission/results.json)。

## 重点绘制

下表使用同一捕获的实际事件。
耗时为通用 GPU 时间，DRAM 表示设备存储访问字节。
指令值来自 `smsp__inst_executed.sum`。
这些数值属于事件级重放诊断。

| 事件 | 用途 | 耗时 | 片元调用 | 通过样本 | DRAM 字节 | 指令计数 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 23277 | 主颜色普通材质 | 0.532 毫秒 | 185,347 | 52 | 35,072 | 70,967,174 |
| 16036 | 快照普通材质 | 0.829 毫秒 | 371,593 | 93,542 | 1,362,816 | 143,085,463 |
| 26298 | 主颜色透明自发光 | 1.294 毫秒 | 459,796 | 459,796 | 9,583,232 | 102,051,463 |

事件 26298 的实际类别为自发光，透明模式为混合。
相同程序身份可用于不同材质及管线专用常量。

事件 23277 已具备深度预填充，节点透明度为一。
其材质及管线身份已由实际推送和专用常量核对。
大量片元执行着色，但仅有五十二个样本通过。
该事件的优先措施为提前消除隐藏片元的执行。

该事件的 L1 命中率为百分之 95.18。
其低 DRAM 访问与大量指令支持隐藏着色成本的判断。
该判断适用于这些重点绘制。
完整场景的峰值带宽及算术饱和度继续分别测量。

## 反射与依赖等待

反射追踪事件为 `20664`，耗时约 0.995 毫秒。
DRAM 字节为 35,652,352，L1 命中率为百分之 52.99。
长依赖等待指标为百分之 61.49。
数学管线阻塞指标为百分之 3.95。

该模式支持继续检查依赖读取及访问局部性。
等待指标按活动执行束的所属分母解释。
具体停顿原因需结合产生数据的指令判断。
指标语义见 [NVIDIA Shader Profiler](https://docs.nvidia.com/nsight-graphics/UserGuide/shader-profiler.html)。

## 结论与边界

CPU 的动态曲线重复校验已得到[独立优化](animation-curve-validation.md)。
GPU 的重点成本为主颜色与快照的场景着色。
硬件样本支持优先处理无效片元执行。
反射追踪的依赖读取按后续单元定位。

当前证据尚未建立整机显存总线饱和结论。
主机传输也需持续时序及链路指标确认。
本轮没有峰值 SM 吞吐或总线利用率样本。
容量、内存忙碌比例及停顿比例分别解释。

一百六十八条百分比样本超出逻辑范围。
原始数值完整保留，超范围值排除出数值结论。
多次重放及异步活动可能影响计数比例。
解释依据见 [NVIDIA 指标精度说明](https://docs.nvidia.com/nsight-compute/ProfilingGuide/index.html#range-and-precision)。

两类时间按原单位记录，分别解释。
