# 普通材质零贡献光源

日期：2026-10-26。范围为 MS5 的主场景着色成本。
角色多层高光、材质帧及完整照明沿用各自契约。
正式场景的 60 帧预算继续验收。

## 着色规则

普通表面先计算公共光源采样及影响范围。
采样贡献严格等于零时，跳过后续 BRDF 计算。
判断使用精确零值，正贡献继续消费原有公式。
角色分支保留主灯选择、投影高光及材质帧状态。

该规则复用现有光源、材质及影响盒字段。
材质布局、纹理槽、管线数量和资源所有权保持现行契约。
主通道与颜色副本编译相同的普通表面规则。
固定描述符及索引描述符分别验证。

## 公共验证

Debug 与 Release 各完成三十三组局部灯检查。
原有正控制保持可见光照阈值。
新增影响盒负控制要求中心输出严格为零。
独立接收遮罩及固定描述符输出须与其一致。

影响盒正控制与原有普通材质输出逐像素一致。
该检查同时覆盖非零输入的现有消费路径。
原有角色、线形灯、包裹下限及完整文档分别回归。
两种构建的最大线性误差均约为 `0.00098044`。

四样点材质运动、场景折射及聚簇灯光分别回归。
折射测试按实际构建声明验证层状态。
原有图像阈值和资源释放门禁保持有效。

## 真实场景

主场景使用十三份完整文档及九动画角色。
独立资源根中的候选图像与冻结主场景逐像素一致。
最终两种构建的二十四个片元变体与候选逐字节一致。
真实主场景的 Debug 四样点近景与冻结图像逐像素一致。
该次捕获启用验证层，并通过资源释放检查。
原生完整画质及动态高频门禁继续执行。

设备为 RTX 4060 Laptop GPU，分辨率为 1920×1080。
每组运行九十六帧，预热十六帧后统计八十帧。
帧率限制和垂直同步均关闭。

模式一的 GPU P95 为 94.19 毫秒。
四样点的 GPU P95 为 377.96 毫秒。
两种模式均继续按 60 帧目标优化。
对应峰值分配约为 3.15 和 3.69 GB。

场景副本、主通道及阴影的成本继续分离核验。
