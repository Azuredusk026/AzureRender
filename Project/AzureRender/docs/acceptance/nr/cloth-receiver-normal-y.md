# 服饰接收法线绿色方向

服饰一的参考夹具按当前 UV 方向编码切线空间法线。
绿色通道在十二个 BC5 层级逐块反向。
压缩块往返逐字节一致，红色压缩块保持原值。
各级解码结果的绿色通道与标准方向转换最多相差一字节。
夹具的纹理路径、几何、采样参数及 Player 使用固定指纹。

## 接收可见量

事件 377 的最后法线覆盖 16,629 个位置。
完整接收区域包含 49,384 个位置。
可见量及颜色均采用每通道一字节容差。

| 设备 | 服饰法线区域超差 | 服饰法线区域新增超差 | 完整接收超差 | 完整头发可见量超差 | 完整头发颜色超差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVIDIA | 296 | 28 | 658 | 0 | 0 |
| Intel | 346 | 31 | 973 | 208 | 575 |

参考深度、对象身份及冻结头发的颜色与可见量逐字节匹配固定对照。
其余原生法线写入区域的可见量逐字节匹配固定对照。
同一设备的 Release 与 Debug 对应附件和三帧颜色逐字节一致。
完整接收及联合画质状态为 `failed-user-review`。

## 剩余输入误差

两块设备的服饰法线误差中位数均为一个编码单位。
NVIDIA 在服饰区域有 11,587 个法线位置处于一个编码单位内，Intel 有 10,590 个。
服饰区域仍超差的可见量位置中，NVIDIA 有 213 处同时存在超过一个编码单位的法线误差，Intel 有 257 处。
这些位置继续按采样后法线重建、深度及图集输入核对。
