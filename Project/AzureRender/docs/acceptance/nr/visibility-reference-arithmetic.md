# 屏幕可见量参考算术

日期：2026-11-10。
状态：公共实现及主配置专项核对通过。

## 配置与范围

`ScreenObjectVisibilityNumerics` 定义构造时的算术配置。
`Device` 使用设备算术，残差数组为空。
`ProfileV1` 使用精确归一化及规范化倒数配置。
矩阵、法线、图集与对象身份保持公共输入契约。

参考配置必须包含 524288 个 32 位无符号整数。
每字按低位优先保存十六个两位残差编码。
编码零、一、二表示最近偶数舍入后的位值偏移。
它们的偏移分别为负一、零和正一。

未知模式、错误长度及保留编码三在分配前拒绝。
残差索引只由浮点输入的二十三位尾数确定。
参考模式的视口归一化采用精确整数舍入。
固定八位子纹素网格决定四点过滤足迹。

一般倒数输入独立处理符号与指数。
指数域一至 252 使用配置并精确缩放。
其他指数域采用设备除法。
非有限及过小齐次分母按既有像素规则处理。

## 所有权与容量

实例在构造期间复制配置到自有缓冲。
调用方可在构造返回后释放源数组。
缓冲在实例生命周期内保持不可变。
所有槽位共享缓冲，绑定五持有存储描述符。

设备模式的占位缓冲为四字节。
参考模式的配置缓冲为 2097152 字节。
原逐槽图像及参数预算另行累计。
全部逻辑载荷共同受 256 MiB 上限约束。

RHI 查询片元存储缓冲数量及单缓冲容量。
Vulkan 查询实际设备限制。
不足时在分配前报告明确失败。
调用方仍须等待在途消费者结束后销毁实例。
