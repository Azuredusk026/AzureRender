## 存储关系

原生浮点值按五位指数及六、六、五位尾数转换。
向零转换可重建全部 31 个实际存储颜色。
Vulkan 浮点值按半精度向零转换，
同样重建全部 31 个实际存储颜色。

半精度最近偶数转换只重建其中五个位置。
该结论限定于本次捕获及实际写入路径。
格式转换和着色算术分别持有各自规则。
存储值持续由实际 GPU 附件确认。

## 浮点差异

Vulkan 浮点值按原生格式向零转换后，
六个位置的三通道与原生存储值完全相同。
其余 25 个位置已具有转换前的颜色差异。
实际最大分量差为 `0.07155084609985352`。

材质参数相同的 25 个位置也包含该峰值。
其中多数较大差异主要沿色度方向分布。
