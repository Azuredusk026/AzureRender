# 聚簇网格分辨率范围

日期：2026-11-10。
本单元核对十六盏灯的冻结静态夹具。
生产网格为 `16×9×24`。
两个控制分别将三个轴加密二倍和四倍。

## 范围与结果

统计按空间单元等权平均。
该口径描述灯列表规模，片元实际访问量另行核定。
原始夹具的灯类型、接收范围及相机保持冻结。
专用响应使用夹具中明确登记的状态。

加密会收紧部分深度区间的灯列表。
普通表面范围的平均访问削减如下表。
当前范围没有形成整场景优化的准入依据。
后续依据须覆盖实际片元分布及对应成本。

| 网格 | 平均列表长度 | 削减比例 | 双槽索引最坏容量 |
| --- | ---: | ---: | ---: |
| `16×9×24` | 2.02228 | 基准 | 13.5 MiB |
| `32×18×48` | 1.94358 | 约 3.89% | 108 MiB |
| `64×36×96` | 1.91434 | 约 5.34% | 864 MiB |

## 容量与边界

二倍加密具有 27648 个空间单元。
四倍加密具有 221184 个空间单元。
索引最坏容量按四类范围及 128 盏灯计算。
该上界与夹具的实际打包引用量分别记录。

本单元没有修改生产代码或构建产物。
原生运行及 GPU 计时进程数均为零。
CPU 八毫秒、GPU 16.6 毫秒及画质门槛有效。
整体状态保持 `failed-user-review`。
