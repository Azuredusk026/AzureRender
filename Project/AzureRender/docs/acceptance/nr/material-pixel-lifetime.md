# 材质像素生命周期验收

日期：2026-10-22。
范围：CPU 像素所有权与加载阶段诊断。
原生大场景的时间、内存和外观另行实测。

## 所有权

缓存提供常量引用和右值两个入口。
右值请求成功后，调用者的像素分配为空。
未命中的唯一输入由缓存直接接管。
命中的重复输入在完整等同性判断后释放。

输入校验和 GPU 对象创建保持既有规则。
失败请求保留调用者的原始像素。
部分创建的 GPU 对象由缓存释放。
调用者可使用相同输入恢复请求。

角色渲染器只移交自己拥有的像素。
共享预解码资产继续由原调用者持有。
选择、蒙皮与动画使用的几何和参数保持可用。
九个材质槽继续采用完整像素和采样参数判等。

## 诊断与限制

加载清单区分八个宿主阶段。
材质缓存分别记录哈希、匹配、层级和上传时间。
每十六份附加资源记录累计进度。
耗时超过一秒的任务记录资源、材质和槽位。

32 MiB 独立哈希探针得到相同的完整哈希。
本机迭代耗时 34.98 毫秒，指针耗时 31.52 毫秒。
该结果用于核对算法和局部成本。
真实场景的长期停顿仍需读取生产阶段计时。

Release 的 NullRhi 目标有既有 D9025 提示。
它来自测试目标的断言编译选项覆盖。
两种配置均完成构建并返回零退出码。
