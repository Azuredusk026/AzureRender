## 操作量与收益边界

深度提前退出限于非普通主颜色裁剪材质。
它要求节点透明度为一，并核对有限正深度。
完整四像素组均被保守判为遮挡时才退出。
普通材质和快照阶段保持既有着色路径。

将全部合格固定主颜色调用视为可消除工作，得到宽松上界 132,190 次。
该数占合格主颜色调用的 12.91%。
它占合格主颜色与快照调用总数的 6.51%。
这个上界还包含最终通过测试的样本。

上述比例只约束深度提前退出的调用数量。
候选还涉及分支折叠与接收状态存储。
这些机制的指令、寄存器及耗时收益需独立证明。
本轮按当前证据保存收益范围。

当前源码对幸存调用保留四级阴影导数。
每级有四处导数调用，产生六个标量结果。
单次调用按源码至多对应 24 个此类结果。
结合历史调用量，源码结果规模上界为 48,702,000。

这个上界用于枚举重复计算的规模。
编译器消除、实际分支及硬件指令次数需单独测量。

两个通道的重复计算仍由各自片元执行。
本候选可证明的跨通道导数消除量为零。
片元身份重合与可复用结果需要分别核对。
表面辐亮度缓存采用其既有性能与内存结论。

当前原生时间只给出宽松的整段成本上界。
主颜色整段为 8.970 毫秒，两阶段为 14.684 毫秒。
候选的实际收益还受材质域、执行路径及新增成本约束。
这两项时间用于规模边界，预期净收益仍待证明。

## 程序目录与回退

当前活动程序为 897 份，目录上限为 1,024 份。
完整候选新增 128 份，合计 1,025 份。
该完整族触及容量淘汰条件。

历史合格描述符实际消费十个规范程序名。
按这十个名字收敛时，目录枚举为 907 份。
这一范围限定于已记录的材质和资源策略。
实际构建与跨场景覆盖需按该范围另行验证。

合格材质为普通及具有固定专用常量的类别。
设备须具备既有 NVIDIA 四像素组资格。
视图须满足单采样、绑定数组及同帧深度条件。
比较方式限定为 `LESS`、`LESS_OR_EQUAL` 与 `EQUAL`。

混合材质、动态类别及资格失配采用参考管线。
参考 UV、参考相机及实验缓存按现有契约回退。
隔离、效果、反射来源及视图尺寸逐帧判断。
缺失可选程序和准备失败由渲染器记录并回退。

完整契约见[材质视图组合](../../runtime/computed-material-view.md)。
十个程序的名单及逐事件分类随结果归档。

## 淘汰依据与重试条件

完整族超过程序容量上限。
十程序子集可满足静态目录枚举条件。
该子集缺少当前版本的逐材质成本和预期净收益依据。
因此本轮结束关联实施与性能采样安排。

历史同宿主约 3.139 毫秒收益保留为方向证据。
它采用所属来源、材质与测量范围解释。
阴影梯度和重复采样探针沿用既有淘汰记录。
当前生产配置及原有性能门槛保持有效。

重试需要与当前产物、材质域和输入匹配的成本证据。
热点占比至少四分之一，预期工作量减幅至少 20%。
预期整帧节省 GPU 3 毫秒或 CPU 2 毫秒也可准入。
目录和回退契约须在同一候选批次中成立。

准入后集中执行关联实现、兼容、画面及同源成对计时。
显著收益成立后按交付范围安排 1,800 帧采样。

## 验证归档
