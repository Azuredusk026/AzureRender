# 规范化倒数压缩配置

日期：2026-11-10。
状态：双设备完整域逐位核对通过。

## 数据与运算

配置定义规范化区间 `[1,2)` 的倒数位值。
索引为二十三位二进制浮点尾数。
每项用两位保存相对最近偶数舍入值的残差。
编码零、一、二分别表示偏移负一、零、正一。

完整配置共有 8388608 项，占 2097152 字节。
32 位无符号整数按低位优先存放十六项。
整数长除法计算正确舍入的规范化倒数。
解码后的残差在位表示上施加偏移。

此规则只定义规范化输入的映射。
一般浮点输入另需符号、指数及非有限边界契约。
配置来源为[已冻结的 NVIDIA 完整计算域](native-reciprocal-domain.md)。
它的实际原生绘制覆盖范围仍为 757617 项。
