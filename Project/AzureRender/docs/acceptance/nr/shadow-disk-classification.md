# 阴影圆盘权重分类验收

## 结果与范围

保守几何分类完成数值及局部效率检查。
一百万组输入的四维权重保持逐位一致。
完整圆盘累计权重也保持逐位一致。
分类分支未达到局部减少 20% 的门槛。

候选代码、独立程序及日志保存于精简证据。
生产采用 `e2c50c9` 的受检入口。
原生截图与整帧计时进程数均为零。
整体画质及正式帧预算继续待通过。

## 数值与局部成本

有效半径为一至十六个纹素。
平方距离判断保留 0.004 的安全间隔。
边界与范围外半径使用原有权重表达式。
检查覆盖随机位置、饱和边界及相邻浮点值。

1048576 组输入中，零权重分类为 259982 组。
一权重分类为 174475 组，其余 614119 组使用原公式。
权重失配为零，同步验证及资源释放检查通过。
这些分类计数属于夹具输入分布。

计时半径覆盖六至八个纹素。
每个区间预热 2048 次，再统计 128 次。
比较按参考、候选、候选、参考顺序执行。
单个进程同时执行数值与累计结果核对。

参考均值约为 0.029671 毫秒。
候选均值约为 0.056686 毫秒，约为参考的 1.91 倍。
前后参考漂移约为 10.86%，超过 5% 的界限。
该数据用于否决本候选，不能解释整帧变化。

已有[圆盘权重局部成本](shadow-disk-kernel.md)保存另一种空覆盖方案。
两项记录均未形成省略开方的实际收益依据。
后续同类实现须先取得新的实际程序成本依据。
CPU 八毫秒、GPU 16.6 毫秒及 RGB 零差异要求有效。
