# 原生接收坐标的实际 GPU 核对

日期：2026-11-09。
状态：NVIDIA 区域诊断通过，Intel 差异继续定位。

## 证据资格

输入引用原生帧 10401 的既有捕获。
诊断修改事件 699 的像素着色器读取出口。
中间值逐字节写入附件的红通道。
原对象可见量持续通过绿通道与原件核对。

区域包含四万九千三百八十四个对象像素。
接收投影、世界位置、法线及偏移分别读取。
深度采样与齐次位置另有独立读取。
全部六十八个中间值版本的绿通道均保持零差。

另一个出口控制版本也保持绿通道零差。
各字节按同一像素位置组合为单精度数值。
诊断版本的最终可见量一致，构成中间值资格。
软件逐指令值仍按其实际附件核对结果解释。

## 数值定位

原生深度采样与原始 R32 值全部逐位一致。
重建控制的齐次坐标有一千七百五十五处差异。
原四十处可见量超差均具有世界位置差异。
世界位置的最大分量差为 0.00006103515625 米。

投影保留显式融合乘加，并约束齐次变量精度。
`precise` 约束后，齐次位置全部逐位匹配。
显式倒数乘法保持原四十处超差。
完全拆开乘加产生二百四十六处超差。

有效控制限定的是运算结合与中间舍入边界。
该结果属于跨接口兼容诊断。
当前证据未说明驱动机器指令的具体形式。
相关合同依据为 [GLSL 精度修饰符](https://docs.vulkan.org/glsl/latest/chapters/variables.html)。
