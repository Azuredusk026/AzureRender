# 角色局部反射控制

日期：2026-10-22。范围属于 NR5 与 NR6。
本项验证角色画像对局部反射探针的控制。
原生场景的反射能量与像素等价继续专项验收。

## 消费规则

场景中的角色表面使用材质画像版本 2。
皮肤、脸、头发、衣料、金属和眼睛属于此范围。
探针贡献消费镜面强度 `styleParameters.z`。
普通 PBR 表面保留公共探针响应。

角色探针贡献为下列各项的乘积：

```text
菲涅耳响应 × 探针采样 × 探针强度
× 材质镜面强度 × 角色表面权重
```

| 角色表面 | 表面权重 |
| --- | ---: |
| 皮肤 | 0.05 |
| 脸 | 0.03 |
| 头发 | 0.08 |
| 衣料、金属、眼睛 | 1 |

权重沿用公共角色画像的镜面策略。
全局环境反射与局部探针共享该策略。
版本 1 的画像保留其消费范围。
`--qa-effect specular --qa-effect-state disabled`
使局部探针的镜面贡献归零。

## 验证夹具

测试入口为 `tools/test_character_probe_gpu.py`。
CTest 名称为 `AzureEngine.CharacterProbeGpu`。
夹具使用公开平面、标准 glTF 和常量 HDR 探针。
探针线性 RGB 为 8、4、2，强度为 1。

每个配置采集 26 张图像。
测试分别覆盖索引描述符与固定描述符。
独立 PBR 正控制通过探针开关确认采样有效。
皮肤覆盖全强度、半强度、零强度和探针关闭。

脸、头发和衣料分别验证表面权重。
版本 1 的脸画像验证兼容范围。
角色与普通 PBR 均验证镜面隔离开关。
Beauty 图像同时核对角色探针的最终合成。

角色低能量响应的线性误差预算为 0.0005。
其余数值夹具的线性误差预算为 0.004。
零强度和关闭状态要求中心区域严格为黑色。
两种描述符路径的全图差值上限为 1 字节。

## 验证结果

Debug 和 Release 均保存 26 次通过结果。
Debug 另通过正式 CTest 入口。
角色最大线性误差为 0.000181。
普通 PBR 正控制的最大响应为 0.637597。

两种描述符路径的全图最大差值为零。
每次卸载后的缓冲与图像数量均为零。
Debug 启用 Vulkan 验证层，日志无错误或警告。
Release 按发布配置关闭验证层。

受影响的四项 Debug GPU 回归全部通过。
范围包含无光照表面、场景角色及投影发丝。
结构化证据见[验证收据](evidence/2026-10-22/character-probe-controls.json)。

实际莱万汀与中庭完成一次 Release 联合采样。
画面为 1920×1080，使用场景相机和灯光。
已安装角色与原生发丝响应候选的摘要相同。
渲染程序、着色器、资产摘要与单帧均已保存。

完整场景的 Debug 装载触及 240 秒预算。
该记录保留为初始化超时，尚无完整场景帧。
公共夹具的 Debug 验证层结果仍独立有效。
