# GPU 通道成本归因

## 结果与范围

通道计时通过两种配置的四项检查。
一次原生采集执行三十二帧，初始八帧单独排除。
其余二十四帧具有十九个可用通道结果。
同步日志无错误，卸载分配残留为零。

## 实际成本

场景尺寸为 1920×1080，采用默认渲染路径。
本次采集显式启用通道计时，未保存截图。
两端完成时间包含资源屏障及管线等待影响。
该数据用于热点归因，正式净收益另行比较。

| 通道 | 均值，毫秒 |
| --- | ---: |
| 最终绘制 | 8.982741 |
| 不透明快照 | 5.630677 |
| 反射计算 | 1.662409 |
| 级联阴影 | 1.446869 |
| 蒙皮 | 0.598936 |
| 反射运动数据 | 0.559147 |
| 阴影分块边界 | 0.475364 |
| 主深度 | 0.320128 |

蒙皮输出还被快照、阴影及最终绘制共同读取。
接续检查其数据宽度、写入量及跨通道复用。
反射运动数据的共享需单独核对数值契约。
候选按实际成本上限及精度要求进入实施。
