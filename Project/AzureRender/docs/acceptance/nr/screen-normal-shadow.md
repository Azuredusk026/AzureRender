# 屏幕法线的阴影偏置

## 范围

本项归属于 Q1 的发片阴影恢复。
屏幕表面法线同时参与照明和对象阴影的表面偏置。
偏置方式遵循对象阴影组件的配置。
径向照明材质采用所属几何法线进行该偏置。

## 独立对照

公共夹具包含接收平面、遮挡物和法线生产平面。
法线贴图与屏幕快照提供等价的物理表面法线。
环境漫反射采集保留材质的真实可见度消费。
两条输入路径的每通道颜色差预算为一个色阶。

几何偏置控制用于区分法线选择。
径向照明控制验证虚拟照明法线的独立用途。
固定描述符和完整材质文档分别核对。
普通、多重采样及超采样覆盖实际渲染尺寸。

## 失败证据

失败控制中，屏幕法线与几何偏置控制逐像素一致。
它与等价法线贴图的最大差异为 96 个色阶。
超过一个色阶的差异涉及 243 个像素。
几何与物理法线控制有 218 个像素相差超过两个色阶。

## 原生角色

原生轮廓使用恢复的表面法线及独立可见度输入。
固定头部的几何、纹理和深度分别持有来源记录。
投影头发主体、前侧混合及后侧混合各自核验。
完整角色和联合画质按既定门槛继续验收。

## 验证结果

Debug 与 Release 各覆盖三种采样配置。
六类输入共完成 36 次 GPU 采集。
屏幕输入、固定描述符及完整文档均与物理法线控制逐像素一致。
最大实测颜色差为零，预算为一个色阶。

常规与径向输入的六帧控制逐像素兼容。
既有对象阴影各通过五项双帧检查。
颜色组合各通过四项检查。
两种构建的 CTest 入口均实际执行通过。

固定头部的 2,832 个不透明轮廓像素平均误差为 1.09 个色阶。
主体颜色保持其既定对照精度。
独立镜头的背景输入仍有差异。
透明合成及完整画质按匹配输入继续验收。

程序指纹、实际采样配置及范围见[结果记录](evidence/2026-11-05/screen-normal-shadow/results.json)。

独立脚本通过 `--quality` 选择采样配置。
