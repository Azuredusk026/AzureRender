非法资源分解和整数溢出均被拒绝。

录制夹具检查真实布局、池类型和描述符写入。
各集合拥有一项独立图像及一项独立采样器。
组合描述符数量按实际材质路径分配。
颜色附件的阶段总资源检查继续待验。
