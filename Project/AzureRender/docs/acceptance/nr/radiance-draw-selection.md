# 逐绘制照明资格验收

## 结果与范围

公共选择器支持有界的逐绘制谓词范围。
场景接入独立资格、稀疏见证及退役统计。
独立视图的两设备输出与释放检查通过。
原生严格像素兼容尚未通过，实验入口默认关闭。

性能计时及正式长采样均未启动。
CPU 八毫秒及 GPU 16.6 毫秒标准有效。
整体画质保持 `failed-user-review`。
正式采样、长跑与人工项继续按原条件验收。

## 选择与统计

全局字控制深度异常及编号异常的整体回退。
局部字记录对应绘制的真实片元失配。
正常见证点间隔为三十二像素。
缺少见证或存在失配的绘制采用完整着色。

公共范围具有起点、步长、拒绝位及必需位。
范围和别名核对继续限定于所属帧槽。
两个区域保持几何字段及原输入顺序。
原始共享选择保持默认许可关闭。

每槽最多保存 65536 个标志及六字头部。
头部归并两类绘制数量及网格见证量。
统计只累计已经完成并回收的帧槽。
网格覆盖表示资格阶段的规模，帧收益另行测量。

## 检查与修复

两种配置、两块设备核对混合命令及全局回退。
拒绝掩码、必需位、步长及所有权均有检查。
两设备完整视图各包含三十个状态及十五组比较。
最终阶段掩码修正另用每设备两状态核验。

首个视图流程在一百八十秒内持续编译管线。
十次已完成的管线准备累计约一百六十六秒。
保留超时日志后，仅恢复未完成的视图流程。
恢复流程的同步错误及分配残留均为零。

投影程序的两个字段曾共用第 132 字节。
八个程序的离线校验复现对应布局错误。
绘制编号使用第 136 字节，并声明两着色阶段。
两种配置的七十个新增或修改程序通过离线校验。

GLSL 构建逐模块执行 `spirv-val`。
两种实验配置各生成并校验 742 份 GLSL 程序。
目录另含一份既有 HLSL 计算程序。

默认配置保留 674 份程序，其中 673 份字节一致。
公共选择程序对应本单元的范围接口实现。

## 原生图像记录

首组四帧保持一致，但日志存在模块布局错误。
布局修正后的第二组前三帧保持一致。
第四帧有十四个像素相差一个色阶。
该组日志同时记录推送常量的阶段掩码错误。

两组各回收两个具有轻量绘制的有效帧槽。
累计轻量绘制为七十四次，完整绘制为十四次。
轻量与完整网格见证分别为 5759 和 974。
该数据来自原生采集，不能作为帧收益结论。

最终阶段掩码修正通过针对性独立视图核验。
原生图像记录对应各自冻结来源。
当前提交的原生精度继续待验收。
本单元保持原有零差异标准。
