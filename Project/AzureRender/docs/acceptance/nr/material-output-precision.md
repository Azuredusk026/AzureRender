# 公共材质输出精度验收

日期：2026-11-10。
状态：公共契约与所属回归通过，完整生产画质待验。

## 公共契约

版本二材质通过 `r11g11b10-output` 特性选择输出精度。
合法组合为受光的不透明或遮罩表面。
解释、直接打包及完整文档保存重开共用校验。
默认特性位为零，材质表保持二十二行、352 字节。

公共 CPU 及 GLSL 助手处理 RGB 的向零量化。
R、G 使用六位尾数，B 使用五位尾数。
负数、非规格化值、溢出及非有限值具有明确规则。
Alpha 按位保留，最终片元出口调用同一助手。

## 数值与配置

两设备、两配置各核对 102400 组输入。
每组执行启用和默认路径，共 819200 次分量比较。
四批总计 3276800 次比较均逐位一致。
CPU 助手同时对照独立的二次幂量化参考。

输入覆盖全部 65536 个半精度位模式。
另有 4096 组单精度边界及 32768 组随机位模式。
符号、非有限值及 Alpha 均使用原始位值核对。
重放及执行日志均无 Vulkan 验证错误。

新接口的缺失检查先于实现执行并按预期失败。
初次配置检查发现无光照组合的错误归属问题。
特性入口及最终解释共用校验后，两配置契约通过。
失败记录和修正后的完整检查结果分别保存。

## 实际材质

PBR 自发光与投影头发分别使用公共特性。
两配置、双设备共十六张实际图像全部通过。
原线性误差预算为 0.008，实测峰差约为 0.003641921。
自发光正控制的蓝通道至少变化二字节。

Release 使用索引描述符，Debug 使用固定描述符。
Debug 验证层启用，四组执行均无验证错误。
每张图的运行卸载记录均为零图像、零缓冲。
默认原始四帧的 PNG 摘要与冻结参考全部一致。
RGB 逐像素比较的差异为零。
实际四帧进程耗时 230.859 秒，资源卸载归零。
