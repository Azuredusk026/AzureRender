# 显式材质坐标系验收

日期：2026-10-23。范围为 NR6-C16 的实例帧。
投影头发通过具名节点与正交基底声明坐标系。
面部和头发共用实例帧的冲突检查。
材质覆盖后重新核对坐标系所有权。

## 输入与运行

画像字段为 `hair.projectedRamp.frame`。
字段版本为 1，包含 `node` 和九分量 `basis`。
缺失节点、重名节点和非正交基底均被拒绝。
同一资源的显式面部帧与头发帧须一致。

顶点程序通过派生功能位消费显式实例帧。
未声明显式帧的画像使用对象帧。
每个实例由当前节点姿态形成对应矩阵。
字段不占用材质参数表，六行布局保持版本 1。

## 检查结果

新增用例首先因未知 `frame` 字段失败。
角色画像与材质文档 CPU 检查通过。
独立节点、缺失节点、重名和冲突帧均有用例。
已有眼睛及传统投影画像按原条件回归。

Release 的十五次 GPU 捕获通过。
其中包含单位帧、独立节点旋转及固定描述符对照。
每个像素使用射线与 CPU 公式形成预期值。
最大线性误差预算为 `0.008`，两种描述符结果一致。

真实角色使用单独候选，几何和动画数据保持一致。
候选将头发帧绑定到已有 SDF 头节点及基底。
两次 1920×1080 完整画面通过运行及释放检查。
变化为 41953 像素，最大字节差为 167。

变化证明头发帧实际消费，完整原生等价继续按 C17 验收。
该候选保存在项目内容中，主线引用按联合外观结果晋升。
原生矩阵、动态姿态及独立条纹仍按各专项验证。
NR6 总体验收保持原有条件。
