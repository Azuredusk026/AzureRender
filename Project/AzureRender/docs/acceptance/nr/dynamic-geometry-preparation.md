# 动态几何准备优化

## 数据与执行

本批来源为 `adfdc00`。
透明拓扑保存实际使用的顶点并集与三角形局部索引。
源索引存储由资产持有，拓扑在所属资产卸载时释放。
材质筛选及图元范围每帧核对，变更时重新准备拓扑。
至少 4096 个顶点的变形与世界变换通过宿主线程池执行。
各任务写入互不重叠的区间，汇合后按原运算生成深度键和稳定次序。
并行录制关闭时采用串行计算。

运动历史持有提交、待提交及备用三个容器。
每帧校验有限值、形状及身份，身份顺序一致时共享不可变索引。
对象重排、新增及移除按身份重新建立索引。
打包继续核对几何、关节及形变表兼容性。
取消保留可复用存储，卸载释放历史与工作空间。

## 局部控制

实际角色含 207364 个顶点。
97326 个真实透明索引引用 25442 个唯一顶点。
二十个实际动画时刻配合原生摄像机输入进行交替控制。
透明位置、三角形索引、运动字及有效对象数均逐字节一致。

| 所属操作 | 基线均值，毫秒 | 候选均值，毫秒 |
| --- | ---: | ---: |
| 透明几何准备 | 1.009 | 0.569 |
| 运动历史暂存与打包 | 0.447 | 0.160 |

透明控制减少约 44%，运动核心减少约 64%。
运动控制使用原生 871 个对象身份及受控关节、形变输入。
其范围是历史暂存与打包，材质和绘制准备由整帧测量覆盖。
串行紧凑路径另有约 26% 的局部透明改善记录。

## 原生结果

完整联合场景以 1080p 固定步长运行。
基线与候选各预热三百帧、采样一百二十帧。

| 指标 | 基线 | 候选 |
| --- | ---: | ---: |
| CPU 均值，毫秒 | 13.144 | 10.760 |
| CPU P95，毫秒 | 14.833 | 11.507 |
| GPU 均值，毫秒 | 21.718 | 21.872 |
| GPU P95，毫秒 | 22.810 | 22.410 |

CPU 短时均值减少约 2.38 毫秒，读数改善约 18%。
GPU 收益未成立，663 份着色器保持相同字节。
原生 1440p 四帧冻结参考图均为零像素差异。
卸载后缓冲和图像归零，验证日志保持清洁。

候选环境记录包含一次软件热限速。
全部观察八十瓦条件未通过。
正式性能、整体画质及双设备范围继续待验收。
CPU P95 八毫秒、GPU P95 16.6 毫秒及正式样本要求保持有效。
