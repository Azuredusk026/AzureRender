# 视角遮罩与影色

## 范围

本项归属于 Q1 的发片颜色恢复。
资产加载器解释视角策略和影色饱和度。
材质表及片元程序持有公共颜色组合契约。
原生纹理、投影表面和角色身份由项目数据声明。

## 公共输入

`rampComposition` 支持 `view-facing-mask`。
该策略根据照明法线与相机轴计算平滑颜色权重。
`shadowSaturation` 声明零至四的有限饱和度。
完整接口见[漫反射组合](../../runtime/npr-diffuse.md)。

两项配置通过完整材质文档保存和重开。
缺省参数保留其声明的颜色组合方式。
普通表面与衣料分别验证该能力。
资源及材质表沿用场景所有权与帧同步。

## 来源核验

原生不透明轮廓事件为 1138。
五处片元追踪包含基色、法线、色带和中间颜色。
独立 NumPy 参考重建完整漫反射颜色组合。
最大线性误差为 `0.0000000253`。

原生影色包含局部亮度、饱和度和全局倍率。
视角权重使用 `smoothstep(0.25, 1, dot(N, -F))`。
局部灯及显示曝光分别核对其所属输入。
完整轮廓的阴影可见度继续独立验收。

## 验证方法

独立平面提供前向、斜向和背向法线。
场景可见量分别取零、二分之一及一。
颜色参考在线性空间计算，最大误差预算为 `0.008`。
影色调整分别覆盖常规和扩展片元程序。

固定描述符、完整材质文档及透明混合分别采集。
普通采样和四倍多重采样核验实际配置。
日志检查验证层、同步诊断及资源释放。
暖肤色联合镜头执行逐像素兼容检查。

## 当前范围

固定角色对照按最终绘制的实际像素归属记录。
头发主体、轮廓及透明阶段分别报告误差。
可见度隔离实验仅用于定位输入差异。
联合画质及完整发片保持待验收状态。

## 验证结果

Debug 与 Release 各完成四项受影响 CPU 检查。
两种构建和两种采样配置共通过 56 次 GPU 采集。
最大线性颜色误差为 `0.004012`。
固定描述符及完整材质文档与对应控制逐像素一致。

既有颜色组合在两种构建中共通过十六次采集。
暖肤色联合镜头各完成四帧兼容验证。
八帧输出与当前交付镜头逐像素一致。
完整原生轮廓和联合画质继续按既定门槛验收。
