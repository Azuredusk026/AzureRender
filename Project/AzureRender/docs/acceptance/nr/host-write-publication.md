# 主机写入发布控制

私有程序保持设备内存偏好，关闭逐次上传读取及锁。
写入发布开关在进程启动阶段读取。
实际分配属性在创建时记录，并在退出后保存。
该控制关闭显式存储屏障。

七十四次主机可见读取分配的实际属性均为七。
四帧全部符合原冻结参考，进程正常退出。
生产源码、运行程序及挂载文件摘要保持一致。
原像素差异未复现，显式发布候选按计划跳过。

该结果未证明写入排序为根因。
原驻留候选继续保持隔离，原验收条件有效。
下一项实施限定到分配器内部策略及既有公共接口。
