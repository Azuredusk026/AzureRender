# 参考头发选层边界

参考头发候选使用已核对的轴向与对角足迹计算基础层级，法线纹理继续使用原有近邻层级、线性纹素过滤和采样器偏移。45 份夹具文件中，头发材质的参考法线编码是唯一变化的声明。GLB 二进制载荷与冻结输入逐字节一致。[Vulkan 层级计算](https://docs.vulkan.org/spec/latest/chapters/textures.html#textures-level-of-detail-operation)

## 实际场景结果

| 设备 | 冻结头发法线超差 | 冻结头发可见量超差 | 冻结头发 RGB 超差 | 完整接收超差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 6 | 2 | 0 | 240 |
| Intel | 13 | 104 | 569 | 486 |

头发和完整接收区域分别包含 17,017 和 49,384 个点。可见量及 RGB 使用逐通道一字节门槛。两路压缩法线使用一编码单位的来源判据。深度与对象标识附件逐字节匹配冻结基线。

Release 构建通过 8 项 CPU 检查，NVIDIA 和 Intel 各通过 5 项 GPU 检查。两次场景采集通过验证层和分配器清零检查。画质门槛因 NVIDIA 新增的 2 处头发可见量超差与 3 处完整接收超差返回失败。生产入口使用已验收的 Player 及 895 份着色器，候选补丁及附件保存在验证归档中。

## 原生层级对应

NVIDIA 的六处法线超差均可逐位匹配某个原生显式层级。四个位置的候选层级为 2，冻结读回对应层级 1。两个头发可见量超差点在 CPU 模型中的层级约为 3.501415，冻结读回对应层级 4，候选读回可对应层级 3。实际着色器的层级与近邻选择边界仍需直接取样核对。

Intel 有 17,016 个位置在同设备某个显式层级中具有相差至多一单位的压缩法线。其余一处 `[1326,1262]` 的候选法线与冻结 NVIDIA 值逐位一致，该位置属于已记录的原生透明覆盖差异。

整体画质状态为 `failed-user-review`。[结果清单](evidence/2026-11-12/reference-hair-mip-footprint/results.json)与[验证归档](evidence/2026-11-12/reference-hair-mip-footprint/validation.zip)记录候选输出、每处误差、执行收据和已恢复摘要。
