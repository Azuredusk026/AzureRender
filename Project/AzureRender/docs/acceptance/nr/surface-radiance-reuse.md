# 同帧表面照明复用评估

## 结果与范围

本记录保存 2026-11-07 的隔离候选。
该批原生零像素门槛未通过。
当前配置与判断见[精度及成本验收](radiance-cache-precision-integration.md)。
CPU P95 八毫秒、GPU P95 16.6 毫秒及整体画质继续验收。
本批原生性能配对未执行。

## 成本依据

当前完整场景的 720p 捕获锁定实际着色程序及专用常量。
普通不透明材质的受检事件均值为 2.469 毫秒。
直接输出快照的成本剥离均值为 0.343 毫秒。
该控制会改变反射输出，仅用于估计可消除计算量。

按片元规模推算，1080p 的成本上限约为 4.78 毫秒。
额外附件读写按 1.5 毫秒估计，预期净收益约为 3.28 毫秒。
以上属于候选开发推断，实际覆盖、带宽及整帧收益各自待验证。
原始捕获见[当前 GPU 成本](current-gpu-cost.md)。

## 机制边界

候选保存三个单精度浮点附件和一个整数身份附件。
身份逐项包含原始深度位、实例、索引三角形及材质。
每像素共 64 字节，附件总预算为 512 MiB。
1440p 双帧槽分配 471859200 字节。
反射重组继续使用当前反射输入、原运算顺序及完整精度。
不适用材质、无效身份、格式与设备能力缺失均执行完整着色。

消费者按四像素组统一选择复用或完整着色。
路径要求 `VK_KHR_shader_quad_control` 和
`VK_KHR_shader_maximal_reconvergence` 的对应能力。
入口声明完整四像素组、导数模式及最大重汇合，保持回退中的隐式采样语义。
相关语言约束见 [Khronos 四像素组扩展](https://github.com/KhronosGroup/GLSL/blob/main/extensions/ext/GLSL_EXT_shader_quad_control.txt)
与[重汇合扩展](https://docs.vulkan.org/glslext/latest/glslext/ext/GL_EXT_maximal_reconvergence.html)。

本批新增 47 份着色程序，原有 663 份程序保持相同字节。
新增程序的编译参数登记于热重载描述，使用 Vulkan 1.3 目标环境。
真实 Vulkan 夹具验证单精度重组、同面优先写入、身份不匹配、帧槽及整组回退。
资源录制夹具覆盖固定与绑定数组描述符、顶点与计算蒙皮、缺失能力和资源释放。
真实 GPU 机制检查归属 RTX 4060 Laptop。
缺失四像素组能力的录制检查采用 NullRhi。

## 原生图像

本批只执行一次冻结四帧评估，分辨率为 1440p。
复用附件在实际候选中启用。

| 帧 | 变化像素 | 最大字节差 |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| 1 | 2 | 1 |
| 2 | 2 | 1 |
| 3 | 1 | 1 |

第一帧逐字节一致，后三帧未满足零像素条件。
生产者和消费者之间的浮点中间值、运算及编译器收缩仍需独立定位。
现有证据尚未确认具体原因。
候选的 GPU 整帧收益保持未测状态。

候选四帧执行约 272.72 秒，前一批已验证实现约 125.09 秒。
两次运行的源码及冷着色缓存状态不同。
该观察记录首次管线创建成本，正式编译耗时归因仍需独立控制。

## 检查与恢复

集中 Release 构建后的七项所属 CTest 通过。
模块边界检查覆盖十八个目标。
原生运行前后的源码、产物及 1729 份挂载输入摘要一致。
卸载后的缓冲与图像归零，原生日志未出现验证错误文本。
原生图像应用未启用验证层；真实 GPU 夹具启用了同步验证。

深度预填录制检查分别验证既有普通材质与固定材质类别的提前深度管线。
两类管线保留独立数量、提交资格及释放断言。
材质类别实现已存在于本批冻结的生产来源。
所属检查修正持续保留，运行时复用候选独立隔离。

恢复核对包括源码输入、Player 代码段、663 份着色程序及四项所属检查。
原生图像兼容证据按相同运行代码和输入复用。
候选源码、完整失败图像、检查日志及成本控制均归档。
