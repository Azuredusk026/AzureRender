# 阴影历史资格与失效策略

日期：2026-11-09。
状态：元数据范围及公共策略通过，运行时接入待完成。

## 资源范围

冻结关卡引用 374 项网格资源。
871 个可见实例中，860 个未声明骨骼、动画或形变。
其余十一项资源包含角色和动态物流几何。
静态实例需要的索引身份范围为 1354227。

以上数量依据关卡、资产标识及 glTF 元数据。
该静态范围属于接收资格的上界。
材质、运行时变换和实际屏幕覆盖继续由渲染器核对。
该范围支持继续接入，帧收益仍待测量。

## 公共策略

`ShadowHistoryPrimitiveRanges` 分配无碰撞三角形范围。
空范围、未对齐索引及容量溢出采用无效哨兵。
`ShadowHistoryViewIdentity` 核对输入位模式和资源代次。
历史资格只在写入命令提交后由调用方确认。

视图输入包含影响阴影的采样、光源及静态内容。
无效输入、跳过提交及显式取消均中断历史链。
调用方分别维护不同工作流的状态。
GPU 可见性依赖历史资源的显式同步。

动态边界投影覆盖盒体八个角点。
投影保留浮点运算误差及栅格边界余量。
前后位置的投影区域合并后参与过滤足迹核对。
无效投影、溢出及未知过滤足迹采用完整求值。

## 验证与边界

首轮红测复现身份分配接口的缺失。
生命周期红测复现未提交帧错误建立历史资格。
最终检查覆盖正交与透视投影的 4096 个内部点。
两配置核对身份、位模式、失效及最大过滤范围。

本单元的原生图像与整帧性能进程均为零。
生产渲染路径尚未消费该策略。
正式画面、CPU 与 GPU 预算保持现有标准。
整体状态仍为 `failed-user-review`。
