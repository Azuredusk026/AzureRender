# 参考外壳深度投影

参考相机可以声明 `outlineDepthProjection`。版本一接受有限的 `clipWSlope` 和有限的正 `clipZIntercept`，并要求启用 `produceSceneDepth`。该配置随项目参考视图保存和读取。

参考外扩使用原始齐次 W 保留屏幕位置。材质深度偏移沿相机前向改变用于计算深度的 W。外壳裁剪深度为 `W × fma(clipWSlope, shiftedW, clipZIntercept) / shiftedW`。普通参考几何、相机拾取和对象阴影图集采用各自的投影。

## 原生场景对照

帧 10401 的事件 440 使用独立的外壳深度系数。夹具按原生常量缓冲写入斜率 `-9.894371032714844e-06`、截距 `0.10000098496675491`。该图元的材质深度偏移为零。参考相机配置是 45 份夹具文件中唯一改变的输入。

| 设备 | 外壳深度逐位一致 | 外壳深度一 ULP 内 | 外壳可见量超差 | 完整接收超差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 2,026 / 2,046 | 2,030 / 2,046 | 1 | 237 |
| Intel | 753 / 2,046 | 1,720 / 2,046 | 43 | 608 |

完整接收包含 49,384 个点，沿用逐通道一字节门槛。两块设备分别有 48 和 32 个原超差点进入门槛，新增超差分别为 1 和 8 处。验证归档保存新增位置的原生值、当前值和深度误差。

同一 Intel 设备的 Vulkan 与 D3D11 深度对照中，2,017 处逐位一致，2,035 处相差至多一 ULP。原生 Intel 与冻结的 NVIDIA 附件有 1,735 处相差至多一 ULP。正式验收继续使用冻结附件。

完整法线与对象标识逐字节匹配固定基线。17,017 个冻结头发点的深度、可见量和颜色在各设备逐字节匹配固定基线。头发可见量超差为 NVIDIA 0、Intel 208，RGB 超差为 NVIDIA 0、Intel 575。

## 解析对照

128 × 128 球体使用非零材质深度偏移，144 个外扩位置在两块设备上覆盖一致。参考系数转换的最大误差为 2 ULP。固定纹理、索引纹理和仅深度路径的深度读回逐字节一致。完整法线与对象标识保持原值。

MSVC 核对参考视图、相机描述及渲染设置的尺寸和现有字段偏移。场景扩展使用 API 17。原生场景的整体状态为 `failed-user-review`。

## 构建与回归

Release 和 Debug 分别通过 8 项和 7 项 CPU 检查，两配置各在 NVIDIA 与 Intel 上通过 5 项 GPU 检查。同一设备的两种构建在五类附件和三帧 PNG 上逐字节一致。目录含 895 份着色器，四份参考外壳顶点程序与预编译摘要一致，其余 891 份与冻结目录逐字节一致。

原始场景四帧逐字节匹配冻结参考，验证层检查和分配器清零通过，运行用时 266.234 秒。[结果清单](evidence/2026-11-12/reference-outline-projection/results.json)和[验证归档](evidence/2026-11-12/reference-outline-projection/validation.zip)保存着色器指纹、原生常量、逐点读回及执行收据。
