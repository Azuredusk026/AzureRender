# 服饰接收法线采样

服饰一的参考夹具使用原生 BC5 十二级纹理。
纹理采样采用线性缩小和放大、最近邻层级以及重复寻址。
层级偏移为 −1，各向异性关闭。
采样配置保存在目标纹理的元数据中。
夹具的纹理、几何、场景及 Player 使用固定指纹。

## 实际接收结果

事件 377 的最后法线覆盖 16,629 个受检位置。
完整接收区域包括 49,384 个位置。
可见量和颜色均使用每通道一字节容差。

| 设备 | 服饰法线区域超差 | 服饰法线区域新增超差 | 完整接收超差 | 完整头发可见量超差 | 完整头发颜色超差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVIDIA | 1,310 | 122 | 1,672 | 0 | 0 |
| Intel | 1,317 | 103 | 1,944 | 208 | 575 |

参考深度、对象身份、完整头发可见量和颜色逐字节匹配固定对照。
事件 377 之外的受检可见量逐字节匹配固定对照。
同一设备的 Release 与 Debug 对应附件和三帧颜色逐字节一致。
完整接收及联合画质状态为 `failed-user-review`。
