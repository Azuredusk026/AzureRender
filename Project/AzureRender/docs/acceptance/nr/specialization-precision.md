# 专用常量精度定位

## 前端核对

十个动态程序与原生候选的对应程序逐字节一致。
其中九个局部专用程序仅改变一个布尔常量指令。
另一程序同时有已记录的提前深度执行模式差异。
前端的相同数学指令不能保证驱动生成相同机器运算。

每程序均有十项横向和十项纵向默认导数。
隐式细节层级采样为二十九至四十一项。
默认导数的粒度由实现选择。
规范依据见[定位计划](../../plans/2026-11-07-specialization-precision.md)。

## 功能控制

第一项私有控制将二十项默认导数限定为细粒度。
十项程序均通过 Vulkan 目标的 SPIR-V 校验。
九项附件与先前专用候选逐字节一致。
该控制未消除已观察到的基线差异。

第二项控制同时将全部隐式采样显式指定为细粒度梯度。
十项程序通过校验，受检隐式采样全部完成转换。
其附件仍未恢复基线，最终显示也出现差异。
两个候选均处于隔离状态。

本单元仅比较附件，没有调用性能计数器。
功能比较时系统报告电池供电，电量分别为 82% 和 79%。
生产源码、GPU 程序及资产保持原内容。
根因仍待机器指令或明确运算差异的进一步证据。
