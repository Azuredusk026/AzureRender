# 透明准备局部成本控制

## 来源与结果

生产源码基线为 `51ed5cd`。
私有程序在同一实际帧中交替运行参考与候选。
参考重复变换顶点，候选按实例保存世界坐标。
二十帧的全部索引及绘制元数据一致。

参考准备均值为 3.937 毫秒。
世界坐标复用均值为 3.663 毫秒。
局部均值差为 0.274 毫秒，约占百分之 6.96。
本次数据没有完整帧收益资格。

每帧有三万九千四百三十一个透明三角形。
静态共享姿态对应六千九百八十九个三角形。
每帧引用三万三千零十五个不同顶点。
完整写入索引数量为十一万八千二百九十三。

约百分之八十二的三角形使用动态姿态。
本记录的生产及私有来源按冻结字节核对。
现行排序及组合验证见[深度准备](stable-depth-sort.md)。
