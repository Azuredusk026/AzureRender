# 场景解析雾验收

阶段为 NR3-F1I，状态为分项通过。
公共绑定支持体积、光谱大气和两层高度雾。
契约见[场景解析雾](../../runtime/scene-fog.md)。
来源及指纹见[结构化证据](evidence/2026-10-28/scene-fog.json)。

## 公共契约

版本一保存捕获体积五个字段。
版本二声明解析对象并支持独立解析场景。
未知版本、字段和非法介质通过事务解码拒绝。
文本场景及关卡缓存键消费完整参数。

逐帧参数使用二十一行、336 字节布局。
相机和材质布局分别为 688 和 336 字节。
GPU 所有者持有体积与独立的在途帧缓冲。
应用着色模块共 199 项。

## GPU 与来源对照

Debug 与 Release 分别通过十六项场景捕获。
范围覆盖组合、独立、失配、正交、偏移和 MSAA。
最大线性颜色误差为 0.002122246，预算为 0.008。
同配置两种描述符路径逐像素一致。

官方四个远端片元来自第 8912 次绘制。
其视图深度约为 65 至 145，高度起始深度为 57.5。
两种配置及描述符路径的最大误差为 0.002593331。
原版透明字符五个片元的浮点附件误差为 0.000937466。

原版太阳方向按场景世界基准转换一次。
高度密度及衰减按原版指数约定换算。
组合顺序为体积、高度层和光谱大气。
RGBA16F 附件用于透明原始颜色对照。
透明夹具核对隔离表面，完整候选持有场景遮挡。

版本一体积雾各配置通过二十六次捕获。
逐采样轮廓各配置通过二十次捕获。
有效检查的验证层诊断为空，资源释放归零。
各配置七项 CPU 检查覆盖绑定、所有权和场景。
解析密度变化验证关卡资源键及重载键更新。
