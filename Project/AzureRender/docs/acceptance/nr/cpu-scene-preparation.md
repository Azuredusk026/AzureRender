# CPU 场景准备

## 阶段归因

源码基线为 `c61ed88`。
独立诊断程序使用当前运行库及二十帧阶段窗口。
正式程序和场景输入保持独立冻结。
本轮 CPU 工作均值为 17.09 毫秒。

| 阶段 | 均值 |
| --- | ---: |
| 场景准备 | 6.46 毫秒 |
| 渲染器更新 | 6.69 毫秒 |
| 命令录制 | 4.21 毫秒 |
| 主机同步 | 0.44 毫秒 |

阶段窗口与工作均值采用不同统计范围。
各阶段均值用于定位，不能直接相加为整轮均值。
该轮热状态通过，八十瓦稳定条件未通过。
阶段采样属于诊断，正式 CPU 门槛仍为八毫秒。

## 实现范围

运行时支持调用者持有的场景快照。
快照复用节点及字符串容量，完整刷新文档内容。
实体身份、变换、可见性及阴影存储各解析一次。
无效节点及灯光继续按所属身份过滤。

Player 在准备存储上生成当前场景并执行插值。
生成成功后交换当前文档，保持失败提交边界。
摄像机与渲染器使用同一帧场景描述。
编辑器保持所属视图的独立场景所有权。

摄像机从实际组件存储选择候选。
世界变换只计算候选节点及其祖先。
可达循环采用完整场景解析的确定次序。
优先级、身份排序、重复标识及诊断保持兼容。

## 局部测量

对照采用联合场景的节点和组件变换。
负载包含 1679 个节点、374 个资源及一台摄像机。
资源路径为资产标识构造，材质解析及 Player 帧不计入。
两种路径交替执行一百六十轮，并检查输出一致。

| 路径 | 基线均值 | 候选均值 |
| --- | ---: | ---: |
| 场景快照 | 1.105 毫秒 | 0.433 毫秒 |
| 摄像机选择 | 0.802 毫秒 | 0.216 毫秒 |

两项合计减少约 66%，节省约 1.26 毫秒。
该局部结果满足所属热点工作量评估门槛。
整帧收益由原生负载的独立计时判断。
