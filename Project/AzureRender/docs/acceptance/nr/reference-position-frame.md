## 公共契约

[参考位置坐标帧](../../runtime/reference-position-frame.md)声明有符号轴置换及偏移。
版本一参数占 32 字节，轴编码为九位整数。
CPU 与 GLSL 采用相同的分量选择、反射及单精度加法。
有限参考加法保留符号零和非规格化值。

`ReferenceDepthConfig` 的版本二持有坐标帧。
公开生产器直接消费世界坐标，随后执行参考裁剪投影。
调用方装配独立的不透明及透明覆盖顶点程序。
配置和程序校验先于 GPU 资源创建。

推送参数占 128 字节，图像及槽位预算遵循所属深度契约。
版本一的相对坐标使用默认程序。
所属资源、在途工作及失败清理见[深度契约](../../runtime/reference-depth.md)。
输入及表面版本分别参与校验。
