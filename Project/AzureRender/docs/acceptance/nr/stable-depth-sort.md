# 稳定深度准备验证

## 实现与来源

源码基线为 `8f4c330`。
透明三角形使用稳定的浮点深度排序工具。
同一实例内的重复顶点引用共享世界坐标。
质心、深度、同深度次序及绘制参数保持当前契约。

排序工具归属于渲染公共能力，工作区归属于当前调用。
实际场景与独立的索引排序夹具共同验证接口。
输入深度保持原字节，非法索引在修改前拒绝。
数据、规则及借鉴来源见[机制说明](../../runtime/transparent-depth-order.md)。

## 同输入控制

私有控制在二十个实际帧中循环改变三组执行顺序。
相邻组分别验证排序算法及世界坐标复用。
三组使用相同模型、姿态、形变和相机输入。
全部索引及绘制元数据一致。

| 配置 | 准备均值 |
| --- | ---: |
| 稳定比较排序 | 4.243 毫秒 |
| 稳定基数排序 | 3.037 毫秒 |
| 基数排序及世界坐标复用 | 2.834 毫秒 |

组合配置的局部均值差为 1.408 毫秒。
该差值约占参考准备成本的百分之 33.19。
每帧有三万九千四百三十一个透明三角形。
写入索引总数为十一万八千二百九十三。

私有程序还执行参考计算及逐项检查。
其整帧时间属于诊断范围，该批热状态未通过。
本单元收益资格为同输入局部成本。
原生整帧收益由后续集中采集核验。
