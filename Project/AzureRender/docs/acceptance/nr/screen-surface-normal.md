# 屏幕表面法线

## 范围

本项属于 Q1 的发片轮廓与透明阶段。
资产加载器解释法线来源，渲染器持有逐帧快照。
材质文档、固定描述符及索引描述符共用该契约。
角色身份、纹理和表面组合由内容资产声明。

## 公共输入

NPR 画像通过 `lightingNormal` 选择 `screen-surface`。
材质使用外扩前的世界位置生成屏幕取样坐标。
空深度和视口外坐标采用所属表面法线。
启用该输入时，设备须支持完整浮点表面快照。

投影头发通过 `snapshotNormal` 选择独立材质法线。
`material-normal-rg` 从标准法线纹理重建切线半球。
绿色通道使用正向约定，切线与缩放由头发画像声明。
该选择与头发照明及透明高光独立组合。

运行契约见[屏幕法线](../../runtime/npr-diffuse.md#屏幕表面法线)。
生产契约见[头发快照](../../runtime/projected-hair-lighting.md#快照法线)。

## 验证方法

独立平面夹具将法线生产与轮廓光接收分开。
NumPy 按世界位置、灯光和法线计算线性参考。
单点最大颜色误差预算为 `0.008`。
外扩用例以不同背景法线区分取样坐标来源。

倾斜法线和斜向灯光用于检查绿色通道方向。
缺省、独立法线、固定描述符及材质文档分别采集。
头发主体颜色的启停对照要求逐像素一致。
三种采样配置覆盖普通、多重采样及超采样。

材质解析检查缺省值、非法类型与画像所有权。
实际日志核验描述符路径、验证层和资源释放。
描边、裁剪、屏幕反射及材质文档执行受影响回归。

## 原生角色范围

来源事件 422 生产独立材质法线。
事件 522 复制该表面，事件 1138 消费屏幕法线。
原生法线纹理与头发参数纹理各有独立来源。
完整角色对照按实际像素归属记录颜色误差。

头发主体颜色保持其既定对照精度。
完整发片轮廓、透明阶段及联合画质继续验收。
当前功能检查按所属范围报告。
对象阴影的表面偏置与径向控制见[阴影核验](screen-normal-shadow.md)。

## 验证结果

Debug 与 Release 各覆盖三种采样配置。
十四类用例共完成八十四项 GPU 检查。
最大线性颜色误差为 `0.001062`。
验证层、描述符路径及资源释放按实际日志核对。

两种构建各完成四帧暖肤色联合对照。
八帧输出与交付镜头逐像素一致。
既有反射快照各完成四项检查。
材质解析与受影响契约各通过八项 CPU 检查。

固定镜头的头发法线角度中位误差为 `0.0811°`。
P95 为 `0.1548°`，最大误差为 `11.4413°`。
该数据用于核对输入，完整轮廓颜色继续验收。
数据和程序指纹见[结果记录](evidence/2026-11-05/screen-normal/results.json)。
