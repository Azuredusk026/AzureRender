# 服饰镜面输入验收

日期：2026-10-22。范围为 NR6-C13。
公共契约见[栅格材质镜面输入](../../runtime/specular-input.md)。
原生二维高光及完整受光组合继续专项验收。

## 原生依据

10401 的服饰绘制 868 采样参数图绿通道。
片元程序使用该值乘以 `0.04` 构造介电反射率。
引擎的显式输入通过倍率 `0.5` 对应该系数。
源参数与自发光使用各自的纹理和采样域。

五份服饰均已生成显式镜面画像。
四个输出通道与源图逐字节对应。
几何、动画二进制及非选择材质保持一致。
既有法线与自发光引用也通过一致性检查。

## 自动检查

加载和生产像素的有效失败记录已保存。
加载测试覆盖合法类别、默认值和非法输入。
未知字段、版本、缺少纹理及所有权冲突均拒绝。
导入后的 Alpha 字节与源值一致。

Debug 与 Release 各完成 28 次生产捕获。
两种描述符路径的输出逐像素一致。
恒定 HDR 探针提供独立的反射率数值期望。
直接镜面、自发光及漫反射分别隔离验证。

省略输入与显式默认来源的输出一致。
零倍率提供镜面消失的正控制。
自发光与漫反射不受镜面来源及倍率影响。
所有有效捕获检查运行错误及资源卸载归零。

## 实际角色

实际角色采集覆盖全身默认、全身显式镜面及近景。
两种全身配置使用相同姿态、机位和光照。
本项验证真实内容消费与受影响表面。
原生整体外观按一致参考条件继续验收。
