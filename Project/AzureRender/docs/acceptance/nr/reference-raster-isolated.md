## 原生接收顶点

双设备读取事件 328、345 和 377 的实际顶点输出。裁剪坐标和 UV 分别在 3,289、1,792 和 32,021 个顶点上逐位一致。事件 377 的索引与图集事件 191 逐字节一致。
