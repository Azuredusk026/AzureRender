# 材质槽位元数据查询

日期：2026-10-25。
范围为完整材质绑定的源身份查询。
主场景画像、动态姿态和完整画质分别验收。

## 公共入口

Assets 提供 `inspectMaterialSlots`。
glTF 查询读取 JSON 中的名称及显式身份。
GLB 查询读取版本二头部及首个 JSON 块。
其他支持格式使用现有模型导入入口。

槽位身份由 `materialSlotIds` 分配。
查询包含模型导入器的隐式回退材质。
场景绑定按模型路径复用当前解析的查询结果。
完整模型准备负责几何、纹理与骨架校验。

编辑事务和 Player 共用场景材质解析。
命令行检查使用以下入口：

```text
AzureMaterialValidator --slots model.glb
```

JSON、输入流和返回列表归当前调用持有。
源文件变化后的调用读取当前文件。
该入口适用于编辑槽位分配及独立资产检查。

## 自动检查

具名、匿名及重复名称与完整模型导入逐项对照。
显式身份、隐式回退及名称碰撞分别覆盖。
非法版本、块类型、长度和截断头部均须拒绝。
重复、空值及非字符串的显式身份均须拒绝。

缺失图片的夹具可查询槽位身份。
同一夹具的完整模型准备仍须报错。
该检查分别验证元数据范围和模型准备责任。

Debug 与 Release 均构建九个相关目标。
每种配置的六项检查全部通过。
范围涵盖项目、关卡、材质文档及共享编辑操作。

## 操作成本

测量使用同一份九动画角色 GLB。
完整导入耗时约 3.46 秒，峰值约 937 MB。
槽位查询耗时约 0.18 秒，峰值约 30 MB。
数值为独立进程墙钟时间及峰值工作集。

该测量限定于单次槽位查询操作。
完整场景启动还包含资产目录及渲染资源准备。
主场景渲染回归以冻结输入和图像指纹核对。

完整画像的主场景图像与冻结指纹逐像素一致。
验证层及运行诊断通过，卸载后资源计数归零。
可玩入口沿用已通过的完整画像等价对照。
