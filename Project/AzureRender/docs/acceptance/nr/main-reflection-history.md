## 装配与生命周期

独立反射由场景拥有运动目标。
时序抗锯齿与反射按视图共享同一目标。
前置运动读取快照的硬件深度。
后置运动读取主颜色所属深度，并供抗锯齿消费。
共享图像的两次生产通过资源图依赖排序。
运动绘制复用已有姿态、描述符和管线。
多样点路径采用可观察的本帧反射回退。

相机与材质布局保持 688 和 336 字节。
历史提交号仅在队列接受后推进。
取消录制保持已提交的历史身份。
完整写入资源采用丢弃式目标转换。
计算命令未提交时，重新录制保持合法布局。
录制异常关闭未完成的信号写周期。

## 自动检查

Debug 与 Release 各通过十四项受影响回归。
回归覆盖运动、辅助视图、重投影及反射层级。
实际 Vulkan 命令完成录制后被丢弃，再重新提交。
该红测曾发现未提交图像的布局错误。
修复后的两种配置均通过取消后重试。

每种配置另验证六条实际 Player 路径。
路径包含独立、共享、固定绑定、关闭和多样点回退。
连续移动目标按每帧的独立镜面投影检查。
每条路径采集十二帧，共保留 144 帧验证结果。
对应的七十二对 Debug、Release 图像逐字节一致。
取消修复前后的七十二对图像同样逐字节一致。
全部运行均通过卸载归零检查。
