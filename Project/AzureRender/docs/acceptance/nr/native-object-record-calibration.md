# 原生对象记录标定验收

日期：2026-11-12。
范围为实际 Player 的对象可见量接收投影。
整体画质状态为 `failed-user-review`。

## 对象记录

具名视图以图集页选择标定记录。
锚点世界投影来自实际 Vulkan 片元常量。
反向接收投影和单位光方向来自原生事件 699。
当前场景提供图集、深度、法线、身份及过滤参数。

锚点采用原生记录的矩阵与光方向位值。
对象和灯光变化时，记录按当前生成投影换算。
相机换轴时，投影及光方向同时换入当前参考坐标。
图集仍按当前场景的正向 D16 写入。

Vulkan 事件 406 的常量缓冲保存实际片元输入。
逆投影、对象投影及光方向与原生来源逐位匹配。
图集及可见量的摘要与对应生产读回匹配。
同步验证及资源释放由同配置采集检查。

## 移动夹具

CPU 对照验证具名视图、矩阵格式和图集页唯一性。
相机换轴、对象平移和灯光变化均覆盖。
浮点仿射对照包含 1,024 组变换。
最大绝对误差为 `3.29691829e-12`。

实际夹具核对斜向投影及背景。
锚点和相机与对象共同移动的可见量逐字节一致。
灯光转动时，常规与标定场景的可见量逐字节一致。
两种灯向分别有 1,144 和 748 个像素的绿通道低于 255。

## 头发图集来源

NVIDIA 的 182 处头发超差均与图集单项对照重合。
17,014 个位置与该对照逐字节一致。
完整 17,017 个头发位置与该对照的差异至多一字节。
后续按逐事件证据核对图集写入。

## 冻结区域

头发区域为 17,017 个位置，完整接收区域为 49,384 个位置。
生产采集核对冻结附件的逐通道一字节门槛。
参考深度、法线、对象身份和三帧颜色摘要分别匹配逆投影标定场景。

| 设备与区域 | 常规记录超差 | 原生记录超差 | 原生记录逐字节一致 | 最大误差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA 头发 | 277 | 182 | 16,802 | 23 |
| Intel 头发 | 428 | 394 | 16,472 | 55 |
| NVIDIA 完整接收 | 3,129 | 3,000 | 45,925 | 255 |
| Intel 完整接收 | 3,327 | 3,259 | 45,466 | 255 |

双设备有 7,182 个头发位置的深度及法线逐位一致。
其中 28 处的可见量设备间差异超过一字节。
完整接收区域继续按实际深度及法线来源核对。

Debug 与 Release 的附件、颜色及区域统计按设备逐项一致。
双设备在两配置各通过四项 GPU 检查。
两配置各通过五项 CPU 检查。
891 份着色器摘要逐项匹配深度方向单元。
