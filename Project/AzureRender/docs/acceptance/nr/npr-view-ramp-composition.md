# NPR 视角色带合成核验

日期：2026-11-02，归属为 Q1 角色着色。
状态：原生中间量重建通过，公共配置接入待完成。
完整角色与场景的联合画质保持未通过。

## 来源与范围

来源为保留的原生 D3D11 帧捕获及片元跟踪。
五份服饰共核对八个内部片元。
服饰四具有四个样本，其余服饰各有一个样本。
纹理身份及绘制资格见[服饰输入核验](native-cloth-inputs.md)。

核验直接读取指令边界处的实际寄存器。
输入包含亮部、阴影反照率及两次色带采样。
输出分别核对室内颜色、合成颜色及完整漫反射权重。
原始输入及摘要见[证据清单](evidence/2026-11-02/npr-view-ramp-composition/manifest.json)。

## 颜色权重

视角权重为视角色带透明度乘以原始遮蔽权重。
阴影混合量为该结果加主光色带透明度。
阴影混合量限制在零至一之间。
室内颜色也使用同一视角权重。

室内亮部采用原生的饱和度计算。
室内颜色与户外颜色按场景可见量合成。
完整漫反射权重按同一可见量混合视角权重与亮部遮罩。

公开响应中的原始遮蔽权重具有独立语义。
镜面和头发消费者各自施加一次视角权重。
颜色合成的视角权重须与该原始值分别保存。
机制接入见[实施计划](../../plans/2026-11-02-npr-shadow-composition.md)。

## 数值结果

| 检查项 | 最大绝对误差 | 预算 |
| --- | ---: | ---: |
| 室内颜色 | 3.651 × 10⁻⁹ | 10⁻⁶ |
| 合成颜色 | 6.353 × 10⁻⁹ | 10⁻⁶ |
| 完整漫反射权重 | 0 | 10⁻⁶ |

八个样本的场景可见量均为一。
室内项通过独立指令边界的中间量核对。
服饰三、五的本次样本具有零遮蔽权重。
公共夹具还需覆盖非零权重和室内混合输出。

以原始遮蔽量直接混合的室内颜色存在偏差。
本组样本中的最大绝对偏差约为 0.0117064。
该偏差为后续 GPU 失败控制提供可观察输入。
