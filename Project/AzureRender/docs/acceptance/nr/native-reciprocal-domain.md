# 原生倒数规则与接收位置

日期：2026-11-10。
状态：诊断参考核对完成，生产接入待验。

## 来源与资格

接收区域为冻结的 49384 个有效像素。
原生生产事件的倒数探针保留绿色附件。
十二个版本的全帧绿色逐字节一致。
撤销替换后，原附件恢复基线。

原生绘制实际覆盖 757617 个规范化输入。
这些输入与 NVIDIA 计算输出逐位一致。
计算夹具覆盖全部 8388608 个规范化尾数。
完整计算域与实际原生覆盖分别记录。

原生保留两项 Nsight 计数器初始化消息。
本次操作没有请求性能计数。
双设备计算启用验证层与同步检查。
四项接收运行均报告零验证错误。

## 倒数参考结果

完整计算域中，7280086 个值正确舍入。
374723 个值偏低一个末位单位。
733799 个值偏高一个末位单位。
完整表的 SHA-256 记录于结果清单。

用原生齐次输入查表并缩放指数后，
49384 个世界位置全部逐位匹配原生。
该控制说明倒数规则具有可测设备差异。
表按数学输入索引，完整域为 32 MiB。

## 双设备接收结果

| 设备 | 一字节以上超差 | 最大字节误差 | 世界位置逐位一致 |
| --- | ---: | ---: | ---: |
| NVIDIA | 0 | 1 | 49384 |
| Intel | 1 | 4 | 49303 |

两端使用相同冻结输入与固定采样足迹。
Intel 的剩余位置为屏幕坐标 `1288,273`。
该点的齐次 X 坐标与原生相差一个末位单位。
119 处误差闭合属于私有参考夹具的结果。

整数精确舍入的 CPU 乘加对照覆盖整个区域。
它与 49384 个原生齐次 X 值全部逐位一致。
Intel 原始乘加有 97 个齐次 X 值存在差异。
下一候选核对 GPU 上的精确乘加边界。
