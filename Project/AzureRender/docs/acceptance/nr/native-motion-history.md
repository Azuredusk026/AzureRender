# 角色移动与历史显露验证

日期：2026-10-24。
范围为 NR7-AA3、AA4 的移动与历史有效性。
计划见[运动覆盖实施](../../plans/2026-10-24-material-motion-coverage.md)。

## 输入与边界

真实角色使用来源帧 10401 的几何及材质绑定。
动画副本增加一个父节点，平移距离为 0.03 世界单位。
来源的 328 个节点及索引保持原值。
原有二进制前缀共 26,428,588 字节。

新增动画共用正式节点动画采样入口。
每组采集八十帧，固定步长为六十分之一秒。
十六帧预热，三十二帧移动，末段保持姿态。
关节形变、遮挡及服饰运动继续分别验收。

诊断分量为多层 KK，曝光为负四档。
测量区域固定为像素矩形 `540,45,765,240`。
关闭抗锯齿及候选均使用 1280×720 输出。
四倍参考使用 5120×2880 输出。

描边下限及接收偏移按对应输出像素配置。
参考图在线性 RGB 中按四乘四面积缩小。
首帧按冻结角色输出逐字节核对。
来源几何、材质和姿态的哈希记录于收据。

## 历史有效性

运动 W 的负一表示前帧匹配缺失。
负二表示完整响应，负一与零之间表示部分响应。
完整响应拒绝当前历史，并写入零历史有效值。
同深度表面显露时，共用既有历史 Alpha 检查。

GPU 检查先输入完整响应，再显露同深度表面。
两帧保持相同投影、几何及深度。
交替颜色处于邻域范围之内。
输出必须等于当前 HDR，Alpha 保持当前语义。

红测的第二帧将参考白色混合为约 0.1。
修复后通过相同输入及全部既有历史检查。
前帧缺失仍可为下一帧提供有效输入。
材质布局、附件及每像素 52 字节预算保持原值。

## 验收结果

门禁沿用能量偏差 2% 及误差比 0.8。
相关细节幅度范围为 0.8 至 1.2。
完整画面与正式入口晋升继续执行 AA5、AA6。

区域能量及整体相关幅度作为独立分项记录。
细发丝另检查原图减去三乘三均值的高频信号。
相关幅度由候选在参考信号上的投影计算。
该检查同样采用 0.8 至 1.2 门禁。

固定姿态平移的整体误差及能量通过门禁。
细发丝的高频相关幅度未达到门禁。
完整角色动态验收保持待完成。
