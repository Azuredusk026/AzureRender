# 阴影成本的材质范围

## 来源

本单元入口为 `ca47eed`。
输入为既有交流供电控制及原始捕获。
控制在相同程序的 1009 次绘制中关闭阴影求值。
该操作改变画面，仅用于成本归属。

捕获分辨率为 1280×720。
本次复用既有计时，新增 GPU 计时次数为零。
读取三十五份实际管线的专用常量。
普通材质资格以常量值判断。

全部主绘制的控制差值为 2.751232 毫秒。
快照阶段的控制差值为 1.338368 毫秒。
两项之和与原 4.089600 毫秒记录一致。

历史可见量缓存接入普通材质的提前深度管线。
相应主绘制的控制差值为 1.473936 毫秒。
该数值约占全部匹配差值的 36.04%。
具体命中、流量及额外管线成本尚未分离。

控制包含编译器消除相关依赖的影响。
这些局部差值并非缓存净收益或原生整帧收益。
历史可见量缓存的 GPU 收益失败保持有效。
原生完整画面及性能批次本轮均未启动。
