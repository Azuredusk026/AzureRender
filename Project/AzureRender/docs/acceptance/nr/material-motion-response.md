# 材质运动响应验证

日期：2026-10-24。
本项属于 NR7-AA3、AA4 的不透明高光运动验证。
执行顺序见[运动与覆盖计划](../../plans/2026-10-24-material-motion-coverage.md)。
透明发丝、服饰及完整角色运动继续分别验收。

## 公共输入

公共模型通过单关节动画执行平移与停留。
序列包含十六帧预热、三十二帧移动及三十二帧停留。
三组输入分别采用来源时序、积分时序及四倍尺寸参考。
固定频率为每秒六十帧。

首帧记录初始姿态，后续时刻来自固定步长。
几何遮罩按参考投影生成，并核对参考图的外部区域。
高光测量固定负四 EV，保留三倍隔离显示系数。
输出及日志保存在内容挂载目录之外。

## 采样与响应

颜色与运动通道共用几何基底判定函数。
恒定基底采用扣除抖动的片元内空间积分。
变化基底使用实际光栅位置的时序样本。
两种情况分别覆盖公共平面与真实角色。

运动纹理的负一表示完整响应。
负一至零之间的数值表示可追踪输入的部分响应。
恒定基底的空间积分输入将内部历史权重折半。
轮廓处保留覆盖积累，透明叠层保持完整响应。

移动重投影采用九次采样的三次颜色重建。
深度、有效状态及邻域约束分别检查。
公共 GPU 探针核对部分响应、变化基底与完整响应。
输出布局及资源生命周期沿用现行契约。

## 架构范围

材质表保持十二行、192 字节及九个纹理槽。
相机表保持 640 字节，运动推送保持 128 字节。
时序纹理预算保持每像素 52 字节。
响应信息通过现有运动纹理传递。

源材质特征沿用完整材质文档及稀疏覆盖入口。
视图提交、取消、切镜及重建沿用既定所有权。
默认抗锯齿模式及正式入口晋升遵守 NR7-AA5、AA6。

## 回归与证据

两种构建各通过二十五项检查及三十三组描边采集。
八十五个着色器产物的跨构建指纹一致。
真实头发三十二帧的跨构建输出逐字节一致。
来源关闭时序的完整输出保持既定指纹。

漫反射兼容探针采用同材质及来源着色器对照。
移动内部误差和残差变化均保持一致。
几何边缘误差比为 0.8914，外部历史残留为零。
该探针验证兼容性，主带改善门禁仍为 0.8。

交替计时固定同一程序、输入及一千二百八十像素视图。
每组采集一百六十帧，统计时舍弃前三十二帧。
管线检查关闭时，对照与候选均约为 11.20 毫秒。
默认检查开启时，两者均约为 11.28 毫秒。

计时用于本项回归，NR12 正式性能条件单独验收。
