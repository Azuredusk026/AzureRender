## 公共状态与失败恢复

主宿主与 Player 在队列接受后通知场景渲染器。
辅助视图仅通知本次完成录制的参与者。
静态缓存保持上次实际渲染的提交号。
相机状态按渲染器实例独立持有。

检查覆盖重复准备、跳帧、取消、尺寸和场景代次。
切镜标记、投影、曝光及非法数值分别检查。
注入录制失败后，已提交状态保持完整。
取消后的视图请求能够重新调度并成功提交。

场景渲染器采用注册 API 版本三。
版本一与版本二在工厂调用前被拒绝。

提交通知要求拥有者线程。
重复、乱序及未完成录制的提交被拒绝。
退役视图接收所属帧的通知。
被丢弃渲染图的租约随图销毁后归零。
