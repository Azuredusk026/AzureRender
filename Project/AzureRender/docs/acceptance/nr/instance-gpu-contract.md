日期：2026-10-23。范围为 C16 的实例容量基础。

对象图绘制及过滤接入继续按 C16-R4-R1 实施。

## 共享契约

`SceneInstanceGpuData` 版本一保持 496 字节。

三个顶点通道共用 `instance_data.glsl`。
字段表见[材质与实例布局](../../runtime/material-input-layout.md)。

宿主继续按冻结实例顺序写入在途缓冲。
矩阵、整数元数据、形变及面部帧具有独立字段。
捕获清单声明 `instanceDataLayoutVersion`。
源资产及角色身份由内容和离线工具持有。

独立计算程序读取两个相邻的实例记录。
每个记录的 124 个字均与宿主输入逐位一致。
检查覆盖矩阵列序、数组步长及高位整数元数据。
Debug 与 Release 均通过，原始顶点程序二进制一致。

主绘制、阴影和描边的双配置指纹均有保存。
绘制记录及不透明度检查通过。
真实角色及主场景各有一次实际捕获。
两份图像分别与参考画面逐字节一致。

## 原生对象投影

对象图的身体和头发与可见通道采用相同几何。
对应索引、UV 与相机相对位置均完全一致。
两份执行后输出合计包含 14853 个顶点。

对象图包含十次源绘制。
身体及头发采用完整几何投影。
