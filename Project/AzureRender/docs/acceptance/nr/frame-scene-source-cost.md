# 帧场景来源成本

## 评估范围

本单元评估 RenderCore 的动态场景输入复制。
`SceneFrameData::sceneSnapshot` 提供共享的只读来源。
候选持有来源，读取节点、灯光、反射和间接光字段。
资源布局及加载配置由已加载场景持有。

候选所属测试覆盖发布者释放、空输入、来源替换和重置。
独立消费者持有各自的来源版本。
缺少实现的编译失败及实现后的通过记录均已保存。
渲染器接入补丁保持隔离，生产采用 `c3def68` 的受检输入。

## 局部结果

负载取联合场景的节点标识、变换及数据规模。
包含 1679 个节点、374 个资源、16 盏灯和十二个反射体。
反射元数据按实际描述解析。
对象阴影的可选状态及灯光数值采用同规模控制。
资产解析、材质解析、渲染器其余准备及 Player 帧不计入。

两种路径交替执行两千轮。
核对的节点字段及消费结果一致。

| 路径 | 单次均值，毫秒 |
| --- | ---: |
| 四类动态字段复制 | 0.03716615 |
| 共享来源读取 | 0.00001350 |
| 局部差值 | 0.03715265 |

绝对差值约为 0.037 毫秒。
本结果不足以证明当前帧存在四分之一以上的对应热点。
CPU 两毫秒的整帧预期节省条件也未成立。
该候选未达到[集中验证门槛](../../development-workflow.md#检查安排)。
原生采集、整帧计时及 GPU 回归未启动。
