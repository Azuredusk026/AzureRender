# 眼睛 NPR 输入与合成

日期：2026-10-23。范围为 C9-E1 的公共照明适配。
原生帧 10401 的事件 846 提供虹膜输入证据。
本项验证捕获姿态，完整眼睛还原继续验收。

## 原生输入

八份原生片元追踪核对视差、双法线及 Matcap。
坐标与法线的最大数值误差小于 `1e-7`。
Matcap 能量误差小于 `2e-8`。
漫反射误差约为 `1.25e-7`。

基础颜色和 Matcap 消费 sRGB 压缩 DDS。
漫反射色带消费线性 RGBA 数据。
原始 mip、最近层级选择和负一偏移分别保留。
材质阴影倍率为 `0.3025000131`。

主灯、环境和 Matcap 组合后具有 HDR 饱和度增益。
局部灯按各自通道合成，直接颜色只合成一次。
原生 R11G11B10 附件与引擎 RGBA16F 分别记录精度。

## 公共契约

`lightingInputs.illuminationModel` 可选 `npr-main-ambient`。
该模式显式声明环境色、主灯色及阴影倍率。
公共色带响应复用共享颜色核。
类型、范围、未知字段及缺失输入均由加载器检查。

材质布局版本九使用十二行、192 字节和九个纹理槽。
第七至九行保存眼睛的可选 NPR 参数。
基础宿主照明保留其缺省参数及固定采样规则。
完整文档和内嵌画像消费同一解释器。

参数规则见[眼表面契约](../../runtime/eye-radial-surface.md)。
联合表归属见[材质布局](../../runtime/material-input-layout.md)。

## 图像验证

公共 NPR 夹具每种构建各十五组。
覆盖环境、主灯、阴影倍率、Matcap 及 HDR 高亮。
独立期望的最大线性误差约为 `0.00278846`。
固定预算为 `0.008`，mip 正控制改变 12892 个像素。

真实角色使用原生执行后眼部顶点及三份 DDS。
内嵌、完整文档和固定描述符的完整画面逐字节一致。
既有角色基线与前次接收坐标候选逐字节一致。
五个原生控制点的输出误差为零至一字节。

完整可见区域包含 255 个像素，最大误差二十字节。
三乘三内缩区域包含 163 个像素。
内缩区域的 95 分位误差为一字节，最大十二字节。
其中七个像素的误差超过一字节。

超差点的基色输入已与原生片元分离核对。
独立 DDS 对照中，原生输入最接近第五级。
候选基色最接近第四级，仍需硬件层级查询确认。
该结果属于采样诊断，完整区域门禁保持待验。

## 剩余门禁

继续核对隐式采样梯度、层级边界和几何覆盖。
眼白附加绘制、眼睑遮挡及逆光主灯项分别验收。
视线变化、头部转动和不同灯向纳入动态对照。
完整原生配方的 `readyForImport` 保持门禁控制。

最终时序输出按 NR7-AA6 和 NR12 联合验收。
