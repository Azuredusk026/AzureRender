# 缓冲驻留局部重放

本轮接续已采用的设备本地缓冲优化。
交流供电的实际状态变化提供了重试条件。
正式性能仍须满足原定 80W 条件。
当前记录属于既有捕获的描述性比较。

## 输入与稳定条件

两份捕获来自主机内存及设备本地缓冲路径。
它们的运行程序和命令存在差别。
匹配范围为 3394 个绘制序号及六十一个图形管线。
二十二份片元程序均匹配原始摘要。

九份代表附件逐字节一致。
初次本地端八次预热从 26.17 降至 13.35 毫秒。
稳定条件需要连续三个读数处于 3% 范围内。
初次序列没有进入本地端正式取样。

修正评估允许至多三十二次有界预热。
实际三端分别在四次、三次及三次预热后稳定。
每端随后保存三个样本。
初次失败及修正批次分别保留原始记录。
