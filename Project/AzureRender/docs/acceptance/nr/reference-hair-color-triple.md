# 头发基色与三纹理选层

原生帧 10401 的事件 950 以同一 UV、采样器和负一级偏移读取基色 `t16`、参数 `t17` 与双法线 `t18`。基色控制只作用于 RGB。Alpha 沿用材质覆盖路径。独立基色和三纹理控制使用轴向与对角足迹及半层采样规则。

## 冻结颜色

逐通道一字节门槛覆盖 17,017 个冻结头发位置。NVIDIA 的六张完整 PNG 逐字节匹配基线，两台设备在两组控制中的五类参考附件也逐字节一致。

| Intel 控制 | RGB 超差 | 进入门槛 | 新增超差 |
| --- | ---: | ---: | ---: |
| 冻结基线 | 568 | 0 | 0 |
| 基色 RGB | 391 | 209 | 32 |
| 参数与双法线 | 393 | 215 | 40 |
| 三纹理 | 32 | 537 | 1 |

三纹理控制使双纹理控制新增的 40 处超差有 39 处进入门槛。32 处剩余中，17 处的参考可见量也超出一字节。新增超差位于显示坐标 `[1240,248]`，峰值为 29 字节。该点的参考法线和实际纹理梯度继续按原生采样定位。
