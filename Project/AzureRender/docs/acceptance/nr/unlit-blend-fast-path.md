# 无光照混合表面优化

## 实现与范围

生产来源为 `9004b9c`，所属实现为 `shaders/unlit_blend.glsl`。
普通与自发光类别的透明混合表面按实际功能位进入主输出。
纹理图层、覆盖率、节点透明度及显示掩码保持原运算。
发光衰减按有效聚类灯顺序计算。
反射快照先取得完整法线及粗糙度，再输出所属无光照颜色。
诊断及其余功能组合使用通用材质入口。

## 局部成本控制

既有冻结捕获中的片元程序与生产文件逐字节匹配。
六百个高成本绘制中有二十三个匹配的无光照混合事件。
实际材质行包含普通发光与光照衰减输入。
原程序、候选、候选、原程序按相同捕获顺序计时。

| 指标 | 原程序均值，毫秒 | 候选均值，毫秒 |
| --- | ---: | ---: |
| 匹配绘制事件 | 3.458 | 0.216 |
| 全部重放事件 | 35.356 | 31.840 |

八份颜色、法线及显示掩码输出逐字节一致。
所属绘制减少约 3.24 毫秒，达到原生集中验证门槛。
历史重放成本与当前原生整帧成绩分别解释。
实现方法参考[微软着色器优化说明](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-optimize)。

## 原生结果

完整联合场景使用 1080p、固定步长及三百帧预热。
每组取得一百二十帧短时样本。

| 指标 | 基线 | 候选 |
| --- | ---: | ---: |
| GPU 均值，毫秒 | 24.114 | 21.208 |
| GPU P95，毫秒 | 24.795 | 21.820 |
| CPU 均值，毫秒 | 16.835 | 17.612 |
| CPU P95，毫秒 | 18.953 | 19.930 |

GPU 均值减少约 2.91 毫秒，短时读数改善约 12%。
两份 Player 的 `.text` 摘要相同，本项没有 CPU 机制收益。
CPU 读数包含环境及驱动影响，继续由所属热点批次处理。
供电观察未保持全部八十瓦，正式性能资格待验收。
八毫秒 CPU、16.6 毫秒 GPU 及整体画质门槛保持有效。

原生四帧 1440p 冻结对照均为零像素差异。
公共检查完成六十五次采集，覆盖诊断、纹理层及发光衰减。
固定与索引描述符、四重采样反射均通过所属检查。
四项 CTest 通过，运行后缓冲和图像归零。
本批保留 GPU 实现，继续执行剩余性能及外观验收。
