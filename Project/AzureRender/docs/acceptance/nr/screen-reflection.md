日期：2026-10-28，阶段为 NR5-R8-I。
范围为本帧反射生产及主场景消费。
公共契约见[屏幕反射组合](../../runtime/screen-reflection.md)。

## 资源与场景

组合资源复用深度、射线、信号层级和空间过滤。
四项资源分别持有内部同步及逐帧状态。
图像分配合计采用 512 MiB 的保守预算。
相机参数保持 688 字节，材质表每项保持 336 字节。
主材质通过只读存储图像绑定 37 读取结果。

输出在构造时清零并进入 `GENERAL`。
描述符在首次命令记录前发布，覆盖缓存命令的使用。
未启用计算生产时，描述符引用中性存储图像。
主辅场景通过既有装配与提交生命周期持有资源。

## 完整画面

Release 捕获原版 3534 机位的完整中庭。
分辨率为 2560×1440，场景共 364 项资源。
捕获清单确认计算生产和七级层级实际启用。
该完整捕获的验证层关闭，配置范围单独记录。

完整图对官方图的平均字节误差为 13.065549。
此前表面快照候选的对应误差为 13.058428。
该结果用于确认接入及定位后续差异。
原版还原精度及完整画面门槛继续验收。
截图见[阶段画面](visual-history.md)。

## GPU 短测

设备为 RTX 4060 Laptop，分辨率为 1920×1080。
固定步长运行一百五十帧，前三十帧用于预热。
后续一百二十帧平均耗时为 38.054 毫秒。
第九十五百分位耗时为 38.655 毫秒。
该结果尚未达到 16.667 毫秒预算。
持续性能及稳定环境条件分别保留正式验收项。

阶段运行和生成缓存均位于 D 盘。
验证结束后清理候选的可再生资产缓存。
原始载荷、截图、日志及收据按清单保留。
