# 编辑器资产刷新

日期为 2026-11-12。
Debug 和 Release 均通过 `AzureEditor.DevtoolsHost` 的探索项目及资产检视项目流程。

## 缩略图生命周期

自动文件刷新在处理渲染资源前完成来源扫描。
缓存按资产及依赖指纹核对缩略图。
键变更的缩略图换代，匹配键保留现有句柄及完成的图像。
场景预览和相机预览随资源刷新退役。
显式资源重载和文档变更执行完整预览失效。

## 复验结果

探索项目修改模型来源后，旧缩略图句柄失效，无关缩略图保留句柄及指纹。
刷新后的 25 帧等待，Debug 为 9.127 秒，Release 为 0.914 秒。
两种配置均满足原十秒门槛。
资产预览、相机面板、着色器重载、窗口恢复及资源卸载按原流程核对。
Debug 复验十一项，Release 复验两项，均通过且无跳过。
两种配置分别核对 1280 和 1635 份沿用的构建产物摘要。
