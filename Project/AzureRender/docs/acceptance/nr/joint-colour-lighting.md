# 场景颜色与原生照明联合验证

验证日期为 2026-10-18。
阶段索引为 NR1、NR2、NR4 和 NR5。
当前结果属于技术集成候选。
原生画面一致性保持待验收。

## 联合候选

场景包含 60 个颜色修正后的模型资源。
重烘焙保留节点、几何、索引及透明状态。
局部反射使用原生白黄色候选的八级纹理。
间接光候选采用分支零的两米方向辐照网格。

当前版本读取 232 个静态灯。
联合候选选用其中 45 个点光及聚光。
位置、方向、颜色及锥角来自当前源字段。
灯光强度保留 0.04 的候选换算比例。

三个候选分别捕获四帧，共十二帧。
采样采用 640×360、固定步长及每秒六十帧。
该批次用于资源接入和短时生命周期验证。
帧率参数表示采样时基，性能另行测量。

三个进程的退出码均为零。
验证层处于启用状态，错误计数均为零。
脚本、表现及场景加载错误均为零。
每次退出的缓冲和图像分配计数均归零。
