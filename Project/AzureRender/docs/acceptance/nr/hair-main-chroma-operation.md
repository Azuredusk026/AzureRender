# 头发主光色度运算

日期：2026-11-10。
状态：原生单因素归因合格，生产颜色未通过。

## 原生实际运算

原生指令 1354 生成随亮度变化的色度系数。
亮度使用既有线性 RGB 权重。
系数为 `1+clamp(亮度-0.5,0,0.5)²`。
指令 1356 在保留亮度的同时增强色度。

该运算位于主光合成后、局部灯循环之前。
本项读取运算前颜色、系数及运算后颜色。
21 个探针均通过完整裁剪蓝通道核对。
31 个位置的调用标志均合格。

撤销后，裁剪区域逐字节恢复。
实际运算增量的最大分量为 `0.0741050243`。
其位置为 `1284,211`。
CPU 公式预测峰差约为 `0.0000000509`。

## 单因素控制

诊断版本将该实际系数设为一。
其余原生运算保持捕获中的输入与顺序。
完整输出复制控制及九个浮点探针均合格。
撤销后，捕获恢复原始裁剪字节。

主要色度组包含参数稳定的 20 个位置。
该组与 Vulkan 最终浮点值的峰差如下。

| 实际原生版本 | 最大分量差 |
| --- | ---: |
| 捕获中的系数 | 0.0715508461 |
| 诊断系数一 | 0.0000861287 |

最大剩余位于已有色带差异点 `1282,211`。
该控制确认主光色度运算是主要误差来源。
该结论限定于本组实际取值及其因果控制。
完整颜色继续使用原始参考及门槛。

## Vulkan 合成边界

两批各十二个实际取值探针均合格。
读取位置位于条纹之后、反射探针更新之前。
该位置的颜色已包含局部灯贡献。
漫反射、高光叶及轮廓光之和也包含这些贡献。

原生主光运算的输入具有独立作用域。
后续候选须显式重建所选主灯的颜色项。
环境量、主灯及主灯高光叶按指定阶段组合。
局部灯继续沿其所属合成边界处理。
