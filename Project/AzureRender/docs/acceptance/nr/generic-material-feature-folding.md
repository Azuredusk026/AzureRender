# 通用材质功能分支裁剪

日期：2026-10-27。范围为 NR7-AA5 的主颜色成本。
前置输入采用有界专用化及完整快照路径。
正式抗锯齿和 60 帧预算保持所属验收条件。

## 材质契约

通用不透明材质支持四种基础功能集合。
其数值为 `0`、`8`、`32` 和 `40`。
自发光遮罩与中性标志保留提交值。
其余功能位按基础集合固定为零。

参数、纹理及两个视图采样标志保持动态。
附加着色功能、未知位及其他透明模式采用完整程序。
主颜色最多准备三条朝向管线，快照采用完整程序。
材质文档及 GPU 数据布局保持现有版本。

glTF 默认材质使用中性标志。
显式 PBR 接入允许零功能集合。
实际热点网格包含 16,857 个索引，功能值为 `40`。
其截帧同时保存类别零、透明模式零及画像版本一。

## 构建依赖

共享 GLSL 函数由主着色器及计算夹具共同消费。
编译器通过依赖文件记录实际包含关系。
CMake 将依赖交给增量构建，文件存入构建缓存。
热重载采用包含共享头文件的内容快照。

仅触碰共享头文件后，两配置各重新构建二十五份输出。
全部 117 份着色器的重建字节保持一致。
两种配置的着色器二进制也逐字节一致。
原有热重载事务检查通过。

## 独立验证

CPU 检查覆盖基础集合、全部功能位和未知输入。
计算夹具分别验证完整路径及基础集合路径。
十二种输入的二十四个 GPU 结果逐值一致。
其中包含自发光、中性、视图标志及未知位。

两配置的选择规则及 GPU 检查通过。
两种配置的角色与主场景均与冻结图像逐字节一致。
主颜色专用程序使用 128 个寄存器，体积为 100,864 字节。
原有三管线方案使用 168 个寄存器。

四样点候选与前置三管线候选逐字节一致。
其相对冻结原图的四处一字节差异保持原值。
既有平坦区预算与严格整图门禁分别记录。

可玩入口完成十六帧输入回放。
动画状态、位置、四次输入及固定步进与基线一致。
七帧各有一处一字节差异，其余九帧逐字节一致。
相对前置方案新增两处动态残差，严格门禁继续待验。

两配置各完成七项契约检查及一项热重载检查。
每配置另有三十六次 NPR、二十六次反射探针采集。
八次文档覆盖及自发光替换采集也通过。
固定与索引纹理路径均保持原有数值预算。

## 实验记录

仅接纳中性标志的实验未覆盖热点功能值。
其同批模式一 P95 为 75.95 毫秒，冻结基线为 62.64 毫秒。
该结果保留为未晋升实验。
当前方案包含自发光遮罩，同批 P95 为 57.40 毫秒。
其较冻结基线降低约 8%，60 帧预算保持未通过。

验证还发现共享头文件的改动缺少增量编译依赖。
构建接入编译器依赖文件后，双配置的 GPU 红测转绿。
重建范围、产物一致性及运行画面分别保存结果。
严格整图残差与正式预算继续按 AA6 和 NR12 核验。
