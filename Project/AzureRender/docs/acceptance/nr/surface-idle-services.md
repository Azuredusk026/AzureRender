## CPU 验证

初始红测确认等待未使用受控时间间隔。
生产辅助函数使用最多 50 毫秒的事件等待。
等待回调在同一宿主线程执行。
测试直接使用生产验证与编辑任务服务。

| 情况 | 结果 |
| --- | --- |
| 表面有效 | 立即返回，事件等待为零次 |
| 连续零尺寸 | 每轮使用定时事件等待 |
| 原生关闭 | 终止等待并返回失败 |
| 文档关闭就绪 | 终止等待，跳过后续事件等待 |
| 查询帧号 | 等待期间返回固定帧号 17 |
| 编辑任务就绪 | 等待期间完成生产任务提交 |
| 帧请求期限 | 墙钟期限到达时返回 `Timeout` |
| 等待一帧 | 帧号固定时保持待处理 |
| 恢复帧推进 | 帧号到达 18 后完成请求 |

两种配置各执行两项 CTest。
`SurfaceLifecycle` 和 `Observation` 全部通过。
Debug 用时 0.18 秒，Release 用时 0.11 秒。
本轮构建范围为对应 CPU 测试目标。
