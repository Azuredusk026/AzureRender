# 联合场景材质纹理内存分配

日期为 2026-11-14。隔离 Release Player 以 `01cc6b2` 的计算材质构建为基础，仅替换图像分配实现。着色程序、主线产物和冻结场景的 1,729 项输入通过摘要检查。

## 分配范围

NVIDIA RTX 4060 Laptop GPU 的 595.79 驱动允许两种 RGBA8 格式在非设备本地内存保留完整层级及优化平铺。运行时夹具核对大图像的实际分配、小图像和渲染附件的本地分配，以及 NVIDIA 关闭选项和 Intel 路径的默认分配。验证层与释放检查通过。

联合场景中有 224 张纹理使用非本地内存，分配载荷为 1,588,625,408 字节。1440p 的四帧 PNG 与同驱动参考逐字节一致，本地内存峰值为 1.589 GiB。与 592.82 生成的冻结四帧仍分别有 228、330、397 和 421 个差异像素，最大 RGB 差依次为 1、7、37 和 23。

## 1080p60 短时配对

固定 80 W，按本地、非本地、本地顺序各执行 120 帧，统计末尾 60 帧。三轮均正常退出，缓冲和图像计数归零。

| 指标 | 本地首轮 | 非本地 | 本地末轮 |
| --- | ---: | ---: | ---: |
| GPU 帧均值 | 16.09 ms | 15.98 ms | 15.84 ms |
| GPU 帧 P95 | 16.57 ms | 16.23 ms | 16.13 ms |
| CPU 工作 P95 | 5.36 ms | 5.38 ms | 5.38 ms |
| 设备本地内存峰值 | 2.593 GiB | 1.343 GiB | 2.593 GiB |

候选 GPU 均值位于两轮本地对照之间。三个短窗口均无软件热降频。计时变化需按测量波动解释。

## 1080p60 持续采样

300 帧预热后连续统计 1,800 帧，实际功率上限为 80 W。卸载后的缓冲和图像计数均为零。

| 指标 | 门槛 | 实测 |
| --- | ---: | ---: |
| GPU 帧 P95 | ≤ 16.6 ms | 18.61 ms |
| CPU 工作 P95 | ≤ 8 ms | 7.53 ms |
| 设备本地内存峰值 | ≤ 1.5 GiB | 1.343 GiB |
| 进程峰值工作集 | ≤ 2 GiB | 1.899 GiB |
| 软件热降频观测 | 0 | 15 |

本地高水位较同场景对照减少 1,342,177,280 字节。GPU 最高温度为 88 °C。首个软件热降频读数约在开始渲染 32 秒后出现，热段高负载读数的核心频率中位数为 2,235 MHz。第 241 至 300 帧的 GPU P95 为 16.45 毫秒，最后 300 帧为 18.73 毫秒。对应的场景阶段均值为 14.21 和 15.78 毫秒，阴影阶段均值为 1.69 和 2.19 毫秒。

## 稀疏层级分配

NVIDIA 独立夹具验证 RGBA8 两种格式的完整本地、完整非本地和按层级混合分配。4096² 图像的最高两级使用非本地内存，其余层及尾部使用本地内存。整数取样、线性取样、显式梯度与跨层线性取样结果逐位一致。两种格式各核对五类样本、三个提交位置及三种分配，验证层通过。

按已捕获图像尺寸及设备的稀疏页规则估算，224 张纹理的最高两级需要 1,488,977,920 字节非本地内存，其余层和尾部需 109,051,904 字节本地内存。该值为绑定容量估计。整帧着色、设备本地高水位和性能以实际运行核验。

冻结画面、热状态和 GPU 帧时延继续按原门槛验收。候选保留在独立构建及复测归档。
