# 场景资源路径成本

## 来源与测量

受检源码为 `27fe011`。
私有宿主在完整联合场景中分开记录物化及路径解析。
观察范围为第 310 至 329 次解析调用。
调用序号独立于实际帧号。

每次有三百七十四份资源和一千六百七十九个节点。
输入路径全部为绝对路径，总长度为 65,685 字节。
二十次文档物化的均值为 1.339 毫秒。
同批路径解析循环的均值为 3.353 毫秒。

路径循环使用正式 `ResourceLocator` 接口。
绝对路径仍逐次进入文件存在性查询。
该成本支持优先验证加载会话的路径结果复用。
采用前须覆盖失效、失败及原生图像条件。

后续独立诊断仅用于 CPU 阶段归因。
该批发生软件热降频，正式环境资格未通过。

私有采集完成四百二十帧，并保留原始计时。

该批整帧数据属于诊断范围，原帧预算保持有效。
