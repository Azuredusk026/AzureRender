# 运动向量绑定验证

## 实现范围

`MotionVectorPass` 在单次调用内复用连续相同的绑定。
管线、描述符和推送数据由该过程拥有。
每次调用从未知绑定状态开始。
变体切换及回切保持原绘制顺序。

该过程同时服务反射重投影与时间重建。
外部 Vulkan 命令与图执行保持各自状态边界。
实施见[运动向量命令绑定](../../plans/2026-11-05-motion-bindings.md)。

## 自动检查

新增检查在原实现上因重复绑定失败。
候选通过连续复用、变体切换及调用边界检查。
Release 与 Debug 完整来源构建通过。
两配置各五项 CPU 检查通过。

两配置在 NVIDIA 与 Intel 上各通过两项 GPU 检查。
运动向量、历史接收与共享附件均走实际 Vulkan 路径。
四帧原生联合输出与冻结参照逐字节一致。
两配置各 535 份生产着色程序保持基线字节。
