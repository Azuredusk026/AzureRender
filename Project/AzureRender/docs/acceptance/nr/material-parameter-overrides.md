# 公共材质参数覆盖验收

日期：2026-10-22。范围为 NR6-C15 的覆盖语义。
版本 1 保持完整替换，版本 2 声明稀疏参数覆盖。
实现复用资产、材质图及编辑操作，渲染布局保持兼容。
完整角色画像的文档表达及统一 Schema 继续实施。

## 运行契约

参数覆盖以所绑定的源材质为输入。
仅显式字段参与修改，其余数据保持继承。
SDF、头发、色带、镜面来源和渲染状态保留原语义。
颜色和金属粗糙度字段作为源像素乘数。

创建菜单提供参数覆盖类型。
表单勾选字段、图端口和编辑操作共用资产文档。
撤销、重做及保存重开保留稀疏字段和模式。
不兼容透射组合在源材质解释时拒绝。

未知字段、空值文档和不支持的版本均被拒绝。
空值编辑用于移除已知覆盖字段。
完整替换的特殊效果丢失诊断保留。
显式参数修改使用对应覆盖语义。

## 检查结果

产物位于以下目录：

```text
build/runs/20261022-233112-material-contract-completion-817c3c/
```

编辑创建测试首先因未知 `mode` 失败。
材质图测试首先因稀疏字段丢失失败。
另有误报完整替换及未知纹理重置的失败记录。
修复后四项材质 CPU 检查通过，模块边界检查通过。

两种类型分别覆盖完整替换和参数覆盖的材质图编辑。
文档中的两段 JSON 由实际材质解析器验证。
Release 编辑器与 Player 构建通过。

编辑器输入回放覆盖创建、勾选、恢复继承和撤销。
首次回放发现撤销按钮位于滚动裁剪区域。
按钮固定在面板底部后，完整回放及两个 Player 运行通过。
实体键鼠与正式发布打包属于集中验收范围。

GPU 夹具使用带独立镜面来源的服饰表面。
八次捕获覆盖两种描述符及四种自发光输入。
完整替换、参数覆盖与 glTF 原始自发光逐像素一致。
关闭覆盖自发光得到零贡献，两个描述符结果一致。

线性误差最大为 `0.0025345369341468194`。
验收预算为 `0.004`。
各次卸载均为 `buffers=0 images=0`。
未发现 Vulkan 验证错误和脚本错误。

实际角色采用主线 `hero-hair-linear-212213.glb`。
覆盖所有源槽的单位颜色及金属粗糙度乘数。
两次 1920×1080 完整画面逐像素一致。
该结果证明源语义保留，原生外观等价仍按技术点验收。
