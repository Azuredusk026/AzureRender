# 体表法线原生选层

原生帧 10401 的事件 328 读取 BC5 法线。
参考区域包含 9,116 个体表位置。
深度误差至多一个末位单位的 7,997 处用于选层对照。
源纹理和采样器见[体表接收法线纹理](native-body-normal-source.md)。

## 实际选层

两块显卡各读取十一层显式样本。
复制程序与恢复后的原始附件逐字节一致。
每个受检位置至少有一层复现隐式压缩法线。

| 设备 | 唯一匹配层级 | 多层匹配 | 轴向欧氏模型逐位一致 | 轴向与对角模型逐位一致 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 5,688 | 2,309 | 7,653 | 7,996 |
| Intel | 5,662 | 2,335 | 7,979 | 7,640 |

两设备隐式附件有 1,609 处差异。
该统计覆盖完整体表位置。
显式层级相同时，设备间仍有法线差异。

## 解码精度

第零级的 NVIDIA 小数模型匹配 6,884 处。
八位舍入模型匹配 4,671 处。
Intel 的两项结果分别为 7,805 和 4,891。
各层统计使用同一图元和压缩法线规则。

参考接收继续核对实际深度、法线和图集。
生产可见量采用逐通道一字节门槛。
