# 材质朝向管线需求验证

日期：2026-11-09。
状态：实现及受影响检查通过，正式帧预算待验。

## 实现与契约

角色渲染器按已加载材质收集朝向需求。
普通不透明材质与各材质类别分别持有需求。
每种单双面需求均保留正常与镜像朝向。
同组混合单双面材质时保留四个朝向。

主颜色、快照及提前深度共用该需求范围。
附加资源参与同一次收集。
材质绑定属于资源布局身份，改变后重新加载。
场景复用、交换链重建及卸载沿现有生命周期执行。

## 受影响验证

独立回归先复现单种材质预建四个朝向。
两配置各通过二十四组加载及交换链重建组合。
范围覆盖普通与类别、单双面混合及剔除开关。
固定纹理与索引纹理路径同时覆盖。

同场景加入相反单双面的第二材质组。
需求按各组分别核对，镜像正面定义保持完整。
每个实际创建的管线均核对一次销毁。
卸载后的缓冲和图像计数为零。

两配置各通过材质提前深度及原策略回归。
提前深度回归继续覆盖透明度及四样点。
Debug 与 Release 的全部主着色器保持原字节。
主着色器数量均为六百七十五。

原生四帧的 RGB 差异均为零。
四张 PNG 摘要均与原件一致。
全部一千七百二十九项项目输入摘要保持一致。
原生验证层无错误，分配器卸载计数归零。
