# 头发虚拟主灯与条纹验收

日期：2026-10-23。范围为 NR6-C16、C17。
公共表面接收方向、对象帧及具名材质输入。
转换工具负责原生字段身份和参数换算。
完整环带形态仍按 C17 的联合条件验收。

## 原生依据

依据为官方锚帧 10401 的事件 950。
像素程序的 1175 至 1196 条指令形成虚拟半角向量。
1219 至 1248 条指令形成发丝条纹调制。
条纹图绑定于 t12，资源身份为 `20170`。

条纹资源为 512×512 的 `BC7_UNORM`。
官方回放导出的 PNG 作为候选线性输入。
CB6 的第 16 至 18 行给出形状、颜色及 UV 参数。
CB1 的对象增益在当前帧为 1。

主灯虚拟方向消费视线在对象 X、Z 轴上的投影。
对象 Y 分量由 `0.5` 与主灯世界 Y 分量混合。
对象轴重建方向后，再混合主灯并归一化。
该方向与视线形成半角向量。

混合量来自宿主明确提供的材质适配。
局部灯继续消费实际入射方向。
动态阴影场形成混合量的路径保持专项待验。
对象增益同时作用于两个专用高光叶。

条纹使用有符号偏移后的发丝方向形成叶函数。
交替条纹与贴图 R 通道通过具名权重混合。
主高光带的最大 RGB 分量保护已有亮区。
最终倍率及饱和度作用于指定的漫反射贡献。

该宿主按已选主灯计算一次环境调制。
`diffuseTarget` 默认选择环境漫反射。
`main-and-ambient` 同时选择环境和已选主灯。
局部灯与其他方向灯保留各自的漫反射贡献。
无方向主灯的场景保持无条纹环境调制。
GI 体积参与后，条纹作用于组合后的环境量。
完整原生照明能量仍归 C11。

## 材质与资源

`hair.projectedRamp.virtualLight` 使用版本 1。
其字段为 `schemaVersion`、`blend`、`objectGain`。
`blend` 范围为 0 至 1，增益范围为 0 至 16。
可选字段缺省时使用现行普通半角向量。

`hair.projectedRamp.line` 使用版本 1。
完整字段如下：

| 字段 | 范围与含义 |
| --- | --- |
| schemaVersion | 整数 1 |
| texture | 合法 glTF 纹理索引 |
| frequency | 0 至 65536，原始 U 方向条纹频率 |
| strandShift | -1 至 1，有符号发丝偏移 |
| range | 0 至 1，叶函数宽度 |
| depth | 0 至 1，调制深度 |
| alternation | 0 至 1，交替条纹与贴图的混合量 |
| diffuseTarget | 可选；`ambient` 或 `main-and-ambient` |
| saturation | 0 至 16，调制颜色饱和度 |
| uvTransform | 四个有限数，分别为缩放及偏移 |

独立条纹占用槽 8，与影色查找表互斥。
非法引用、缺少字段及冲突在加载时拒绝。
固定与索引描述符消费同一纹理缓存和采样语义。
九槽预算及材质资源退休规则保持有效。

完整材质文档通过同一解释器接入这些字段。
纹理索引转换及 UUID 图片依赖沿用 C15。
GPU 表版本、偏移及所有权见[材质输入](../../runtime/material-input-layout.md)。
