## 公共契约

缺失组合接口的首次编译按预期失败。
CPU 验证预算、格式、参数、历史槽位及图像别名。
非法记录先于描述符和命令变化而拒绝。
子组件构造失败及完整对象关闭均回收资源。

独立 GPU 镜面真实取消一次完整录制。
随后直接重录并提交，覆盖分帧资源和参数。
验证层、缓冲及图像计数均为零。
相机、表面和来源的既有门槛保持有效。

## 完整组合对照

一条路径调用公共组合对象。
另一条路径逐个装配已验证的公共组件。
两条路径使用相同几何、参数和原始输入。
分别读回颜色、足迹、可信度及最终浮点过滤结果。

每配置对照八项案例，共 15,360,000 字节。
四类输出均逐字节一致。
当前模式还核对一像素零运动与全尺寸零场的等价性。
历史模式在同一提交中先生产前帧，再消费独立槽位。

错误位姿和遮挡分别验证变换及前帧深度的真实消费。

前四项使用既有镜面的尺寸和尺度。
后四项使用十分之一几何尺度，核对深度拒绝门槛。
全部过滤像素要求有限、非负，可信度位于 `[0,1]`。
这些检查属于公共计算输出，主场景合成另行验收。

## 过滤通道控制

独立错误注入将足迹选择从 G 通道接到 R 通道。
原始命中仍为 2,432，最终过滤命中降为零。
预定的镜面门槛直接拒绝该输出。
正确通道恢复后按同一门槛执行双配置回归。

该控制验证组合中的过滤输入及通道选择。
边缘宽度变化还核对完整图像的可信度响应。
颜色及足迹保持一致，可信度逐像素不增。
运动和几何拒绝均通过实际 GPU 读回判断。
