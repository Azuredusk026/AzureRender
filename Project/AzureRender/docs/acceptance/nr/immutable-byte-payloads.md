## 构建与 GPU 结果

定稿源码构建实际 Debug 与 Release 宿主。
两配置各十三项所属回归通过，跳过项为零。
NVIDIA 与 Intel 的两配置各通过 648 组 GPU 条件。
每组包含 486 份原始载荷及 162 份压缩载荷。

每组设备与配置完成 10616832 次分量逐位比较。
其中 504 组实际消费收窄纹理表示。
验证检查包含告警、错误及销毁边界，结果均为零。
Intel 两配置另各通过 317 项表面响应检查。

773 份既有 SPIR-V 产物摘要保持一致。
十三份用户保护文件摘要保持一致。

GPU 字节等价与加载容量分别验收。
