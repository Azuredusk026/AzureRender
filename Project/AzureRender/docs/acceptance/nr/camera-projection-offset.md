日期：2026-10-23。范围为 NR6-C16-R2。
公共投影与实际输入对齐通过验证。

事件 950 的实际顶点常量提供投影矩阵。

四个真实片元的位置复算支持同一偏移。
原始常量文件、摘要和矩阵保存在验证收据。

配置及共享消费见[运行契约](../../runtime/camera-projection-offset.md)。

双配置各十一组 CPU 与模块边界检查通过。
检查覆盖迁移、非法输入、取景、保存重开及预览。

双配置各十四次公共相机 GPU 捕获通过。

固定描述符及版本一的对应画面逐像素一致。

双配置各三次局部灯及三次主光阴影检查通过。
偏移后的局部灯在移动位置保持可见正贡献。
主光遮挡、无阻挡及旧相机分别与独立公式比较。
运行日志核对校验状态、诊断与资源释放。
主项目的一次 1280×720 捕获与既有基线逐像素一致。

## 真实角色

基础色与法线各完成一次 2560×1440 捕获。
发梢基础色的最大线性误差由 0.017602 降至 0.000809。
四点法线的最大分量误差由 0.056112 降至 0.006035。
数值以八位图像解码，量化误差保留在结果中。

五次完整角色捕获覆盖完整画面、高光及边缘分项。
完整材质文档与固定描述符画面逐像素一致。
发冠选定像素与参考均为 `[231,105,104]`。
主项目仍按 NR8-V2 的完整外观条件接收候选。

发冠区域的编码 RGB 平均误差为 0.051356。
同区域的零偏移九灯候选误差为 0.050188。
投影对齐改善片元输入，完整区域仍存在合成差异。
剩余边缘能量、暗区及覆盖层按真实追踪继续定位。
