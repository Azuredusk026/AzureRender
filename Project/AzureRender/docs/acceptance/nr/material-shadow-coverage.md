# 材质投影覆盖验证

日期：2026-10-23。范围为 C16-R4-R1 的覆盖输入。
公共材质支持完整几何与平方根 Alpha 投影。
原生对象图集及接收过滤继续按独立门禁实施。

## 输入与归属

材质画像版本二通过互斥特征选择覆盖方式。
参数见[角色材质画像](../../runtime/character-material-profile.md)。
解释器、完整文档和稀疏覆盖共用该契约。
渲染器按显式覆盖声明接纳乘色表面的投影。

阴影片元采用基色纹理 Alpha 及节点透明度。
完整几何覆盖继续消费节点的几何空间覆盖。
平方根覆盖使用确定性像素噪声。
噪声固定浮点运算顺序与常量位模式。

特征占用现行材质标志位。
材质保持版本六、192 字节及九纹理槽。
灯和实例保持版本三与版本一。
本项资源归属沿用阴影绘制与材质生命周期。

## 原生证据

十次对象投影中，九次采用完整几何覆盖。
一次服饰投影采用 Alpha 平方根与梯度噪声。
四个真实片元已提取 Alpha、平方根及噪声。
运算顺序由原始片元程序及调试轨迹确认。

自动乘加融合会改变噪声，需显式约束运算。
数值探针覆盖四个真实位置与四个真实 Alpha。
原有误差预算保持生效。
捕获对象名及源身份保存在离线候选数据中。

## 验证入口

公共图像检查通过生产 Player 运行。
CTest 名称为 `AzureEngine.MaterialShadowCoverageGpu`。
独立运行命令如下。

```powershell
python tools/test_material_shadow_coverage_gpu.py --executable build/ninja-msvc-release/AzurePlayer.exe
```

夹具覆盖缺省、完整几何及平方根 Alpha。
另有完整文档、织物、乘色及节点透明度组合。
固定描述符路径与完整文档图像须逐字节一致。
每次运行检查验证层、运行错误及卸载归零。

## 验收范围

双配置各七组 CPU 与各 260 个数值探针通过。
覆盖、透明度与 NPR 阴影图像合计四十六次。
真实角色、固定路径与主场景另有实际捕获。
日志、图像摘要及数值见[结构化收据](evidence/2026-10-23/material-shadow-coverage.json)。

完整原生皮肤与角色画面仍有独立对象阴影待项。
