# 头发参数与双法线选层

原生帧 10401 的事件 950 使用相同的 UV、采样器和层级偏移读取参数纹理 `t17` 与双法线纹理 `t18`。固定着色程序分别核对参数纹理和两份纹理的选层。轴向与对角足迹沿用参考头发的半层规则。两组控制共用同一 Player、材质、纹理、采样器和参考通道。

## 冻结颜色

受检范围包含 17,017 个冻结头发位置，逐通道容差为一字节。两种控制在每台设备各采三帧。五类参考附件在全部控制中逐字节匹配基线。NVIDIA 的六张完整 PNG 逐字节匹配基线。

| Intel 控制 | RGB 超差 | 进入门槛 | 新增超差 |
| --- | ---: | ---: | ---: |
| 冻结基线 | 568 | 0 | 0 |
| 参数纹理 | 528 | 53 | 13 |
| 双法线纹理 | 449 | 166 | 47 |
| 参数与双法线纹理 | 393 | 215 | 40 |

联合控制使双法线单项的 47 个新增超差位置中有 12 个进入门槛。两组单项均超差的位置中，有 20 个在联合控制中进入门槛。基色纹理 `t16` 在原生事件使用同一采样契约，基色 RGB 的独立及联合控制继续验收。
