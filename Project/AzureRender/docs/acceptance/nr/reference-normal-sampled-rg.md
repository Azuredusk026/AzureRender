# 参考法线采样后重建

版本二材质画像使用 `referenceNormal` 声明参考法线编码。
画像指定标准 `normalTexture`，参考通道使用对应采样器。
片元采样红绿分量后重建正向 Z，并使用插值法线和切线转换。
参考光栅的背面朝向作用于完整法线。

## 独立对照

64 × 64 平面使用固定切线帧和具有已知红绿蓝分量的法线纹理。
默认 RGB 输出的八面体编码为 `[673, 243]`。
采样 RG 重建的输出为 `[675, 777]`，与解析值完全一致。
固定纹理与索引纹理输出逐字节一致。
画像门槛核对版本一、版本二、字段集合及合法编码。
完整材质替换报告丢失的参考法线声明，参数覆盖继承该声明。

## 冻结接收区域

事件 377 的最后法线覆盖 16,629 个位置。
完整接收区域包含 49,384 个位置。
可见量和颜色采用每通道一字节容差。

| 设备 | 服饰法线区域超差 | 服饰法线区域新增超差 | 完整接收超差 | 完整头发可见量超差 | 完整头发颜色超差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVIDIA | 158 | 24 | 520 | 0 | 0 |
| Intel | 224 | 18 | 851 | 208 | 575 |

NVIDIA 的服饰区域有 13,919 个法线位置处于一个编码单位内，Intel 有 12,766 个。
深度、对象身份、冻结头发的可见量与颜色逐字节匹配固定对照。
其余原生法线写入区域的可见量逐字节匹配固定对照。
同一设备的 Release 与 Debug 对应附件和三帧颜色逐字节一致。
完整接收及联合画质状态为 `failed-user-review`。

## 回归

Release 通过八项 CPU 检查，Debug 通过七项 CPU 检查。
两种构建在两块设备上各通过五项 GPU 检查。
默认场景的原始四帧 PNG 逐字节匹配冻结摘要。
程序目录包含 895 项，参考可见量使用固定和索引两份片元程序。
其余 893 项程序逐字节匹配固定对照。
