# 阴影过滤预取评估

本单元归属于 RenderCore 的阴影接收过滤。
候选交错发出两个相邻四元组的深度读取。
两个结果依照原顺序完成比较、权重乘积及累加。
末尾单个四元组独立处理，原零权重条件保持有效。

实际深度图在当前绘制期间只读。
预取状态属于当前片元的当前循环。
普通主颜色与不透明反射快照共同消费该机制。
操作依据为 [NVIDIA 的纹理读取批次建议](https://developer.nvidia.com/blog/the-peak-performance-analysis-method-for-optimizing-any-gpu-workload/)。

十一份程序通过 SPIR-V 校验。
私有管线的片元寄存器数为一百二十八。
机器代码为 113280 字节，原私有控制为 108928 字节。
编译查询没有队列提交，验证错误为空。

九项附件均逐字节一致。
各阶段采用连续三次百分之三以内的稳定预热条件。

匹配均值下降约 0.50%，两端基线相差约 0.49%。
该结果未达到集中原生评估的收益门槛。
候选保持隔离，原生四帧及正式性能测试未启动。
本项不能证明纹理延迟或寄存器占用为实际主导原因。

实际附件与计时批次用时约五十九秒。
环境检查错误为空，源文件及主构建摘要保持一致。
