## 身份与并发

可见量保留完整单精度位模式。
原子占位确定同像素记录的唯一写入者。
前一帧记录与当前帧写入使用不同的缓冲。

五项策略检查覆盖有界身份、视图和布局失效。
两种投影分别检查二千零四十八个内部点。
过滤扩展、无效投影及空区域也纳入检查。
不同写入顺序的枚举控制复现普通双字写入撕裂。

两设备各完成四万九千一百五十二条片元记录核对。
范围包含单层、三十二层及一百二十八层重叠三角形。
两套工作流分别重置、写入并回读。
片元记录未撕裂，验证层与释放计数均通过。
