## 实际角色

角色输入沿用[分量核验](component-radiometry.md)的冻结来源。
官方头发可见遮罩固定内部与一像素边界。
1280×720 输出与 5120×2880 参考分别采集。
高光隔离固定负四 EV，并保留三倍显示系数。

末八帧按同一遮罩逐相位统计。
两种构建配置的三十二帧逐字节一致。
下表为专用管线的逐相位结果。

| 固定区域 | 八相位能量比 |
| --- | ---: |
| 发冠 | 0.99473–0.99685 |
| 头发内部 | 0.99092–0.99264 |
| 细发边界 | 0.98228–1.00760 |

三个区域的每个相位均满足 2% 门禁。
这些结果只证明当前固定机位的高光能量。
原生完整画面、运动残差及服饰另设验收。
多机位环带位置、宽度与峰值继续核验。

发冠峰值为独立参考的 0.99637。
细发边界峰值为独立参考的 0.95044。
峰值、环带宽度与运动残差保持独立待项。
