# 环境权重与主灯条纹验证

日期：2026-10-23。范围为 NR6-C11、C16 和 C17。
本项验证全局环境权重和条纹的贡献归属。
原生完整颜色、动态机位及晋升继续逐项验收。

## 输入与职责

10401 帧的环境权重来自全局常量。
`cb1[29].x` 与 `cb1[122].w` 形成混合量。
结果乘以 `cb1[27].x`，本帧为 0.2877224684。
该值通过场景的 `nprLighting.ambientWeight` 接入。

默认值为 1，合法范围为 0 至 16。
环境响应消费该权重，主灯直接照明独立计算。
屏幕遮蔽和材质遮罩保留各自的输入职责。
本帧的预览环境分支使用常量颜色。

事件 950 的指令 1271 至 1276 调制完整漫反射。
条纹通过可选字段 `diffuseTarget` 选择贡献。
`ambient` 为默认值。
`main-and-ambient` 选择环境和已选主灯。

所选主灯通过稳定身份对应 GPU 灯光索引。
局部灯和其他方向灯保留各自的贡献。
KK、镜面及自发光保持独立的合成职责。
原生转换器为活动条纹声明完整漫反射目标。
