# 绘制批提交范围

## CPU 成本口径

本单元复用既有一百二十帧参考记录。
CPU 工作均值约为 6.242 毫秒。
录制窗口约为 1.574 毫秒，占约 25.21%。
窗口包含图准备、工作线程及主线程执行。

| 窗口分项 | 每帧均值，毫秒 |
| --- | ---: |
| 图准备 | 0.653651 |
| 线程工作及等待 | 0.479413 |
| 主线程执行 | 0.440524 |

线程区间约占 CPU 工作的 7.68%。
该区间包含调度及等待，并非纯绘制驱动耗时。
批提交收益须按实际受影响部分建立依据。
完整窗口的占比单独用于描述总规模。

## 绘制与实现范围

每帧约有 1845 次绘制及 3706 次推送更新。
历史主颜色的 655 项材质记录形成 98 个管线段。
快照的 354 项记录形成 79 个管线段。
这些段还会受几何绑定及逐绘制数据拆分。

现有几何采用逐资源顶点和索引缓冲。
跨资源批提交需要共享几何及逐绘制数据契约。
材质顺序、设备能力及帧槽生命周期共同决定资格。
当前结果属于乐观范围，实际可合并数量继续核定。

## 状态与接续

批提交保持提案状态，原生准入依据尚未成立。
本单元新增构建、GPU 测量及原生进程均为零。
生产源码、着色程序及现有验收状态保持原值。
CPU 八毫秒、GPU 16.6 毫秒及原画质标准有效。
