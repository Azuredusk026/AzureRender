# 时序运动与历史接入验证

日期：2026-10-24。
范围为 NR7-AA1 至 AA3 的公共接入机制。
材质细节、运动画质及正式入口晋升继续验收。
运行契约见[时序抗锯齿](../../runtime/temporal-antialiasing.md)。
程序、着色器和原始检查见[证据清单](evidence/2026-10-24/temporal-reconstruction-integration.json)。

## 公共契约

场景渲染器采用 API 版本四。
注册器拒绝版本一、二、三。
渲染设置采用版本十八，并提供模式三。
关卡编码、版本迁移和部分覆盖分别验证。

视图拥有七份独立纹理分配。
纹理预算为每像素 52 字节。
资源超限、缺失运动能力及不可采样格式分别检查。
空间回退保持正常提交与资源释放。

硬件深度的只读加载保持全部测试像素。
附件存储按深度写访问同步。
渲染图另提供片元统一缓冲读取语义。
基础顶点、材质和实例表的布局保持现行契约。

## GPU 与生命周期

前帧姿态检查包含二十六组和三种缓冲变体。
共核对 1,560 个标量，预算为 `1e-6`。
输入覆盖关节、形变、镜像、Gizmo 和眉毛位移。
描边包含固定宽度、距离宽度及深度偏移。

实际运动附件核对 18,750 个标量。
独立平移、无效前帧、响应像素及描边分别比较。
实际 HDR 合成核对 20,480 个输出标量。
历史混合、当前 Alpha、透明响应和切镜重置分别检查。

两个公共资产分别渲染十帧。
各视图完成八相位采样及独立历史提交。
后续检查包含相机移动、取消与尺寸重建。
GPU 校验通过，卸载后的缓冲和图像分配归零。

Debug 与 Release 各通过十八项受影响检查。
Player 与编辑器均完成两种构建。
缺失运动能力与格式回退使用生产视图入口。
辅助视图的帧槽由实际录制上下文确定。

## 真实角色

两种配置各记录十六帧模式三画面。
Debug 使用固定描述符与顶点蒙皮。
Release 使用索引描述符与计算蒙皮。
历史提交号达到十六，活动前帧对象数为一。

2560×1440 的时序纹理占用为 191,692,800 字节。
实际入口通过 Vulkan 校验及卸载归零检查。
两种配置的第零、十五帧逐字节相同。
第七帧仅有一个通道相差一个输出字节。

两种配置的模式零均保持冻结画面的完整指纹。
时序首帧与该模式零基线逐字节一致。
七十七份着色器在两种配置间具有相同指纹。
其中既有六十九份保持冻结产物指纹。

官方材质事件为 950，时序输出事件为 1579。
头顶区域包含 7,344 个固定遮罩像素。
其官方时序颜色平均误差由首帧 4.75 降至 3.71 字节。
全头区域平均误差由 6.36 降至 5.17 字节。

这些区域误差包含材质、覆盖和历史内容差异。
其结果独立于高采样参考的抗锯齿验收。
完整头发、细发丝和服饰的质量门禁保持待验。
C17、C18 与 NR6 的整体验收保持未通过。
