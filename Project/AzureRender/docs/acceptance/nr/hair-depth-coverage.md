# 头发深度覆盖与边缘光

日期：2026-10-26。范围为 NR6-C18 的实际覆盖核对。
参考为官方帧 10401 的事件 422、440 和 950。
公共距离投影与片元覆盖分别验证。

## 原生输入

顶点描边图为资源 `23875`，提供连续宽度变化。
片元裁剪图为资源 `23880`，提供独立覆盖。
两张图均为 512×512 的线性 BC7。
片元图具有十个原生层级。

普通深度 422 与外扩深度 440 使用同一裁剪图。
片元采样采用线性过滤、最近层级及重复寻址。
着色器叠加负一层级偏移，并丢弃小于 0.5 的红值。
顶点宽度采样使用其独立的零级输入。

显示坐标 `[1320,170]` 对应原生 `[1320,1269]`。
原生普通片元和外扩片元均在此处丢弃。
该位置的后方深度约为 26.52 米。
头发边缘光以此深度计算可见响应。

## 数据接入

片元覆盖复用标准材质的 `MASK` 和 0.5 阈值。
原生裁剪图红值进入基础颜色的线性透明通道。
基础颜色采用带 sRGB 标记的 RGBA8 DDS。
十二级颜色的编码 RGB 按字节保持一致。

`coverage_mips` 位于角色表面转换模块。
输入为已解码的两套完整层级。
函数校验尺寸、二次幂对齐和完整链。
采样器、容器编码和来源收据由调用方持有。

2048 基础图的第二级对应 512 裁剪图的零级。
第二至第十一级直接保存对应原生裁剪图素。
零级和第一级采用双线性放大。
这两级的完整覆盖等价性保持独立门禁。

基础颜色的透明通道须由覆盖独占。
纹理坐标、层级过滤及偏移须与源覆盖匹配。
共享采样器无法表达的组合需单独设计和验证。
当前资产通过既有材质、缓存及深度通道消费。

## 实际捕获

候选 Vulkan 捕获已保存实际执行后顶点和附件。
普通深度与着色顶点的裁剪坐标逐分量一致。
原生普通投影的最大屏幕误差为 `0.000473` 像素。
原生扩张投影的最大屏幕误差为 `0.000758` 像素。

实际扩张的中位数为 `0.661973` 像素。
最大扩张为 `0.881803` 像素。
两个弱边缘光采样点的视深度误差小于七微米。
对应源深度约为 `3.230851` 和 `3.231997` 米。

正确裁剪候选在 `[1320,170]` 丢弃普通及外扩片元。
六个冻结强边缘光点的最大误差为一字节。
Debug 与 Release 的完整候选图像逐字节一致。
上传、运行诊断和卸载另存对应日志。

## 完整区域

发冠区域包含 7,344 个可见像素。
误差 95 分位为一字节，最大值为 17 字节。
完整头发区域包含 17,017 个像素。
误差 95 分位为 21 字节，最大值为 44 字节。

完整头发的一字节门禁继续验收。
原生普通深度和着色使用背面剔除。
头发通过 `doubleSided: false` 声明该状态。

剩余重点为局部覆盖边界、颜色轮廓和多层高光。
抗锯齿同时检查原生层级及运动中的覆盖稳定性。
动态主项目的跨入口质量归属 NR8-V2。

第六版主候选保留九条动画及 327 个节点。
几何、蒙皮、节点和动画保持同一来源。

主入口及可玩入口使用十三份完整材质文档。
可玩输入回放完成十六帧及约 1.156 米移动。
176 个动画帧及 112 个固定步完成运行检查。
头发基础图及其 UUID 依赖进入完整文档。
