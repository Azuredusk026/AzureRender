# GPU 稳定排序机制验收

## 实现范围

本阶段入口为 `16f6f18`。
RenderCore 提供 `GpuStableKeySort`。
输入为分段的无符号整数键及附属值。
同键记录保持原输入顺序，段之间独立排序。

排序器采用逐轮并行归并。
每项通过对侧区间的二分位置确定独立输出。
相同键的左右区间采用确定的先后规则。
算法只使用三十二位整数及基础计算能力。

最多处理 1048576 项及 65536 段。
内部缓冲逻辑总池至多为 64 MiB。
资源按帧槽独立持有，调用方负责槽退役。
输入、输出及失败恢复见[公共契约](../../development/gpu-stable-key-sort.md)。

## 集中验证

Debug 与 Release 的所属目标构建通过。
每配置执行一项录制检查及两项设备检查。
六项 CTest 全部通过，着色程序校验通过。
模块边界核对覆盖十八个目标，违规数为零。

每设备每配置核对四组、共 22325 条记录。
整数键及浮点深度编码分别采用独立 CPU 参考。
范围包含非二次幂、空段、重复键及正负零。
帧槽切换及同槽范围变化、复用均保持相同顺序。

设备为 RTX 4060 Laptop 和 Intel UHD Graphics。
四份 GPU 结果均逐记录、逐附属值一致。
同步验证错误为零，卸载后图像和缓冲均为零。
既有 665 份着色程序在两配置均保持原字节。

## 接续范围

当前交付为通用稳定排序机制。
透明场景继续采用既有 CPU 准备路径。
变形、深度键、索引写入及场景收益仍需验证。
本阶段未启动原生画面、帧计时或正式性能采样。

整体画质保持 `failed-user-review`。
