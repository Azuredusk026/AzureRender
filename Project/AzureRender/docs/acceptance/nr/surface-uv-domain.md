# 表面 UV 验收

日期：2026-10-27，范围为 NR1-S2 的实际采样流。
运行规则见[表面坐标契约](../../runtime/surface-uv-domain.md)。
生成方法见[原生 UV 转换](../../development/native-surface-uvs.md)。

## 原生输入

官方 3534 帧的 A3 绘制使用 `9090` 个索引。
UV0 位于第二顶点流偏移零，UV1 位于偏移八。
该绑定的步长为十六字节。
`TEXCOORD1` 和 `TEXCOORD4` 引用同一组 UV1。

探针包含 `3153` 个顶点及两份 UV 边车。
两组数据与 GPU 对应上传区间逐值一致。
三角形匹配保留独立 UV1 及其接缝。
主表面有 `3030` 个三角形及 `9090` 个角点。

角点位置最大匹配误差约为 `1.285e-6` 米。
UV0 匹配误差为零。
另一子网格的五百一十个角点共同通过。
实际材质的基础色和法线选择 UV0，遮罩选择 UV1。

源遮罩和 NRO 图像在方向对应后逐像素一致。
基础色按 sRGB 解码后处于一个线性字节误差内。
图像方向、坐标方向和颜色域分别核对。
原始文件及 GPU 导出保持各自摘要。

交换格式的两项既有检查通过。

实际场景入口完成独立 A3 表面导出。
源矩阵及网格边界检查通过。

## GPU 与实际镜头

每配置十六次独立采集覆盖两种描述符。
用例包含普通表面、法线、透明、镜像及四倍采样。
UV1 候选与独立 UV0 参考逐像素一致。
Debug 与 Release 的对应图像共同核对。

既有完整候选通过公共导入修复后复采。
其完整图像与保留基线逐像素一致。
来源清单中的 `2157` 份既有纹理选择均为零。
检查范围内的材质采用一致的坐标域。

真实 A3 候选通过公共 UV1 导入消费。
A2、A3 标签方向及分区图案按官方图像检查。
作者切线候选另有输入摘要及独立复采。
完整画面误差和剩余差异保存于机器证据。

完整候选在一次内存余量有限的采集中出现分配失败。
该次输出作为失败记录保留。
截帧快照使用实际可见几何及其资源引用。
该快照与完整基线逐像素一致。

隐藏资源的载入峰值纳入后续资源预算任务。
失败采集与有效采集分别记录。
