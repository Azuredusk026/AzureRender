# 计算反射材质候选核验

## 判定

来源为 `acf9826`，设备为 RTX 4060 Laptop。
候选未通过原生四帧零像素条件，处于隔离状态。
生产源码、双配置 GPU 程序和 Release Player 代码段恢复一致。
CPU、GPU 帧预算和整体画质继续待正式验收。

## 兼容与定位

局部成本依据见[材质执行成本](computed-material-cost.md)。
实现使用专用常量编号四，按实际上传参数选择管线。
主颜色的屏幕法线与混合材质分别核对提前深度资格。
候选在 Debug 和 Release 各通过十四项关联检查。

| 冻结帧 | 差异像素数 | 最大通道差 |
| --- | ---: | ---: |
| 0 | 4 | 1 |
| 1 | 7 | 1 |
| 2 | 12 | 1 |
| 3 | 16 | 6 |

隔离控制只关闭专用管线选择。
原始统一缓冲输入和提前深度修改保持一致。
四帧均恢复为零像素差异。
该结果定位到专用管线选择，具体浮点变换仍待归因。

两次采集均核对 1729 个挂载文件及程序摘要。
输入在采集期间保持一致，卸载后的资源计数为零。
原生门槛失败后，候选计时和公共 GPU 批次未启动。
正式一千八百帧及长跑未执行。

## 启动与恢复

候选首次管线创建耗时约为 258.24 秒。
后续隔离控制的管线创建耗时约为 0.258 秒。
两者属于冷暖缓存条件不同的启动记录。
帧内收益及稳定启动预算均独立判定。

恢复后的 Debug 和 Release 各通过十三项关联检查。
两配置的原有 663 个 GPU 程序逐字节一致。
全部源码输入及 Release Player 代码段与冻结基线一致。

检查脚本首次缺少 PE 解析依赖。
独立脚本直接读取 PE 节表，完成真实代码段比较。
原失败与后续核验分别保存在归档中。
