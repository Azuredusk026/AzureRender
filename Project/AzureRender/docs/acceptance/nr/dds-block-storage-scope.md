# DDS 块存储范围

日期：2026-11-11。
本项核对冻结源文件、设备格式能力和现行上传契约。
生产候选及实际 GPU 节省量继续独立验收。

## 源文件容量

冻结输入包含八十五份独立 DDS，全部摘要核对通过。
其中六十四份为 BC7 sRGB，八份为 BC7 UNORM。
两份为 BC5，十一份采用其他存储格式。
全部文件编码容量合计为 70200100 字节。

块压缩来源的逐层 RGBA 容量为 189137672 字节。
对应块载荷按文件头计算为 47289440 字节。
两者相减为 141848232 字节。
该数字属于源文件容量范围，实际缓存另行核对。

## 设备与运行时

Intel 与 NVIDIA 的实际格式查询均通过。
BC5 UNORM、BC7 UNORM 和 BC7 sRGB 支持采样及线性过滤。
查询仅取得物理设备格式属性。
逻辑设备启用特性按设备创建链另行核验。

现行设备创建链保留默认的 `textureCompressionBC` 值。
解码器保存 RGBA8 多级图像及来源压缩名称。
BC5 法线重建属于处理后的像素契约。
上传接口以每像素字节数描述缓冲到图像复制。

## 后续准入依据

块存储候选需关联实际缓存身份和各级图像。
采样结果需与处理后的 RGBA 基线逐字节核对。
设备能力、特性启用及块复制布局分别验证。
