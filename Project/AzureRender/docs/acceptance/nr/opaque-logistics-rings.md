# 物流彩色环带验收

阶段为 NR7-L4M，静态几何与自发光分项通过。
本页核对固定捕获相位下的实例和表面采样。
动态时钟、反射等价及整体门禁继续验收。
输入及指纹见[结构化证据](evidence/2026-10-28/opaque-logistics-rings.json)。

## 来源与实例

原版 3534 帧的环带来自不透明绘制 5066 和 5078。
两次绘制分别具有一和二个实例。
每个实例包含 114 顶点及 336 索引。
像素历史对应 HDR 附件及 GBuffer 的实际写入。

三个实例使用真实顶点输出重建世界位置。
镜像基准由场景父节点应用一次。
原始 UV 保存在第二组坐标，固定相位进入采样坐标。
源矩阵重投影最大误差小于 0.000000061。

候选资源核验未匹配到该组源网格。
完整候选接入三份捕获姿态及两张色带纹理。
实例世界姿态和采样相位按该帧冻结。
关卡资源总数为 364。

## 材质与采样

来源纹理为资源 12182 和 12178。
格式为 BC7 sRGB，尺寸为 32×1024，各有十一层。
图像保留原始各层载荷及来源标识。
材质使用普通物理材质及现有自发光通道。

源材质的三通道颜色组合在本帧等同纹理 RGB。
自发光强度为一，缩小和放大均采用线性过滤。
层级过滤为最近，mip 偏置为负一。
实例颜色及曝光的实际乘数分别核对。

图像导入元数据显式声明最近层级过滤。
普通 glTF 材质的采样器接入列入 C15-S1。
该任务核对字段映射、默认值及图像元数据覆盖。
头发已知的硬件层级边界保持独立待验。

## 性能与范围

完整场景短测使用 Release、1920×1080 和九十六帧。
场景采用单样本光栅化及空间抗锯齿模式一。
全部原始帧纳入统计，平均 GPU 范围为 46.025018 毫秒。
P95 为 45.073392 毫秒，16.67 毫秒目标保持未通过。

本阶段复用现有材质、资源及反射通路。

兼容结果引用相同输入和环境的解析雾阶段。

动态实例、滚动时钟及完整反射保持待验。
