# 反射时间过滤组合验证

日期：2026-10-29。阶段为 NR5-R8-M。
`ScreenReflectionGpu` 按需组合公共时间过滤。
接口及预算见[屏幕反射](../../runtime/screen-reflection.md)。

## 资源契约

启用时间过滤时，每个槽位增加单层当前信号。
其保守浮点预算为每个基础像素 20 字节。
组合图像上限保持 512 MiB。
2048×2048 的双槽位时间组合被预算检查拒绝。
对应的本帧组合仍满足原有预算。
预算失败发生在分配图像前。

当前信号与历史合成输出分别持有图像。
历史借用既有信号层级的基础视图。
有效性、运动和遮挡显露接收权重由调用者提供。
无效历史使用当前信号作为占位输入。
同槽位历史、缺失视图及非法参数在录制前拒绝。
失败检查同时核对命令与描述符写入保持为空。

## GPU 验证

Debug 与 Release 各通过八项受影响检查。
两种配置的 Player 和编辑宿主均完成构建。
每种配置另通过十组实际 Player 反射采集。
四个表面快照场景分别通过两种配置检查。
既有八十份射线及组合输出继续通过独立求交参考。
透视、正交、镜头偏移、旋转和移动遮挡分别覆盖。

新增十六份时间组合输出覆盖完整和半尺寸。
每种尺寸分别使用打包和浮点信号格式。
每组连续录制两个槽位并复用历史。
有效历史在信号边缘产生可测差异。
四组有变化的输出标量分别为 2754、2781、664、664。
接收权重为零时，完整输出恢复本帧结果。
该检查对全部输出字节执行精确比较。
校验错误为零，最终图像与缓冲数量归零。

公共时间核的原版来源及逐字节范围沿用[时间过滤验收](reflection-temporal.md)。
本项验证时间核与射线、层级和空间过滤的实际连接。
本阶段的 208 份着色器产物均保持既有指纹。

主场景使用现行的本帧组合路径。
共享运动的拥有者已接入主宿主。
