# 场景副本着色需求验证

日期：2026-10-25。
范围为 MS5 的副本着色成本与材质兼容。
联合运动画质及正式性能预算继续验收。

## 着色选择

角色渲染器根据可见资源和实际反射设置选择管线。
屏幕反射、场景折射和场景染色消费完整颜色副本。
眉毛遮挡、屏幕边缘光及深度壳只消费深度。
径向眼睛的透明裁剪使用完整材质 UV 变换。

深度专用片元程序写入线性深度及硬件深度。
裁剪阈值、纹理梯度和节点透明度与主材质一致。
单样点及四样点共用现有材质推送布局。
管线由角色渲染器持有，随资源重建和卸载释放。

深度顶点接口只导出 UV、世界坐标和透明度坐标。
蒙皮、形变及投影沿用公共顶点计算。
固定顶点流与计算蒙皮分别编译对应入口。
片元接口与实际顶点输出保持一致。

通道、源图像和解析目标沿用公共所有权契约。
完整颜色需求由全部可见资源合并判断。
固定描述符和索引描述符采用相同选择规则。
该机制适用于角色边缘光与通用折射场景。

## 成本定位

测量设备为 RTX 4060 Laptop GPU。
真实角色使用 1920×1080、固定相机及完整颜色输出。
每组运行九十六帧，预热十六帧后统计八十帧。
帧率限制与垂直同步均关闭。

冻结基线的四样点 GPU P95 为 61.81 毫秒。
诊断时间戳测得副本平均耗时约 29.59 毫秒。
诊断程序、补丁和输出与正式产物分别保存。
正式程序的时间戳位置保持常规通道定义。

最终构建的四样点 GPU P95 为 40.37 毫秒。
单样点 P95 为 13.00 毫秒。
四样点 P95 降幅约为 34.7%。
四样点仍需完成主通道优化与 60 帧预算验收。

单样点的设备本地峰值为 821,657,600 字节。
四样点的设备本地峰值为 1,368,719,360 字节。
数值来自所属分配器的联合峰值计数。
