## 公共契约

头发照明使用可选的 `characterVisibility`。
来源为常量一、场景、主灯或对象可见量。
头发缺省采用常量一。
通用漫反射缺省采用场景可见量。

两类材质共享同一个类型化来源枚举和严格解析。
完整材质、内嵌画像和图片 UUID 复用既有入口。
来源缺失、非法类型及未知字符串分别检查。
对象记录缺失时，返回完整可见。

材质布局版本十使用既有标志分量保存来源。
虚拟主灯保留独立的最低位。
材质记录为 192 字节，片元纹理槽为九个。
对象图集、实例身份及采样器沿用现行所有权。
