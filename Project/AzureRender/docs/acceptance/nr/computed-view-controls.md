# 计算反射视图控制流核对

日期：2026-11-10。
状态：严格四帧通过，场景区间效率门槛未通过。
候选限定普通不透明材质的主颜色程序。
实验来源、程序和输入均在采集期间冻结。

## 精度与资格

候选沿用现有隔离管线及精确照明组合。
场景照明、默认效果及计算反射限定实验输入。
私有程序固定相关分支，其他数值输入沿用原表达式。
本次结果用于判断该组合的兼容性。

六十四份私有程序均通过 SPIR-V 校验。
两个录制及生命周期检查通过。
原生实际选择八条对应管线，准备失败原因为空。
四帧的 RGB 差异与 PNG 摘要差异均为零。

1729 项项目输入摘要保持一致。
同步验证无警告和错误。
卸载后的缓冲和图像计数归零。
该结果没有单独归因各项编译变换。

## 短时成本

三进程依次执行前参考、候选和后参考。
场景为 1920×1080，采用每秒二十四次固定更新。
每端预热六十帧，随后统计六十帧。
CPU 数值按同一窗口记录，保持观察范围。
