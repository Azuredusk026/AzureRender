# 眼部阴影纹理与遮挡

原生帧 10401 的事件 1245 使用六层 BC7 纹理。
纹理红通道提供覆盖率，线性 RGB 常量提供乘色。
固定姿态 Player 对照把两项输入写入各级 RGBA 纹素。
每一级保留原生遮罩，采样使用重复寻址、双线性缩放、最近层级和负一偏移。
