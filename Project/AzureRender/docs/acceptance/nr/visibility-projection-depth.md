# 对象可见量深度方向验收

日期：2026-11-12。
范围为公共图形通道的图集与对象投影方向。
整体画质状态为 `failed-user-review`。

## 方向契约

图集通过 `objectDepth` 定义纹素方向。
每条记录可通过 `projectionDepth` 定义投影方向。
缺省记录使用图集方向。
过滤统一比较反向深度。

参数块用最低位标记图集的正向深度。
其余八位按对象身份标记正向接收投影。
参数块大小为 992 字节，输出为 `R8G8_UNORM`。
无效的记录方向在录制及描述符更新前拒绝。

## 图集对照

合成图集保存介于四分之一和四分之三之间的深度。
同一帧的两种记录分别产生完整阴影和全可见。
图集方向切换后，逐对象方向和缺省方向分别核对。
第八条记录覆盖方向位的边界。

双设备在两配置各通过四项 GPU 检查。
普通及参考算术各核对 2,299 个像素。
两配置各通过五项 CPU 检查。
同步验证与资源释放均通过。

## 参考算术

公共图形通道读取冻结的深度、法线、图集和对象记录。
头发区域为 17,017 个位置，完整接收区域为 49,384 个位置。
参考算术沿用每通道一字节门槛。

| --- | ---: | ---: | ---: |

## 实际场景

两设备在 Debug 与 Release 各采集三帧。
五份参考附件和颜色摘要匹配逆投影标定场景。
同设备的冻结区域统计在两配置一致。
实际场景的一字节门槛继续有效。
