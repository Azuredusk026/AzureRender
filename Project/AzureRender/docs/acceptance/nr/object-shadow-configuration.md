## 投影与边界

八个对象使用独立实例身份与图集分区。
测试覆盖固定分区、自动分配及重复身份拒绝。
中心跟随镜像与非均匀缩放的完整变换。
垂直主灯采用稳定基底，非法与溢出输入被拒绝。

公共矩阵与原生对象投影的最大误差为 `2.24e-8`。
投影记录采用十六字节对齐，大小为 96 字节。
本分项验证记录的宿主契约，GPU 上传继续待验。

浮点属性的合法端点通过保存重开。
范围校验采用存储类型的可表示边界。
标量和向量的相邻越界值继续被拒绝。
失败写入保持已有组件值。
