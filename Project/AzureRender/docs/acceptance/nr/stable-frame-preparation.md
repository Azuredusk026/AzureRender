# 稳定场景帧准备优化

## 所有权与失效

固定步长前的变换由 `PreviousTransformSnapshot` 独立持有。
运行时身份、场景修订及有序实体代际决定索引有效性。
组件值每步刷新，渲染插值保持原表达式与节点顺序。
组件删除、稠密顺序变化、实体复用和场景替换触发重建。
匿名或无效实体保留完整遍历的空键语义。
超过六万五千五百三十六个组件时采用完整映射。

`SceneTransformCache` 持有拓扑、局部输入及世界矩阵。
局部输入逐位匹配，父级变化传播到完整子树。
环路、非有限输入及超额布局采用原完整解析。
加载和资源释放清空所属状态。
本批原生末帧复用全部 1679 个节点的世界矩阵。

## 原生评估

同一联合场景以 1080p 固定步长运行。
基线与候选各预热三百帧，采样一百二十帧。

| 指标 | 基线 | 候选 |
| --- | ---: | ---: |
| CPU 均值，毫秒 | 9.616 | 7.156 |
| CPU P95，毫秒 | 10.459 | 7.974 |
| GPU 均值，毫秒 | 22.071 | 21.867 |
| GPU P95，毫秒 | 23.239 | 22.744 |

CPU 均值减少约 2.46 毫秒，短时改善约 26%。
CPU P95 在该短窗口内满足八毫秒条件。
正式一千八百帧、完整环境资格及整体画质继续验收。
GPU 收益未成立，原有 663 份着色器保持相同字节。
GPU 帧预算仍未通过。

原生 1440p 四帧均与冻结 RGB 零像素差。
源码、产物及 1729 份挂载输入在采集前后摘要一致。
卸载后的缓冲与图像归零。
原生日志未出现验证错误文本，原生应用未启用验证层。
基线记录一次相对热余量失败，候选记录一次软件热限速。
全部观察八十瓦稳定条件未通过。
