## 单因素对照

几何对照仅替换快照法线的初始来源。
倾斜对照采用 `normalize(geometricNormal+vec3(0.1,0,0))`。
两者均保持全图快照深度与粗糙度逐位一致。
方向由实际准备法线和捕获矩阵独立复算。

| 路径 | 右侧几何命中 | 右侧射线接收 | 右侧过滤接收 | 相对控制的方向角差 |
| --- | ---: | ---: | ---: | --- |
| 材质法线控制 | 97 | 0 | 0 | 0° |
| 几何法线 | 97 | 0 | 0 | 0.528055°至 0.559980° |
| 受控倾斜法线 | 87 | 0 | 0 | 5.517571°至 6.207216° |

左侧 92 点在三条路径均无几何命中。
命中及历史地址来自实际射线程序足迹探针。
探针保持射线颜色与置信度逐字节一致。
解除替换后，所有留存附件均逐字节恢复。

几何对照使成片的 556 个存储字节变化。
倾斜对照使成片的 1,437 个存储字节变化。
该计数覆盖完整 BGRA 附件，表示传播范围。
它属于来源诊断，不替代画质与性能门槛。
