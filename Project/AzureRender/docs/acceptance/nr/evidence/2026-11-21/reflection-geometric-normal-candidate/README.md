状态为候选未通过，大厅画质继续验收。

射线、历史、深度、粗糙度及颜色保持捕获输入。
生产入口按所属验收状态维护。

## 归因与接续条件

法线来源会影响两区的亮度及局部结构。
本次单变量不能闭合大厅的全部结构差异。
同址前景、材质法线与历史状态仍需匹配输入。
现有捕获的这些输入差异见[来源核验](../../2026-11-20/reflection-surface-normal-lineage/README.md)。

原始冻结四帧仍要求可用的 592.82 环境。
本轮主机查询结果为 595.79。
正式房间交付和 Steam 实机按工作线暂停项维护。

## 独立复算

解压[验证归档](validation.zip)，运行 `python score.py`。
依赖 NumPy、Pillow 和 OpenCV。
`python build.py` 使用归档源码复编两份程序。
该入口使用本机 Vulkan SDK 1.4.350.0。

[结构化收据](qualification.json)保存程序和画面摘要。
归档包含变化坐标、区域像素与完整判定规则。
