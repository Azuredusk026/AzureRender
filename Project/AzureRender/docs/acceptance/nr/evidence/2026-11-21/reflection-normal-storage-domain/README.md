# 反射法线存储域与材质绑定

状态为来源核对通过，大厅画质继续验收。
基线为 `0d3e942`，复用封存的两端法线。
本项核对量化域、实际绘制及纹理数组槽位。

## 存储域

原生附件使用 10 位 Y 极八面体编码。
Player 源附件使用浮点 Z 极八面体编码。
两端方向按已验证的世界 X 轴映射配对。
每个接收位置保留 Player 的四个源纹素。

以下计数要求至少一个纹素进入原生编码范围。
最近舍入采用半单位容差，保守对照采用一单位。
编码比较的附加数值容差为 0.00001 单位。

| 区域 | 配对点 | 半单位范围内 | 一单位范围内 | 最小编码距离中位数 |
| --- | ---: | ---: | ---: | ---: |
| 中央地面 | 19,281 | 5 | 8 | 1.75579 |
| 青色环带 | 6,478 | 0 | 0 | 1.60793 |

编码距离为两通道绝对差的最大值。
四个纹素取其中的最小距离。
存储量化不足以解释封存两区的方向差异。
原生编码 `[511,511]` 各占 18,468 点和 6,126 点。

## 实际材质绑定

批次 2332 和 2334 核对两个接收点的写入。
像素为 `[1201,1021]` 与 `[1101,1121]`。
两点均由绘制 17241、实例 77 写入。
绘制前后字节与准备前完整附件一致。

批次 2335 读取同次绘制的推送常量。
偏移 136 的 `textureBase` 为 407。
法线纹理读取 `textureArray[textureBase+1]`。
对应资源为 1487，尺寸为 1024×1024。

实际绑定格式为 `R8G8B8A8_UNORM`。
共 1,048,576 个纹素，其中 956,901 个为中性码。
该中性码为 `[128,128,255,255]`。
当前解码使用 `sample.xyz*2-1`。

八位中性码解码后具有轻微切线方向分量。
实际方向还受几何基底及取样位置影响。
后续用几何法线单因素对照核定其画面贡献。
正式采用仍要求区域、邻区和冻结四帧通过。
