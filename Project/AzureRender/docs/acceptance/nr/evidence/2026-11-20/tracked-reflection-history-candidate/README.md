# 运动深度反射候选

候选在原创检修站恢复了切换帧的反射。
封存大厅的实际画面保持逐像素一致。
大厅仍有结构与亮度差，候选保留为诊断代码。

## 历史接收判定

候选保持现行静态接收路径。
静态检查拒绝后，完整运动响应可进入前帧深度核对。
该路径要求有效当前深度和大于一个纹素的运动。
历史颜色的采样地址、色值和过滤设置沿用捕获。

预测深度取自运动缓冲的 B 通道。
历史深度与预测深度在同一前帧投影中核对。
容差取一个射线纹素的世界跨度及原门槛的较小值。
当前射线还须通过当帧表面距离检查。
