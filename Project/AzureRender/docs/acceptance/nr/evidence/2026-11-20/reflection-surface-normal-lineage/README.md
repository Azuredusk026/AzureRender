# 反射接收法线与前景深度

接收法线偏差在表面准备前已经存在。
中央地面的大幅命中偏差主要伴随同址前景深度差。
公共表面准备通过独立解析夹具。

## 法线来源

批次 2318 读取原生 3534 帧与 Player 第 1 帧。
原生准备事件 8691 的两份法线输入逐字节一致。
Player 准备事件 21055 读取完整分辨率表面。
射线实际读取的法线资源按原摘要复核。

Player 中心纹素的八面体转换复现了准备输出。
原生 2×2 覆盖中的左下纹素复现率最高。
中央地面 19,040 点和环带 6,382 点的双通道精确。
此统计为两区主导位置，保留其他纹素结果。

| 对照 | 中央地面法线中位差 | 青色环带法线中位差 |
| --- | ---: | ---: |
| 实际准备输出 | 0.2630° | 0.2504° |
| 最接近的 Player 单纹素 | 0.2630° | 0.2504° |
| Player 中心纹素经 10 位量化 | 0.3193° | 0.3193° |

四个源位置在两区给出相近的中位误差。
10 位对照基于 Y 极八面体编码。
当前误差来自输入方向差异，范围涵盖封存两区。
Player 仍按公共表面契约执行中心采样。

## 前景与命中

受控复算采用最近深度、32 步、参考相位及同址法线。
复算坐标用于查询两端的实际深度附件。
原生地址须能唯一确定半分辨率纹素。
以下统计将超过 50 像素的差异作为长尾。

| 指标 | 中央地面 | 青色环带 |
| --- | ---: | ---: |
| 共同命中和唯一参考地址 | 18,725 | 6,307 |
| 长尾样本 | 3,063 | 10 |
| 复算地址处的 Player 表面近于参考至少 0.5 m | 2,763 | 0 |
| 参考地址处的两端深度差超过 0.5 m | 0 | 0 |

批次 2324 核对中央地面三个长尾代表点。
三个较近表面均由 Player 绘制 18593 写入快照。
绘制前后纹素与完整快照摘要一致。
实际绘制、索引缓冲和程序摘要见[收据](qualification.json)。

这些点的前景来自实际快照。
长尾坐标由受控 CPU 搜索产生。
正式大厅画质以实际成片和完整验收规则判定。

## 公共接口回归

## 剩余验收条件

大厅的中央地面和青色环带维持 0.95 的 SSIM 门槛。
中央地面亮度和邻区新增超差沿用既定阈值。
方向及遮挡归因需要匹配同场景输入与历史状态。
候选成片在对应条件下覆盖两区、邻区和冻结四帧。

592.82 冻结四帧要求参考驱动在目标显卡可用。
现机隔离进程的枚举结果见[驱动复核](../reflection-regional-cross-address/README.md)。
原创房间交付和 Steam 实机沿用工作线暂停项。
