# 大厅反射区域取样归因

大厅两区的主要取样差异来自射线命中位置。
同址亮度差在取样地址接近的样本中仍然存在。
时间合成改变了亮度分布，剩余误差随区域变化。

## 帧与样本

共享队列 2306 回放原生第 3534 帧和 Player 第 1 帧。
两组探针分别记录射线命中与历史颜色地址。
颜色、置信度及恢复后的足迹逐字节核对。
捕获、着色器与实际绑定见[结构化收据](qualification.json)。

两端接收面前向深度相差至多 2 cm，且均有射线命中。
交叉取色要求两个历史地址均可唯一解出。
直接取色复算须在实际颜色一个量化单位内。
距离使用完整画面纹素，原生行序转换为显示方向。

| 指标 | 中央地面 | 青色环带 |
| --- | ---: | ---: |
| 匹配深度与双命中 | 19,281 | 6,478 |
| 唯一地址且复现取色 | 16,996 | 5,715 |
| 历史地址距离中位数 | 8.06 px | 6.32 px |
| 地址贡献占比 | 60.56% | 65.27% |
| 命中及历史地址均唯一 | 16,644 | 5,571 |
| 命中位置差中位数 | 8.25 px | 8.06 px |
| 回移差中位数 | 0.00 px | 2.00 px |

分别按两端实际地址从两份历史颜色取样。
地址贡献为两份颜色源下地址差的平均值。
颜色源贡献为两个地址下源差的平均值。
占比以两项绝对贡献之和为分母。

在相距不到两像素的样本中，同址残差仍约为 0.05。
在相距至少八像素的样本中，同址取色显著减少误差。
所有差异按最大分量压缩后的亮度计算。
场景内容与历史收敛差异仍限定解释范围。

## 时间合成

原生时间颜色输入位于事件 8741、资源 15861。
两区的输入与同帧射线颜色逐值一致。
其输出为资源 16552，摘要与实际空间过滤输入一致。
统计使用各区全部深度匹配双命中样本。

| 指标 | 中央地面 | 青色环带 |
| --- | ---: | ---: |
| 原生时间合成平均绝对亮度变化 | 0.04759 | 0.06679 |
| 合成前与 Player 射线的绝对亮度误差均值 | 0.09874 | 0.10247 |
| 合成后与 Player 射线的绝对亮度误差均值 | 0.09597 | 0.10994 |

后续优先核对半分辨率深度和射线命中位置。
当前区域指标用于归因，正式画质沿用原门槛。

## 冻结四帧环境

两次探测使用独立进程选择 Vulkan 驱动。
参考 592.82 返回退出码一，未枚举到物理设备。
当前 595.79 返回退出码零，枚举到 RTX 4060 Laptop GPU。
冻结四帧的恢复条件是参考驱动在目标设备上可枚举。

## 独立复算

解压[验证归档](validation.zip)后运行 `python regional.py`。
需要 NumPy，所用数值及驱动日志均在包内。
复算包含地址、颜色、两区配对和实际时间增量。
