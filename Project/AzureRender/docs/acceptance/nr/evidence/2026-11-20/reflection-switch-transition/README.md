# 检修站反射过渡归因

导光板移动时，历史颜色有效，反射可信度归零。
世界位置检查把导光板位移计入几何误差。
同帧读回覆盖历史地址、射线颜色、置信度与过滤输出。

## 帧身份

批次 2295 捕获原创检修站正常成片的第 4 帧。
捕获末端显示资源与封存 PNG 的 RGB 摘要一致。
Player、着色器、输入与验收回放按指纹核对。
捕获大小为 37,503,493 字节。

射线事件为 270，实际空间过滤事件为 331。
三次足迹探针保持完整射线颜色与置信度逐字节一致。
解除替换后核对三份原始射线输出。
完整绑定与帧指纹保存在[收据](qualification.json)。

## 反射与历史接收

解析镜面投影划定左侧 92 点和右侧 97 点。
左侧具备初始资格，当前射线均为空。
右侧 97 点均有几何命中和完整运动响应。
这些点均回移至导光板的前帧红色。

| 右侧证据 | 范围或计数 |
| --- | ---: |
| 几何命中与完整运动响应 | 97 |
| 非零射线置信度 | 0 |
| 非零过滤置信度 | 0 |
| 前帧取样红通道 | 0.80322 至 0.81006 |
| 当前射线与当帧表面的距离 | 0.00071 至 0.01062 m |
| 静态世界位置检查的距离 | 1.40002 至 1.40262 m |
| 同一检查的距离门槛 | 0.25000 至 0.26673 m |
| 运动预测与前帧深度位置的距离 | 0.000004 至 0.00944 m |

运动包含当前减前帧的二维位移和前帧设备深度。
复算将运动 B 转为准备阶段的反向设备深度。
预测深度和实际前帧深度在同一前帧坐标系比较。
97 点均具有唯一的运动、深度和取色地址。

这组证据支持在完整运动路径核验前帧预测深度。
候选还须保留深度不匹配时的拒绝。
生产采用仍按大厅 SSIM、亮度、邻区和冻结门槛判定。

## 独立复算

解压[验证归档](validation.zip)后运行 `python verify_transition.py`。
复算需要 NumPy 和 Pillow，读取封存 PNG 与原始附件。
归档记录射线常量、位移、取色、深度和真实输出。
结论适用于该帧导光板平移及其解析镜面范围。
