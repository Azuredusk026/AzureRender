# 反射搜索输入敏感度

两区的命中位置对接收法线敏感。
固定最近深度时，步数和相位主要影响环带的远端误差。
中央地面仍有较大的长尾偏差。

## 来源与对照

复算采用封存 Player 的射线常量、掩码和法线。
深度分别使用实际中心采样及最近深度候选。
基线命中与实际探针的中位误差约为 0.012 像素。
在共同样本中，两区的第 90 百分位均约为 0.019 像素。

深度配对使用 2 cm 门槛，两端均须实际命中。
统计保留所有复算方案都产生几何交点的样本。
中央地面保留 19,017 点，环带保留 6,415 点。
比较目标是原生的实际命中位置。

色值、历史接收和空间过滤属于后续链路。
本次计算复算搜索，不发布渲染或画质验收结果。

## 命中位置

以下距离采用完整分辨率像素。
相位对照固定 32 步，仅采用对应种子和纵轴方向。
法线对照固定其余条件，并转换原生法线的世界 X 方向。

| 条件 | 地面中位数 | 地面第 90 百分位 | 环带中位数 | 环带第 90 百分位 |
| --- | ---: | ---: | ---: | ---: |
| 中心深度，128 步 | 8.34 | 196.25 | 7.98 | 111.68 |
| 最近深度，128 步 | 8.41 | 199.72 | 8.15 | 112.54 |
| 最近深度，32 步 | 8.16 | 220.71 | 7.52 | 71.24 |
| 最近深度，32 步及参考相位 | 7.81 | 222.60 | 7.15 | 19.57 |
| 最近深度，128 步及同址原生法线 | 0.58 | 193.53 | 1.37 | 98.54 |
| 最近深度，32 步、参考相位及同址原生法线 | 0.08 | 210.59 | 0.07 | 0.10 |

环带的命中长尾受相位和接收法线共同影响。
中央地面的长尾仍需独立核对相邻表面和遮挡。
本轮结果指向接收法线的输入来源与取样位置。
大厅成片继续按现行 SSIM、亮度和邻区门槛验收。

## 复算

[结构化收据](qualification.json)记录完整统计和归档摘要。
解压[验证归档](validation.zip)后运行 `python step_sensitivity.py`。
需要 NumPy，复算使用包内的常量、输入和命中读回。
