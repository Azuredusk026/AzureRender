候选按原门槛淘汰。

## 同帧控制

批次 2310 回放 Player 第 1 帧。

候选只将 2×2 源覆盖的深度选为最近有效值。
法线、粗糙度、掩码和初始置信度逐字节一致。

解除替换后，全部阶段与成片逐字节恢复。

## 同址几何与搜索预算

按两端各自的实际命中坐标读取三份深度。
三份来源为原生、Player 中心采样和最近深度候选。
接收面配对与坐标唯一性使用[区域读回](../reflection-regional-cross-address/README.md)。
深度为相机前向距离，阈值为 2 cm。

| 区域与地址 | 有效样本 | 中心采样超差 | 最近深度超差 |

这些统计使用基线记录的实际命中坐标。
候选成片则由修改后的真实调度重新运行。

原生两区采用完整预算的点分别占 97.41% 和 97.97%。
Player 两区的掩码均选完整预算。

搜索步数与射线落点继续按相同深度条件核对。

## 独立复算

[结构化收据](qualification.json)记录批次、指标和归档摘要。
解压[验证归档](validation.zip)后运行 `python verify.py`。
运行 `python geometry.py` 复算实际命中处的深度差。
两个入口需要 NumPy，画面指标还需要 Pillow 与 OpenCV。
