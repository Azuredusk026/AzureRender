## 历史接收

当静态世界位置检查拒绝时，可进入运动深度核验。
该路径要求完整历史位移、有效深度和响应一。
当帧命中须贴合当前表面，前帧深度须贴合运动预测。
容差取原距离门槛与射线纹素跨度的较小值。

历史取色地址、颜色及足迹沿用原有生产规则。
背景、无效响应、屏外和错误深度保持拒绝。
着色器参数布局及资源所有权沿用既有契约。

## 验证结果

测试先行的移动用例有 2432 个目标采样。
受检基线的接收数为零，修复后的接收数为 2432。
主配置共通过 17 项 GPU 定向检查。
每项验证错误及存活缓冲、图像计数均为零。

实际 Player 使用同一程序执行六次配对回放。
输入按 F 在第 4 帧移动导光板和检修灯。
两种成片的右侧反射均在第 4 帧达到门槛。
原无输入序列的十二帧保持逐像素一致。

| 第 4 帧 | 基线红色信号 | 修复后红色信号 |
| --- | ---: | ---: |
| 反射隔离 | 0 | 0.547641 |
| 正常成片 | 0 | 0.547442 |

红色信号沿用解析镜面范围及 0.003 门槛。
六次启动均完成同步验证及退出释放检查。
程序和着色器按独立摘要记录。
