## 来源

本机包中的着色器名为 `HGRP/DeferredLighting`。
对象身份为 `CAB-5f6bd227bdb9064436ebffdaf50061e0:6850169740889141214`。
转换器恢复了 Vulkan 平台的静态程序。
所选片元程序来自完整照明通道的基础变体。

恢复文本为 `deferred-vulkan-base.hlsl`。
第 1814 至 1833 行包含点光与聚光距离衰减。
负指数分支使用平滑范围截止及距离平方分母。
非负指数分支使用归一化范围的幂函数。

该程序还包含线状灯、Cookie 和局部阴影分支。
当前公共衰减模型覆盖非线状的点光与聚光。
完整原生灯光组合语义仍需继续核验。

## 指数字段

原生共享灯数据的附加结构位于组件偏移 `0x1a0`。
本机 getter `0x180219250` 复制该结构的 32 字节。
托管方法 `0x1856c6210` 将指数写入结构偏移 `0x1c`。
由此确定序列化灯组件的指数偏移为 444。

读取器保留原始指数，并拒绝非有限数值。
`lighting_ecs.render_falloff` 生成引擎配置。
当前选定的 45 盏灯中，43 盏的指数为负一。
另外两盏的指数约为 6.24。

上述关系来自静态指令与序列化数据。
热更新路径和实时有效灯组尚未观察。
输入包、原始属性与函数地址均保存在本机证据中。

## 公共验证

主 Debug 配置完成全部目标构建。
五项 Python 用例覆盖读取、拒绝及配置映射。
60 项 GPU 数值探针覆盖八个衰减数值。
关卡与路径追踪测试覆盖保存和累计失效。

五组实际画面验证了生产渲染路径。
平滑距离平方模型的最大八位比值误差为 2.9366%。
范围指数模型的最大比值误差为 0.3393%。
聚光边界误差为 0.4634 像素。

无光表面最大通道值为零。
运行校验错误与卸载资源计数均为零。
这些结果验证引擎模型及源字段读取。
原生灯光单位、激活、线状灯与局部阴影仍待还原。

路径追踪另有三组 64 采样的真实画面。
同一平面和灯光验证默认模型及两种显式模型。
平滑距离平方模型的最大比值误差为 0.5466%。
范围指数模型的最大比值误差为 0.1261%。
两者均满足既定 3% 的八位输出阈值。
运行与资源释放检查均通过。
