# 材质纹理共享验收

日期：2026-10-22。
范围为不可变材质纹理的共享与释放。
公开夹具使用两份独立 glTF 资源。
原生场景整体外观与容量进入 NR1 联合验收。

## 契约与构建

缓存属于通用渲染资源层。
渲染器拥有缓存，材质持有借用绑定。
完整像素、过滤语义与有效采样描述共同判定身份。
环境、反射与动态附件各自持有资源。

Debug 与 Release 均已构建受影响目标。
目标包含编辑宿主、Player 和相关测试。
源码与产物指纹记录于[结构化证据](evidence/2026-10-22/sampled-texture-cache.json)。

## 自动检查

两种配置各通过四项 CTest 检查。
缓存用例包含六组契约测试。
生产加载器覆盖固定与索引描述符。
每种描述符均执行卸载后重新加载。

| 检查 | 范围 |
| --- | --- |
| `SampledTextureCache` | 完整身份、冲突、层级字节、异常恢复 |
| `MaterialTextureSharing` | 多资源共享、模式切换与重复释放 |
| `TextureFiltering` | 颜色、法线与透明度过滤 |
| `NullRhiPass` | 渲染提交、描述符容量与既有场景 |

描述符容量按真实布局验证。
四份材质占 36 个纹理槽。
共享纹理和场景快照各占三个槽。
六个缓冲区使每阶段总资源数为 48。

精确容量 42 个采样槽时选择索引模式。
五项容量上限分别减一时选择固定模式。
各回退路径保持绘制和阴影提交数量。
首次失败记录与恢复结果均保存在本轮目录。

## GPU 结果

设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
输出为 640×360，抗锯齿关闭。
两个三角形均进入画面。
展示平台和脸部附加纹理特性关闭。

基线由未使用缓存的 Release 宿主生成。
候选包含 Debug 与 Release 的两种描述符模式。
四份候选均与对应基线逐像素一致。
最大通道差异与变化像素数均为零。

| 缓存统计 | 每个候选结果 |

| 成功请求 | 32 |
| 命中请求 | 23 |
| 唯一纹理 | 9 |
| 请求逻辑图像字节 | 576 |
| 唯一逻辑图像字节 | 164 |

各候选退出后的图像和缓冲区计数均为零。
Debug 明确启用 Vulkan 校验层。
全部日志均无 VUID 和校验错误。
Release 同时请求环境校验层。

逻辑图像字节体现纹理的完整层级大小。
小纹理仍受实际分配对齐影响。
场景显存收益需结合真实分配器测量。
