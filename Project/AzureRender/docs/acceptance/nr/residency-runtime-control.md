# 同程序驻留策略控制

一个私有分配器对象链接到当前运行目标。
两种分配策略使用同一份可执行文件。
诊断在每次上传后读取数据，并保存最后一次范围。
生产源码及运行程序保持受检内容。

主机模式和设备模式各四帧均符合原冻结参考。
实际缓冲属性分别为六和七。
两组记录的六十个上传范围具有相同用途和长度。
两组所有有效记录字节一致。

两个完整实例缓冲的差异位于有效记录之后。
有效实例共 874 条，每条 496 字节。
其余上传范围的完整内容一致。
进程正常退出，卸载资源计数归零。

原驻留候选的十四处差异仍未解释。
诊断读取、锁及文件操作可能影响写入排序或调度。
下一项控制移除上传读取，仅切换显式写入发布。
该假设依据 [Vulkan 主机写入规则](https://docs.vulkan.org/spec/latest/chapters/memory.html)。

本项未采集整帧计时，正式功率和帧预算保持有效。
