## 输入与结果

来源为官方 3534 帧的计算事件 8702。
输出尺寸为 1280×720，活动瓦片数为 9,115。
三份完整输出共 8,294,400 字节。
正式比较使用零差异门槛。

| 输出 | 格式 | 字节数 | 差异字节数 |
| --- | --- | --- | --- |
| 颜色 | `R11G11B10_FLOAT` | 3,686,400 | 0 |
| 过滤足迹 | `R16G16_UNORM` | 3,686,400 | 0 |
| 可信度 | `R8_UNORM` | 921,600 | 0 |

Vulkan 夹具通过现有 RHI 上传、派发和读回。
正序与逆序活动瓦片分别比较完整输出。
验证层、同步与资源释放分别检查。
来源等价的范围为当前设备及冻结单帧输入。

## 冻结数据

导出数据总计 75,379,584 字节。
载荷包含三份常量、瓦片缓冲及六份采样纹理。
三份存储图像分别持有派发前内容及派发后参考。
七级深度纹理按完整层级边界导出。

可信度的派发前内容参与计算。
该输入与派发后结果存在 250,130 个差异字节。
采样纹理和常量在派发前后逐字节一致。
活动瓦片的集合、唯一性及范围分别核对。

导出脚本核对原始捕获、程序及输出的指纹。
原始程序重复重放的三份输出保持一致。
载荷校验在外部 GPU 执行前后各运行一次。
读取范围为所属目录，载荷总预算为一百二十八 MiB。

## 算术契约

点积先计算首个单精度乘积，再依次执行乘加。
二、三、四分量点积均显式声明累计顺序。
三个投影位置使用倒数、半幅缩放和乘加。
源文件及生成算法共同决定编译输入。

| 冻结对照 | 颜色差异 | 足迹差异 | 可信度差异 |
| --- | --- | --- | --- |
| 原始镜像直接编译 | 5,616 | 41,250 | 200 |
| 显式点积累计 | 0 | 9,164 | 0 |
| 点积与投影顺序 | 0 | 0 | 0 |
| 投影像素缩放合并控制 | 0 | 6,883 | 0 |

GPU 位观测先以已知整数位模式验证编码。
观测使用颜色格式中可精确表示的整数分量。
世界位置、归一化方向和正余弦通过逐位核对。
投影后的差异由完整输出控制进一步定位。

部分除法观测会影响 D3D 的后续足迹结果。
对应观测记录为未通过副作用资格检查。
这些中间值按其观测范围解释。
数值验收依据未插入观测的完整输出。

编译使用 DXC、计算着色模型 6.0 和 Vulkan 1.1。
存储图像格式及资源绑定均显式声明。
`spirv-val` 核对目标环境及 SPIR-V 有效性。
编译器、动态库、生成源码与产物记录 SHA-256。

## 公共夹具

接口接收计算程序、数据清单及新输出目录。
实现归属测试层，资源由夹具按作用域持有。
清单声明尺寸、格式、层级、初始内容和参考字节。
版本、缓冲长度及派发范围在设备创建前检查。

合成案例使用独立的 8×8 输入。
空反射验证实际清零，零派发验证初始内容保留。
单字节参考篡改必须被完整输出比较识别。
非法版本、瓦片、层级及绑定在 GPU 使用前拒绝。

公共射线、深度层级和历史过滤沿现有接口回归。
Debug 与 Release 各通过十四项受影响检查。
各配置另通过两项完整来源顺序检查。
合成及非法输入覆盖十项独立案例。

当前来源数据使用设备投影深度及前帧输入。
生产接入需明确深度约定、历史所有权及提交身份。
相关接口与连续序列按后续阶段实施。

## 复现步骤

以下命令在引擎目录执行。
`<任务目录>` 使用产物管理工具创建。
各输出子目录由对应工具创建。

```powershell
python tools/test_native_ray_fixture.py
python tools/compile_native_ray_reference.py `
  --sdk D:/Tools/VulkanSDK/1.4.350.0 `
  --output build/runs/<任务目录>/compiler
```

导出需要原始捕获及 RenderDoc 1.46。
清单记录全部载荷的长度及指纹。

```powershell
python tools/export_native_ray_fixture.py `
  --capture <原始捕获.rdc> `
  --renderdoc <RenderDoc目录>/qrenderdoc.exe `
  --output build/runs/<任务目录>/inputs
```

GPU 复现使用对应配置的已编译夹具。
省略 `--fixture` 时运行合成及非法输入检查。
提供来源清单时分别运行正序与逆序比较。

```powershell
python tools/test_native_ray_reference_gpu.py `
  --executable build/ninja-msvc-release/AzureNativeRayReferenceGpuTests.exe `
  --shader tests/fixtures/native_ray_vulkan/reference.spv `
  --fixture build/runs/<任务目录>/inputs/manifest.json
```

构建、对照、设备及检查结果见[结构化回执](evidence/2026-10-31/ray-vulkan-reference/summary.json)。
来源清单位于 `tests/fixtures/native_ray_vulkan/source.json`。
正式画面、持续性能及 NR 总体状态沿现有门禁验收。
