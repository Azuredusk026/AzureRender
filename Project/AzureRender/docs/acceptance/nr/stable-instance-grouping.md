网格键升序与组内源顺序共同决定连续实例范围。
契约及生命周期见[运行说明](../../runtime/stable-instance-grouping.md)。

## 正确性与规模

缺少分组接口时，实际编译产生预期失败。
独立逐资源判定核对交错输入及组内稳定顺序。
空输入、无效键、随机资源及节点反转均通过。
两配置各十五项受影响 CPU 检查通过。

规模夹具使用六万五千五百三十六个节点及一千零二十四个网格。
每个算法执行八次，输出校验值保持一致。
Release 的总耗时为参考 250.965 毫秒、候选 1.5265 毫秒。
该数字仅描述合成分组成本，整帧收益按独立采集判断。

首轮构建缺少 MSVC 标准库搜索路径，失败日志保留。
通过仓库环境入口初始化后，两配置实际构建通过。
正式产品与受影响目标均记录来源及指纹。
两配置各五百三十五份生产程序保持原字节。

实际联合场景四帧与原冻结参考 RGB 逐字节一致。

## 短时计时

原生一千九百二十乘一千零八十负载采集四百二十帧。
