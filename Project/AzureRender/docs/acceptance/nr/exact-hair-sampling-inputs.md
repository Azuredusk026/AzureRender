# 头发采样输入位值核验

本轮属于 Q1 的纹理层级边界定位。
输入为原生帧 10401 及对应 Vulkan 捕获。
生产程序、着色程序和挂载内容保持原摘要。
功能探针使用电池供电，整帧计时未执行。

## 实际输入

位置 `[1322,263]` 的 UV 在两端逐位一致。
纵向梯度存在约 `5.96e-8` 的幅值差异。
粗粒度横向梯度也存在独立差异。
其他控制点覆盖不同粒度选择及插值误差。

| 梯度，按显示坐标归一 | 原生 | Vulkan |
| --- | ---: | ---: |
| 粗粒度 U 横向 | 0.002685546875 | 0.0026851296424865723 |
| 粗粒度 V 横向 | -0.0002295374870300293 | -0.00022923946380615234 |
| 细粒度 U 横向 | 0.002685546875 | 0.002685546875 |
| 细粒度 V 横向 | -0.0002295374870300293 | -0.0002295374870300293 |

两端的中间附件采用相反的纵向坐标关系。
粗粒度导数在四像素组中的取值位置需分别核对。
默认导数具有实现选择的粒度范围。
规范依据见 [Vulkan 导数规则](https://docs.vulkan.org/spec/latest/chapters/shaders.html#shaders-derivative-operations)。

## 相同梯度控制

精确浮点位值构造同一个仿射纹理坐标场。
本轮保留原生指令偏置及 Vulkan 采样器偏置。
相同的第一组梯度使两端均报告 1.5。
相同的第二组梯度使两端均报告 1.49609375。

该结果限定于两份捕获及本次固定输入。
偏置位置不是该同输入控制中的必要差异条件。
实际层级选择还由取样颜色单独确认。

## 实际取样

原生隐式取样匹配第二级纹理的显式取样。
Vulkan 隐式取样匹配第一级纹理。
采用细粒度或纵向翻转四像素组的梯度后，
Vulkan 在该点匹配第二级纹理。

第二级参与过滤的四个纹素逐通道位值一致。
原生绑定为 `BC7_SRGB`，Vulkan 为 `R8G8B8A8_SRGB`。
两份图像均为 2048×2048，具有十二级纹理。
本项四纹素核对没有发现来源内容差异。

取样结果在写入附件前按完整位值读回。
原生隐式结果与 Vulkan 细粒度控制逐位一致：
`[0.385498046875,0.0885009765625,0.09283447265625]`。
纵向翻转四像素组的控制也得到同一结果。

原生附件为 `R11G11B10_FLOAT`。
Vulkan 附件为 `R16G16B16A16_FLOAT`。
附件读数与取样前的浮点结果分别记录。

## 查询资格

Direct3D 的层级查询在最近层级过滤下未定义。
查询值用于本驱动的定位观察。
实际选择使用同纹理的隐式与显式取样核对。
规则见 [Direct3D 11.3 功能规范](https://microsoft.github.io/DirectX-Specs/d3d/archive/D3D11_3_FunctionalSpec.htm#inst_LOD)。
