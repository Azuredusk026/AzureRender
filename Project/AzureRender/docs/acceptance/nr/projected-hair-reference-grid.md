# 投影头发参考光栅网格

投影头发可声明参考相机的八位子像素网格。
材质画像指定策略，颜色顶点程序按视口尺寸执行。
输入规则见[投影头发照明](../../runtime/projected-hair-lighting.md#参考相机光栅网格)。

## 场景检查

每种设备采集三帧，并核对五类参考附件。
附件和颜色分别匹配同设备的冻结来源。
NVIDIA 的固定及索引描述符输出逐字节一致。

| 设备 | 完整接收超差 | 头发可见量超差 | 头发 RGB 超差 | RGB 最大误差 |
| --- | ---: | ---: | ---: | ---: |
| NVIDIA | 237 | 0 | 0 | 1 |
| Intel | 494 | 111 | 31 | 15 |

完整接收覆盖 49,384 个位置。
冻结头发覆盖 17,017 个位置。
颜色和可见量采用逐通道一字节容差。
原生头发绘制前后的颜色附件差集与冻结覆盖逐点一致。Intel 的 31 处颜色超差在连续坐标与八位子像素坐标下覆盖到同一组三角形。实际写入的三角形及三份纹理的采样继续核对。 [逐点结果](evidence/2026-11-14/character-geometry-light-diagnostics/results.json)

## 静态画面

双设备共通过十项近景和十六项全身区域对照。
近景覆盖发冠、刘海、脸颊、下巴和左眼。
五处近景的最低 SSIM 为 0.99835。
最大中位亮度误差为 1.74%。

全身固定姿态核对三个衣料及五个头发区域。
最低 SSIM 为 0.95968，最大亮度误差为 3.02%。
左眼和脸部统计覆盖原有矩形内的像素。
全身虹膜按原生绘制的 255 个位置核对。
NVIDIA 和 Intel 的 SSIM 分别为 0.93363、0.93637。
两块显卡的中位亮度误差为 18.57% 和 17.75%。
身体皮肤及脸部内部达到区域门槛。
局部颜色差异及实际绘制来源见[面部与体表局部颜色来源](face-skin-color-sources.md)。

左眼矩形在两块显卡上有 418 和 415 处超差。
蓝通道峰差为 90 字节，位于显示坐标 `[667,808]`。
脸颊和下巴的 3,970 个位置均在一字节内。
该检查采用同机位独立画面的线性显示参考。
NVIDIA 仅关闭泛光时，左眼矩形峰差为一字节。

## 回归

Release 通过十一项 CPU 检查，Debug 通过十项。
两种配置在两块显卡上各通过六项 GPU 检查。
每种配置核对 895 份着色程序。
十二份参考颜色顶点程序通过 SPIR-V 验证。

冻结四帧的 PNG 摘要逐一匹配。
验证层检查通过，卸载后缓冲和图像计数归零。
Debug 符号归档因产物上限中断。
恢复后的符号归档通过完整性检查。
Intel 采集及压缩正常退出，产物池末次检查超限。
本项逐份核对已完成的采集、附件和设备收据。
