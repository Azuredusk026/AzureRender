# 预备纹理缓存命中成本

材质加载先以不可变载荷和上传参数查找纹理。
共享载荷命中时直接返回现有图像绑定。
缓存未命中或需要比较原始字节时还原载荷。
一次请求按需缓存还原结果，供比较与上传共同使用。

## 配对计时

参考源码为 `63523ad`，两端为 Release Player。
采样使用同一联合场景、1080p 视口与 NVIDIA 595.79。
两端各运行四帧，结果用于材质加载归因。
候选端在运行前后核对 1,729 项冻结输入摘要。

| 指标 | 参考 | 候选 |
| --- | ---: | ---: |
| 预备载荷直接还原次数 | 1,443 | 349 |
| 命中的直接还原次数 | 1,094 | 0 |
| 预备载荷直接还原耗时 | 5.787 秒 | 1.786 秒 |
| 材质上传阶段耗时 | 17.577 秒 | 13.317 秒 |
| 纹理缓存请求数 | 6,169 | 6,169 |
| 纹理缓存命中数 | 5,784 | 5,784 |
| GPU 纹理驻留字节 | 1,852,081,920 | 1,852,081,920 |

本场景省去 4,698,494,780 字节的重复还原。
该阶段的单组配对节省约 4.26 秒。
管线缓存状态分开记录，收益按材质阶段计算。
完整启动与稳态帧率按各自范围验收。

## 回归

缓存身份继续比较完整内容和上传参数。
混合输入比较、碰撞、上传失败及卸载归属缓存契约。
正式 Release 构建通过两项 CPU 回归。
标准与独立覆盖纹理通过四组实际 Player 采集。

图像覆盖测试的对应输出一致。
联合场景两端的缓冲与图像卸载计数均归零。
产物池中断通过清理前序任务的 NuGet 下载缓存恢复。
正式构建采用现行缓存实现。
