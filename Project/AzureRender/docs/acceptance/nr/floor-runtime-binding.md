# 地面运行绑定与颜色上传

日期：2026-10-27。范围为 NR5-R7 的两个中央地面绘制。
公共输入规则见[表面转换](../../runtime/native-surface-conversion.md)。

## 原生输入

来源为官方截帧 3534 的事件 5299 和 5310。
索引数量分别为 16857 和 6138。
实际索引与源网格对应子网格逐字节一致。
对象常量的变换与来源实体矩阵一致。

两次绘制共用实际顶点流、顶点程序和片元程序。
第二流步长为八字节，保存一组二维浮点坐标。
`TEXCOORD0/1/4` 均绑定该流的零字节偏移。
顶点程序将对应坐标传给两组纹理坐标输出。

这两个绘制的 `_MaskUVSet=1` 使用 UV0 别名输入。
掩码缩放为 `[6,6]`，偏移为零。
该结论以实际输入声明及程序共同限定范围。
其他网格的坐标来源按各自绘制核对。

## 参数与转换

材质为 `M_mod_map01_zmdbuliding+1_002_21` 和 `_24`。
四组表面颜色的 RGB 按 sRGB 函数上传为线性值。
Alpha 保持线性，遮罩权重按来源参数计算。
全部三十二行 GPU 参数的最大误差为 `6.59e-8`。

误差预算为 `1e-6`，比较覆盖两份完整参数缓冲。
纯数据测试覆盖来源颜色、非法输入及输入保持。
独立 DXBC 参考提供实际 GPU 颜色作为输入。
静态及样条入口分别通过八项 CPU 烘焙检查。

特效兼容检查覆盖发光、透明度、寻址及 HDR。
样条生成的八项数据回归通过。
公共转换保持现有材质文档、资源导入及纹理角色。
本项使用既有着色器和描述符布局。

## 主场景与边界

候选通过两份版本三完整材质文档绑定中央节点。
网格、相机、角色及三层 GI 资源保持对应候选输入。
材质保留来源的双面规则。
诊断候选的剔除警告及修正结果分别保存。

Debug 与 Release 的完整图像逐像素一致。
双配置验证层无错误，卸载后缓冲与图像计数归零。
固定地面区域的线性亮度均值为 `0.11210`。
该数值记录候选输出，完整原作对照继续验收。

烘焙纹理用于颜色上传和主入口的可见效果复核。
各来源纹理的独立过滤与层级采样继续实施。
原生相机配准、完整照明及反射按正式条件验收。
