# 八面体环境数组验收

日期：2026-10-27，范围为 NR5-R7 的资源与硬件采样。
公共格式和所有权见[运行契约](../../runtime/octahedral-environment.md)。

## 原生输入

来源为官方 3534 帧的活动照明事件 8912。
资源 14742 为 576 方形、32 层及十层级数组。
原始载荷为 56622336 字节。
全部 320 个子资源在重排时核对摘要。

原采样器采用三线性过滤及边缘夹持。
有效区域缩放为九分之八，偏移为十八分之一。
原生折叠使用数学符号，负 Z 轴映射到中心。
这项约定作为显式资源参数保存。

原绑定诊断显式替换片元输出，保留输入和采样器。
七个诊断点通过完整浮点位编码回读。
独立 D3D11 计算读取同一原始数组。
七个参考颜色与原绑定诊断逐位一致。

## 双配置检查

两配置各执行 295 个真实载荷采样。
查询覆盖全部数组层、整数及小数层级和范围夹持。
RGB 最大误差为零，预算为 `1e-4`。
UV 最大误差为 `5.97e-8`，预算为 `2e-6`。

两配置各四项新增 CTest 通过。
合成层级检查独立颜色、边缘方向和两种折叠约定。
既有环境资源及镜面环境两项回归分别通过。
所有 GPU 批次验证层无错误，资源释放归零。

完整记录包括先行失败、来源程序、查询及载荷摘要。
硬件颜色等价限定为本机两种 API 的上述采样点。
主场景消费、有序探针及完整反射继续实施。
正式 NR5、NR6 和 NR12 状态由各阶段验收决定。

结构化结果见[采样收据](evidence/2026-10-27/octahedral-environment.json)。
