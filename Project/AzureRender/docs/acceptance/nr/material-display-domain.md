## 颜色可达范围

数值诊断从上述区域抽取五百个源显示颜色。
以最近格点及阻尼迭代估计调色表的逆向输入。
皮肤样本可得到接近零的局部求解残差。
头发及眼睛的部分颜色仍保留较大残差。

迭代残差本身仅说明所用数值方法的结果。
后续使用格点的支撑平面独立检查颜色边界。
双线性切片和切片间插值均为格点的凸组合。
因此任意采样值均不能越过格点的支撑平面。

十六个眼睛抽样颜色具有有效的不可达边界证据。
其中最大通道误差下界约为 `0.08747`。
该下界高于既有 `0.008` 线性颜色预算。
证据仅限定受测调色表及所列颜色。

支撑平面及其全部数值见[颜色边界](evidence/2026-11-01/material-display-domain/gamut-certificate.json)。
数值迭代与选样见[可达性诊断](evidence/2026-11-01/material-display-domain/inverse-feasibility.json)。
这些结果支持继续建立明确的材质显示策略。
该策略与入射光、色带响应及辐亮度倍率分别持有。
