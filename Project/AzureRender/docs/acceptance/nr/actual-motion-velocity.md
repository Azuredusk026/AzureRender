# 角色实际运动速度验收

日期：2026-10-21。
范围：NR11 的物理观测与运动动画驱动。
状态：Debug CPU 回归通过。
联合场景的 Player 画面由展示验收记录。

## 运行契约

`PhysicsWorld` 持有每个角色的速度采样。
`velocity()` 提供控制器的积分速度。
`actualVelocity()` 提供最近物理步的位移速度。
两者均使用世界坐标，单位为米每秒。

实际速度取碰撞和台阶解算后的位移。
外部变换校正在采样起点之前应用。
暂停保留最近采样，单步产生一次采样。
角色删除与关卡替换按物理生命周期释放状态。

运动动画使用实际速度减去接地平台速度。
持续顶墙时，动画可进入静止状态。
沿墙滑动时，动画使用切向移动速度。
平台上的静止角色保持静止动画。

该机制同时适用于探索角色和平台玩法。
它通过物理公共接口供其他表现系统使用。
角色标识、场景路径与动画名称归属于内容。
运行说明见[角色速度观测](../../runtime/physics-input.md#角色速度观测)。

## 断言验证

验证使用正式 `GameRuntime` 与 Jolt 物理步。
顶墙用例持续输入前进与加速。
断言同时核对位置稳定、输入保持和静止动画。
该用例已保存失败与通过证据。

首次失败命中运动状态断言。
失败时，既有七个运动用例通过。
完整实现覆盖下列边界。

| 范围 | 验证内容 |
| --- | --- |
| 顶墙 | 实际位置停止，运动状态为静止 |
| 沿墙 | 阻挡方向停止，切向速度保留 |
| 移动平台 | 承载位移和角色相对运动分别核对 |
| 采样创建 | 首次物理步前返回零向量 |
| 自由移动 | 每秒位移与配置速度一致 |
| 暂停与单步 | 采样保留与单次替换 |
| 位置校正 | 瞬时传送距离属于位置校正 |
| 删除与重载 | 采样随物理状态释放和重建 |
