# 对象阴影精确深度偏置

日期：2026-10-27。范围为 NR6-C16 的对象图集生产。
公共管线能力、实际深度和角色颜色分别验收。

## 原生来源

帧 10401 的对象深度附件为 D16。
八处实际投影绘制使用反向深度偏置负八。
引擎的正向深度使用对应的正八格式单位。

七处诊断点的副本深度与普通表面深度一致。
输入法线及接收位置保留独立的来源记录。
原生接收位置由深度与逆投影矩阵重建。
当前输入的重建精度继续按整区门禁核对。

## 偏置单位

Vulkan 缺省单位允许实现采用额外缩放。
当前设备的缺省一单位产生两个 D16 单位移动。
生产诊断保存偏移八单位的失败输入。
独立 GPU 红测直接复现该偏移。

偏置规则见 [Vulkan 扩展说明](https://github.khronos.org/Vulkan-Site/features/latest/features/proposals/VK_EXT_depth_bias_control.html)。
原生定义见 [Direct3D 深度偏置](https://learn.microsoft.com/en-us/windows/win32/direct3d11/d3d10-graphics-programming-guide-output-merger-stage-depth-bias)。

## 公共能力

`GraphicsPipelineDesc::depthBiasExact` 请求精确格式单位。
调用方查询 `IRhi::supportsExactDepthBias()`。
设备协商控制特征和精确单位特征。
运行清单记录对象管线的实际选择。

缺省管线沿用 Vulkan 格式相关单位。
能力受限设备通过既有对象管线继续绘制。
不支持的显式精确请求返回错误。
阴影、共面覆盖及独立绘图可复用同一能力。

对象管线保持正八单位及零斜率。
材质为 192 字节，片元纹理槽为九个。
对象记录为版本二，每条 112 字节。
图集、同步和在途帧沿用现行所有权。

## 验证

独立 D16 夹具覆盖正负一及八单位。
三个输入深度均为整数附件值。
合计 15,360 个像素采用逐值检查。
整数深度用于独立测量偏置单位。

常量零的基准图检查完整覆盖及深度一致。
默认模式的独立诊断保留两倍单位红测。
能力拒绝和场景回退分别检查。
双配置的三项 CPU 与三项 GPU 检查通过。
两配置各三十一项公共夹具通过，共 124 帧。
对应图像跨配置逐字节一致。
Debug 与 Release 编辑器及 Player 构建通过。

## 实际对象图集

Vulkan 捕获的最终图像与普通捕获逐字节一致。
图集共同覆盖 182,211 个纹素。
有符号深度差的中位值为零，95 分位为一单位。
其中 176,136 个纹素的绝对差至多一单位。

差值超过两单位的纹素有 2,380 个。
完整图集的几何覆盖和光栅精度继续验收。
接收过滤与完整颜色沿用各自的冻结门禁。
