# 同帧表面阴影复用验收

## 结论与状态

标量阴影复用候选通过兼容与实际命中检查。
诊断开启和关闭两种配置均通过严格四帧。
两个成本控制均未取得 GPU 净收益。
候选源码及必要程序保存在精简证据。

生产采用 `64e7cc3` 的受检入口。
整体画质继续为 `failed-user-review`。
CPU 八毫秒及 GPU 16.6 毫秒标准有效。
正式采样、长跑及人工项按原条件验收。

## 载荷与检查

候选缓存完整精度的阴影可见量。
四个身份字记录深度、实例、源索引及材质。
匹配按像素独立判断，失配执行完整计算。
纹理附件每像素占二十字节。

诊断配置的最终所属检查为二十八项。
关闭诊断后的受影响检查为八项。
最终结果共三十六项通过，跳过数为零。
摘要范围明确的结果沿用，首次失败日志完整保留。

范围包括资源预算、帧槽、非法值及身份失配。
GPU 夹具覆盖混合像素、NaN、无穷值及符号零。
两设备的实际视图覆盖普通和扩展材质。
关闭计数的视图使用未启用片元原子操作的设备配置。

整数附件采样器使用最近 MIP。
消费端按指数位拒绝非有限值。
阴影程序使用实际需要的 SPIR-V 环境。
最终验证及资源释放检查均通过。

## 原生兼容与覆盖

两次原生采集均为 2560×1440 的严格四帧。
八张图像分别与原基准的 RGB 及 PNG 摘要一致。
源码、程序及 1729 项项目输入保持各次冻结状态。
同步错误及卸载分配残留均为零。

诊断配置在两次退役帧槽中取得 7958 次合格请求。
其中像素身份匹配为 7184 次，约占 90.27%。
采样间隔为三十二个像素，生产记录为 7572 次。
该覆盖率仅属于上述严格四帧及稀疏网格。

1440p 的附件容量为 147456000 字节。
1080p 的附件容量为 82944000 字节。
关闭诊断的配置具有相同载荷及身份规则。
该配置的计数缓冲容量为零。

每个角色预热六十帧，再选取六十帧。
场景尺寸为 1920×1080。
一次比较按前参考、候选、后参考顺序执行。
本组使用核心 GPU 时间戳。

| 候选 | 24.256735 | 24.347280 | 6.313600 |
