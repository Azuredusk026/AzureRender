# 公共反射过滤验收

阶段为 NR5-R8-B，公共 GPU 过滤资源分项通过。
输入包含独立室内表面夹具及原版冻结反射载荷。
主场景生产、连续历史及整体性能继续实施。
完整指纹见[结构化证据](evidence/2026-10-28/reflection-spatial-filter.json)。

## 资源与接口

过滤由渲染模块的独立资源所有者执行。
输入借用深度、表面数据及颜色层级。
六个私有描述符和 48 字节参数按槽位隔离。
输出采用 `RGBA32F`，调度复用 `ComputePass`。

构造和记录校验尺寸、层级、参数及资源别名。
输出总预算为 512 MiB，支持一至八个在途槽位。
异常清理及正常销毁沿 RHI 释放资源。
接口及同步见[反射空间过滤](../../runtime/reflection-spatial-filter.md)。

## 双配置与独立输入

Debug、Release 的 CPU 及 GPU 两项 CTest 均通过。
每种配置执行十份合成 GPU 输出。
检查覆盖常量层级、压缩颜色、深度分离及尾部工作组。
解析颜色的最大误差为 0.000000060。

同次提交记录两份不同深度衰减参数。
两份输出各自保留对应的过滤结果。
两槽位的同输入结果逐位一致。
验证层错误为零，全部缓冲及图像释放归零。

## 原版载荷与精度

真实输入保留原版七级 `R11G11B10_FLOAT` 颜色。
深度及表面数据分别保留实际投影和粗糙度语义。
可信度在本项隔离输入中固定为一。
实际动态可信度及消费者由生产接入阶段验收。

浮点坐标运算顺序由 `precise` 和显式 `fma` 固定。
源输出的向下量化已通过独立 GPU 实验核对。
跨 API 预算为原版格式的 1.01 个量化单位。
该预算同时覆盖源格式量化及浮点数值余量。

每种配置完成 921,600 像素的整图核对。
最大误差为 1.000008 个量化单位，超预算像素为零。
Debug、Release 的全部浮点输出逐位一致。
未固定运算顺序的同格式候选有 136 个超差像素。
