# 原生纹理取样足迹

D3D11 探针使用 100 种已知纹素梯度方向与长度比例，每种取 257 个尺度。纹理的 12 个 mip 层级各自存储固定编码。采样器使用线性纹素过滤、最近层级和环绕寻址。

每个设备身份读取 411,200 个像素。25,700 个取样格的角点梯度逐位匹配输入，格内各像素选择相同层级。`SampleBias` 的偏移为 −1。以二分之一的实测导数调用 `SampleGrad`，两种方式在全部格内选择同一层级。显式层级零与十一用于核对绘制覆盖。[D3D11 纹理偏移采样](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-to-samplebias)

## 设备读回

NVIDIA 和 Intel 在 2,701 个取样格选择不同层级。Intel 的两个本机适配器 LUID 各自运行探针，选层及梯度的完整读回逐字节一致。首次按厂商枚举在 Intel 条目处触发歧义检查，归档保存首次退出及 NVIDIA 的读回摘要。第二次按 PCI 标识测量全部对应 LUID，NVIDIA 逐字节复现首次结果。

| 取样尺度模型 | NVIDIA 不一致格数 | Intel 不一致格数 |
| --- | ---: | ---: |
| 最大轴长度 | 2,764 | 63 |
| 椭圆长轴 | 888 | 2,529 |
| 轴向与对角近似 | 46 | 2,745 |

轴向与对角近似取四项的最大值。轴向使用 `G(dx)` 和 `G(dy)`，对角使用 `(11/16) × G(dx+dy)` 和 `(11/16) × G(dx−dy)`，其中 `G(v)` 为绝对值较大分量加上较小分量的 `11/32`。输入为纹素梯度。

## 冻结头发对照

帧 10401 的事件 422 提供独立的实际顶点、可见图元和显式层级读回。以八位子像素坐标推导纹素梯度后，近似选层在 NVIDIA 的 17,012 个位置逐位复现冻结压缩法线。沿用原始 17,017 个位置和 10 位编码的一单位门槛，NVIDIA 有 5 处超差，Intel 在选择同一层级后有 11 处超差。椭圆长轴对照分别有 267 处和 274 处超差。

第二次 GPU 运行用时 1.172 秒，D3D11 设备状态正常。本机缺少 D3D11 SDK 调试层。实测字节码与预编译字节码逐字节一致，Release 和 Debug 的 Player 与各 895 份着色器摘要一致。整体画质状态为 `failed-user-review`，实际头发可见量与 RGB 继续按逐通道一字节验收。[结果清单](evidence/2026-11-12/native-texture-sampling-footprint/results.json)和[验证归档](evidence/2026-11-12/native-texture-sampling-footprint/validation.zip)保存取样矩阵、原始读回及两次执行收据。
