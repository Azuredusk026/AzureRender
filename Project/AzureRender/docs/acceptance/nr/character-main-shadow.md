局部灯、镜面与自发光保持各自输入契约。

其主光项由场景阴影可见度控制。
`_1649` 表达式另以该值选择室内和室外颜色。
源程序及生产模块摘要保存在结构化收据中。

生产实现位于 `shaders/mesh.frag`。
检查位于 `tools/test_npr_diffuse_gpu.py`。
公开字段及生命周期见[颜色组合](../../runtime/npr-diffuse.md)。
