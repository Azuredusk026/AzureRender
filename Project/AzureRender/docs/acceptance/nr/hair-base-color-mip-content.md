## 实际绑定

原生来源为帧 10401 的事件 950。
基色位于绑定 16，资源编号为 139677。
资源格式为 `BC7_SRGB`。
Vulkan 来源为冻结捕获的事件 493、绑定一。

两份纹理均为 2048×2048，具有十二级内容。
各级通过 RenderDoc 的 DDS 保存接口导出。
DDS 使用 Pillow 解码到八位 RGBA。
每级尺寸、原始文件和解码结果均记录摘要。

## 内容结果

十二级合计包含 5592405 个纹素。
各级 RGB 均逐通道一致，最大字节差为零。
对应 RGB 字节流的 SHA-256 均一致。
第零至十级的垂直翻转控制均存在 RGB 差异。

Alpha 具有独立的覆盖内容差异。
第零级共有 338455 个 Alpha 不同的纹素。
这些差异与 RGB 结果分别记录。
覆盖来源继续遵守既有材质及层级契约。

本项排除这两份捕获的基色 RGB 内容差异。
隐式梯度、实际层级和采样舍入分别核对。
CPU 解码结果不替代实际 GPU 取样值。
四纹素取样依据见[输入核验](exact-hair-sampling-inputs.md)。
