# 材质类别功能位特化验证

日期：2026-10-31。归属为主场景着色成本专项。
状态：实现及受影响自动检查通过，正式预算待验。
正式渲染预算继续按 NR12 验收。

## 策略与所有权

公共策略位于 `MaterialPipelinePolicy.hpp`。
同类材质的交集与并集共同确定固定功能位。
各材质之间变化的功能位由当前材质输入提供。
两个视图功能位 `0xc0000000` 由本帧输入提供。

固定掩码为 `~(intersection ^ combined) & 0x3fffffff`。
固定值为 `intersection & fixedMask`。
着色程序使用专用化编号二、三消费掩码与固定值。
材质类别使用编号一，材质布局保持一百四十四字节。

角色渲染器持有每类策略及各朝向管线。
主颜色与颜色副本共用公共选择规则。
每次绘制核对当前材质是否匹配固定掩码。
不匹配时使用已有动态管线。

空类别、未知类别及混合材质沿动态装配规则处理。
创建失败、热重载与卸载由渲染器生命周期回收。
每种颜色用途最多四十条类别管线。
实际完整场景创建二十八条类别管线。

## 公共场景

独立 Player 夹具使用两份布料材质资源。
功能值分别为三十二与四十，共享位及变化位同时存在。
三个抗锯齿配置分别为关闭、时序及四样点。
冻结程序的三项红测均命中缺少特化记录的诊断。

Debug 与 Release 各通过三项实际 Player 检查。
各配置的十帧 PNG 均与冻结夹具字节一致。
实际掩码为 `0x3ffffff7`，固定值为三十二。
程序、着色程序及输入文件均完成运行前后指纹核对。

| 反射历史实际路径 | 六组通过 | 六组通过 |

历史路径覆盖独立、共享、固定、关闭、四样点及运动。

## 实际 GPU 常量

RenderDoc 捕获实际 Vulkan 管线和编译常量。
四次布料绘制分别属于主颜色及表面快照。
着色字节码身份与当前构建的对应文件一致。
常量掩码、固定值及类别分别为 `1073741815`、`32`、`4`。

两份材质的实际提交值为 `0x80000020` 与 `0x80000028`。
时序视图位保留在动态材质输入中。
常量来自编译常量块的反射解码。
材质块仍为一百四十四字节。
