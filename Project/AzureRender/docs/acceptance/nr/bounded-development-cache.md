# 有界开发缓存验证

## 缓存与迭代

当前程序集合拥有独立缓存代次。
设备、驱动和 UUID 继续决定兼容范围。
所有代次共用 128 MiB 单文件及 256 MiB 总池上限。
最多八项，闲置七天后纳入每日维护。

本批对同一原生输入执行一次冷、暖启动。
每次只运行两帧，用于保存及重用核对。
输入、源码及全部着色程序均有摘要核对。
该批次没有采集画面及正式帧成本。

| 指标 | 空代次 | 跨进程重用 |
| --- | ---: | ---: |
| 管线准备，毫秒 | 1078.1737 | 129.7070 |
| 创建请求 | 645 | 645 |
| 应用缓存命中 | 507 | 645 |
| 保存载荷，字节 | 27300335 | 27300335 |

管线准备局部减少约 87.97%。
该数值来自本批两次启动，驱动内部缓存状态另有影响。
暖启动请求全部取得应用缓存命中反馈。
两次保存均成功，文件为 27300387 字节。

## 工具与目录

受管子进程采用任务内的十项临时及 SDK 路径。
实际 MSVC 环境及 NuGet 查询均确认 D 盘位置。
SDK 初始化采用进程内配置，项目数据按任务期限回收。
技能发现入口与完整规则均位于 D 盘项目目录。

日志及时刷新，有界保留头部及末尾。
普通任务保留一天，受管任务池为 16 GiB。
既有每日维护按一次共享额度执行。
本单元没有追加全盘扫描或重复每日清理。
