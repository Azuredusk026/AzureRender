# 乘法材质合成验收

日期：2026-10-22。
范围为 NR6-C3 的公共合成与原生候选转换。
材质契约见[角色材质画像](../../runtime/character-material-profile.md)。

## 公共能力

版本 2 画像声明 `multiply-composite` 特征。
配置对象使用 `schemaVersion: 1` 和 `mode: multiply`。
类别允许 `generic` 与 `overlay`，透明模式为 `BLEND`。
非法版本、类别、模式、字段和组合在加载时拒绝。

颜色遵守线性公式 `Cdst * mix(1, tint, alpha)`。
覆盖量消费基础纹理、材质因子和节点透明度。
选中状态调整染色颜色，覆盖量保留材质输入。
场景灯光、全局光照和反射照亮接收表面。

主颜色附件使用 `Zero/SrcColor` 混合。
目标透明度保留，次级附件关闭颜色写入。
深度比较使用 `LESS_OR_EQUAL`，深度写入关闭。
普通、镜像和双面管线具有独立创建及销毁路径。

覆盖层跳过阴影和外轮廓绘制。
透明实例及图元保持内容规定的提交顺序。
图元内部沿用现有透明三角形排序。
跨实例的全局透明排序具有独立的实现范围。
