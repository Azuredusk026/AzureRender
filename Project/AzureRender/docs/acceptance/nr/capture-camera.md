# 捕获相机来源验收

日期：2026-10-27。范围为 NR0 的捕获输入来源与指纹。
公共字段见[运行契约](../../runtime/capture-camera.md)。

## 来源与实现

官方 3534 帧的对照相机使用 10000 米远裁剪面。
关卡后备配置与实际相机具有各自的输入范围。
独立夹具复现了清单使用后备范围的偏差。
失败输入和实际报告单独保存。

捕获入口消费帧内选定的相机描述。
镜头及上向量通过现有清单输出。
近远裁剪使用相同来源。
指纹纳入完整精度的镜头、位置、目标及上向量。

## 公共检查

角色渲染与路径追踪分别执行七组场景。
同一项目路径复用相同几何和材质。
输入分别改变裁剪面、视场、正交高度、横滚及细微位置。
双配置各十四次实际采集通过。

单精度单位的位置变化具有独立指纹。
裁剪面超出可见几何的两份图像逐像素一致。
视场及正交高度变化同时符合可见面积方向。
横滚改变上向量，并产生可见的画面变化。

双配置各十四次既有投影偏移检查通过。
覆盖透视、正交、路径追踪、固定描述符及天空。
每配置两项共享相机与截帧解码检查通过。
Player 与编辑器的双配置构建通过。

完整原生对照使用已保存的空间映射及来源相机。
