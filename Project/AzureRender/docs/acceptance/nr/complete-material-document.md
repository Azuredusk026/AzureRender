## 契约与架构

`azure.profile` 保存单个 glTF 材质及图片 UUID 表。
表面参数、功能及状态沿用 glTF 画像解释器。

材质图保存相同画像，编辑表单调用生产操作。

图片表具有连续索引、类型和数量预算。
所有图片原始字节总量上限为 64 MiB。
解释过程生成受控嵌入数据，沿用原有解码器。
新增 GPU 布局和资源缓存继续按 C16 实施。

结构 Schema 描述版本、字段和参数类型。
生产解释器校验纹理、节点及合法功能组合。
命令行工具与 Python 入口消费同一解释器。
未知画像字段、小数版本和错误组合被拒绝。
