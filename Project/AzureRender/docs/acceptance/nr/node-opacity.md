# 节点透明度验收

日期为 2026-10-22，阶段归属为 NR7-L2。
范围为通用节点透明度与光栅绘制通道。
该能力可用于物流实例和层级提示组。
原生物流曲线的联合接入单独验收。

## 实现范围

资产扩展为 `AZURE_node_opacity`，版本为 1。
节点默认值为 1，有效范围为 `[0,1]`。
支持阶梯、线性和三次样条动画。
动画混合后按祖先链计算有效透明度。

不可变绘制快照保存各实例的有效值。
图元通过来源节点选择透明度。
相邻相同透明度保持实例批次。
透明度为零的图元省略绘制。

颜色、采样深度、阴影和描边共用覆盖函数。
不透明材质使用物体空间稳定抖动。
混合材质在线性空间乘入最终透明度。
几何尺寸、骨骼与表情保持各自语义。

淡出描边持有独立的完整几何遮罩。
重叠实例各自拥有一块图集区域。
完整几何先建立深度，随后绘制外壳轮廓。
遮罩的资源规则见[节点透明度](../../assets/node-opacity.md)。

## 验证配置

主设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
构建配置为 MSVC Debug 与 Release。
独立图像夹具分辨率为 `256×192`。
颜色夹具关闭抗锯齿、泛光和色调映射。

阴影夹具使用 `stylized-key` 灯组。
其他夹具使用场景灯组与反照率隔离视图。
混合检验先将截图转换回线性空间。
固定纹理表对照同时关闭计算蒙皮与并行录制。

CPU 回归每个配置覆盖九项。
覆盖节点、绘制批次、帧快照及动画曲线。
姿态、表情和形变目标参与受影响回归。
原有三个 GPU 用例覆盖角色与折射组合。

选中图元的变换通过真实录制路径检查。
颜色、深度、阴影、遮罩与描边使用共用矩阵。
夹具覆盖平移、旋转、缩放与未选图元。
固定纹理表和计算蒙皮的四种组合均需通过。

## 验收标准

单物体分别捕获透明度 `0`、`0.5` 和 `1`。
主颜色与采样深度的中点覆盖率应接近一半。
混合材质的线性响应应处于 `0.48～0.52`。
阴影响应应随透明度变化。

不透明及描边图像须满足端点归属检查。
半透明像素应来自隐藏或完整端点。
重叠夹具验证前景轮廓与遮罩所有权。
固定路径的像素差不得超过 1。

所有捕获均要求脚本与表现系统无错误。
Debug 同时要求 Vulkan 验证无错误与警告。
卸载后 GPU 分配器的图像和缓冲均为零。
具体数字和来源指纹见[验收记录](evidence/2026-10-22/node-opacity.json)。

Debug 与 Release 各完成 24 次捕获。

Debug 验证层的错误与警告均为零。

## 限制

图像夹具验证通用契约及受影响绘制路径。
目标场景的高分辨率性能仍需联合测量。
路径追踪尚需消费节点透明度。
原生曲线的实际发射语义由物流内容管线记录。
