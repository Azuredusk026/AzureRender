# R2 阶段验收记录

> 日期：2026-09-26
> 平台：Windows、Vulkan、MSVC 14.44

## 已验证内容

- RHI Compute Pipeline、计算描述符绑定与非空调度已接入 Vulkan 和 NullRHI。
- `ComputePass` 提供尺寸向上取整、空尺寸跳过和禁用降级行为。
- GPU 能力报告记录 Compute 与无格式存储图像能力，并同步 JSON Schema。
- 光源按 `stableId` 稳定排序，并打包为 GPU 友好的位置半径与颜色强度布局，支持数量上限。
- 级联阴影分割使用可复现的对数与均匀混合计算。
- OpenEXR 环境资源按线性浮点通道读取为 RGBA16F，支持非零数据窗口原点；损坏文件返回包含路径的格式化错误。
- 聚簇光照网格提供确定性的二维屏幕加对数深度索引表，支持 GPU 索引缓冲展平。

## 2026-09-30 运行期 Compute 进展

- Blackhole 接入四级 HDR Bloom Compute：亮部提取、三级降采样与多级合成写入 RGBA16F 图像，TAA Pass 采样合成结果。
- RTX 2060 Debug Validation 下运行 Blackhole 30 帧，Compute 路径已确认，验证层无错误。`AzureRender.BlackholeComputeGpu` CTest 检查实际 Compute 路径并扫描 Validation 输出。
- 1280×720 Balanced 首帧与旧输出均值差 `0.0001315`，超过 `0.00784` 的通道阈值像素占比为 `0.00313`。变化来自多级 Bloom，角色基线不受影响。
- Character 环境图新增 GPU 粗糙度预滤波 Mip，漫反射采样最粗 Mip，镜面采样按粗糙度选层。Debug Validation 下 30 帧运行无错误，`AzureRender.CharacterIblComputeGpu` CTest 验证实际执行。
- Character Beauty 基线已按 GPU IBL 的有意着色变化更新；Albedo、Normal、Material ID、Outline、Direct Diffuse 与 Face SDF 六项保持原基线。
- Release R2 基准：RTX 2060、1280×720、300 帧。Character 平均 `0.526 ms`、p95 `0.917 ms`、p99 `1.017 ms`；Blackhole 平均 `10.613 ms`、p95 `10.921 ms`、p99 `11.527 ms`。完整分配与提交数据见 `build/perf/R2/`。

## 2026-09-30 光照、阴影与动画蒙皮验收

环境：Windows 11、MSVC 14.44、Vulkan、RTX 2060；GPU 采样分辨率为 1280×720。

- 角色片元着色器读取场景点光缓冲、屏幕瓦片与对数深度聚簇索引。`ClusteredLightGrid` 将光源影响球体分配到覆盖聚簇，并按确定顺序展平头索引和光源索引。
- 四级级联阴影写入 2×2 深度图集，片元按相机视深度选择级联。每级保留 12 次遮挡物搜索和 16 次 PCF 过滤，采样限制在所属图集区域。NullRHI 检查四个 viewport；Debug Vulkan Validation 下蒙皮场景 30 帧无错误。
- 公共角色网格包含单关节线性动画和一个 Morph 目标。第 16 帧、Morph 权重 `0.75` 下，Compute 与顶点回退 Beauty 均值差和变化像素占比均为 `0`；零权重与形变帧均值差 `0.122428`，变化像素占比 `0.523045`。`AzureRender.CharacterSkinningComputeGpu` 与 `AzureRender.CharacterMorphComputeGpu` 覆盖实际 GPU 调度和回退一致性。
- `AzureRender.ClusteredLightingGpu` 比较相同角色在 0 与 16 个点光源下的捕获，均值差 `0.001293`，变化像素占比 `0.036572`；测试同时扫描 Vulkan Validation 输出。
- `AzureRender.SceneModel` 验证 v3 光源字段往返，并确认 v1/v2 场景读取后提供空光源列表。
- Debug 与 Release 的 `ctest --test-dir build/msvc-debug --output-on-failure`、Release Gate 内部 CTest 均为 33/33 通过。七视图严格回归、固定描述符回归、顶点蒙皮回退、Blackhole Bloom、Character IBL、动画 Morph、聚簇光照与安装清单测试均通过。
- Release Gate 命令：`cmake -DBUILD_DIR=build/msvc-release -DCONFIG=Release -P tools/run_release_gate.cmake`。`build/msvc-release/release-gate/result.json` 显示安装、隔离运行、资源校验、内容清单和压缩包检查全部通过，安装包 SHA-256 记录在该结果文件中。
- Release 性能基线：RTX 2060、1280×720、300 帧。Character 平均 `0.554 ms`、p95 `0.952 ms`、p99 `0.959 ms`；Blackhole 平均 `10.711 ms`、p95 `10.980 ms`、p99 `15.054 ms`。Character 每帧 12 次 draw、2 次 descriptor 绑定。
- 标准 Release GPU 基准命令：`python tools/run_performance_baseline.py --executable build/msvc-release/AzureRender.exe --stage R2 --frames 300 --output-dir build/perf --summary build/perf/R2/summary.json`。
- 聚簇规模命令：`python tools/run_clustered_light_performance.py --executable build/msvc-release/AzureRender.exe --output-dir build/perf/R2/light-scale --frames 300`。
- 0/16/64/128 个局部光源分别产生 0/296/1385/3225 个聚簇引用。主场景平均 GPU 时间为 `0.296/0.327/0.367/0.484 ms`，总帧平均为 `0.532/0.595/0.578/0.673 ms`。
- 128 个光源下总帧平均较 0 光源增加 `26.5%`，draw 与 descriptor 绑定保持 12/2 次每帧。完整数据见 `build/perf/R2/light-scale/clustered-light-performance.json`。
- Windows Debug 安装树用于开发机验证，依赖本机 Visual Studio Debug CRT 与对应依赖运行库。Release Gate 对 Debug 配置记录 `development-only`，可分发压缩包只由 Release 配置生成。
