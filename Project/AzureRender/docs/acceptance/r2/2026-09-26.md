# R2 阶段验收记录

> 日期：2026-09-26
> 平台：Windows、Vulkan、MSVC 14.44

## 已验证内容

- RHI Compute Pipeline、计算描述符绑定与非空调度已接入 Vulkan 和 NullRHI。
- `ComputePass` 提供尺寸向上取整、空尺寸跳过和禁用降级行为。
- GPU 能力报告记录 Compute 与无格式存储图像能力，并同步 JSON Schema。
- 光源按 `stableId` 稳定排序，并打包为 GPU 友好的位置半径与颜色强度布局，支持数量上限。
- 级联阴影分割使用可复现的对数与均匀混合计算。
- OpenEXR 环境资源按线性浮点通道读取为 RGBA16F，支持非零数据窗口原点；损坏文件返回包含路径的格式化错误。
- 聚簇光照网格提供确定性的二维屏幕加对数深度索引表，支持 GPU 索引缓冲展平。
