# R2 阶段验收记录

> 日期：2026-09-26
> 平台：Windows、Vulkan、MSVC 14.44

## 已验证内容

- RHI Compute Pipeline、计算描述符绑定与非空调度已接入 Vulkan 和 NullRHI。
- `ComputePass` 提供尺寸向上取整、空尺寸跳过和禁用降级行为。
- GPU 能力报告记录 Compute 与无格式存储图像能力，并同步 JSON Schema。
- 光源按 `stableId` 稳定排序，并打包为 GPU 友好的位置半径与颜色强度布局，支持数量上限。
- 级联阴影分割使用可复现的对数与均匀混合计算。

## 测试证据

- Debug：`ctest --test-dir build/ninja-msvc-debug --output-on-failure`，25/25 通过。
- Release：`ctest --test-dir build/ninja-msvc-release --output-on-failure`，25/25 通过。
- 新增契约：`AzureRender.ComputePass`、`AzureRender.CascadedShadow`。
- 既有视觉回归、固定描述符回归、发布门禁和安装清单测试均通过。

## 后续验收入口

多级 Bloom、GPU IBL、Compute 蒙皮与 Morph、OpenEXR 解码、聚簇光照以及真实级联阴影 Pass 继续沿用本阶段的 Compute、能力报告、光源打包和 Render Graph 契约；完成对应场景接入后补充 GPU 时间、视觉基线和资产兼容证据。
