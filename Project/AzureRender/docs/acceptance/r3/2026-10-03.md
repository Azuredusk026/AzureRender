> 文档类型：验收记录
> 状态：生效
> 更新日期：2026-10-03
> 适用范围：Windows Vulkan，RTX 4060 Laptop GPU

## 阶段结论

R3 保持 Active。现有性能采样按 `r3-budget-v2` 达标，自动判定工具与阶段证据收尾尚待完成。

当前实现具备只读帧快照、独立命令池、并行录制、GPU 剔除与间接提交。性能预算按[渲染核心实施计划](../../plans/render-core-implementation.md)中的 `r3-budget-v2` 执行。

## 实现契约

四个常驻工作线程与主线程参与录制。五个线程分别使用独占命令池，任务批次持有稳定存储。任务完成后合并统计并执行图，资源重用由帧 fence 约束。

全部网格蒙皮在一个 Compute Pass 中分别调度，各网格输入、输出和共享关节缓冲具有明确依赖。透明实例最多划分为四个连续片段，执行顺序与快照索引顺序一致。

阴影和主场景回调读取共享只读上下文，显式传入 recorder 与独立统计槽。GPU 缓冲和加载期资源由资源所有者保持到对应 fence 完成。

## 定位与后续工作

任务级采样确认蒙皮小任务和透明片段存在调度开销。当前版本已合并蒙皮并划分透明录制，功能回归通过。并行 CPU 录制较串行增加约 23%，绝对增加 0.085914 ms。

现有原始 JSON 保留采样时的判定字段。现行标准复核结果见 `evidence/2026-10-03/budget-v2-evaluation.json`。后续同步性能工具的判定逻辑，再完成阶段证据与提交。

## 复现命令

在工程目录执行：

```powershell
ctest --test-dir build/ninja-msvc-debug --output-on-failure
cmake -DBUILD_DIR=build/ninja-msvc-release -DCONFIG=Release -P tools/run_release_gate.cmake
python tools/run_r3_performance.py --executable build/ninja-msvc-release/AzureRender.exe --output-dir build/perf/R3-current --generate-resources 32 --frames 300 --repeats 3 --check-recording-budget
python tools/run_r3_performance.py --executable build/ninja-msvc-release/AzureRender.exe --output-dir build/perf/R3-small-current --instances 256 --frames 300 --repeats 3
```

MSVC 构建环境使用 `vcvars64.bat -vcvars_ver=14.44`。完整阶段门禁由[渲染核心实施计划](../../plans/render-core-implementation.md)定义。
