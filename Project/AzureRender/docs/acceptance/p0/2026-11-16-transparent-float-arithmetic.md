# 普通透明混合画面验收

支持 VK_KHR_shader_float_controls2 的设备对普通透明混合片段程序使用固定的 32 位浮点表达式舍入顺序。浮点策略采用有限值假设，并允许忽略零的符号及使用倒数转换。表达式按既定乘加和结合顺序完成各步舍入。独立覆盖率和材质采样策略沿用各自的管线规则。设备功能支持情况决定采用的片段程序。

## 画面回归

NVIDIA 595.79 上，Release 和 Debug 均执行原注册命令。五项检查覆盖不透明对照、普通透明对照，以及公开角色的默认路径、兼容描述符路径和兼容蒙皮路径。公开角色每套配置比较 21 张图，差异像素为零。

普通透明对照在两轮采集中分别使用五条渲染路径和十帧。每轮的路径输出一致，两轮输出也一致。

## 帧时间

固定 80 W 的 Release 单场景配对测试使用同一个 GPU。两次参考和候选的 GPU P95 分别为 9.941、9.947 和 10.225 毫秒。候选比参考均值多 0.281 毫秒，参考组间差为 0.006 毫秒。
