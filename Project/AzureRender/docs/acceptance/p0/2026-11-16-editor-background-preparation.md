# 编辑器场景管线准备验收

编辑态资源刷新按帧推进场景准备。图形管线在后台创建，主窗口继续呈现，并显示资源准备状态。场景准备完成后，窗口在帧边界发布新场景。资源请求处理缩略图失效，保留与当前资源匹配的缩略图。发布场景时保留准备期间创建的预览。

## 正式宿主

Release 宿主通过四项注册检查，覆盖开发工具、程序化资产、编辑器主流程和可玩场景。探索与资产检视项目通过 Windows 原生回放，覆盖视角、窗口缩放、焦点、文件对话框和资产拖放。原生输入回放通过 Windows 消息和输入调用执行。实体设备、输入法和多屏交互列入现场复核。
