# 编辑器与渲染组合验收

组合构建包含编辑器场景管线、普通透明混合和 .NET 9.0.22 托管运行时。在 NVIDIA 595.79 上，Release 宿主通过 11 项已注册检查。

渲染检查覆盖不透明和普通透明对照，以及公开角色的默认路径、兼容描述符路径和兼容蒙皮路径。每条公开角色路径比较七张冻结图，差异像素为零。

编辑器检查覆盖宿主、可玩预览、开发工具和程序化资产。探索项目和检查项目均完成 Windows 原生交互回放。CoreCLR 与 NativeAOT 工作流均完成项目运行、编辑器预览与移动安装包启动。
