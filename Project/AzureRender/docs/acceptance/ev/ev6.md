## 交换契约

交换包入口扩展名为 `.azuresceneexchange`。
版本为 1，资源表和节点表分别保存共享资源与实例。
节点具有稳定来源 ID、父节点和局部变换。
模型资源使用米制，交换描述的位移按单位换算。

局部变换支持三轴位移、角度旋转和缩放。
矩阵采用列优先排列的 16 个数值。
镜像和非均匀缩放由现有变换分解服务校验。
含剪切或奇异变换的候选返回错误。

节点支持材质槽位覆盖及游戏相机描述。
点光保存颜色、强度、范围和启用状态。
其他灯光类型进入损失表。
Blender 能量单位的外观对应关系需另行验收。

解析拒绝未知版本、重复 ID 和循环父链。
缺失依赖、目录逃逸和非有限数值同样拒绝。
交换描述预算为 16 MiB，单模型预算为 512 MiB。
节点与资源预算分别为十万和一万条。
