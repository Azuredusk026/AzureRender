## 表情契约

`ExpressionPose` 使用版本 1。
预设包含身份、骨架指纹、骨骼增量及形态值。
骨骼以稳定层级路径定位。
形态以节点路径和目标名称定位。

指纹覆盖层级路径、局部姿态和逆绑定矩阵。
算法标识为 `expression-v1-fnv64`。
该值用于兼容性检查，属于非加密指纹。
未知版本、缺失目标和不匹配骨架均被拒绝。

骨骼层叠加局部平移与局部旋转增量。
旋转增量按最短路径球面插值混合。
形态值按预设权重覆盖当前姿态。
输入姿态和共享资源保持只读。

`applyExpressionPose` 返回独立姿态。
`resolveAssetPose` 重建世界矩阵和蒙皮矩阵。
调用顺序为身体动作、表情层、实例覆盖。
矩阵节点需先分解为平移、旋转和缩放。

## 持久化与操作

`azure.animator` 组件版本为 4。
`expression` 保存版本化预设 JSON 文本。
`expressionWeight` 保存零至一的混合权重。
`morphOverrides` 保存版本化权重数组。

版本 3 的迁移保留既有两个形态字段。
新增预设与覆盖默认使用空配置。
组件注册器校验文本中的版本和有限数值。
运行帧使用强类型共享预设及独立权重数组。

编辑操作通过组件事务维护撤销和重做。
保存、重开及 Play/Stop 使用现有文档机制。
编辑器与自动入口调用相同生产操作。

| 操作 | 用途 |
| --- | --- |
| `animation.expression.apply` | 校验模型并应用预设 |
| `animation.expression.clear` | 清空选中对象的预设 |
| `animation.expression.weight` | 调整表情强度 |
| `animation.morph.set` | 按目标身份设置形态权重 |

预览帧与运行帧均携带表情配置。
骨架辅助线使用叠加后的真实姿态。
动画面板提供表情强度及清除操作。
渲染消费者的集成由 EV4 验证。
