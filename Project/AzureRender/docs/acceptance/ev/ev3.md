# 通用形变数据验收

日期：2026-10-16。阶段：EV3。
状态：数据加载和曲线采样通过，渲染集成由 EV4 验证。

加载器保留每个节点的默认形态权重。
形态范围记录节点、顶点区间和目标名称。
每个网格支持最多 64 个形态目标。
目标包含位置、法线与切线增量。

访问器读取前验证缓冲范围与步长。
稀疏访问器支持缺省零值基础缓冲。
稀疏索引必须递增且位于合法范围。
资产稀疏展开预算为 512 MiB。

动画支持 TRS 与可变宽度权重通道。
曲线支持 STEP、LINEAR 与 CUBICSPLINE。
三次曲线按键间隔缩放切线。
四元数采样保持归一化。
