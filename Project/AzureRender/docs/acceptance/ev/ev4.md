## 实现契约

形态数据由共享模型持有，实例持有独立权重。
每个目标包含位置、法线及切线增量。
求值顺序为身体动作、表情、实例覆盖和蒙皮。
每网格最多 64 个目标，GPU 数据预算为 128 MiB。

计算蒙皮、顶点回退、阴影与描边读取相同数据。
CPU 拾取与路径追踪消费完整实例姿态。
路径追踪累积指纹包含表情内容及覆盖权重。
包围盒缓存关节与目标的增量区间。

包围盒求值按权重符号累计区间边界。
每帧成本取决于关节及目标数量。
非法范围、重叠、宽度和非有限值均被拒绝。
GPU 打包失败保留调用前的输出内容。
