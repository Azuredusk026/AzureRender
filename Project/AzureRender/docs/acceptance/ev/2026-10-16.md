## 运行入口

以下命令从引擎目录执行。
先使用产物工具创建独立运行目录。
将 `$run` 设为该目录的绝对路径。
构建产物冻结后再执行 GPU 检查。

```powershell
python tools/run_resource_validation.py `
  --suite assets_public/resource_validation/validation-suite.json `
  --output "$run/public" `
  --player build/ninja-msvc-release/AzurePlayer.exe `
  --project assets_public/resource_validation/game/project.azureproject `
  --character assets_public/resource_validation/game/assets/character.gltf `
  --scene assets_public/resource_validation/game/assets/validation.azurelevel `
  --animation idle

python tools/run_resource_validation.py `
  --suite assets_public/resource_validation/validation-suite.json `
  --output "$run/private" `
  --player build/ninja-msvc-release/AzurePlayer.exe `
  --project assets_private/resource_validation/game/project.azureproject `
  --character assets_private/resource_validation/game/assets/character.glb `
  --scene assets_private/resource_validation/game/assets/validation.azurelevel `
  --animation idle

python tools/test_character_finish.py `
  --executable build/ninja-msvc-release/AzureRender.exe `
  --asset assets_private/resource_validation/ev2/baked60/character.glb `
  --output "$run/character" --camera full-body-front `
  --camera face-side-left --camera back-detail --camera face-front `
  --light neutral-material

python tools/test_material_fixture.py `
  --executable build/ninja-msvc-release/AzureRender.exe `
  --asset assets_public/third_person/material_fixture.gltf `
  --output "$run/material-fixture"

python tools/test_material_authoring.py `
  --executable build/ninja-msvc-release/AzureRender.exe `
  --player build/ninja-msvc-release/AzurePlayer.exe `
  --output "$run/material-authoring"

python tools/test_independent_animation_gpu.py `
  --executable build/ninja-msvc-release/AzurePlayer.exe `
  --output "$run/independent-animation"

python tools/run_r3_comparison.py `
  --executable build/ninja-msvc-release/AzureRender.exe `
  --output-dir "$run/transparency" `
  --frames 10 --instances 16 --transparent-fixture

ctest --test-dir build/ninja-msvc-release --output-on-failure `
  --no-tests=error -R 'AnimationPose|AssetDeformation|SkinningBatch|SkinningGpu|IndependentAnimationGpu|AnimationAuthoring|MaterialDocument|AssetLevel|MorphTargets|AnimationCurve|ExpressionPose|SceneImport'
```
