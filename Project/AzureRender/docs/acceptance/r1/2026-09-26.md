# R1 阶段验收记录

> 文档类型：阶段验收
> 状态：生效
> 更新日期：2026-09-26
> 适用范围：Windows Vulkan 渲染核心同步契约

## 目标

完成图像与缓冲区屏障描述、Vulkan 提交路径、NullRHI 记录路径，并保持现有场景渲染回归通过。Android 目标在本阶段保持 Deferred。

R1 的公共帧收口还登记了 shadow、scene、post-process 和 editor-ui Pass。`RenderGraph` 在每帧录制前编译资源声明，失败时阻止提交并输出诊断。

## 实现与文档

`ICommandRecorder` 提供图像和缓冲区屏障接口；Vulkan 后端映射到 `vkCmdPipelineBarrier`；NullRHI 输出句柄、范围和访问掩码。运行时规则见 `docs/runtime/rhi-synchronization.md`，总计划状态由 `docs/plans/azure-engine-plan.md` 维护。

## 风险与限制

当前接口面向单图形队列，未覆盖跨队列所有权转移。窗口最小化、恢复和关闭的等待逻辑由可替换前端测试覆盖；真实窗口事件与 Vulkan 交换链重建已通过下文联调。Release 既有测试中的 `assert` 受 `NDEBUG` 影响；新增生命周期与屏障错误检查使用显式退出码。

## 参考来源

Vulkan 1.3 规范的 pipeline barrier 章节；项目内 `docs/documentation-standard.md`。


## 执行环境与复现命令

设备为 NVIDIA GeForce RTX 4060 Laptop GPU，Vulkan SDK 为 1.4.350.0，编译器为 MSVC 19.44。命令在项目根目录执行。开发者终端使用 `VsDevCmd.bat -arch=x64 -vcvars_ver=14.44`，确保编译器与系统头文件版本一致。

```powershell
cmake --build --preset msvc-debug
ctest --test-dir build/ninja-msvc-debug --output-on-failure
cmake --build --preset msvc-release
ctest --test-dir build/ninja-msvc-release --output-on-failure
python tools/check_windows_surface.py
python tools/run_performance_baseline.py --executable build/ninja-msvc-release/AzureRender.exe --stage R1 --frames 150 --output-dir build/r1-performance --summary build/r1-performance/summary.json
```

Debug 与 Release 均通过 19/19 CTest，包含默认与固定描述符路径的 GPU 视觉回归。`SurfaceLifecycle` 覆盖有效尺寸、最小化恢复、等待期间关闭与已关闭窗口；测试先在原等待逻辑下失败，修复后通过。真实窗口测试通过调整尺寸、最小化恢复及最小化关闭，退出码均为 0，Debug 验证层启用且未报告 VUID。日志位于 `build/r1-window-restore.log` 与 `build/r1-window-close-minimized.log`。

性能记录使用 1280×720、150 帧。角色 GPU 总平均为 0.257 ms，p95 为 0.266 ms；黑洞 GPU 总平均为 9.493 ms，p95 为 11.182 ms。机器可读报告位于 `build/r1-performance/summary.json`。这些数值是本机采样，不能作为其他设备的预算。


## 发布与构建记录

Debug 和 Release 发布门禁均通过，覆盖配置、构建、19 项测试、安装、迁移安装目录、资源校验、隔离运行环境、打包与内容清单校验。结果分别保存在 `build/ninja-msvc-debug/release-gate/result.json` 和 `build/ninja-msvc-release/release-gate/result.json`。安装清单由现有门禁生成，源资产 manifest 与 Schema 版本保持适用。

```powershell
cmake -DBUILD_DIR=build/ninja-msvc-debug -DCONFIG=Debug -P tools/run_release_gate.cmake
cmake -DBUILD_DIR=build/ninja-msvc-release -DCONFIG=Release -P tools/run_release_gate.cmake
```

阶段提交标题为 `feat(r1): 建立桌面同步契约`，提交范围包含本页；可通过 `git log --grep="feat(r1)"` 定位提交。生成证据保存在已忽略的 `build/`，开发者复现时重新生成。

Debug 与 Release 的 sample、character、blackhole 各完成 120 帧冒烟测试，六次退出码均为 0。对应日志位于 `build/r1-<配置>-<场景>.log`。本阶段按路径隔离生成文件，保留用于复现的日志与性能报告。
