### 2. 构建失败:imgui 版本漂移(阻塞,需决策)

- 代码 ImGuiEditorLayer.cpp 使用旧 API(MSAASamples、CreateFontsTexture、DockSpaceOverViewport 双参),与 vcpkg 安装的 imgui 1.92.8(2025/09/26 大改版)不兼容
- vcpkg.json builtin-baseline 锁定 imgui 1.92.8(与代码 API 冲突,疑似接手前 Windows 构建从未真正验证过 ImGui 路径)
- 本地 vcpkg 只有 1.92.8 源码缓存,无网络无法安装旧版
- 修复方向:适配 imgui 1.92.8 新 API(InitInfo.PipelineInfoMain.RenderPass/MSAASamples、字体纹理 API 变化、DockSpaceOverViewport 四参)

### 3. 构建环境关键经验(Windows + MinGW)

- Git Bash 下 MinGW g++ 编译静默失败:TMP/TEMP 被 Git Bash 设为 POSIX 路径(/tmp),g++ 无法写入临时文件
- 解决:使用 PowerShell 工具构建,或在 bash 中 export TMP/TEMP 为 Windows 路径
- ninja 在 D:/JetBrains/CLion 2026.1/bin/ninja/win/x64,不在 PATH
