## 设备

| 设备 | 功能与资源查询 | 实验资格 |
| --- | --- | --- |
| RTX 4060 Laptop | 动态渲染与局部读取功能通过，三色槽及组合格式通过 | 具备三路径能力，执行待验 |
| Intel 核显 | 同一颜色单样本负载能力通过 | 补充桌面设备，执行待验 |
| Xiaomi 14 / Adreno 750 | 系统工具返回 Vulkan 1.3，当前列表缺少 DRLR | 与用户能力查看器记录待复核 |

手机查询根节点的 API 版本描述加载器。
设备 API 版本以 `devices[].properties` 为准。
原生程序将直接查询功能并核验设备创建。
其传统及子通道组合用途与实际运行继续核验。

原生 ARM64 查询已取得相同设备及驱动版本。
实际组合用途查询支持两个候选尺寸。
动态渲染功能为真，局部读取功能为假。
请求局部读取扩展创建设备返回错误码 -7。

错误码对应 `VK_ERROR_EXTENSION_NOT_PRESENT`。
该结果适用于当前系统原生驱动通道。
用户的能力查看器观察保留为待对照证据。
发布方查看器下载本次返回 HTTP 403。

本负载只局部读取颜色附件，样本数为一。
桌面另记录深度与多采样局部读取属性。
两个 Intel 枚举项按设备清单原样保存。
正式矩阵通过设备身份固定实际选择。

## 工具

桌面使用 SDK 1.4.350.0 的头文件与加载器。
资格程序通过独立 CMake 目标构建。
手机使用既有 RenderDoc 内的 ADB。
手机原始查询命令为 `adb shell cmd gpu vkjson`。

桌面计时采用图形队列的有效时间戳。
查询记录时间戳周期及有效位。
硬件流量计数工具的实际可用性待测。
正式采集使用统一重负载租约入口。

## 实现缺口

现有 `VulkanRhi.cpp` 创建单子通道渲染通道。
其路径枚举可用于标签与配置选择。
实际子通道切换及 DRLR 仍需实验目标实现。
传统路径也需执行论文共同三阶段负载。

独立目标持有实验资源与命令生命周期。
轮廓邻域读取采用共同外部采样阶段。
三路径的图像、同步、释放及计时分别验收。
正式数据以实际执行和环境资格为准。
