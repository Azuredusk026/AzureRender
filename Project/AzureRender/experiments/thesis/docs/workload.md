# 共同负载契约

日期：2026-11-09。
状态：实现候选，正式矩阵待冻结。

## 输入与几何

场景使用本项目生成的单位球网格。
低复杂度为 32 经线与 16 纬线区间。
高复杂度为 128 经线与 64 纬线区间。
两档分别包含 960 与 16128 个三角形。

网格由固定公式生成，源码及输出摘要记录来源。
材质为固定橙色，采用固定方向光。
相机使用正交投影，目标中心与观察方向固定。
对象、灯光及相机在测量期间保持静止。

过程网格属于本项目实验输入。
其许可沿用仓库许可，分发时附源码及许可。
原生角色素材继续用于所属工程验收。
论文复杂度结论限于该几何变化及共同着色负载。

## 附件

所有附件使用单样本、单层和最优平铺。
尺寸候选为 1920 × 1080 与 2560 × 1440。
格式能力按实际组合用途查询。

| 名称 | 格式 | 用途与存活范围 |
| --- | --- | --- |
| 反照率 | `R8G8B8A8_UNORM` | 几何写入，卡通阶段读取 |
| 法线与深度 | `R16G16B16A16_SFLOAT` | 几何写入，卡通及轮廓读取 |
| 深度测试 | `D32_SFLOAT` | 几何阶段深度测试 |
| 卡通结果 | `R8G8B8A8_UNORM` | 卡通阶段写入，轮廓读取 |
| 最终结果 | `R8G8B8A8_UNORM` | 轮廓写入，区间外读回 |

法线附件前三通道保存插值单位法线。
第四通道保存投影后的零至一深度。
深度测试附件通过清除开始，结束后可丢弃。
本负载的局部读取只使用颜色附件。

## 阶段与访问

几何阶段使用同一顶点序列及片元程序。
卡通阶段按同像素读取反照率与法线。
它使用相同光向、量化级数及背景规则。
轮廓阶段使用同一全屏程序。

轮廓读取中心及上下左右的法线与深度。
像素坐标在图像边缘夹取到合法范围。
轮廓阈值及最终颜色规则由共同着色器持有。
背景清除值、量化格式与采样位置保持一致。

传统路径用独立通道和纹素读取连接前两阶段。
子通道路径在同一渲染通道内切换子通道。
局部读取路径在动态渲染范围内设置局部依赖。
三路径的轮廓均在独立的共同渲染通道执行。

子通道及局部读取采用输入附件读取同像素。
局部依赖使用按区域的颜色写入至输入读取。
轮廓依赖使用完整图像范围的写入至采样读取。
局部依赖和邻域依赖分别记录。

## 生命周期与流量模型

反照率在局部卡通着色后可结束生命周期。
法线与深度需要保留至轮廓阶段。
卡通结果需要跨渲染范围供轮廓读取。
最终结果在测量后复制至主机。

模型按每像素未压缩附件字节量计算。
共同逻辑访问量与假设的外部流量分别记录。
局部路径可按反照率局部复用建立下界场景。
法线附件的后续存活要求进入模型。

驱动是否合并阶段与实际写回由观测解释。
输入附件机制本身不能证明物理零流量。
硬件计数器独立记录工具、单位和覆盖区间。
计数器缺失时明确报告可观测范围。

## 测量与正确性

GPU 时间戳包含三个阶段及阶段间依赖。
时间戳排除图像读回与文件保存。
CPU 计时单独覆盖共同命令的录制。
命令池重置、等待、提交及呈现分别处理。

资格阶段启用可用验证层与同步验证。
性能阶段记录层状态和程序指纹。
图像比较覆盖背景、球体边界和内部明暗带。
优先验证三路径 RGBA 字节完全一致。

试运行核对时间戳有效位及纳秒转换。
正式运行前冻结输入、程序、设备及运行顺序。
五次独立进程运行作为候选重复设计。
每次运行的 GPU 样本方差采用 n − 1 分母。
