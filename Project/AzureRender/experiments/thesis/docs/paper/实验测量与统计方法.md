# 实验测量与统计方法

日期：2026-11-12。
研究目标沿用 O1 至 O3 与关联性 H3。
正式结果由合格设备的独立运行记录产生。

## 比较条件

每组固定设备、驱动、尺寸及几何复杂度。
组内比较传统多遍、子通道与 DRLR。
相机、材质、灯光和着色器计算保持一致。
共同轮廓阶段读取中心及四个相邻像素。

局部交换只发生在几何与卡通着色之间。
反照率在卡通阶段后结束生命周期。
法线与深度附件继续供轮廓阶段读取。
三路径均按此生命周期定义存储与依赖。

两档过程球网格具有固定的生成公式。
低档含 960 个三角形，高档含 16128 个。
几何复杂度解释限于该输入变化。
公开复现包记录生成源码、配置和输入摘要。

## 时间区间

GPU 时间戳从几何阶段前记录至轮廓结束。
该区间包括阶段间依赖与必要布局转换。
图像读回、复制文件和交换链呈现位于区间外。
查询记录队列家族、有效位与纳秒周期。

CPU 录制区间包围共同三阶段的命令录制。
命令池重置、时间戳命令和提交等待分别处理。
场景准备、资源创建和着色器编译位于采样外。
呈现工作单独记录，按其实际调用区间解释。

当前基准逐帧等待 GPU 完成。
该策略用于三路径一致的独立帧区间比较。
它的吞吐与帧间调度结论限于该策略。
交换链间隔和端到端交互延迟另有测量含义。

## 附件字节模型

模型使用单样本的未压缩全帧等效附件访问量。
令像素数为 P，所有项按每像素格式字节计算。
它描述逻辑工作量与局部复用假设。
硬件外部事务采用单独的计数器观察。

| 阶段 | 每像素逻辑访问 | 字节量 |
| --- | --- | ---: |
| 几何缓冲 | 反照率、法线深度及深度测试写入 | 16P |
| 卡通着色 | 两附件读取及卡通颜色写入 | 16P |
| 轮廓 | 五次法线深度读取、卡通读取及输出写入 | 48P |
| 合计 | 共同逻辑附件访问 | 80P |

深度测试的四字节写入在三路径中采用同一口径。
实际覆盖、重复绘制和快速清除另列模型限制。
顶点、纹理、描述符和读回流量位于模型范围外。
压缩、缓存命中及物理事务粒度由硬件解释。

局部复用场景省去反照率的写回及再次读取。
它同时假设卡通阶段的法线读取在片上完成。
这三项合计为 16P，场景估值为 64P。
法线存储及轮廓的邻域访问继续计入。

完整物化场景对三条路径均采用 80P。
局部场景的 64P 需要实际合并或局部保留条件。
两种场景分别报告，硬件计数独立列示。
H1 的结论注明采用的估算定义及证据范围。

## 独立运行与统计

正式矩阵覆盖 Pixel 6 和 RTX 4060 Laptop GPU。
每台设备使用 1920 × 1080、2560 × 1440 两个尺寸及两档网格复杂度。
每个设备、尺寸、复杂度和路径组合运行五个独立进程。
每次预热三百帧，随后保留一千个测量帧。
冻结清单记录随机种子、五轮组内路径顺序及环境门槛。
同一原始文件的重复导入按摘要拒绝。

每次运行分别计算均值、中位数及分位数。
P95 与 P99 使用有序样本的线性插值。
样本方差使用 n − 1 分母，单位为 ms²。
运行内连续帧与独立运行数分别报告。

H3 首先比较各路径的运行方差分布。
每个独立进程产生一个 GPU 时间样本方差，作为路径比较的观测单位。
同一进程的 1,000 帧用于估计该进程的方差。
每个设备、尺寸及复杂度组分别解释，同一区组内的路径进行配对。
两种局部路径可具有相同的理论流量水平。
重复运行数与不同模型水平数分别列示。

路径、模型值和硬件因素之间的混杂进入讨论。
相关或回归取决于条件数量及实际诊断。
当前描述脚本输出运行级统计及模型假设。
假设判断、区间估计和拟合由正式数据支持。

## 来源与资格

原始记录关联源码、程序、着色器和输入摘要。
设备身份、系统、驱动及功能查询进入清单。
验证层状态与捕获状态随运行记录保存。
捕获进程用于命令资格，正式计时另行执行。

每次运行前后记录供电及热状态。
Pixel 6 记录系统热状态、可读的温度传感器及电池状态。
RTX 4060 记录温度、功率、时钟、GPU 使用率及热降频标志。
正式运行独占重负载与 GPU 调度入口，关闭验证层、呈现与捕获。
接受的运行须与对应试运行的最终 RGBA 图像摘要一致。
发生热状态越界时保留排除记录，恢复后整组三路径最多重试一次。
矩阵、运行原始文件及校验工具见[跨平台采集记录](../../evidence/2026-11-12-pixel6/README.md)。
