# 技术依据与相关工作

## 非真实感渲染与轮廓负载

Bénard 与 Hertzmann 的教程梳理了三维模型线描的几何、可见性和风格化处理，并在图像空间方法中讨论法线、深度等缓冲参与轮廓提取的方式。不同算法在精度、控制能力和实时开销之间具有各自的适用范围。本研究固定卡通着色与屏幕空间轮廓计算，在相同视觉任务下比较附件传递路径。 [Bénard 与 Hertzmann，2019，第 1 章及第 8 章](https://arxiv.org/html/1810.01175v2)

## 延迟着色与数据访问

Olsson 与 Assarsson 的《Tiled Shading》比较了分块前向、分块延迟和传统延迟着色。其研究为着色组织和性能评价提供了相关背景。本研究的比较变量是 Vulkan 附件传递路径，具体测量包含固定的几何缓冲、卡通着色与轮廓。因此，对该论文的引用用于解释着色组织的研究背景，其性能数据按原论文的光照场景理解。 [Olsson 与 Assarsson，2011，出版摘要及大学出版记录](https://research.chalmers.se/en/publication/152886) [出版摘要](https://www.tandfonline.com/doi/abs/10.1080/2151237X.2011.621761)

## 子通道与片上保留

Khronos 的子通道示例将几何与光照组织在同一渲染通道中，说明驱动可在满足条件时合并子通道并保留中间附件。合并受附件布局、格式、用途及硬件资源条件影响，示例使用硬件计数器观察相关行为。本研究据此将附件保留视为需要说明条件的模型场景，并单独记录硬件事务的实际观测范围。 [Khronos，Subpasses，Merging 与 Transient attachments](https://docs.vulkan.org/samples/latest/samples/performance/subpasses/README.html)

## 动态渲染局部读取

Khronos 的 DRLR 示例使用输入附件完成同像素读取，通过附件映射、局部读取布局和按区域依赖衔接相邻绘制。其接口为动态渲染范围中的局部数据交换提供了实现方式。本项目将同像素的几何与卡通交换放入局部路径，轮廓的邻域采样由共同的外部阶段完成。这是依据访问范围作出的项目设计。 [Khronos，Dynamic Rendering local read，Input attachments 与 Self-Dependencies](https://docs.vulkan.org/samples/latest/samples/extensions/dynamic_rendering_local_read/README.html) [项目负载契约](../workload.md)

`VK_KHR_dynamic_rendering_local_read` 已进入 Vulkan 1.4 核心。官方扩展页区分单样本颜色附件读取与深度、模板、多采样读取所需的能力范围。本负载使用单样本颜色附件，设备准入按实际使用范围检查。 [Vulkan 扩展参考，Promotion to Vulkan 1.4](https://docs.vulkan.org/refpages/latest/refpages/source/VK_KHR_dynamic_rendering_local_read.html)

功能结构通过 `vkGetPhysicalDeviceFeatures2` 返回 `dynamicRenderingLocalRead`。使用该能力时，设备创建需要在对应结构中启用功能。本研究同时保存原生查询与显式启用后的设备创建结果，设备资格以实际驱动返回值为依据。 [Vulkan 功能结构参考](https://docs.vulkan.org/refpages/latest/refpages/source/VkPhysicalDeviceDynamicRenderingLocalReadFeatures.html) [项目原生资格记录](../../evidence/pixel6-qualification/pixel6-capabilities.json)

## 测量证据与研究问题

Khronos 的时间戳示例说明在命令缓冲中写入 GPU 时间戳、检查队列支持，并使用 `timestampPeriod` 将计数差换算为时间。流水线阶段的重叠使测量区间的选择影响解释。本研究固定共同三阶段的起止区间，并将 CPU 录制时间另行报告。 [Khronos，Timestamp queries，Checking for support 与 Interpreting the results](https://docs.vulkan.org/samples/latest/samples/api/timestamp_queries/README.html) [项目测量实现](../../src/benchmark.cpp)

以上来源分别提供视觉负载、数据组织、局部读取机制及计时方法的依据。由此形成的项目研究问题是，在固定 NPR 负载、附件生命周期和设备驱动下，三路径的 GPU 时间、CPU 录制时间及运行级方差如何表现，以及附件模型量与方差呈现何种分组关联。该问题由冻结矩阵的完整结果回答。 [实验方法与有效性限制](实验方法与有效性限制稿.md) [表图规格](结果章节表图规格与复现模板.md)
