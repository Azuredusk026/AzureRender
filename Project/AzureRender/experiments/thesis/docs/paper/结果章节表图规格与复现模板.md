## 复现命令与流程核对

以下命令在 PowerShell 中执行。`$run` 指向原受管任务，`$tools` 指向论文工作树的分析工具。检查点命令输出带范围标记的流程核对文件。

```powershell
$base = 'D:/Projects/FYP-worktrees/thesis-paths/Project/AzureRender/experiments/thesis'
$run = 'D:/Projects/FYP/Project/AzureRender/build/runs/20261112-215615-thesis-pixel6-experiment-b05cd7'
$py = 'D:/Projects/FYP/Project/AzureRender/build/reinstall-environment/venv/Scripts/python.exe'
$tools = Join-Path $base 'tools'
$output = Join-Path $run 'results-template-checkpoint'
& $py -B (Join-Path $tools 'audit_experiment.py') $run --checkpoint --output $output
if ($LASTEXITCODE -ne 0) { throw '检查点审计失败' }
& $py -B (Join-Path $base 'evidence/2026-11-19-results-template/verify_mapping.py') `
    --run-dir $run --export-dir $output --output-dir $output
if ($LASTEXITCODE -ne 0) { throw '表图字段映射失败' }
```
