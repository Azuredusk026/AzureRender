## 购买前检查

1. 确认完整机型、固件、驱动及 Android 版本。
2. 导出能力报告，核对扩展名称与实际功能位。
3. 核对 ADB 授权、USB 数据传输和系统更新能力。
4. 用论文原生资格程序检查组合附件用途。
5. 执行三路径短测，核对同步及图像等价。
6. 核对电池、散热、持续运行及退换条件。

基准使用原厂驱动通道，并记录设备来源。
可解锁引导程序属于维护条件，按实际需要选择。
SIM 无锁与引导程序解锁分别核实。
三路径通过后才冻结正式移动设备条件。
