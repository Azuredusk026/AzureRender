## 准入条件

能力查询同时检查扩展与实际功能位。
格式查询使用实际组合用途及样本数。
局部读取限定同像素颜色附件。
深度和多采样局部读取各有独立资格。

轮廓跨像素读取需要完整的外部依赖。
局部按区域依赖只用于卡通着色交换。
背景像素、边缘夹取与输出量化统一。
附件生命周期决定流量模型的可用假设。

## 验收与阻塞

CPU 录制计时排除等待、提交及呈现。
GPU 时间戳覆盖几何缓冲开始至轮廓完成。
读回及图像保存安排在测量区间外。
统计先按独立运行计算方差与分位数。

候选矩阵为两设备、两尺寸及两复杂度。
每路径拟做五次独立运行，每次一千测量帧。
矩阵须经资格及试运行冻结。
移动设备未连接时保留相应待验状态。
