# 统计与附件模型

`tools/analysis.py` 按独立运行生成描述统计。
输入为基准输出的 `run.json` 文件。
每个文件分别报告 GPU 与 CPU 录制指标。
原始文件摘要用于拒绝重复导入。

```powershell
python -B tools/analysis.py <运行一>/run.json <运行二>/run.json --output <受管任务>/summary.json
```

统计包含均值、中位数、P95、P99 及样本方差。
方差使用 n − 1 分母，单位为 ms²。
分位数使用有序样本的线性插值。
无效数值会中止分析并报告错误。

工具核对路径、样本数量和实际调用计数。
三条路径的共同逻辑附件模型为每像素八十字节。
局部复用场景为每像素六十四字节。
模型保留法线存储与轮廓的五次邻域访问。

完整物化场景对三条路径采用相同逻辑量。
局部场景有明确的附件保留假设。
硬件流量计数与上述模型分别解释。
顶点、缓存、压缩和读回属于模型边界。

## 正式结果表

`tools/audit_experiment.py` 核对冻结矩阵、运行索引、原始文件和试运行，并生成运行表与条件表。
调用入口和采集条件见[续跑记录](resume.md)。
当前流程验证使用 `paused-checkpoint`，覆盖已接受的 90 次运行。所有 24 个条件均列出实际和计划运行数，文件名带 `checkpoint-` 前缀。
正式导出要求 40 个区组全部通过，每个条件包含五次独立运行。

| 文件 | 每条记录的单位 | 字段 |
| --- | --- | --- |
| `run-summary.json` | 一次独立进程 | 设备、尺寸、复杂度、路径、轮次、区组、原始文件摘要、GPU 与 CPU 录制的时间统计、附件模型 |
| `condition-summary.csv` | 一个设备、尺寸、复杂度与路径组合 | 数据范围、独立运行数、运行统计量的中位数、每个运行的测量帧数、模型字节量、区组内的配对差异 |

GPU 方差在每个进程的 1,000 个 GPU 时间样本上计算，得到一个样本方差，单位为 ms²。
路径比较以独立进程为统计单位。同一进程的帧是运行内观测。
条件表取各独立进程方差的中位数，并记录与同一区组传统路径配对后方差较低的运行次数。
相对 GPU 时间以区组内的运行均值计算百分比变化，再汇总中位数、最小值和最大值。

H1 按附件模型描述估算量。两条局部路径在该模型中使用同一个局部复用场景值。
H2 在固定分辨率和复杂度下比较两台设备的 DRLR 与子通道配对差异。外推范围限于实测设备及驱动。
H3 按设备、分辨率和复杂度报告模型水平与运行方差的描述性关联，并讨论路径与模型值的混杂。
三项假设的正式解释以完整矩阵为依据。
