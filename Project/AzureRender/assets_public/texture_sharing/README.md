# 纹理共享夹具

本目录包含自主生成的合成资产。
资产按 CC0 1.0 提供。
两个 glTF 文件具有独立路径与材质名称。
几何为一个三角形，贴图为 2×2 棋盘格。

全部缓冲与图像嵌入 glTF。
夹具可随仓库移动和独立加载。
`MaterialTextureSharingTests` 经生产加载器读取两份资源。
测试覆盖固定和索引描述符，以及卸载后重新加载。

每份资源带有显式材质与加载器的后备材质。
两个资源共发出 32 次有效纹理槽请求。
完整键对应 9 份唯一纹理和 23 次缓存命中。
逻辑图像字节为请求 576 字节、驻留 164 字节。

运行说明见 [材质纹理共享](../../docs/runtime/sampled-texture-cache.md)。
