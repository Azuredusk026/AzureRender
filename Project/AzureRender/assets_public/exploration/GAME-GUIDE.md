# 探索关卡操作说明

使用 WASD 移动，Shift 冲刺，空格跳跃。
鼠标旋转相机，滚轮调整距离。
E 触发当前提示的交互，R 重新开始。
Esc 释放光标，点击游戏区域恢复控制。

先与起点的引导角色交谈。
沿沙土道路寻找金色石柱旁的三个物件。
检查点位于道路中段，坡道用于练习地形移动。
收集完成后，打开蓝色灯光标记的大门。

进入大厅尽头即可完成探索。
步行速度为每秒两米，冲刺速度为每秒五米。
路线包含短距离支路，通道宽度为 4.6 米。
素材与生成来源见 ENVIRONMENT-GENERATION.json。

探索完成后按 E 进入平台跳跃。
平台采用金币引导，掉落返回检查点。
平台中的 R 重新开始平台关卡。
